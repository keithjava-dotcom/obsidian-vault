# Gemini蒸馏器

这是 OpenClaw 的外部模型审美蒸馏库。

它不绑定 Gemini API。今天用 Gemini，明天换 Claude / GPT / 其他模型，所有样本、差异拆解、规则候选都继续保存在这里。

## 一句话流程

OpenClaw 打包原素材 + dagang + 初稿 → 柯哥丢给 Gemini → 柯哥回传 Gemini 稿 → OpenClaw 归档 → 拆解差异 → 生成规则候选 → 经实战验证后回灌 fanwen。

## 铁律

- 保存原始输入，不只保存结论。
- 外部模型稿不能直接覆盖正式稿。
- Gemini 好，不代表全对；事实、主视角、商业落点仍由 OpenClaw 核。
- 单次好句不升级全局规则。
- 规则必须能迁移，不能只收藏漂亮句子。
