# 冉总IP 账号语言档案候选池

用途：承接反哺队列升到 L2 的账号级规则。目标是给冉总 IP 未来的语言档案打底稿，等到同账号再验证 2 次以上就可升 L3 写进语言档案本尊/评分尺。

## 池内规则（2026-07-08 Claude 拍板批次）

### 1. SOP 具象化 + 情感锚保留 + fanwen 二次审视

- 来源案件：冉总IP-同行抱怨没订单我同一天接两个大单（冉总09）
- 适用场景：服务流程 + 真实情绪并存的稿
- 要点：SOP 不能是抽象名词，必须落到"看得见的动作+关系+后果"；情感锚（客户原话/现场画面/砸锤瞬间）不能被总结代替；fanwen 出稿后要二次审视一遍是不是把这两条丢了。
- 待验证方向：下次冉总 IP 有服务流程类稿时，主动套一遍，看是不是仍然命中。

### 2. 主线纯度 + 起手对抗 + 结尾硬度

- 来源案件：冉总IP-全员放假省里来人了（冉总07）
- 适用场景：破偏见 / 商业高光类稿
- 要点：主线只服务一个判断，不掺杂枝节；开头就摆冲突对象（对手/偏见/传闻）；结尾必须硬到能砸下去，不能软收。
- 交叉写回：同时进 [[稿类候选池-破偏见商业高光]]。
- 待验证方向：等冉总 IP 下一次商业高光/破偏见稿再套一次。

### 3. 先入场再讲商业判断 + 砸锤后保留商业落点

- 来源案件：冉总IP-异业门店二维码下单模型测评
- 适用场景：招商口播稿类
- 要点：不上来就商业判断，先把冉总本人推到现场；砸锤（点出偏见/亮出立场）后不能直接切走，必须留一个明确的商业落点（合作邀请/资源接口/下一步动作）。
- 交叉写回：同时进 [[稿类候选池-招商口播]]。

### 4. 关键信息节点不碎拆

- 来源案件：冉总IP-急刹车与送钱局（反向蒸馏）
- 适用场景：冉总 IP / 极短句风格分组
- 要点：人名 + 身份 + 动机是一个信息束，必须拧紧后再拆句；不能为了追极短句节奏把这个束拆散，否则观众抓不到主角。
- 归类：极短句风格分组（冉总常态节奏）。
