# 招商口播稿类方法论候选池

用途：承接反哺队列升到 L2/L3 的招商口播类规则。目标是给未来所有招商口播稿（不限 IP）打底稿，等跨账号再验证就升到全局。

## 池内规则（2026-07-08 Claude 拍板批次）

### 1. 先入场再讲商业判断 + 砸锤后保留商业落点【L2】

- 来源案件：冉总IP-异业门店二维码下单模型测评
- 要点：不上来就抛商业判断；先把主 IP 拉到现场（在门店/在车上/在会议桌），观众看得见你在哪、在做什么，再讲判断；砸锤之后不能直接切走，必须把商业落点（合作方式/接口/下一步动作）说清楚——否则前面砸得越硬，后面越浪费。

### 2. 叙事完毕后加一道商业转化问诊【L2】

- 来源案件：冉总IP-急刹车与送钱局（反向蒸馏）
- 要点：叙事讲完，别默认观众"自己会转化"；加一道明确的问诊——"你现在面对的是不是这种局面 / 你手里的资源是不是也在这个坑里"；然后才是招商邀请。相当于给招商稿装一个把叙事和商业动作焊起来的关节。
- 合并说明：与第 1 条属于同一稿类的两个位置（一个管开场入场，一个管收口问诊），实际使用时联动。

### 3. 收口钩子从完成感转向参与感【L3 · 待跨账号验证】

- 来源案件：冉总IP-急刹车与送钱局（反向蒸馏）
- 要点：结尾钩子不做"我讲完了/这就是全部"这种完成感表达；改为"你要不要接一把 / 你想不想进来试一次"这种参与感钩子。招商口播里这条尤其明显——完成感 = 门关上；参与感 = 门留着。
- **状态说明**：柯哥拍板停在 L3，**不升 L4，不动 fanwen 轻量反哺包全局**。
- **待跨账号验证**：**冉总 IP 只有一次样本，差 2 次跨账号才能升 L4**。未来 Claude 拿到线索：等到黄倩/其他招商口播账号也出现同款场景，命中即记一次；累计 2 个跨账号有效样本 + 柯哥点头 → 才升 L4 写进 fanwen 轻量反哺包全局。

## 使用方式

- 招商口播稿下一次写完，用这三条做后置检查。
- L2 两条累计 2 次以上稿类内命中 + 柯哥点头 → 升 L3 稿类方法论定稿。
- L3 那条走跨账号计数，不走同账号计数。
