# Gemini口播审美评分尺

用于 fanwen 出稿前和整流拆解时校准口播手感。

## 四个正向标准

1. 每句都在推剧情  
   没一句只是解释背景；每句话都让事情往前走。

2. 用词像刀  
   两个字能砸出画面，不用四个字解释概念；少形容词，多动作、物件、数字。

3. 节奏有呼吸  
   短句是刀，长句给情绪落地；不是一路短句发电报，也不是一路长句做汇报。

4. 砸锤不解释  
   结尾定音后停，不补“所以我觉得”“希望大家”。

## 六格审美校准

| 维度 | 通过标准 |
|---|---|
| 进场感 | 人在现场，不是站外讲解 |
| 剧情推进 | 每句都有动作或判断推动 |
| 用词刀口 | 抽象词被砸成动作/物件/数字 |
| 呼吸节奏 | 读出来不卡、不碎、不像播音 |
| 砸锤方式 | 最后一句有力量，且不解释 |
| 商业落点 | 不为了文采丢掉招募、转化、成交任务 |

## Gemini常见风险

- 可能编画面动作。
- 可能让结尾太文艺，断掉商业线。
- 可能把 IP 主视角写错。
- 可能为了顺口牺牲事实证据。
