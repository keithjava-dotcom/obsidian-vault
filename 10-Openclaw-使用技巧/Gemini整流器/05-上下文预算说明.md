# 上下文预算说明

目标：让 OpenClaw 像橄榄球运动员，肌肉发达但灵活。

## 原则

1. 仓库可以大，入口必须小。
2. 样本原文只在整流任务里读，fanwen 默认不读。
3. fanwen 只读轻量反哺包；命中当前账号时，再读最多 1-3 个差异拆解。
4. 规则升级必须经过 L1-L4，不让单次好稿污染全局。
5. 每个 Skill 只拿自己当前棒位需要的信息，不越权读全链路。

## 推荐读取顺序

fanwen 写稿：

1. dagang 真文件。
2. 当前客户语言风格。
3. `fanwen轻量反哺包.md`。
4. 如命中当前客户强正样本，最多 3 个 `03-差异拆解.md`。

整流任务：

1. 当前案件的投喂包。
2. 当前案件的模型回稿。
3. 当前案件的差异拆解。
4. 写入规则候选和反哺队列。
