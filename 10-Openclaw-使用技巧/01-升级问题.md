📝 OpenClaw 升级与排坑全记录 (v5.22 -> v5.28)

📌 一、 标准更新流程

日常升级 OpenClaw，最标准的官方推荐指令只有一条：

openclaw update

(注：该指令会自动拉取新版本、执行 doctor 体检并尝试重启网关服务)

⚠️ 二、 常见问题与排坑指南

坑点 1：更新时提示 “Downgrading to latest (unknown)”（降级警告）

  - 现象：终端出现黄色警告，询问是否继续 (Downgrading from 2026.5.22 to latest (unknown) can break
    configuration. Continue?)，并且上方有 fetch timeout 的报错。
  - 原因：网络连接 NPM 官方源超时，导致系统无法获取最新版本号，误判为“降级”。
  - 解决办法：
    1.  千万不要选 Yes！ 选 No 或按 Ctrl + C 终止更新。
    2.  切换为国内镜像源（如淘宝源）：
        npm config set registry https://registry.npmmirror.com
    3.  重新执行 openclaw update 即可顺利完成更新。

坑点 2：更新显示成功，但服务无法启动

  - 现象：终端提示更新完成，但执行 openclaw gateway start 或 restart
    没有反应，或者客户端连不上。日志里有一句隐蔽的提示：Your
    OpenClaw config was written by version 2026.5.28, but this command is
    running 2026.5.22.
  - 原因：典型的 macOS 路径冲突（PATH）。旧版的后台守护进程（LaunchAgent）还霸占着旧路径，导致新版配置无法被正确加载。
  - 解决办法（强制重新绑定服务路径）： 关闭当前终端，重新打开一个全新的终端窗口，依次执行：
    # 1. 彻底卸载旧的后台常驻服务
    openclaw gateway uninstall

    # 2. 用当前新版本的路径重新安装服务
    openclaw gateway install

    # 3. 启动服务
    openclaw gateway start

坑点 3：浏览器仪表盘（Dashboard）提示“需要认证”连不上

  - 现象：打开网页控制台时，提示“Gateway 可以访问”，但要求输入“网关令牌（Token）”。
  - 原因：网关服务重装后，浏览器缓存的旧凭证失效。
  - 解决办法（二选一）：
      - 方法 A（最简单自动登录）：关掉当前网页，在终端直接输入 openclaw dashboard，系统会自动带上正确的令牌并在浏览器中打开。
      - 方法 B（手动获取）：在终端输入 openclaw config get
        gateway.token，复制输出的那串字符，粘贴到网页的“网关令牌”框内，点击连接。

🧹 三、 强迫症清理：消除烦人的黄色警告 (Config warnings)

每次敲击命令都会弹出大段重复插件或找不到插件的黄色警告，可以用以下命令清理干净：

# 清理不存在的飞书配置（如果你不用飞书）
openclaw config remove plugins.entries.feishu

# 清除冲突的重复微信插件
openclaw plugins uninstall @tencent-weixin/openclaw-weixin

✅ 四、 验证环境是否完全健康

完成所有操作后，可以通过以下命令检查当前系统的最终状态：

# 检查当前版本（应显示最新版，例如 2026.5.28）
openclaw --version

# 检查网关深度状态（状态全绿即为正常）
openclaw gateway status --deep
