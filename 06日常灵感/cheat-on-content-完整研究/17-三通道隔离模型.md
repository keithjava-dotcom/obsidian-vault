# 三通道隔离模型（Channel A / B / C）

这是 cheat-on-content 整个项目最精妙的工程设计。花时间理解它——比学任何具体 skill 都值。

## 背景问题

AI Agent 给内容打分的核心困境：**主对话已经被污染了**。

- 用户曾经说过"上次那条跑 70w"
- 主 Claude 读过复盘段、看过实绩数据
- 写 prediction 时已经在心里有了"这条大概会是什么水平"的后视镜

这就是"自己骗自己"的问题。不解决它，所有打分都等于"已经有了答案再回推理由"。

## 三通道解

| Channel | 角色 | 输入 | 风险 |
|---------|------|------|------|
| **A = 主对话** | 跟用户交互、决策、写复盘 | 全部上下文 | 被实绩/用户态度污染 |
| **B = blind sub-agent** | 一份未受污染的打分 anchor | **只** script + rubric_notes.md | 仍是 Claude，RLHF prior 共享 |
| **C = 跨模型 audit** | bump 终局 sanity check | 校准池数据 + 新公式 | RPM 限制、模型差异 |

## Channel A → 主对话（我们都在用）

做决策、跟用户讨论、写复盘文件。**天然被污染**——它的输入包含了实绩数据、用户情绪、历史复盘。

## Channel B → blind sub-agent（核心创新）

通过 Task tool 把一个打分动作丢进**全新 context**。这个 sub-agent：
- 没看过主对话
- 没读过 state
- 没碰过 predictions/
- 只读了 script 全文 + rubric_notes.md

**它不决策，只打分**。把结果回传给主对话，主 Claude 用它当对照，不当真理。

## Channel C → 跨模型审计（最外层刹车）

bump 时调 mcp__llm-chat__chat（qwen-max）做独立审核。只干一件事：看新公式的排序一致性是否真的成立。

Channel C 不是每次 predict 都调——只有 bump 才调。**成本可控**。

## Disagreement Detection（Phase 2.5）

这是三个 channel 之间的关键交互：

1. Channel B sub-agent 给出 9 维盲打分
2. Channel A 主 Claude 自估一份（内心估，不落盘）
3. 对每个维度算 delta = |主估 - blind|
4. 任意维度 delta ≥ 2（默认阈值）→ 弹给用户裁定：
   - a) 信 sub-agent（隔离打分但同 Claude 模型）
   - b) 信主 Claude（有更多上下文但可能是 contamination）
   - c) 用户自己给分

**所有 delta 都记录到 BlindScore Disagreement 字段**——即使 delta=0 也记。复盘时分析"哪类维度 sub-agent 与主 Claude 系统性分歧"是 rubric 演进的重要信号。

## 已知但接受的三项污染

项目最诚实的地方——承认三个 channel 都不完美：

1. **Channel B 的模型 prior**：sub-agent 仍是 Claude，RLHF 共享——它的"盲"不代表另一个判分体系，只是另一个 context 窗口
2. **Rubric 设计 bias**：rubric_notes.md 是用户自己写的，自然偏向自己内容。Sub-agent 用这个 rubric 打分天然喜自己的内容
3. **Channel B 需要主 Claude 发 Task prompt**：如果主 Claude 在 prompt 里不小心塞了"播放数"信息，contamination 就发生了——所以有 grep 自检

**所有三项都在 bump 报告里诚实标注。不假装完美隔离。**

## 对我们体系的意义

我们用 OpenClaw 的 sessions_spawn 可以实现类似 Channel B：

```
fanwen 写完 → spawn sub-agent ← 只收 [脚本全文, rubric标准]
                  ↓
              纯 JSON 打分 → 回传主对话

主对话拿到打分 → 自估一份 → 对比 → 弹柯哥裁定
                                     ↓
                              记录分歧 → 落盘
```

不完美（sub-agent 仍是同一个 DeepSeek 模型），但比"主对话 inline 打分"好 10 倍。

## 核心哲学

> Channel A 是发动机，Channel B 是导航仪，Channel C 是质检员。

发动机决定方向，导航仪提供 unbiased 参考，质检员在关键决策前做最终检查。
