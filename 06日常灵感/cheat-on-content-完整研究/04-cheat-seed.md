# cheat-seed — 选题生成器

## 定位

跟用户讨论选题的对话式工具。核心是**听用户讲→帮提炼角度→写一份 draft**，不是 AI dump 15 候选让用户挑。

## 四种模式

### Mode A — 用户主动给主题（最常见）
用户说"我想做一条关于 X 的" → AI 深挖触发瞬间/情绪锚点 → 收敛到一个具体角度 → 写 1 份 draft

### Mode B — 用户给方向但不具体
用户说"想做职场" → AI 单问"为什么想做这个？" → 逼出真动机

**关键设计**：只问 1 个问题，不扔 a/b/c 三种例子。用户回答含具体经历 → 转 Mode A；抽象热度归因 → 再问一次；真没想法 → 转 Mode C。

### Mode C — 用户完全没想法
调热点工具抓今天的话题 → 用户挑 → 回到内省深挖

**兜底路径**：回到"聊经历"三选项——a) 最近真实接触的事 / b) 最近想吐槽的内容 / c) 长期琢磨的困惑

### Batch Mode — 显式要批量（`/cheat-seed --batch N`）
保留旧的 brainstorm N 候选 + 写 N 份 draft 流程

## 工作流详情

```
Mode A:
[用户给主题]
→ Phase 2A: 深挖（最多 4 轮反问，一次 1 个问题）
→ Phase 2A.5: 时事判断（如话题涉时事→问用户要不要拉外部数据）
→ Phase 3: 收敛输出（一句话立意 + 走法 + 粗打分）
→ Phase 4: 写 draft（按 script_patterns 选结构）
→ Phase 4.5: humanizer 去 AI tells（em-dash/rule of three/inflated 词汇）
→ Phase 5: 展示，用户改或确认
```

## Mode A 的反问类型

- **触发瞬间**："最初是哪个具体瞬间触发你想做的？"
- **情绪锚点**："这里面最让你觉得有意思的是哪个细节？"
- **角度选择**："你想说的是现象批判 / 自我反思 / 泛化到普遍？"
- **受众想象**："你心里想着是说给哪种人听？"
- **反对意见探测**："如果有人反驳说 [反方观点 X]，你会怎么回？"

**纪律**：一次只问 1 个问题，最多 4 轮。用户不耐烦→立刻收敛。

## 收敛输出格式

```
我感觉这个角度能做：

[一句话立意：50 字以内]

走法：
- 用 [Pattern X 结构]（来自 script_patterns.md）
- 钩子：[具体场景/句子]
- 主体：[3 个观察是什么]
- 收尾：[MVP 句方向]

粗打分（v0 等权 7 维）：ER=X HP=X ... → composite ≈ X.X
Confidence: 🔴 极低

要不要让我先写一份 draft？
```

## 关键设计洞见

1. **默认对话式一次一个**，batch 是 escape hatch——好内容来自用户的真实经历，AI 不可能凭空 brainstorm 出来
2. **B 模式只问"为什么"**，不扔选项——逼内省不是给选择
3. **热点驱动只出现在 C 模式**（完全没想法时），不是默认——区分"用户有素材"和"用户需要素材"
4. **暂写 draft 后走 humanizer**——去 AI 写作 tells，但不动 header 的"必须改写"警告
5. **读 audience.md 做"谁在看"镜子**——Confidence 🟡 以上才当检验视角

## 和我们的 xuanti-workflow

xuanti 的 15 角度发散法更结构化、适合批量产出。cheat-seed 的对话式深挖更个性化。可以结合：xuanti 出 15 候选 → cheat-seed 深挖精选的几个。
