## 安装卸载

**安装**（用户运行）：
```bash
git clone https://github.com/XBuilderLAB/cheat-on-content.git
cd cheat-on-content
bash install.sh              # Claude Code
bash install.sh --codex      # Codex
bash install.sh --all        # 两个都装
bash install.sh --copy       # 冻结版本（不 symlink）
```

14/15 个子 skill symlink 到 agent skill 目录。adapter 目录不 symlink——它们在用户克隆目录里由 cheat-init 引导配置。

**卸载**：
```bash
bash uninstall.sh            # Claude Code
bash uninstall.sh --codex    # Codex
```

**升级**：git pull + /cheat-migrate（老用户）。1.3→1.4 是 BREAKING 修复——不跑 migrate 盲打分持续报 non_blind_warning。
