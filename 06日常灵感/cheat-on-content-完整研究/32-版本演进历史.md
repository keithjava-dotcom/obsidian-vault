# CHANGELOG — 版本演进历史摘要

从原始 CHANGELOG 提取的关键版本故事。按问题→修复模式记录，每个版本讲一个"发生了什么问题→怎么修的"。

## 版本演进大事记

### 初始版本（v0.1.0）
- 7 维打分（ER/SR/HP/QL/NA/AB/SAT）
- 观点视频 rubric，基于 25+ 样本拟合
- Cold-start/calibration 双模式
- Cold-start-simple/complete 双预测复杂度
- 绝对/比率/百分位 三套 bucket 方案

### v1.0 — 首次重构
**问题**：mode（cold-start/calibration）、prediction_complexity（simple/complete）、bucket_scheme（三套）三个二元选项带来分裂的用户体验——用户在第 5 篇突然解锁完整版，UI 割裂。

**修复**：全部删除。统一 7 组件预测结构，confidence 等级派生自 calibration_samples。一个格式走到底。

### v1.1 — 发布频率+线索 cadence（MINOR）
- 新增 target_publish_cadence_days
- Buffer 转换到"buffer_days"（按用户 cadence 派生），不再按"篇数"
- 优先同时长锚点

### v1.2 — Channel B 引入（MINOR 大改）
**问题**：AI 自己在主对话里打分——但主 Claude 看过实绩数据，打分被污染。bump 时 rank 一致性可能 overfit 而非真信号。

**修复**：
- 引入 cheat-score-blind sub-agent（Task tool 隔离 context）
- 三通道模型：A=主对话，B=blind sub-agent，C=跨模型 audit
- Phase 2.5 disagreement detection——|delta|≥2 弹用户裁定
- BlindScore Disagreement 全维度记录
- --skip-blind flag 标记 last_prediction_self_scored

### v1.3 — 路径泄漏修复（BREAKING）
**问题**：douyin-session adapter 把 cookie/debug/report 写到 skill 源码目录——用户的会话凭据有被 commit 的风险。meta-logging hook 过度采集（存 prompt 摘要）。

**修复**：
- 新增 paths.py 运行时路径 helper
- .auth/→用户项目根，debug→.cheat-cache/
- meta-logging 缩为只记 prompt_present(bool)+长度

### v1.4 — 文件拆分（BREAKING，最关键修复）
**问题**：cheat-bump Phase 5 把升级 Memo 写进 rubric_notes.md——sub-agent 通过白名单读到了实绩数据。实测 5 条已发视频里 2 条 sub-agent 自报 non_blind_warning。

**修复**：
- 拆 rubric_notes.md + rubric-memo.md（盲白名单 vs 含实绩档案）
- cheat-score-blind 硬禁读 rubric-memo.md
- cheat-bump Phase 5 leak guard（grep 自检，命中→abort+回滚）

### v1.5 — 受众画像（cheat-persona）
- 新增第 15 个子 skill
- 四维聚类：自我认同/情绪寄存/反驳点/语言
- 强制反画像
- audience.md 硬禁读（refusal_code blocked_audience）

### v1.6 — diff 修复
**问题**：line-level diff 在口语化转录场景严重误报——draft markdown 长句 vs whisper 短断行（内容同，行数差 3x），line-level 算出 ~200% diff。

**修复**：char-level Levenshtein（normalize 后），rapidfuzz 优先，difflib fallback。3 fixture × 2 backend 全过。

### v1.7 — Seed 改成对话式
**问题**：用户反馈 cheat-seed 的 draft 正文是"一行一句"的字幕格式。Draft 写完后 AI tells 重（em-dash/rule of three）。

**修复**：
- 加 humanizer skill 去 AI tells
- 加 format 自检（avg_chars_per_line）
- 默认 Mode A（对话式深挖一次一个），batch 作为 escape hatch

### v1.8 — README 递归宿命版 + 中文版
- README tagline 改："你正在读这段话——这个 skill 预测过了。"
- docs/README_CN.md 中文版
- docs/logo.svg + star-history 图表

### 已知未解决的问题

1. sub-agent 仍是同 Claude 模型——RLHF prior 共享，新 context ≠ 新判分体系
2. Rubric design bias——用户自己写的 rubric 自然让内容显得好，由 Channel C 审计和定期 bump 解决
3. persona 只有评论数据→偏向会评论的活跃少数
4. 评论可被水军污染
