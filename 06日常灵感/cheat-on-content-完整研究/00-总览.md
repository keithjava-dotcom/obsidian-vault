# cheat-on-content 总览

## 一句话概括

一套给 AI Agent（Claude Code / Codex）用的**内容预测-复盘-进化工作流**。由 XBuilderLAB 开发，MIT 开源。15 个子 skill 构成闭环，把创作者的"我感觉这条能爆"变成可校准的实验。

## 核心工作流（5 阶段闭环）

```
📊 打分 → 🎯 盲预测 → 🚀 发布 → 📈 T+3d 复盘 → 🧬 进化评分公式
```

## 三条不可违反的设计原则

### 原则一：盲预测不可改（Blind Prediction + Immutability）

预测段一旦写入 predictions/*.md 的 `## 预测` 段，字符级不可修改——由 hook 层强制拦截任何 Edit 操作。复盘只能在文件末尾追加 `## 复盘` 段。

**为什么**：预测段被事后修改后，所有"哪个维度被验证/推翻"的判断都失去基线——不知道当初是真预测对了，还是事后改对了。

**校准价值** = 预测精度 × 预测可信度。预测精度可以靠 rubric 升级慢慢提升；预测可信度一旦破坏不可恢复。

### 原则二：升级 = 全量重打（Bump = Full Re-score）

Rubric 公式升级时，校准池所有有实绩数据的样本必须用新公式重打分。新排序与实际表现排序若在 ≥80% 样本上不一致，升级被拒。升级必须经跨模型独立审核（Channel C）。

**为什么**：防止"调权重直到拟合已有数据"——那不是校准，是 overfit。

### 原则三：Rubric 是工作台不是博物馆

被新数据推翻或被吸收为正式维度的观察，删除。不要留"我曾经以为 X，但其实..."的考古层。Git history 才是档案。

## 三通道隔离模型（Channel A / B / C）

这是项目最精妙的设计：

| Channel | 输入 | 用途 | 风险 |
|---------|------|------|------|
| A = 主对话 | 全部上下文 | 跟用户交互、写复盘、决策 | 被实绩/用户态度污染 |
| B = blind sub-agent | 只读 script + rubric_notes.md | 一份未受污染的打分作为 anchor | 仍是 Claude，RLHF prior 共享 |
| C = 跨模型 audit | 校准池数据 + 新公式 | bump 终局 sanity check | RPM 限制/模型差异 |

A 决策时把 B 当对照看 disagreement，不当真理。C 只在 bump 终局调一次。

详见 `16-三通道隔离模型.md`

## 价值排序（对我们）

1. **盲预测 + 不可改** → 填补 fupan-workflow 的核心缺陷
2. **Rubric 体系 + 升级回测** → 让判断积累成为可量化的系统
3. **Channel B 隔离打分** → 防自己骗自己的工程保障
4. **预测 7 组件解剖** → 反事实场景+锚点对比+关键校准假设
5. **Buffer 警戒系统** → cadence 管理
6. **受众画像聚类** → 从评论数据反推
