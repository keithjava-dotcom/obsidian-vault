# 韬定律 + 第二曲线 · 讨论笔记

## 华为"韬定律"是什么？

**一句话**：芯片性能提升，不一定要把晶体管越做越小——可以把信号跑的路程缩短。

**背景**：摩尔定律（晶体管每两年缩小一倍）在7纳米以下撞墙。华为2019年被制裁后，根本用不了最先进光刻机，必须另找路。

**核心**：τ（tau，时间常数）——芯片快的本质不是"小"，是信号从A到B花的时间短。韬定律 = 不缩尺寸，压时间。

**技术**："逻辑折叠"——把平铺的电路纵向堆叠（像盖楼不是铺院子），信号纵向穿越，路程缩短。

**数据**：华为6年量产381款芯片。预计到2031年，基于韬定律的芯片晶体管密度达到1.4纳米制程同等水平。

**底层方法论**（柯哥提取）——跟金字塔原理完全同构：

| 步骤 | 华为做了什么 |
|------|------------|
| 界定问题 | "几何缩微"走不下去了 |
| 分析框架 | 芯片性能本质是压缩时间 |
| 找方案 | 逻辑折叠——纵向堆叠替代平面铺开 |

## 第二曲线：柯哥的理解 + 小龙补充

### 柯哥原理解
> "不走常规路，以解决问题和结果为第一目标做事情。不用考虑常规的做事方法。"

**判断**：抓住了第二曲线的**精神**（打破旧规则），但缺了最关键的**时间要素**。

### 第二曲线的完整定义（查尔斯·汉迪）

核心不是"换条路走"，而是 **"在第一曲线到顶之前，就主动开始第二条"**。

三个关键：
1. 第一曲线顶峰时你有资源（钱、信心、团队）——这时候布局第二曲线
2. 等到第一曲线下滑了再找，那是自救，不是布局
3. 第二曲线刚开始一定向下（投入期），需要第一曲线养着

### 柯哥自己的第二曲线

```
第一曲线：操盘手 → 交付累，复利低
第二曲线：新媒体教学（4980） → 产品化，可规模
```

不是操盘做不下去了才转教学。是操盘还在跑的时候就开始布局教学。

### 第二曲线 vs "换条路"

| | 第二曲线 | 随便换赛道 |
|--|---------|----------|
| 时机 | 第一曲线到顶前 | 什么时候都行 |
| 资源 | 有第一曲线养着 | 断了后路 |
| 心态 | 从容布局 | 焦虑自救 |
| 关联 | 跟第一曲线有关联 | 毫无关联 |
