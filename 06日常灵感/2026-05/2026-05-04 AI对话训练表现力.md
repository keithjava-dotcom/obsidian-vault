# AI对话训练表现力

## 灵感来源

柯哥看完安先生最新视频后的思考：
"关于我如何提高表现力，我可以给AI设定一个提示词，让AI跟我对话，这样的话，我觉得我能输出内容更加自然一些。"

## 为什么这个思路对

**核心问题**：对着镜头说话像在"表演"，不像在"说话"。
**观影规律**：安先生说——观众看视频是"一个人看另一个人"，有第六感。观众能感觉到你是不是真的在跟人交流。
**解决方案**：不看镜头，看对话对象。AI就是这个对象。

## 运作逻辑

```
传统录视频：
  柯哥 → 看镜头 → 背/念稿子 → 表情僵硬、情绪假
                          ↓
                    观众感觉："这人在表演"

AI陪练模式：
  柯哥 → 看屏幕上的AI回复 → 自然回应 → 表情真实、情绪自然
                                ↓
                          观众感觉："这人在跟我说话"
```

关键是：**有来有回才有真情绪**。一个人对墙说话和对一个人说话，能量完全不同。

## 提示词设计思路

给AI的设定：
1. 扮演一个对新媒体感兴趣的创业者/老板
2. 根据视频选题，抛出真实的问题和困惑
3. 在柯哥给出关键观点时追问
4. 偶尔质疑、偶尔共鸣——制造真实的对话张力
5. 不抢戏，主要作用是"垫话"——让柯哥有话可接

## 使用方式

```
拍摄前：
  1. 确定本期视频选题
  2. 给AI设定角色和对话方向
  3. 柯哥对着电脑/手机屏幕，跟AI自然对话
  4. 摄影师从侧面拍柯哥（不看镜头，看屏幕）
  5. 后期只保留柯哥的声音和画面，AI的"垫话"是拍摄辅助，不剪进去

效果：
  柯哥的表情、语气、情绪都是真实的对话反应
  观众看到的是一个"正在跟人说话"的人，不是"正在表演"的人
```

## 和安先生理论的连接

安先生说"生命力是永恒的流量密码"。
生命力从哪来？从真实的交流中来。
你对着镜头表演 → 生命力被消耗
你对着一个真实对象交流 → 生命力被激发

这个AI陪练法，本质是：**用对话激发生命力，而不是用表演消耗生命力。**
