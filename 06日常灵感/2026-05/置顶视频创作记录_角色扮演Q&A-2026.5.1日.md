# 置顶视频创作记录 · 角色扮演Q&A

## 背景

柯哥要出一条置顶视频，回答"我是谁，凭什么关注我"。
采用角色扮演方式：小龙扮演目标用户（传统老板），连续追问四个扎心问题，柯哥即兴回答。聊出了真实定位。

---

## 完整对话

### 问1：你跟市面上那些99块割韭菜的课有什么区别？

**柯哥**：我凭什么，我凭我能给到所有行业一个确定性方向。

我是自学的，但我学的东西是从科班出来的——跟北京电影学院导演学的拍片、视听语言。后来做B站健身博主、小红书博主，因为条件原因没做下去。然后去上班，给小红书博主做文案，8个月从3万粉做到13万粉，商单从300块做到2万。

离职后做代运营，专挑同行不敢干的行业——医美、医院，都是敏感行业。医美账号0起盘到变现不超过3个月。后来做汽修、装修、三农，还做过千万播。然后又做招商——科技类招商6-8个月业绩400多万，家政招商2000粉到8000粉，单周客资130+，一个月400+。

我的课不卖便宜。只要有生意，嫁接到我的思路，我能给你确定性方向。我还做前三个月陪跑，每条稿我帮你写，三个月后你写我审。你问我越多，你得到越多。

### 问2：给一句大白话，你到底帮人解决什么问题？

**柯哥**：帮你赚钱。只要你的产品在线下能卖，行业正规合法，我帮你做乘法，×10或者×100。

### 问3：你跨那么多行业，怎么做到的？

**柯哥**：很多老板拍视频的目的是销售，不是拍视频。我懂用户心理，我懂短视频规则语法。视频第一步是给平台算法看，算法过了才推给人。我总结出一套公式，跨行业套公式就行。

举个干货——起号最简单的方法：讲内幕。医美内幕、医院内幕、家政招商内幕。你去搜平台关键词，搜大家关心什么讨论什么，老板针对这些回答。这就是非常好的稿子，起号特别快。

### 问4：你自己做成了什么？（最扎心）

**柯哥**：我自己确实没有做成什么。但我现在不正在做吗？

这个账号不到200粉丝，已经变现了2万多。我不认为我能成现象级IP，我也不想当网红——我的形象、综合因素不足以支撑。但我是一个会做生意的人。

我干的就是这行，4980就是我的产品，我肯定得教。

---

## 核心洞察

### 这条视频的差异化在于"诚实"

市面上的新媒体导师都在晒数据、晒案例，没人敢说"我自己粉丝不到200"。

柯哥敢认，这就是最大的信任钩子。

整条视频的逻辑不是"我很牛所以你要关注我"，而是——
**"我没那么牛，但我真能干成事，而且我敢认。"**

### 四条追问挖出来的金句

| 问题 | 金句 |
|------|------|
| 凭什么？ | "我能给任何行业一个确定性方向" |
| 你到底干嘛的？ | "帮你赚钱，做乘法×10" |
| 跨行业怎么做到的？ | "视频第一步给算法看，懂规则就能套公式" |
| 你自己做成了什么？ | "不到200粉丝，变现了2万多。我不是网红，是会做生意的人" |

### 一句话人设

> 一个敢承认自己没粉丝、但真帮人赚到钱的新媒体商业顾问。

## 置顶视频思维导图

```
置顶视频：诚实的人设视频

├─ 开头钩子（3秒）
│   └─ "我做了8年新媒体，但自己连200粉丝都不到"
│
├─ 我是谁（10秒）
│   ├─ 给老板做新媒体运营
│   ├─ 医美、医院、家政、低空经济、装修全干过
│   └─ 专挑同行不敢接的行业
│
├─ 凭什么信我（20秒）
│   ├─ 懂用户心理 + 平台规则语法 = 可复制公式
│   ├─ "讲内幕起号"案例
│   └─ 真实成绩：医美3个月变现、科技招商400万、家政周客资130+
│
├─ 诚实时刻（15秒）→ 最大差异化
│   ├─ "我自己确实没做成什么大号"
│   ├─ 不到200粉，变现2万+
│   └─ 我不是网红，是会做生意的人
│
├─ 我能给你什么（15秒）
│   ├─ 产品线下能卖 → 我做乘法×10
│   └─ 4980 = 课 + 3个月陪跑 + 3个月后你写我审
│
└─ 结尾（5秒）
    └─ "我叫柯建军，我不帮你写，我教你怎么自己写"
```
