# 观众就是刁钻甲方

柯哥原话：

之前有个视频讲互联网产品——把用户想象成既小气又难伺候、非常刁钻的人，能做出来好的互联网产品。

这句话放在短视频运营上同样适用。你把观众当成：又难伺候、又小气、又刁钻、爱占便宜的人，你就能有流量。

## 小龙提炼

类比成立的点：
1. **前3秒容忍度=零** → 互联网产品加载超2秒用户流失，短视频前3秒没钩子就划走
2. **信息密度要求高** → 用户觉得你页面没干货就关，观众觉得你水内容就划
3. **价值感知敏感** → 用户要"免费但好用"，观众要"不花钱但学到东西"
4. **说教立刻反感** → 用户讨厌弹窗广告，观众讨厌被教育
5. **比较心态重** → 用户比价格，观众比你跟同类博主的差异

核心心法：**预设观众是刁钻的，内容质量自动提档。** 不是迎合，是倒逼自己。
