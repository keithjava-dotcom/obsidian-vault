# 健身情绪曲线 · 音乐卡点视频

## 定位

**自嗨 + 传播价值。** 不是教人健身，是把自己的真实体验当样本：前一天大脑CPU超负荷、内耗焦虑、一直找不到释放出口 → 运动把我拉出来了。让观众能对号入座——每个人都会有"脑子停不下来、做什么都不对"的时刻。

**核心信息**：运动一开始是痛苦的，但痛苦之后确实能消散情绪、解决内耗、缓解焦虑。

## 完整结构（锚点 + 五段 + 结尾）

| 段落 | 内容 | 情绪 | 音乐 |
|------|------|------|------|
| **0. 锚点** | 昨天状态——忙乱、焦虑、CPU超负荷（字幕/生活画面/手机消息截图），找不到释放出口 | 被困住、烦躁 | 安静、低气压 |
| **1. 抵触** | 坐在健身房/准备器材，动作迟缓，面无表情，不想动 | 抗拒、麻木 | 低沉、慢节奏 |
| **2. 痛苦** | 开始有氧训练，表情痛苦，咬牙坚持 | 挣扎、难受 | 节奏开始爬升 |
| **3. 心流** | 动作流畅起来，嘴角不自觉上扬，津津有味 | 专注→微笑 | 进入律动，drop 前蓄力 |
| **4. 高强度** | 高强度训练，力量爆发，满脸痛快 | 释放、爽 | drop 爆发，最强段落 |
| **5. 开朗** | 训练结束，大口喘气，发自内心笑出来 | 彻底释放、开心 | 收尾，明朗开阔 |
| **结尾** | 字幕："运动解决不了所有问题，但我脑子里的噪音确实停了。" | 平静、释然 | 淡出 |

## 拍摄要点

- **不讲话**，纯靠画面、表情和字幕
- 锚点段落用生活画面（手机/桌面/杂乱的信息截图），快速建立"他为什么需要运动"
- 表情是核心：扑克脸 → 狰狞 → 微笑 → 痛快 → 大笑
- 音乐卡点要对齐情绪转折，尤其是"痛苦→心流"和"心流→高强度"两个拐点
- 真实感受，不是演的——这是训练的真实体验

## 音乐要求

- 找一条情绪递进正好对上六段的曲子：安静起 → 低沉 → 爬升 → 蓄力 → drop爆发 → 明朗收尾
- 音乐不对，片子就塌了；音乐对了，表情不到位也能被带着走

## 一句话钩子（备选）

- "每次健身都是先把负面情绪碾碎"
- "大脑超负荷了一整天，我只想停掉那些噪音"
- "这才是运动最大的作用，不是塑形，是清空大脑"
