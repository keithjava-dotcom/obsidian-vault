# 工具边界：有意义的重复应该自己做

柯哥原话：

> "其实昨天我有感受，让你抓取，我自己消化得并不好，丧失了对视频的体验感。当我自己去看一遍或者思考一遍，其实虽然比较慢，但是我觉得我的收获比较大，我的灵感也可以帮我记录一下。"

> "有时候工具的使用并不一定对。我认为重复冗余的工作可以让工具去做，但是像这种体验感、有意义的重复，我觉得还是自己做比较好。"

## 核心判断

**工具使用边界法则**：
- 重复冗余的工作 → 交给工具（省时间）
- 有体验感、有意义的重复 → 自己做（深度消化、激发灵感）

工具替你省的是时间，但替你省不掉的是**体验过程本身带来的理解和灵感**。

## 适用场景

- 看视频/读文章消化内容 → 自己看，不要抓取
- 思考一个选题 → 自己琢磨，不要AI代劳
- 看竞品/同行内容 → 自己感受，不要只读摘要
- 数据整理/格式化/重复性操作 → 可以交给工具
