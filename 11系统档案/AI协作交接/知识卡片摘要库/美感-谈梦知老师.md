## 剪辑_BGM起承转合结构

# BGM起承转合结构

任何一首完整的BGM都有四个结构：起（轻缓，把观众拉入情境）→承（逐渐上扬，加入新乐器/变奏）→转（高潮，最能点燃情绪的部分）→合（逐渐落伏，收尾）。剪辑时要找到每个结构的节点，把音乐剪成适配文案长度的片段。文案的起承转合要和音乐的起承转合对应，让观众坐一次情绪过山车。

# 声音的前景声与背景声层次

视频中所有声音分两层：前景声（人声独白/旁白/对白、拟声音效）权重最高，背景声（BGM、环境音）权重次之。两者同时出现时，提高前景声音量，削弱背景声。前景声结束后，背景声恢复正常音量。层次越立体，观众感受到的视听体验越丰富。独白权重最高，应放在声音响度的第一优先级。

# 音乐与文案意境融合

对白有两种拍法：①主观视角——镜头对着你看到的东西，像打开后置摄像头的视频电话，观众默认你在和他们说话；②突然插入现场台词——在音频主轨道之外重新插入一段现场台词，把观众从故事里拉回现实，只用现场音不用音乐。情绪空镜头（黄昏窗户、城市夜景）也属于对白的一种，配合声音把观众带入情境。

# 旁白的拍摄方式：定场镜头+人物侧写

旁白是第三人称视角，别人来记录你。拍法：①定场镜头（先给整体环境的远景，让观众知道你在哪）；②人物侧写（背影、行走、做事的客观镜头）；③固定机位为主，不需要复杂运镜；④名词可视化+动词可视化，说到什么就出现什么。景别多切换，角度多变化，但机位固定，保证信息传递精准。

# 景别的具体功能：控制观众的观察范围

景别越大（远景），环境信息越多，人物情绪越弱；景别越小（特写），单个信息越清晰，环境被削弱。特写：传达动作/物体的具体功能，衔接动作关键部分。近景：人物说话，弱化肢体，适合口播。中景：展示上半身肢体动作，表现人物关系。全景：交代人物全身+局部环境。远景/定场镜头：交代大环境，告诉观众故事在哪里发生。

# 灯光通识：柔度光比是影像质感的核心

# 独白画面的拍摄技法：隐秘感是核心

独白是给观众的悄悄话，画面要传递隐秘感。五种技法：①前景虚化（人物虚焦，不是背景虚）；②人物侧脸或背对镜头；③眼神/动作/肢体的特写；④刻意欠曝或剪影（人物变成黑色轮廓）；⑤两个片段重叠（画面叠化传递内心感受）。整体画面偏灰暗，人物不直视镜头，BGM要委婉偎偎道来，不能激烈。

# 视角的具体功能：平拍/仰拍/俯拍的心理暗示

# 声音是视频创作的第一位

## 视觉美学_影调与氛围的关系
> tags:视觉美学/美感-谈梦知老师/待链接 · 来源:美感-谈梦知老师课程 · 日期:2026-04-21

# 影调与氛围的关系

影调是影像传达氛围的第一优先级，优先于色彩。高调（亮部多、反差小）：轻松、明朗、柔和、安全，表现正面情绪。低调（暗部多、反差大）：神秘、阴郁、紧张、讶异，表现负面情绪。中间调：客观、理性、冷静，适合中立叙事。正确顺序：先选景别→选视角→选影调→最后才选色彩。

## 关联

- 适用场景：拍摄前规划整体视觉基调

## 视觉美学_焦段与空间关系

# 焦段与空间关系：深焦浅焦裂焦

深焦：前后都清晰，适合需要同时交代前景和背景的场景，信息量大，镜头不能快速切走。浅焦：突出焦点，弱化背景，强行把观众注意力拉到焦点，是强势的拍摄方法。裂焦：前景和背景都清晰，中间虚化，消除空间纵深感，在一个镜头内完成两个镜头的功效，暗示前后人物有关联。短焦凑近前景：增强空间纵深感，拉开人物心理距离。

# 色彩的情绪语言

色彩是影像传达情绪的第二优先级（影调第一）。暖色（红/橙/黄）：热情、活力、温暖、危险。冷色（蓝/绿/紫）：冷静、忧郁、神秘、疏离。中性色（黑/白/灰）：高级感、极简、理性。色彩饱和度越高，情绪越强烈；饱和度越低，越接近纪录片质感。调色时先确定影调，再调整色彩倾向，最后微调饱和度。

# 传播分、效果分、互动分：三维度诊断选题

传播分（播放量）：选题是否成功，决定入水口人群基数。效果分（停留时长）：内容深度是否够，播放高但停留短说明选题对但内容有问题。互动分（评论/点赞/转发）：表达方式是否引发共鸣，互动低说明表达方式出了问题，不是选题本身的问题。三个维度分开诊断，对症下药。

# 选题要有垂直性，不能今天摄影明天美容

# 选题要围绕自己为线索展开
