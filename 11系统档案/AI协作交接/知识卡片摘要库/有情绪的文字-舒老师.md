# 产品名要有卖点

好名字里能直接体现卖点，让人一眼看出和别人的区别。"一整根"（人参饮料）比"深滋养"更好，因为卖点更直接、更少见。两种方法：直说卖点（找别人没说过的角度）；类比暗示（用相近事物的特征暗示产品卖点）。

# 受众标签化分类法

# 品类名不是产品名

"婴幼儿奶粉"是品类名，"iPhone"才是产品名。很多品牌直接用品类名或型号名当产品名，是因为产品线太多、太相似，已经找不到区分特征了。但对于新品牌，这是一个巨大的传播浪费。

# 好产品名的四个标准

好名字至少满足其中一条：①能体现产品性格；②能体现产品卖点；③有绰号空间；④可以被人格化或可被描述。名字越具象越好，越抽象越难传播。大牌可以无视这些规则，但初创品牌不行。

# 好名字要有绰号空间

# 不用问卷的调研方法EIOR

# 15字内解决问题

人在情绪放松时，能注意到的有效信息一般在15个字内。超过15字，除非高度集中，否则容易被忽略。第一次和陌生人打照面，你只有一句话的空间介绍自己。这句话用好，比一段话影响力更强。

## 文案_产品文案要为品牌沉淀情感价值
> tags:文案/有情绪的文字-舒老师/正式卡/品牌价值 · 来源:有情绪的文字-舒老师 第49课 · 日期:2026-06-29

# 产品文案要为品牌沉淀情感价值

产品文案不能只完成卖点介绍，还要尽量把偶然流量转化成更稳固的品牌价值。介绍完产品后，最好多写一句能让用户感到“我们是同类”的精神层表达。

理性卖点能促成一次购买，情感价值能让人记住品牌。产品卖点再聪明，本质仍是买卖关系；情绪、价值和共同理念，才更有机会沉淀为长期粘性。

## 操作动作

- 产品卖点讲完后，补一句品牌和用户之间的共同信念。
- 把“这个产品好在哪里”升级成“我们和用户在什么地方想到一起”。
- 商业 IP 口播结尾也可以用这个思路：不只收咨询，还要沉淀人设价值。

## 禁区

- 不要硬升华到空洞口号。
- 不要在事实没讲清前先讲灵魂。
- 不要把品牌价值写成自我感动。

# 从暗需求中找卖点创新

## 文案_别人用过的表达不要再套用
> tags:文案/有情绪的文字-舒老师/正式卡/原创性 · 来源:2-舒老师-有情绪的文字 · 日期:2026-06-29

# 别人用过的表达不要再套用

经典文案可以学习，但不能直接套用。把自己的产品硬塞进别人的句式里，用户看到的是模仿者、低配感和山寨感。

模仿和致敬的区别在于：模仿是把自己塞进别人的第一人称表达；致敬是站在第三人称，主动说明借用关系，并留出大部分空间给自己的创新。

## 操作动作

- 看到熟悉句式，先停下来判断出处。
- 如果只是换主语，直接判为套用。
- 真要借用，要明确做成致敬语境。
- 保留 70%-80% 的自我表达空间。

## 禁区

- 不要写“不是每个X都叫Y”这类高度撞脸句。
- 不要把广告圈名句直接改行业。
- 不要让品牌被贴上“平替/山寨”的身份。

## 适配 Skill

- fanwen：逐字稿金句检查。
- gemini-rectifier：审美样本回流时避免复制表层句式。

## 关联

- 文案_陌生感是文案有特点的来源
- 文案_四步改造法从口水话到文案

# 别埋包袱，说话简单

短视频口播不能让观众猜作者意图。重要信息要尽早给出，复杂概念要先换成生活问题，再讲观点。好的口播文案首先应该好说、好懂、好记。

## 禁区

- 不要开头先讲来龙去脉。
- 不要把一句话写成论文摘要。

## 文案_卖点提炼要找共鸣和差异
> tags:文案/有情绪的文字-舒老师/正式卡/卖点提炼 · 来源:2-舒老师-有情绪的文字 · 日期:2026-06-29

# 卖点提炼要找共鸣和差异

好文案不能只做甲方资料的复述机器。卖点提炼要从两个方向找：一是差异，横向对比竞品，看产品到底哪里不同；二是共鸣，找那些有需求规模、但过去没有被重视的小细节。

舒老师的关键判断是：卖点不是凭空创造，而是在已有信息网络里做选择题。文案要主动参与卖点判断，帮助甲方看见他们自己没有意识到的价值。

## 操作动作

1. 收集产品基础信息，先不急着筛。
2. 横向对比竞品，找独有差异。
3. 从真实体验里找被忽视的共鸣点。
4. 放进需求三原理验证，避免自嗨。
5. 再按需求规模和竞争优势分类。

## 禁区

- 不要把专业名词直接当卖点。
- 不要为了讨好甲方保留模糊、套路、消费者听不懂的信息。
- 不要把“甲方说得多”误判成“用户真在意”。

## 适配 Skill

- dingwei：判断商业优势。
- dagang：确定选题里的核心冲突。
- fanwen：写逐字稿时选择哪一个点重锤。

## 关联

- 文案_需求三原理验证卖点真实性
- 文案_核心卖点只有一个
- 文案_好文案不是复述机器

## 文案_受众处境决定表达方式
> tags:文案/有情绪的文字-舒老师/正式卡/fanwen质量层 · 来源:有情绪的文字-舒老师 第18-25课 · 日期:2026-06-29

# 受众处境决定表达方式

受众不是年龄、职业、性别这些空标签，而是一个具体处境里的人：他正在为什么烦、用什么替代方案、在哪个渠道看到你、真正做决策的人是谁、他的性格和生活习惯是什么。

文案不是对“宝妈、老板、高净值客户”这种标签说话，而是对一个正在某个问题里犹豫的人说话。处境越具体，表达越容易有抓手。

## 操作动作

- 写导戏卡时必须写清：这个人现在处于什么状态。

- 文案开头优先击中处境，不优先复述身份标签。

## 禁区

- 不要只写年龄、职业、收入。
- 不要把购买者和使用者混成一个人。
- 不要让出镜人的经历完整复述给无关受众。

## 适配 Skill

dingwei / xuanti / dagang / fanwen

## 文案_品牌性格决定表达边界
> tags:文案/有情绪的文字-舒老师/正式卡/品牌性格 · 来源:有情绪的文字-舒老师 第48课 · 日期:2026-06-29

# 品牌性格决定表达边界

文案不是想怎么写就怎么写。一个品牌或 IP 已经有原本的性格时，文案必须和它的气质协调，否则再有创意也会显得不对劲。

同一句话，放在年轻搅局型品牌上可能有态度，放在豪华高冷型品牌上就可能掉价。写作前要先判断：这个品牌是正式的、年轻的、东方的、科学的、高冷的、幽默的，还是攻击性的。

## 操作动作

- 写之前先给品牌/IP 标 2-3 个性格词。
- 判断当前文案语气是否和性格匹配。
- 如果要打破原性格，必须有足够强的战略理由和极高完成度。

## 禁区

- 不要把所有品牌都写成同一种“网感”。
- 不要为了年轻化硬套玩梗语气。
- 不要让豪华、专业、严肃型 IP 说廉价的话。

## 适配 Skill

dingwei / fanwen / account-calibration

## 文案_唐突与冒犯是必要的
> tags:文案/有情绪的文字-舒老师/正式卡/表达风格 · 来源:有情绪的文字-舒老师 第42课 · 日期:2026-06-29

# 唐突与冒犯是必要的

文案里的“冒犯感”不是攻击消费者，而是用更有性格的语气打破讨好式表达。它的价值在于制造陌生感和记忆点，让一句话从温吞的说明变成有传播力的表达。

真正可用的冒犯，是语气上的“不讨好”、观点上的“有立场”、情绪上的“更鲜明”。它服务于记忆，而不是服务于挑衅。

## 操作动作

- 当文案过于温顺时，尝试把语气改成更坚定、更有态度。
- 冒犯错误观念，不冒犯目标用户。
- 对攻击型或强判断力 IP，可以适度使用“我只说一遍”“你别后悔”这类带性格的句式。

## 禁区

- 不要攻击消费者本人。
- 不要为了刺激而制造低级对立。
- 不要让品牌或 IP 显得讨厌、刻薄、油腻。

## 适配 Skill

fanwen / xuanti / zuoye-dianping

## 关联

- 文案_一句话文案的核心是有特点
- 文案_陌生感是文案有特点的来源

## 文案_四步改造法从口水话到文案
> tags:文案/有情绪的文字-舒老师/正式卡/改稿方法 · 来源:2-舒老师-有情绪的文字 · 日期:2026-06-29

# 四步改造法：从口水话到文案

文案不是一下子憋出来的，而是一步步改造出来的。舒老师的方法是：先写出口水话，保证字义准确；再发散感觉和联想；再精炼成广告语；最后用陌生感、类比暗示等方法做改造。

这套方法特别适合训练 OpenClaw 的逐字稿：先别追求金句，先把意思说准，再一轮一轮变得有味道。

## 四步

1. 描述：用口水话把意思写准。
2. 发散：追问这个感觉像什么、能联想到什么。
3. 精炼：把啰嗦句子缩成更有力量的表达。
4. 改造：加入陌生感、类比、口语反差或节奏。

## 禁区

- 不要第一稿就追求高级。
- 不要为了精炼丢掉核心意思。
- 不要直接搬名人名言或经典句式。

## 适配 Skill

- fanwen：逐字稿二改、三改的核心工作流。
- gemini-rectifier：把 Gemini 好稿拆成“描述-发散-精炼-改造”的可学习过程。

## 关联

- 文案_别人用过的表达不要再套用
- 文案_陌生感是文案有特点的来源
- 文案_类比暗示要正向增强卖点

## 文案_帮消费者问问题
> tags:文案/有情绪的文字-舒老师/正式卡/消费者视角 · 来源:2-舒老师-有情绪的文字 · 日期:2026-06-29

# 帮消费者问问题

写文案卡住时，不是继续堆资料，而是站在消费者立场替他问问题。好问题能把甲方的基础信息逼成可用卖点，也能提前解答用户的疑虑。

舒老师的 VC 案例里，真正的卖点不是“VC是什么”，而是“为什么买你家的”“含量高意味着什么”“一天吃几片够不够”“有没有糖”“资质有什么差异”。这些问题一问，文案方向就出来了。

## 操作动作

- 问差异：你和别人有什么不同？
- 问意义：这个数字/成分/资质对我有什么用？
- 问顾虑：我为什么不信你？我担心什么？
- 问替代：我为什么不买竞品？
- 问行动：知道这些之后，我下一步该怎么做？

# 平庸产品去竞品和评价区找线索

# 情绪也是卖点

情绪不是文案的装饰，而是卖点的一部分。实用卖点解决“我需要”，情绪卖点解决“我喜欢、我认同、我愿意长期记住你”。

产品力到达一定程度后，继续拉开差距的往往不是参数，而是仪式感、稀缺性、优越感、身份认同和品牌故事。商业 IP 口播同理：如果只讲功能和道理，观众会把你当工具；如果能讲出情绪和价值，观众才会记住你这个人。

# 慎用热点与当下流行

热点文案有保质期。它来得快，去得也快，适合短周期传播，不适合长期放在产品介绍、品牌介绍和核心口号里。

如果一个文案依赖当下流行语成立，那么热点过去后，它很容易显得土、俗、过时。长期使用的文案要尽量像钢筋水泥，而不是快闪展板。

## 操作动作

- 如果必须借热点，要让热点服务品牌观点，而不是替代品牌观点。

## 禁区

- 不要把短期流行语写进长期品牌资产。
- 不要为了显得年轻而套用热梗。
- 不要让文案过度依赖当下语境。

## 适配 Skill

fanwen / export-to-client / account-calibration

# 数字让文案更具体更有底气

# 文案法律风险先避绝对化和数据无来源

商业文案不能只追求刺激，还要避开基础法律风险。舒老师提醒的重点包括：绝对化用语、产品属性混淆、数据无来源、贬低同行、模糊概念和擦边表达。

- 避免“第一、顶尖、极致、终极”等绝对化表达。

- 不玩可能误导消费者的模糊概念。

## 禁区

- 不要为了钩子写无法证明的话。
- 不要把自家推测当检测结论。
- 不要在医疗、保健、金融等高风险行业随便放大承诺。

## 文案_自嗨表达vs它嗨表达
> tags:文案/有情绪的文字-舒老师/正式卡/fanwen质量层 · 来源:有情绪的文字-舒老师 第6课 · 日期:2026-06-29

# 自嗨表达vs它嗨表达

自嗨表达只说自己有多好；它嗨表达会继续说清楚：这个好对用户有什么用。

两者最大的区别不是文采，而是有没有把优势和用户需求连接起来。文案从自嗨切到它嗨，很多时候只需要多补一句“所以你能得到什么”。

例子：

- 自嗨：我们有三万平大工厂。
- 它嗨：我们有三万平大工厂，所以每一批货都能严格质检，不容易出错。

## 操作动作

- 看到“我们/我/本公司/本产品”开头的句子，追问一句：这和用户有什么关系？

- 不要把履历、规模、资质当成天然说服力。
- 不要用企业自夸替代用户收益。

## 文案_详情页四件事表达优势需求引导困惑解答性格塑造
> tags:文案/有情绪的文字-舒老师/正式卡/产品详情页 · 来源:2-舒老师-有情绪的文字 · 日期:2026-06-29

# 详情页四件事：表达优势、需求引导、困惑解答、性格塑造

产品详情页不是把卖点堆满页面，而是在构建差异和回答问题。舒老师把详情页文案总结成四件事：表达优势、需求引导、困惑解答、性格塑造。

这套方法也能迁移到商业短视频：一条口播稿如果只有优势，没有需求引导，用户不知道和自己有什么关系；如果不解答困惑，用户不会行动；如果没有性格，内容就没有记忆点。

## 操作动作

1. 表达优势：先说清产品或人物真正强在哪里。
2. 需求引导：把优势和用户具体处境拉近。
3. 困惑解答：提前回答用户心里的疑问、顾虑、反驳。
4. 性格塑造：让产品/IP有可感知的人格和语气。

## 禁区

- 不要只罗列卖点。
- 不要把专业信息直接堆给用户。
- 不要忽略用户看完后最可能产生的顾虑。

## 适配 Skill

- fanwen：商业口播稿的检查框架。
- b-roll-plan：画面应服务四件事，而不是只补素材。

## 关联

- 文案_帮消费者问问题
- 文案_受众处境决定表达方式
- 文案_品牌性格决定表达边界

# 陌生感是文案有特点的来源

"香得令人发指"比"香醇厚重"更有力，原因是陌生感。用常见词汇写出不常见的组合，就能打破视觉疲劳。陌生感不是发明新词，而是把日常词汇用在不常见的场景里。积累词汇库是获得陌生感的方法。

## 关联
- 文案_一句话文案的核心是有特点

## 文案_降低阅读障碍的四个方法
> tags:文案/有情绪的文字-舒老师/正式卡/可读性 · 来源:2-舒老师-有情绪的文字 · 日期:2026-06-29

# 降低阅读障碍的四个方法

阅读障碍有两类：一类是太长太无聊，用户没耐心读完；一类是太空、太专业、没画面，用户看不进去。商业文案要降低用户的阅读成本，让人越读越有兴趣。

## 四个方法

1. 拒绝生僻字：不要让用户迟疑。
2. 适度押韵：让句子更顺、更容易传播，但不能为了押韵牺牲意思。
3. 概念类比：用熟悉事物解释陌生技术或专业名词。
4. 交流式沟通：不要只做信息罗列，要像人和人之间说话。

## 禁区

- 不要把信息做成一堆框框让用户自己扫。
- 不要迷信短，短但空也会读不进去。
- 不要上来就押韵，先保证字义准确。

## 适配 Skill

- fanwen：逐字稿最终校对层。
- b-roll-plan：复杂概念可用画面和类比降低理解成本。

## 关联

- 文案_别埋包袱说话简单
- 文案_类比暗示要正向增强卖点

# 需求三原理验证卖点真实性

提炼出卖点后，用这三条原理验证：①人们想生活得更有品质；②人们想成为更好的人；③人们想获得赞扬与优越感。卖点至少要符合其中一条，否则多半是伪卖点或用力过猛的引导。

- 文案_核心卖点只有一个
- 适用场景：提炼完卖点后做真实性自检

## 选题_不用问卷的四步调研法EIOR
> tags:选题/有情绪的文字-舒老师/待链接 · 来源:有情绪的文字-舒老师课程 · 日期:2026-04-21

# 不用问卷的四步调研法EIOR

调研消费者不一定要做问卷。四步法：E亲历（自己体验产品和场景）、I访谈（小范围问真实用户感受）、O观察（总结归纳现象）、R推理（回归产品思考卖点）。这套方法快速、低成本，适合文案和小品牌。

# 购买者和使用者可能不是同一人

拐杖的使用者是老人，但购买者是子女。两者关心的卖点完全不同：老人关心价格和经典款式，子女关心安全性和科技感。受众分析必须同时考虑购买决策者和实际使用者，否则文案方向会偏。
