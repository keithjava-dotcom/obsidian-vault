## 一、一句话说清它是什么

**小龙是一条把"柯建军的判断力"复制成流水线的内容生产系统。**

不是一个聊天机器人，不是一个写稿工具。它是**一条产线**：
原始素材从一头进去，能直接开拍的成稿从另一头出来，中间每一道工序都有人（机器）盯着不许偷工减料。

它跟市面上"用 AI 写文案"最大的区别：
**市面上的 AI 是"你问它答"，小龙是"你教它，它记住，下次不用你教"。**

## 二、全景图：它由四层组成

```mermaid
flowchart TB

        K1[安老师课程<br/>舒老师情绪技法<br/>谈梦知美感]
        K2[柯哥自己的方法论<br/>过山车/三起三落]
        K3[客户档案<br/>定位方案/语言指南/素材]
    end
    subgraph L3["③ 规则层 · 教它怎么做（宪法 + 31个技能）"]
        R1["SOUL.md<br/>它是谁、怎么做事"]
        R2["AGENTS.md<br/>什么活找谁干"]
        R3["31个技能<br/>每道工序的操作手册"]
    end
    subgraph L2["② 代码层 · 物理拦截（guard 插件 144KB）"]
        C1["12道硬闸<br/>拦不合格的产出"]
        C2["5个工具<br/>读写知识库的唯一通道"]
        C3["6个钩子<br/>挂在模型每次动作前后"]
    end
    subgraph L1["① 执行层 · 大模型（DeepSeek V4）"]
        M["小龙本体<br/>读规则、调知识、写稿"]
    end

    L4 -->|按需取用| M
    L3 -->|开工前灌进去| M
    M -->|每一次落盘| C1
    C1 -->|不合格打回| M
    C1 -->|合格| OUT[("Obsidian 知识库<br/>2931 份文档")]

    style L2 fill:#ffe8e8
    style L1 fill:#e8f4ff
    style OUT fill:#e8ffe8
```

**为什么要分四层？**

因为**只靠一层会垮**：

| 只有这一层会怎样 | 实际发生过的事故 |
|---|---|
| 只有大模型 | 它想怎么写就怎么写，今天这样明天那样 |
| 只加规则 | 规则堆到 33KB，**模型看不完就开始忘**（你说的"塞太多就变傻"） |
| 只加代码闸 | 拦得住写坏，拦不出写好（沉静第06稿：闸判 82 分不过，你说"这一版还可以"） |
| 只有知识 | 321 张卡躺在库里，写稿时它一张都想不起来调 |

**四层各管一段，谁也替代不了谁。**

## 三、主流程：一条稿子是怎么生出来的

```mermaid
flowchart LR
    S(["柯哥给素材<br/>『给冉总写一篇』"]) --> X

    subgraph 五棒流水线
    X["① 选题<br/>xuanti"] --> D["② 大纲<br/>dagang"]
    D --> F["③ 写稿<br/>fanwen"]
    F --> B["④ 拍摄脚本<br/>b-roll"]
    B --> P["⑤ 复盘<br/>fupan"]
    end

    X -.需你拍板.-> KE1{{"你挑一个角度"}}
    D -.需你拍板.-> KE2{{"你认可方向"}}
    F --> J{"裁判打分<br/>≥80分"}
    J -->|不过| F
    J -->|过| G{"12道闸<br/>逐条查"}
    G -->|拦下| F
    G -->|放行| OUT(["成稿落盘<br/>你验收"])

    style KE1 fill:#fff4c2
    style KE2 fill:#fff4c2
    style OUT fill:#e8ffe8
```

**三个卡点必须你本人点头**（黄色）：选哪个角度、大纲方向对不对、最后成稿认不认。
**其余全自动**。

### 为什么不许跳棒

你 2026-07-22 定的："不管素材厚与不厚，都应该先走选题。"

**跳棒的代价（真实事故）**：一冉集团号第17/18稿直接从素材写稿，出来的东西没角度、平铺直叙。
现在这条由代码强制：**没有大纲，稿子物理写不进去**。它想绕也绕不过。

## 四、12 道闸分别在拦什么

闸不是为了刁难它，每一道背后都对应一次真实事故。

```mermaid
flowchart TB
    W(["它要写文件"]) --> A1{路径对吗}
    A1 -->|"想直接改客户原始素材"| X1["❌ 拦：原稿保护"]
    A1 -->|OK| A2{有大纲吗}
    A2 -->|"没有就想写稿"| X2["❌ 拦：跳棒"]
    A2 -->|OK| A3{文件名全吗}
    A3 -->|"叫『（IP口语稿）』"| X3["❌ 拦：文件名残缺"]
    A3 -->|OK| A4{双链对吗}
    A4 -->|"没链 / 链到别的稿号 / 链了不存在的"| X4["❌ 拦：wiki链接"]
    A4 -->|OK| A5{格式对吗}
    A5 -->|"缺封面/走线/注意事项"| X5["❌ 拦：四板块"]
    A5 -->|OK| A6{裁判过了吗}
    A6 -->|"低于80分"| X6["❌ 拦：质量线"]
    A6 -->|OK| A7{正文跟裁判过的<br/>是同一份吗}
    A7 -->|"偷换了内容"| X7["❌ 拦：换稿"]
    A7 -->|OK| OK(["✅ 落盘"])

    style X1 fill:#ffd9d9
    style X2 fill:#ffd9d9
    style X3 fill:#ffd9d9
    style X4 fill:#ffd9d9
    style X5 fill:#ffd9d9
    style X6 fill:#ffd9d9
    style X7 fill:#ffd9d9
    style OK fill:#d9ffd9
```

**闸的设计原则（吃过亏才定的）**：

1. **物理拦截 > 写在纸上**——写进 SKILL 的规矩，模型上下文一压缩就忘；写进代码的，它绕不过。
2. **拦下必须说清怎么改**——只说"不合格"它会瞎试；报错里必须带"正确写法长什么样"。
3. **同一个错拦三次就停手报你**——2026-07-24 装的断路器。连拦三次多半是闸有 bug，不是它的错。
4. **闸管别写坏，不管别写好**（2026-07-27 新增）——闸和好东西冲突时让你看见，别让闸替你做决定。

## 五、你的话是怎么变成它的能力的

这是整个系统最值钱的部分，也是你问过的"能不能越用越聪明"。

```mermaid
flowchart LR
    K(["你说一句话<br/>『这稿没人味儿』"]) --> H["收割器<br/>每天自动捞"]
    H --> IN[("调教收件箱")]
    IN --> C{Claude 判断<br/>该变成什么}
    C -->|能量化的| M1["体检项<br/>机器自动量"]
    C -->|要判断的| M2["规则<br/>写进技能"]
    C -->|是范例| M3["样板<br/>照着写"]
    M1 --> V{"拿你骂过夸过的<br/>稿子验区分度"}
    V -->|分得开| ON([上线])
    V -->|分不开| OFF([作废])
    M2 --> BUDGET{"规则预算<br/>加一条挤一条"}
    M3 --> SAMPLE[("样板库<br/>第22稿/沉静06稿V4")]

    style K fill:#fff4c2
    style V fill:#ffe8e8
    style ON fill:#d9ffd9
    style OFF fill:#ffd9d9
```

**三条出路，为什么要分开**：

- **体检项**（能量化的）：可以无限加，加到 50 条模型也不变傻——**因为它不用背，机器替它量**
- **规则**（要判断的）：有天花板，加一条必须挤掉一条，否则就是你说的"塞太多变傻"
- **样板**（是范例）：最省事也最可靠——照着好稿写，比让机器判分靠谱

**验区分度是关键一环**：一个体检项装不装，不是我说了算，是看它能不能把**你骂过的稿子**和**你夸过的稿子**分开。
2026-07-27 实测：我装的 9 项里 6 项在真实样本上区分度反向，当场全停。**机器审判了我。**

## 七、已知的边界（做不到的事）

**说清楚做不到什么，比吹能做什么重要。**

1. **它写不出你没教过的好角度**——"给自己鞠一躬"那种切入点，是它偶然想出来的，不是系统保证的。
   **系统能保证不写坏，不能保证写好。**
2. **判断力不能量化**——角度假不假、这选题值不值得做，机器测不出来，只能靠你验收。
   我试过做成判据，2026-07-27 被数据证伪。
3. **它自己悟出来的东西存不住**——沉静第06稿它自己总结出"叙事者要是正在经历的人"，
   这话你没教过，是它想的。但**下次换个客户它可能又忘了**，得我手工收进系统。
4. **换个人用不了**——规则里刻满你的审美、你的客户、你认可的稿子。
   这是它成为**你的**分身的代价，也是它现在还不算产品的原因。
