## 2A · 基础六维度分析

### 1. 语感特征

- **高频词和口头语**：说实话、我觉得、可能就是、不太清楚、有时候、说实话
- **句式习惯**：中等长度句为主，自然的叙事节奏。想到哪说到哪，不刻意铺陈。说痛苦也不煽情——"我看上去可能是最平静最冷静的一个人，但实际上这种痛苦可能会一点一点蔓延到我的一生"
- **情绪基调**：安静、内敛。她说话的底色是平静的，哪怕是讲最痛的事。不喊、不哭、不夸张。这种平静本身比大喊大叫更有力量
- **绝对不会说的话**：矫情的话、心灵鸡汤、"你一定要XX"、"正能量"、"蜕变"

### 2. 核心差异化（竞争力六维度对照）

| 维度 | 评价 | 说明 |
|名片: { 行业: "宝妈成长/情绪", 人设: "安静自省·不打鸡血", 内容类型: "口播故事/共鸣" }
------|------|------|
| 正 | ❌ 不推荐 | 不是育儿专家，没必要跟大V拼"专业宝妈" |
| 反 | ✅ 推荐 | 主流宝妈=带娃多厉害/多快乐/教你带娃。她=当妈两年了还不知道自己是谁。这是真反共识 |
| 和 | ✅ 推荐 | 会计的理性视角 + 宝妈的感性生活 = 用会计思维算人生账。她不算怎么省奶粉钱，她算"我丢了自己多少年" |
| 跨 | ⚠️ 暂不推荐 | 跨界需要另一个领域有话语权，她目前积累不够 |
| 入 | ⚠️ 可选 | 可以切"糖尿病妈妈"这个细分，但不是核心竞争力 |

**推荐组合**：弱 + 和 + 反，三层叠加。

### 3. 目标受众

| 优先级 | 人群 | 为什么 |
|--------|------|--------|
| 主 | 28-38岁城市女性，正在经历"当妈后找不到自己"的困惑 | 她的痛苦就是她们的痛苦。她们不需要另一个"完美妈妈"，需要一个说真话的人 |
| 次 | 有慢性病/创伤经历但不想被"励志化"的女性 | 她不贩卖苦难，她只是展示"带着病，我还是在过日子" |
| 辅 | 在大城市独自带娃、缺少家庭支持的年轻妈妈 | 北京的身份认同 + 单人带娃的真实 |

**聚集平台**：小红书（文字+图片偏感性，她适合）+ 抖音（故事型口播）

### 4. 变现目标

- **客户现在想要**：还账、养孩子、为自己人生负责
- **最短路径**：不急变现。前3-6个月的任务只有一个：让人认识她、记住她、信她。她是4980学员，内容先跑通再想变现
- **中长期**：陪伴型内容付费 / 生活好物推荐 / 同类人群社群
- **时间预期**：0-3个月内容积累 → 3-6个月人设成形 → 6个月后试探变现

## 2B · 人设挖掘七维度

### 1. 故事性

**反差点**：
- 一个表面"老实"的女人，心里有一团火
- 每天打针30多年了，从没喊过苦——这不叫"坚强"，这叫"已经习惯了"
- 失去第一个孩子时，她是全家最平静的那个人。但她说痛苦"一点一点蔓延一生"

**1个故事N个角度**：引产经历
- 角度A（失去）：36周，约定剖腹产前一周，心跳没了
- 角度B（平静的假象）：所有人都崩溃了，她最平静。但平静不是没事
- 角度C（女儿的降临）：2年后女儿来了，给了她希望，也带来了新的痛苦——"不知道自己是谁"
- 角度D（被安排）：妈妈让她来北京，怕她找不到对象。她来了，结婚、生子、失去、再生子——一路被生活推着走

### 2. 性格、品行、人格魅力

- **感性**（她自己说的）——她感受深但不外露
- **"老师/老实"**（她自己说的）——但强调"老实表面下藏着一颗躁动的心"。这个"躁动"是金矿
- **自卑**（她自己说的）——不自欺。说出"我自卑"本身就是一种力量
- **韧**（她自己没说但一眼能看出来）——30年糖尿病每天打针，引产第一个孩子，当了两年妈妈还在找自己。这些都没打倒她
- ⚠️ 禁止凹的人设词：活泼、搞笑、可爱、励志、蜕变

### 3. 与观众的关系（五种姿态）

**选择：同道中人/灵魂伴侣（亦步亦趋）**

她不是来教你怎么做妈妈的。
她自己也还不知道怎么做。
她只是跟你一起在找。

> 这个姿态和她"自卑"的性格恰好匹配——越真诚越有力。

### 4. 三观/意识形态

**她认可的**：
- 痛苦可以平静地说出来
- 接受自己的脆弱不是软弱
- 生活不需要假装一切好

**她反对的**：
- "你一定要正能量"——她经历过真正的苦，知道那套没用
- 假装完美的妈妈人设
- "生了孩子人生就完整了"——她的经历不让她信这个

**个人简介方向**：不适合写履历（她不是专家型IP）。适合写态度——"我在找自己。你也一样吗？"

### 5. 愿望/渴望/个人目标

- **短期**：还账，不再靠别人
- **中期**：找到自己是谁
- **长期**：养好孩子，为自己的人生负责
- **喜好/软肋**：她的孩子、她的身体、她那个"躁动的心"
- **缺点（她自己说的）**：懒、自卑、不敢变动

### 6. 情绪基调（早期单点定调）

- **主基调**：安静内敛 —— 她的文字和声音本身就是这样。不煽情、不喊、不哭。平静但有力。
- **辅基调**：偶尔的"躁动"——"老实表面下藏着一颗躁动的心"。不能每条都用，但偶尔露一下就是惊喜
- **参考博主**：类似那种安静讲故事的女性博主，不是知识付费型，是陪伴型
- **音乐风格**：安静的钢琴或吉他，不铺太满
- **光线**：自然光，家里的暖光，不要棚拍感
- **语速**：正常偏慢，给她留停顿的空间。她的停顿本身就在说话

### 7. 思维习惯（MBTI对照）

⚠️ **让客户测一次MBTI再定。** 从她的叙述推测：内倾（I）、感性（F）、偏直觉（N）。可能是INFJ或ISFJ类型。

对应内容形态：**生活日常 + 讲故事**混合。她不是逻辑输出型，是感受分享型。
