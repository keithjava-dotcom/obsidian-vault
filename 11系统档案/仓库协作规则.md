# 仓库协作规则

> 三人共笔：柯哥、Hanako、小龙。2026-05-06 起生效。

## 作者归属

- 文件 frontmatter 有 `author: Hanako` → Hanako 写的
- 文件 frontmatter 有 `author: 小龙` → 小龙写的
- 文件没有 `author` 字段 → 柯哥写的

## 修改追溯

所有修改自动由 Obsidian Git 记录。右键文件 → Version History Diff 查看改动。

找不到了问 Hanako——她知道什么东西在哪、谁什么时候改的。

## 目录公约

- `00柯的账号/` — 柯哥个人内容
- `01/02/03...` — 方法论、知识库、行业研究
- 不要在他人活跃的目录里随意增删顶层文件夹
