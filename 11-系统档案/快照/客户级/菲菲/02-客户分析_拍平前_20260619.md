## 1. 语感特征

- 高频词和口头语：维度、能量、高维、本自具足、觉醒、简单、究竟、陪伴、功课、滋养
- 句式习惯：喜欢用类比（蚂蚁看人/离开地球看地球）；先抛结论再解释；口语化长句，偶尔用短句收尾
- 情绪基调：温和、通透、有使命感，不焦虑，不说教，像一个走过来的人在分享

## 2. 核心差异化

别人有的：心理咨询、疗愈、觉醒课程

**她觉得理所当然但其实极稀缺的：**

1. 服务过几百万到几千万资产的企业老板——高端客户背书，大多数疗愈师没有，她自己没有主动放大
2. 终身服务承诺（一次付费终身服务）——行业极稀缺，她说起来很随意，但这是极强的信任锚点
3. 理工科思维+量化SOP——疗愈行业普遍感性，她有"100次疗愈/3个月/90%满意度"这类数据，是感性行业里的理性壁垒
4. 底层逻辑是"升维后问题自动消失"而非"帮你解决问题"——和99%咨询师方向相反，是真正的认知差异化

## 3. 目标受众

**优先级1：事业有成但内心焦虑的中高收入人群（30-45岁）**
企业老板、职场高管、高净值人群的太太。有钱有地位，但内心有恐惧、有匮乏感、有卡点。他们不缺方法，缺的是"从高维看清楚自己卡在哪"。愿意为高客单价服务付费。

**优先级2：婚姻关系出现裂缝、找不到根源的女性**
感觉"努力了但婚姻还是不对劲"，或者"全家人都在耗我"。菲菲的婚姻内容（不被看见/能量滋养/灵魂功课）对这类人有强烈共鸣。

**优先级3：对觉醒/心灵成长感兴趣但不知从哪入手的普通人（种子顾客）**
不一定有钱，但对"活出自己"有渴望。这类人是账号冷启动期的流量来源，也是口碑传播的主力。

**平台聚集地：视频号（中年女性主力阵地）、抖音（泛流量拉新）**

## 4. 变现目标

- 客户想从账号得到什么：扩大影响力，吸引更多高质量客户，传播她的生命智慧体系
- 最适合的变现路径：内容积累信任 → 私信/评论引流加微信 → 1对1咨询（入口） → 觉醒人生陪跑营（主产品，3个月） → 终身服务（留存）
- 时间预期：3个月建立人设，6个月开始稳定引流，1年形成口碑裂变

## 5. 内容潜力

- 能持续输出的方向（至少3个）：
  1. 婚姻/家庭关系（素材极丰富，行业内幕多）
  2. 高端客户案例（千万老板的心理困境，反差感强）
  3. 觉醒/维度提升方法论（信念功课/疗愈SOP/三问法）
- 最有爆款潜力的方向：高端客户反差案例（"几千万老板找我咨询，他的问题不是钱"）
- 内容储备是否充足：充足，原始素材超2万字，案例、方法论、行业内幕都有

## 6. 风险提示

- 最容易踩的坑：内容太"虚"——维度、能量、高维智慧这类词，普通用户听不懂，需要全部落地成具体场景和案例
- 性格或背景上的潜在障碍：她有使命感，容易讲太多，一条视频想说三件事，需要克制到只说一个核心情绪刺点
- 需要提前告知的现实预期：视频号冷启动慢，前3个月以建立人设为主，不以涨粉数量为目标；平台敏感词需注意（避免"保证""一定改变""100%"等表述）
