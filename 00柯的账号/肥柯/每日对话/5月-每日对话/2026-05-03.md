## 一、情绪曲线怎么用文字表现

音乐是辅助，文字才是骨架。文字里藏情绪，靠三样东西：

### 1. 句型的长短切换

不是内容长短，是**视觉上的长短**——观众看字幕能感受到节奏：

```
长句（铺）→ 观众跟着你的细节走，沉浸进去
         "我每天从晚上八点折腾到凌晨一两点，追着技术更新跑"

短句（钉）→ 突然收住，像一锤子砸下来
         "我他妈在给AI打工。"

再长句（再铺）→ 又展开一段新的
         "连做AI的人都把知识存在本地"

再短句（再钉）→ 
         "我凭什么指望AI替我记住一切？"
```

**核心：每一次短句落地的时刻，就是情绪曲线的拐点。** 观众脑子跟不上字幕切换的速度，但情绪跟得上。长→短→长→短，这就是波形。

### 2. 措辞的烈度递进

同一件事，用不同力度说出来，情绪自动分层：

```
轻度 → "不太好用"
中度 → "胡言乱语、质量忽高忽低"
重度 → "我他妈在给AI打工"

你不是在告诉观众"我现在很生气"——
你是在用措辞的烈度让观众自己感受到"事情变严重了"。
```

### 3. 代词切换制造距离感

```
前半段："我以为…"、"我把AI当成…"（主语是"我"，观众还在旁观）

顶点处："我他妈在给AI打工"（"打工"——把自己降成工具，
                           观众开始代入："我也是"）

结尾处："你是大脑，它是外挂"（主语变成"你"，
                             观众从旁观者变成主角）
```

"我→你"这个切换，就是情绪从"共鸣"到"行动"的桥。
