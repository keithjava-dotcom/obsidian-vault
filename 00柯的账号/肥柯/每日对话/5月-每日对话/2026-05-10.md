## 大模型工作原理，一步步拆

### 第一步：分词（Tokenization）

你输入"我饿了想吃饭"。

模型不认识汉字，只认识数字。所以它先把这句话**切成小块**，每个小块叫一个 token。

"我 / 饿了 / 想 / 吃饭" → 每个词对应一个数字ID，比如 [1024, 5837, 291, 8462]。

切得越细，词汇量越大，模型越聪明。DeepSeek V4 用的词表有十几万个token。

### 第二步：向量化（Embedding）

现在有了4个数字ID，但数字本身没有含义——"1024"和"5837"之间没有任何关系。

Embedding 做的事情：把每个 token ID 映射到一个**高维向量**（比如7168维的一个数组），这个向量就是这个词的"含义指纹"。

```
"我"   → [0.03, -0.15, 0.72, ...]  (7168个小数)
"饿了" → [0.41, 0.08, -0.33, ...]
"想"   → [-0.12, 0.55, 0.19, ...]
"吃饭" → [0.27, -0.08, 0.61, ...]
```

向量的精妙之处：含义相近的词，向量也相近。"饿了"和"想吃"的向量方向会比较接近，而"饿了"和"汽车"的向量就差很远。

### 第三步：位置编码（Positional Encoding）

模型读东西不是按顺序读的——它同时看所有token。但"狗咬人"和"人咬狗"含义完全不同。

所以在向量里**注入位置信息**：第一个位置加一组数，第二个位置加另一组数。这样相同的词在不同位置，向量就不同了。

### 第四步：注意力机制（Attention）— 核心

这是大模型最关键的发明。一句话概括：

**让每个词去问其他所有词"你跟我有什么关系"。**

具体怎么做？三个矩阵：

- **Q（Query，提问）**："我"问全场——你们谁跟"我"有关？
- **K（Key，索引）**：每个词贴个标签——"我是'饿了'，是动词"
- **V（Value，内容）**：每个词的真实含义

流程：
1. "我"的Q去和"饿了""想""吃饭"的K做点积（算相似度）
2. 算出分数："我"和"饿了"相关性0.8，"我"和"吃饭"相关性0.6，"我"和"想"相关性0.4
3. 用这些分数作为权重，把各个V加权求和

结果：**"我"被重新定义**——它现在不再只是"我"，而是"一个饿了想吃饭的我"。

这就是"理解上下文"。一个词经过注意力后，吸收了整句话里其他词的含义。

### 第五步：多层堆叠（Transformer Layers）

一层注意力不够。第一层理解了"我饿了"，第二层可能理解"我饿了所以想吃饭"，第三十层可能理解"这种饿是生理饥饿还是心理空虚"。

**每往下一层，理解就更深一层。**

视频里说的"token穿一层就暗一分"，说的是信息损耗——几十层算下来，原始信息慢慢被稀释了。

### 第六步：残差连接 + 层归一化

为了解决信息损耗，有个**旁路**：每层计算的输出，**加上**输入的原值。

```
输出 = 注意力加工(输入) + 输入（原封不动）
```

这样就算某一层做了错误计算，原始信息还在。视频里说的"支路"和"超链接"就是这个。

### 第七步：前馈网络（Feed-Forward Network）

注意力让词之间互相交流完后，还要过一个**独立加工厂**——前馈网络。

比方说经过注意力后，"饿了"现在知道自己是"我"的感受、程度是"强烈"的。前馈网络就把这些信息进一步加工，提取更深层的特征。

**注意力 = 词和词之间交换信息。前馈 = 每个词自己深度加工。**

### 第八步：KV缓存压缩（MLA / 注意力池化）

这是 DeepSeek V4 的核心创新。

注意力计算需要存 K 和 V（每个词的两个矩阵）。你如果输入了10万个token，KV矩阵就大到爆显存。

DeepSeek 的做法叫 **MLA（Multi-head Latent Attention，多头潜在注意力）**：

- 不存完整KV，而是把KV**压缩成一个极小的潜在向量**
- 需要计算时再从这个潜在向量还原
- 同时保留最近几个token的**高清未压缩版本**（滑动窗口）

效果：显存省了80%以上，推理成本大幅下降，但精度损失极低。

视频里"每四个KV压成一个精华线"就是这个意思。

### 第九步：MoE（混合专家模型）

前面说的前馈网络，一个模型通常只有一个。但 DeepSeek V4 有**很多个前馈网络**——叫"专家"。

每个 token 进来，先过一扇**门（门控网络）**，门控网络判断这个token应该交给哪几个专家处理。

```
"饿了" → 门控 → 激活专家#3（饮食语义）、专家#17（身体状态）
"想吃饭" → 门控 → 激活专家#3（饮食语义）、专家#42（动作意图）
```

同时只激活少数专家（比如8个），而不是全部671B参数都在算。**总参数量大，但每次推理只用一小部分。** 这就是 DeepSeek V4 又快又便宜的秘密。

### 第十步：线性投影 + Softmax（输出）

最后一层算完，得到最后一个token的向量。但它还是7168个小数——人类看不懂。

- **线性投影**：把7168维向量映射到词表大小（十几万维），每个维度对应一个词的分数
- **Softmax**：把分数转成概率——"吃饭"概率0.72，"睡觉"概率0.15，"跑步"概率0.03...

选概率最高的那个词：**"吃饭"**。

### 第十一步：自回归（生成下一个词）

模型输出了"吃饭"，然后把"吃饭"作为新的输入，放到之前的序列后面：

```
"我 饿了 想 吃饭" → 预测 → "了"
"我 饿了 想 吃饭 了" → 预测 → "吗"
"我 饿了 想 吃饭 了 吗" → 预测 → 结束
```

**每次只生成一个词，然后用这个词作为下一次的输入，循环到结束。**

这就是你看到AI一个字一个字往外蹦的原因。

## 日式排版，我知道的那些事

日式排版不只是"留白"两个字，它是一整套视觉伦理。我从大到小说。

### 一、哲学地基：不是技法，是审美本能

**1. 間（ま）— 负空间崇拜**

留白在日本设计里不是"省事的空白"，而是**画面的主角之一**。内容和空白同等重要。

你去看原研哉的MUJI海报——地平线系列，画面95%是天空和大地，一条地平线加一行小字。那不是省钱，是**空白在说话**。

2. **引き算（减法）— 减到不能再减**

西方设计思维是"加法"——加元素、加装饰、加层次。日本是"减法"——不是"还能加什么"，而是"还能删什么"。

删到最后只剩骨头，那个骨头就是设计的灵魂。

3. **詫び寂び（Wabi-sabi）— 不完美即完美**

不对称、不规则、不完美——这跟中国人"工整对称"的审美正好相反。日本海报很少正中央放标题，一定是偏的、歪的、不完全对称的。

---

### 二、文字排版的四件事

这才是真功夫。字不是"打上去的"，是"摆上去的"。

**1. 字重对比**

日本人玩字重玩得极致。不是"粗体标题+细体正文"这么简单。而是一个画面里可能有五种字重：极粗、粗、中、细、极细——分别担任"视觉打击→信息分层→氛围渲染"的角色。

短视频封面上能学的：**标题用最粗的，其他字能用多细用多细**。粗细差距拉开，高级感就出来了。

**2. 假名与汉字的节奏**

日语是汉字+假名混排。汉字方正厚重，假名圆润轻盈。同一个句子里，汉字和假名天然产生节奏变化。

中文没有假名，但可以用 **「宋体+黑体混排」** 模拟这个效果——关键词用粗黑体，辅助词用细宋体，视觉节奏就出来了。

**3. 字间距**

中国设计师习惯"默认间距"。日本设计师对字间距有洁癖——**标题类必须手动调字间距**，尤其是在字少的封面上。

你试一下：把封面标题的默认字间距拉开15-20%，立刻贵了。

**4. 竖排**

日式海报大量用竖排。中文短视频封面大部分横排。偶尔用一次竖排标题放在画面左侧或右侧，视觉差异巨大，辨识度一下子就出来了。

---

### 三、构图的不对称法则

中国人习惯了"居中对称"，日本设计恰好相反——**不对称才是高级**。

| 中式直觉 | 日式做法 |
|----------|----------|
| 标题放中间 | 标题放一侧（通常左侧或左上） |
| 元素均匀分布 | 重心故意偏斜，另一侧留白 |
| 画面撑满 | 画面有"空"的地方 |
| 对称 = 平衡 | 不对称 + 留白 = 视觉平衡 |

短视频封面上最直接的应用：**人脸放一侧，标题放另一侧的空白区域，人脸和标题不对齐。**

---

### 四、配色体系

**1. 低饱和主色**

日本设计的颜色很少"纯"。红色不是大红，是赭红、暗红、砖红。蓝色不是正蓝，是靛蓝、灰蓝、藏青。全都降低饱和度。

**2. 黑白灰为底，一个强调色**

日本最经典的海报配色：大面积白或浅灰底色 → 黑色标题 → 一个高饱和色做点缀（通常是很小的面积）。

短视频封面上：背景用白/浅灰/黑，标题用重黑，辅助信息用一个颜色（不要多于一个）。

**3. 传统色**

日本有自己的一套传统色系统——「和色」。这些颜色天然带有高级感，因为它们来自植物染料和自然矿物。

你可以直接用这个窍门：**封面背景不要用纯白，用"生成色"（类似米白、象牙白），暖1-2个色温，高级感就出来了。**

---

### 五、几何形的运用

日本设计大量用**线、框、圆**来分割画面：

- **细线分割**：一条0.5pt的极细线横穿画面，上下分区
- **圆形聚焦**：一个空心圆圈住文字，视觉聚拢
- **矩形框架**：用细边框把文字框起来，形成"画中画"
- **对角线切割**：一条斜线把画面切成两个色块

封面上最简单的一招：**在标题旁边放一个极小的几何元素（圆点、小方块、细横线），不解释，不标志，就是放在那。** 这就是"设计感"——不需要理由的元素。

---

### 六、照片处理

日本设计中照片很少"裸放"，一定会处理过：

- **降低对比度**：照片做褪色处理，方便在上面叠文字
- **裁切大胆**：不追求完整性，敢把主体切一半
- **黑白化**：彩色照片转黑白后叠一个暖色调

短视频封面上：拿一张照片，降饱和30%，对比度减10%，再叠上白色大字——立刻日式。

### 二、文字：封面最直接能用上的六招

- 封面标题3-5个字：字间距拉开到字号的15%-25%

- 偶尔用一次竖排放在画面左或右侧1/3处
- 中文竖排天然带有"古典+高级"的联想

**6. 文字不要居中**
- 居中是最安全、最无聊的对齐方式
- 左对齐是日式的默认选择

**方案B：低饱和双色**

**缺点**：iCloud 和 Google Drive 同时同步可能有冲突（两个同步服务争抢同一个文件夹）

### 方案二：Custom Frames 插件

**优点**：不离开 Obsidian，复制粘贴笔记内容到 NotebookLM 很快
**缺点**：本质上还是手动操作，没自动化

### 方案三：手动导出上传
