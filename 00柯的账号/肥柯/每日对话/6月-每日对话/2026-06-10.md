# 2026-06-10 文案实验 · 同一素材双账号写稿

> 📝 两个实验：同一份700平别墅素材，分别写给"本地服务端"和"冉总IP"两个账号。
> 一个讲活儿，一个讲信任。

---

## 素材

```
客户付先生，700余平（地上4层+地下2层），风机发电工程，极度爱干净不爱动手
5天5人7项服务：全屋收纳/深度保洁/玻璃/沙发/烟机拆洗/厨房除油/二楼除异味
报价10万+
四楼一个房间物品300余万，必须戴手套鞋套，拍照留底，原样归位
```

---

## 实验一：本地服务端

### 任务
用现场看房人的视角，写一条给大连本地找保洁的人看的稿子。

### 写作过程

**Step 1 — 定位受众**
给谁看：大连本地有保洁需求的人。要让他觉得"这个公司干活靠谱"。
谁在说：去现场看房的人，不是坐办公室的老板。边走边跟你说。

**Step 2 — 写第一版**
```
700多平。全屋收纳、深度保洁、玻璃、沙发、烟机拆洗、厨房除油、二楼除异味——七项服务。
五天，五个人。报价，十万。
四楼一个房间。东西，三百多万。
你进去手一伸旁边就是个你赔不起的东西。
团队进去戴手套、鞋套。全程手背在后面。
不是紧张。是规矩。
...
```

**Step 3 — 柯哥提醒：别用"10万"具体数字**
改成"报价不便宜""听着多不多？"这种引发好奇的方式。

**Step 4 — 出稿**
- `09-大连某高端小区，700平别墅，10万块钱的活儿。.md` → 标注版
- IP口语稿应该编号10，但09已被"探探大连2000平的家政店"占用

### 错误
- **编号冲突**：没检查现有文件就用09编号
- **修复**：改名10，记入 `小龙-错误清单.md` 第13条

### 产出
- `09-大连某高端小区，700平别墅，10万块钱的活儿。.md`（标注版）
- `10-700平别墅十万块钱的活儿-IP版.md`（IP口语稿）

### 核心判断
同一件事，本地号讲的是"活儿多大"，核心钩子是"你进去手一伸旁边就是个你赔不起的东西"。

## 实验二：冉总IP

### 任务
同样的700平别墅素材，用冉总（创始人）的视角写一条给创业者/潜在合作伙伴看的稿子。

### 写作过程

**Round 1 — 直接进fanwen，失败**

没走dagang，直接激活fanwen出逐字稿。

🔴 **重大错误**：看到IP语言档案里"删减派"标签，"句子极短，事实接事实"，于是机械地把每句话切成发电报：
```
700多平。全屋收纳、深度保洁...七项服务。五天。五个人。报价，十万。
四楼一个房间。东西，三百多万。
团队进去，戴手套，鞋套。手背在后面。
不是紧张。是规矩。
```

柯哥指出来：
> "删减派让稿子又变成了发电报。删减派这个概念来自哪里？"

**复盘**：IP语言档案里有一节"补丁·极短句≠切词组"（2026-06-10），明确写了：
> "一段话里短句号连打超过3次→报警"
> "念着像发电报/打快板→句号太多了，用逗号揉回去"

我读了这个补丁，但在"删减派"标签下机械执行，完全无视了补丁的警告。

**Round 2 — 柯哥让删除"删减派"概念**

从IP语言档案中删除：
1. `〇·句法派系` 整个章节（派系标签、判定依据、补丁）
2. `删减派 IP 通用死穴` → 改为 `通用死穴`

死穴本身保留（自问自答、扣题总结、"此时此刻"等仍然是冉总不能用的），只是标签删了。

**Round 3 — 不发电报了，改正常版**

重新写，用了自然节奏：
```
700多平，全屋收纳、深度保洁、玻璃、沙发、烟机拆洗、厨房除油、二楼除异味——七项服务。
五天，五个人。报价，十万。
四楼一个房间，东西三百多万。
团队进去，戴手套，鞋套。手背在后面。
不是紧张。是规矩。
```
⚠️ 仍然有"报价十万"——此时还没收到柯哥"不说具体价格"的要求。

**Round 4 — 柯哥让重新走dagang→fanwen流程**

> "你用这个素材，重新走一下dagang技能，然后再走一下fanwen技能出逐字稿呗"

**Dagang环节**：

含金量体检：A级（全过）
- 闸1（意识形态）✅：专业性、信任、极致精细——对齐目标受众价值观
- 闸2（速判性）✅：真实案例，平视分享
- 闸3-6全部✅

三步主轴：
- 锚定对象：事（700平10万项目）
- 大类：清单式
- 动力类型：共鸣性推进（观众从围观到理解"一冉为什么能做到"）

**柯哥拍方向**：
1. ❌ 不要透露客户隐私 → 用"大连企业家""有别墅的人"
2. ❌ 不要说报价10W → 说"高质量客户"
3. ✅ 加一条：家政创业者要把自身价值做上去
4. ✅ 加：15步标准化流程
5. ✅ 核心：一冉对谁都一样，不分别墅还是普通住家

**Fanwen环节**：

冰山水下五件：
- 规定情境：冉总坐办公桌前，回顾公司签的单
- 情绪反应：平静里有底气，不炫耀
- 行动动机：很多人不知道家政能做成这样
- 人物关系：想创业的女性、潜在合作伙伴
- 最高任务：让屏幕前的人觉得"我想做出这样的家政公司"

路C（没有IP初稿），按dagang骨架新建毛坯。

**V1产出**：

**Round 5 — 柯哥说"加点血肉"**

加了5处具身体验和视觉细节：
- "地上四层、地下两层。光走一圈，腿都酸。"（身体感受）
- "五天，五个人。"（工期人力）
- "收藏品、摆件、字画，看着不重，碰碎了赔不起。"（视觉品类+后果）

## Round 7 — 柯哥教"人味桥梁法则"，彻底重写

### 柯哥指出的问题

> "你在陈述事实和升华价值观之间，缺少了情绪的桥梁。你加了'腿发酸'、'赔不起'这些细节，这很好，但这叫'加肉'，不叫'加人味'。真正的'人味'，是在镜头前跟观众聊天、拉扯、预判观众的想法。"

### 对比诊断

**❌ 我的版本（工作汇报+生硬鸡汤）**：
```
团队进去，戴手套，鞋套。15步标准化流程。
客户是大连的企业家……
在我们一冉，对谁都一样。不会因为你住别墅就好好干……
家政这行，最贵的不是价格。
```
→ 自言自语念旁白。观众被动接收，没有参与感。

**✅ 内容总监爆改版（顶级人味与拉扯）**：
```
那这活儿咱们怎么干？ ← 设问开头，拉回注意力
所有保洁进去，必须戴手套鞋套……
有人可能会说：冉总，这种大别墅的客户，
你们肯定得伺候得特别仔细吧？ ← 替观众把偏见说出来
说句掏心窝子的话……在我们一冉，规矩对谁都一样。 ← 翻掉偏见
```
→ 跟观众聊天。你猜他怎么想、替他说出来、然后告诉他真相。

### 人味 ≠ 加血肉

| 加肉 | 加人味 |
|------|--------|
| 加具体细节、感官描写 | 加对话感、拉扯感、预判观众心理 |
| "腿发酸""碰碎了赔不起" | "那这活儿咱们怎么干？""有人可能会想……" |
| 让文案更生动 | 让文案变成聊天 |

### 人味桥梁法则（已吸收进写作核心）

1. **设问引出流程**：不要直接罗列流程/标准，用"这活儿怎么干？""遇到这种客户怎么办？"来引出动作
2. **反直觉垫话**：在说出价值观之前，先替观众把世俗偏见说出来（"你肯定以为……"），再一把推翻

### 自问自答的边界重新理解

| 该删的自问自答 | 该留的聊天钩子 |
|----------------|----------------|
| "为什么？因为…" — 机械空转 | "那这活儿咱们怎么干？" — 我替观众问，然后答 |
| "怎么来的？其实是…" — 替自己问 | "有人可能会想：冉总，你们肯定…" — 预判观众心理 |
| 自己设问自己答 — 像在自言自语 | 替观众提问然后回答 — 像在跟他聊天 |

### 重写后的关键变化

1. "这活里面最难的，不是大。是四楼有个收藏室。" → 先悬疑再揭底
2. "那这活儿咱们怎么干？" → 设问开头，观众注意力拉回来
3. "有人可能会想——冉总，这种大别墅的客户，你们肯定得伺候得特别仔细吧？" → 反直觉垫话，替观众把偏见说出来
4. "说句掏心窝子的话……绝不会因为你住700平的别墅……也绝不会因为你住70平的老破小……" → 推翻偏见，价值观落地
