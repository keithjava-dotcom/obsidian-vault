# 自媒体联盟 · 商业模式 v0.1

## 一句话

**免费加入、日更换技术、三条变现出口——柯哥出赛道和产品，成员靠执行力赚自己的钱。**

---

## 一、联盟是什么

一个免费、公开、公益的自媒体实践联盟。

- 不收会费
- 不签独占
- 分享短视频技术

唯一的入场券：**给柯哥拍视频。**

---

## 二、成员规则

| 规则 | 说明 |
|------|------|
| 必须日更 | 每天至少一条——拍自己 + 拍柯哥 |
| 一周不更 | 踢出联盟，权限收回 |
| 拍什么 | 柯哥的工作日常、观点输出、教学场景 |

**逻辑**：拍柯哥的过程 = 学技术的过程。构图、引导IP说话、剪辑节奏——每天都在练。

---

## 三、三条变现出口

### 出口一：卖大连本地代运营

| 环节 | 谁做 |
|------|------|
| 销售 | 成员自己谈 |
| 交付 | **通过考核的成员**接单 |
| 未过考核 | 只能卖，不能交付。单子甩给联盟里过了考核的人接 |

**考核标准**：代运营能力验收——能独立完成从定位→脚本→拍摄→剪辑→复盘的全流程，由柯哥审批通过。

### 出口二：卖柯哥的课程（4980新媒体技巧课）

| 环节 | 谁做 |
|------|------|
| 销售 | 成员 |
| 交付 | **柯哥亲自** |
| 分润 | 成员拿提成（比例待定） |

### 出口三：招全国加盟商

| 环节 | 谁做 |
|------|------|
| 线索获取 | 成员（通过账号内容吸引） |
| 转化成交 | 推给柯哥 |
| 分润 | 成员拿 **10%** |

---

## 四、飞轮

```
新人入盟（免费，日更换入场券）
  │
  ├─ 每天拍柯哥 + 拍自己 → 练技术
  │
  ├─ 账号做起来了
  │     ├─ 卖课程（前端，柯哥交付）
  │     ├─ 招加盟（前端，推给柯哥，10%提成）
  │     └─ 想接代运营？
  │           ↓
  │         通过考核
  │           ↓
  │         接单交付赚钱（前后端通吃）
  │
  ├─ 成员赚到钱 → 案例 → 更多人想加入
  │
  └─ 柯哥获得：大量免费UGC内容（多账号分发）
```

## 五、柯哥的收益

| 维度 | 收益 |
|------|------|
| 内容 | 多个账号同时在拍柯哥，全网内容密度暴增 |
| 课程 | 销售队伍指数级扩张 |
| 加盟 | 线索来源从1个号变成N个号 |

## 七、一个形象的比喻

这不是MCN。MCN是"你这个号我签了，我帮你变现"。

这是**驾校+滴滴的结合体**：
- 先免费教你开车（日更练技术）
- 你要想拉客赚钱，得过考试（考核）
- 过了考试你开滴滴（代运营交付）
- 不想开车也行，你卖课、卖加盟（分润模式）

柯哥的角色不是老板，是**驾校教练+车队调度**。
