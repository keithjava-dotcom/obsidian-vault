# 客户全景仪表盘

> 这份仪表盘是 Dataview 自动生成的视图。
> 数据源:每个客户的「客户元数据.md」frontmatter。
> 仪表盘自动刷新,不需要你手动维护。

## 数据从哪来

仪表盘扫描 `04服务客户/` 下所有带 `client_role: client` 标签的 .md 文件。
每个客户在自己的目录下有一份「客户元数据.md」(或类似名字),
仪表盘读取它的 frontmatter 字段。

**仪表盘暂时是空的是正常的——它需要等客户的元数据文件建好。**

## 视图 1:所有客户当前状态

```dataview
TABLE
  client_name AS "客户",
  service_status AS "当前阶段",
  last_delivery_date AS "最近交付",
  risk_level AS "风险"
FROM "04服务客户"
WHERE client_role = "client"
SORT last_delivery_date DESC
```

## 视图 2:柯哥的审核待办池

```dataview
TABLE
  client_name AS "客户",
  柯哥审核待办 AS "待办事项",
  service_status AS "阶段"
FROM "04服务客户"
WHERE client_role = "client" AND length(柯哥审核待办) > 0
SORT length(柯哥审核待办) DESC
```

## 视图 3:风险等级中/高的客户(优先关注)

```dataview
TABLE
  client_name AS "客户",
  service_status AS "阶段",
  risk_level AS "风险",
  last_delivery_date AS "最近交付"
FROM "04服务客户"
WHERE client_role = "client" AND (risk_level = "中" OR risk_level = "高")
SORT risk_level DESC
```

## 视图 4:超过 7 天没动的客户(可能被遗忘)

```dataview
TABLE
  client_name AS "客户",
  last_delivery_date AS "最近交付",
  service_status AS "停在哪"
FROM "04服务客户"
WHERE client_role = "client" AND date(today) - last_delivery_date > dur(7 days)
SORT last_delivery_date ASC
```

## 视图 5:Hanako 起草中、待柯哥审核

```dataview
TABLE
  file.name AS "文件",
  client_name AS "客户",
  delivery_type AS "类型",
  created_at AS "起草时间"
FROM "04服务客户"
WHERE status = "ai-drafted"
SORT created_at ASC
```

## 怎么让仪表盘"活起来"

每个客户的元数据文件需要有标准 frontmatter。

**优先级**:
- 高:菲菲(MVP 试点客户)
- 中:其他正在服务的客户
- 低:历史归档的客户

**不需要一次做完**。
每次有新客户接入或有现成客户改造,顺手加 frontmatter 即可。

具体的 frontmatter 标准在 [[02-客户元数据标准]] 里。
