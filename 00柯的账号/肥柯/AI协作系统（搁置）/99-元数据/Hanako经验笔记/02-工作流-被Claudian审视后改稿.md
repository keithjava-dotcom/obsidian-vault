# 经验笔记：被 Claudian 审视后改稿

## 一、什么时候会触发这种工作

**什么样的初稿会被 Claudian 审视？**
- 进入客户服务模式后起草的第一份稿子
- 柯哥主动召唤 Claudian——没有固定频率，由柯哥决定
- 目前已知：菲菲第 07 稿是 Claudian 第一次被召唤审视的稿子

**什么样的反馈意味着我要改 v2？**
- 不是"措辞要调整"——那个柯哥直接在注魂里改
- 是"结构层面有问题"——情绪刺点不唯一、中段抽象孤岛、开头不是0帧、骨架没有血肉
- 当 Claudian 调用多篇方法论笔记做诊断、给了具体的改稿优先级时 → 要出 v2

---

## 二、读 Claudian 报告时的关键动作

**今晚我做对的：不是全盘照单全收。**

### 什么样的建议要采纳
- **有方法论支撑、能直接定位到稿子里具体句子的判断。** 比如"开头是背景介绍不是0帧起手，把邻居那句话直接放第一帧"——明确、可执行、有方法论依据。
- **不改变客户交付原则、只优化结构的建议。** 唯一化情绪刺点、补场景——这些不改菲菲的语气，只改骨架。

### 什么样的建议不采纳（或调整后再采纳）
- **涉及"替客户编内容"的建议。** Claudian 建议"选一个菲菲提供过的具体细节填进纠结段"。但沟通记录里没有这个颗粒度——如果我编一个，就违反了"不给菲菲写稿子"的原则。我把"填场景"改成了"问场景"——用更具体的开放式提问引导菲菲自己说。
- **改变客户语气规则的。"** 内心独白使用风险"笔记说新 IP 要警惕内心独白。但菲菲不是新 IP了，到了第07稿，她的镜头感已经在建立。这份稿子不需要为"内心独白风险"做保守处理。

### 不被带偏的方法
读完 Claudian 报告后，先问自己三个问题再动手：
1. 这条建议改了之后，稿子还是菲菲在说话吗？
2. 这条建议需要的素材，菲菲的沟通记录里有没有？没有的话，我是不是在替她编？
3. 这条建议是改结构（可以做），还是改语气（碰之前要更谨慎）？

## 三、调用方法论笔记的实操经验

### 今晚的选择：5 篇深读，2 篇不读

| 深读的 5 篇 | 理由 |
|------------|------|
| 0帧起手 | 开头重构必须有这条规则打底 |
| 核心卖点只有一个 | 三个情绪锚点竞争——这条是砍锚点的刀 |
| 文学性原稿改短视频 | 感受→事件——整个纠结段要换写法 |
| 骨架里要有血肉 | 补场景——纠结段画面完全空白 |
| 情绪三起三落 | 情绪曲线——给金句制造爆发前的低谷 |

| 不读的 2 篇 | 理由 |
|------------|------|
| 从抽象到具象 | 柯哥在 v1 里直接标注了抽象句——问题已被精确定位，不需要方法论再诊断一次 |
| 内心独白使用风险 | 菲菲在第07稿，不是新IP了。且 v2 已经走向事件叙述，这条不适配当前稿子 |

### "选择性调用"的原则

不是每篇相关笔记都要读。判断标准是：
1. **这个缺陷是"直觉感知到的"还是"已精确标注的"？** 后者不需要再翻方法论——问题已经定位了，直接动手改。
2. **这条笔记适配当前客户的阶段吗？** 新 IP 第一稿的适用规则，不一定适用于第07稿的菲菲。
3. **翻了这条笔记后我的执行动作会改变吗？** 如果读了也是做同样的事，不读。

## 四、改写时的常见错误

今天 v1→v2 我踩的一个坑：

**以为"排成线性"就是"唯一化"。** v2 里我把三个锚点排成"开头（眼睛在发光）→中段（问了一个月）→结尾（想都是恐惧）"——以为这就是唯一化刺点。但 Claudian 后来指出"问了一个月"还是独立情绪落点。压在中间不等于降级为铺垫。

**我可能还会踩的坑（还没发生但需要警惕）：**
- 改了结构但丢了原稿的优点。v2 开头有力了，但会不会没有 v1 的温和感了？要对比检查。
- 按方法论改但失去了客户语气。五篇笔记都是柯哥的方法论——但菲菲不是柯哥。改结构的时候，菲菲的词汇不能变成柯哥的。
- 为了改而改。如果 Claudian 给了三条建议，但有一条改了反而更差——要敢说不改。
- 改完之后看不懂自己 v1 当初为什么那么写。要保留 v1 作为对照，不删除、不修改。

今晚自评 78-82。Claudian 预估 82-85。误差 3-4 分。

这一节只有一次数据点，无法建立校准规律。留待更多循环后补。

## 六、给我自己的提醒

Hanako——

你改 v2 的时候做对了一件事：不是全盘照抄 Claudian。她让你填场景，你改成问场景——因为你记得菲菲的稿子不是用来替她编故事的。

但你也做错了一件事：你以为把三个锚点排成一条线就叫"唯一化"。把东西排进流水线不等于把情绪压成单点。下次写稿的时候，写完情绪主线之后回头问一句：中间那个落点是在帮最后一句蓄力，还是在跟最后一句抢戏？

最后——v1 到 v2 的差距，不是你的语言能力，是你有没有拿起方法论工具。你缺的不是感受力——柯哥和 Claudian 都说了这一点。你缺的是把"这里不对劲"变成"用这条方法论改这里"的执行习惯。下次别停在感知层。
