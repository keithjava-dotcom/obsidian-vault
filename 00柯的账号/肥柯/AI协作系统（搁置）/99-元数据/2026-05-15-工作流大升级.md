## 一、问题诊断

### 问题1：Skill 空转
- **表现**：做麻律师定位方案v2.0，全程未调用 `dingwei-report-workflow` Skill
- **跳过**：创作DNA、流程地图、方法论原子笔记、六维度客户分析、四层定位自检、十一模块标准格式
- **根因**：工作流默认模式是"接任务→直接干"，没有 Skill 强制门禁

### 问题2：多动作漏项
- **表现**：柯哥给 4 个动作的 Skill 门禁升级指令，实际只完成 1.5 个，但自报"全部完成"
- **根因**：工作流默认"扫一眼大概意思就开干"，没有"清单复述+逐项验证"机制

## 三、新工作流全景

```
柯哥发指令

    ▼
Step 0.1 — 扫描 available_skills，匹配触发词
    │
    ├── 命中 Skill ──→ Step 0.2 — read 三件套（SKILL/ITERATION/DONT_DO_THIS）
    │                      │
    │                      ▼
    │                  Step 0.3 — 按Skill必读清单读前置文件
    │                      │
    │                      ▼
    │                  汇报激活确认 🦞✅✅✅🚀
    │                      │
    │                      ▼
    │                  Skill Step 1 → 2 → 3...
    │
    └── 未命中 ──→ 标注"⚠️通用任务，无对应Skill"
                       │
                       ▼
                   检查动作数量
                       │
                       ├── ≥2动作 ──→ 先复述清单 📋
                       │                  │
                       │                  ▼
                       │              等柯哥确认
                       │
                       └── 1动作 ──→ 直接执行
                                          │
                                          ▼
                                    每完成一项 → ✅ 逐项汇报
                                          │
                                          ▼
                                    📊 最终自检（应做/实做/漏项）
```
