# 课程骨架草稿：创业小老板新媒体21小时一对一

**学员画像**：开烤肉店 + 卖烤肉食材 + 理发店的创业小老板
**之前状态**：找过代运营，现在想自己干
**基础**：零
**目标**：学会做人设 + 学会本地生活内容 + 解决留资问题
**规格**：7次课 × 3小时 = 21小时

---

## 课程目标

**让一个零基础的实体店老板，7次课后能独立拍出有留资能力的本地生活短视频。**

---

## 第1次课：认知重建 + 账号定位（3小时）

### 核心内容
1. **打破旧认知**（45min）：为什么代运营不管用了 / 本地老板自己做内容的优势在哪 / "自己干"和"找人干"的真正区别
2. **定位五要素**（60min）：价值（你给谁提供什么）+ 用户（服务谁）+ 人设（你是谁）+ 类型（什么形式）+ 风格（什么调性）。现场帮学员用这五个要素写出第一版定位
3. **一句话定位**（30min）："我给谁提供什么价值"公式。验收标准：目标受众看到第一句话，能不能立刻判断"这个账号跟我有关"
4. **定位是模糊的方向**（15min）：先做决策，边做边清晰。不等百分之百确定再行动
5. **课后作业**（15min）：把一句话定位发给10个真实客户或朋友，收集反馈

### 调用的知识笔记
- `定位_账号定位五要素` — 五要素框架
- `定位_人设不等于定位` — 区分定位与人设
- `定位_定位是模糊的方向` — 行动优先心态
- `账号定位_一句话定位要过受众视角测试` — 验收标准
- `定位_账号定位的核心公式` — 我给谁提供什么价值
- `定位_目标受众默认收窄` — 前3个月只磕第一受众

### 学员课后能做到
写出一句经过验证的一句话定位，能说清楚"我的账号是给谁看、提供什么价值"

---

## 第2次课：人设建立 + 找到自己的记忆点（3小时）

### 核心内容
1. **人设≠定位**（20min）：人设是五要素之一，不是全部
2. **四种人设挖掘法**（60min）：
   - 特殊经历法：你身上有什么和同行不一样的经历？（开烤肉店之前你在干嘛？为什么做这行？）
   - 以弱胜强法：你的短板是什么？把它变成你的课题（"我不像大店有中央厨房，但我的肉是从XX来的"）
   - 工具在前人格在后法：先提供能用的价值，再让人喜欢上你
   - 划清敌友法：你的朋友是谁？你的敌人是谁？（"帮想好好吃饭的人拒绝预制菜"，立敌=预制菜）
3. **导师型还是陪伴型**（20min）：帮学员判断，烤肉店老板更适合哪种
4. **人设反差写法公式**（30min）：粗颗粒词汇（翻肉/油烟/凌晨进货）+ 高维度词汇（供应链/成本结构/品质门槛）= 反差张力
5. **人设不是宣告出来的**（10min）：自然划过，不宣告。不讲"我是一个认真的烤肉店老板"，而是在讲肉的时候带出来
6. **课堂练习**（30min）：现场写出学员的"人设记忆点清单" + 3个"自然划过"的文案片段
7. **课后作业**（10min）：挖掘3个自己觉得"没什么特别的"但可能是记忆点的经历

### 调用的知识笔记
- `人设不等于定位` — 区分定位与人设
- `特殊经历是人设的记忆点` — 挖掘特殊经历
- `以弱胜强现身说法` — 弱点变竞争力
- `短视频_安先生技法全集-柯哥适配版` — 人设五个关键：领域+体验、划清敌友、过度热爱、弱点共鸣、工具在前人格在后
- `人设反差写法公式_粗颗粒加高维度` — 反差张力公式
- `定位_陪伴型博主vs导师型` — 类型判断
- `定位_人设型vs内容型的选择` — 起号前路径选择
- `定位_特殊经历和弱点是最强人设` — 弱点就是差异化
- `流量人格化` — 不可替代的是判断/经历/气质/价值取向

### 学员课后能做到
手里有一份自己的人设记忆点清单，能说出"我让观众记住我的3个理由"

## 第3次课：选题库建立 + 内容规划（3小时）

### 核心内容
1. **四大内容柱**（45min）：干货知识40% + 案例故事30% + 副业变现20% + 热点借势10%。帮学员适配到烤肉/理发场景：
   - 干货：怎么选肉/怎么烤不柴/理发怎么跟Tony沟通
   - 案例：今天店里来了个特别的客人/那条差评让我改了什么
   - 副业变现：我的烤肉酱/食材包怎么买
   - 热点：节假日/天气/本地事件蹭法
2. **选题公式 = 需求 × 解决方案**（30min）：每条视频回答一个具体问题
3. **六大爆款选题公式**（30min）：数字清单型、反常识型、对比冲突型、故事型、痛点型、场景型
4. **冷启动期内容策略**（30min）：账号权重低时越垂直越好。前1000粉集中做干货+案例
5. **选题库搭建**（30min）：现场帮学员列出前30条选题。问自己"客户一个月来问我的前10个问题是什么"
6. **课后作业**（15min）：每天记录1个客户问过的问题，连续7天

### 调用的知识笔记
- `内容策略_四大内容柱与冷启动原则` — 内容比例与节奏
- `选题_冷启动期内容策略` — 新号内容策略
- `选题_选题公式需求乘以解决方案` — 选题核心公式
- `选题_每条视频要有赌注` — 每条视频的核心竞争力
- `选题_围绕自己展开且保持垂直` — 垂直性原则
- `选题_超量准备选题库和EIOR调研` — 选题库建设
- `选题_选题落地定位` — 定位通过选题落地
- `定位_选题落地定位` — 观众看不到蓝图只看到视频

### 学员课后能做到
有一份30条选题清单，知道未来一个月每天拍什么

## 第4次课：文案写作——从一句不会写到能出逐字稿（3小时）

### 核心内容
1. **文案和文字的区别**（20min）：文案要留下三样东西——情绪共鸣、身份认同、行为引导。写每一句话前问"这句话的目的是什么"
2. **声音优先**（20min）：先写文案→录成音频→再配画面。画面是填空题，声音是骨架
3. **0帧起手**（40min）：开头禁止"大家好我是XX"，四种起手方式：
   - 直接切入事件："今天来了个客人，说我的肉不如XX。我笑了。"
   - 直接给反常识："烤肉店越忙越亏，你们信吗？"
   - 直接还原对话："师傅，我不想剪太短。/那你来理发店干嘛？"
   - 直接抛冲突："我开了3家店，最赚钱的居然不是最大的那家。"
4. **五种钩子选一个**（20min）：利益钩/悬念钩/冲突钩/共鸣钩/反常识钩
5. **总分总结构**（30min）：开头5秒点题→中间并列/递进/对比展开→结尾快速总结+点睛
6. **100字一单元**（20min）：每100字自成一体，只有20%承上启下
7. **课堂练习**（30min）：现场用学员自己的选题，写出3条完整的逐字稿开头
8. **课后作业**：用剩下的选题写出10条完整的逐字稿，每条60-80秒

### 调用的知识笔记
- `文案_文案的核心功能是引导行为` — 文案本质
- `文案_文案的三个留存物` — 情绪共鸣/身份认同/行为引导
- `文案_文案必须有目的性` — 每句话的目的
- `声音是视频创作的第一位` — 声音优先原则
- `短视频开头禁止自我介绍必须0帧起手` — 开头法则
- `开头三秒决定完播率` — 开头重要性
- `开头五种钩子类型` — 五种钩子选一种
- `文案_总分总结构与清单式结构` — 宏观结构
- `文案_短视频文案结构总分总加100字一单元` — 微观结构
- `短文案写法索引` — 封面/标题速查
- `短视频骨架三段论` — 开头抓人/中间留人/结尾升华
- `文学性原稿改短视频的核心动作` — 把感受换成事件
- `写短视频稿的第一步是确定受众` — 受众决定骨架
- `开头0帧起手需要嵌入上下文关键词` — 0帧+关键词公式

### 学员课后能做到
手里有10条完整的逐字稿，能拿起来就拍

## 第5次课：本地生活内容实战——拍什么、怎么拍（3小时）

### 核心内容
1. **本地生活内容的本质**（30min）：服务半径3-5公里的人为什么要在抖音看你？不是因为你多专业，是因为你让他们"觉得近、觉得真、觉得想来"
2. **四种本地爆款模板**（60min）：
   - 产品展示型：今天进了什么好肉/这个部位为什么好吃/30秒展示一道菜从生到熟
   - 顾客故事型：老顾客为什么吃了3年/今天有个小朋友说了一句话让我想了很久
   - 幕后真实型：凌晨4点去市场选肉/后厨最脏的角落/关店后我们在干嘛
   - 避坑指南型：怎么判断肉新不新鲜/理发店这个服务其实不用加钱
3. **手机拍摄实操**（60min）：
   - 固定机位+免提收音=零基础能出片
   - 三段式拍法：全景看环境→中景看动作→特写看细节（肉在烤盘上滋滋冒油）
   - 声音比画面重要：环境音+说话声，不用BGM也不怕
4. **POI定位与同城标签**（30min）：发视频必须带店铺定位、带同城标签、带#城市名+品类名

### 调用的知识笔记
- ⚠️ **知识库空白**：本地生活内容无专项笔记。以上内容基于柯哥8年代运营实战经验推导，需柯哥审校和补充。
- `拍摄_帮观众在想象中购物` — 间接可用：展示使用场景
- `声音是视频创作的第一位` — 音频优先
- `剪辑_视频生产五步流程` — 写文案→录音频→剪气口→标记→BGM→插素材
- `剪辑_声音骨架画面填空BGM起承转合` — BGM使用

### 学员课后能做到
用手机独立拍出一条60秒本地生活短视频（产品展示型），带定位发到抖音

## 第6次课：留资转化——从刷到到到店（3小时）

### 核心内容
1. **获客的进化**（30min）：从坐商（等人来）→行商（打广告）→关系（朋友圈）→算法（抖音推荐）。现在客户不等你，是算法把内容推给附近的人
2. **成交长链路**（30min）：刷到→记住→搜索→比较→观察→到店→下单→复购。每一条视频在扮演什么角色？
3. **五种内容角色设计**（45min）：
   - 拉新内容：让附近的人第一次刷到你（展示食材/环境/氛围）
   - 搜索内容：让搜"XX区烤肉"的人找到你（POI+关键词+定位）
   - 信任内容：降低怀疑（你的肉从哪来/你怎么对待差评/后厨长什么样）
   - 比较内容：跟同行拉开差距（"别家都在用冻肉，我告诉你为什么贵20块"）
   - 成交内容：临门一脚（"这个套餐这周只卖50份""评论区前10位到店送一份牛舌"）
4. **留资三件套**（45min）：
   - 评论区引导："想来的评论区扣1，我私信你定位"
   - 主页装修：头像+简介必须说清楚三件事（你是谁/在哪/怎么联系你）
   - 私信自动回复+团购链接：挂抖音团购/评论区置顶门店地址
5. **一条视频的三步自检**（30min）：
   - 观众看完知道店在哪吗？
   - 观众看完有理由来找你吗？
   - 观众看完知道怎么找你吗？

### 调用的知识笔记
- `短视频_安先生技法全集-柯哥适配版` — 获客四阶段进化论、成交长链路化、五种内容角色、前置投流化
- `文案_互动评论设计原则` — 评论引导公式
- `思考方式_信任感是一切变现的前提` — 信任前置
- `文案_文案的核心功能是引导行为` — 引导到店是最终目标
- `变现_变现三种基本模式` — 变现框架（MOC引用）
- ⚠️ **知识库空白**：留资转化专项笔记很少。现有多为变现认知层，缺少"实操层面"的留资SOP——如评论话术模板、私信自动回复模板、团购详情页写法、到店转化率追踪。

### 学员课后能做到
拍出一条"成交内容"级别的短视频，评论区有明确的留资引导路径

## 第7次课：复盘框架 + 独立运营SOP（3小时）

### 核心内容
1. **数据不是评判是反馈**（20min）：数据差=内容没打到用户，不是你不行。科学家心态。
2. **三维诊断复盘法**（45min）：
   - 传播分（播放量）低 → 选题没打中需求，换选题方向
   - 效果分（停留时长）低 → 内容深度不够或开头不行，检查开头钩子+信息密度
   - 互动分（评论/点赞/转发）低 → 表达方式没引发共鸣，检查有没有"让人想说点什么"的钩子
3. **复盘实操**（45min）：现场拿学员这周发过的视频，逐条走三维诊断
4. **每周运营SOP**（30min）：
   - 每周日用30分钟跑五大热点渠道找选题
   - 每周一写好本周5条文案
   - 每天固定时间拍+发（建议下午4点前）
   - 发布后24小时内回复每一条评论
5. **70分原则**（20min）：不纠结完美，两条视频之间的差别远小于零条和一条之间的差别。发出去就是赢。
6. **课后交接**（20min）：给学员一张"独立运营检查表"——发视频前7项检查+发视频后3项复盘+每周1次大盘检查

### 调用的知识笔记
- `数据诊断三维复盘法` — 传播分/效果分/互动分
- `传播分效果分互动分三维诊断` — 源头笔记
- `数据是反馈不是评判` — 科学心态
- `思考方式_行动优先70分原则` — 不纠结
- `选题_热点选题五大渠道SOP` — 每周30分钟找选题
- `思考方式_文案学习没有公式只有练习` — 长期练习心态

### 学员课后能做到
独立完成一条视频的发布→复盘→优化完整循环，不需要再找人代做

## 课程节奏总览

```
第1次 → 定位（我是谁、给谁看）
第2次 → 人设（观众凭什么记住我）
第3次 → 选题（我接下来30天拍什么）
第4次 → 文案（怎么写才让人看完）
第5次 → 本地生活（怎么拍才有到店）
第6次 → 留资（怎么让人来找我）
第7次 → 复盘（怎么越做越好）
```

**设计逻辑**：前四次解决"做出能看的内容"，后三次解决"做出有结果的内容"。不按知识体系分类，按学员能独立作业的顺序排列。
