### 2. 文案缺骨架的根因：规则密度超过单次注意力预算
不是模型笨，是 250 行 SOUL + 220 行 AGENTS + 十几条 MEMORY 永久规则同时竞争注意力窗口，"先画逻辑线→再画情绪曲线"排在边缘掉了。换任何模型都有上限。**解法不是"下次注意"，是工程级触发。** 柯哥在想的向量搜索扩展方向对——但解决的是召回，不是触发。

### 3. 实体店老板被割三坑 = 一个系列内容池
探店收割 / 假数据代运营 / 本地名人话术——底层同一个病：老板向外求而非向内求。Claude 点出的陷阱：容易滑到抱怨流。顾问立场的差别：不是"这些都是骗子"，是"你以为是买 X，实际是买 Y"——给观众一把刀自己切。

### 4. 柯哥自己就是内容
"工作流比天赋重要"这条灵感，柯哥自己就是最佳案例——OpenClaw 的每一次迭代、每一次小龙犯傻、每一次修 Skill，都是选题。**账号的隐藏优势：讲的是"我自己怎么做的"，不是"你应该怎么做"。**
