# 柯建军新媒体课程体系 · 五边形框架

## 核心理念

以**自媒体心法**为核心，向外辐射五边形技能系统：定位、文案、拍摄、剪辑、复盘。

模块化设计——每个角独立可迭代，像特斯拉电池组，哪里更新换哪里。

---

## 一、课程总览

```
                    定 位
                   /     \
           复 盘           文 案
           |   自媒体心法    |
           剪 辑           拍 摄
                   \     /
```

| 产品 | 定位 | 内容 |
|------|------|------|
| 399试听课 | 认知打开 | 从五边形选一个角切入，让人想上正课 |
| 599试听课 | 实操体验 | 带一个具体交付物，听完就能用 |
| 4980正课 | 系统掌握 | 心法打底 + 五边形逐个击破 + 变现实战 + 三层诊断 |
| 迪派入门系统课 | 16节入门 | 心法3节 + 五边形10节 + 实战串联3节 |
