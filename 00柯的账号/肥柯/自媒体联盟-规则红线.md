# 自媒体联盟 · 规则红线 v0.1

> ⚠️ 联盟免费，不代表没规矩。以下红线，碰一条走人，没警告、没商量。

---

## 一、名称使用规范

| 禁止 | 说明 |
|------|------|
| ❌ 未经柯哥书面同意，不得以"柯哥团队""柯哥合伙人""柯哥弟子"名义对外接单 | 你是联盟成员，不是柯哥代理人 |
| ❌ 不得在个人账号简介写"柯建军团队""柯哥工作室" | 除非柯哥单独授权 |
| ✅ 可以说"自媒体联盟成员""柯哥的联盟" | 你在联盟里，不是代表联盟 |

**为什么这么严**：一个人打着柯哥名头接了个烂单，客户发一条"柯建军团队骗人"，你的4980课程、代运营口碑全跟着遭殃。一个人烂，全体买单。

---

## 二、代运营交付标准

| 标准 | 要求 |
|------|------|
| 必须通过考核 | 未过考核不能接交付，只能卖单 |
| 考核内容 | 独立完成定位→脚本→拍摄→剪辑→复盘全流程，柯哥审批 |
| 交付流程 | 签合同→出方案→每周复盘→交付验收 |
| 质量问题 | 客户投诉→柯哥介入→核实后，第一次警告，第二次取消接单资格 |

**未过考核的成员接了代运营怎么办**：
- 他不知道规则 → 补课
- 知道了还接 → 直接走人

---

## 三、定价规范

| 规则 | 说明 |
|------|------|
| 代运营价格不得低于联盟指导价 | 防止恶意压价搞乱市场 |
| 不得以"柯哥亲自带""柯哥操盘"为理由加价 | 你卖的是你的服务，不是柯哥的 |
| 课程价格统一 | 4980，任何人不得打折 |

**为什么定价要控**：一个人报2000块做代运营，别人3000就接不了。整个市场的价格底线被拖垮。最后大家都没钱赚。

---

## 四、客户归属

| 场景 | 规则 |
|------|------|
| 成员自己开发的客户 | 归成员 |
| 联盟分配的客户线索 | 谁成交归谁，但必须能交付 |
| 成员离开联盟后 | 已成交客户归成员，未成交线索留在联盟 |
| 成员被踢出后 | 正在服务的客户 → 联盟安排其他人接手，收入归接手人 |

---

## 五、竞业与品控

| 禁止 | 说明 |
|------|------|
| ❌ 用联盟客户资源私下接活 | 客户资源是联盟的。绕过联盟接私单 = 偷 |
| ❌ 在联盟内部挖成员客户 | 成员之间不是竞争关系 |
| ❌ 诋毁联盟或柯哥 | 你有意见可以直接找柯哥说，公开发牢骚不行 |
| ❌ 卖假课/盗版课 | 碰了直接走人 |
| ❌ 借用联盟案例冒充自己的 | 不是你交付的活，不能挂你名下 |

## 六、退出与踢出

**自动退出**：
- 连续7天未日更 → 移除联盟群和权限
- 可重新申请，重新走新人流程

**主动退出**：
- 跟柯哥说一声即可
- 正在交付的代运营项目 → 交接完再走，不能撂挑子

**被踢出（永久，不能重新加入）**：
- 触犯名称规范（冒充柯哥团队）
- 触犯竞业（挖客户、私单）
- 触犯定价（恶意压价）
- 质量事故（代运营交付严重失职，造成客户损失）
