### 第五轮：深度诊断

**柯哥质问**：
> 就是你写的很乱套，我不知道是什么原因？

**小龙的诊断过程**：
1. 重新读了冉总语言风格指南
2. 对比了跑通的冉总稿子（Hanako写的"12-同一天两拨人"和"00活没干钱先到了"）

**发现的根因**：

| 维度 | 跑通的稿子（Hanako） | 小龙写的 |
|------|-------------------|---------|
| 句子结构 | 一行一个意思 | 一句话装三个信息 |
| 例 | "第一拨。苏州来的。一个女生。" | "教什么？擦玻璃、油烟机清洗...不是随便找个人上去讲两句" |
| 逻辑连接 | 事实→事实→事实→停 | 事实→提问→回答→扣题总结 |
| 收尾 | "开始有人看了。"停。 | "不是来找你说段子，是来做事的。"（扣题回马枪） |

**小龙总结的三个核心问题**：

1. **帮观众提问** — "妇联为什么找我们？""这个单子怎么来的？" — 冉总不说，直接给答案
2. **帮观众总结** — "这才是妇联找一冉的原因" — 冉总说完就停，不扣题
3. **描写观众看得见的东西** — "此时此刻我站在楼下抬头看" — 画面拍着呢，不用解说

**语法差异**：
- 冉总：每句话一行。"听完。签了。"
- 小龙：压缩成段落。"听完就直接签了，很干脆。"

## 小龙的错误模式总结

**默认写作模式**：撰稿人模式
```
开场铺垫 → 提一个问题 → 自己回答 → 分点展开 → 解释为什么 → 最后扣题总结
```

**应该用的模式**：冉总说话模式
```
事实 → 事实 → 事实 → 停
```

**具体禁止项（写冉总稿前的检查清单）**：
- 禁止自问自答（"为什么？""怎么来的？"）
- 禁止扣题总结（"这才是...的原因""不是...是..."）
- 禁止描写可见画面（"抬头看""站在楼下"）
- 禁止"此时此刻"后面接长句铺垫
- 禁止一句话装三个信息——拆成三个短句
- 禁止过渡词（"接下来怎么干""为什么要先给""那有人说"）
