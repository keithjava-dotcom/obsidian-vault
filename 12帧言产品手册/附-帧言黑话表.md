# 帧言黑话表

> 看手册时碰到不懂的词，来这查。用大白话解释。
> 回总纲：[[00-产品总纲]]

---

## 产品/技术词

| 词 | 大白话 |
|----|--------|
| **PRD** | 产品需求文档，就是"产品经理的书"，讲清产品是什么、怎么做 |
| **前端 / 界面层** | 用户看到、点的那层 |
| **后端 / BFF** | 幕后干活的服务器程序，用户看不见 |
| **数据库** | 存所有用户资料/内容的地方 |
| **上云 / 公网** | 把程序放到互联网上，让全世界打得开（现在只在你电脑本地） |
| **Capacitor** | 把网页"套壳"变成苹果/安卓 App 的工具 |
| **PWA** | 能"加到手机桌面"当 App 用的网页 |
| **React / TypeScript** | 写界面用的主流编程语言 |
| **Taro / uni-app** | 能同时出 App 和小程序的框架（帧言现在没用，上小程序才需要） |

## AI 相关

| 词 | 大白话 |
|----|--------|
| **大模型 / LLM** | 会"思考"的 AI（DeepSeek、GPT、Claude 都是） |
| **DeepSeek** | 国产大模型，便宜、中文好，帧言默认用它 |
| **离线模式** | AI 没接真的、在"练手"，回答不够聪明（现在的状态） |
| **Provider（供应商）** | AI 的来源，帧言设计成能随时换 |

## 帧言业务词

| 词 | 大白话 |
|----|--------|
| **数字柯建军 / 小龙** | 帧言里那个 AI 分身，用你的方法论帮用户干活 |
| **技能 / SKILL** | 你的一套方法论，比如"出选题""写文案"。共 34 个 |
| **技能柜 / Marketplace** | 陈列所有技能的地方，用户挑着用 |
| **五棒流水线** | 做内容的五步接力：选题→大纲→范文→分镜→复盘 |
| **交接卡 / Handoff** | 一棒传下一棒时的"工作交接单"，带内核和禁区 |
| **Fork / 复制技能** | 把一个技能复制到自己柜子里，改成贴合自己的版本 |
| **Paywall / 付费墙** | 免费用户用超了，弹出来的"升级付费"提示 |
| **Tier / 分级** | Free（免费）/ Pro（订阅）/ 企业版 三档 |
| **筛子理论** | 你的方法论：内容是筛子，筛中对的人、赶走错的人 |
| **最后一根稻草** | 你的方法论：逼用户交代具体时间地点原话，防写成空话 |
| **含金量六闸** | 你的方法论：内容质量的六道关卡 |
| **画像外扩** | 你的方法论：把目标用户画像往外拓宽 |
