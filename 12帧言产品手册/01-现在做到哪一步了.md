# 现在做到哪一步了

> 诚实盘点，不粉饰。🟢=能跑、真做了 🟡=半成品/是假的 🔴=还没做。
> 回总纲：[[00-产品总纲]]

---

## 🟢 已经能跑的（我亲手点过）

| 功能 | 实测结果 |
|------|---------|
| **注册 / 登录 / 记住账号** | 真的存到后端了，刷新页面不丢，换浏览器能登回来 |
| **技能柜（32 个技能）** | 你的 34 个方法论迁进去了，能搜索、筛选、看详情 |
| **跟"数字柯建军"做选题** | 走完整套：筛子理论追问 → 最后一根稻草 → 强制补料防瞎猜 → 15 角度矩阵 → 交接卡"待柯哥拍板"。**这是核心，跑通了** |
| **五棒接力** | 选题→大纲→范文→分镜→复盘，能一棒传一棒，交接卡带"禁区"提示 |
| **复制技能到自己的柜子（Fork）** | Pro 用户能把技能复制走改成自己的 |
| **付费墙** | 免费用户试用 3 次后，弹"升级 Pro"，真的会拦住 |
| **界面（宋雅色卡）** | 全站视觉过关，字看得见（登录页、访谈页的隐身字都修好了） |
| **iOS 打包配置** | 应用名"帧言"、包名都设好了，离上架就差账号和图标 |
| **抗意外** | 刷新不丢数据、多个标签页开着不打架、崩溃有兜底不白屏 |

## 🟡 半成品 / 现在是"假"的（这几条最关键）

| 功能 | 现状 | 说明 |
|------|------|------|
| **AI 的聪明程度** | 🟡 现在跑"离线本地模式" | 五棒流程是**规则引擎**在跑（照你的方法论走流程，可靠）；但"自由聊天时 AI 有多懂你"取决于有没有接真大模型——**接口接好了，默认没开真的**。这是上线前第一件事 |
| **支付** | 🟡 假的 | 点"升级"走的是模拟流程，没接真微信/支付宝/苹果内购。收不到钱 |
| **后端** | 🟡 只在你电脑本地跑 | 数据存成本地文件，没上公网、没用正经数据库。**别人现在打不开** |

> ⚠️ **这三条是"能演示"和"能卖钱"之间的差距。** 现在是一台精致的样机，能给人看、能自己玩，但还不能开门营业。
