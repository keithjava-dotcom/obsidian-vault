> 这是一份"产品经理的书"（业内叫 PRD / 产品需求文档）。

## 一句话讲清帧言

**帧言 = 一个让新媒体讲师和学员"随时跟数字柯建军聊天做内容"的短视频创作 APP。**

用户打开 APP，跟里面的 AI 聊天，就像跟你本人聊天一样——你把 34 个文字方法论（SKILL）调教进系统，系统就用你的脑子帮学员出选题、写稿、复盘。

> 🗺️ **但这只是核心。** 你在 kiro 里写的完整愿景更大：帧言是创作者的**完整成长平台**——记灵感→变脚本→教拍摄→看成长→接操盘手→买书课设备。完整版图见 [[10-完整产品全景]]。

## 为什么做（产品定位）

| 维度        | 说明                                                           |
| --------- | ------------------------------------------------------------ |
| **给谁用**   | ①你的 4980 线上课学员 ②想做内容但没方法的新媒体人 ③未来：企业内容团队                     |
| **解决什么**  | 学员上完课，回去还是不会做——因为方法在脑子里、执行没人盯。帧言把你的方法论变成"会追问、会拦你瞎搞"的贴身教练     |
| **凭什么是你** | 别人做的是通用 AI，帧言里跑的是**柯建军的判断**：画像外扩、痛点要痛、最后一根稻草、含金量六闸——这些是你的护城河 |
| **怎么赚钱**  | 4980 线上课引流 → APP 订阅变现（Free 试用 / Pro 订阅 / 企业版），目标上 App Store  |

## 北极星（衡量成不成的唯一指标）

**"学员用帧言真的产出了能发的稿子，并且愿意持续用。"**

不是下载量、不是注册数——是**真产出 + 留存**。一切功能围绕这个。

<font color="#9bbb59">柯：北极星是什么意思？</font>

> 📖 **答**：北极星 = 航海时靠北极星辨方向。产品里指"衡量成不成的那**唯一一个**核心指标"。定一个北极星，是为了不被一堆虚荣数字（下载量、注册数）带偏——只要这个指标涨，产品就是真的好。帧言的北极星 =「真产出 + 留存」。
