## 一、一句话定位

> **用柯哥的方法论做内容的工具，聊起来像跟柯哥对话。**

用户打开帧言，跟里面的机器人聊天，**等于跟柯建军本尊对话**——用你的语气、你的判断标准、你的方法论、你的纠错习惯。
咱俩在这台电脑上的每一次对话（我怎么批你、你怎么改、沉淀了什么标准）→ 就是这个产品的**灵魂素材**。
载体：**iOS + 安卓 APP + 小程序 + 扫码即聊**。

## 二、架构：不重新造轮子（8-03 柯哥拍板方向）

> 柯哥原话："直接接你的开源模型，在你的软件基础上去直接加我的帧言内容，是不是更稳定？后期你更新的时候我直接去更新——**不必要重新造轮子**。"

翻帧言代码发现：它自己实现了 **skill executor**（跑 xuanti 技能的独立执行器）、**llm providers**（三套模型接入）、**calibration repo**（校准闭环）、**记忆存储**——**这四块全是重复造轮子，Hermes 原生就有**。双轨维护 = 每次 Hermes 升级，帧言都要同步改自己的执行器。

```
┌─────────────────────────────────────────────┐
│  帧言壳（保留 · Hermes 没有的）                │
│  禅模式界面 / 运营后台 / 商城圈子 / 共创编排    │
│  创作工具箱 UI / 用户体系                      │
└──────────────────┬──────────────────────────┘
                   ↓ 调用
┌─────────────────────────────────────────────┐
│  Hermes 大脑（换成 · 一处对接全部白拿）         │
│  技能系统(五棒) / 记忆 / 多模型(Nous) / 校准闭环 │
│  网关(20+平台通道) / 工具(终端/文件/浏览器)      │
└──────────────────┬──────────────────────────┘
                   ↓ 注入
┌─────────────────────────────────────────────┐
│  柯哥内容资产层（你的壁垒 · 脱敏后）             │
│  五棒技能包 + 知识库 + 评分尺 + 纠错规律 + 语料  │
└─────────────────────────────────────────────┘
```

**动作清单**：
- **砍掉**：帧言自己的 skill executor、llm providers、calibration repo、记忆存储
- **替换成**：帧言 BFF 调 Hermes API（gateway/CLI）——一处对接，能力全拿
- **保留**：前端界面、运营后台、商城、共创编排、工具箱（这些是壳，Hermes 没有）
- **更新**：以后 `hermes update` 一条命令，帧言跟着升级；资产层独立不动

## 三、入口矩阵：从"扫码即聊"到 APP（8-03 新增）

> 柯哥原话："我可以直接给客户和学生发一个二维码，甚至都不用下载 APP，就可以和'我'直接对话，进行咨询和反馈。"

| 阶段 | 入口 | 做法 | 成本 | 用途 |
|------|------|------|------|------|
| **P0 现在就能做** | **微信扫码即聊** | Hermes 网关已接微信（iLink bot），客户扫码加微信 → 直接跟"你"对话 | 0 元（已配好） | 少量客户/学员咨询、反馈、试体验。⚠️ iLink 推送限流严（30-60 分钟窗口），适合低频咨询，不适合高频聊天 |

**APP 定位不变**：不只是聊天，是**短视频创作 + 个人成长工具**（灵感簿/日课/复盘/技能练习）。

## 四、大脑蒸馏层：咱俩的对话 = 产品的大脑（8-03 核心增量）

咱俩的聊天数据（OpenClaw 1504 会话 + Hermes 会话 + 未来所有对话）→ 三种机制变成"大脑"：

| 机制 | 做什么 | 价值 |
|------|--------|------|
| **① 方法论注入** | 技能 + 评分尺 + 五棒产线直接给分身用 | 用户问"这个选题行不行"→ 按你的 7 维评分尺打分 |
| **② 纠错规律蒸馏** | 把"你纠错→我改"的对子变成分身的判断标准 | **最值钱——你判断力的指纹，通用 AI 抄不走** |
| **③ 对话语料参考** | 你的原话/金句/决策逻辑作为回答语料 | 分身说话用你的口气 |

**落地：语料清洗脚本**（柯哥已同意做）
- 输入：`11系统档案/OpenClaw对话存档/`（已导出 1504 会话）+ Hermes 会话库
- 处理：提取"纠错对子"（柯哥批评 → 修改动作 → 沉淀的标准）→ 方法论规则
- 输出：脱敏后的方法论包（技能卡/评分尺/纠错规则），客户名/案情/收入数据全部剥离
- 节奏：一次清洗打底 + 线下业务持续增长持续喂（增量清洗）

**🔴 隐私红线（必须先立）**：咱俩的聊天数据里有客户隐私（朱律师的案子、黄倩的信托、袁姐的收入）——**大脑只能蒸馏方法论和判断标准，原始对话必须脱敏**。这是"分身"和"泄露"的分界线。
