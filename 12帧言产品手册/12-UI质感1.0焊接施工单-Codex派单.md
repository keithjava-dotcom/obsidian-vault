## 二、拆单（4 单，依序派，每单独立验收）

### F-UI-1 · token 地基（先行，半天）

**动的文件**: `src/styles.css` / `tailwind.config.js` / `index.html` / `src/theme/themes.ts`

- styles.css `:root` 全套换成定稿 HTML 里的变量（纸/墨三档/玉青/朱砂/旧金/线两档/影四档/纹理五层 grain・cloud・bamboo・glow・vignette），`[data-theme="dark"]` 竹夜全套照搬
- tailwind.config.js：**删除重复色阶**（vermilion 与 cinnabar 二选一留 cinnabar；gold 与 oldgold 留 gold），色阶锚点对齐新 token
- index.html：`theme-color` 从 #000000 改 #F8F1DC（dark 对应 #13231B）；**移除 Google Fonts CDN**（PingFang/Songti 系统字体已覆盖，国内加载负担清零）
- themes.ts：songya palette 更新为 1.0 终值，dark palette 补竹夜

**验收**: `npm run lint` 绿；全站启动无样式崩坏；grep 确认业务代码零 hardcode 新色值（只许引 token）

### F-UI-2 · 背景质感层（依赖 F-UI-1，半天）

- body 五层背景按定稿顺序：vignette → bamboo → grain → cloud → glow（SVG data-URI **原样照搬定稿文件，一个字符不许"优化"**——feTurbulence 的 `stitchTiles='stitch'` + filter region `x='0' y='0' width='100%' height='100%'` 是防接缝的，动了就有竖缝）
- `[data-finish="matte"]` 哑光覆盖块照搬
- `@media (max-width:640px)` 竹影降级块照搬
- `prefers-reduced-motion` 已有全局关动画，确认覆盖新动效

**验收**: 桌面/375px 双端截图对照定稿；深色模式无白闪

### F-UI-3 · 组件三档 + 印章（依赖 F-UI-1，1 天）

- 按钮统一三档类（对照定稿 .btn-jade/.btn-ink/.btn-red + shadow-rest/lift/press 三态）；**全站现存 CTA 收编**：登录/注册的 gold 主钮、vermilion 渐变钮全部改玉青实底，危险动作改朱砂描边
- 卡片双层影（card-shadow / card-shadow-lift）替换现有 glass-panel 阴影
- 印章组件化 `<FySeal size>`：边栏 ::after、歪 2 度、hover/active、stampIn + sessionStorage 限频；Sidebar 品牌区与 SplashScreen 接入
- **原生 alert/confirm 全站清零**（App.tsx:428,457 等六处）换成设计弹窗——这是宋雅美学最大的破功点

**验收**: lint 绿 + 现有 vitest 全绿；截图五处代表页（登录/首页/灵感/圈子/分销）按钮三档统一

### F-UI-4 · 竹夜夜面首接（依赖 F-UI-2，半天）

- 提词器、拍摄模式两个本来就黑的场景先接竹夜 token（黑底换 #13231B 系）
- 全局昼夜切换开关**本单不做**（放第 5 周后），只留 token 就绪

**验收**: 提词器/拍摄模式截图对照竹夜样张
