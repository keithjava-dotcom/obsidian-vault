## 安先生_营销视频和成交视频必须分开

### 来源

安先生课程/Claude帮我整理的.md 第2节

### 一句话用途

判断一条内容到底负责拉新、种草、成交还是降成本，避免一条视频承担太多功能。

### 核心判断

- 营销视频的任务是扩大认知和制造兴趣，成交视频的任务是降低信任成本和决策成本。
- 同一条视频同时想拉新、教育、成交、证明专业，通常会变成结构散焦。
- 短视频不是只用来涨粉，还能降低成交成本、缩短信任路径、帮销售预热客户。

### 操作动作

- xuanti 先标注本题属于营销型、成交型、信任型还是教育型。
- dagang 只围绕一个功能搭骨架，不让副功能抢主线。
- fanwen 结尾动作必须匹配视频功能：营销型要关注/收藏，成交型要咨询/私信。

### 禁区

- 不要让一条视频既讲认知、又讲故事、又卖课、又做成交证明。
- 不要用成交话术硬收营销型视频。

### 适配 Skill

xuanti / dagang / fanwen / fupan

### 版本

v2.0-candidate · 2026-06-28


## 安先生_价值垂直大于赛道垂直

### 来源

安先生课程/Claude帮我整理的.md 第2节

### 一句话用途

解决账号定位和选题只盯行业标签的问题，让内容围绕同一类人和同一种价值持续打穿。

### 核心判断

- 赛道垂直只是外壳，价值垂直才决定账号是否能沉淀精准信任。
- 同一行业可以服务不同人群，同一价值也可以跨行业迁移。
- 选题不只问属于哪个行业，还要问给谁解决了什么具体问题。

### 操作动作

- dingwei 把账号价值写成“帮谁从什么状态到什么状态”。
- xuanti 按价值主线筛选题，不只按行业关键词筛选。
- 复盘时看评论区是否围绕同一类价值需求，而不是只看播放量。

### 禁区

- 不要把行业垂直误当成内容垂直。
- 不要为了追热点破坏账号价值主线。

### 适配 Skill

dingwei / xuanti / account-calibration

### 版本

v2.0-candidate · 2026-06-28


## 安先生_A1-A5人心结构

### 来源

安先生课程/Claude帮我整理的.md 第2节

### 一句话用途

把用户从陌生到成交拆成阶段，决定内容应该先唤醒、再信任、再行动。

### 核心判断

- 不同阶段用户的问题不同：不知道你、不信你、不急、不懂怎么做、临门一脚都不是同一个问题。
- 内容要匹配用户心智阶段，而不是出镜人想到哪讲哪。
- 高客/企业主账号尤其不能跳过信任和风险解除。

### 操作动作

- xuanti 给每个选题标 A1-A5 阶段。
- dagang 根据阶段安排开头冲突、证据密度和商业动作。
- fanwen 只保留对当前阶段有推动力的信息。

### 禁区

- 不要对 A1 陌生用户直接做强成交。
- 不要对 A4/A5 成熟用户继续科普基础常识。

### 适配 Skill

xuanti / dagang / fanwen / fupan

### 版本

v2.0-candidate · 2026-06-28


## 安先生_定位是决策不是想清楚

### 来源

安先生课程/Claude帮我整理的.md 第4节

### 一句话用途

防止定位阶段无限分析，逼系统把定位落成取舍和行动。

### 核心判断

- 定位不是一次想清楚，而是先做决策，再在内容反馈中变清晰。
- 定位的价值在于决定放弃什么，不是把所有优势都写进去。
- 账号定位要能落到选题和表达方式，否则只是描述，不是定位。

### 操作动作

- dingwei 输出必须包含“保留/放弃/暂不做”的取舍。
- xuanti 对不符合定位的高热题标记为不做或后置。
- account-calibration 用连续作品表现回校定位，而不是每条都重开定位。

### 禁区

- 不要把定位写成履历大全。
- 不要等完全确定后才开始内容生产。

### 适配 Skill

dingwei / xuanti / account-calibration

### 版本

v2.0-candidate · 2026-06-28


## 安先生_骨架六种推进是大纲动力源

### 来源

安先生课程/第20节(骨架·6种推进)主流程升级+注解层补丁 · 2026-06-07.md

### 一句话用途

给 dagang 和 fanwen 判断一条稿为什么往前走，避免流水账和观点平铺。

### 核心判断

- 短视频不是把信息排出来，而是让观众被一个动力推着往下看。
- 过程、对抗、递进、反转、拆解、证明等推进方式要先定，再写逐字稿。
- fanwen 改文案时不能破坏 dagang 已定的骨架动力。

### 操作动作

- dagang 先标骨架动力类型，再输出结构。
- fanwen 若改结构，必须说明是否改变骨架动力。
- 复盘低完播时先检查动力断点，而不是只改开头句子。

### 禁区

- 不要把骨架理解成小标题列表。
- 不要为了文采牺牲推进动力。

### 适配 Skill

dagang / fanwen / fupan

### 版本

v2.0-candidate · 2026-06-28
