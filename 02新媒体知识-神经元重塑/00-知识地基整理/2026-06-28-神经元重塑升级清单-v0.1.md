## 神经元 2.0 标准

每张正式知识卡后续统一为：

```md
# 知识卡名称

## 来源
老师 / 课程 / 源文件 / 时间

## 一句话用途
这张卡在生产中解决什么问题

## 核心判断
真正能指导决策的 3-7 条

## 操作动作
遇到什么情况，应该怎么做

## 禁区
不能怎么用，容易误用在哪里

## 适配 Skill
定位 / 选题 / 大纲 / 文案 / 拍摄 / 复盘 / 作业点评

## 实战验证
来自哪个真实客户、哪条稿、哪次反馈

## 版本
v1.0 / v2.0 / 更新时间
```
