# 真实感来自实话实说和口语语境

消费者普遍戒备商家话术，所以真实感本身就是竞争力。舒老师把真实分成两种：一是实话实说，敢展示小缺憾；二是真实语境，用口语化、反商业的表达，让用户感觉像在听一个人说话。

真实不是粗糙，而是降低套路感。越像标准商业话术，越容易让用户防备；越像一个具体的人在说真话，越容易建立信任。

## 操作动作

- 可以主动承认小缺憾，换长期信任。
- 把商业套话改成口语表达。
- 用具体人话替代“平台、赋能、一站式”等抽象词。
- 让 IP 的表达保留人味。

## 禁区

- 不要把真实写成卖惨。
- 不要用诚实包装低质量。
- 不要为了高级而牺牲可听懂。

## 适配 Skill

- fanwen：逐字稿要保留出镜人的真实说话感。
- dingwei：判断 IP 可信度资产。
