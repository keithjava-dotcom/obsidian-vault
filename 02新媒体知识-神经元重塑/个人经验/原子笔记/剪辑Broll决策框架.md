# 剪辑经验沉淀：置顶视频执行指令

## 一、B-roll决策框架（可复用）

### 核心原则：口播听一遍不懂的，才加画面

```
拿到逐字稿 → 逐句问两个问题：
  Q1: 观众只听一遍，能懂这句话吗？
  ├─ 能 → 留脸（情绪、态度、反问、有画面感的口述）
  └─ 不能 → 加B-roll
        ├─ 抽象关系 → 图形动画（公式、逻辑）
        ├─ 流程步骤 → 分步演示（搜索法、时间线）
        ├─ 数据堆叠 → 卡片展示（案例数字）
        └─ 行业名词 → 分屏/标签
```

### 6种不加画面的情况

| 情况 | 为什么不加 | 例子 |
|------|-----------|------|
| 情绪爆发 | 脸比画面有力 | "我怕人笑话" |
| 态度声明 | 语气就是画面 | "没意思""隔路" |
| 反问句 | 眼神比动画狠 | "凭什么教你" |
| 口播自带画面感 | 观众脑子里有 | "千万播放" |
| 情绪拐点 | 任何东西挡脸都削弱 | "懒"+"但是"反转 |
| 结尾收情绪 | 留脸=留信任 | "这就是我" |

### 执行口诀
> 不懂才解释，情绪全靠脸。数据要看见，流程要跟手。

## 二、Keynote视觉模式库（已验证可用）

### 模式1：公式可视化 ⭐
**适用**：两个概念产生第三个概念的关系。
**做法**：两圆→向中间靠拢重叠→重叠区出结果。
**实例**：用户心理 + 平台规则 = 可复制公式。
**关键**：Magic Move过渡，0.5s。唯一带"动画感"的，因为解释的是抽象逻辑。

### 模式2：搜索/流程分步演示 ⭐
**适用**：观众需要"跟着做"的操作步骤。
**做法**：4张片子串流程，每张3-4秒，Magic Move过渡。
**实例**：搜索框→输入关键词→结果列表→箭头指向结论。
**关键**：不跳步。让观众感觉自己也在操作。

### 模式3：案例数据卡 ⭐⭐
**适用**：多个案例多个数字，耳朵记不住。
**做法**：一张片子，三张卡片逐卡飞入，间隔2秒。白底黑字，数字用红色/黄色高亮。
**实例**：医美（3个月起号）+ 科技招商（400万）+ 家政（130条/周）
**关键**：无装饰，数字是主角。

### 模式4：时间线轴
**适用**：有时间关系的产品/交付/过程。
**做法**：一条横轴，三个圆点+文字构件依次出现。
**实例**：0月●→3个月●→12个月●，每个节点有简短说明。
**关键**：线要细，点要有呼吸感。底部一行字概括。

## 三、BGM情绪设计法（可复用）

**原则**：一首到底，不换歌。用音量控制情绪，而不是换歌。

| 情绪 | 音量处理 | 时机 |
|------|---------|------|
| 开场 | 极简，单音 | 让观众听清第一句话 |
| 态度输出 | 渐起+轻鼓点 | 有力量但不抢戏 |
| 干货输出 | 微推，节奏微快 | 配合信息密度上升 |
| 情感拐点 | **转暖** | 从数据切换到情感 |
| 反转 | 微收 | 让观众听清反转句 |
| 结尾 | 音乐落，留白 | 直视镜头，3秒余韵 |

**推荐方向**：坂本龙一/Einaudi纯钢琴。有起承转合、有温度、不抢戏。

## 四、精剪方法论

**发现信息密度问题时，砍三个地方：**
1. 合并同类项——同类表达只留一个
2. 紧缩案例——案例罗列时加速语速或合并表述
3. 砍口语重复和多余停顿

**判断标准**：2:30是个舒适线。超过3分钟必须自查是否拖了。

---

## 五、封面设计模式

**知识类IP封面**：深灰/黑底 + 白色粗体大字 + 一个颜色锚点。
**钩子公式**：反常识对比。如"200粉丝 | 凭什么教你？"
**锚点色**：只用一种（红/橙），只在高亮字上。
**字体**：无衬线加粗，不加花里胡哨。

---

## 六、发布文案公式

```
视频描述 = Hook（反常识对比）
         + 履历（专挑难的）
         + 方法论标签（用户心理+平台规则）
         + 价值提炼（可复制）
         + 态度金句（不卖焦虑不吹牛逼）
         + 谁适合（有生意有产品行业正规）
         + 承诺（帮你做乘法）
```

**评论区置顶**：一个不需要观众动脑的问题——"你做什么行业？"
