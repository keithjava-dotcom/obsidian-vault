# 知识类IP封面设计 · 图形锚点 + 主题色体系

## 核心公式

```
深色/纯色背景 + 一行主题字 + 一个主题图形 = 知识类IP封面
```

封面不是说明书，是钩子。信息越克制，越有专业感。

---

## 两大核心技巧

### 一、图形锚点：用图形把抽象概念变具象

每个封面放一个**能代表本期主题的图形**，让用户扫一眼就知道方向。不是装饰，是视觉锚点。

| 视频主题 | 可以用的图形 | 原理 |
|----------|-------------|------|
| 企业传承 | 家族树形图 | "传承=树"，直观 |
| 腰痛科普 | 简笔骨盆图 | 靶向身体部位 |
| 品牌信任 | 公鸡/盾牌 | "可靠"的符号 |
| 破局/突破 | 鸡蛋 | 破壳=突破 |
| 增长策略 | 上山箭头 | 上升趋势 |
| 视频制作 | 播放按钮/问号 | 直接关联主题 |

**选图原则**：选了之后问自己——不读文字，光看这个图形，观众能猜到这期聊什么吗？猜不到就换一个。

### 二、主题色体系：按内容类型固定配色

同一类内容固定一个色系，观众扫封面颜色就知道今天是什么类型。

| 内容类型 | 推荐色系 |
|----------|---------|
| 方法论/干货 | 暖橙、明黄 |
| 行业解读/深度 | 深蓝、墨绿 |
| 案例拆解 | 森林绿、深棕 |
| 观点/洞察 | 亮黄、橙红 |

> 肥柯可以分三类：**行业解读**→深蓝、**方法论**→暖橙、**案例拆解**→深绿。观众看颜色就知道今天吃什么菜。

---

## 信息层级（从封面到列表页的统一感）

单张封面看简洁，列表页看品牌感。每张封面的信息层级保持一致：

```
主标题（大字，核心价值）
    ↓
副标题/补充（小字，可选）
    ↓
一个图形元素（居中或偏下）
```

**不堆的东西**：痛点词、反问句、花字特效、多个图形——这些会让封面从"知识IP"变成"营销号"。

---

## PPT手作的附加价值

用PPT/Keynote做封面，不用AE、不做复杂合成：
- **钝感 = 人感**：观众潜意识知道这不是AI流水线内容
- **瑕疵感 = 真实感**：小细节的不完美反而证明背后是真人
- **低成本迭代**：一期换一个图形，10分钟搞定，不用依赖设计师
