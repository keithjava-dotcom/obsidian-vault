# 短视频骨架三段论

开头抓人，中间留人，结尾升华。

**开头：制造一个让人停下来的理由**
不是悬念钩子，是反常识的行动或细节。
观众要觉得"这个角度我没想过"。

**中间：每100字给观众一个继续看的理由**
四种驱动力：好奇 / 揭秘 / 情节推动 / 冲突
每隔一段问自己：看到这里的观众，为什么要看下一段？
答不上来，就是断点，必须修。

**结尾：三选一**
- 升华：把故事拉到更大的意义
- 互动引导：让观众有话说
- 点题总结：把核心情绪再钉一遍
