# 短视频文案四大通用技法

> 来源：Gemini 冉总稿子两轮对比 + 柯哥点评提炼
> 适用：跨 IP 通用，根据 IP 类型调节强度

## 技法一：攻击性开头

不用场景铺垫，第一帧怼脸。

| IP 类型 | 用法 | 示例 |
|---------|------|------|
| 直接攻击型（冉总、黑叔） | 全力 | 「家政淡季？那是你根本没接过大活」 |
| 温和通透型（菲菲） | 降级 | 降级为「反常识开头」：第一帧给一个没想到的角度，不打脸 |

**检查标准：** 开头前三秒，观众是被挑衅了还是被邀请了？攻击型 IP 用前者。

## 技法二：触觉化描写

不写抽象形容词。写观众能摸到、闻到、看到的具体物。

| ❌ | ✅ |
|----|-----|
| 烟道在漏油 | 黑油顺着缝隙往下滴 |
| 后厨很脏 | 厚油垢在灯光下反着恶心的光 |
| 施工难度大 | 上楼顶得从隔壁翻窗户出去 |
| 没有服务端 | 没有沾过油的手 |

**适用：** 所有 IP，是通用写作标准，不限于攻击型内容。

## 技法三：二元对立

不写「我们不一样」。写具体的对立面。

| ❌ | ✅ |
|----|-----|
| 我们有服务端，别人没有 | 别人只有招商PPT，我们有沾过油的手 |
| 我们不骗人 | 收完加盟费消失的是割韭菜，带你下泥潭的是领路人 |
| 我们专业 | 他连你行业都没研究过 |

观众记忆两条对比远强于记住一条陈述。对立的画面感越强，记忆越深。

**适用：** 需要攻击性差异化的 IP（冉总、黑叔）。菲菲类 IP 降级为「区别」而非「对立」。

## 技法四：结论砸死

不摆事实让观众自己判断。直接替观众下结论。

句式：「这就是……」「那就叫……」「说白了就是……」「你看到的，就是……」

**适用：** 立人设和防坑指南类内容。不适用于客户案例类——案例要让故事自己说话，结论留给观众。

## 写稿后自检

每篇稿子写完，过这四条：
- [ ] 开头是挑衅还是铺垫？
- [ ] 有没有一句触觉化描写能被拍剪师直接执行？
- [ ] 有没有一组二元对立能让观众记住？
- [ ] 核心结论是摆出来的还是砸下去的？
