# IP的灵性词汇不能删

有些IP说的话，你自己听不懂、不顺口——
但她的受众能懂。

比如心理咨询类IP说"能量""生命剧本""福报""究竟的智慧"，
你作为一个外人觉得这是玄词，
但在她的受众那里，这是日常表达。

删掉这些词，等于删掉IP的辨识度。
一个心理咨询师说"能量低"和说"情绪不好"是完全不同的两个人。
前者有她的世界观，后者谁都能说。

**底线：**
你不理解的词，先去问IP：你的受众怎么理解这个词？
如果受众能懂，保留。
如果IP自己也说不上来，再删。
