# 🗺️ 短视频创作流程地图（导航版）

> **这是导航，不是关卡。** 它只告诉你：手头这条稿现在在哪一棒、下一棒是谁、各棒产出什么。 具体怎么走，看那一棒自己的 Skill；所有判断的总尺子，是 **创作DNA**。 🔴 手头的稿不需要从头走完五棒——改个标题就只进文案，复盘就只进复盘。**按需进对应的棒，不为走完而走完。**

## 进哪一棒：先做适配诊断

创作前先答三问，决定从哪一棒进、哪些棒可跳：

1. 这是什么 IP？（专业人士 / 创业者 / 疗愈成长 / 服务行业）
2. 什么行业？有什么特殊限制（违禁词等）？
3. 这条的目的？（立人设 / 解决问题 / 情绪共鸣 / 引流）

---

## 各棒的"弹药在哪"（细节不在地图里，在各 Skill 名下）

> 🔴 原则：地图只指路，不教怎么走。每棒的具体技巧/原子笔记，**回各自 Skill 里待着**，那才是它们的家。下面只标"去哪找"，不展开。

- **① 定位**：定位类原子笔记（账号定位公式、人设型vs内容型、特殊经历是最强人设、三维筛选法……）→ 在 `dingwei-report-workflow` 名下。
- **② 选题**：选题类（选题公式、每条要有赌注、垂人群、热点五渠道SOP、受众决定骨架……）→ 在 `xuanti-workflow` 名下。
- **③ 大纲**：骨架类（总分总、钩子七种、0帧起手、核心卖点只一个、好奇心驱动骨架、三段论……）+ **金字塔检查**（见下）→ 在 `dagang-workflow` 名下。
- **④ 文案**：精细化类（抽象到具象、自嗨到它嗨、三种演绎语法、情绪底层驱动、节奏感、IP灵性词不删、三色交付……）+ 拍摄弹药（景别、空间、物品手法）→ 在 `fanwen-workflow` 主轴与弹药库里。
- **⑤ 复盘**：复盘类（数据是反馈不是评判、三维复盘法、行动优先70分、服务周期反推行业知识……）→ 待 `fupan-workflow` 立项后归入。
- **附·变现节点**：变现三角、三种变现模式、免费分享是最强变现、信任是变现前提 → 账号成熟后参考，不进单条创作主线。

## 🔺 金字塔检查（心法层 · 归在大纲那一棒）

> 柯哥定的心法："先画逻辑 → 再画情绪 → 金字塔过一遍 → 最后打磨。" 它管的是**逻辑骨架对不对**，所以归 **大纲（dagang）** 那一棒，作为搭完骨架后的一道**验收尺子**（不是卡死的关卡）。 六项：①一句话能画出树状结构吗 ②SCQA（背景→冲突→疑问）③每句制造下个疑问吗 ④逻辑顺序对吗（演绎/时间/结构/程度）⑤MECE（不重叠不遗漏）⑥情绪双轨（内容线+情绪线并行）。

## IP 类型·快速筛选（哪几棒是重点）

|IP 类型|重点棒|必用|避免|
|---|---|---|---|
|专业人士（律师/医生/咨询师）|选题+大纲+文案|反常识钩子 / 对白为主 / 案例切入|直接讲干货 / 大量内心独白|
|创业者（老板/创始人）|定位+选题+素材协作|弱者叙事 / 故事切片 / 利他逻辑|过早暴露商业目的|
|疗愈成长|大纲+文案+素材协作|情绪共鸣钩 / 对白为主 / 陪伴感结尾|大量内心独白（新IP表现力未知时）|
|服务行业（家政/装修/培训）|选题+大纲|案例钩子 / 承诺背书 / 信任建立|广告感太强|
