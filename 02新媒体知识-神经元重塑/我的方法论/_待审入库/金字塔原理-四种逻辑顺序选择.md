# 四种逻辑顺序选择

## 一句话
你讲东西的顺序只有四种。选错了顺序，内容再好也乱。

## 场景
视频脚本结构、客户方案汇报、任何"有很多点要讲但不知道先讲哪个"的情况。

## 核心机制
人脑能处理的逻辑关系只有四种。你讲一组观点时，必须先确定用哪种顺序。

## 四种顺序

### 1. 演绎顺序：大前提 → 小前提 → 结论
- "减肥不能吃高热量的东西。（大前提）
- 碳水和油脂热量高。（小前提）
- 所以减肥不能吃碳水/油脂。"（结论）
- **适合**：讲道理、推翻错误认知、论证一个观点。

### 2. 时间顺序：第一步 → 第二步 → 第三步
- "做账号分三个阶段。第一个月只管发，第二个月看数据筛选题，第三个月放大爆款。"
- **适合**：教程、流程、HOW TO 类内容。

### 3. 结构顺序：按空间/组成部分
- "北京市场怎么打？上海市场怎么打？广州市场怎么打？"
- **适合**：分地区、分部门、分人群的内容。

### 4. 程度顺序：最重要 → 次重要 → 一般
- "做短视频最致命的就一件事：选题不对。其次是表达，最后才是拍摄。"
- **适合**：优先级排序、避坑指南、资源分配建议。

## 怎么选
- 你在**论证**一个观点 → 用演绎
- 你在**教步骤** → 用时间
- 你在**分板块** → 用结构
- 你在**排优先级** → 用程度

## 原理出处
> 金字塔原理：演绎推理、发现因果、化整为零、归纳总结是大脑可以进行的仅有四种分析活动。这四种顺序也是大脑可用于组织思想的四种顺序。要写出条理清晰的文章，关键就是在开始写作前先将思想放入金字塔结构中，并根据规则检验。
