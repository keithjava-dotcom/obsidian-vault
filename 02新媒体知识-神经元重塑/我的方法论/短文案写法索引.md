# 短文案写法索引

> 封面与标题专用。短视频创作时只读这个索引，不用翻全库。

---

## 核心原则（四条铁律）

1. **意外感**：让人觉得"这个角度没想过"，打破原有认知
2. **收获感**：让人觉得"看完能得到什么"，对你有用
3. **封面文字 ≤ 12字**：有情绪，有冲击力
4. **标题带关键词 + 钩子**：用户搜得到（SEO），想点进去（心理缺口）

口诀：常理之外，对你有用。

---

## 钩子类型速查

写标题/封面时从以下七种选一个：

| 类型 | 说明 | 示例思路 |
|------|------|----------|
| 利益 | 直接说对用户的好处 | "学会这招，XX提升3倍" |
| 悬念 | 制造信息缺口 | "90%的人不知道的XX" |
| 冲突 | 展示矛盾或对立 | "为什么越努力越穷" |
| 共鸣 | 说出用户心里话 | "你是不是也这样" |
| 反常 | 颠覆既有认知 | "XX其实是错的" |
| 意外感 | 打破预期角度 | "从没想过可以这样XX" |
| 收获感 | 承诺看完有收获 | "看完省下3000块" |

## 快速自检清单

写完后对照：
- [ ] 标题/封面包含意外感或收获感（至少一个）
- [ ] 封面文字 ≤ 12字
- [ ] 标题含目标用户会搜的关键词
- [ ] 用了至少一种钩子类型
- [ ] 核心卖点聚焦，不贪多
- [ ] 15字内能说出这条视频讲什么
