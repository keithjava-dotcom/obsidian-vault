# 心理IP拍摄制作洞察

## 核心原则

**心理疗愈是"画面天生劣势"行业——没有家政那种干活对比画面。所以画面不是填满的，是留白的：人比画面重要，停顿比B-ROLL有力量，微表情比补拍镜头有内容。**

## 触发信号

- 拍摄/剪辑心理疗愈类口播
- 成片感觉"空"或"满"拿不准
- 逆光拍摄人脸发暗、手机位置不对

## 操作方法

**画面处理（疗愈行业专属）**：
- 不用画面填满，用停顿留白——三个问题之间的停顿比B-ROLL有力量
- 微表情比任何补拍画面都重要（说话时眼神的变化本身就是内容）
- 客户案例类用文字卡代替人物出镜（保护隐私同时传递信息）

**拍摄两条硬规则**：
1. 灯光第一原则：**顺光优先**。窗户在身后=逆光翻车；要么换方向拍顺光，要么前面打光大于背景光
2. 镜头高度：**与心口齐平**。太低显下巴大，太高显俯视

**剪辑五步流程（可复用到所有客户）**：
1. 音频粗剪 → 剪掉气口（"嗯""啊"、超1秒沉默）
2. BGM铺设 → 按起承转合分段铺，只调音量不调位置
3. 气口精修 → 逐段调停顿时长，用耳朵听不用眼睛看波形
4. 画面填空 → B-roll插进去，不需要的地方敢留白
5. 字幕导出 → 检查节奏，导出

## 边界

- 表达力弱的IP需要"加"（情绪引导），强势IP需要"减"——加减方向相反
- 案例出镜必须授权；留白不等于空洞，停顿要有内容承接
- 剪辑点评要"给指令"（五步清单）而不是"说问题"
