# 财富传承赛道独特

## 核心原则

**财富传承不是"有钱人才需要"——是中产以上都需要。有房产/公司股权/境外账户，其中任何一样，传承就有风险。**

## 触发信号

- 客户是财富传承/家族信托方向律师
- 选题总是从法律概念出发（没人搜"财富传承律师"）
- 目标客户定位成"富豪"

## 操作方法

1. **目标客户**：不是富豪，是有资产的人（房子/股权/境外账户有一样就算）
2. **选题从生活场景出发，不从法律概念出发**：客户不会搜"财富传承律师"，会搜"怎么把房子留给小孩""婚前协议有用吗""海外资产怎么继承"
3. **关键词不带法律术语**：例"嫁给有钱人之前这3件事一定要问清楚" — 精准击中富二代配偶的不安全感
4. **客户要的不是法条，是"有人替我想到了"**：选律师比的是谁更懂他的处境

## 边界

- 中产以上都有传承需求，但付费意愿从"有资产+有焦虑"开始
