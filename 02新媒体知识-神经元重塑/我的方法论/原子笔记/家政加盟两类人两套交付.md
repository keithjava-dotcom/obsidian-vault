# 家政加盟两类人两套交付

## 核心原则

家政合伙人大类只有两种：**想干活的**（学技术赚钱，缺自主拓客能力）和**想招商的**（复制总部模式赚加盟费，缺行业经验）。两类人期待完全不同，混在一起交付就是灾难。解法是双轨交付——服务型交付（C/B级，3天学会7天接单）和招商型交付（A/W级，7天学会招商15天招第一个合伙人）。**培训不是交付完成，客户能独立跑通业务闭环才算。**

## 触发信号

- 家政客户是加盟/合伙人模式，讨论合伙人培训、成活率
- 交付内容设计、产品分层定价
- 加盟费该不该当利润

## 操作方法

1. **先分人**：判断合伙人是想干活还是想招商，对应走哪条交付轨道
2. **双轨交付**：服务型与招商型各一套SOP，不混轨
3. **产品分层必须真实差异**：四级体系（1980入门/9800技术/19800投资/50000创业），每一级必须有「只有这一级才有」的交付项，可视化、可感知，不是纸面差异
4. **加盟费当入口不当利润**：加盟费是筛选门槛，真正利润来自合伙人产生的订单流水抽成和续费

## 边界

- 统一交付的结果是两边都不满意，合伙人成活率低
- 高级别与低级别交付内容雷同 → 溢价逻辑不成立，纠纷从这里开始
- 把加盟费当利润拼命招人不管交付 → 短期有钱，长期口碑崩
