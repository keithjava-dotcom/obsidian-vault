# 心理疗愈IP核心矛盾

## 核心原则

**心理疗愈IP做短视频最大的死穴是"线下有魅力，上镜就假了"——不是人没内容，是制作方式把活人气堵死了。解法不是改稿子，是改制作方式。**

## 触发信号

- 心理咨询/疗愈客户写逐字稿念稿后人味尽失
- 内容专业但没人看、感觉假
- 定位在"帮人解决问题"和"让人看见自己"之间摇摆

## 操作方法

三大核心矛盾及解法：

| 矛盾 | 表现 | 解法 |
|------|------|------|
| 线下有魅力，上镜假 | 有金句、有故事、有态度，一念稿力量就没了 | 不写逐字稿，写问题框架；让她对着手机说，录完剪辑精简；保留她的口语词（"生命剧本""宇宙安排"）——这是辨识度不是噪音 |
| 行业黑话 vs 用户听不懂 | 能量、维度、本自具足、觉醒、因果——删掉失去辨识度，不删受众听不懂 | 保留专业词（锚点，吸引对的受众）+ 类比落地（桥，让更多人过河）。例："升维"→蚂蚁看人/离开地球看地球；"能量"→用客户真实转变故事具象化 |
| "帮人解决问题" vs "让人看见自己" | 定位含糊，内容方向摇摆 | 二选一：前者是咨询师-客户关系（讲方法），后者是同行者关系（讲维度）。菲菲走后者：不讲方法论，讲"你看到自己卡在哪了" |

## 边界

- IP本身没有口语表达能力时，问题框架法不适用——改用提前准备框架、保留其书面语言风格
- 纯知识科普账号（不以人设为卖点）不适用
- 专业词保留不等于不翻译，纯黑话堆砌会让新观众流失
