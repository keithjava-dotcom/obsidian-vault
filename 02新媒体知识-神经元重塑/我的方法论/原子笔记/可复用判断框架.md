# 可复用判断框架

## 核心原则

**判断一个心理疗愈IP能不能做起来，看三点：有没有一件"只有我经历过"的事、对着镜头能不能正常说话、她信不信自己说的东西。三点全中，剩下的只是技术问题。**

## 触发信号

- 评估新疗愈IP要不要接
- 客户定位方向拿不准
- 把单客户经验沉淀成可复用方法

## 操作方法

**三点判断框架**：
1. 有没有一件"只有我经历过"的事？→ 若溪有（体制内辞职）；菲菲有（医院背景+疗愈觉醒）；赵姐有（30年痛苦经历）
2. 对着镜头能不能正常说话？→ 若溪能（甚至太能了）——表达力是硬门槛
3. 她信不信自己说的东西？→ 若溪信（她的内容是她活出来的）——信念感观众感受得到

**配套可复用资产**：

剪辑五步流程（可复用到所有客户）：
1. 音频粗剪 → 剪掉气口（"嗯""啊"、超1秒沉默）
2. BGM铺设 → 按起承转合分段铺，只调音量不调位置
3. 气口精修 → 逐段调停顿时长，用耳朵听不用眼睛看波形
4. 画面填空 → B-roll插进去，不需要的地方敢留白
5. 字幕导出 → 检查节奏，导出

**沉淀方向**：剪辑点评从"专业反馈"变成"可执行清单"——这个转化本身值得沉淀成方法论（对每个客户给指令，不说问题）。

## 边界

- 三点全中 ≠ 一定爆——更新频率、安全边界、平台规则仍是变量
- 体制内身份的内容安全边界需要在每条内容里重新确认
- 框架是初筛，深度判断仍需结合[[客户沟通中的判断标准]]四信号
