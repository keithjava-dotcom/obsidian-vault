# 从高光时刻到IP方向

## 核心原则

**IP方向不在"我会什么"，在"我经历过什么"——转化链：高光时刻→热爱的事→分享方式→个人IP→影响他人→自然变现。关键转折：不是"我学会了什么去教别人"，是"我经历过什么去分享"。**

## 触发信号

- IP定位模糊，不知道做什么方向
- 帮学员/客户找人生方向
- 客户说"干啥都行，能赚钱就行"

## 操作方法

**核心三问（递进式）**：
1. **挖掘高光时刻**："你以前的高光时刻是哪一个时刻？"——不看现在的能力，看过去的峰值
2. **锁定热爱**："如果这两个高光时刻选一个，你选哪个？"——逼选择；犹豫=没想清楚（"含糊的，宇宙不知道你要什么"）
3. **检验持续性**："这件事情你能天天干吗？"——不是"你愿意吗"，是"你能吗"，感受性问题，让学员想象每天做这件事的状态

**转化路径示例**（写作型学员）：
成长经历→写出来→发表（公众号/小红书图文）→影响同频的人→收到"你怎么做到的"反馈→开写作疗愈营→收费

**两条判断**：
- 每个人的人生都是值钱的，关键有没有去总结："真感情就是好文章"
- 赚钱不是唯一标准："干啥都能赚钱，但赚钱的过程中你要快乐，要满足内心真正的渴求"

## 边界

- 方向必须来自真实经历，不能硬造
- 三问要问出真实回答才算数，客户敷衍时往下追问
- 高光时刻是起点不是终点——还要过"热爱"和"持续性"两关
