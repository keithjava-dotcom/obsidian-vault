# 信息量扩充六维度

## 核心原则

**内容信息量不足时，从六个维度扩充——向下细分、向上汇总、向内折叠、情感转折、逻辑转折、情感升温。创作者反过来做：只提供细节，让观众自己得出结论。**

## 触发信号

- 稿子写完觉得"空、薄、没料"
- 大纲只有骨架没有血肉
- 一段讲完没有推进感

## 操作方法

| 维度 | 做法 | 示例 |
|------|------|------|
| ①向下细分 | 并列（清单式，每点都有意思）+ 次序（发展式，有递进） | 三条并列证据 → 逐步深入的论证 |
| ②向上汇总 | 越具体覆盖人群越广 | 泰坦尼克号个体爱情 → 触达普遍人性 |
| ③向内折叠 | 信息量=体验深度+情感浓度 | 不写"很感动"，写手抖、眼眶热 |
| ④情感转折 | 否定/反转 | 本以为A → 其实是B |
| ⑤逻辑转折 | 跳跃感 | 从A跳到C，中间留白让观众自己接 |
| ⑥情感升温 | 情绪积累爆发 | 三起三落 → 最后一击 |

## 边界

- 扩充不是注水：每点都要有独立信息量，宁缺毋滥
- 清单式是基本功，发展式是进阶——先做好清单式再碰发展式
