# 节奏感五工具

## 核心原则

**押韵、排比（最好上手）、顶针、长短句——建议大多数人用短句，一句一个意思。**

## 触发信号

- 稿子读起来"平"，没有节奏起伏
- 长句堆叠观众喘不过气
- 想加文采但不知道用什么工具

## 操作方法

1. **押韵**：句尾押韵形成韵律（克制用，满篇押韵=顺口溜）
2. **排比**：最好上手，三连排比有推进力
3. **顶针**：前句结尾=后句开头（"人穷志短，志短则懒"）
4. **长短句**：长句铺陈+短句砸点（"十四件事。没有一件是开庭。"）
5. **一逗一义**：一个逗号一个意义单元，短句为主

## 边界

- 节奏是工具不是目的——内容空洞时节奏救不了
- 押韵靠天赋不强求，排比人人可用
