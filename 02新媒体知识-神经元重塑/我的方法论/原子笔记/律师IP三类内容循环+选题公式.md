# 律师IP三类内容循环 + 选题公式

## 核心原则

**律师内容三线循环：立人设（凭什么信你）→ 场景唤醒（为什么看）→ 解法展示（关注有什么用）。选题公式 = 焦虑场景 + 反常识结论 + 身份关联。**

## 触发信号

- 律师 IP 内容规划单一（只讲案例或只普法）
- 选题没有固定公式，每期硬想

## 操作方法

### 三类内容循环（不是等比例）
| 内容线 | 解决什么 | 冷启动占比 |
|--------|---------|-----------|
| 立人设（特殊经历/为什么做这行） | "我凭什么信你" | 最高 |
| 场景唤醒（具体场景让观众觉得"跟我有关"） | "我为什么要看" | 中期上升 |
| 解法展示（方向性思路，不是完整方案） | "关注你有什么用" | 始终辅助 |

### 选题公式：焦虑场景 + 反常识结论 + 身份关联
- 例："嫁给有钱人之前这3件事一定要问清楚" = 焦虑场景（资产不安全感）+ 反常识（不是不问，是要问清楚）+ 身份（10年财富传承律师）
- 劳动仲裁："被裁员时HR让你签的那张纸，90%的人没看第二页"
- 刑事："被警察带走24小时内，家属做错的3件事"

**共同结构：你不是在讲法律，你是在讲一个人在最脆弱的时候最需要知道什么。**

## 边界

- 解法展示过度会稀释"去找律师"的动机 — 短视频承载不了解法交付
- 画面极简：固定机位、干净背景、直接看镜头，信任来自稳定不来自炫酷
