# 侦察兵差异化

## 核心原则

**还没成功但有真实故事的IP，差异化只有一条：做侦察兵，不做将军。"我还在探路，先把前面有什么告诉你"比"我帮你成功"更有信任感——观众知道后者是吹牛，前者是真的。**

## 触发信号

- 客户还没成功但想立人设
- 客户想包装成成功者
- 陪伴型IP定位

## 操作方法

1. ❌ 包装成成功者 → 被质疑
2. ❌ 回避失败经历 → 失去最大武器
3. ✅ "冲在前面排雷、避坑、刷失败经验"——把"还没成功"从弱点变成卖点
4. **适用判断**：客户已成功→导师型；客户在路上→侦察兵型。关键不是成没成功，是承不承认

## 边界

- 已成功者硬装侦察兵=矫情
- 侦察兵也要有可见进步（只排雷没前进=卖惨）
