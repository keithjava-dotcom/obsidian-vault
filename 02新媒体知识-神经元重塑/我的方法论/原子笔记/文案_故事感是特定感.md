# 故事感是特定感

## 核心原则

**故事感在某种程度上就是特定感。加时间、地点、职业、名字、数量——"个体的经历和普遍的经验结合，就有了神性"。**

## 触发信号

- 稿子写完像"正确的废话"，没有画面
- 讲案例没有细节，观众记不住
- 想要故事感但不知道加什么

## 操作方法

专属细节五件套（按需加，不是全加）：
1. **时间**：4月16号下午3点（不是"那天下午"）
2. **地点**：春福路43号（不是"一家店"）
3. **职业/身份**：他是开货车的（不是"一个人"）
4. **名字**：清甜的椰子水、灯塔笔记本（给物品起名）
5. **数量**：三个儿子、第七次、两年零三个月

**"所谓故事，就是'什么人'和'什么人'干什么事"** — 讲不清的知识用"什么人干什么事"打比方。

## 边界

- 特定感≠编造：细节必须来自素材或真实经历，数字保真
- 泛泛而谈的内容不会有流量——这是死线
