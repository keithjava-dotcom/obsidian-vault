# 实战案例如何拆解成疗愈内容选题

## 核心原则

**一个真实案例就是一条选题。拆解公式：背景→关键画面→干预动作→底层洞察；案例要同时打两根钉子——共鸣钉（观众看到自己）和价值钉（观众看到你能帮到）。**

## 触发信号

- 手上有真实客户案例但不知道怎么变成视频
- 案例讲成流水账没人看
- 案例只有故事没有结论

## 操作方法

**案例拆解四段模板**（以67岁信教老人案例为例）：

| 环节 | 内容 | 作用 |
|------|------|------|
| 背景 | 老伴年轻时打她，现在卧床不认人，她伺候但不心甘情愿 | 让人物立起来 |
| 关键画面 | 有情绪时偷偷揍老伴→揍完忏悔"神看到我揍人了"→血压升高进医院三回 | 共鸣钉：让观众看到自己（被道德绑架的压抑感） |
| 干预动作 | "你就是你家族的神""神爱世人本来的样子，神没有标准" | 价值钉：让观众看到IP的能力 |
| 底层洞察 | 宗教迷信让人用外在标准压迫内在真实感受→情绪淤堵→疾病 | 拔高收尾，留下记忆点 |

**操作步骤**：
1. 从沟通记录/辅导记录里提取真实案例（越具体越好：时间、动作、原话）
2. 隐私处理：模糊身份细节，或用文字卡代替人物出镜
3. 双钉检查：观众能否看到自己？观众能否看到你能帮？只打一个就重做
4. 长故事拆条：人物故事拆成4-6条视频，每条一个完整情绪起落（若溪小传法：辞职务→婚姻冲突→和解→职场感悟）

## 边界

- 无授权不暴露真实身份；案例不能变成"说客户坏话"
- 不能贩卖焦虑（案例只展示痛苦不给希望=消费痛苦）
- 干预动作必须真实发生过，不能编造"我改变了她"
