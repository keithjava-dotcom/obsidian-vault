# 情绪物化法

## 核心原则

**把抽象情绪绑定到观众能感受的身体感官/具体物件上——"感情太容易磨损了，有时还不如一把化妆刷"。情绪看不见，物化了观众才接得住。**

## 触发信号

- 写"很感动/很难过/很幸福"类抽象情绪
- 情绪核带过没砸实（反面教材病症）
- 想让观众"感觉到"而不是"知道"

## 操作方法

1. **绑身体感官**：手抖、喉咙紧、眼眶热（不是"我很紧张"）
2. **绑具体物件**：化妆刷、旧手机、一件没拆吊牌的衣服
3. **绑场景瞬间**：黄昏窗户、城市夜景、被风吹起的窗帘（情绪空镜头）
4. **物化后不加解释**：物件摆出来，让观众自己品

## 边界

- 物化不是比喻堆砌——一个情绪一个物，多了就散
- 物件必须观众有共同经验（别用只有你懂的梗）
