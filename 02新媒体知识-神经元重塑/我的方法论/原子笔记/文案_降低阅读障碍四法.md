# 降低阅读障碍四法

## 核心原则

**平均详情页停留仅18秒。四法：拒绝生僻字 / 押韵大法 / 概念类比 / 交流式沟通。**

## 触发信号

- 文案读起来费劲、观众划走
- 用词生僻或句式绕
- 想让复杂概念一秒懂

## 操作方法

1. **拒绝生僻字**：能说"干净"不说"澄澈"
2. **押韵大法**："一瓶沐浴露能有多特殊，洗的要干净，而且能护肤"（工具：完美韵脚）
3. **概念类比**："高速研磨"→"剁饺子馅的速度加速1000倍"
4. **交流式沟通**："不想让你焦虑，但请务必擦亮眼睛，我们未添加以下任何一种"

## 边界

- 押韵克制用，满篇押韵=顺口溜
- 交流式≠套近乎，是降低距离感
