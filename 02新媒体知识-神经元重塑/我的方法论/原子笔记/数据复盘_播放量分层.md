# 播放量分层复盘

## 核心原则

**播放量是综合结果，不是单一元素决定。按层级定位问题：<5000基本盘、5000-5万数据量/需求量、10-20万只差需求量、百万级双高、千万级看宏观。**

## 触发信号

- 账号数据复盘
- 视频播放量不达标时定位问题层
- 不知道该改选题还是改内容

## 操作方法

| 播放量 | 问题层 | 诊断方向 |
|--------|--------|---------|
| <5000 | 基本盘 | 形式或选题让人讨厌（画面丑/假干货/大脸怼镜头） |
| 5000-5万 | 数据量+需求量 | 点赞率<5%=数据量问题；选题没建桥梁=需求量问题 |
| 10-20万 | 只剩需求量 | 选题笼罩面不够宽 |
| 百万级 | 双高 | 需求+情绪双高，沉淀为可重复模型 |
| 千万级 | 宏观 | 市场蝴蝶效应，不是人力可为 |

**关键指标**：点赞率 ≥10% 高 / ≥5% 及格 / <2% 不值得点赞。两小时冲80万后停流=进人工审核。

## 边界

- 至少3条视频再归因，排除偶然性
- 控制变量：5-10条只变一个变量
- 重复正确的动作 > 改正错误的动作
