# 灵魂三问：快速建立高级感

## 核心原则

**面对高价值客户，前三分钟不被打动，这次咨询就失败了。不聊专业、不问你的问题——问本质。灵魂三问：你到底想活成什么样？现在有没有达到？那跟你现在有啥关系？**

## 触发信号

- 见企业老板/高净值客户，开场冷场
- 咨询陷入"你企业多大/你什么需求"的平庸问答
- IP采访式拍摄没有提问框架

## 操作方法

**成交场景三问**：
1. "你到底想活成什么样？"（不问他企业多大）
2. "现在有没有达到？"
3. "那跟你企业有啥关系？"

**逻辑链**：他认为企业做好了就幸福 → 不是这样的 → 幸福有好几个维度（健康、亲密关系、企业自动化、员工臣服）→ 全是问题 → 你想改变哪个？

**落点**：把你产品能解决的那个维度亮出来——不是卖产品，是把他大的问题落回到他自己的问题上。（"你死了还能把企业搬走吗？不能。那你现在过的好吗？没有。"）

**内容拍摄场景三问（问题框架法）**：
- 你站在哪里 / 你想活成什么样 / 你愿意做什么
- 让IP对着手机回答，录完剪辑精简——高级感来自她真实的语言能量，不是稿子

## 边界

- 灵魂三问需要信念支撑——没有"我能帮他"的底气，问出来是空架子
- 对低意向客户不适用（先分层，A类客户才值得全力三问）
- 三问之后必须落到"你想改变哪个"，不能只制造焦虑不落地
