# 客户沟通中的判断标准

## 核心原则

**判断客户"必然能做起来"看四个信号；遇到"太能讲"的客户不压制、用结构引导；客户对自己的理解比稿子准——文案不是替客户说话，是帮客户把她已经知道但说不出来的话说出来。**

## 触发信号

- 接新客户做能力评估
- 客户太能讲，不知道怎么管理
- 改稿时客户意见和稿子冲突，不知道该听谁的

## 操作方法

**"这个IP必然能做起来"的四信号**（柯哥判断若溪时用）：
1. 有独特的不可替代的真实经历
2. 口播表达力天然强（不需要教她说话）
3. 对自己的内容有深度理解（不是"你帮我随便写写"）
4. 愿意接受专业意见（剪辑点评后能改）

**"太能讲"客户的处理**：
1. 先让她对着镜头自由讲20分钟（素材）
2. 从素材里提炼逐字稿（结构）
3. 逐字稿给她——不是让她念，是给她边界
4. 保留她的语言习惯和即兴感

**客户自述最准原则**：
- 若溪4.25电话改稿时自己说出最核心的点："体制内要求稳重严谨，但我内心创新的那一面要长出来了"——这句话比任何第三方分析都准
- 允许客户自己补充核心判断，不替她编
- 文案不是替客户说话，是帮客户把她已经知道但说不出来的话说出来

## 边界

- 四信号是判断不是保证——更新频率、安全边界仍是变量
- 客户不愿接受专业意见时，服务策略要调整（"愿意改"是前提信号）
- 客户自述准 ≠ 客户说啥写啥——帮她说出来，不是替她想
