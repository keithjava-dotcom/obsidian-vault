# 负债困境类IP内容边界

## 核心原则

**困境IP不能消费自己的苦难，要给出路。说"我现在欠XX万，正在一点点还"✓，不说"我好惨，帮帮我"✗。核心信息是"我在爬起来"，不是"我有多惨"。**

## 触发信号

- 客户以负债/困境为内容主体
- 内容容易滑向卖惨
- 观众质疑"博同情"

## 操作方法

1. **边界线**：✅"我现在欠XX万，正在一点点还" / ❌"我好惨，帮帮我"
2. **操作标准**：每期涉及困境的内容，结尾必须落在"行动"上，不能落在"情绪"上——今天做了什么、还了多少、学到了什么
3. **第一条视频第一帧就亮身份**："我是负债者"——不铺垫不解释，不是博同情，是建信任
4. **典故一拖一**：引用典故立刻跟大白话翻译（"王阳明在龙场躺了三年，不是躺平，是在聚能。我现在也是这样。"）

## 边界

- 只讲惨不讲路=消费苦难
- 1000粉前不做变现内容（先认识→再信任→才谈钱）
