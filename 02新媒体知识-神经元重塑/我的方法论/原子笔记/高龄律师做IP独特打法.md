# 高龄律师做IP独特打法

## 核心原则

**"60多岁还在学"本身就是最强的IP叙事。高龄不是劣势，是天然的信任加速器 — 年轻人的专业需要证明，老年人的专业只需要被看见。**

## 触发信号

- 客户是高龄专业人士（50+，尤其退休边缘）
- 客户担心"我这么大年纪玩不明白短视频"
- 客户觉得自己话题不够多、不会运营

## 操作方法

1. **叙事核心**：不用讲"我很专业"，让观众看到"这么大年纪还在学短视频" — 观众自己会补上判断：这个人一生都在学习
2. **降低输出门槛**：IP 只负责提供原材料（真实经历/观点/语音），运营方负责洗稿整理出文案，IP 拿着拍就行 — 别期待老人学会选题策划
3. **内容来源**：个人经历最省力 — 学习/留学/从业/转型经历，随便拎一段就有故事，不用编
4. **不追热点**：坐下来讲一段真事，比追热点有效

## 边界

- 适合经历丰厚的老专家型 IP
- 运营方承担加工职责，IP 只出原材料
