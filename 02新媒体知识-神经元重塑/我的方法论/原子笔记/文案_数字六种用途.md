# 数字六种用途

## 核心原则

**数字很好用，六种用途：第一名权威 / 零添加绝对承诺 / 概念具象化 / 行为引导 / 真实性塑造 / 情绪化表达。注意广告法。**

## 触发信号

- 稿子里有数字但只是"报数"（没发挥数字的作用）
- 想让数字更有说服力/画面感

## 操作方法

| 用途 | 做法 | 示例 |
|------|------|------|
| ①行业权威 | 第一名/首创 | No.1类（先过广告法） |
| ②绝对承诺 | 零添加/零糖 | 用数字表现底气 |
| ③概念具象化 | 陌生数字配熟悉物体 | "相当于十斤橘子的维C"（268毫克没人有概念） |
| ④行为引导 | 不需逻辑直接指挥 | "两粒一起嚼" |
| ⑤真实性塑造 | 精确数字比整数可信 | "389042家庭的选择"比"30万"可信 |
| ⑥情绪化表达 | 夸张但有情绪 | "免费看书100年" |

## 边界

- 广告法红线：禁用词（第一/极/顶尖等）、数据必须标来源（最好第三方）
- 数字顺序遵守预期上升原则（58%+31%→89%，只升不降）
- 行业分尺：实体服务数字"越大越好"；金融保险"十倍"属无证据口语夸张不能进稿
