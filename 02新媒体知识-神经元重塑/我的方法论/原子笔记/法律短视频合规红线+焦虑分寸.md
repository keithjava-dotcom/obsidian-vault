# 法律短视频合规红线 + 焦虑分寸

## 核心原则

**法律IP独有的两条硬规则：不给具体法律建议、不承诺结果。这是保护自己，不是削弱专业度。**

## 触发信号

- 写律师稿子涉及个案/建议/结果承诺
- 内容用焦虑驱动（法律行业最易踩"贩卖焦虑"线）

## 硬规则（红线）

1. **不给具体法律建议**："你应该..." → "有一种思路是..."
2. **不承诺结果**："这个案子一定能赢"✗ → "这个案子赢面大的原因有三个"✓
3. **不讲在办案件**：《律师法》第38条（执业中知悉的信息保密，严重犯罪例外）
4. **不自我标榜"专家"**：说"我专做刑事辩护"✓，不说"刑事辩护专家/XX第一人"
5. **免费服务引流谨慎**：普法免费可，免费个案分析引流违规

## 焦虑分寸（判断标准）

说"你的资产可能传不下去"（唤醒需求✓）vs"你再不行动就完了"（制造恐慌✗）。
**看完观众是想"我要了解一下"，还是"我好害怕"？** 后者打回去重写。

## 边界

- 平台规则：抖音需「法律科普内容讲解资质」（每年复审）；视频号/快手=职业认证即准入
- 案例必须脱敏：不出现可识别信息
