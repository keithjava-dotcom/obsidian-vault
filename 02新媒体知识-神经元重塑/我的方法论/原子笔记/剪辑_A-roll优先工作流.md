# A-roll优先工作流

## 核心原则

**先拍A-roll（口播/声音轨道）粗剪，闭眼听，再补拍B-roll填空。声音是主轨道和骨架，画面全部基于音频生产——"先拍画面再配音"必然逻辑不通。**

## 触发信号

- 拍摄/剪辑流程颠倒（先拍画面再配文案）
- 口播视频不知道剪辑顺序

## 操作方法（标准6步）

1. 分段式写文案（100字一段）
2. 录纯音频或口播视频
3. 主轨道剪气口，完成A-roll
4. 字幕条标记对白/旁白/独白，搭剪辑框架
5. BGM结构剪辑
6. 按标记插入B-roll（填空题式剪辑，边剪边拍）

**完成声音端=70%工作量。音频即画面的脚本。**

## 边界

- 旅拍/事件类反向：先拍无序素材→看素材写文案→为剪辑做预埋
- 声音好画面几张图观众也能听下去；画面再好静音也看不下去
