# 门店员工口播 · 四步写法

**核心理念**：不是写顺口溜，是写顺耳的人话。

---

## 第一步：定核心卖点

| 区域 | 就抓一个点 |
|------|----------|
| 前台 | 招呼感 |
| 厨房 | 新鲜/信任 |
| 肉类区 | 品类全 |
| 串品区 | 省事 |
| 试吃区 | 降低决策成本 |
| 用品区 | 一站配齐 |
| 礼盒区 | 面子 |
| 酒水区 | 搭配氛围 |
| 凉菜区 | 下酒解腻 |
| 调料区 | 味道省心 |
| 后厨 | 安全/放心 |

每区只抓一个点，不在一句话里塞多个卖点。

---

## 第二步：写人话

❌ 不写：品质保障、精选好物、舌尖盛宴、尊享体验

✅ 要写：我这有什么、你怎么拿、回去怎么用、能省什么事、吃着放不放心

员工的话要像他真站在摊位前说出来的。不要像公司统一培训出来的广告词。

---

## 第三步：验听感（押韵自检）

押韵不是两个字表面押韵，是念出来顺不顺耳。

自检方法：**写完后念一遍。**
- 卡嘴 → 换韵脚，甚至放弃押韵
- 顺嘴 → 过

宁可少押韵，不要硬押韵。目标不是快板顺口溜，是听起来自然的落脚。

---

## 第四步：配动作（动作锚）

口播句子必须能拍出画面，不能拍的长镜头脚本是废的。

**话是钩子，动作是句号。**
观众记不住你说了什么，但记得住你做了什么。

检查方法：写完一句话，问自己——这句话对应什么画面动作？

> "原切鲜肉，纹路看得透。" → 拍厨师切肉、展示纹理
> "烤炉二十起，气罐餐具配得齐。" → 拍员工拿炉子、扫过餐具
> "肉归肉，菜归菜，生熟分得清。" → 拍后厨分区、冷柜

重要：动作要和最后半句话**同时落地**，不是说完了再做动作。边念边做，不报幕。

---

## 四道闸自检

每写完一句，四道闸全过才放行：

1. ✅ 员工真实能不能说出口？（不是广告词）
2. ✅ 观众听起来顺不顺耳？（不是顺口溜）
3. ✅ 这句话有没有明确卖点？（不是废话）
4. ✅ 镜头能不能拍出来？（不是内心独白）

有一条不满意 → 重写。

---

## 实战案例

【实战案例·2026-06-15·炙野烧烤食材店】
场景：门店开业长镜头，11名员工接力口播
判断：员工话不能像广告，押韵要顺耳不要顺口溜，句子必须能拍
处理：每区域定一个卖点→写人话→念一遍验听感→配动作锚→四闸自检
预期：观众听着顺、看着有画面、觉得东西全、买着省事、吃着放心
