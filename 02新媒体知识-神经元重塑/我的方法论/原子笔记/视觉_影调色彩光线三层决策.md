# 影调→色彩→光线三层决策

## 核心原则

**先景别 → 视角 → 影调 → 最后色彩。影调优先级最高，色彩不强化前三者就是干扰。**

## 触发信号

- 拍摄画面情绪不对但说不出哪不对
- 画面色彩花哨但没传递情绪
- B-roll/封面配色决策

## 操作方法

1. **影调**（明暗关系，优先级最高）：低调=负面情绪（神秘阴暗硬朗）/ 高调=正面情绪（轻松明朗）/ 中间调=客观叙事
2. **色彩**（最后加）：色彩必须强化影调，否则就是干扰
3. **光线**：柔光=细腻皮肤/直射强光=结构/逆光=透明/侧逆光=轮廓/顺光=干净（拍菜用顺光）
4. **色温心理**：暖光=红烧肉/红光=菜市场猪肉/蓝色=消毒干净/绿气=有毒

## 边界

- 画面永远是辅助，服务文案传递
- 别在画面里藏"寓意"等人来读——要当下那口本能反应
