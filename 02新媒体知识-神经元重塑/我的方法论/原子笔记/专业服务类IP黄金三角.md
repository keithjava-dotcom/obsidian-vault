# 专业服务类IP黄金三角

## 核心原则

**焦虑是入口，信任是转化，专业是交付。专业服务类IP在短视频里越少展示专业，转化率越高。**

## 触发信号

- 客户是专业服务者（律师/医生/咨询师/顾问/家政老板）
- 内容总在展示专业度但没转化
- 适用所有专业服务IP，跨行业可迁移

## 黄金三角

1. **焦虑是入口**：客户不是因为"这个律师很专业"来找你，是因为"我担心我的钱传不下去"来找你
2. **信任是转化**：客户在视频里判断的不是你的专业度（他判断不了），是"这个人我信得过吗"
3. **专业是交付**：信任建立之后，专业能力在私域交付，不在短视频里展开

**反常识结论**：短视频里展示专业 → 观众觉得"我知道了，不需要找他了"；唤醒焦虑 → 观众觉得"我需要找个人帮我"。

## 操作方法

1. 选题从客户焦虑场景出发（不是从专业概念出发）
2. 内容做"同路人"姿态（坐旁边不站对面）
3. 专业能力放进私域/咨询环节交付
4. 案例脱敏（唤起共鸣，不展示战绩）

## 边界

- 适用高客单专业服务（决策周期长、信任要求高）
- 不适用低客单快消品内容
