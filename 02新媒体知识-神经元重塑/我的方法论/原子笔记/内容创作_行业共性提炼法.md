# 行业共性提炼法

> 来源：柯哥 2026-05-31，菲菲疗愈赛道实操验证

---

## 核心逻辑

当面对同一个行业多个IP时，不要每个IP从零做定位和内容。

先找出这个行业的共性——受众画像、内容型态、关键词库、算法逻辑、变现路径——把这些作为"行业根"。然后每个IP在根上做个性化匹配。

```
行业根（共性，一次提炼，多IP复用）
  ├── IP-A 适配：调整内容支柱侧重点、人设标签
  ├── IP-B 适配：调整内容支柱侧重点、人设标签
  └── IP-C 适配：调整内容支柱侧重点、人设标签
```

这样内容不白做——换一个IP，底层框架不需要重来。

---

## 行业根包含什么

| 模块 | 内容 | 复用度 |
|------|------|--------|
| 市场规模和趋势 | 全球/中国数据，增长率 | 100% |
| 平台选择 | 主攻哪个平台，为什么 | 100% |
| 内容型态分类 | 陪伴式/导师式/技术式/故事式 | 100% |
| 算法关键词库 | 分平台#标签和语意 | 100% |
| 赛道逻辑 | 情绪驱动/逻辑驱动，信任路径 | 100% |
| 平台风险 | 违规词、敏感话题 | 100% |
| 变现路径 | 课程/咨询/社群/沙龙 | 80%（可微调） |
| 对标账号 | 头部案例分析 | 50%（按IP方向筛选） |
| 内容支柱 | 哪些主题方向 | 30%（每个IP侧重不同） |
| 人设标签 | 核心标签+辅助标签 | 0%（每个IP不同） |

## IP个性化匹配

行业根做好后，每个新IP接入做四步：

1. **归类型**：这个IP属于哪种内容型态（陪伴式/导师式/技术式/故事式）
2. **找侧重**：在行业通用内容支柱里，这个IP侧重哪几个
3. **关键词口头植入**：把行业关键词融进引导问题里，让IP在自然讲述中自动带出关键词——不是背词、不是硬读，是"讲故事的时候那个词自己就出来了"
4. **调人设**：基于IP的真实经历和语感，提炼人设标签和语言风格

### 关键词口头植入（关键步骤）

> 标签是给算法看的，但标签加在话题栏还不够。算法还扫描你口播文案中的关键词，来判断你的内容属于哪个赛道。所以关键词必须融入口头表达。

**错误做法**：列一张关键词表→让IP"记得说这些词"→录的时候刻意停顿想词→不自然、卡顿、假。

**正确做法**：设计**含关键词的引导问题**。IP看到这个问题，顺着往下讲，关键词自动出现在话里。不是记得说，是话到嘴边就有了。

```
引导问题 = 选题主题 + 2-3个核心关键词

示例（菲菲·信神老太太）：
  原版问题："讲一下你在医院遇到的那个老太太"
  含关键词版："你在医院遇到过一个被原生家庭困了一辈子的老太太，讲一下她是怎么觉醒的、那一刻她的能量发生了什么变化"
  → 菲菲回答时，"原生家庭""觉醒""能量"三个词自然就出来了
```

**原则**：
- 引导问题里不堆关键词（过多会引导失真）
- 用IP自己讲故事的方式设计问法
- 录完检查：关键词自己跑出来了没？没跑出来的，换个角度再问一次

## 验证案例：菲菲（疗愈赛道）

**行业根提炼内容**：
- 市场规模、平台选择、内容型态分类、算法关键词库、赛道逻辑、平台风险
- 产出：`心理咨询室/2026-05-31-疗愈赛道小红书调研.md`

**菲菲个性化**：
- 归类型 → 导师式疗愈（偏万相凡清路线）
- 找侧重 → 三大支柱全方位，偏重案例和觉醒方法
- 调人设 → 疗愈师面+商业创始人面，双面语感

成果：11条选题，每条对标行业关键词库做#标签和嵌入指引。

**复用预期**：下一个疗愈赛道IP接入时，行业根不改，只做个性化三步。
