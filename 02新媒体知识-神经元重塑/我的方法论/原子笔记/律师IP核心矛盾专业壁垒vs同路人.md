# 律师IP核心矛盾：专业壁垒 vs 同路人

## 核心原则

**律师做IP，专业是底色不是主菜。主菜是客户在深夜办公室抽烟时心里那个说不出口的恐惧。专业只是"我能解决这个恐惧"的证据。**

## 触发信号

- 律师 IP 把短视频当普法课（列法条/讲案例/给结论）
- 内容干货满满但没人看
- 姿态不自觉变成"专家教训人"

## 操作方法

1. **不讲法律讲焦虑**：观众打开短视频不是为了学法条，是为了消除焦虑。谁消除焦虑谁获得信任
2. **"同路人"姿态 > "专家"姿态**：坐观众旁边，不站观众对面。"真实、可信、有温度，不娱乐、不讨好"
3. **护城河不在法律能力**：在背景/经历/性格（麻律师=数学+金融+法律三重背景、政府10年、华威商学院）— 这些让客户"信得过"
4. **咨询切入三问**：①先问客户群（接触最多的是什么人）②再问深夜焦虑（客户睡不着时想什么）③最后问差异化（客户为什么选你）

## 边界

- 专业壁垒是双刃剑：内容不对（普法腔）观众进不来；但专业度是底色，不能丢
- 不适用：纯普法科普账号（不以转化律师服务为目标）
