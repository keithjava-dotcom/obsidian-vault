# 康复拍摄预期+工具替代

## 核心原则

「演起来好尴尬」是所有新手的必经阶段，不是个别人问题，**唯一解法是多拍**。工具替代降低观众的行动门槛：本来「没工具做不了」→「啤酒瓶也能用，我现在就试试」，这种细节直接决定完播率和评论区的感谢。

## 触发信号

- 学员/客户说拍摄尴尬、紧张、想放弃
- 动作需要工具（泡沫轴、弹力带）但观众家里不一定有
- 学员「能复制但写不出」，从念稿到独立创作卡住

## 操作方法

1. **拍摄预期管理**：第一条视频开拍前就告诉学员「前几条肯定尴尬，这是正常的，所有人都是这么过来的」——提前做预期管理，降低放弃率；拍到50条自然不紧张
2. **工具替代给方案**：有泡沫轴的用泡沫轴，没有的拿啤酒瓶（圆的就行，效果一样，冰过的还能顺便冰敷一下）——替代方案要人人家里都有
3. **教学递进四步**：
   - 用学员的本行做类比（对康复学员说「跟你学康复动作一样，刚开始不标准」）
   - 先给改好的稿子让她念 → 找到「原来短视频是这么说」的语感
   - 再让她自己写，写完之后不改内容，只改结构和开头
   - 拍到50条自然不紧张

## 边界

- 尴尬不是能力问题，是**不熟悉短视频语法**（像健身动作刚开始不标准，练着练着就标准了）
- 别给观众用不起的工具，替代方案必须家家户户都有
