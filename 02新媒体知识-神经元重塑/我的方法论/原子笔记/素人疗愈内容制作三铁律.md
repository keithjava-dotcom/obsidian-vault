# 素人疗愈内容制作三铁律

## 核心原则

**素人疗愈内容三铁律：用"我第一次……"开头不用"你知道吗"；每段痛苦后面必须跟一个"我现在懂了"；术语全部翻译成大白话，但保留她的灵性词汇。你不是来上课的，你是来分享的。**

## 触发信号

- 素人IP文案写成科普/说教腔
- 开头用"你知道吗"这类导师句式
- 痛苦段没有翻转；行业术语堆砌

## 操作方法

**铁律一：用"我第一次……"开头，不用"你知道吗"**
- 赵姐最好的文案都以具体事件开场："18岁，我嫁人了。全家反对。""结婚第一年，我们就打架。""我做过家政，做过护眼，做过美业。全都失败了。"
- 这不是技巧，是内容本质："你知道吗"隐含师生关系，"我第一次"隐含同行关系

**铁律二：每一段痛苦后面必须跟一个"我现在懂了"**
- 核心结构反复出现：那会儿我不懂/不知道 → 现在我懂了/明白了
- 没有"我现在懂了"的翻转，痛苦就只是诉苦；翻转让痛苦变成资产
- 写完自检：痛苦段后面有没有觉醒段？没有就是在消费痛苦

**铁律三：术语翻译成大白话，保留灵性词汇**
- 保留：她的灵性词汇是辨识度，不能洗掉（"一切都是最好的安排""宇宙给我设计的剧本""能量调频"）
- 翻译：疗愈行业术语必须翻成她能说的版本
  - 不是"原生家庭创伤" → 是"我爸妈总吵架，我就想逃"
  - 不是"价值感崩塌" → 是"不知道自己还有没有用"

## 边界

- 灵性词汇保留也要有度，堆成听不懂的玄学就失去大众
- 故事必须真实——素人IP唯一的信用是真实
- 三铁律适用"素人过来人型"，强势型/专业型IP有自己的打法
