# 素人疗愈文案自检清单

## 核心原则

**素人疗愈文案写完过六道自检：开头具体事件、痛苦有翻转、术语翻译、结尾陪伴邀请、镜子效应、灵性词汇保留。六项全过才能发。**

## 触发信号

- 素人疗愈稿写完，投稿前质检
- 改稿拿不准哪里有问题
- 内容发出去数据差，不知道哪一环断了

## 操作方法

**六条自检清单**：
1. 开头是一个具体事件吗？（不是抽象概念）
2. 痛苦段后面跟着"我现在懂了"的翻转吗？
3. 术语翻译成她的原话了吗？
4. 结尾是陪伴邀请，不是导师说教？
5. 观众看完能在里面看到自己吗？（镜子效应）
6. 保留了她的灵性词汇（"一切都是最好的安排"等），没有洗掉？

**配套：受众心理链条检查**（每条视频必须完成前三步，第四步交给评论区/主页）：
1. 「她说的这个，我也有」→ 共鸣
2. 「她走出来了」→ 希望
3. 「她是怎么走出来的」→ 好奇
4. 「我也想找她聊聊」→ 行动（不硬塞进视频，留给主页/私信）

## 边界

- 清单适用"素人过来人型"IP——强势型/专业型IP有各自的检查标准
- 六项全过 ≠ 一定爆，但不过 = 一定不稳
- 自检是写作时的习惯，不是发布前的临时补救
