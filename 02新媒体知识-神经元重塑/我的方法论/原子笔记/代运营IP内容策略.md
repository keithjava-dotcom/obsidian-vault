# 代运营IP内容策略

## 核心原则

**不教方法论，展示真实交付过程。两种路径：信任型（揭露行业乱象→老板信任→签约）vs 内容型（展示真实过程→观众喜欢→商家主动找）。**

## 触发信号

- 代运营客户做账号定位
- 内容方向犹豫"讲干货还是展示过程"

## 操作方法

1. **信任型路径**（有行业经验者）：揭露行业乱象→老板信任→签约。核心卖点=经验+诚实
2. **内容型路径**（无资历者）：街头挑战+真实记录→观众喜欢→商家主动找。核心卖点=敢干+真实
3. **陪伴型IP三要素**：在路上的状态（不是已成功）+真实的困难（被拒绝/做不好要展示）+可见的进步（观众能看到变化）
4. **"不够好"是内容红利**：口才不好→说话真实没演讲腔；学历不高→接地气；不包装成不是自己的人

## 边界

- 只展示困难没进步→观众觉得这人不行；只展示成功不展示困难→变导师型学不来
- 街头挑战类选题核心是"找谁拍"不是"拍什么"——选有职业特征、愿意聊天、本身有故事的人
