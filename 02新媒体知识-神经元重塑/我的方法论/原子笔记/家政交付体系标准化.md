# 家政交付体系标准化

## 核心原则

**没有流程 = 每次交付都在重复造轮子。** 家政行业普遍问题：创始人自己会干，但教不会别人——因为没有SOP，每次交付依赖人的经验，无法规模化。交付快慢决定口碑。

## 触发信号

- 家政客户说「我们都会，就是没梳理出来」「总在干重复的事」
- 交付依赖创始人个人经验、教不会人
- 讨论培训体系、品牌授权、接单流程

## 操作方法

1. **写SOP手册**：把交付内容写成可打印的SOP手册，分服务型/招商型两套
2. **节点化验收**：签约 → 培训 → 考核 → 发证 → 首单
3. **品牌授权后置**：不签约当天发，培训考核通过再发（毕业证逻辑）
4. **订单供给先行**：「3天学会，7天接单」的前提是总部能保证订单供给——没有订单，培训越快口碑越差

## 边界

- 没有订单供给支撑的快速培训 = 口碑崩，外地代理商场景尤其严重
- SOP不落地成可打印手册、不节点化验收，等于没有SOP
