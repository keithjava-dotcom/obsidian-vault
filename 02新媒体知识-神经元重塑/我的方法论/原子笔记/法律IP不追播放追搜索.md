# 法律IP不追播放追搜索

## 核心原则

**高客单价法律服务 = 搜索流量驱动，不是推荐流量驱动。不追播放量，追搜索匹配。**

一个人有法律需求（合同纠纷/离婚/刑事），不会刷着刷着突然想咨询 — 他是**带着问题去搜的**。搜索流量靠视频标题+内容匹配对方的搜索关键词，不靠你多火。

## 触发信号

- 客户是律师/法律从业者 IP
- 客户纠结"播放量为什么上不去"
- 选题方向犹豫"该追热点还是讲专业"

## 操作方法

1. **选题方向**：不是"什么话题火"，是"什么问题是潜在客户会搜的"（如"工伤赔偿标准""欠薪怎么要"）
2. **考核指标**：看私信、看好友添加量、看咨询转化 — 不看播放量（朱律师定位方案原话："不追播放量，看私信、看谁加你好友"）
3. **咨询量少≠账号有问题**：法律服务不是快消品，内容的目的是筛选"刚好需要你这个人"的精准客户 — 100个泛流量不如1个精准客资（3个月3-4个咨询，成交1个就覆盖全部运营成本）
4. **平台顺序**：视频号优先于抖音 — 法律IP信任建立在圈层传播（朋友的朋友）上，视频号半熟人信任 > 抖音陌生人兴趣

## 边界

- 适用于**高客单价**法律服务（诉讼/顾问），不适用于低客单普法账号
- 不追播放 ≠ 不做内容质量：搜索到的观众同样3秒决定划不划走
