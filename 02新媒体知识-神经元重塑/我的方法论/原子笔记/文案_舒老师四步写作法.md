# 舒老师四步写作法

## 核心原则

**描述（口水话把字义写准，不能出错）→ 发散（联想多个方向选其一）→ 精炼（长话变短，字义不变）→ 改造（陌生感/类比暗示雕刻）。绝大多数文案都是从潦草一步步改造出来的。**

## 触发信号

- 句子写出来"平、熟、没特点"
- 关键句打磨没有章法
- 想改稿但不知道改哪里

## 操作方法

以"真的好甜啊"为例：
1. **描述**：先把意思写准（口水话，不能出错）
2. **发散**："甜是什么感觉？"联想多个方向选其一
3. **精炼**：长话变短，字义不变
4. **改造**：陌生感/类比暗示雕刻 → "毫不夸张，甜过蜂糖" → "蜂蜜不是它的对手"

另一例："掩藏岁月浸透之美" → "岁月打不过美人"

## 边界

- 描述不出错是根基——字义错了，后面全是错的
- 先口水话后文采，顺序不能反
