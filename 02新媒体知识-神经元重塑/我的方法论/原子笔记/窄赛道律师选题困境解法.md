# 窄赛道律师选题困境解法

## 核心原则

**窄赛道的核心问题不是"话题对不对"，是"同一个入口太窄，人不进来"。拓宽不是换赛道，是在外围开入口。**

只讲一个主题（如"球员欠薪"），流量稳定但不破圈，咨询人群单一。

## 触发信号

- 律师 IP 只讲单一细分领域，流量瓶颈
- 播放稳定但咨询类型单一（如全是家长，成年客户不来）
- 选题库越做越窄，没东西可讲

## 操作方法

把主赛道当入口之一，在外围开更多入口：
1. **行业内幕**（观众想看）— 如赛事内幕
2. **热点评论**（路人想看）— 如转会八卦、行业新闻
3. **个人经历**（对你这个人感兴趣的人想看）— 留学/从业/转型故事
4. **反常识认知**（打破"只有专业"的印象）

核心公式：**泛内容做入口 → 垂直内容做转化 → 主页做人设收口。**

## 边界

- 泛内容不是讲你不懂的事，是用你能讲的事把陌生人拉进来
- "短视频的短不是时长短，是信息密度的短" — 讲得精彩，90秒观众也追着看完
