# 情绪空镜头自查表

## 核心原则

**情绪→画面映射表：以物传情。黄昏窗户、城市夜景、被风吹起的窗帘、雨林小道——空镜头不空，是情绪的容器。**

## 触发信号

- B-roll缺情绪镜头
- 心理活动/独白段不知道配什么画面
- 画面"有"但"没情绪"

## 操作方法（情绪→空镜头映射）

| 情绪 | 空镜头 |
|------|--------|
| 孤独/失落 | 黄昏窗户、空房间、路灯下的影子 |
| 想念/怀念 | 旧物特写、被风吹起的窗帘、老照片 |
| 城市疲惫 | 城市夜景、地铁人流、雨打车窗 |
| 释然/平静 | 大海、天空、树叶摇晃 |
| 紧张/不安 | 门缝、走廊尽头、时钟特写 |

**用法**：固定视角、一段台词配一个固定空镜头，配合声音把观众带入情境。

## 边界

- 空镜头是情绪的容器不是装饰——情绪不对宁可不用
- 别藏"寓意"等人来读，要当下那口本能反应
