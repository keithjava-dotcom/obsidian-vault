# 尖峰时刻四法

## 核心原则

**聚焦局部瞬间、生理反应、时间瞬间、临界点、压力叠加——把"最动的那一下"放大到观众眼前。**

## 触发信号

- 故事讲平了，找不到情绪最高点
- 关键瞬间一笔带过
- 情绪核"带过"没有砸实（反面教材病症之一）

## 操作方法

四种尖峰手法：
1. **局部瞬间**：聚焦一个局部——划过锁骨的发梢（不写"她很美"）
2. **生理反应**：手抖、呼吸、喉咙发紧（身体比形容词真）
3. **时间瞬间**：杯子摔碎的一瞬间、打响指前一刻（临界点）
4. **压力叠加**：两个压力不够，再来一个（情绪堆到顶点再释放）

## 边界

- 尖峰是"停住"，不是"喊出来"——慢下来，加表情，加对方原话
- 全稿只用1-2处，处处尖峰=没有尖峰
