# 社区30万挑战运营模型

## 核心原则

**这不是算账，是执行力模型。** 把大目标拆成一单一单的动作，IP内容才有素材，团队才有方向。异业合作是家政获客的核心渠道，不是挂个牌子，是有具体利益分配的。

## 触发信号

- 家政客户定社区目标（如30万/社区）、讲社区挑战
- 讨论每天该干什么、团队没方向
- 异业合作怎么谈、怎么分钱

## 操作方法

1. **目标逐级拆解**：99块一单 → 3030个订单；30天 → 每天61单；10个人 → 每人6单
2. **拆到动作层**：每天进多少户、打多少电话、贴多少广告——拆到不能再拆，就知道明天一大早该干什么
3. **异业合作带利益分配**：
   - 异业门店推一单，怎么分钱
   - 异业门店自己接不了的单，怎么转给家政
   - 社区活动（免费清洗油烟机体验）怎么变成引流钩子

## 边界

- 异业合作没有具体利益分配机制 = 挂个牌子，无效
- 拆解必须拆到「明天一大早干什么」的动作层，停在数字层面不算拆完
