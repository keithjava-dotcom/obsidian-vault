# 家政IP不讲服务讲带人赚钱

## 核心原则

家政行业C端内容（打扫得多干净、用了什么工具）**流量天花板低**。真正有传播力和招商力的方向是「怎么带人赚钱」。IP定位不是「一个家政服务有多好」，是「一个带你干家政赚钱的人」。

## 触发信号

- 家政老板做IP，写定位/选题/文案
- 内容方向纠结在服务展示还是招商叙事
- 老板是直接型、行动派性格

## 操作方法

1. **内容方向四选**：
   - 我一个社区怎么从0跑到30万
   - 我为什么敢把1980退给你
   - 我的人怎么培养的（老带新体系）
   - 家政行业的水有多深（行业揭秘/防坑）
2. **人设匹配开头**：直接型创始人不需要场景铺垫，第一帧怼脸——揭露式（「那是你根本接不到大活」）、实证式（「1980到底能不能回本？我今天下午亲自跑了一趟」）、态度式（「求人不如求己」）
3. **核心算法**：攻击性开头 + 触觉化描写 + 二元对立 + 结论砸死
4. **画面到拍摄级别**：不说「烟道在漏油」，说「黑油顺着缝隙往下滴」；不说「我们服务很标准」，拍B-ROLL里师傅干活手法的起落节奏

## 边界

- 攻击性开头只适用于直接型创始人，温和派人设不能硬套
- 家政是触觉行业，画面看不到「手在干什么」，观众感受不到专业——画面必须到拍摄级别
