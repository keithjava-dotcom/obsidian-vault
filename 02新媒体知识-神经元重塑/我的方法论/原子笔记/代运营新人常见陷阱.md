# 代运营新人常见陷阱

## 核心原则

**新人代运营五个坑：承诺结果 / 无案例空谈能力 / 包装成专家 / 交付无边界 / 内容不真实。**

## 触发信号

- 代运营新人接单前自查
- 客户服务出问题时的诊断

## 操作方法（五个坑+解法）

1. **承诺结果**→ 只承诺过程+方法论，结果用案例说话
2. **无案例空谈能力**→ 先积累案例（街头帮人做视频是低成本起步）
3. **包装成专家**→ 真实人设比专家人设更有传播力（对无资历者）
4. **交付无边界**→ 边界书面化，不承诺范围外的事
5. **内容不真实**→ 展示真实交付过程，不教空方法论

## 边界

- 有真实行业经验者可以直接走专家路线（黑叔），新人别硬装
