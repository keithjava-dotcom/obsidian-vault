# BGM起承转合结构

## 核心原则

**BGM按结构点剪段适配文案段落：起（轻缓拉入情境）→承（上扬变奏）→转（高潮精华）→和（落幅收尾）。一首视频的BGM是多首音乐+音效+停顿音的组接。**

## 触发信号

- 视频配乐凭"好听"选，没按结构配
- 音乐和文案情绪不搭
- B-roll/剪辑阶段不知道音乐怎么剪

## 操作方法

1. **起**：轻缓拉入情境（第一句台词不要有音乐，渐入）
2. **承**：上扬、新乐器变奏（进主题用）
3. **转**：高潮精华（激烈段用）
4. **和**：落幅收尾、回弹渐隐（结尾用原曲落幅）

**衔接技巧**：
- 段落衔接找旋律重合点拼接
- 停顿音单独剪下做转场音效（文案转折处必须停顿）
- 过渡音乐（平缓无结构）像中性镜头，衔接两段音乐
- 拟声音效可作两段BGM的万能衔接（设进出→卡一段拟声音效→进下一首）

## 边界

- 先写文案做成声音轨道，再找BGM——不是先找音乐
- 凭喜好选BGM会减分：舒缓不配激烈、有歌词不与人声重叠
