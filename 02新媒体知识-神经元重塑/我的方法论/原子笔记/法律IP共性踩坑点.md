# 法律IP共性踩坑点

## 核心原则

**法律人做内容四个通病：专业术语自嗨 / 话题不敢泛 / 追求"做正规"忘了"做有效" / 案例不脱敏。**

## 触发信号

- 律师 IP 稿子写出来像"法律意见书"
- 客户坚持只讲专业领域
- 视频拍得正规但没互动

## 踩坑清单（含解法）

1. **专业术语自嗨**：不自觉地进入写法律意见书的语态。检验标准：**把稿子读给你妈听，她能听懂就能发**，听不懂改
2. **话题不敢泛**：惯性思维"只能讲专业领域"。解法：泛内容=钓鱼，把陌生人拉进来翻主页，总有一天能用上你
3. **追求"做正规"忘了"做有效"**：正式感是职业习惯，但观众是来消遣的。放松聊天口吻比西装革履念稿有效百倍
4. **案例不脱敏**：所有案例不出现可识别信息 — "我见过一个企业主..."不是"我有个客户叫XXX"。案例功能是唤起共鸣，不是展示战绩
5. **焦虑唤醒无分寸**：说"你的资产可能传不下去"（唤醒需求✓）vs"你再不行动就完了"（制造恐慌✗）。判断标准：观众看完想"我要了解一下"还是"我好害怕"

## 边界

- 法律红线：不给具体法律建议（"你应该"→"有一种思路是"）、不承诺结果（"一定能赢"✗ →"赢面大的原因有三个"✓）
