# 小白也能做的人设逻辑

## 核心原则

**核心人设不是"我很厉害"，是"我也不太懂，但我敢干"。弱点是传播力——"一个和你一样的人做给你看"比"专家教你"更有行动召唤力。**

## 触发信号

- 客户是短视频新人/无行业资历
- 客户觉得自己"不够格"做IP
- 陪伴型IP定位

## 操作方法

1. **人设锚**："不是专家教学，是普通人也能干成的真实证明"
2. **三要素**：在路上的状态+真实的困难+可见的进步（缺一不可）
3. **弱项变资产**：口才不好→真实；学历不高→接地气；不会深度思考→内容要真实不要深刻
4. **红线**：不要包装成不是自己的人（强行讲干货反而失去辨识度）

## 边界

- 适用陪伴型/成长型IP；导师型IP不适用
- 示弱≠卖惨：要有可见的进步支撑
