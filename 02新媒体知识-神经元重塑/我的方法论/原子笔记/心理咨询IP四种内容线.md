# 心理咨询IP四种内容线

## 核心原则

**心理咨询IP四条内容线：人物故事线主攻转化、观点输出线拉新客、专业背书线建立权威、用户共鸣线保持生命力。四线配合运转，不是四选一。**

## 触发信号

- 心理咨询IP内容单一（全是观点或全是故事）
- 不知道内容结构怎么排
- 新客进不来或老粉留不住

## 操作方法

| 内容线 | 作用 | 做法 |
|--------|------|------|
| A 人物故事线（主攻线） | 转化 | 小传不是一次性讲完，拆成4-6条视频，每条一个完整情绪起落 |
| B 观点输出线 | 拉新客 | 有争议性的话题："女强人的婚姻到底能不能幸福""体制内年轻人怎么不废掉" |
| C 专业背书线 | 建权威 | 证书+职场经历=双背书；但不做"专家科普"，做"我用这个方法救过自己" |
| D 用户共鸣线 | 保持生命力 | 读用户留言、讲用户故事——心理咨询IP的生命力在"被看到" |

**人物故事线拆条示例**（若溪小传）：
- 01：我给自己的创造力找了一个新地方（辞去领导职务）
- 02：我觉得他配不上我（婚姻冲突）
- 03：我是强势女人，但我的婚姻越来越好（婚姻和解）
- 04：在体制内活出自己（职场感悟）

**配比思路**：观点输出线拉新客（流量入口），人物故事线做转化（信任出口），专业背书线托底（权威感），用户共鸣线续命（互动与留存）。

## 边界

- 故事必须真实——虚构人设是自杀
- 体制内转型IP：不攻击体制、不说具体人物、把经历抽象成"人生故事"而非"工作汇报"
- 四线权重按IP类型调整：素人过来人型偏故事线，强势型偏观点线
