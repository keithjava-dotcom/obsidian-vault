# 强势型IP内容打法

## 核心原则

**不要压制强势，要引导强势——强势表达是稀缺资产，用结构框住它而不是收着它。逐字稿不是让她念的监狱，是给她画的边界。她有内容，缺的是新媒体语法。**

## 触发信号

- IP"太能讲"（一条视频能即兴讲20分钟）
- 内容有攻击性、有力量但散
- 担心强势表达会得罪人，想让她"收着点"

## 操作方法

**强势型 vs 温和型对照**：

| 维度 | 强势型（若溪） | 温和通透型（菲菲） |
|------|---------------|-------------------|
| 开头方式 | 直接怼脸，不铺垫场景 | 场景+情绪切入 |
| 语言节奏 | 快、有攻击性、不解释 | 慢、娓娓道来、有留白 |
| 金句风格 | 短刀型——「我觉得他配不上我」 | 温润型——「爱是我懂你」 |
| 内容主色 | 冲突→和解（有张力） | 觉察→成长（有温度） |
| 镜头表现 | 天生口播者，需要减 | 需要情绪引导，需要加 |

**"太能讲"客户的处理流程**：
1. 先让她对着镜头自由讲20分钟（素材）
2. 从素材里提炼逐字稿（结构）
3. 逐字稿给她——不是让她念，是给她边界
4. 保留她的语言习惯和即兴感（在气口和段落上做控制）

**核心策略**：
- 不压制强势：攻击性+直接感是她的辨识度
- 用结构框住表达力：逐字稿=边界，不是监狱
- 强势IP最怕剪辑"把空填满"——她说话有力，停顿更有力，敢留白

## 边界

- "强势"在哪个点上会变成"让人不舒服"，边界还在探索——需要在每条内容里重新确认
- 体制内身份的安全边界：不攻击体制、不说具体人物、把经历抽象成"人生故事"
- 强势打法不适用于所有IP——若溪天生口播者才需要"减"，表达力弱的IP要"加"
