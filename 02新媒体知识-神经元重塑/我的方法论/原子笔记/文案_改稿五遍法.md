# 改稿五遍法

## 核心原则

**边读边改三到五遍，每遍聚焦一件事。第一遍改内容对不对，第二遍改顺不顺口，第三遍改画面感，第四遍改节奏，第五遍通读定稿。**

## 触发信号

- 初稿写完不知道下一步
- 一稿就想交付
- 改稿没有章法（一次想改所有问题）

## 操作方法（五遍各聚焦）

1. **可视化**：be→do（"是什么"变"做什么"），there be句式
2. **专属细节**：加时间/地点/职业/数量（故事感=特定感）
3. **故事感**：人与人的纠纷（"什么人干什么事"，解释不清就打比方）
4. **尖峰时刻**：冲突瞬间/生理反应/临界点/压力叠加
5. **节奏感**：押韵/排比/顶针/长短句，多用短句一逗一义

## 边界

- 每遍只做一件事，别一次改完（会乱）
- 改完必须念出声（念不通=没改完）
