# 拍摄教学_大动作拆小动作法

## 核心观点

拍摄的本质不是"拍什么"，而是**把每一个大动作拆解成一连串小动作**。拆得越细，越知道怎么拍。

柯建军原文：你把每一个行程都拆分成小步，记住这个核心原则，你就知道怎么去拍了。

## 方法

1. **列出大动作**：比如"从大连飞杭州"
2. **拆成小步**：出发→取票→过安检→候机→上飞机→起飞→等待→下飞机→打车→到酒店→前台→进房间
3. **每个小步对应景别**：远景（交代环境）→ 特写（给细节）→ 远景 → 特写 → 交替推进

## 实战示例

| 步骤 | 可拍内容 | 景别建议 |
|---|---|---|
| 出发 | 机场、人与环境关系 | 远景（0.5倍） |
| 取票 | 手拿机票 | 特写 |
| 过安检 | 安检过程 | 中景+跟拍 |
| 候机 | 机票特写、座位上等待 | 中景+特写 |
| 上飞机 | 找座位、坐下 | 跟拍 |
| 起飞 | 窗外 | 远景 |
| 等待 | 看书/看窗外 | 中景 |
| 下飞机 | 到达 | 远景 |
| 打车 | 出租车窗外杭州街景 | 中景 |
| 到酒店 | 酒店外观 | 远景 |
| 前台 | 领房卡 | 特写 |
| 房间 | 环境、灯、床单、摆饰 | 远景+特写 |

## 公式

> 大动作 → 拆小步 → 远景+特写交替 → 画面有张力

## 适用范围

- 旅行vlog、探店、日常记录、事件类内容
- 特别适合不知道"拍什么"的初学者
