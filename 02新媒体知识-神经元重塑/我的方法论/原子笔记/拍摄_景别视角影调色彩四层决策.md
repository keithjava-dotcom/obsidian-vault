# 景别→视角→影调→色彩四层决策

## 核心原则

**处理顺序：先景别 → 视角 → 影调 → 最后色彩（色彩不强化前三者就是干扰）。影调优先级最高。**

## 触发信号

- 拍摄前不知道用什么镜头
- 画面情绪不对
- B-roll/口播机位决策

## 操作方法

**①景别**：
- 特写=动作功能+衔接动作 / 近景=口播最佳 / 中景=对话与人物关系 / 全景=全身动作 / 远景=定场
- 景别交替产生节奏：由远及近递进至少3镜头；跳景别=快节奏；相邻交替=平缓

**②视角**：
- 平拍=客观中性 / 倾斜=失衡焦虑 / 俯角削弱人物力量 / 仰角增强力量压迫
- 主客观视角反复切换=画面丰富感

**③影调**（优先级最高）：低调=负面情绪 / 高调=正面情绪 / 中间调=客观叙事

**④色彩**（最后）：不强化前三者就是干扰

## 边界

- 单镜头单独无意义，只为适配文案
- 取舍原则：确认分镜头功能后用最小景别装进去
