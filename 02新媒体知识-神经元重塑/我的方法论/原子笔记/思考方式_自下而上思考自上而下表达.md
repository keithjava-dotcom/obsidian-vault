# 思考方式：自下而上思考，自上而下表达

你脑子里先有碎片，再往上找主题——但说出来的时候，先甩主题，再拆碎片。

## 核心机制

写作/创作时脑子里的实际过程是**自下而上**的：
先有一堆零散想法 → 归类分组 → 抽象概括 → 找到核心主题

但表达的时候必须反过来，**自上而下**：
先抛出主题 → 分层展开 → 用碎片论证

你已经在用这套路，只是没叫这个名字。

## 动作步骤

### 思考阶段（自下而上）

**第一步：倒碎片**
把关于这个话题的所有想法都写下来。不管多碎、不管顺序。

**第二步：归堆**
找共同点，归成2-3堆。每堆用一个词概括。

**第三步：往上抽主题**
这2-3堆在说什么？往上再抽象一层——这就是你的核心观点/视频主题。

### 表达阶段（自上而下）

**第四步：先甩结论**
视频第一句话就是核心观点。不是铺垫，不是背景。

**第五步：分层展开**
结论 → 分论点1 → 论据 → 分论点2 → 论据 → 分论点3 → 论据

**第六步：结尾回扣**
回到核心观点，给行动指令或情绪收尾。

## 你自己的工作流就是这个

你日常把灵感倒进 `06日常灵感/`，需要做视频时从里面捞碎片 → 归类 → 提炼主题——这就是**自下而上的思考**。

写稿子时上来就说核心观点 → 拆3点论证 → 收尾——这就是**自上而下的表达**。

## 在客户工作里怎么用

**帮客户提炼视频主题：**
让客户先说说最近想聊什么（倒碎片） → 你帮他归类 → 抽出一句核心主题 → 再反推用什么素材支撑

**帮客户改混乱的文案：**
先看他说了哪些点 → 归堆 → 找主题 → 重新用自上而下的顺序重构

**做企业咨询报告：**
访谈/调研阶段是自下而上的（收集散乱信息）→ 写报告是自上而下的（结论先行，再逐层展开）

## 常见错误

**思考自上而下了：** 还没倒碎片就想"我要做一条关于XX的视频"——然后强行往这个框里塞素材，视频会很空。

**表达自下而上了：** 把碎片思考过程直接讲出来——"我当时想到了A，然后又想到B，不过B跟A有点矛盾，后来我发现其实……"——观众不想跟你一起思考，他们只想要结论。
