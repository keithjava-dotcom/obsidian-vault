# 成交节奏：不要等，不要恐惧

## 核心原则

**成交节奏两条铁律：马上跟进，不要等——等三个月，客户就找别的老师了；大胆成交，别恐惧——恐惧时客户能感觉到，退一步去分享，别硬上。**

## 触发信号

- 谈完客户迟迟不跟进，想"再等等"
- 成交前犹豫不决："了解得还不够""再准备准备"
- 报价绕弯子，不敢明码标价

## 操作方法

**不要等（节奏）**：
1. 马上跟进，别等三个月以后再跟——人家找别的老师了
2. 引导式提问：不要总听他讲什么，你要知道你想要什么。他讲能把祖坟刨出来给你讲一遍还没用，按你的方式引导他找到你想要的答案
3. 操作流程：问他来干嘛（很多人说"我不知道我卡哪了"）→ 你给他捋（钱够吗？感情好吗？身体好吗？）→ 落到你能解决的那个问题上 → 说"那你给我修一下"——产品卖出去了

**不要恐惧（心态）**：
1. 不突突，别恐惧。恐惧时不要成交——退一步，去跟他分享。客户能感觉到你的恐惧
2. 别挑人，也别觉得了解得不够——先成交一轮再说
3. 明码标价，别绕弯子——"谁跟你呜呜轩轩的讲讲事？"
4. 对产品极度信任——你自己学了你受益了，才能成交别人
5. 乐观主义拼概率——"概率多了，捡都能捡两只"（香港粉丝案例：加好友聊1小时，直接"来，买9800"，钱不够转5000等开工资，成交不到10分钟；后续又买2万，每天转2000）

## 边界

- 节奏快 ≠ 逼迫——前提是"信念+用心+不怕"三件套齐了
- 专业型客户直接上，关系型客户先走心（见信任卡）
- 恐惧时的"退一步分享"不是放弃，是换个姿态继续
