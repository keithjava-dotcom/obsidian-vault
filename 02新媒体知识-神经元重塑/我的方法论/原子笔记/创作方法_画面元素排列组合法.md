# 创作方法_画面元素排列组合法

## 核心观点

景别、构图、视角、运镜——四种画面元素可以像乐高积木一样自由排列组合，创造无限可能。

柯建军原文：景别、构图、视角、运镜——这四种是可以融合的，跟乐高一样，可以排列组合。任何一个知识点我们都可以去排列组合去创造更多。

## 四元素清单

| 元素 | 选项 |
|---|---|
| 景别 | 远景、中景、近景、特写 |
| 构图 | 居中、三分、前景（+引导线、框架、对称、对角线） |
| 视角 | 第一视角、第二视角、第三视角（+上帝、航拍） |
| 运镜 | 推、拉、摇、移、跟 |

## 组合示例

- **简单组合**：特写 + 居中 = 产品展示
- **叙事组合**：远景(交代环境) → 跟拍(走进) → 中景+三分(坐下) → 特写+推(咬一口)
- **创意组合**：第一视角 + 移 + 前景 = 沉浸式逛街

## 核心原则

1. 不要一直把手机架在那里不动——会单调死板
2. 每切换一个步骤，可以考虑换一个元素（景别变→构图变→视角变→运镜变）
3. 初学者先保证"远景+特写交替"就有基本张力
4. 水平提高后，任意组合创造自己的风格

## 适用范围

- 所有短视频拍摄
- 教学场景：让初学者快速理解"为什么我的视频很单调"
