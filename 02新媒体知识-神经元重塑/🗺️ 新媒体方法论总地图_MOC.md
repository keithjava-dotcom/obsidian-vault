## 三个老师的独特贡献

**花火商学院擅长：**
系统性定位框架（账号定位五要素、竞争力六字箴言）、选题工作流（需求库+解决方案库）、变现路径设计（变现三角+私域转化）、内容框架（开头五种钩子+结尾CTA）。适合做系统性知识体系的人。

**谈梦知老师擅长：**
视频生产的完整技术体系（声音优先→五步流程→对白/独白/旁白→景别/视角/影调/色彩/焦段）、账号搭建三阶段的具体指标、自媒体vs流媒体的判断标准、互动机制设计。适合做视频创作的人。

**舒老师擅长：**
文案底层逻辑（文字vs文案、三个留存物、自嗨vs它嗨）、卖点分析框架（竞争优势三层+需求规模三层）、受众分析（购买者vs使用者、标签化分类法）、EIOR调研法。适合做产品文案和品牌定位的人。

## 待我判断的冲突观点

- [x] ✅ **情绪是"唯一"度量衡 vs 三个留存物**：谈梦知说情绪是短视频唯一的度量衡；舒老师说文案要留下情绪共鸣+身份认同+行为引导三样东西。两者侧重不同——谈梦知偏流量逻辑，舒老师偏文案功能逻辑。→ [[我的方法论/原子笔记/思考方式_情绪是内容的底层驱动力]]
- [x] ✅ **开头钩子：5种类型 vs 2个维度**：花火的开头五种钩子类型（利益/悬念/冲突/共鸣/反常识）vs 舒老师的标题两个维度（意外感+收获感）。两套框架整合为7种钩子类型。→ [[我的方法论/原子笔记/思考方式_钩子七种类型整合]]
- [x] ✅ **需求是真实存在的 vs 需求是被引导出来的**：花火说选题要从真实需求出发；舒老师说消费者的需求大多数是被商家引导的。→ [[我的方法论/原子笔记/思考方式_需求真实存在但需要被唤醒]]
- [x] ✅ **声音是"第一位" vs 情绪是"唯一度量衡"**：谈梦知说声音是视频创作的第一位，同时说情绪是唯一度量衡。声音是载体，情绪是目标，不矛盾。→ [[我的方法论/原子笔记/思考方式_画面声音文字三位一体]]
- [x] ✅ **人设型账号适合知识付费 vs 知识付费看信任深度**：谈梦知说人设型适合信任产品浅交付；花火说知识付费看信任深度。信任感是一切变现的前提，路径不同但目标一致。→ [[我的方法论/原子笔记/思考方式_信任感是一切变现的前提]]
