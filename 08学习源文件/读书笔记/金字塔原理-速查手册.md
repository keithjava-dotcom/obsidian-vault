## 一、核心公式

### 金字塔结构一句话

**结论先行，以上统下，归类分组，逻辑递进。**

先重要后次要，先总结后具体，先框架后细节，先结论后原因，先结果后过程，先论点后论据。

### 三种子结构

| 子结构 | 作用 | 怎么用 |
|--------|------|--------|
| **纵向关系** | 疑问回答式对话 | 每个表述引发读者疑问 → 下一层回答 → 再引新疑问 |
| **横向关系** | 演绎或归纳推理 | 演绎 = 三段论；归纳 = 找共性归类 |
| **序言结构(SCQA)** | 讲故事吸引读者 | 背景 → 冲突 → 疑问 → 回答 |

### SCQA 公式

```
S（背景）：读者已知的事实
C（冲突）：发生了什么变化/问题
Q（疑问）：读者脑中产生的疑问
A（回答）：你的核心观点
```

> 短视频钩子不是大喊大叫，是用 SCQA 勾起读者想知道答案的欲望。

## 二、三种逻辑顺序（检查任何一组思想的工具）

| 顺序类型 | 使用场景 | 排列规则 |
|----------|---------|---------|
| **时间顺序** | 描述过程/步骤/行动 | 按发生先后：第一步 → 第二步 → 第三步 |
| **结构顺序** | 描述整体与部分/空间关系 | 按地图/示意图顺序，模拟读者视角 |
| **程度顺序** | 按重要性/优先级排列 | 从最重要到最次要 |

### 时间顺序自检法

假设自己执行每一步，看：这一步是为了下一步铺垫，还是它就是下一步？如果是铺垫，它们不在同一层级。

### 结构顺序自检法

你画图的时候按什么顺序画，就按什么顺序讲。按读者的观看顺序，不按你的理解顺序。

## 三、MECE 原则（分类自查清单）

**两句话：不重叠，不遗漏。**

每次分类时间自己两个问题：
1. 有没有东西能同时被分进两个类别？ → 有 = 不独立，重分
2. 有没有东西哪个类别都放不进去？ → 有 = 不穷尽，补一个

> MECE 是思考方式，不是用完就放的工具。你在做客户分类、选题覆盖、团队分工时已经在用，只是没叫这个名字。这本书的价值是给你一个名字，下次教员工就能说清"为什么你的分类有问题"——不是「我觉得乱」，而是「你这几个类别有重叠，而且漏了一类」。

## 四、写作/表达行动清单

### 写之前的自检

1. **读者是谁？他们想知道什么？**
2. **中心思想一句话能说清吗？**（金字塔顶端的主语+谓语）
3. **分几步/几个方面来支撑？**（关键句，3~5个，别超过7个）
4. **每组思想用哪种逻辑顺序？**（时间？结构？程度？）
5. **分类 MECE 了吗？**（不重叠、不遗漏）

### 写之中的自检

- 每段第一句是不是该段的结论？
- 这段话回答了读者上一个疑问吗？
- 读完后读者会产生新的疑问吗？下一段回答了吗？

### 写完后的自检

- 把各段关键句抽出来排成目录，逻辑通吗？
- 有没有缺哪一步？（用 MECE 穷尽检查）
- 有没有啰嗦重复的？（用 MECE 独立检查）

## 五、管人/沟通行动清单

### 检查别人汇报乱不乱

1. 把他列的 N 条理由逐条拆开
2. 归类：哪些说的是同一个事？
3. 找上层主题：这几类合起来想表达什么？
4. 用 MECE 检查：缺没缺？有没有重叠？
5. 用结构顺序排一遍

> 以前觉得别人汇报「乱」是一种感觉，现在有工具了。

### 帮员工理清表达

员工说了一堆，你帮他做：
1. 找结论：你到底想说哪一句话？
2. 找原因：支撑这一句话的理由有哪些？
3. 排顺序：这些理由按时间讲还是按重要性讲？
4. 查遗漏：还有没有没说的？

## 六、经典案例速览（一句话记住）

| 案例 | 问题 | 关键方法 |
|------|------|---------|
| 改会议时间 | 约翰说了一堆没人听懂 | 结论先行：周四上午11点开，然后列三个理由 |
| 零售价调查 | 数据采样不准 | 主题句先出，下面列具体改法 |
| 电子档案管理 | 要不要上电子档案 | 结论：近期不适合。理由分决策者、成本、员工三个维度 |
| 饮料企业塑料瓶 | 11条理由说服力不够 | 归类后只剩5个因素，还漏了一个有利因素 |
| 西奈沙漠地图 | 介绍顺序混乱 | 按读者看地图的顺时针顺序介绍 |

## 七、柯哥的关键洞察汇总

1. **思想 = 向受众发送新信息并引发疑问的语句**。做自媒体、开会、写方案，本质都是这个。
2. **写作能力 ≠ 手写**。脑子里先想清楚的过程就是写作能力，嘴比脑子快就是胡说。
3. **改变写作风格像学打字**，要大量重复练习。成年人没时间，但有意识地练就能改。
4. **短视频钩子的本质**：用 SCQA 勾起读者想知道未知信息的欲望。
5. **金字塔原理不是学完就提高**。粗读一遍口才写作没明显提升，但思考力和全局观有进步。精读目标是提升表达。
6. **陌生知识最有效的练习方式**：用自己的行业案例替换书里的案例。把「轮胎部、硬件部」换成「年轻夫妻、有娃家庭、老人家庭」。
7. **MECE 你早就在用**。做客户分类、列选题时已经在归类检查，这本书只是给你一个名字。

## 八、常见错误速查

| 错误 | 表现 | 修正 |
|------|------|------|
| 仅用同一名词概括就放一组 | "五个问题""十个步骤"但之间没逻辑 | 追问共性到底是什么，用三种逻辑顺序之一重组 |
| 结论句没有思想性 | "公司存在某个问题" → 等于没说 | 结论必须是有观点的判断句 |
| 原因和结果混在同一层 | 行动步骤里夹着行动结果 | 时间顺序自检：这一步是为了铺垫还是就是下一步？ |
| 超过7条不分组 | 列了8个步骤把人看晕 | 超过5条就归类分组，提取子过程 |
| 分类有重叠 | 年轻夫妻 / 高收入家庭 / 有房一族 → 全重叠 | MECE独立检查 |
| 分类有遗漏 | 上衣、裤子、袜子分好了，围巾还在地上 | MECE穷尽检查，补遗漏的类别 |

## 九、一句话速记口诀

> **先结论，后原因。先重要，后次要。分三组，不超七。不重叠，不遗漏。问自己：读者看完这段，下一个疑问是什么？**
