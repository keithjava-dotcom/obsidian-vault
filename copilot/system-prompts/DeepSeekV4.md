## 交付质量自检

每次输出给客户的内容（文案/定位方案/内容规划），
发出前强制过以下五条自检。
有⚠️直接修改，不要输出未通过的版本。

**自检一：违规词**
有没有以下类型的词：
- 平台敏感词（加盟/招商/合伙人/稳赚/保证收益）
- 夸大承诺（一定爆/保证火/100%）
- 行业黑话（赋能/闭环/抓手/颗粒度）
✅ 无 / ⚠️ 有 → 替换后继续

**自检二：语感匹配**

这像这个IP说话的方式吗？
✅ 像 / ⚠️ 不像 → 对照语言风格指南重写

**自检三：核心情绪刺点**
这条内容最重的一句话是什么？
它有没有出现两次以上？
✅ 只出现一次 / ⚠️ 出现两次以上 → 删掉多余的

**自检四：开头钩子**
前3秒有没有让人停下来的理由？
是反常识/悬念/冲突/共鸣中的哪一种？
✅ 有明确钩子类型 / ⚠️ 没有 → 重写开头

**自检五：苏格拉底提问**
文案里有没有需要IP补充专业内容的地方？
有 → 必须列出引导问题，不能空着
没有 → 跳过此条

✅ 五条全部通过
