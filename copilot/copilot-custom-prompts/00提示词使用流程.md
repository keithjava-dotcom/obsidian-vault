# 服务客户提示词使用流程

## 使用说明
这是整个客户服务系统的导航文件。
每个阶段该用哪个指令，看这里。

---

## 完整服务流程

### 阶段一：接到新客户

**第一步：发问卷收集信息**
→ 打开：01账号定位信息收集问卷.md
→ 发给客户，让他填写
→ 收回答案后存入：
  04服务客户/[城市]/[客户名]-[领域]/01-原始素材.md

**第二步：做账号定位**
→ 打开：02客户账号定位·Claudian标准执行指令.md
→ 替换客户名/城市/领域
→ 发给Claudian执行
→ 输出：02客户分析 + 03定位方案 + 04语言风格指南
         + 05内容规划初版 + 06复盘记录(空) + 07沟通记录(空)

---

### 阶段二：日常服务中

**每次和客户沟通完**
→ 打开：06客户沟通记录更新指令模板.md
→ 替换客户名+城市+领域+日期
→ 粘贴聊天要点
→ 发给Claudian
→ 它自动判断并更新相关文件

**需要挖掘更多素材时**
→ 打开：04素材挖掘指令模板.md
→ 替换客户信息
→ 发给Claudian生成开放式提问清单
→ 把问题发给客户补充回答

**开始写视频文案时**
→ 确认04-语言风格指南.md已存在（没有先做定位）
→ 打开：03文案执行指令模板.md
→ 替换客户名+选题
→ 发给Claudian执行

---

### 阶段三：企业客户（非个人IP）

**做内容规划时**
→ 打开：05企业内容规划指令.md
→ 替换企业名+行业+项目背景
→ 发给Claudian执行

---

### 阶段四：视频发布后（复盘）

**看完数据之后**
→ 暂时手动复盘（复盘执行指令待建）
→ 把复盘结论存入：06-复盘记录.md

---

## 指令对应关系速查

| 我要做什么 | 用哪个指令 |
|-----------|-----------|
| 给新客户发问卷 | 01 账号定位信息收集问卷 |
| 做账号定位分析 | 02 客户账号定位执行指令 |
| 写视频文案 | 03 文案执行指令模板 |
| 挖掘更多素材 | 04 素材挖掘指令模板 |
| 企业客户内容规划 | 05 企业内容规划指令 |
| 每次沟通后更新档案 | 06 客户沟通记录更新指令 |
| 视频发布后复盘 | 待建 |

---

## 注意事项

**素材不足不能做定位**
01-原始素材.md 少于800字 → 让客户继续补充问卷
多于800字 → 才能启动定位流程

**语言风格指南是文案的前提**
没有04-语言风格指南.md → 不能写文案
先做定位，再写文案

**客户档案是活的**
每次沟通后必须更新
不更新 = 定位方案和语言风格指南会过期
