# 日式排版操作手册：原理到封面的全套技法

> 整理自"阿托的Artopia狂想"视频碰撞 + 系统设计知识。
> 定位：柯哥做短视频封面时的速查参考。

---

## 一、三个底层原理

| 原理 | 日文原词 | 一句话 |
|------|----------|--------|
| 空白是主角 | 間（ま） | 留白不是省空间，留白本身就是内容 |
| 减到骨头 | 引き算 | 不是"还能加什么"，是"还能删什么" |
| 不对称才活 | 不均斉 | 对称是死的，不对称才有视觉张力 |

---

## 二、文字：封面最直接能用上的六招

### 1. 字重差距拉到5倍以上
- 标题用最粗字重
- 其他所有字用最细字重
- 粗细差距越大，画面越"日式"

### 2. 手动调字间距
- 封面标题3-5个字：字间距拉开到字号的15%-25%
- 默认间距=廉价感，拉开间距=设计感
- 这在中文设计里是最被忽略的

### 3. 字体不超过2种
- 主标题：一种粗字体
- 辅助信息：另一种细字体
- 如果只有一种字体，用大小和粗细做层次

### 4. 混搭字体的窍门
- 中文可以"黑体（关键词）+宋体（辅助词）"模拟日文"汉字+假名"的节奏
- 不要把两种相似的字体放一起——要反差

### 5. 竖排标题
- 偶尔用一次竖排放在画面左或右侧1/3处
- 中文竖排天然带有"古典+高级"的联想

### 6. 文字不要居中
- 居中是最安全、最无聊的对齐方式
- 左对齐是日式的默认选择

## 三、构图：三个模板直接套

### 模板一：对角分割
```
┌─────────────────┐
│                 │
│    留白区       │
│   （放标题）    │
│                 │
│        ╱        │
│      ╱  人物    │
│    ╱   或产品   │
└─────────────────┘
```
对角线把画面劈成两块：一块留白放字，一块放图。

### 模板二：框内文字
```
┌─────────────────┐
│                 │
│    全屏照片     │
│   （降饱和）    │
│   ┌──────┐     │
│   │ 标题 │     │
│   └──────┘     │
│                 │
└─────────────────┘
```
照片做底，文字放在一个半透明框或细线框里。

### 模板三：极端留白
```
┌─────────────────┐
│                 │
│                 │
│   一条大标题    │
│                 │
│   一行小字      │
│                 │
│                 │
└─────────────────┘
```
画面只放文字，不放图。无印良品风格。适合观点型、金句型封面。

## 四、配色：三套现成方案

### 方案A：黑白+一个强调色
- 背景：白/浅灰/生成色（米白）
- 主文字：黑
- 强调元素：一个高饱和色（红、蓝、黄任选）
- 比例：70%白 + 25%黑 + 5%强调色

### 方案B：低饱和双色
- 背景：低饱和暖色（驼色、米黄、鼠尾草绿）
- 文字：深棕或深灰（不要纯黑）

### 方案C：黑白照片+白字
- 背景：黑白照片（对比度降低20%）
- 文字：白色，加一点点阴影

---

## 五、几何元素：让画面"有设计感"的秘密

- **0.5pt极细线**：一条横线或竖线穿过画面，分割上下或左右
- **空心圆**：在文字旁边画一个空心小圆圈
- **小方块**：在标题前面放一个颜色小方块，像列表符号但更大
- **斜线**：30-45度斜线切割画面

这些元素本身不传达信息，但能让画面从"文字+图片"变成"设计"。

## 六、照片处理：别裸放

| 处理方式 | 操作 | 效果 |
|----------|------|------|
| 降饱和 | 饱和度 -20~30% | 颜色更克制，不抢文字 |
| 降对比 | 对比度 -10~15% | 方便在上面叠白字 |
| 加滤镜 | 暖色调+褪色 | 日系复古感 |
| 黑白化 | 直接转黑白 | 叠什么都好看 |
| 裁切 | 不追求完整 | 敢把主体切一半，设计感+1 |

## 七、短视频封面的日式套路速查表

| 问题 | 日式解法 |
|------|----------|
| 字太多 | 删到只剩核心词 |
| 颜色太花 | 降到2-3个颜色，加一个留白 |
| 不留空 | 标题四周留至少一个字的间距 |
| 居中呆板 | 改左对齐，画面立刻活 |
| 字太密 | 行距拉到1.5倍，字间距拉开15% |
| 照片抢字 | 降饱和，叠白字，或局部模糊 |
| 没设计感 | 加一条细线、一个空心圆、一个小方块 |
| 颜色刺眼 | 纯黑改深灰，纯白改米白 |
