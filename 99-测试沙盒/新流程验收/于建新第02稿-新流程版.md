# 于建新 · 第02稿 · 刑警首案·抛尸（新流程版）

## 🎬 封面标题建议

**候选1**：我第一个现场，是抛尸案
**候选2**：BP机、212吉普的年代，刑警靠什么破命案
**候选3**：第一次出现场就是抛尸。后来我才知道，那一课有多重。

**封面文字**：前刑警·现刑事律师

**平台标题**：刑警学院毕业第一案：冰天雪地的抛尸案，没有监控的年代靠什么破的？

## 🧭 结构走线

```
尸体在郊外，不是第一现场
理由：开篇3秒建立身份——这个人是刑警出身，真干过，不是讲别人故事
引文：我毕业那年分配到刑警队。重案大队。第一个现场，抛尸。

那个年代什么都没有——BP机、212吉普，破案靠腿靠嘴
理由：时代感反差，让观众理解那时的刑警有多难——不是能力差，是工具少
引文：那个年代是什么年代。BP机。大哥大。刑警队最好的车是212吉普。

冰天雪地走访摸排，一根线索一根线索地拼
理由：画面感——观众能看见雪地、感受冷，相信那是真走过的路
引文：冒着刺骨寒风。冰天雪地里一家一家走访。一根一根线索地拼。

起因是一顿酒——一条人命，就这点破事
理由：戏剧反差——命案的惊悚和起因的日常，让案子一下变近了
引文：起因说起来你都不信——两个人喝酒。被打的那个人觉得伤面子。

现在坐辩护席，看的还是那几样——细节、矛盾、哪里不对
理由：兜底——这段经历不是回忆，是今天做律师的底层判断力
引文：现在我做刑事律师。坐辩护席上看案卷。看的还是那几样。
```

## ⚠️ 注意事项

**口气**：像在跟人回忆一段不再存在的时光。不是骄傲不是怀旧，是"我经历过，你现在没法经历了，我跟你说说"。带着一点淡淡的"你们不知道那个年代"。

**别拍成回忆录**：不是在讲"当年我多辛苦"，是在讲"当年我是这么干的"。节奏不要太慢，不要叹气，不要煽情。

**商业落点**：信任这个人的判断力。观众看完的感觉应该是——"这个人真干过，他看的案卷和当年看的现场是同一套东西。"

**拍摄提醒**：
- 语速偏慢，但不要拖。每句话之间有停顿，让信息落地
- 找一个真人坐在镜头后面跟他讲，不要读稿
- 手势自然——办案子怎么比划就怎么比划
- 眼神看人，别看镜头
- 说到"做警察没做过刑警"那句时有一点点笑，但立刻收住
- 说到喝酒起因时可以有一点点无奈，但不要渲染

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿

我毕业那年分配到刑警队。
重案大队。
第一个现场，抛尸。
尸体在郊外。
到了就知道——这不是杀人的地方。
地上干干净净。
没有血迹。
没有厮打的痕迹。
尸体是从别处运过来的。
这就是我当刑警办的第一起案子。
那个年代是什么年代。
BP机。
大哥大。
刑警队最好的车是212吉普。
领导才坐桑塔纳。
没有视频监控。
没有大数据。
破案靠什么。
靠腿。
靠嘴。
靠现场勘察提取痕迹物证。
靠挨家挨户走访排查。
那时候有句话——做警察没做过刑警，等于没干过警察。
还有一句——好人不愿干，坏人干不来。
但真干了，什么都能锻炼出来。
接着说这个案子。
那个季节天已经冷了。
冒着刺骨寒风，冰天雪地里一家一家走访。
同时发公告确认死者身份。
大量的摸排。
大量的走访排查。
一根一根线索地拼。
最后案子破了。
起因说起来你都不信——两个人喝酒。
喝着喝着闹矛盾。
一方把另一方打了。
被打的那个人觉得伤面子。
憋屈。
找了个机会。
把打他的人杀了。
杀了以后抛尸郊外。
就这么简单。
一条人命，起因就是喝酒这点破事。
你看，在没有监控、没有大数据的年代，破一个命案要跑多少路、找多少人、磨多少鞋。
现在技术方便了——调监控，查大数据，很多事一目了然。
但我回过头来看，在刑警队那些年给我的东西，是技术替代不了的。
看现场的时候，先看哪里不对。
查案子的时候，哪里说不通，哪里就藏着东西。
现在我做刑事律师。
坐在辩护席上看案卷。
看的还是那几样——细节、矛盾、哪里不对。
只不过当年是让有罪的人没地方躲。
现在是让不该重判的人不被冤枉。
