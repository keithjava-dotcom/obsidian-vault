# 新媒体短视频创作课 · 课表

> 不填鸭。36节课，每节你手里多一条片子、多一件家伙。课上完，号也起来了。

---

## 一、这门课怎么构成的：五边形

短视频创作不是一个一个知识点堆起来的——是一套动作。

```
                    选题
                   /     \
             大纲           逐字稿
             |    定位/心法    |
             声画 ————————— 复盘
```

**中间：定位/心法认知。** 不是"学完就过"的第一课，是全程垫在底下的东西。你是谁、拍给谁、凭什么是你、这条路往哪走——每一节都在加固这一层。

**外面五个角：选题 → 大纲 → 逐字稿 → 声画 → 复盘。** 一条片子的完整动作链。但课不是按这五个角一顺讲下来的——是交错铺开的，因为做片子不是"先学完选题再学大纲"。
