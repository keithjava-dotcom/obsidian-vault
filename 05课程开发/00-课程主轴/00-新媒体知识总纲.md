# 新媒体知识总纲

**全部柯哥主讲。** 
底下每块写的不是"谁来讲"，是这块的功夫柯哥融了哪几位老师的什么、又自己加了什么——因为柯哥就是听他们的课，一条一条做起来的。三位老师的知识，早就化进柯哥自己这套里了。

一条隐线：心法垫底，剩下的按一条价值链走——想清楚、有的拍、拍得好、发出去、赚到钱、越做越好。

## 一、五边形：这门课的总图（柯哥 2026-07-06 定）

前提先立住：**不填鸭**。新媒体知识系统非常大，硬塞没用——学习的目的是用出来，变成自己的技能。

总的说，新媒体短视频创作是一个五边形：

```
              选题
        复盘        大纲
          ┌─ 定位 ─┐
          │ 心法认知 │
          └────────┘
        声画       逐字稿
```

- **中心**：定位 / 心法认知层
- **五条边**（就是五棒流水线）：选题 → 大纲 → 逐字稿 → 声画 → 复盘，复盘反哺选题，循环转
- 与五棒同构：中心=dingwei，五边=xuanti / dagang / fanwen / b-roll / fupan——课程教的就是柯哥每天真实干活的产线

**36 节按五边形归位**：

| 归属 | 节 | 数量 |
|---|---|---|
| 中心 · 定位/心法认知 | 1、2、3、26、29、30 | 6 |
| 选题 | 4、5、28 | 3 |
| 大纲 | 6、7、8、9、10、11 | 6 |
| 逐字稿 | 12、14、19、20、27、34 | 6 |
| 声画 | 15、16、17、18、21、22、23、24 | 8 |
| 复盘 | 13、25、31、32、33、35、36 | 7 |

（2026-07-06 柯哥 v4.0 亲定归属：开头/钩子/痛点归大纲——架子阶段的设计；密度/成交归逐字稿——落笔的功夫；排期和操盘/代表作/毕业三节归复盘——数据闭环收官。不设"综合"类。每节归它主要发力的角，跨角是常态。）

节数分布即重心：声画 8 节、复盘 7 节最厚，大纲/逐字稿各 6 节。变现没有独立的角，是一条暗线：26（中心·认知）→ 27、34（逐字稿），符合"变现前置"。五棒对应：定位/心法=dingwei-report，选题=xuanti，大纲=dagang，逐字稿=fanwen+zuoye-dianping，声画=b-roll-plan，复盘=fupan。

**五边形与下面九块的关系**：五边形是顶层总图（柯哥的心智模型 = 教学与生产的形状）；九块是备课料的组织方式（九份融合底稿各挂一块）。映射：认知心法+定位→中心；选题→选题边；文案→大纲边+逐字稿边；拍摄+剪辑→声画边；复盘网感→复盘边；分发获客+变现成交→散作暗线织进各边。

## 三、每块分两层：先能做出来，再做得高级

这是从安先生课表偷来的排法——他把技法劈成"基本功篇"和"进阶篇"，同一个域走两遍。先让学生能拍出来，回头再教他为啥这么拍才狠。照搬。

| 板块 | 基本功层（先能做出来） | 进阶层（再做得高级） |
|---|---|---|
| **[[01-认知心法-融合底稿|认知心法]]** | 流量不等于价值、信息密度、八大特性、三种变现模式 | 信任红利、影响决策不是卖货、内容证据化、AI 协作公式、意义驱动、获客四阶段 |
| **[[02-定位-融合底稿|定位]]** | 定位五要素、人设、受众八字段（张小阳） | 竞争力六字（正反和跨入弱）、敌人哲学化、六种幸存者、买单人不等于观看人的双层人群 |
| **[[03-选题-融合底稿|选题]]** | 选题=需求×解决方案、建选题池、每条有赌注 | 需求四层金字塔（隐藏需求在评论区骂声里）、流量漏斗、热点五渠道 SOP、加时间限制 |
| **[[04-文案-融合底稿|文案]]** | 说人话（14 病症）、总分总加 100 字一单元、大纲架构 | 13 钩子、结构六推进、情绪刺点（三起三落）、痛点要痛、信息效率、防御式、每条藏个敌人 |
| **[[05-拍摄-融合底稿|拍摄]]** | 景别视角影调三步、空间调度、灯光、声音构成、录前进状态 | 用画面讲故事、名词动词可视化、情景化、表现力四层、叙事美学（时间的语法） |
| **[[06-剪辑-融合底稿|剪辑]]** | 剪映五步、BGM 起承转合、卡点 | 断裂感设计、进度条设计法、画面叙事逻辑、节奏 |
| **[[07-分发获客-融合底稿|分发获客]]** | 发布机制、埋搜索关键词、同城信息流基础 | 前置投流、私域和成交长链路、流量漏斗运营 |
| **[[08-变现成交-融合底稿|变现成交]]** | 三种变现模式、变现三角（流量×信任×产品） | 变现前置（定位时就想清楚）、信任内容、成交长链路、不尬带货 |
| **[[09-复盘与网感-融合底稿|复盘与网感]]** | 看完播、涨粉、评论，数据是反馈不是评判 | 预判对实绩、三维复盘、网感（看怎么说不看说什么）、拆对标账号 |

## 四、三位老师的知识，怎么化进你的课

全是你讲，因为你是听他们课做起来的。他们的知识在你这套里是这么分布的：

- **安先生**是你的全景骨架——认知、变现思维、定位、选题、流量漏斗、政治思维、叙事美学，整个架子的形状是他给的，你把它讲成了自己的话。
- **舒老师**是你文案里的深潜——尤其"受众分类"和"痛点对卖点"那一大块，安先生略讲的地方你补的是舒老师。注意舒老师那套是产品/详情页文案，你化进来的是他的受众和痛点思维，不是详情页的格式。
- **谈梦知**是你拍摄剪辑里的导演功夫——镜头、声音、画面叙事，你"用画面讲故事"的底子是他的。

**有两块，三位老师都没给透，是你自己趟出来加进去的：**

- **分发获客（第 7 块）**：安先生就一个"本地生活"特殊专题。你服务实体店老板，同城信息流是命根子，这块深度是你自己的。
- **复盘与网感（第 9 块）**：三位老师都薄。你原子卡里的"数据诊断三维复盘""预判对实绩"，这块的深度是你操盘攒的。

一句话：前七块你踩三位老师的肩膀讲，后两块是你自己站上去讲的。学员要只学前七块，去听安先生也行；你的不可替代，在后两块，也在于"这一整套是被你一个人融成一口气讲出来的"。

## 五、这张纲怎么用

1. **起课**：按九个板块排课，标题都照三位老师那个"一眼看懂"的调起（学完能干嘛，别玩概念）。同一块，基本功排前面、进阶排后面，别一次喂完。
2. **备课融合**：每块做一份"融合底稿"——你的主线为骨，把安/舒/谈相关的点焊进去，讲成你自己的话（每块一份底稿见同目录 01-09，文案见 `04-文案-融合底稿`）。
3. **补知识**：分发获客、复盘这两块是你顶的，也是知识库现在最薄的，优先把你的操盘经验沉淀成原子卡。
4. **对齐五棒**：这九块跟你现在的五棒流水线是同一套（定位/选题/文案对 dingwei/xuanti/dagang-fanwen，拍摄剪辑对 b-roll，复盘对 fupan），分发获客和变现是五棒之外该补进系统的两块。

## 六、九块怎么塞进 36 节（总课时不变）

（备课视角的粗映射；节次归属的权威分类以第一节五边形表为准——柯哥 v4.0 亲定。）

九块是"知识家谱"，36 节是"上课顺序"。课不是按块一顺讲下来的——按峰终定律和边学边起号的排法，九块是**交错**铺在 36 节里的，每节都产一条片。对照如下（每份融合底稿就是对应几节课的备课料）：

| 板块 | 落在哪几节 | 说明 |
|---|---|---|
| 认知心法 | 节 1 + 全程贯穿 | 开课第一节讲透，之后每节的"翻号"都在复利这层认知 |
| 定位 | 节 1、2、3、29、30 | 前面立定位，29/30 用竞争力六字和幸存者模型收长期活法 |
| 选题 | 节 4、5、13、28 | 4/5 建选题池，13 照数据补题，28 蹭热点 |
| 文案 | 节 6-12、14、16、19、20、33 | 最厚的一块，11 节，撑起第一二季主干 |
| 拍摄 | 节 15、16、17、18 | 进状态、可视化、分镜、拆动作 |
| 剪辑 | 节 22、23、24 | 断裂感、BGM、进度条 |
| 分发获客 | 节 21、28、32 | 封面埋搜索词、蹭热点、内容日历 |
| 变现成交 | 节 25、26、27、34 | 预判爆款、信任片、软带货、成交片 |
| 复盘与网感 | 节 13、25、32、35、36 | 读数据、预判对实绩、账号复盘、毕业 |

（节 31 全自主、节 36 毕业是"全武器合成"，不归单块。）

**总课时锁死 36 节，不加课。** 九块知识全在这 36 节里跑完，一节都不多。要压到 30 节或扩到 40 节，按 v3.0 课程表尾注那三根骨头不动的原则调，块的归属不变。
