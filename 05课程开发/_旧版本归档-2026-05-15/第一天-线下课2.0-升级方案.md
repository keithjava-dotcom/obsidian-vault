# 线下课2.0升级方案 | 基于5月12日首讲复盘

## 升级目标

把目前"七个模块+大量信息灌输"的模式，升级为：
> **每节课学生带着三个"马上能拍"的选题走，下节课带数据回来诊断。**

不牺牲"底座"的思维深度，但在底座上盖一层"开箱即用"。

---

## 一、课程结构重组

### 原结构（本次实讲）
```
平台认知 → 定位公式 → 人设三层 → 创作方法论 → 视频制作 → 投流矩阵 → 常见误区
```
**问题**：模块间串联弱，定位公式跳得太早，人设讲得散。

### 新结构（建议）
```
第一节课（2-3小时）：认知 + 定位 + 作业
  开场：平台认知（15min）
  决策：选平台（5min）          ← 新增
  定位：一句话公式（20min）
  人设：三层结构（30min）
  破冰：当堂拍第一条（10min）    ← 新增
  拆解：看3个同行号（15min）     ← 新增
  总结：发3条选题作业（5min）    ← 新增

第二节课：拆解 + 拍摄 + 诊断
  复盘：上节课发的3条数据分析
  拆解模板教学
  拍摄形式教学
  学生当场拍+当场改

第三节课：剪辑 + 投流 + 矩阵
  剪辑实操
  投流逻辑与实操
  矩阵搭建
```

### 关键变化

| 变化 | 原来 | 现在 |
|------|------|------|
| 定位公式位置 | 平台对比后立刻讲 | 加"选平台"桥梁后再讲 |
| 人设模块 | 跟案例、翻拍搅在一起 | 每层讲完当场让学生举例 |
| 当堂拍摄 | 没有 | 必做：拍15秒破冰视频 |
| 同行拆解 | 随口提 | 准备3个号当场拆 |
| 课后作业 | "回去想想" | 3条具体选题+参考模板 |

## 二、学生视角查漏补缺

### 补1：当堂破冰拍摄（10分钟）

**目的**：解决"我拍出来太别扭"的心理障碍。

**操作**：
1. 讲完人设三层后，让学生拿手机
2. 不给选题、不给脚本，就说："你用监控器视角拍一段你店里的日常，配一句话"
3. 拍完不看效果，存着
4. 告诉他："你看，你已经拍了第一条了。后面只会越拍越好。"
5. 这条不一定发，只用来破冰

**话术参考**：
> "你对着手机不会说话，但你会跟顾客唠嗑。所以你现在对着顾客说话，别对着手机说话。我减肥——你用监控器拍一段，你在后厨跟师傅说话，你在前厅跟客人打招呼。不用脚本，拍完再说。"

### 补2：三号当场拆解（15分钟）

**目的**：让学员"看到终局"，知道做成什么样算好。

**准备**：
- 一个同行业做得好的号（拆他的人设三层每一层怎么打的）
- 一个做得差的号（拆他哪里踩坑）
- 一个同城低粉但转化好的号（给信心）

**每号拆解维度**：
1. 主页第一眼看到什么？（头像、简介、封面）
2. 他的人设三层分别用哪条视频打的？
3. 开头钩子用什么类型？（自嘲/冲突/悬念/对比）
4. 这条为什么火/为什么不火？

**话术参考**：
> "你看这个号，粉丝才800，但每条视频5000播放。他做了什么？第一，他的定位够窄——只做企业团建烧烤。第二，他每条视频都在打一个点：实惠。不是口头说实惠，是用画面告诉你2000块能摆一桌子。这就是我们今天学的——你要做到的也是这个。"

### 补3：每节课必出3条选题

**目的**：学生课后不是"回去想想"，是"回去就拍"。

**选题格式**：
```
选题1：[标题/钩子]
- 打人设哪一层：经历/专业/客户故事
- 拍摄形式：口播/监控器/旁白/跟拍
- 参考模板：（给一条同行视频链接）
- 预计时长：30秒

选题2：...
选题3：...
```

**话术参考**：
> "下节课之前，你拍这三条。不管好坏，拍了就发。数据截图带过来。拍砸了比不拍强一百倍——因为你带了数据来，我才能帮你诊断。"

## 三、逻辑串联优化

### 每个模块之间加"一句话桥梁"

| 当前模块 | 下一模块 | 桥梁话术 |
|---------|---------|---------|
| 平台认知 | 选平台 | "好，你现在知道四个平台了。但你是做烧烤的，你该去哪个？我们先定战场。" |
| 选平台 | 定位公式 | "平台定了，现在你在这个平台上发什么？你总得先搞清楚——你是做什么的、卖给谁。" |
| 人设经历层 | 人设专业层 | "观众知道了你是谁，现在他得知道——你凭什么值得信任？" |
| 人设专业层 | 人设客户层 | "你自己说专业没用，得让别人替你说——接下来我们讲怎么借客户的口。" |
| 人设三层讲完 | 当堂拍摄 | "好了，你现在脑子里有三层内容了。先不急着全拍，我们先做一件事——你打开手机……" |
| 拍完 | 三号拆解 | "你刚拍了第一条。别急着评判好坏，我们先看看别人是怎么做的……" |
| 拆解完 | 作业 | "好，现在你知道怎么拍了，也知道做成什么样算好。下节课之前，你拍这三条——" |

## 四、案例弹药库建设

### 原则
- 每个模块讲一个通用案例（非学生本人行业），再让学生用自己行业套
- 覆盖柯哥已有客户行业：烧烤露营、家政、装修、美发
- 正面案例和反面案例各一半

### 案例分配表

| 模块 | 通用案例（讲课时用） | 学生行业（互动用） |
|------|-------------------|------------------|
| 选平台 | 美发店为什么选小红书（高客单价+强视觉）而非抖音 | 学生报自己行业→现场判断 |
| 定位公式 | 家政："独居老人在什么场景下需要什么样的保洁服务" | 学生用自己行业填公式 |
| 经历层 | 一冉家政：从工厂女工到家政老板的故事 | 学生讲自己的入行经历 |
| 专业层 | 装修：三招判断装修公司专不专业 | 学生讲自己行业的专业知识 |
| 客户故事 | 烧烤：工厂老板花2000给员工团建 | 学生回忆最近成交的一单 |
| 低粉爆款 | 找一条同城家政的低粉爆款拆解 | 让学生搜自己行业 |
| 反面案例 | 拿一个"画面精美但没人看"的号讲画质误区 | — |
| 反面案例 | 拿一个"天天发产品图"的号讲内容娱乐化 | — |

### 每个案例的标准结构
```
1. 一句话说清这个案例讲什么
2. 核心数据（播放量/粉丝数/点赞等关键数字）
3. 拆解：为什么好/为什么不好（关联课程理论）
4. 学生可以怎么模仿/避免
5. 耗时控制在3分钟内
```

## 六、课程定位

### 名字：**底座** ✅ 不变

柯哥决策："底座是个名词，所有人都熟悉。'操作系统''底层思维'这些词太AI了。"

**底座的内涵**：不是教招式，是帮学生建立一套"底层对自媒体的思考方式"。
- 平台认知 = 知道在哪儿玩
- 定位公式 = 知道我是谁、卖给谁
- 人设三层 = 知道怎么让人信
- 测试循环 = 知道怎么越做越好

七个模块 = 一套思维系统，核心是**底层思考方式**，不是操作步骤。

### 上课模式：灵活一对一 ✅ 不变

不搞固定三节课序列。保持现在的一对一灵活模式。内容骨架（七个模块）稳定，但根据学生行业、进度、互动随时调整顺序和深度。
