# 线下课结构化整理 | 2026-05-12

## 课程结构总览

```
第一模块：平台认知 → 搞清楚在哪儿玩、怎么玩
第二模块：定位公式 → 一句话说清你是谁、卖给谁
第三模块：人设建立 → 三层结构建立信任
第四模块：内容创作 → 从思路到落地的完整链路
第五模块：视频制作 → 三要素 + 测试循环
第六模块：投流与矩阵 → 放大和复制
第七模块：常见误区 → 避坑指南
```

## 第一模块：平台认知

### 1.1 自媒体本质
- **核心在"自"**：先有人（个人或团队），再谈媒体（传播）
- **与传统媒体本质区别**：自媒体内容是自己**创作**出来的，传统媒体是**报道**已发生的事
- 信息流广告是把已有的商品用流的形式推出去，不是内容创作

### 1.2 四大平台对比

| 维度 | 抖音 | 小红书 | 快手 | 视频号 |
|------|------|--------|------|--------|
| 核心人群 | 年轻人、行业大咖 | 30-40岁女性/白富美 | 三五线城市/娱乐大众 | 40-60岁 |
| 内容调性 | 创意、脑洞、专业深度 | 实用、精致、高审美 | 娱乐、八卦、接地气 | 慢节奏、沉稳 |
| 粉丝价值 | 泛粉多 | 单个粉丝价值最高（≈50个抖音粉） | 娱乐粉 | 私域转化强 |
| 流量机制 | 标签+算法推荐 | 搜索+推荐 | 同城+社交 | 社交裂变+私域 |
| 当前趋势 | 2025起下滑，越来越卷 | 稳定增长 | 平稳 | ⬆️ **风口**（微信生态闭环） |

### 1.3 视频号为什么是风口
- 微信生态：朋友圈→私域→视频号，闭环完整
- 社交裂变机制：点赞即推荐给好友，天然人传人
- 竞争比抖音小，对新手友好
- 40-60岁人群在微信上最活跃，转化路径最短

### 1.4 平台算法本质
- **抖音**：层层流量池（200→300→3000→1.5W→...），考核完播率、5秒跳出率、互动率。数据好才推下一级
- **视频号**：基于社交关系裂变，朋友点赞=推荐
- **共性**：机器识别你的语音→转文字→拆关键词→打标签→推给匹配的人

### 1.5 平台是商业房东
- 平台靠广告费/抽佣赚钱
- 你要么花钱买流量，要么用内容换流量
- **内容质量决定你的流量成本**

## 第二模块：定位公式

### 2.1 核心一句话
> **什么人在什么场景下遇到什么问题 → 我怎么解决**

### 2.2 定位推导步骤
1. 列出你的产品/服务的所有卖点
2. 从客户角度反向推：什么人买？在什么场景需要？他们担心什么？
3. 用一句话串起来

### 2.3 案例（本节课学生）
- **卖点**：食材新鲜、种类齐全、户外露营一站式
- **客户**：40-50岁工厂老板（团建）、家庭出游、年轻人聚会
- **场景**：户外烧烤不知道怎么准备、怕买到假肉、不知道配什么
- **定位方向**：「户外露营烤肉，从吃到用一站式搞定」

### 2.4 关键词植入
- 地名（凤城、丹东等）
- 品类名（烧烤、露营、烤肉）
- 场景词（户外、团建、家庭聚会）
- **目的**：让平台知道推给谁，让用户搜得到你

## 第三模块：人设建立

### 3.1 信任逻辑
> **信任不是靠说"我家东西好"，是靠一件件小事堆出来的。**

### 3.2 人设三层结构

#### 第一层：个人经历（建立第一印象）
- 为什么开这家店？（初心故事）
- 过往经历（干了多少年、从哪儿来、经历过什么）
- 性格特点（开朗、善良、爽快、幽默）
- **关键**：主动暴露性格，性格就是人设标签

#### 第二层：专业展示（建立专业信任）
- 食材怎么选的（颜色、纹理、来源）
- 怎么腌制的（工艺流程独家方法）
- 怎么吃的（烤制顺序、搭配技巧）
- 行业内幕科普（注水肉怎么分辨、僵尸肉什么样）
- **关键**：不要推销，要"教你"——在教你过程中你会默认我是专业的

#### 第三层：客户故事（持续养信任）
- 今天来了个什么客户
- 他有什么需求、我怎么解决的
- 客户说了什么、结果怎么样
- **可以编，但编得真实。** 互联网上大部分内容都有编排，关键是不穿帮。

### 3.3 案例：流浪狗故事
1. 某天店里来了一只流浪狗
2. 老板给它喂了剩的碎肉
3. 续集：这只狗天天来，老板每次都喂
4. **结果**：观众看到的是一个有爱心的老板，信任自然建立
5. **原理**：一个小事件比一百句"我家是良心商家"更有说服力

### 3.4 人设可以多面
- 对媳妇什么样（开玩笑、宠她）
- 对员工什么样（爽快、不墨迹、工资给到8000）
- 对顾客什么样（用心、不计较）
- **每条视频只打一个点，主页综合起来才是完整人设**

## 第四模块：内容创作方法论

### 4.1 铁律
> **内容必须娱乐化。** 没人打开手机是为了看广告。

### 4.2 隐藏式广告法则
- 不要喊"我家东西好" → 改成"今天来了个客户，他说..."
- 不要列产品清单 → 改成"2000块钱能买到这些东西，你敢信？"
- 不要说自己专业 → 改成"教大家三个方法挑新鲜羊肉"

### 4.3 内容类型（按人设三层展开）

**经历类：**
- 为什么开这家店
- 我和媳妇的故事
- 我在北京的那些年

**专业类：**
- 教大家怎么挑好肉（颜色、纹理、气味）
- 烤肉的先后顺序大讲究
- 行业内幕：注水肉的三个特征

**客户故事类：**
- 好大哥花了2000给员工团建
- 一对情侣花100块钱想办大事
- 大爷花了3000要浪漫

**扩散类（破圈用）：**
- 凤城本地新闻/八卦
- 周边好玩的地方推荐
- 避坑指南（哪里不好玩、别去）

### 4.4 选题来源
- **低粉爆款法**：抖音热点中心 → 低分爆款 → 筛选行业关键词（如"烧烤"）
- 看别人什么选题火了，用自己的行业+自己的话翻拍
- **翻拍≠抄袭**：换成自己的行业、自己的表达方式

### 4.5 开头钩子
- 自嘲式："我一个37岁的老爷们..."
- 冲突式："咱凤城老板就是不一样，别的城市..."
- 悬念式："2000块钱在我这儿能买到啥？"
- 对比式："北京的老板最多给员工花1000，咱凤城..."

## 第五模块：视频制作

### 5.1 三个要素
| 要素 | 标准 | 注意事项 |
|------|------|---------|
| **画面** | 干净、手机够用 | 画质太高反而增加距离感；内容驾驭不了高画质反而减分 |
| **声音** | 人声清晰即可 | 平台会把人声转文字提取关键词；音乐匹配内容调性 |
| **文字** | 字幕+标题+贴纸 | 铺满屏幕，让机器多抓关键词；用贴纸标注价格/亮点 |

### 5.2 拍摄形式
- 口播、监控器视角、旁白配音、演绎、日常跟拍
- **形式不重要，内容对就行**
- **不要轻易换形式**，在一个形式上持续迭代

### 5.3 测试标准

| 播放量 | 判断 | 行动 |
|--------|------|------|
| <1000 | 视频质量问题 | 检查三要素哪里没做好 |
| 1000-2000 | 正常，选题可能不够好 | 换选题方向测试 |
| 2000-3000 | 看互动数据 | 点赞率<10%就优化内容结构 |
| 3000-5000 | 稳定，本地已算好 | 保持方向，持续发 |
| 持续3000+ | 账号做起来了 | 复制成功模式 |

### 5.4 迭代原则
- 三条一组，每组比上一组要好一点
- 遇到什么问题改什么问题
- **不要今天口播明天段子后天监控器**——平台需要时间学习你的标签

## 第六模块：投流与矩阵

### 6.1 投流逻辑
- 蓝V号可以挂商品组件
- 投流考核：商品浏览率 → 下单率 → 转发
- **核心公式**：投100赚200就继续投，投100亏了就换视频
- 持平也可以投——赚了曝光
- 节日/开业适合大预算买曝光

### 6.2 矩阵思维
- **主号（老板IP）**：做人设+信任，不挂车或少挂车
- **商品号（蓝V）**：做货品展示，挂组件，投流
- **员工号**：发日常+圈主号，低成本扩矩阵
  - 买号成本低（4.9-9.9元/张卡），10人月费不到300
  - 发布内容：工作日常+热门音乐+圈@主号
  - 简介全圈主号

### 6.3 内容分发逻辑
- 同一视频不同平台**错开发**（隔天，避免算法判定搬运）
- 视频号优先发，隔天发抖音
- 小红书独立内容策略

## 第七模块：常见误区

### ❌ 误区1：觉得所有人都是客户
- **真相**：精准定位反而吸引更多人。"我只做企业团建"比"欢迎所有人"更有效
- 专精→破圈，不是广撒网→破圈

### ❌ 误区2：相机画质越高越好
- **真相**：高画质=高预期，内容跟不上反而减分
- 手机拍的画面给观众低预期，内容好反而超预期

### ❌ 误区3：不火就换形式
- **真相**：平台需要时间抓取你的标签，频繁换形式=每次从零开始
- 在一个方向上持续迭代，优化选题和结构

### ❌ 误区4：直接抄大号的段子
- **真相**：大号10万粉的流量池跟你1000粉的不一样
- 看**低粉爆款**（0-1万粉）才是你的参考对象

### ❌ 误区5：AI随便问一句就生成内容
- **真相**：AI需要喂养数据：你的角色+你的目的+你的需求
- "帮我写个文案" → 垃圾
- "我是凤城做露营烧烤的老板，我的客户是40-50岁工厂老板团建，帮我想3个开头钩子" → 可用
- 国内AI（豆包等）数据质量差，容易"讨好"你编假信息

## 课程落地清单

### 学生作业
1. **自我挖掘**：对着手机语音转文字，尽可能多说——你是谁、什么经历、性格、店里故事、客户故事
2. **拆解模板**：等老师发模板，然后套用自己的产品，把自己所有品类拆一遍
3. **建立专辑**：后台把产品分类（牛肉、羊肉、户外用品等）
4. **测试三条**：用今天学的思路拍三条发出去，看数据迭代

## 课程升级思考（待讨论）

### "底座"换什么词？

夏老师用"底座"，偏基建感。柯哥的课更像在给学生装一套**思维操作系统**：

候选方向：
1. **"底层操作系统"** — 强调思维框架，不教技法教思维
2. **"内容基因"** — 注入创作基因，学生自然长出内容
3. **"底层逻辑"** — 直白，但怕被用烂
4. **"认知地基"** — 与"底座"近义但更偏认知
5. **其他方向**：留空等柯哥定

### 课程模块化建议
从今天这节课看，七个模块逻辑清晰，可以考虑：
- 每个模块独立成章
- 模块间用"为什么→是什么→怎么用→怎么测"的闭环串起来
- 加入更多行业案例（不只烧烤，覆盖家政、美发、装修等柯哥已有的行业）
