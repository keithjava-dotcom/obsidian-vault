# 底座课 · 案例弹药库

> 每个模块准备2-3个行业案例。讲课时先用"非学生行业"的通用案例讲透概念，再让学生用自己行业套一遍。

---

## 模块一：平台认知

### 案例1-1：为什么烧烤店首选视频号而非抖音
**来源**：百味肉坊凤城（丹东）

| 维度 | 说明 |
|------|------|
| 行业 | 烧烤露营食材（本地生活+零售） |
| 核心客群 | 40-50岁工厂老板、家庭用户（凤城本地） |
| 为什么选视频号 | 客群年龄偏大，微信使用频率高；凤城是县级市，更依赖熟人推荐；视频号点赞=朋友圈推荐，裂变效率高 |
| 反面教训 | 抖音投了100块，买了2000播放，没人下单——因为抖音上的年轻人不是他的客户 |
| 课堂用法 | "你是做本地生意的，你的客户在哪儿？先定客户，再定平台。" |

### 案例1-2：为什么美发店应该做小红书
**来源**：百味肉坊凤城学生（第二产业：美发）

| 维度 | 说明 |
|------|------|
| 行业 | 美发（高客单价服务） |
| 核心客群 | 25-40岁女性 |
| 为什么选小红书 | 小红书女性用户为主，对美发有强搜索需求；粉丝价值高（≈50个抖音粉）；内容天然适合视觉展示 |
| 对比抖音 | 抖音上做美发，用户刷到更多是娱乐心态，看完就划走；小红书用户搜"发型""染发"，带着目的来 |
| 课堂用法 | "同样的老板，两个产业选两个不同平台。不是平台好坏的问题，是你的人在哪。" |

### 案例1-3：为什么家政公司要同时做抖音和视频号
**来源**：一冉家政（大连）

| 维度 | 说明 |
|------|------|
| 行业 | 家政服务（保洁+月嫂+培训） |
| 为什么抖音 | 本地生活强推家政品类，有同城流量扶持；年轻人帮父母找保洁，在抖音搜 |
| 为什么视频号 | 微信私域闭环：客户加微信→看视频号→转介绍，一整套不跳出微信 |
| 为什么不做小红书 | 家政不是"种草型"消费——用户不会因为保洁视频好看就下单，更多是"有需求了才找" |
| 课堂用法 | "一个行业为什么选多个平台？因为客户分两层：找保洁的年轻人和被推荐的熟人。" |

## 模块二：选平台（新增模块）

### 案例2-1：无人机培训的选平台逻辑
**来源**：创翼无人机（大连）

| 维度 | 说明 |
|------|------|
| 行业 | 无人机培训（B端企业服务+C端考证） |
| 核心客群 | 企业客户（巡检、测绘）、个人（考证就业） |
| 选平台逻辑 | B端客户在微信生态里（朋友圈+视频号+公众号），C端考证学员在抖音搜 |
| 策略 | 视频号打企业信任，抖音打个人获客，小红书发考证攻略 |
| 课堂用法 | "不是所有生意都要上所有平台。算清楚你的客户看哪个平台成本更低、转化更快。" |

## 模块三：定位公式

### 案例3-1：烧烤店的一句话定位
**来源**：百味肉坊凤城

**公式拆解**：
```
什么人：凤城及周边想户外烧烤的人（家庭、企业、朋友聚会）
什么场景：周末出游、公司团建、家庭聚会，不知道买什么、怕买到假肉
怎么解决：从吃到用一站式配齐，按人头配套餐，人均几十块搞定
```

**一句话定位**："在凤城想户外烧烤，不知道买什么、怕买到假肉——来我这，从肉到炉子到调料，按人头给你配好。"

### 案例3-2：家政公司的一句话定位
**来源**：一冉家政（大连）

**公式拆解**：
```
什么人：大连本地家庭（搬家、日常保洁、深度保洁、月嫂）
什么场景：家里太乱不想收拾、搬家前后、过年大扫除、媳妇怀孕需要月嫂
怎么解决：标准化服务流程，不满意重做
```

**一句话定位**："在大连，家里需要保洁、搬家、月嫂——我们上门服务，不满意免费重做。"

### 案例3-3：整理收纳的一句话定位
**来源**：新颖家整理收纳（大连）

**公式拆解**：
```
什么人：大连中高端家庭（有预算、对生活品质有要求）
什么场景：家里乱但不知道从哪下手、搬新家不会布置、衣柜塞不下
怎么解决：专业整理师上门，从分类到收纳到维持，一套流程
```

**一句话定位**："大连中高端家庭的整理收纳——不只是帮你收拾，是帮你建立一套'不复乱'的系统。"

### 案例3-4：康复工作室的一句话定位
**来源**：深圳康复工作室

**公式拆解**：
```
什么人：深圳都市白领（久坐、肩颈腰问题、运动损伤）
什么场景：脖子疼肩膀酸、去医院太麻烦、健身房不知道怎么练
怎么解决：专业康复师一对一，从评估到训练到手把手教
```

**一句话定位**："在深圳，久坐腰疼脖子疼——来我这，康复师一对一帮你找到问题、手把手带你练好。"

## 模块四：人设建立（三层结构）

### 第一层：个人经历

**案例4A-1：一冉家政创始人的入行故事**
- **为什么开家政公司？** 从工厂女工到家政老板。在工厂干了多年，发现身边姐妹都找不到好工作。会做家务的姐妹想赚钱但没渠道，需要家政服务的家庭又找不到靠谱的人。于是自己出来干。
- **课堂要点**：入行故事不是"我开公司很厉害"，是"这个行业跟我有什么关系"。故事里要有**转折**（从女工到老板）和**初心**（想帮姐妹）。

**案例4A-2：烧烤店老板的"37岁+媳妇"故事**
- **为什么在凤城开烧烤店？** 媳妇干了20年美发，嫁给我之后一起开了这个店。37岁了，就想在凤城踏踏实实做个靠谱的店。
- **课堂要点**：用自嘲加一点幽默——"我媳妇做了20年美发，嫁给我还得管烧烤店"。**暴露性格比展示能力更重要。**

**案例4A-3：张伟——负债者的前行者故事**
- 来源：【江西】张伟
- 他不是成功了来教你，是摔倒了还没爬起来但已经在探路了。"我冲在前面排雷、避坑、刷失败经验"
- **课堂要点**：人设不一定要是"成功者"视角。"我还在这条路上"反而更真实、更有共鸣。

### 第二层：专业展示

**案例4B-1：烧烤店——教大家挑好肉**
- 打开冰柜，拿一块羊肉：看颜色（鲜红有光泽）、看纹理（纹路清晰）、闻味道（没有异味但也不需要香精味）
- 补一刀："做餐饮的想让肉闻着香太容易了，加东西就行。我这不玩那个。"
- **课堂要点**：专业知识不是讲课，是**问答式**——"你以为好肉是什么样？其实不是。" 有反差才有记忆点。

**案例4B-2：康复师——专业术语双重表达法**
- 来源：深圳康复工作室
- 嘴里说人话给用户听："拿个瓶子这么揉"
- 画面配专业术语给算法看："放松胸小肌"
- **课堂要点**：一条视频同时服务两个人。用户听懂了你说的，机器抓到了专业关键词。两不误。

**案例4B-3：整理收纳师——为什么你家收了又乱**
- 你请了保洁、自己收拾了，为什么三天又乱回去？因为你没有分类系统。
- 揭秘行业真相："收纳不是把东西藏起来，是建立'每样东西有固定位置'的习惯。"
- **课堂要点**：专业展示的最高境界是**推翻用户的错误认知**。"你以为收纳是这样的，其实不是。"

### 第三层：客户故事

**案例4C-1：烧烤店——工厂老板花2000团建**
- 凤城一个工厂老板，给员工搞团建。去北京上海见过大城市的老板，最多给员工花1000。咱凤城老板花了2000。
- 你给他配了羊肉串、牛排、鸡翅、蔬菜、调料、炉子、碳，一堆人吃得开心。
- **课堂要点**：用一个客户引出几个信息——你东西实惠（2000买这么多）、老板大方（对比一线城市）、员工开心（结果好）。

**案例4C-2：家政——独居老人的故事**
- 来源：一冉家政
- 一个独居老太太，家里乱了好几个月。子女不在身边，自己又收拾不动。保洁阿姨上门不只是打扫，还陪老人聊了半小时天。
- **课堂要点**：家政的客户故事不只是"打扫干净"，更是**人情温度**。这条视频打的是"我们的服务有温度"。

**案例4C-3：康复——久坐白领的逆袭**
- 来源：深圳康复工作室
- 一个程序员，脖子疼了两年，去过三家医院没解决。来工作室，康复师发现是坐姿问题。三周后脖子好了，回家还教老婆怎么坐。
- **课堂要点**：客户故事要有**问题→解决→结果**三拍。重点是"他自己都没想到能好"的意外感。

## 模块五：视频三要素

### 案例5-1：画质太高反而无效（反面）
- **来源**：百味肉坊凤城
- 学生的口播视频：画面精良，摄影师专业打光，结果没人看。评论区只有表情没活人。
- 对比：监控器随手拍的视频，画面粗糙，评论区活人在说话，流量比口播好得多。
- **课堂要点**："清晰度不等于有效。你那个画面像广告，人家直接划走。监控器画面像偷拍，人家停下来看。"

### 案例5-2：声音关键词的重要性
- **来源**：康复工作室
- 康复师说话："拿个瓶子这么揉"——平台听不懂。
- 画面上加字幕："放松胸小肌"——平台识别到专业关键词，推给关注运动康复的人。
- **课堂要点**：机器人不懂人话，但认识关键词。**画面上的文字帮机器人读懂你的内容。**

### 案例5-3：字幕+贴纸让机器理解你
- 烧烤店视频：画面上标注"2000块＝这些"、价格标签、品类标签
- 目的：让机器抓取"烧烤、凤城、户外、实惠"等关键词
- **课堂要点**："你嘴上说实惠，机器听不懂。你打字'2000块买了这么多'，机器就懂了。"

## 模块六：低粉爆款拆解（课堂教学用）

### 案例6-1：公勺倒辣椒——全网爆款底层逻辑
**事件**：拉面馆监控视角，顾客用公勺舀辣椒，店主看到直接整瓶倒给他。
**为什么火**：
- 监控视角（真实感，不像广告）
- 老板动作干脆（爽快人设，一秒树立）
- 观众自己得出"这老板真好"（不是硬塞结论）
**课堂要点**："全网几千万人看过这条视频。它没有精美画面、没有复杂文案、没有专业设备——形式不重要，事件本身说话。"

### 案例6-2：肉掉地上不收——烧烤店人设事件
- 监控器拍到：一块肉掉地上，老板没捡起来洗洗再卖，直接收走扔了。
- 观众自发得出结论："这老板靠谱""有良心"
- **课堂要点**："你说一百遍'我食材新鲜'，不如拍一个扔肉的动作。信任是观众自己得出的，不是你告诉他的。"

## 模块七：常见误区案例

### 案例7-1：信息流思维，不是人设思维（反面）
- **来源**：百味肉坊凤城（改善前）
- 症状：口播内容像广告片，拍得正规、说得官方、评论区全是表情没人说话
- 诊断：用广告思维做人设，用户不买账
- **课堂要点**："拍得像广告→用户划走→平台不推→你觉得短视频没用。链条第一步就错了。"

### 案例7-2：内容太短被判低质（反面）
- **来源**：新颖家整理收纳
- 症状：选题好（收纳前后对比），但每条太短，平台判定为低质内容
- 诊断：收纳前后的对比很吸引高端客户，但视频太短=机器认为你没内容
- **课堂要点**："选题对了但时长不够，等于白费。平台考核的是用户在你视频上花的时间。"

### 案例7-3：用AI但没给够数据（反面）
- AI生成的内容"像AI但不像你"——因为没喂数据
- 给AI三个东西：我是谁（烧烤店老板、凤城人、37岁）、我的目的（让本地人知道我的店靠谱）、我的需求（帮我写一条开头钩子）
- 不给数据的结果：AI开始编，编出来经不起考验
- **课堂要点**："国内AI（豆包等）数据质量差，会讨好你编假信息。你在自己行业干了这么多年，一眼就能看出它胡说。所以一定要把数据给到位。"

## 使用说明

### 讲师准备清单（每节课前）
1. 根据学生行业，从这个弹药库里选1-2个"非本行业"的通用案例
2. 准备1个正面案例（拆给学生看） + 1个反面案例（让学生知道坑在哪）
3. 每个案例控制在3分钟内讲完
4. 讲完后立刻问："你行业里有没有类似的情况？"

### 行业覆盖
| 行业 | 已覆盖模块 | 缺口 |
|------|-----------|------|
| 烧烤/餐饮 | 全模块 | 无 |
| 家政/保洁 | 全模块 | 无 |
| 整理收纳 | 定位、人设 | 客户故事 |
| 康复/健康 | 定位、人设、客户故事 | 视频要素 |
| 美发 | 平台选择 | 定位、人设、客户故事（待补充） |
| 知识付费/个人IP | 人设经历 | 定位、客户故事 |
| 装修 | 未覆盖 | 需补充案例 |
| 教育培训 | 未覆盖 | 需补充案例（迪派教育可作为案例） |

### 待补充行业
- 装修（柯哥有装修行业服务经验）
- 法律/专业服务（大成律所可补充）
- 教育培训（迪派教育可补充）
