## 第四步：选题判断——三个自问

每想出一个选题，过一遍：

| 选题 | 新鲜吗？（观众不知道？） | 颠覆吗？（打破常识？） | 可落地吗？（看完能做？） |
|------|:--:|:--:|:--:|
| 例：自助餐的肉为什么便宜 | ✅ 很多人不知道 | ✅ 颠覆认知 | ✅ 下次吃自助会看 |
| | | | |
| | | | |
| | | | |

三个全是✅才拍。有一个不是就回去调。

## 第六步：写文案——SCQA故事法（进阶）

> 背景→冲突→疑问→答案

### 把你的真实经历套进去

**你的S（背景）**：本来是什么样的？
> 例：我本来在大连生活挺舒服的，我爸做了三十年的店。

**你的C（冲突）**：发生什么事了？
> 例：我爸非让我回来接手，我不想干餐饮，我想做自己的事。

**你的Q（疑问）**：怎么办？（不用写，隐含在故事里）

**你的A（答案）**：最后怎么样了？
> 例：我决定留下来，带着我爸三十年的经验，开了自己的店。

## 第七步：文案基本功——三招急救

### 招一：开头别陈述，要有情绪

把下面的陈述句改成有情绪的：

| ❌ 陈述 | → 你的情绪版 |
|---------|------------|
| 这是一家开了三年的烧烤店 | |
| 我们家的肉很新鲜 | |
| 我是做美发店的 | |

**参考词库**：凭什么 / 为什么 / 家人们你敢信吗 / 我服了 / 我告诉你一个事儿

---

### 招二：形容词删掉，换成具体的动作

| ❌ 形容词版 | → 你的动词版（谁+什么时间+做了什么具体动作） |
|-----------|--------------------------------------|
| 我们家很干净 | |
| 我们家的肉很好吃 | |
| 我们家生意很好 | |

**检查**：删掉"干净""好吃""好"之后，观众脑子里有画面吗？没有就再加一个动作。

## 第八步：超量准备——一周操作流程

### 每周固定动作

| 时间 | 做什么 | 产出 |
|------|--------|------|
| 周一 | 花2-3小时想选题（用本手册第一步到第三步） | 7-15条选题 |
| 周一 | 筛选有内容的选题，写文案（用第五步第六步） | 6-7条文案初稿 |
| 周二 | 集中录制6-7条（录音频A轨） | 6-7条音频 |
| 周二 | 日常随手拍B轨素材（虾/肉/顾客/洗菜/进货） | 素材库 |
| 周三-四 | 剪辑/外包剪辑（A轨+B轨拼接） | 6-7条成品 |
| 周五-日 | 发布，看数据，准备下周 |

### 效率提示

- **别一天拍一条**——每次走一遍流程太浪费时间
- **集中半天拍完**——状态更好，效率更高
- **日常随手拍素材**——说到虾就有虾的画面，说到顾客就有顾客的画面

## 记住

> 不要瞎抄爆款，要看爆款背后的逻辑。

> 越底层的需求，观众看得越起劲。

> 把形容词删掉，用具体的动作和事件说话。

> 每一个步骤都要有目的性——洗栗子不是为了洗栗子，是为了告诉顾客这东西特别干净。

> 众多小目的组成大目的，众多大目的组成你的账号定位。
