# 第三天 · 画面拍摄实操课

> 整理自柯哥线下课录音原文稿

---

## 一、课前复习：从定位到画面的完整链路

**定位**
- 定位就是"自己"跟"用户"
- 自己：通过问题回顾，挖掘性格、故事、经历
- 用户：找一个最近的用户，邀请来做用户画像，分析需求特征
- 最终：用短视频链接两者

**选题**
- 第一步：判断需求（从马斯洛需求层次切入）
- 商业需求 → 社交需求 → 自我实现
- 反过来看，就是流量漏斗
- 选题类型：资讯类、认知类、掏心掏肺（故事/情绪）、日常类

**选题效果自检**
1. 够不够新鲜？（陌生感）
2. 有没有独特视角？（同一个事，不同角度讲）
3. 观众看完能不能落地？（能做 / 能买）

**文案**
- SCQA框架：背景 → 冲突 → 问题 → 答案
- 故事型结构：背景 → 痛苦 → 解决问题 → 结果
- 关键：带着思维去拆解好账号，仿写到自己身上

**拆解框架**
1. 拆定位 → 他怎么赚钱的
2. 拆选题 → 他覆盖了哪些需求
3. 拆文案 → 结构怎么搭的
4. 仿写 → 用在自己身上

## 二、画面：五大景别

| 景别 | 倍率 | 作用 | 例子 |
|------|------|------|------|
| **远景**（广角） | 0.5x | 交代环境和背景，告诉观众"事情发生在哪" | 电影开头的大全景、地图 |
| **全景** | 1.0x | 拍人物的全身或2/3身体，交代人物关系 | 两人谈话、谈判场景 |
| **中景** | — | 拍人物上半身，展示动作和表情 | 大多数口播博主用中景 |
| **近景** | 2.0x | 局部特写，突出细节 | 推产品、手部细节、干活的画面 |
| **特写** | — | 更极致的局部，放大情绪或质感 | 食物特写、表情特写 |

**核心原则**：
- 观众极易审美疲劳 → 不同景别穿插使用 → 持续刺激视觉新鲜感
- 所有主体（除了远景）尽可能放在画面中间位置 → 清晰、干净
- 不需要复杂的构图理论，主体清晰就够用

## 三、运镜：让画面动起来

| 运镜 | 动作 | 说明 |
|------|------|------|
| **推** | 摄影师往前走 | 主体不动，镜头靠近 |
| **拉** | 摄影师往后退 | 主体不动，镜头远离 |
| **摇** | 站在原地，左右转身 | 扫描环境 |
| **移** | 平行移动 | 摄影师横向走 |
| **跟** | 镜头跟着主体走 | 主体动，镜头跟 |
| **甩** | 快速转向 | 很少用，除非特殊效果 |

**运镜黄金原则**：
- 主体静止 → 镜头动（推拉，给呼吸感）
- 主体在动 → 镜头尽量不动（让观众看清楚）
- 最常用：推、拉、跟

## 四、构图：决定画面的质感和审美

### 常用构图法

| 构图 | 怎么用 |
|------|--------|
| **三分法（九宫格）** | 主体放交叉点或线上 |
| **中心构图** | 主体放正中间，最直接、最干净 |
| **对称构图** | 左右对称，适合前后对比 |
| **前景构图** | 前面加一个元素（电脑、植物、门框），增加层次 |
| **框架构图** | 透过门缝、窗户等框架拍，制造窥视感 |

**实战建议**：不用记全部，先练中心构图和三分法，够用。

---

## 五、视角：新鲜感的来源

### 基础视角

| 视角 | 效果 |
|------|------|
| **第一视角** | 沉浸式，带着观众体验——"仿佛自己干了一遍" |
| **第三视角** | 客观旁观，日常拍摄最常用 |

### 玩出花样的视角

| 视角 | 玩法 |
|------|------|
| **无人机/高杆** | 换个角度看世界，新鲜感强 |
| **监控视角** | 真实感、偷窥感 |
| **动物视角** | 猫/狗脖子上绑摄像头 |
| **顾客视角** | 文案里也可以用——以顾客的眼睛看服务 |

**核心**：每一个新视角出现，观众就觉得新鲜。视角是可以创造的。

---

## 六、拍摄高度：平视/俯视/仰视

| 高度 | 效果 | 适用 |
|------|------|------|
| **平视** | 客观、中立、没有态度 | 日常讲解、口播 |
| **俯视** | 居高临下，抬高观众 | 揭秘、评价 |
| **仰视** | 树立高大形象 | 拍权威人物、政务、领导 |

**一句话记**：拍大人用仰视，拍揭秘用俯视，口播用平视。

---

## 七、五大风格组合：自由混搭

1. **正常**：平视 + 中景 + 中心构图
2. **揭秘**：俯视 + 偷拍感 + 晃动
3. **权威**：仰视 + 中景 + 对称构图
4. **沉浸**：第一视角 + 跟拍 + 近景
5. **偷拍/内幕**：门缝、晃动、低角度、不规整

**关键**：尽情组合景别、运镜、构图、视角、高度 → 让画面持续给观众新鲜感。
