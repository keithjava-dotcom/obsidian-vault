# Day 2 作业：情绪能量层级分析

## 作业一：记录一次"情绪事故"，标注能量层级变化

### 📍 事件描述

今天（5月7日）上午，我正在跟Claude深度聊天，获得了搭建Obsidian+OpenClaw+Claude系统的灵感。整个人特别兴奋，一直在让Claude帮我搭建，连中午的午睡都放弃了——就想把这个系统搭完。

正在兴奋头上，一兰集团的总助突然发消息来叫摄影师。那一瞬间我**非常愤怒**。这不是第一次了，这种低效且重复的事情不断被打断。

我在群里直接给她制定了规则："你就置顶吧，以后这种事情不要来找我了。"

### 📊 能量层级变化轨迹

```
事件前    →  打断瞬间    →  愤怒中    →  行动后    →  冷静反思后
主动(310) → 愤怒(150)   → 愤怒(150) → 勇气(200) → 淡定(250)
```

### 🔍 逐层分析

**1. 事件前：主动（310）**
在研究新系统，脑子高速运转，想快速搭完。这是高能量状态，积极拥抱新事物。

**2. 打断瞬间：愤怒（150）**
从310直掉到150。但注意——按霍金斯相对值理论，**愤怒不是坏事**。如果我对这种打断已经麻木了（冷漠75），那才是真危险。愤怒说明我还想要掌控自己的专注时间。

**3. 愤怒持续：愤怒（150）→ 勇气（200）**
没有停在愤怒里内耗。直接做了行动——在群里定规则。这就是夏鹏老师说的"向上牵引"：愤怒→行动→勇气。

**4. 冷静反思：勇气（200）→ 淡定（250）**
后来想清楚了："规则就是规则，但是规则可以优化。我也不是那么独断的人，我觉得规则肯定可以优化。优化的话，她收费的时候跟我优化就好了。"

能接受结果（她遵守规则或提出优化），能做出选择（规则可以改但不是现在），这就是淡定层级的特征。

### 🎯 关键发现

**我的情绪内耗模式**：不是"容易生气"，是**专注时被打断**——尤其是被打断去处理"低效重复且本该规则化"的事。

**这次为什么没陷入内耗**：因为愤怒之后立刻行动了（定规则），没有停在"凭什么"的阶段反复想。

## 作业二：找到"踩刹车"的关键点

### 🚦 踩刹车的时机

**起点**：专注被打断的那一刻。

**踩刹车的动作**：
不是"别生气"（没用），而是**问自己一个问题**：

> "我是在生气被打断，还是在生气这件事本不该由我处理？"

**为什么这个问题有效**：
1. 按照霍金斯理论，**观察情绪本身就开始消解情绪** —— 问这个问题就是在观察
2. 如果是"被打断" → 那是情绪问题，缓一下就行
3. 如果是"本不该由我处理" → 那是系统问题，**需要建规则**，该行动就行动

### 🔑 下次类似情况的应对流程

```
被打断 → 问自己那个问题 → 判断是情绪还是系统问题
                              ↓                    ↓
                         缓一下回到专注       当场建规则或记录
                              ↓                    ↓
                         事后补规则            不内耗、继续干活
```

### 💡 课程知识应用

- **学习 → 安顿内心**：听了夏鹏老师这课，我现在知道自己为什么愤怒是健康反应（从310掉到150但没到50，说明核心能量底子是高的）
- **行动 → 打破内耗**：当场定规则就是行动，不让自己在愤怒里反复咀嚼
- **向上牵引**：310→150→200→250，每一步都是向上走
- **相对正能量**：愤怒（150）虽然绝对值不高，但相比冷漠（75）来说，说明还"要"这件事——这是好事
