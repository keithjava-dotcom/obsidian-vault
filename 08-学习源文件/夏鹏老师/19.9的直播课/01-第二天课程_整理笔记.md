## 一、夏鹏的亲身经历

**25岁在新东方总部**：不爱上班，办公室门打开，电脑打开，茶杯摆好，走人回家打PS2。烂人烂事、不作为的领导、打黑枪的同事——选择表演上班。

**转折**：发现这样不行。情绪内耗最大的成本不是躯体化，是**时间浪费了**。一天8小时，情绪不好可能半小时都干不了事。年龄在增长，社会对你的容忍度越来越低。

**解决**：去读了长江商学院全日制MBA。不是为了学知识，是为了**把自己的时间省下来**。

> "学而时习之不亦乐乎——论语开篇谈学习，不是学到了什么知识和技术，而是**安顿了自己的内心**。"

**MBA回来后第二个情绪卡点**：14年做战略扫描，建议俞敏洪做在线大班教学，总裁办不置可否。又内耗。解决方案：**行动**。自己做了MVP，微信群里讲莎士比亚讲外刊，一个月赚100万。15年出来创业，俞敏洪投了800万占10%。

**两个武器**：
1. **学习** → 安顿内心
2. **行动** → 打破内耗

## 二、霍金斯能量层级模型

### 完整层级表（从低到高）

| 分数 | 情绪 | 关键词 |
|------|------|--------|
| 20 | 羞愧 | 不配活、号练废了 |
| 30 | 内疚 | 都是我的错 |
| 50 | 忧伤 | 无助、委屈 |
| 75 | 冷漠 | 爱谁谁、躺平 |
| 100 | 恐惧 | 怕失去、不安全感 |
| 125 | 欲望 | 我想要但得不到 |
| 150 | 愤怒 | 凭什么 |
| 175 | 骄傲 | 我知道我擅长什么 |
| **200** | **勇气** ⚡ | **行动治百病** |
| 250 | 淡定 | 做选择、接受结果 |
| 310 | 主动 | 积极拥抱变化 |
| 350 | 宽恕 | 翻篇、放下过去 |
| 400 | 理智 | 学习、哲学、宗教 |
| 500 | 爱 | 无条件的爱 |
| 540 | 喜悦 | 圣人层级 |
| 600 | 平和 | 孔子、佛陀 |
| 700-1000 | 开悟 | 地球至今没有 |

### 三个核心原理

**① 情绪量化本身就消解情绪**
> "你劝一个人别生气了，他能被劝住吗？但你问他：你给我想想为什么愤怒，谁惹你了，你开始观察情绪的时候，情绪已经开始被消解了。"

**② 正能量的两个定义**
- **绝对值**：以勇气（200）为分界线，以上为正
- **相对值**：看跟什么比。从冷漠（50）到愤怒（150），愤怒也是正能量——因为能量升了

**③ 向上牵引**
每一步向上一级就是进步。从内疚→忧伤→恐惧→愤怒→骄傲→勇气→淡定→主动……不需要一步登天，一步一步往上爬。

## 三、三个案例拆解

### 案例3：中年大姐（团队+女儿问题）

**困境**：团队反感她，女儿不听话，内耗严重
**所在层级**：忧伤/恐惧（觉得大家不理解她，担心失控）
**向上路径**：
1. 测盖洛普→发现"审慎+成就"优势 → **骄傲（175）**
2. 让女儿也测→发现共通点 → **勇气（200）+行动**
3. 给团队全测、坦诚沟通 → **主动（310）**
4. 结果：女儿考上重点高中，团队关系修复

### 案例4：小弟（新晋管理者被穿小鞋）

**困境**：升职后原同事变下属，给他穿小鞋，很懵逼
**所在层级**：忧伤（50）/恐惧（100）
**关键发现**：忧伤的本质是恐惧——怕失去友谊和他人评价
**向上路径**：
1. 参加心理训练营→认知到恐惧源头
2. 导师问"你为什么被升职？你自己为什么同意？"→唤醒**欲望（125）**→**愤怒（150）**
3. 打电话摊牌："我是领导，想干就好好干，不想干现在辞职" → **勇气（200）+行动**
4. 后来帮原同事也争取晋升 → 进入**爱（500）**

> 💡 **老好人真相**：你当好人是因为恐惧，还是因为有爱？表象一样，能量层级完全不同。

### 案例5：体制内内向男（被强势领导压了多年）

**困境**：领导一批评就脑子空白，连续几年升职跟他无关
**所在层级**：**内疚（30）**——觉得辜负了别人期待，不觉得是别人的事
**向上路径**：
1. 导师让他回忆曾经愤怒的时刻 → 借**愤怒（150）**之力向上拉
2. 还原为什么从愤怒滑到内疚 → **理智（400）**层级走一遍
3. 宽恕原生家庭 → **宽恕（350）**
4. 每天学习+健身 → **勇气（200）+行动**
5. 状态变好→领导看到变化→获得升职

> 💡 体制内人脉重要、情商重要，但**前提是你自己的状态对**。

## 四、方法论提炼

### 情绪处理核心公式

```
情绪内耗 → 观察情绪（给自己打分） → 找到能量锚点 → 向上牵引一步 → 行动/学习
```

### 两个万能武器

| 武器 | 作用机制 | 能量层级 |
|------|---------|---------|
| 学习 | 安顿内心，提升认知视角 | 理智（400） |
| 行动 | 打破内耗循环 | 勇气（200） |

### 课程设计逻辑

夏鹏的课程体系与霍金斯层级对应：
- 优势（盖洛普）→ **骄傲（175）**
- 社群氛围、夸夸群 → **宽恕/爱（350-500）**
- 交作业、满勤奖 → **主动（310）**
- 学习本身 → **理智（400）**

> "我们不解决具体问题，我们解决你**考虑问题的方式**。"
