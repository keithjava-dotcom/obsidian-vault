# 第04稿 · 开庭前会计一句话，我5小时白干了

## 🎬 封面标题

封面标题：开庭前会计一句话，我5小时白干了
封面文字：开庭前会计一句话，我5小时白干了
平台标题：早上八点想到一个绝妙论证，写到下午一点。开庭前打电话确认——会计在旁边来了一句，全废了。

## 🧭 结构走线

```
【早上八点】
→ 不解释什么案。直接进时间。开头像复盘一件事给朋友听，不是讲道理。
"早上八点，想到一个论证思路。之前没往那个方向想过。"

【五小时】
→ 不是渲染辛苦，是写"当时觉得多好"——给反转蓄力。
"从八点到下午一点，一直写。基于当事人告诉我的信息，这份论证，漂亮。"

【路上那个电话】
→ 一句带过。不展开。
"一点多出门开庭。路上给当事人打了个电话。"

【会计一句话】
→ 核心反转。用原话——"退税是退到我们账户的"。不加解释，让这句话自己炸。
"我跟他讲这个思路。他会计在旁边来了一句——"

【已经退回的30万】
→ 三个连锁反应，层层加码。讲事实，不渲染。
"一句话。所有质证全被推翻。更让人难受的是——这30万，早就退回来了。"

【三四万块诉讼费】
→ 事后算账，不是甩锅。说"白白交"，不说"他害的"。
"但凡她早说三天。这官司根本不用打。三四万诉讼费，白白交。"

【经理也气炸了】
→ 情绪最轻的地方讲——"我俩都在电话里愤怒。但没用。"
"经理给我打电话。我俩在电话里都表达了——对这个会计失误的愤怒。但是，已经解决不了任何问题了。"

【最可惜的是】
→ 不收在"教训"，收在那五个小时本身——不是愤怒，是可惜。
"这个事纯因会计失误造成。但最可惜的不是打输了。是早上那个思路——我真觉得写得挺好。"
```

## ⚠️ 注意事项

1. 语气不是愤怒、不是委屈——是荒唐。"跟你说个事，你听听看"。
2. 会计那句话说完**停半拍**——让观众自己消化那个反转。
3. "五小时"那一段，说到"漂亮"的时候可以笑一下——那是苦笑。你知道后面会发生什么。
4. 结尾不收在"所以你要对律师说实话"——让故事本身说话。停在"我真觉得写得挺好"。
5. 禁止：抱怨当事人/教训观众/科普法律/诉苦律师辛苦/解释为什么五小时很可惜。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了讲戏卡之后，用自己的话说。

那天早上八点。

我想到一个论证思路。

之前一直没往那个方向想过。

从八点到下午一点。

一直在写。

基于当事人之前告诉我的信息，这份论证——

漂亮。

一点多，出门开庭。

在路上给当事人打了个电话。

跟他讲这个思路。

他会计在旁边。

来了一句——

退税是退到我们账户的。

一句话。

所有质证，全被推翻。

更让人难受的是。

这30万，早就退回来了。

但凡她早说三天。

这个官司根本不用打。

三四万块的诉讼费，白白交。

经理给我打了个电话。

我俩都在电话里，表达了对这个会计失误的愤怒。

但是。

已经解决不了任何问题了。

这个事，纯因会计失误造成。

但最可惜的，不是打输了。

是早上那个思路——

我真觉得，写得挺好。
