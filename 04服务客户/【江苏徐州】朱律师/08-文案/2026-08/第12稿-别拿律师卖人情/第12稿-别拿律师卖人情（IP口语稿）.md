# 第12稿 · 凌晨一点，亲戚让我改合同。改完我才知道，他拿我卖了人情

## 🎬 封面标题

封面标题：凌晨一点，亲戚让我改合同
封面文字：碍于面子改了，第二天才知道他拿我卖了人情——认识律师，别把别人的事甩给他，合同出问题谁都不好过
平台标题：凌晨一点，亲戚发信息让我帮忙改份合同，说是自己的事。碍于面子，改了。一天后才知道——他拿我卖了人情，那合同根本不是他的事。认识律师，别把别人的事甩给他。合同出了问题，对谁都不负责任。

## 🧭 结构走线

```
【结论先行 · 凌晨1点画面】
注：第一句立画面——凌晨1点，亲戚来让改合同。观众秒懂"这场景我见过"。

例："凌晨一点，亲戚给我发信息，让我帮忙改份合同。说是他自己的事。我碍于面子，改了。"

【转折 · 被卖人情】
注：转折砸在这——帮了半天，帮的是别人的事。语气带一点无奈，不愤怒。

例："改完第二天，我丈母娘打了个电话过来。我才知道——那合同根本不是他的事。他拿我，卖了个人情。"

【边界 · 为什么不行】
注：解释边界——不是小气，是只有自己的事律师能负责到底。帮了别人的事，出问题背锅的是律师。

例："不是我小气。帮熟人自己的事，我从来没拒绝过。但帮的是别人的事——合同真出了问题，背锅的是我。我连对方是谁都不知道，怎么负责？"

【提醒 · 收口】
注：收口是提醒不是抱怨——"认识律师，别把别人的事甩给他"。不提人名，姿态正。

例："所以认识律师的朋友，听我一句：你自己的事，随时来找我。别人的事——别甩给我。合同出了问题，对谁都不负责任。"
```

## ⚠️ 注意事项

1. 第一句就是画面："凌晨一点，亲戚给我发信息" — 场景感抓人。
2. 被卖人情是转折：语气带一点无奈的苦笑（"我才知道——他拿我，卖了个人情"），不愤怒、不骂人。
3. 边界说清楚："帮熟人自己的事，我从来没拒绝过" — 先立这个，再讲别人的事不行。不然观众会读成"律师小气"。
4. 不提人名：全程"亲戚""我丈母娘" — 不点名赵叔/老丈人（柯哥要求：反例C的破法）。
5. 收口是提醒："你自己的事，随时来找我。别人的事——别甩给我。" — 姿态是提醒，不是划清界限。
6. 禁止：骂亲戚、吐槽"人情社会"、说教（"你们要学会尊重律师"）、反问引导。

## 📝 口播文案示例

昨天凌晨一点，
亲戚火急火燎发微信让我帮忙改份合同，
说是自己的事。

我碍于面子从被窝里爬起来给他改完，
结果今天丈母娘一个电话打过来我才知道，这合同压根跟他没半毛钱关系，人家是拿我当免费劳动力，出去卖他顺水的人情。

说实话真不是我这人抠搜，熟人碰上难处，你半夜找我我也给你办。
但你拿别人的事来套我，这就有点没意思了。

合同这东西一字千金，真出了什么狗屎一样的烂摊子，你拍拍屁股做完好人，最后背锅的可是我。
我连对面是人是鬼都不知道，我拿头去负责啊？
以后啊，真别把律师当土特产随便送。
你自己的事，随时找我；别人的事，这好人我当不起。
