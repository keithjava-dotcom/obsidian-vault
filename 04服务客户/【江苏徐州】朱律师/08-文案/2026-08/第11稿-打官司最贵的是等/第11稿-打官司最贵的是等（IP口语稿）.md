# 第11稿 · 我自己被人欠钱，选择上门要，不起诉

## 🎬 封面标题

封面标题：我自己被人欠钱，选择上门要，不起诉
封面文字：我自己被人欠钱，选择上门要，不起诉
平台标题：我帮别人打官司，自己的律师费被人拖着，我选择上门要，不起诉。为什么？因为我比谁都清楚——诉讼的成本不只是法院收的那些钱，还有拖几个月甚至几年的时间和心理消耗。打官司最贵的，是等。

## 🧭 结构走线

```
【结论先行 · 反常识】
第一句就扔反差：打官司的律师，自己不打官司。

注：第一句就立反差——帮别人打官司的律师，自己的钱反而不起诉。观众第一反应：为什么？

例："我帮别人打官司。自己的律师费被人拖着，我选择上门要，不起诉。"

【为什么 · 算账】
不是怕，是算过账。法院收的钱是小头。

注：解释动机——不是软弱，是律师比谁都清楚诉讼的真实成本。平静地算账。

例："有人问，你是律师，怎么不起诉？因为我算过账。诉讼的成本，不只是法院收的那些钱。"

【真正的成本 · 时间】
层层揭：几个月、几年。律师见过太多拖垮人的案子。

注：把"时间"具体化——几个月几年，不是抽象概念，是真实消耗。

例："法院收的钱，是小头。真正贵的是时间。一个案子拖几个月、拖几年，是常态。这期间，钱压着，人耗着，啥也干不了。"

【真正的成本 · 心理】
第二层：心理精力。打官司的人都被磨过。

注：心理成本——打过官司的人都知道那种被吊着的感觉。不说"我很累"，说事实。

例："还有心理上的。案子没结，心里就吊着一块石头。今天问进度，明天等通知，后天又没动静。这种消耗，比钱还磨人。"

【自己算过账 · 收口】
落点：所以我选择上门要。不是怕，是算得清。

注：回扣开头——"所以我选择上门要"不是怂，是算得清。收口留白。

例："所以我自己的钱，我选择上门要。不是怕打官司。是这笔账，我比谁都算得清。"
```

## ⚠️ 注意事项

1. **第一句就是反差**："我帮别人打官司。自己的律师费被人拖着，我选择上门要，不起诉。" — 全片钩子。
2. **算账的口气**：平静、笃定，像老师傅点破行规。不渲染"打官司多苦"。
3. **两层成本**：时间（几个月几年）+ 心理（吊着石头）— 逐层揭，不并在一起。
4. **收口**："是这笔账，我比谁都算得清。" — 停在这，不追加"所以你也别打官司"（让观众自己算）。
5. **禁止**：劝退打官司（"你们别起诉了"）、渲染情绪（"我太难了"）、贬低法院、反问引导。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了结构之后用自己的话说。

我帮别人打官司。自己的律师费被人拖着，我选择上门要，不起诉。

有人问，你是律师，怎么不起诉？因为我算过账。诉讼的成本，不只是法院收的那些钱。

法院收的钱，是小头。真正贵的是时间。一个案子拖几个月、拖几年，是常态。这期间，钱压着，人耗着，啥也干不了。

还有心理上的。案子没结，心里就吊着一块石头。今天问进度，明天等通知，后天又没动静。这种消耗，比钱还磨人。

所以我自己的钱，我选择上门要。不是怕打官司。是这笔账，我比谁都算得清。
