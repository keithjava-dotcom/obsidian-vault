# 第11稿 · 律师自己讨债，不上法庭

> **说两句**：这条的道理你早就懂，观众缺的是"你亲眼见过的"那个画面。看到【🎤】就停一下，想一件你真经历过的——被欠费那次、当事人被拖垮那次。你脑子里有画面，观众才有画面。稿子是我搭的架子，故事是你的，别搞反了。

## 🎬 封面标题

封面标题：律师自己讨债，不上法庭
封面文字：帮人打了多年官司，自己的律师费被赖，我连诉状都没写直接上门要——打官司最贵的不是诉讼费，是等
平台标题：我帮别人打官司，自己的律师费被人拖着，我选择上门要，不起诉。为什么？因为我比谁都清楚——诉讼的成本不只是法院收的那些钱，还有拖几个月甚至几年的时间和心理消耗。打官司最贵的，是等。

## 🧭 结构走线

```
【结论先行 · 反常识】
注：第一句就立反差——帮别人打官司的律师，自己的钱反而不起诉。观众第一反应：为什么？
🎤 补讲：被欠费那次，是哪个案子？欠了多少？你听到"再等等"的时候心里什么感觉？

例："我帮别人打官司。自己的律师费被人拖着，我选择上门要，不起诉。"

【为什么 · 算账】
注：解释动机——不是软弱，是律师比谁都清楚诉讼的真实成本。平静地算账。
🎤 补讲：你手上现在有没有拖了半年以上的案子？当事人什么状态？

例："有人问，你是律师，怎么不起诉？因为我算过账。诉讼的成本，不只是法院收的那些钱。"

【真正的成本 · 时间】
注：把"时间"具体化——几个月几年，不是抽象概念，是真实消耗。
🎤 补讲：你见过最久的一个案子，拖了多久？中间当事人熬成什么样？

例："法院收的钱，是小头。真正贵的是时间。一个案子拖几个月、拖几年，是常态。这期间，钱压着，人耗着，啥也干不了。"

【真正的成本 · 心理】
注：心理成本——打过官司的人都知道那种被吊着的感觉。不说"我很累"，说事实。
🎤 补讲：有没有哪个当事人，半夜给你打电话问进度？他说了什么？

例："还有心理上的。案子没结，心里就吊着一块石头。今天问进度，明天等通知，后天又没动静。这种消耗，比钱还磨人。"

【自己算过账 · 收口】
注：回扣开头——"所以我选择上门要"不是怂，是算得清。收口留白。
🎤 补讲：上门要那天，对方什么反应？最后怎么拿到的？

例："所以我自己的钱，我选择上门要。不是怕打官司。是这笔账，我比谁都算得清。"
```

## ⚠️ 注意事项

1. **第一句就是反差**："我帮别人打官司。自己的律师费被人拖着，我选择上门要，不起诉。" — 全片钩子。
2. **【🎤】是补讲位**：标了的地方，换成你真办过的那个案子、那位当事人的原话。想到哪个说哪个，不用凑。
3. **算账的口气**：平静、笃定，像老师傅点破行规。不渲染"打官司多苦"。
4. **两层成本**：时间（几个月几年）+ 心理（吊着石头）— 逐层揭，不并在一起。
5. **收口**："是这笔账，我比谁都算得清。" — 停在这，不追加"所以你也别打官司"。
6. **禁止**：劝退打官司（"你们别起诉了"）、渲染情绪（"我太难了"）、贬低法院、反问引导。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了结构之后用自己的话说。

我天天帮别人打官司，但前两天我自己的律师费被人赖了，我连诉状都没写，直接开车上门去要。🎤【哪个案子欠的？欠多少？】

所里年轻律师问我怎么不走程序，我跟他说我太清楚这里头的账了。法院收的那点诉讼费就是个零头，真正贵的是时间。🎤【你手上拖最久的案子拖了多久？当事人什么样？】

案子一旦扔进程序里，拖个几个月、一两年那都是常态，这期间你钱压在里头，整个人都得跟着干耗着。

更狗屎的是心理折磨，只要这案子一天没结，你心里就永远吊着这块石头。今天问进度，明天等通知，后天对面再给你玩个管辖权异议，这种天天被吊着胃口的消耗，比直接亏钱还磨人。🎤【有当事人半夜给你打电话问进度吗？他说了什么？】

所以我自己的钱，我宁愿跑一趟当面结清。真不是怕打官司，只是这笔账，我们干这行的算得比谁都清楚。🎤【上门要那天，对方什么反应？】
