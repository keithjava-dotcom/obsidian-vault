# 第06稿 · 律师的一周

## 🎬 封面标题建议

1. 律师的一周，跟走秀似的。不带彩排
2. 法庭上的律师你见过了。法庭外的，看这一周就够
3. 一周两次庭，加起来不到三小时。剩下165小时在干嘛

**封面文字**：朱律师 · 真实工作周记

**平台标题**：一周两次庭，加起来不到三小时。剩下165小时在干嘛。

## 🧭 结构走线

```
【钩子 · 跟走秀似的】
→ 随口一句，不解释。说完就进事件。
"律师的一周。跟走秀似的。不带彩排。"

【周一 · 十四件事零开庭】
→ 念清单，让观众觉得"好忙"——然后推翻。忙的跟开庭无关。
"开庭？一件都没有。"

【周二 · 开庭来了但重点不是庭】
→ 真正占脑子的不是开庭，是那个插着管的人。宋民只讲一半。
"人插着管。靠机器活着。"

【推进① · 你以为这就完了】
→ 当事人的心理独白。以为经历宋民这周不会再有什么事——然后周三砸过来。
"我以为这一周差不多就这样了。"

【周三 · 最重的一天】
→ 四层叠上去：体力→制度→法官原话→深夜被蹭。念到"中国法律没这条"别用力。
"凌晨两点才躺下。"

【周四 · 喘气】
→ 昨天凌晨两点，今天十点半。同行不是对手。
"同行之间。互相理解。"

【推进② · 刚缓过来】
→ 一口气刚喘匀，周五又来了——但这次不是体力，是另一种消耗。
"总算缓过来一点。"

【周五 · 另一种累】
→ 从体力消耗转到心理消耗。两边都看着你。
"说不出哪儿累。"

【周六 · 精神病院】
→ 周末？五个字就推翻。中间人立场冲突。
"风险必须完整摆出来。"

【推进③ · 没有周末】
→ 当事人自己的结论，不是导演旁白——你在意识到这行的周末不存在。
"周末？我就没过过周末。"

【周日 · 瞒了一周】
→ 在家。客户瞒了一周的三十个G。催方案。
"我毕竟不是算命的。"

【收口 · 循环】
→ 结束是新的开始。不是"我终于休息了"——是"下周一还有十四件事"。
"下周一。还是十四件事。"
```

## ⚠️ 注意事项

- **姿势**：周日晚上，一个人在办公室。面前一杯茶，手边是这周的工作日志。不是对镜头说话——是脑子里跟自己复盘。
- **说话方式**：讲发生过的事，不是在论证"走秀"这个观点。走秀那句说完就过。三个内部独白（"我以为差不多就这样了""总算缓过来一点""周末？我就没过过"）是当事人自己的反应，不是导演旁白——念的时候小声一点，像自言自语。
- **推进感**：周一到周二（事实密度升级）→ 周三到周四（体力极限到喘息）→ 周五到周六（心理消耗到职业荒诞）→ 周日（被背叛的感觉）。每一段结束后脑子里自然冒出一个"还能更夸张？"——下一段回答：能。
- **周三四重递进**：体力→制度扯皮→法官原话→深夜被蹭。法官说"你拿律师证去派出所调就行"时不激动——越平越有杀伤力。下一句"中国法律没这条"更平。
- **结尾**：不总结"所以律师很辛苦"。收在"下周一。还是十四件事"——让观众意识到这不是例外，是日常。
- **"我毕竟不是算命的"**：07-19日记原话。别改。嘴角带苦笑。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了讲戏卡之后自己说。现场有感觉的地方自由发挥，方向不跑偏就行。

---

律师的一周。
跟走秀似的。
不带彩排。

星期一。十四件事。
起草反诉状。改合同。写投标书。处理拆迁纠纷。
开庭？
一件都没有。

星期二。开庭了。
替人救火。徐主任的案子。宿迁。
来回三个半小时。
但那天开庭我心里想的不是这个。
是宋民。
上访路上出的车祸。一级伤残。高位截瘫。
人现在插着管。靠机器活着。
开完庭我跟对方律师说。
转达你们政府。直接雇个护工。这个等不了判决。

我以为这一周差不多就这样了。

星期三。
五点起来。十一个小时火车。
去浙江玉环调一份档案。
法院不给调查令。
我说符合条件就该出具。
法官说不用。你拿律师证去派出所调就行。
我做了这么多年律师。中国法律没这条。
七八通电话。我态度好。事情没让。
最后他们内部系统调出来的。之前全是在给我加难度。
晚上十一点回徐州。一天没吃饭。人是晕的。
去烧烤店吃碗面。
熟人认出来了。拉着咨询。
凌晨两点才躺下。

星期四。
头天凌晨两点睡的。十点半才起来。
本来有个庭。对方律师说时间冲突。我同意了。
打电话。写东西。
同行之间。互相理解。

总算缓过来一点。

星期五。上午见当事人。中间夹着个介绍人。
介绍人想打听当事人的事。
当事人不想让他知道。
两边都看着我。每句话都得想清楚再说。
下午谈判谈到八点。送同事回家。
路上又被咨询。
累。说不出哪儿累。

到了周六。连云港。
精神病院。股权尽调。
中间人是客户的朋友。他想平衡两边关系。
我想控制风险。立场不一样。
最后我跟他说。不管怎么选。风险必须完整摆出来。让客户自己决定。

周末？我就没过过周末。

星期天。在家。
客户发过来三十个G的录音视频。
瞒了我一个礼拜。今天才给我。
问我什么时候出方案。
我毕竟不是算命的。

走完这一周。
两次庭。加起来不到三个小时。
这就是律师的一周。

下周一。还是十四件事。
