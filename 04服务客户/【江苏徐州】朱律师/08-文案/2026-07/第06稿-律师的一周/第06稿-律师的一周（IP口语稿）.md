# 第06稿 · 律师的一周

## 🎬 封面标题

封面标题：一周两次庭，加起来不到三小时。剩下165小时在干嘛
封面文字：律师的一周 · 真实工作周记
平台标题：一周两次庭，加起来不到三小时。剩下165小时在干嘛。周一写反诉状写到晚上十一点，周三五点起来坐十一个小时火车调几页档案，周六一大早奔精神病院。

## 🧭 结构走线

```
【开场】
随口一说。说完就进。

律师的一周。跟走秀似的。不带彩排。

【周一 · 推翻预设】
坐下来，再抬头，天黑了。十四件事，没有一件是开庭。

开庭？零。一件都没有。

【周二 · 开庭了但心里不是庭】
嘴在说一个案子，脑子里全是另一个人。宋民只讲一半，"插着管靠机器活着"就够了。

这个等不了判决。

【周三 · 最重的一天】
五点起来，十一个小时火车，就为了几张纸。法官原话——"中国法律没有这一条"。凌晨两点终于躺下。

中国法律没有这一条。

【周四 · 因果】
凌晨两点→闹钟没听见→十点半醒。同事之间互相理解。不用解释难不难。

同行之间。互相理解。

【周五 · 换一种累】
体力刚缓过来，心理消耗接上。夹中间每句话在想。送完同事一个人在车里。

看着方向盘。

【周六 · 荒谬峰】
方向盘→精神病院。不是安排的桥段，是生活本身的荒谬在推。

一大早奔连云港。精神病院。

【周日 · 最后一刀】
以为搞定了。客户瞒了一个礼拜的三十个G终于砸过来。

我毕竟不是算命的。

【收口 · 回头看一眼】
讲完七天自己回头。不是总结道理，是发现了一个事实。

跟开庭没关系。但哪一件离得了法律。
```

## ⚠️ 注意事项

- **姿势**：周日晚上，办公室，一杯茶。跟一个熟人聊这周。聊着聊着自己也才刚想明白。
- **衔接不靠解释句**，靠事件之间的反差推：
  - "这个等不了判决"→"星期三。五点就起来了"：宋民的重量还没放下，人已经在火车上了
  - "凌晨两点。终于躺下了。"→"星期四。闹钟响的时候根本没听见"：身体替你做了决定
  - "看着方向盘"→"星期六。一大早奔连云港。精神病院"：荒谬感自己出来
- **周三那段**：念"中国法律没有这一条"别用力。越平越狠。
- **"我毕竟不是算命的"**：07-19 日记原话。苦笑，不真生气。
- **情绪曲线**：惊讶（周一）→沉（周二宋民）→更深（周三极限）→回升（周四缓过来）→憋屈（周五夹中间）→荒谬峰（周六精神病院）→背刺（周日瞒一周）→释然（收口）。
- **结尾**：不是朗诵。讲完了自己停下来想了想。跟自己说的。
- **禁止**：反问（"你猜""你知道吗"）、渲染（"我太难了"）、升华（"这就是律师的使命"）、数据堆砌。
