# 第06稿 · 律师的一周

## 🎬 封面标题建议

1. 一周开了两次庭，加起来不到三小时
2. 你猜律师一周开庭多久？不到三小时
3. 律师的一周：开庭是最小的事

**封面文字**：朱律师 · 真实工作周记

**平台标题**：开了两次庭，加起来不到三个小时。剩下的165小时在干嘛？

## 🧭 结构走线

```
【星期一 · 14件事，零开庭】
→ 上来就念清单，先建立"忙"的预期再推翻。观众以为是忙开庭？
"开庭？一件都没有。"

【星期二 · 替人救火】
→ 开庭终于来了，但重点在案子不在庭。宋民的故事不讲完，点到为止就够。
"人插着管。靠机器活着。"

【星期三 · 5点起来】
→ 最密的一天，速度快一点喘不过气。法院刁难、深夜被蹭，都是律师隐形成本。
"法院不给调查令。来回扯。"

【星期四 · 同行互谅】
→ 节奏突然慢下来，跟昨天形成落差。10点半起床不是懒，是真实。
"同行之间。互相理解。"

【星期五 · 夹在中间】
→ 不能说的累比体力累更憋。说明不了的处境。观众能感觉到那种憋。
"什么能说。什么不能说。"

【星期六 · 精神病院】
→ 周六两个字的意外感就够。中间人对立不加解释。
"他要平衡两边。我要控制客户风险。"

【星期天 · 瞒了一周】
→ 收在无奈不是愤怒。这句话只能朱律师自己说。
"我毕竟不是算命的。"

【收口 · 不到三小时】
→ 算总账。不替观众做减法，就停在这儿。
"这就是律师的一周。"
```

## ⚠️ 注意事项

- **状态**：周日晚坐在办公室，翻这周的工作日志给自己看。不是在做汇报，不是在诉苦，就是复盘。对着朋友可以聊的口吻。
- 每天只一件事，不展开流水账。念完一天停一下，让观众消化。
- 不加形容词。"很累""很辛苦""不容易"全删。让事实自己说话——五点起床、十一个小时火车、法院刁难、熟人趁你累咨询你、客户瞒你30G数据——这些东西摆在一起，不需要你再多说一句。
- 收口别补"但很值得"之类的话。到"不到三个小时"就停。加减法交给观众。
- "我毕竟不是算命的"是朱律师07-19日记原话，别改、别换成你自己的话。这种台词只有本人说才有味道。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了讲戏卡之后自己说。现场有感觉的地方自由发挥，方向不跑偏就行。

星期一。
十四件事。
改合同。写投标书。起草反诉状。处理拆迁纠纷。
开庭？
一件都没有。

星期二。
开庭了。
替徐主任救火。
宿迁。来回三个半小时。
手里还有个案子。宋民。
上访路上出的车祸。
一级伤残。
人插着管。靠机器活着。

星期三。
五点起来。
十一个小时火车。去浙江调一份档案。
法院不给调查令。来回扯。
晚上十一点到徐州。吃碗面。
熟人认出来了。
又拉着我咨询。
凌晨两点。睡觉。

星期四。
本来有庭。
对方律师申请调时间。我同意了。
十点半才起来。
打电话。写文件。
同行之间。互相理解。

星期五。
上午夹在介绍人和当事人中间。
什么能说。什么不能说。
下午谈判。谈到八点。
送人回家。路上又被咨询。
累。说不出口。

星期六。
连云港。
精神病院。股权尽调。
中间人立场跟我不同。
他要平衡两边。
我要控制客户风险。

星期天。
还在梳理录音。
客户手里有三十个G的录音视频。
瞒了我一个礼拜。
今天才给我。
我毕竟不是算命的。

这一周。
开了两次庭。
一次替人救火。一次调解。
加起来。
不到三个小时。

这就是律师的一周。
