# 第06稿 · 律师的一周

## 🎬 封面标题建议

1. 律师的一周，跟走秀似的。一件事接着一件事，不带彩排的
2. 法庭上的律师你见过了。法庭外的，看这一周就够
3. 你以为律师天天开庭？我这一周，跟开庭有关的，不到三小时

**封面文字**：朱律师 · 真实工作周记

**平台标题**：一周两次庭，加起来不到三小时。剩下165小时在干嘛。

## 🧭 结构走线

```
【钩子 · 跟走秀似的】
→ 随口一说，不展开解释。像朋友跟你聊到一半突然来了这么一句，然后接着往下说。
"律师的一周。跟走秀似的。各种事轮着登台。不带彩排。"

【周一 · 十四件事零开庭】
→ 先念清单让人感觉"好忙"，然后告诉观众：没一件跟开庭有关。
"开庭？一件都没有。"

【周二 · 开庭终于来了】
→ 但真正占脑子的不是这个庭——是那个插着管的人。宋民只讲一半，让观众自己补后一半画面。
"人插着管。靠机器活着。"

【周三 · 最重的一天】
→ 四层叠上去：体力→制度→法官原话→深夜被蹭。念到"中国法律没这条"别用力，越平越有杀伤力。
"中国法律没这条。"

【周四 · 喘口气】
→ 昨天凌晨两点，今天十点半才起。同行不是对手。
"同行之间。互相理解。"

【周五 · 憋着的累】
→ 从体力消耗转向心理消耗。不能说出口的比跑法院更磨人。
"什么能说。什么不能说。"

【周六 · 精神病院 ⚡ 再推高】
→ 连云港精神病院五个字就是走秀第二高峰。不加戏。
"他要平衡两边。我要控制客户风险。"

【周日 · 瞒了一周 ⚡ 最高峰】
→ 从体力到制度到人情——最后收在人。客户瞒了一周，还催方案。
"我毕竟不是算命的。"

【收口 · 不到三小时】
→ 走完这一周。回到观众最早的预设——开庭。算总账。不补"但很值得"。
"这就是律师的一周。"
```

## ⚠️ 注意事项

- **姿势**：周日晚上，一个人在办公室坐着。面前一杯茶，手边是这周的工作日志。不是对着镜头说话——是脑子里跟自己复盘。
- **说话方式**：讲发生过的事，不是在论证一个观点。走秀那句随口带过就行，后面七天直接推事件——不用"第一个第二个"编号，不用"但这才刚开始""终于到了""缓了一天"这些旁白。观众自己会感觉到事件在推着走。
- **周三四重递进**：体力（五点起床、十一个小时火车）→制度（法院不给调查令）→对白（法官说"你拿律师证直接去派出所调"——越平越有力量）→人情（深夜被蹭咨询、凌晨两点）。一层推一层。
- **别解释别总结**：全篇不出现"所以律师很辛苦""你们不知道律师背后付出了什么"。"不到三个小时"收住，观众脑子会自己算。
- **"我毕竟不是算命的"**：朱律师07-19日记原话，一个字别改。嘴角带苦笑，不是真生气。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了讲戏卡之后自己说。现场有感觉的地方自由发挥，方向不跑偏就行。

---

律师的一周。跟走秀似的。
各种你想不到的事。轮着登台。不带彩排。

星期一。十四件事。
起草反诉状。改合同。写投标书。处理拆迁纠纷。
开庭？
一件都没有。

星期二就不一样了。开庭了。
替徐主任救火。宿迁。来回三个半小时。
但那天我脑子里不是这个庭。
是宋民。
上访路上出的车祸。一级伤残。高位截瘫。
人现在插着管。靠机器活着。

星期三。五点起来。十一个小时火车。
去浙江玉环调一份档案。
法院不给调查令。
我说符合条件就该出具。
法官说不用。你拿律师证直接去派出所调身份信息就行。
我做律师这么多年。中国法律没这条。
七八通电话。态度好。事不让。
最后他们内部系统就调出来了。
之前全是在给我增加难度。
晚上十一点回徐州。一天没吃饭。人是晕的。
去烧烤店吃碗面。
熟人认出来了。拉着咨询。
凌晨两点才躺下。

星期四。
前一天凌晨两点睡的。十点半才起来。
本来有庭。对方律师申请调时间。我同意了。
打电话。写文件。
同行之间。互相理解。

星期五。上午见当事人。中间夹着介绍人。
他想通过我打听当事人的事。
当事人不想让他知道。
什么能说。什么不能说。每一句都得想清楚。
下午谈判谈到八点。送同事回家。
路上又咨询。
累。说不出哪儿累。

星期六。连云港。精神病院。股权尽调。
中间人是客户的朋友。他要平衡两边关系。
我要控制客户风险。立场不一样。
最后我跟他讲。不管怎么选。
风险必须完整摆出来。让客户自己决定。

星期天。在家梳理录音。
客户手里三十个G的录音视频。
瞒了我一个礼拜。今天才给我。
他问我什么时候出方案。
我毕竟不是算命的。

走完这一周。两次庭。
加起来。不到三个小时。
这就是律师的一周。
