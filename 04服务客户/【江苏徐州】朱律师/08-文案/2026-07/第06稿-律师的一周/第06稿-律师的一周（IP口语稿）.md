# 第06稿 · 律师的一周

## 🎬 封面标题建议

1. 一周开了两次庭，加起来不到三小时
2. 你猜律师一周开庭多久？不到三小时
3. 律师的一周：开庭是最小的事

**封面文字**：朱律师 · 真实工作周记

**平台标题**：开了两次庭，加起来不到三个小时。剩下的165小时在干嘛？

## 🧭 结构走线

```
【0帧钩子 · 不到三小时】
→ 上来就给反常识数字。观众以为律师天天开庭？直接推翻。
"我算了算上周。两次庭。加起来不到三个小时。"

【周一 · 14件事零开庭】
→ 先建立"很忙"再推翻预期——忙但不是忙开庭。念清单快一点，到"一件都没有"停住。
"开庭？一件都没有。"

【周二 · 开庭了但心里想的是宋民】
→ 开庭终于出现但重点不在庭，在那个案子。宋民只讲一半——让观众自己补后一半画面。
"人插着管。靠机器活着。"

【周三 · 5点到凌晨2点 ⚡ 全文最重】
→ 四重叠加：体力极限→法院刁难→具体对白→深夜被蹭。每层推一步，念到"中国法律没这条"的时候不要义愤填膺只是平说事实，越平越有力量。
"五点。十一个小时火车。法院说律师可以直接去派出所调身份信息。中国法律没这条。"

【周四 · 喘息】
→ 两行收。节奏突然慢下来是对昨天的呼应。10点半不是懒是真实。
"十点半才起来。同行之间。互相理解。"

【周五 · 说不出的累】
→ 不能说的累比体力累更堵。这种情绪不解释。
"什么能说。什么不能说。"

【周六 · 精神病院尽调 ⚡ 第二峰】
→ "精神病院"三个字本身就够意外，不加戏。中间人对立是职业困境。
"他要平衡两边。我要控制客户风险。立场不一样。"

【周日 · 30G瞒一周 ⚡ 收口峰】
→ 最累的一天不是体力。客户瞒了一周，今天才给30G数据。"我毕竟不是算命的"是日记原话，别改。
"他问我什么时候出方案。我毕竟不是算命的。"

【收口 · 算总账】
→ 回到开头那个数字。但这次观众已经知道165小时里装了什么。不加"但很值得"。
"两次庭。不到三个小时。这就是律师的一周。"
```

## ⚠️ 注意事项

- **状态**：周日晚，一个人坐在办公室翻这周的工作日志。不是在做汇报，不是诉苦，是复盘。说话对象是脑子里的另一个自己。
- **节奏**：周一快→周二收→周三大展开→周四两行喘气→周五憋→周六再推开→周日推到顶→收口落地。别念成匀速。
- **周三四重叠加**：体力（5点起14小时）→制度（法院不给调查令）→对白（"律师可以直接去派出所调身份信息"法庭原话）→人情（深夜被熟人蹭咨询）。每层推进一步，不是并列。
- **不解释**：全篇不出现"所以律师其实很辛苦""你们不知道律师背后付出了什么"这类话。事实自己解释。解释就是认输。
- **结尾**：不加"但很值得""我依然热爱"等升华。"不到三个小时"停住，观众自己算168减3。
- **"我毕竟不是算命的"**：朱律师07-19日记原话，别改成任何其他表述。这句话只有他本人说出来有味。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了讲戏卡之后自己说。现场自由发挥，方向不跑偏就行。

我算了算上周。
两次庭。加起来不到三个小时。
剩下165个小时在干什么。

星期一。十四件事。
改合同。写投标书。起草反诉状。处理拆迁纠纷。
开庭？一件都没有。

星期二。开庭了。
替徐主任救火。宿迁。
来回三个半小时。
但那天我脑子里想的不是这个庭。
是宋民。
上访路上出的车祸。
一级伤残。高位截瘫。
人现在插着管。靠机器活着。

星期三。
五点起床。十一个小时火车。
去浙江玉环调一份档案。
法院不给调查令。
说法官不需要给我出。
我说符合条件就必须出。
法官说。你可以直接拿律师证去派出所调任何人的身份信息。
我做了这么多年律师。中国法律没这条。
七八通电话。我态度好。事情不让。
最后他们从内部系统调出来了。
之前全是在给我加难度。
晚上十一点到徐州。
一天没吃饭。人是晕的。
去烧烤店吃碗面。
熟人认出来了。知道我是律师。拉着我咨询。
凌晨两点。睡觉。

星期四。
本来有庭。对方律师申请调时间。我同意了。
十点半才起来。
打电话。写文件。
同行之间。互相理解。

星期五。
上午见当事人。中间夹着介绍人。
介绍人想通过我打听当事人的事。
当事人不想让我说。
什么能说。什么不能说。
下午谈判。谈到八点。
送同事回家。路上又被咨询。
累。说不出哪儿累。

星期六。
连云港。精神病院。股权尽调。
中间人是客户的朋友。
他要平衡两边。
我要控制客户风险。
立场不一样。
但我得把风险说清楚。让客户自己选。

星期天。还在家梳理录音。
客户手里有三十个G的录音视频。
瞒了我一个礼拜。今天才给我。
他问我什么时候出方案。
我毕竟不是算命的。

这一周。
两次庭。不到三个小时。
这就是律师的一周。
