# 第06稿 · 律师的一周

**封面文字**：朱律师 · 真实工作周记

**平台标题**：律师的一周，就两件事跟开庭有关。剩下的全是走秀。

## 🧭 结构走线

```
【钩子 · 走秀现场】
→ 打破观众对律师的想象。用走秀比喻，一句话让观众重新想律师是干嘛的。
"律师的一周。就是一个大走秀现场。"

【第一件 · 星期一】
→ 念清单建立"忙"的感觉，然后推翻——忙的不是开庭。
"开庭？一件都没有。"

【第二件 · 星期二】
→ 开庭了但不是自己案子，更意外的是案子背后的人。宋民点到为止。
"人插着管。靠机器活着。"

【第三件 · 星期三 ⚡ 最重】
→ 四层递进：体力→法院踢皮球→法官原话→深夜被蹭。越到对白越平着念。
"中国法律没这条。"

【第四件 · 星期四】
→ 节奏松下来。昨天14小时，今天10点半才起。同行不是对手。
"同行之间。互相理解。"

【第五件 · 星期五】
→ 从体力累转向憋屈。什么能说什么不能说，比跑法院更消耗。
"什么能说。什么不能说。"

【第六件 · 星期六 ⚡ 再推】
→ 五个字本身就有冲击力。不加戏。中间人对立是真实职业处境。
"他要平衡两边。我要控制客户风险。"

【第七件 · 星期天 ⚡ 最高】
→ 瞒了一周加催方案，压到最后一天才给。"算命的"是日记原话。
"我毕竟不是算命的。"

【收口 · 走秀落幕】
→ 一周七场走完。回到观众最初的预设——开庭。然后揭晓。
"不到三个小时。这就是律师的一周。"
```

## ⚠️ 注意事项

- **姿势**：坐着，像跟律师同行聊天。不用"你们知道吗"那种对镜头的语气——是对面坐了一个人，你在跟他说这周发生的事。
- **推进感**：每一天结束时要有"还没完"的感觉——但不是台词里写"还没完"，是情绪到了观众自己觉得"还能更夸张？"然后你真的给了一个更夸张的。
- **周三展开最重**：体力（五点十一小时）→制度（法院踢皮球）→对白（"中国法律没这条"）→人情（深夜被蹭）——四重递进，每层推深一步。念的时候越到对白越平，越平越有力量。
- **不解释不总结**：全篇不出现"所以律师真的很累""你们不懂律师的苦"。"不到三个小时"就停，观众自己会做减法。
- **"我毕竟不是算命的"**：朱律师07-19日记原话，别改。念的时候嘴角带一丝苦笑，别真的生气。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了讲戏卡之后自己说。现场自由发挥，方向不跑偏就行。

---

律师的一周。就是一个大走秀现场。
你想不到的事。一个接一个。轮着登台。

第一个出场的。
星期一。十四件事。
改合同。写投标书。起草反诉状。处理拆迁纠纷。
开庭？一件都没有。

第二个。星期二。开庭了。
替徐主任救火。宿迁。
来回三个半小时。
但那天我脑子里想的不是这个庭。
是宋民。
上访路上出的车祸。一级伤残。高位截瘫。
人现在插着管。靠机器活着。

但这刚开始。
第三个。星期三。
五点起床。十一个小时火车。
去浙江玉环调一份档案。
法院不给调查令。
说法官不需要给我出。
我说符合条件就必须出。
法官说。你可以拿律师证直接去派出所调任何人的身份信息。
我做了这么多年律师。中国法律没这条。
七八通电话。态度好。事情不让。
最后他们从内部系统调出来了。
之前全是在给我加难度。
你以为今天结束了？
晚上十一点到徐州。一天没吃饭。人是晕的。
去烧烤店吃碗面。
熟人认出来了。知道我是律师。拉着我咨询。
凌晨两点。睡觉。

还没完。
第四个。星期四。
刚喘口气。本来有庭。对方律师申请调时间。
我同意了。十点半才起来。
打电话。写文件。
同行之间。互相理解。

但紧接着。第五个。星期五。
上午见当事人。中间夹着介绍人。
介绍人想通过我打听当事人的事。
当事人不想让我说。
什么能说。什么不能说。
下午谈判。谈到八点。
送同事回家。路上又被咨询。
累。说不出哪儿累。

周末？没有。
第六个。星期六。
连云港。精神病院。股权尽调。
中间人是客户的朋友。
他要平衡两边。我要控制客户风险。
立场不一样。
但我得把风险说清楚。让客户自己选。

最后一天。最过分的来了。
第七个。
星期天。还在家梳理录音。
客户手里有三十个G的录音视频。
瞒了我一个礼拜。今天才给我。
他问我什么时候出方案。
我毕竟不是算命的。

走完这一周。
开了两次庭。加起来不到三个小时。
这就是律师的一周。
