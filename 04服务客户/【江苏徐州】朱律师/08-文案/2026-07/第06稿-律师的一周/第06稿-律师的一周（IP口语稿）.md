# 第06稿 · 律师的一周

**封面文字**：朱律师 · 真实工作周记

**平台标题**：一周两次庭，加起来不到三小时。剩下165小时在干嘛。

## 🧭 结构走线

```
【钩子 · 跟走秀似的】
→ 随口一说，不解释。说完就进。
"律师的一周。跟走秀似的。不带彩排。"

【周一 · 十四件事零开庭】
→ 念清单推翻预期。"你以为律师就是开庭"——不是结论，是这一周的开场白。
"开庭？一件都没有。"

【周二 · 开庭了但心里不是庭】
→ 开庭了但不是自己的案子。庭上说着话，脑子里是另一个人。宋民只讲一半。
"人插着管。靠机器活着。已经没有经济来源了。"

【推① · 情绪残留】
→ 不是"我以为结束了"——是开完庭坐在车里，脑子出不来。那个插着管的人跟了你一整夜。然后五点闹钟响了。
"你没办法不想他。但五点还是起来了。"

【周三 · 最重的一天】
→ 四层：体力→扯皮→法官原话→深夜被蹭。念"中国法律没有这一条"别用力。
"凌晨两点才躺下。"

【推② · 身体不是自己的】
→ 不是"第二天十点半起来"——是闹钟响了你根本没听见。前一天的账今天在还。
"身体已经不像是自己的了。"

【周四 · 因果】
→ 不是独立的一天，是周三的尾款。同行之间互相理解。但缓过来也就一天的事。
"昨天凌晨两点的账。今天在还。"

【推③ · 换一种消耗】
→ 体力刚还完，心理消耗接上。夹在中间每句话都得想。送完同事回家，车上坐了会儿。不是累——说不出哪儿累。
"我看着方向盘。脑子已经不转了。"

【推④ · 荒谬推进】
→ 周五脑子不转→周六连云港精神病院。不是故意安排的桥段，是生活本身的荒谬。
"连云港。精神病院。股权尽调。"

【推⑤ · 最后一下】
→ 以为总算能在家了。没有。星期天。客户发过来三十个G。瞒了一个礼拜。
"我毕竟不是算命的。"

【收口 · 算账发现】
→ 讲完七天自己回头看。不是提前准备的结论——是刚发现的：开庭不到三小时，其他全跟开庭没关系，但全跟法律有关系。
"这些事跟开庭没关系。但每一件都离不了法律。"
```

## ⚠️ 注意事项

- **姿势**：周日晚上，办公室。面前一杯茶，手边是这周的工作日志。跟一个熟人复盘这一周。
- **腔调**：体验腔。你不是在解释"律师有多不容易"——你是在重新经历这一周。越说越发现自己这周干了什么。
- **衔接是情绪在推，不是句子在推**——
  - 周二宋民插管 → 在车里坐了很久 → 那个画面跟了你一整夜 → 五点起来的时候脑子还在那。不是"然后星期三"，是**宋民的重量还没放下，火车已经在动了**。
  - 周三凌晨两点躺下 → 闹钟响了没听见 → 十点半才醒来。不是"然后星期四"，是**身体替你做了决定**。
  - 周五脑子不转 → 接着周六就到了精神病院。不是故意安排的桥段——是**生活本身的荒谬在推着你走**。
  - 周六总算搞定 → 想着在家待一天 → 周日客户三十个G砸过来。不是"然后星期天"，是**松一口气的瞬间就是下一次打击**。
- **周三那段**：念"中国法律没有这一条"越平越狠。到了"凌晨两点才躺下"让观众自己感觉到。
- **"我毕竟不是算命的"**：07-19日记原话。别改。苦笑，不真生气。
- **结尾七行**：不是朗诵。讲完七天自己停下想了想，发现了一个事实。说给自己听的。

律师的一周。
跟走秀似的。不带彩排。

星期一。十四件事。
起草反诉状。改合同。写投标书。处理拆迁纠纷。
从早上一直弄到晚上十一点。
开庭？
一件都没有。
你以为律师就是开庭。你看看这一天我在干什么。

星期二。开庭了。
但不是我的案子。
徐主任临时有个会。我去替他。宿迁。
来回三个半小时。
那天在庭上我代表当事人在说话。但我脑子里想的不是这个案子。
是一个叫宋民的人。
上访的路上出的车祸。一级伤残。高位截瘫。
人现在插着管。靠机器活着。已经没有经济来源了。
开完庭我跟对方律师说。
转达政府。直接给他雇个护工。这个等不了判决。

开完庭那天我在车里坐了很久。
不是累。
是那个插着管的人。你没办法不想他。
但我没办法停下来想他。
第二天早上五点。又起来了。

十一个小时火车。去浙江玉环调一份档案。
就为了一份工商登记材料。
到了之后。法院不给调查令。
我说符合条件就该出具。
法官跟我说，不用调查令。你拿律师证去派出所调就行。
我做了这么多年律师。中国法律没有这一条。
七八通电话。态度很好。事情没让。
最后从内部系统调出来的。也就是说之前全是在给我加难度。
晚上十一点回到徐州。
一天没吃饭。人是晕的。
去烧烤店吃了碗面。
熟人认出来了。拉着咨询。
凌晨两点才躺下。

躺下去的时候。身体已经不像是自己的了。
第二天闹钟响的时候我根本没听见。
十点半才醒。
本来有个庭。对方律师说时间冲突能不能调。我说行。
打电话。写文件。
同行之间。互相理解。
昨天凌晨两点的账。今天在还。

缓过来。也就是一天的事。
星期五。上午见当事人。中间夹着个介绍人。
介绍人想打听当事人的情况。当事人不想让他知道。
我夹在中间。每句话都得在脑子里过一遍。
下午谈判谈到八点。送同事回家。
路上她又问法律问题。
送完她我在车里坐了一会儿。
不是累。是说不出哪儿累。
我看着方向盘。脑子已经不转了。

星期六。连云港。
精神病院。股权尽调。
中间人是客户的朋友。他想平衡两边。
我想控制风险。立场不一样。
最后我跟他说。不管怎么选。风险必须完整摆出来。让客户自己决定。
他同意了。

我想着总算能在家待一天了。
星期天。客户发过来三十个G的录音视频。
瞒了我一个礼拜。今天才给我。
发完问我什么时候出方案。
我毕竟不是算命的。

走完这一周。两次庭。
加起来不到三个小时。

我算了算剩下的时间都在干嘛。
跑外地。调档案。精神病院做尽调。被法院反复刁难。
深夜吃碗面被拉着问法律问题。夹在介绍人跟当事人中间每句话都得想。

这些事跟开庭没关系。
但每一件都离不了法律。

这就是律师的一周。
下周一。还是十四件事。
