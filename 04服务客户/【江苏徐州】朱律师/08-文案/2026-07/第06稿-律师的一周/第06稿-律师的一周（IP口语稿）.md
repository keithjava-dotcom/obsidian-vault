# 第06稿 · 律师的一周

## 🎬 封面标题建议

1. 一周开了两次庭，加起来不到三小时
2. 你猜律师一周开庭多久？不到三小时
3. 律师的一周：开庭是最小的事

**封面文字**：朱律师 · 真实工作周记

**平台标题**：开了两次庭，加起来不到三个小时。剩下的165小时在干嘛？

## 🧭 结构走线

```
【14件事，开庭0件】
→ 上来就念工作清单，别铺垫。改合同写投标书这些具体活，见过律师工作的会有感受。
"星期一。14件事。改合同。写投标书。起草反诉状。处理拆迁纠纷。开庭？一件都没有。"

【替徐主任救火】
→ 开庭了，但重点不在开庭——在那个案子。宋民的故事一句话就够。念到"靠机器活着"停一下。
"星期二。开庭了。替徐主任救火。宿迁。来回三个半小时。"

【5点起床，14个小时】
→ 这一天事最密。5点到凌晨两点，念快一点让观众感觉喘不过气。到"吃碗面"松口气，然后熟人咨询又捅一刀。
"星期三。5点起来。11个小时火车。去浙江调一份档案。"

【10点半才起来】
→ 节奏突然慢下来。昨天14小时今天10点半才起——这才是真实的。同行互谅这句别用力，平着念。
"星期四。本来有庭。对方律师申请调时间。我同意了。10点半才起来。打电话。写文件。同行之间。互相理解。"

【什么能说什么不能说】
→ 这种憋着的累比体力累更难。念到"累但说不出口"别叹气，就停在那儿。
"星期五。上午夹在介绍人和当事人中间。什么能说。什么不能说。"

【精神病院尽调】
→ 周六出现精神病院三个字本身就够意外，别加戏。中间人那段想想自己经历过的类似处境再念。
"星期六。连云港。精神病院。股权尽调。"

【30个G，瞒了我一周】
→ 七天里最累的一天。不是体力——是客户瞒了你一周。念"毕竟不是算命的"嘴角带一点无奈，别真的生气。
"星期天。还在梳理录音。客户手里有30个G的录音视频。瞒了我一个礼拜。今天才给我。我毕竟不是算命的。"

【不到三个小时】
→ 算总账。念完"不到三个小时"停三秒，然后平着把最后一句念完。别加重语气。
"这一周我开了两次庭。一次替人救火。一次调解。加起来。不到三个小时。这就是律师的一周。"
```

## ⚠️ 注意事项

- **状态**：周日晚坐在办公室，跟一个朋友复盘这周。不是诉苦，不是炫耀。像翻开工作日志，念到哪算哪。
- 每条一天、一件事，别展开成流水账。念完一段停一下，让观众消化。
- 别加形容词。"很累""很辛苦"之类的话一个字都别多。让事实自己说话。
- 收口别补"但很值得"之类的话。就到"不到三个小时"——观众自己会算168减3等于多少。
- 全篇没有一句"律师好累"，但看完观众自己会觉得。要的就是这个效果。

星期一。
14件事。
改合同。写投标书。起草反诉状。处理拆迁纠纷。
开庭？
一件都没有。

星期二。
开庭了。
替徐主任救火。
宿迁。来回三个半小时。
手里还有个案子。宋民。
上访路上出的车祸。
一级伤残。
人插着管。靠机器活着。

星期三。
5点起来。
11个小时火车。去浙江调一份档案。
法院不给调查令。来回扯。
晚上11点到徐州。吃碗面。
熟人认出来了。
又拉着我咨询。
到家。凌晨两点。

星期四。
本来有庭。
对方律师申请调时间。我同意了。
10点半才起来。
打电话。写文件。
同行之间。互相理解。

星期五。
上午夹在介绍人和当事人中间。
什么能说。什么不能说。
下午谈判。谈到8点。
送人回家。路上又被咨询。
累。但说不出口。

星期六。
连云港。
精神病院。股权尽调。
中间人立场跟我不同。
他要平衡两边。
我要控制客户风险。

星期天。
还在梳理录音。
客户手里有30个G的录音视频。
瞒了我一个礼拜。
今天才给我。
我毕竟不是算命的。

这一周我开了两次庭。
一次替人救火。一次调解。
加起来。
不到三个小时。

这就是律师的一周。
