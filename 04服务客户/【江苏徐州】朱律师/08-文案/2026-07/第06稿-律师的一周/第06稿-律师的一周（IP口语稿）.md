# 第06稿 · 律师的一周

## 🎬 封面标题建议

1. 律师的一周，跟走秀似的。不带彩排
2. 法庭上的律师你见过了。法庭外的，看这一周就够
3. 一周两次庭，加起来不到三小时。剩下165小时在干嘛

**封面文字**：朱律师 · 真实工作周记

**平台标题**：一周两次庭，加起来不到三小时。剩下165小时在干嘛。

## 🧭 结构走线

```
【钩子 · 随口一说】
→ 不展开。说完就进。
"律师的一周。跟走秀似的。不带彩排。"

【周一 · 推翻预设】
→ 坐下来→再抬头天黑了。十四件事没有一件是开庭。
"开庭？零。一件都没有。"

【周二 · 开庭了但心里不是庭】
→ 嘴在说一个案子，脑子里全是另一个人。宋民只讲一半，"插着管靠机器活着"就够了。
"这个等不了判决。"

【周三 · 最重的一天】
→ 五点起来，十一个小时火车，就为了几张纸。法官原话，不反驳，只说事实——"中国法律没有这一条"。凌晨两点终于躺下。
"中国法律没有这一条。"

【周四 · 因果】
→ 凌晨两点→闹钟没听见→十点半醒。同事之间互相理解。不用解释难不难。
"同行之间。互相理解。"

【周五 · 换一种累】
→ 体力刚缓过来，心理消耗接上。夹中间每句话在想。送完同事一个人在车里。
"看着方向盘。"

【周六 · 荒谬峰】
→ 方向盘→精神病院。不是安排的桥段，是生活本身的荒谬在推。
"一大早奔连云港。精神病院。"

【周日 · 最后一刀】
→ 以为搞定了。客户瞒了一个礼拜的三十个G终于砸过来。立刻催方案。
"我毕竟不是算命的。"

【收口 · 回头看一眼】
→ 讲完七天自己回头。不是总结道理，是发现了一个事实。
"跟开庭没关系。但哪一件离得了法律。"
```

## ⚠️ 注意事项

- **姿势**：周日晚上，办公室。面前一杯茶。跟一个熟人聊这周。聊着聊着自己也才刚想明白。
- **衔接不靠解释句**，靠事件之间的反差推——
  - "这个等不了判决"→"星期三。五点就起来了"：不需要说"我很难过"——宋民的重量还没放下，人已经在火车上了。
  - "凌晨两点。终于躺下了。"→"星期四。闹钟响的时候根本没听见"：身体替你做了决定。不需要解释。
  - "看着方向盘"→"星期六。一大早奔连云港。精神病院"：从一个人对着方向盘发呆，直接切到精神病院——荒谬感自己出来。
  - "他同意了"→"星期天。客户发过来三十个G"：刚搞定就砸新的。观众替你感觉到了。
- **周三那段**：念"中国法律没有这一条"别用力。越平越狠。
- **"我毕竟不是算命的"**：07-19日记原话。苦笑，不真生气。
- **情绪曲线**：惊讶（周一）→沉（周二宋民）→更深（周三极限）→回升（周四缓过来）→憋屈（周五夹中间）→荒谬峰（周六精神病院）→背刺（周日瞒一周）→释然（收口）。
- **结尾**：不是朗诵。讲完了自己停下来想了想。跟自己说的。

---

律师的一周。
跟走秀似的。不带彩排。

星期一。早上九点坐下来。
写反诉状。审合同。投标书。拆迁纠纷。
一口气弄到晚上十一点。
你猜这十四件事里有几件是开庭。
零。一件都没有。

星期二。总算开庭了。
但不是我的案子。替人去的。宿迁。
来回三个半小时。
在庭上我嘴在说当事人的话。脑子里全是另一个人。
宋民。
上访路上出的车祸。一级伤残。高位截瘫。
人插着管。靠机器活着。没有经济来源了。
开完庭我跟对方律师说。
转达政府。直接给他雇个护工。
这个等不了判决。

星期三。五点就起来了。
从徐州坐火车到玉环。十一个小时。
就为了调一份工商内档。几张纸的事。
到了法院。不给调查令。
我说符合条件就该出具。
法官跟我说，不用调查令。你拿律师证去派出所调就行。
我做了这么多年律师。
中国法律没有这一条。
七八通电话打出去。态度都很好。事情都不让。
最后他们内部系统调出来的。
晚上十一点回到徐州。
一天没吃饭。人是晕的。
找个烧烤店要了碗面。
熟人认出来了。拉着我咨询。
凌晨两点。终于躺下了。

星期四。闹钟响的时候根本没听见。
十点半才醒。
本来有个庭。对方律师说时间冲突能不能调。我说行。
打电话。写文件。
同行之间。互相理解。

星期五。上午见当事人。中间夹着个介绍人。
介绍人想打听当事人的情况。当事人不想让他知道。
他问一句。我在脑子里转三秒。再开口。
下午谈判。从两点谈到八点。
送同事回家。车还没停稳她就开始问法律问题。
送完她我没马上走。在车里坐了一会儿。
看着方向盘。

星期六。一大早奔连云港。
精神病院。做股权尽调。
中间人是客户的朋友。他想平衡两边的关系。
我想控制风险。立场不一样。
最后我跟他说。不管选哪条路。你自己走。但风险必须完整摆在你面前。
他同意了。

星期天。客户发过来三十个G的录音视频。
瞒了我整整一个礼拜。今天才给我。
发完问我什么时候出方案。
我毕竟不是算命的。

回头看一眼这一周。
两次庭。加在一起不到三个小时。

剩下的大把时间。跑外地。调档案。精神病院做尽调。
被法院反复刁难。深夜吃碗面被拉着咨询。
夹在介绍人跟当事人中间。每句话都得想。

跟开庭没关系。
但哪一件离得了法律。

这就是律师的一周。
下周一。还是十四件事。
