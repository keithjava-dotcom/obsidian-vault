# 第06稿 · 律师的一周

## 🎬 封面标题建议

1. 律师的一周，就是一个大型走秀现场
2. 法庭上的律师你见过了。法庭外的，看这一周就够
3. 你以为律师天天开庭？我这一周，跟开庭有关的，不到三小时

**封面文字**：朱律师 · 真实工作周记

**平台标题**：一周两次庭，加起来不到三小时。剩下165小时在干嘛。

## 🧭 结构走线

```
【钩子 · 走秀现场】
→ 上来就给观众一个没听过的比喻，让他们重新想律师是什么。
"律师的一周。就是一个大型走秀现场。"

【周一 · 十四件事零开庭】
→ 先念清单让人感觉"好忙"，然后告诉观众：没一件跟开庭有关。
"开庭？一件都没有。"

【周二 · 开庭不是重点】
→ 开庭终于出现了。但真正占脑子的不是庭——是那个插着管的人。
"人插着管。靠机器活着。"

【周三 · 最重的一天】
→ 四重叠加：体力→制度→法院原话→深夜被蹭。念到法官那两句话别用力，越平越有杀伤力。
"中国法律没这条。"

【周四 · 喘口气】
→ 昨天凌晨两点，今天十点半才起。同行不是对手，是真的互相理解。
"同行之间。互相理解。"

【周五 · 憋着说不出来的累】
→ 从体力累转向心理消耗。不能说出口的比跑法院更磨人。
"什么能说。什么不能说。"

【周六 · 精神病院 ⚡ 再推高】
→ 连云港精神病院五个字就是走秀第二高峰。不加戏。
"他要平衡两边。我要控制客户风险。"

【周日 · 瞒了一周 ⚡ 最高峰】
→ 从体力到制度到人情——最后收在人。客户瞒了你一周，还催你出方案。
"我毕竟不是算命的。"

【收口 · 不到三小时】
→ 所有东西走完。回到观众最早的预设——开庭。然后算总账。不补"但很值得"。
"不到三个小时。这就是律师的一周。"
```

## ⚠️ 注意事项

- **姿势**：周日晚上，一个人在办公室坐着。面前一杯茶，手边是这周的工作日志。不是对着镜头说话——是脑子里跟自己复盘。
- **节奏**：周一快念→周二慢下来（宋民那里停一下）→周三大段展开、语速加快、越到法官对白越平→周四突然松→周五憋着讲→周六周日推到最高→收口落地。整篇是一条从"忙"到"消耗"到"荒谬"的弧线，不是七条平行线。
- **周三四重递进**：体力（五点起床、十一个小时火车）→制度（法院不给调查令、来回扯皮）→对白（"律师可以直接去派出所调身份信息"法庭原话——越平越有力量）→人情（深夜被熟人蹭咨询、凌晨两点才睡）。一层推一层，最后一层最轻但最磨人。
- **别解释别总结**：全篇不出现"所以律师很辛苦""你们不知道律师背后付出了什么"。事实自己解释，解释就是认输。"不到三个小时"收住，观众脑子会自己算168减3。
- **"我毕竟不是算命的"**：朱律师07-19日记原话，一个字别改。念的时候嘴角带苦笑，不是真的生气。

律师的一周。
就是一个大型走秀现场。
各种你想不到的事。轮着登台。没有彩排。

星期一。幕布拉起来。
十四件事。起草反诉状。改合同。写投标书。处理拆迁纠纷。
开庭？
从头到尾一件都没有。

到了星期二。开庭终于来了。
但不是我的。
替徐主任救火。宿迁。去了一趟。回来。
来回三个半小时。
不过那天真正占我脑子的。不是这个庭。
是宋民。
上访路上出的车祸。一级伤残。高位截瘫。
人现在插着管。靠机器活着。

但这才刚开始。
星期三。五点起床。十一个小时火车。从徐州坐到温岭。
去浙江玉环调一份档案。
法院不给调查令。
我说符合条件就应该出具。
法官跟我说。你不用调查令。拿律师证直接去派出所调身份信息就行。
我做律师这么多年。
中国法律没有这一条。
七八通电话。来回扯。态度我很好。但事情没让。
最后他们从内部系统就调出来了。
之前全是在给我增加难度。
你以为这一天到这就完了？
晚上十一点到徐州。一天没吃饭。人是晕的。
去烧烤店吃了碗面。
熟人认出来了。知道我是律师。拉着咨询。
凌晨两点。才躺下。

终于到了星期四。
前一天凌晨两点睡的。今天没定闹钟。十点半才起来。
本来有个庭。对方律师申请调时间。我同意了。
这种事同行之间经常遇到。
打电话。写文件。互相理解。

缓了一天。星期五又被卷进去。
上午见当事人。中间夹着一个介绍人。
介绍人想通过我打听当事人的事。
当事人不想让介绍人知道。
什么话能说。什么话不能说。
每一句都得想清楚。
下午谈判。谈到八点。送同事回家。
路上又被拉着咨询。
累。但说不出哪儿累。

我以为周末能歇一下。
并没有。星期六。连云港。
精神病院。股权尽调。
客户的朋友是中间人。他的立场跟我完全不一样。
他要平衡两边的关系。
我要控制客户这边的风险。
最后我跟他讲。不管怎么选。
风险必须完整摆出来。让客户自己决定。

周六跑完连云港。周日想着总算可以在家了。
并没有。
客户手里有三十个G的录音视频。
瞒了我一个礼拜。今天才给我。
他问我。什么时候能出方案。
我毕竟不是算命的。

走完这一周。
开了两次庭。加起来。不到三个小时。
这就是律师的一周。
