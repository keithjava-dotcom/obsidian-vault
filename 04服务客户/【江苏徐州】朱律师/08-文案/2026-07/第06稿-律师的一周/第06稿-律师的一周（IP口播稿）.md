## 🧭 结构走线

```
【星期一，14件事 · 0:00-0:15】
→ 上来就翻日记，一句一句念。别铺垫，直接让人看到"开庭？零"这个反差。
"星期一。14件事。开庭？零。"

【替人救火 · 0:15-0:35】
→ 周二开庭了但不是我自己的案子。宋民的事说清楚：上访路上车祸、一级伤残、等不了判决。那个"直接给他雇护工"就是你跟对方律师说的原话。
"开庭了。替人救火。"

【14个小时在路上 · 0:35-1:00】
→ 5点起床这个数字很重要。法院不给调查令那段，别加情绪——就陈述来来回回的过程。晚上吃面被蹭咨询，不用演"好烦"，就平淡说出来。
"星期三。5点起床。火车上11个小时。"

【同行之间 · 1:00-1:15】
→ 这段最短，口气最松。对方律师申请调时间，你同意了。一句"同行之间，互相理解"就够了——不解释。
"星期四。10点半才起。"

【夹在中间 · 1:15-1:35】
→ 介绍人和当事人之间——什么能说、什么不能说。谈判到8点。送人回家还被咨询。注意"很疲惫"这三个字别加重读，让它自己去。
"夹在介绍人和当事人中间。"

【星期六，没有周末 · 1:35-1:55】
→ 连云港精神病院——这个地方名要念清楚，反差在"精神病院"这个词上。中间人立场冲突不展开，一句话带过：他要平衡两边，我要控制风险。最后补"星期六，没有周末"——不在感叹，在陈述。
"连云港。精神病院。"

【我毕竟不是算命的 · 1:55-2:15】
→ 周日还在听录音。30个G是钩子。客户瞒了一周，今天才给你。最后那句"我毕竟不是算命的"——不用笑，不用摇头，就是自言自语。
"30个G。瞒了我一个礼拜。"

【不到三小时 · 2:15-2:30】
→ 算账。两次庭，替人救火一次，调解一次。加起来不到三小时。最后一句不加重，让它自己掉下来。
"加起来。不到三个小时。"
```


## ⚠️ 注意事项

1. **别演，别加形容词。** 这就是翻工作日志给人看，如实念。不加"好累""好烦""太不容易了"——事件本身够重了。
2. **每天之间留一口气。** 不是"然后星期二""然后星期三"——是翻过一页日历。停顿1-2秒。
3. **收尾"不到三个小时"不加重读。** 不给笑脸、不叹气、不摊手。就像在算一笔账，算完了把笔放下。
4. **朱律师的声音**：叙事驱动，短句，不煽情。"我毕竟不是算命的"那种语气——对自己说的话，不是对观众说的话。


## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

星期一。14件事。开庭？零。
改合同。写投标书。起草反诉状。处理拆迁纠纷。
全在桌子上，全是纸。

星期二。开庭了。
替人救火，徐主任的案子。
当事人叫宋民。
上访途中出的车祸。一级伤残。高位截瘫。
插着管，机器维持。

我跟对方律师说：转达你们政府，直接给他雇个护工。
这个等不了判决。

星期三。5点起床。
火车上11个小时。来回14个小时。
就为调一份档案。
法院调查令，不给。来来回回，就是不给。

晚上11点到徐州。吃碗面。
熟人看见我了。又拉着咨询。

凌晨2点。睡。

星期四。10点半才起。
对方律师申请调时间。我同意了。
不同立场。但同行之间，互相理解。

星期五。
夹在介绍人和当事人中间。
什么能说，什么不能说。
下午谈判到8点。
送人回家。路上又咨询我。
很疲惫。

星期六。连云港。
精神病院。股权尽调。
中间人的立场和我完全不一样。
他要平衡两边。我要控制客户风险。
星期六。没有周末。

星期天。还在听录音。
30个G。
录音和视频。客户手里一直有这些。
瞒了我一个礼拜。今天才给我。
我毕竟不是算命的。

这一周。开了两次庭。
一次替人救火。一次调解。
加起来。不到三个小时。
这一周。我没停下来过。
