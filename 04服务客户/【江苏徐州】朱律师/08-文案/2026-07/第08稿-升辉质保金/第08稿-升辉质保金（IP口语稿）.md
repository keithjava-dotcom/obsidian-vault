# 第08稿 · 他想打官司，我说先发封函——昨天发，今天钱到了

## 🎬 封面标题

封面标题：他想打官司，我说先发封函——昨天发，今天钱到了
封面文字：他想打官司，我说先发封函——昨天发，今天钱到了
平台标题：客户想起诉，我说没必要，先发一封函过去。昨天发的材料，今天对方就付钱了——7500块质保金。解决问题才是核心，打官司不是。

## 🧭 结构走线

```
【结论先行 · 结果砸出来】
第一句就给结果。反差：想打官司 vs 一封信解决。

"客户想让我起诉，我说没必要。先发了一封函过去——昨天发的材料，今天对方就把钱付了。"

【背景 · 两句话】
为什么想起诉。一句带过。

"启平公司的质保金，对方一直没付。他们想让我起诉升辉。"

【为什么不用打 · 常识判断】
他的判断逻辑。不讲法律流程，讲常识。

"我说没必要。对方可能不是不想付，是没收到正式的材料，没法走程序。"

【做法 · 一个台阶】
给对方一个能向上汇报的东西。

"先发一封沟通函过去，让对方的法务能向上汇报工作。"

【结果 · 干净利落】
昨天发，今天付。数字具体。

"昨天发的材料，今天对方就愿意付钱了，7500块。"

【收口 · 戴律式判断】
"解决问题这四个字才是核心"。

"律师的价值，不光是打官司。有时候给对方一个台阶，比起诉快得多。"
```

## ⚠️ 注意事项

1. **第一句就是结果**："客户想让我起诉，我说没必要。先发了一封函过去——昨天发的材料，今天对方就把钱付了。" — 反差即钩子。
2. **去打字机**：句子干脆流动，不碎。
3. **不讲法律流程**：不提"催款函""质保金条款"这些专业名词怎么走，就讲"给个台阶"。
4. **姿势**：简单的故事，干脆地讲。像跟朋友说"这单我没打官司，一封信搞定了"。
5. **收口**："解决问题这四个字才是核心" — 戴律式判断，不喊口号。
6. **禁止**：专业术语堆砌、说教（"所以企业主们要记住"）、打字机断行。
