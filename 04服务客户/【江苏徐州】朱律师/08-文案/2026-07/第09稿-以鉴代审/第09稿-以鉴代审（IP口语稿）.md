# 第09稿 · 我们行业里有个词，叫"以鉴代审"

## 🎬 封面标题

封面标题：法官不想审，直接让鉴定机构上——行业里叫"以鉴代审"
封面文字：法官不想审，直接让鉴定机构上——行业里叫"以鉴代审"
平台标题：装修纠纷，对方自己做了个增项表就起诉了，按合同应该双方确认。法官为了省事，直接让鉴定机构入场，什么都干。我们行业里有个词，叫"以鉴代审"。

## 🧭 结构走线

```
【结论先行 · 词砸出来】
第一句就把行业黑话亮出来。让外行想听，让内行会心。

"我们行业里有个词，叫以鉴代审。"

【案例 · 具体事】
装修案。对方自己做的增项表，没让双方确认就起诉了。

"一个装饰装修的案子。对方自己做了一个增项表，没有按合同规定让双方确认，就直接到法院起诉了。"

【法官的操作 · 平静陈述】
不愤怒，就讲他干了什么。

"法官为了省事，直接让鉴定机构入场。"

【解释 · 什么叫以鉴代审】
一句话讲白。

"什么叫以鉴代审？就是法官为了自己省事，不审理合法要件，让鉴定机构什么都做。"

【收口 · 戴律式判断+留白】
不骂法官，收在现象本身。

"这个案子，28号鉴定机构入场。拿到结果之后，我再给大家做案件分析。"
```

## ⚠️ 注意事项

1. **第一句就是结论**："我们行业里有个词，叫以鉴代审。" — 平静地抛黑话，不炸不喊。
2. **去打字机**：句子流动。参照"对方自己做了一个增项表，没有按合同规定让双方确认，就直接到法院起诉了" — 一口气讲完。
3. **不是愤怒**：柯哥明确要求"平静地讲一个现象"。法官的操作原样陈述，不加形容词。
4. **"什么叫以鉴代审？"** — 用自问自答推进（他的句式），不是反问观众。
5. **收口**："拿到结果之后，我再给大家做案件分析" — 留白收束，未完感。
6. **禁止**：骂法官、煽动情绪、说教、打字机断行。
