# IP口语稿 朱律师 律师自保的两个细节 2026-07-26

## 🎬 封面标题建议

**三个候选：**

1. **被当事人反水过一次，我养成了两个习惯**
2. **律师自保的两个动作：留痕和原件交接**
3. **做了这么多年律师，这两件事我从不含糊**

**封面文字**：被反水过 所以这么干

**平台标题**：被当事人反水说方案是你自己拿的主意？两个动作让律师不吃哑巴亏

## 🧭 结构走线

```
【开场 · 0:00-0:10】
→ 直接给冲突——被反水过。不铺垫。
"之前被当事人反水过。过了几天他跟别人说，这个方案是律师自己拿的主意。"

【教训 · 0:10-0:18】
→ 一句话总结代价——没有聊天记录说不清。
"如果没有聊天记录。你跳进黄河也说不清。"

【动作一 · 0:18-0:40】
→ 方案确认留痕——操作层。每个细节可执行。
"不管是什么方案。一个字一个字打好了发过去。他不确认，我不往下走。"

【动作二 · 0:40-0:65】
→ 原件拍照交接——操作层。
"只在开庭前几天去取。拿到了拍照发给他。送回去再拍一张。"

【收口 · 0:65-0:70】
→ 就这两个，不总结不升华。
"就这两个动作。留痕。和原件交接。都是被坑出来的。"
```

---

## ⚠️ 注意事项

1. **"之前被当事人反水过"轻描淡写**。不是"你们不知道我被坑得多惨"——是"有这么一个事，后来我就注意了"。语气不沉重。
2. **"第一个""第二个"可以换成"一个习惯是""另一个"**。编号感不用太强——裁判测出这个点但没扣分。
3. **"你跳进黄河也说不清"是全文唯一一句俗语**。说的时候不加重音——这是普通人的感叹，不是律师的引用。
4. **"某某原件"用正常代称**——拍的时候举一个具体例子就够，不用每个原件类型列举。
5. **"就这两个动作"说到这停住**。不再加"希望对你有帮助""以后注意"——结尾不拖。

之前被当事人反水过。

我们沟通好了一个方案。
过了几天。

你跳进黄河也说不清。

后来我跟你说。
被坑一次就够了。
从那天开始。
我就养成了两个习惯。

第一个。
不管是什么方案。
所有诉讼请求。
所有证据策略。
一个字一个字打好了发过去。

不替当事人做任何决定。
哪怕他觉得麻烦。
这个责任必须他自己担。

第二个。
原件我不代收。

以前也有当事人说。
把原件放你那儿就行。
我从来没有拿过。

拿到了。
拍照发给他。

开庭结束送回去。
再拍一张。
某某原件已归还。

这个案件基本就废了。

就这两个动作。
留痕。
和原件交接。
