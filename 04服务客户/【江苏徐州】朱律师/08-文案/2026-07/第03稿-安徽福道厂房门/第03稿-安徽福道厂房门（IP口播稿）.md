# 第03稿 · 安徽福道厂房门 · IP口播稿

## 🎬 封面标题建议

**候选标题（三选一）：**

1. 争议5万，账上写了30万——侄媳妇一句话翻了
2. 你以为铁赢的案子，自己会计算错了一笔账
3. 有时候拆你案子不是对方律师，是你自己人

**封面文字：**
自己的会计拆了自己的案子

**平台标题：**
厂房买卖合同纠纷。争议本来5万块，侄媳妇做账写成了30万。起诉。从有理变成了没理。开庭途中对方又堵了路。见到周总坐下来调解——律师的价值，有时候不在法庭上。

## 🧭 结构走线

```
【开场 · 0:00-0:10】
→ 开门见人见事。不给情绪，五短句把案件轮廓铺出来——让观众自己进。
"买卖合同纠纷。厂房的内门。廖总的厂房。面积很大。一排一排的车间。"

【纠纷 · 0:10-0:22】
→ 结算纠纷→账算不清→起诉。三件事连成一条线。让观众自己看出"有问题的是账"。
"他卖了其中两个车间。买方姓周。双方结算。产生了纠纷。账算不清。廖总起诉了周总。"

【焦点 · 0:22-0:32】
→ 数字。这是全篇最重的两个字——五万vs三十万。不加渲染，说出来就够。
"争议本来五万块左右。廖总的侄媳妇是会计。把账算错了。"

【翻车 · 0:32-0:46】
→ 从"有理"变"没理"——三个字的落差就是全篇的核。法院看账不看心。
"账上写了三十万。认为对方少付了三十多万。起诉。从有理。变成了没理。"

【恶化 · 0:46-0:56】
→ 不是法庭上的较量，是工厂的共用道路被堵了。建筑垃圾。双方都进不去。
"起诉的过程中。双方又出了新问题。车间之间共用一条道路。周总把路堵了。建筑垃圾堆在路上。"

【调解 · 0:56-1:05】
→ "坐下来"是关键词。不是开庭，不是谈判，是坐下来把事聊开。
"我见到了周总。坐下来。沟通。把事情聊开。调解了。"

【收尾 · 1:05-1:15】
→ 不收在"赢了"。收在"打官司之前先翻账册"。最后一句点认知。
"律师的价值。有时候不在法庭上。在你怎么帮当事人。把问题解决掉。打官司之前。先把自己家的账册翻一遍。有时候拆你案子的人。不是对方律师。是你自己人。"
```

---

## ⚠️ 注意事项

1. **语气**：全篇克制造。像在办公室翻完案卷跟同事复盘——平静、专业、不带情绪。不讲"我赢了"也不讲"他输了"。只讲真实发生的事。
2. **关键句**："争议本来五万块。账上写了三十万。"数字讲出来就够，不加渲染。"打官司之前。先把自己家的账册翻一遍。"不收在输赢，收在一个行动建议。
3. **"法院看的是账"**：这是整个案件的转折——法律不看你心里怎么想，看你白纸黑字留下了什么。
4. **结尾**："有时候拆你案子的人。不是对方律师。是你自己人。"——不收在对方律师、不收在法官、不收在运气。收在自己人。
5. **画面建议**：办公桌前坐着讲。讲到"路堵了"停顿一下让观众想象画面。"坐下来。沟通。"节奏放慢。最后收在合上卷宗或看向镜头。
