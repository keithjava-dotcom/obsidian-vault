# 第02稿 · 律师真实的一天 · IP口播稿

## 🎬 封面标题建议

**候选标题（三选一）：**

1. 女朋友发"你到底爱不爱我"，我看了一眼继续改诉状
2. 对方在庭上满嘴假话，我一句一句记下来
3. 开庭前一晚没睡着——不是紧张，是在想怎么开口

**封面文字：**
律师的一天

**平台标题：**
开庭前一晚没睡着，不是紧张，是在想怎么开口。律师真实的一天——三通免费电话、女朋友的微信、凌晨两点的改诉状。

---

## 🧭 结构走线

```
【开庭 · 0:00-0:10】
→ 反常切入——不从起床从法庭。不铺垫直接告诉你今天经历了什么。
"今天开个庭。对方在庭上满嘴假话。"

【记下来 · 0:10-0:18】
→ 给动作。不是生气不是反驳——是"记下来"。专业克制感就三个字。
"一句一句记下来。"

【回程 · 0:18-0:28】
→ 从法庭切到车上。导航时间+三个相同句式的电话。"都是熟人"解释了什么叫免费咨询。
"导航显示一个半小时。路上三个电话。"

【加班 · 0:28-0:38】
→ 回律所继续。没提几点到，直接跳到十二点。中间全是省略——你看到的是结果。
"改诉状。整理证据。找相关判例。抬头一看。十二点。"

【微信 · 0:38-0:48】
→ 全片情绪点——女朋友微信。看了没回。沉默比回复更重。
"手机亮了。女朋友发的。就一行字。你到底爱不爱我。"

【收尾 · 0:48-0:60】
→ 不结束在今夜加班，结束在昨晚没睡着。收在"怎么开口"——替一个人想了一整晚。
"开庭前一晚没睡着。不是紧张。是在想怎么开口。"
```

---

## ⚠️ 注意事项

1. **语气**：全篇克制造。不是在跟观众说话，是在跟一个老朋友复盘——"今天就这样了"。女朋友微信那段不要加重读，正常念。"没回"后面停一秒让观众自己补。
2. **关键句**："开庭前一晚没睡着"是全篇轴心。前面对方说假话、免费咨询、加班、女朋友——都是铺垫，最后落在"怎么开口"。这句不要重读，正常说出就行，前面的信息量够观众自己品。
3. **画面建议**：开庭片段配法院走廊/停车场。回程配导航屏幕。加班配桌上卷宗和亮了又暗的手机。收尾配一个推镜头——从案卷推到窗外黑夜。
