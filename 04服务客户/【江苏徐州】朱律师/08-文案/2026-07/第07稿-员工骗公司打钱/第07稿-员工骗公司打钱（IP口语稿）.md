# 第07稿 · 公司说"你另辟蹊径"，我说巧妇难为无米之炊

## 🎬 封面标题

封面标题：公司说"你另辟蹊径"，我说巧妇难为无米之炊
封面文字：公司说"你另辟蹊径"，我说巧妇难为无米之炊
平台标题：员工说有项目让公司投钱，老板直接打款，没签合同。出纠纷想追回——连对方身
份信息都没有。公司说"律师你另辟蹊径"，我说巧妇难为无米之炊。

## 🧭 结构走线

```
【结论先行 · 荒唐砸出来】
注：第一句就定性——这个案子打不了。戴律式"有些案子，律师听完就知道打不了"。

例："有些案子，律师听完就知道打不了。这个案子，你听完会觉得怎么会有这种事。"

【故事 · 摆事实】
注：从头讲。不评不判，观众自己会"啊？"。

例："一家公司，一个员工跟老板说，蚌埠那边有个项目可以投。老板直接打钱，没签合同，而
且是以个人名义，打给员工和员工指定的账户。"

【难点 · 摊开】
注：想追，追不了。三个死结。

例："后来出了纠纷，蚌埠的施工方不认这家公司——没合同。现在想起诉追回这笔钱，连对方身
份信息都没有。唯一的证据，是跟这个员工的几条聊天记录。"

【专业知识 · 核】
注：停半拍再说。这句是全场最重。

例："公司的人跟我说，朱律师你能不能另辟蹊径。我说，巧妇难为无米之炊。律师只在合法范
围内干活，不可能去做违法的事情，去获取他人的身份信息。"

【收口 · 戴律式判断+留白】
注：不收教训，收在无奈本身。像放下杯子。

例："不是每一个案子都能赢。有些事，从没签合同那一刻就注定了。"
```

## ⚠️ 注意事项

1. 
**第一句就是结论**："有些案子，律师听完就知道打不了。这个案子，你听完会觉得怎么
会有这种事。" — 戴律式开场，先定性再讲故事。
2. **去打字机**：句子流动。"公司的人跟我说，朱律师你能不能另辟蹊径" — 
一句话讲完。
3. **不站队**：不替公司愤怒，也不替员工定罪。就是把一件事摊开。
4. 
**"巧妇难为无米之炊"是核**：前面不铺垫不预告，到了就说，停半拍，让分量自己出来。
5. **收口不收在教训**："以后签合同"不要说。停在"从没签合同那一刻就注定了"。
6. 
**禁止**：说教（"老板们记住"）、反问、升华（"信任是这个时代最贵的东西"）、打字机
断行。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了结构之后用自己的话说。

有些案子，律师听完就知道打不了。这个案子，你听完会觉得怎么会有这种事。

一家公司，一个员工跟老板说，蚌埠那边有个项目可以投。老板直接打钱，没签合同，而且
是老板个人名义，打给员工和员工指定的账户。

后来出了纠纷，蚌埠的施工方不认这家公司——没合同。现在公司想追回这笔钱，连对方身份
信息都没有。唯一的证据，是跟这个员工的几条聊天记录。

法院要的是证据，不是"这事儿大家都清楚怎么回事"。

公司的人跟我说，朱律师你能不能另辟蹊径。我说，巧妇难为无米之炊。律师只在合法范围
内干活，不可能去做违法的事情，去获取他人的身份信息。

不是不想帮，是帮不了。

不是每一个案子都能赢。有些事，从没签合同那一刻就注定了。
