# 第01稿 · 宋民案件 · IP口播稿

## 🎬 封面标题建议

**候选标题（三选一）：**

1. 他去上访，政府连夜派人送他回去——半路出了车祸
2. 开完庭，我走到对方律师面前，说了一句判决书里没有的话
3. 一级伤残，高位截瘫，插管——他们还在争论该赔多少钱

**封面文字：**
法庭外的较量

**平台标题：**
帮同事开个庭，当事人高位截瘫靠机器存活。开完庭我跟对方律师说了句话——不是所有胜诉都在判决书里。

## 🧭 结构走线

```
【开场 · 0:00-0:10】
→ 先让人知道这是真案子。用"帮同事开庭"降低期待——越普通后面越重。
"前几天帮徐主任开了个庭。当事人叫宋民。"

【上访 · 0:10-0:20】
→ 上访→被送回→车祸，三件事一口气说出来。不解释不渲染，事实自己会说话。
"政府派了车。半路上出了车祸。一级伤残。"

【惨状 · 0:20-0:30】
→ 四个事实拼出这个人现在什么状态：高位截瘫+插管+没收入+自己垫钱。
"插管靠外置机器存活。没有经济来源。自己垫医药费。"

【法庭 · 0:30-0:38】
→ 从人的惨切到钱的争论。不讲庭审多激烈，讲"都觉得太高了"——观众自己品那个"都"字。
"开庭。政府跟保险公司都觉得护理费太高了。"

【庭后 · 0:38-0:46】
→ 全片转折。"卷宗合上"微动作→走到对方面前。观众等的是继续争，结果是走过去。
"开完庭。卷宗合上。我走到对方律师面前。"

【建议 · 0:46-0:55】
→ 全片核。不重读不强调，越轻越有力。前面信息量够重了，这句是释放。
"让政府给宋民请个护工吧。两边都好。"

【收尾 · 0:55-0:65】
→ "案子就这么结了"铺垫→"还在等"画面收→转发钩子从"也在等"长出，不是换词模板。
"那个插着管子的宋民。还在等。"
```

---

## ⚠️ 注意事项

1. **语气**：平铺直叙。不是播新闻、不是演讲、不是普法课——是开完庭回来跟同事复盘一个案子。越克制越有力。
2. **关键句**："让政府给宋民请个护工吧"——全片核。不要加重语气、不要强调，说出来就行。前面铺得够重了，这句越轻越对。
3. **节奏**：句号处停半秒。正常说话速度，太快像赶路太慢像朗诵——都不要。
4. **画面建议**：前面讲案情时用办公桌、卷宗、窗外。最后一句"那个插着管子的宋民"给一个留白——朱律师看向某个方向，或者站起来。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师按自己的说话习惯调整即可。

前几天帮徐主任开了个庭。
当事人叫宋民。
宋民想去北京上访。
在徐州停了一下。
户籍所在地的政府知道了。
让他连夜回南通。
他说没高铁了，第二天走。
政府派了车。
半路上出了车祸。
一级伤残。
高位截瘫。
肺部感染。
插管靠外置机器存活。
没有经济来源。
自己垫医药费。
起诉政府和保险公司偿还。
开庭。
政府跟保险公司都觉得护理费太高了。
希望降低护理标准。
开完庭。
卷宗合上。
我走到对方律师面前。
没再去争那个赔付数字。
我说，让政府给宋民请个护工吧。
政府开支能降下来。
宋民也不用每次都起诉。
两边都好。
案子就这么结了。
那个插着管子的宋民。
还在等。
如果你认识的人也正在跟什么耗着——
把这条给他看看。
