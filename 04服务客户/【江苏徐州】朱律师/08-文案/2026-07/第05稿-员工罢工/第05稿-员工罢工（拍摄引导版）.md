# 第05稿 · 七小时变八小时罢工 · 拍摄引导版

> ⚠️ 这是拍摄引导版，不是逐字稿。三处事实缺口需朱律师回忆/询问客户补充后，才能解锁正式口语稿。

## 🎬 封面标题建议

1. 一个老板把七小时调成八小时，员工直接罢工了
2. 对员工太好，迟早会出问题
3. 老板找我帮忙，我给的建议和法律一点关系没有

**封面文字：**
管理"好人陷阱"

**平台标题：**
给员工七小时双休，加班一次被拒，调成八小时就罢工了。冲进办公室当面对峙。这个老板找我帮忙，我给的建议跟法律无关——管理人员不能和员工走太近。边界感的缺失，迟早会算账。

## 🧭 结构走线

```
【钩子 · 0:00-0:10】
→ 上来就砸冲突画面。说慢一点，让"罢工"两个字沉下来。
"一个老板，把工作时间从七小时调成八小时。员工不干了，直接冲进她办公室。然后集体罢工。"

【蓄力 · 0:10-0:22】
→ 讲她平时怎么对员工的。这儿带一个真事——她做过什么让你印象深的。不说"很好"，说做了什么。
"她公司一直是七小时工作制，双休。很舒服。老板是大家长型管理，跟员工也没什么距离。"

【触发 · 0:22-0:30】
→ 从"正常"到"不对劲"的转折。说那个电话——谁打的、对面说了什么。
"上周六有个临时的事，需要员工加班。打电话过去，员工直接拒绝了。"

【爆发 · 0:30-0:45】
→ 整条视频最重的一段。把冲办公室那一下说清楚——几个员工进来的、谁说第一句话、说了什么。不渲染，但让观众看见。
"她很生气，把时间调成八小时。调完之后两件事。员工冲到办公室当面对峙。然后集体罢工。"

【认知 · 0:45-1:00】
→ 她问你怎么处理。你说的建议——说慢，让她听懂同时也让观众听懂。
"她问我怎么办。我说，造成今天这样是长期管理问题。管理人员不能和员工走太近。已经罢工了，不要激化。逐个击破。毕竟是你在发工资，员工同盟并不坚固。找几个刺头治一下。"

【立场 · 1:00-1:10】
→ 最后一个判断，不教做人。平静，收住。
"对员工好是好事。但管理不能只有好。边界感的缺失，迟早会算账。"
```

## ⚠️ 开拍前说明

**素材来源**：7月23号那天你来跟我说的——佳实公司老板胡玲玉，七小时双休的公司，因为周六加班被拒、她改成八小时，员工冲进办公室罢工。你给了她管理建议，不是法律建议。

**这条讲给谁看**：正在管人的人——老板、中层、创业者。对员工好但管不住的那种。

**你今天为什么非说这件事**：这里面有个普遍盲区——对员工好不等于管理。你见过太多老板对员工跟对朋友一样，最后一算账全亏。

**拍之前先想这一下**：你现在坐在镜头前，对面是另一个做企业的朋友——他最近也在头疼员工的事。你跟他说"我最近有一个客户，遇到这么个事……"从头到尾说一遍。

**不能讲成什么腔**：
- ❌ 管理课——"企业管理有三个原则"
- ❌ 吐槽——"现在员工真难管啊"
- ✅ 复盘一件事——说出来，让听的人自己想

## 🎤 穿插问题（拍的时候自己问自己，能说多少说多少）

### 蓄力段｜需要补画面：老板具体对员工好在哪里

**问题1（开放式·问自己）**：胡玲玉平时怎么对员工好的？有没有一个具体的画面——比如团建去了哪、过年发了什么、平时请大家吃了什么——就一个就行，让你觉得"这老板对员工是真不错"。

🔴 **引导模式**：只记录，不自答。如果一时想不起来，说"记不太清了"就往下走，不要硬想。

**如果答了**：拿这个具体画面替代"很舒服"那句话。

### 爆发段｜需要补画面：冲进办公室那一下

**问题2（开放式·问自己）**：员工冲进办公室的时候，几个人？谁带的头？进来第一句话说的是什么？

🔴 **引导模式**：不预设。是说"你凭什么改"还是"公司违约"还是别的——你回忆什么就说什么，记不清就说"具体记不清了"。

**如果答了**：用这句原话进稿。比你替他编好一百倍。

**问题3（如果记得、开放式·问自己）**：罢工之后呢？当天下午人走了吗？公司那几天什么状态？

🔴 **引导模式**：不强问。想不起来就不说。重点是冲办公室那个瞬间，后续状态有就有，没有就收在"罢工"两个字。

### 爆发段｜需要补画面：老板当时的反应

**问题4（开放式·问自己）**：员工冲进来的时候，胡玲玉什么反应？她是懵了、还是马上对上了、还是打电话叫你？

🔴 **引导模式**：你看见的就说，没看见的不用猜。你是事后听她说的还是当时在现场？听说的就说"她后来跟我说"。

## ⚠️ 注意事项

1. **当事人信息脱敏**：拍的时候用「一个老板」「她公司」「我的一个客户」代替真实公司名和全名。公司名「佳实」、老板名「胡玲玉」不出镜。
2. **"找几个刺头治一下"**——这句话留着。老板观众会觉得解气，普通观众会觉得狠。不需要解释或软化，朱律师的专业判断就是这样。
3. **第三人称开头**——"一个老板"开始讲，说完"她问我怎么办"之后切换成"我说……"——从转述变成亲历，这个切换本身就有节奏感。
4. **结尾不下结论**——"边界感的缺失，迟早会算账"不是教人做人，是你复盘完这件事冒出来的一个念头。说的时候别加重音，就跟你跟自己叹口气一样。
5. **时长控制**：1:00-1:10 左右，不要太长。这是一件事，讲完就收。
6. **拍完之后**：回传这段素材+上面四个问题的回答，我出正式口语稿。
