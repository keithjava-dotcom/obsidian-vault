# 第05稿 · 七小时变八小时罢工 · 拍摄引导版

> ⚠️ 拍摄引导版：结构走线 + 口播示例 + 穿插问题三合一。三处事实缺口已嵌入结构和示例稿中，标注【作业】——朱律师拍的时候对照回答就行，拍完回流解锁正式稿。

## 🎬 封面标题建议

1. 一个老板把七小时调成八小时，员工直接罢工了
2. 对员工太好，迟早会出问题
3. 老板找我帮忙，我给的建议和法律一点关系没有

**封面文字：**
管理"好人陷阱"

**平台标题：**
给员工七小时双休，加班一次被拒，调成八小时就罢工了。冲进办公室当面对峙。这个老板找我帮忙，我给的建议跟法律无关——管理人员不能和员工走太近。边界感的缺失，迟早会算账。

## 🧭 结构走线 + 穿插问题

```
【钩子 · 0:00-0:12】
→ 0帧扔冲突。说慢，让"罢工"两个字沉下来。
"一个老板，把工作时间从七小时调成八小时。员工不干了，直接冲进她办公室。然后集体罢工。"


【蓄力 · 0:12-0:22】
→ 讲她平时怎么对员工的。不说"她人很好"——说她做了什么。
🟡 【作业·问自己】胡玲玉平时对员工好在哪里？有没有一个具体的画面——团建去了哪、过年发了什么……就一个，让你觉得"这老板是真对员工好"。想不起来就说"记不清了"，往下走。
"她公司一直是七小时工作制，双休。[作业·在这里讲一个她对员工好的具体画面]。老板是大家长型管理，跟员工也没什么距离。"


【触发 · 0:22-0:30】
→ 从"正常"到"不对劲"的转折。
"上周六有个临时的事，需要员工加班。打电话过去，员工直接拒绝了。"


【爆发 · 0:30-0:50】
→ 全篇最重的段落。把冲办公室说清楚——几个员工、谁说第一句话、说了什么。不渲染，让观众自己看见。
🟡 【作业·问自己】冲进办公室的时候——几个人？谁带的头？进来的第一句话说的是什么？"你凭什么改"还是"公司违约"还是别的——你回忆什么就说什么。
🟡 【作业·问自己】胡玲玉当时什么反应？懵了、还是马上对上、还是打电话叫你？你是事后听说的还是当时在现场？听说的就说"她后来跟我说"。
🟡 【作业·如果记得】罢工之后呢？当天下午人走了吗？公司那几天什么状态？记不清就不说。
"她很生气，把时间调成八小时。调完之后——[作业·冲办公室画面：几个人、谁带头、第一句话]。然后集体罢工。[作业·如果记得：罢工后的现场]。"


【认知 · 0:50-1:05】
→ 她问你怎么处理。你说的建议说慢，让观众听懂的同时也让观众自己想了。
🟡 【作业·问自己】你当时跟她说了什么？和下面这段引文有出入吗？
"她问我怎么办。我说，造成今天这样是长期管理问题。管理人员不能和员工走太近。已经罢工了，不要激化。逐个击破。毕竟是你在发工资，员工同盟并不坚固。找几个刺头治一下。"


【立场 · 1:05-1:15】
→ 最后一个判断。不教人、不下结论——就是你复盘完冒出来的一个念头。
"对员工好是好事。但管理不能只有好。边界感的缺失，迟早会算账。"
```

## 📝 口播文案示例

> ⚠️ 这是示例，不是逐字稿。带【作业】的地方是事实缺口——你拍的时候能回答就用自己的话替掉，回答不了就跳过、把这段空过去，我后续补。你的表达习惯：不反问、不渲染情绪、不教人，像跟朋友复盘一件事。

一个老板，把工作时间从七小时调成八小时。
员工不干了，直接冲进她办公室。
然后集体罢工。

她公司一直是七小时工作制，双休。很舒服。
【作业·讲一个她对员工好的具体画面——比如团建去了哪、过年发了什么。】
老板是大家长型管理，跟员工也没什么距离。

上周六有个临时的事，需要员工加班。
打电话过去，员工直接拒绝了。

她很生气，把时间调成八小时。
调完之后——
【作业·冲办公室画面：几个人、谁带头、第一句话说了什么。】
然后集体罢工。
【作业·如果记得：罢工后的现场——人走了吗，公司什么状态。】

她问我怎么办。
我说，造成今天这样是长期管理问题。
管理人员不能和员工走太近。
已经罢工了，不要激化。
逐个击破。
毕竟是你在发工资，员工同盟并不坚固。
找几个刺头治一下。

对员工好是好事。
但管理不能只有好。
边界感的缺失，迟早会算账。

## ⚠️ 注意事项

1. **当事人脱敏**：拍的时候用「一个老板」「她的公司」「我的一个客户」。公司名「佳实」、老板名「胡玲玉」一律不出镜。
2. **第三人称开头**——"一个老板"讲到"她问我怎么办"之后自然切"我说……"。从转述变亲历，这个切换本身就有节奏。
3. **"找几个刺头治一下"留着**——这是你的判断，不解释不软化。老板观众觉得解气，普通观众觉得狠，都对。
4. **结尾不下结论**——"边界感的缺失，迟早会算账"不是教人，是复盘完冒出来的念头。别加重音，跟叹气一样。
5. **时长 1:05-1:15，讲完就收**。这是一件事，不展开。
6. **不能讲成管理课**（"企业管理有三个原则"）也**不能讲成吐槽**（"现在员工真难管"）。就是跟另一个做企业的朋友说"我最近有个客户遇到这么个事"。
7. **拍完之后回传**：素材 + 上面结构里标了【作业】的问题你能回答的部分 → 我出正式口语稿。
