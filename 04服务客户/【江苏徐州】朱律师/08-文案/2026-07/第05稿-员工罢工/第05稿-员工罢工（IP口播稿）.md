## 🧭 结构走线

```
【开场 · 0:00-0:12】
→ 上来就是冲突，别铺垫。说慢，让"罢工"沉下去。
"员工不干了，直接冲进她办公室。然后集体罢工。"

【蓄力 · 0:12-0:22】
→ 讲她平时对员工什么样，不讲人很好——讲一件她做过的事。
"她公司一直是七小时工作制，双休。很舒服。"

【触发 · 0:22-0:30】
→ 正常变不对劲的转折，就一个电话的事。
"打电话过去，员工直接拒绝了。"

【爆发 · 0:30-0:50】
→ 最重一段。把冲进来那下讲清楚——几个人、谁带头、第一句话。
"她很生气，把时间调成八小时。然后集体罢工。"

【认知 · 0:50-1:05】
→ 她问你怎么处理。你的建议跟法律无关，这才有意思。
"管理人员不能和员工走太近。已经罢工了，不要激化。"

【立场 · 1:05-1:15】
→ 收住。复盘完冒出来的念头，别加重量。
"边界感的缺失，迟早会算账。"
```

## 📝 口播文案示例

> ⚠️ 这是示例，不是逐字稿。括号处对着下方穿插提问回答——填进自己话，填不了就跳过。

一个老板，把工作时间从七小时调成八小时。
员工不干了，直接冲进她办公室。
然后集体罢工。

她公司一直是七小时工作制，双休。很舒服。
（填空·见提问1。她对员工好的一个具体细节。）
老板是大家长型管理，跟员工也没什么距离。

上周六有个临时的事，需要员工加班。
打电话过去，员工直接拒绝了。

她很生气，把时间调成八小时。
调完之后——
（填空·见提问2。冲进办公室：几个人、谁带头、第一句话。）
然后集体罢工。
（填空·见提问3。罢工之后，如果记得的话。）

她问我怎么办。
我说，造成今天这样是长期管理问题。
管理人员不能和员工走太近。
已经罢工了，不要激化。
逐个击破。
毕竟是你在发工资，员工同盟并不坚固。
找几个刺头治一下。

对员工好是好事。
但管理不能只有好。
边界感的缺失，迟早会算账。

## 🎤 穿插提问（拍的时候自己问自己）

### 蓄力段 · 提问1：老板"好"的具体细节

胡玲玉平时怎么对员工好的？有没有一个具体的细节——团建去了哪、过年发了什么、平时请大家吃了什么——就一个就行，让你觉得"这老板对员工是真不错"。

如果记得：拿这个细节替掉示例稿里的填空。
如果记不清：说"记不太清了"直接往下走，不强想。

### 爆发段 · 提问2：冲进办公室那一下

员工冲进办公室的时候，几个人？谁带的头？进来第一句话说的是什么？

不预设回答。是说"你凭什么改"还是"公司违约"还是别的——你回忆什么就说什么。记不清就说"具体记不清了"。

如果答了：用这句原话进稿。比你替他编好一百倍。

### 爆发段 · 提问3：罢工之后（不强求）

罢工之后呢？当天下午人走了吗？公司那几天什么状态？

想不起来就不说。重点是冲办公室那个瞬间，后续有就有、没有就收在"罢工"两个字。

### 爆发段 · 提问4：老板当时的反应

员工冲进来的时候，胡玲玉什么反应？她是懵了、还是马上对上了、还是打电话叫你？

你在现场还是事后听她说的？听说的就说"她后来跟我说"。

## ⚠️ 注意事项

1. **当事人脱敏**：用「一个老板」「她的公司」「我的一个客户」。公司名「佳实」、老板名「胡玲玉」一律不出镜。
2. **第三人称开头**——"一个老板"讲到"她问我怎么办"自然切"我说……"。转述变亲历，这个切换就是节奏。
3. **"找几个刺头治一下"留着**——不解释、不软化。这是你的判断。
4. **结尾不下结论**——"边界感的缺失，迟早会算账"不是教人，是复盘完冒出来的念头。别加重音，跟叹气一样。
5. **时长 1:05-1:15，讲完就收。**
6. **不能讲成管理课**（"企业管理有三个原则"）也**不能讲成吐槽**（"现在员工真难管"）。就是跟做企业的朋友说"我最近有个客户遇到这么个事"。
7. **拍完回传**：素材 + 以上四个提问你能回答的部分 → 出纯净版。
