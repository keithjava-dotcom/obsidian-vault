## 🎬 封面标题建议

2. 对员工太好，迟早会出问题
3. 老板找我帮忙，我给的建议和法律一点关系没有

**封面文字：**
管理"好人陷阱"

**平台标题：**
给员工七小时双休，加班一次被拒，调成八小时就罢工了。冲进办公室当面对峙。这个老板找我帮忙，我给的建议跟法律无关——管理人员不能和员工走太近。边界感的缺失，迟早会算账。

## 🧭 结构走线

```
【开场 · 0:00-0:12】
→ 上来就是冲突，别铺垫。说慢，让"罢工"沉下去。
"员工不干了，直接冲进她办公室。然后集体罢工。"

【蓄力 · 0:12-0:22】
→ 不讲人很好。她做过什么——团建去哪、过年发啥，就一个细节。记不清就说记不清。
"她公司一直是七小时工作制，双休。"

【触发 · 0:22-0:30】
→ 正常变不对劲，就一个电话的事。
"打电话过去，员工直接拒绝了。"

【爆发 · 0:30-0:50】
→ 最重一段。说清楚冲进来那下——几个人、谁带头、第一句话，你回忆什么说什么，记不清跳过。胡玲玉当时什么反应？你在现场还是听她说的？罢工之后的事记得就说，不记得收在"罢工"两个字。
"她很生气，把时间调成八小时。"

【认知 · 0:50-1:05】
→ 她问你。你的建议跟法律无关——这才是看点。跟下面引文有出入就按你的说。
"管理人员不能和员工走太近。"

【立场 · 1:05-1:15】
→ 收住。复盘完冒出来的念头，别加重量。
"边界感的缺失，迟早会算账。"
```

## 📝 口播文案示例

> ⚠️ 这是示例，不是逐字稿。括号里的引导你对着回忆——能填就用自己的话替掉，填不了就跳过。你的表达：不反问、不渲染、不教人，像跟朋友复盘一件事。

一个老板，把工作时间从七小时调成八小时。
员工不干了，直接冲进她办公室。
然后集体罢工。

她公司一直是七小时工作制，双休。很舒服。
（填空：她对员工好在哪——团建去哪、过年发啥，就一个细节。记不清就说"记不太清了"直接往下走。）
老板是大家长型管理，跟员工也没什么距离。

上周六有个临时的事，需要员工加班。
打电话过去，员工直接拒绝了。

她很生气，把时间调成八小时。
调完之后——
（填空：几个人冲进来的？谁带的头？第一句话说的什么？你回忆什么就说什么，记不清就说"具体记不清了"。）
然后集体罢工。
（填空：罢工之后呢？当天下午人走了吗？想不起来就不说，收在"罢工"两个字。）
（填空：胡玲玉当时什么反应？懵了还是马上对上？你在现场还是事后听她说的？听说的就说"她后来跟我说"。）

她问我怎么办。
我说，造成今天这样是长期管理问题。
管理人员不能和员工走太近。
已经罢工了，不要激化。
逐个击破。
毕竟是你在发工资，员工同盟并不坚固。
找几个刺头治一下。

对员工好是好事。
但管理不能只有好。
边界感的缺失，迟早会算账。

## ⚠️ 注意事项

1. **当事人脱敏**：用「一个老板」「她的公司」「我的一个客户」。公司名「佳实」、老板名「胡玲玉」一律不出镜。
2. **第三人称开头**——"一个老板"讲到"她问我怎么办"自然切"我说……"。转述变亲历，这个切换就是节奏。
3. **"找几个刺头治一下"留着**——不解释、不软化。这是你的判断。
4. **结尾不下结论**——"边界感的缺失，迟早会算账"不是教人，是复盘完冒出来的念头。别加重音，跟叹气一样。
5. **时长 1:05-1:15，讲完就收。**
6. **不能讲成管理课**也**不能讲成吐槽**。就是跟做企业的朋友说"我最近有个客户遇到这么个事"。
7. **拍完回传**：素材 + 上述填空的回答 → 出纯净版。
