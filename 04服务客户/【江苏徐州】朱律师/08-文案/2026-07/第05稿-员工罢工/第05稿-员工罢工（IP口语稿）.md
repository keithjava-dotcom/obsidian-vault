# 第05稿 · 七小时变八小时罢工 · IP口语稿

## 🎬 封面标题建议

**候选1：** 一个老板把七小时调成八小时，员工直接罢工了
**候选2：** 对员工越好越容易出问题——管理不能只有好
**候选3：** 老板找我帮忙，我给的建议和法律一点关系没有

**封面文字：** 管理"好人陷阱"
**平台标题：** 有个老板找我帮忙，跟法律没关系。她把公司七小时调成八小时，员工直接冲到办公室集体罢工。平时她对员工好到没有边界——请吃饭发福利谁有事她第一个帮。我给的建议是：这不是法律问题，是管理问题。边界感的缺失，迟早会算账。

## 🧭 结构走线

```
【开场】
→ 0帧扔反差——最好老板vs罢工，观众脑子被勾住
"她是对员工最好的老板。但她的员工集体罢工了。"

【七小时，双休】
→ 先铺舒适区，蓄力。【作业】处给一个具体画面替代概括，他知道是哪个
"这家公司七小时工作制，双休。老板是大家长式的人。"

【直接被拒绝了】
→ 转折点——加班被直接拒绝。重音在"直接"上，像在说一件想起来还觉得离谱的事
"临时有个事，打电话让员工加班。对方直接就拒绝了。说不去就不去。"

【冲进办公室】
→ 全篇最高冲突——用动作和声音还原现场。说到"人全走了"放慢，留两秒
"几个老员工带头冲进办公室。指着她说公司违约。当天下午人全走了。"

【声音是抖的】
→ 情绪最低点——不是诉苦，是复述。说完"他们怎么能这样"停一拍，让观众自己消化
"她给我打电话的时候声音是抖的。她说我对他们那么好，他们怎么能这样。"

【跟法律没关系】
→ 全篇认知转折——"跟法律一点关系没有"这句要平静但笃定，不是炫耀，是看穿了
"我说你先冷静。这件事的解决办法，跟法律一点关系没有。造成今天这个结果，是长期的管理问题。"

【一个个谈】
→ 给实操解法——说到"找几个刺头"带一点"这就是现实"的通透感
"不要激化。一个个谈。毕竟是你在发工资——找几个刺头，先攻下来。剩下的自己就散了。"

【迟早会算账】
→ 收在判断上。这句像跟自己说的，不像对镜头说的
"对员工好是好事。但管理不能只有好。边界感的缺失，迟早会算账。"
```

## ⚠️ 注意事项

1. 整条的姿势：复盘，不是上课。像跟另一个老板在茶桌上聊自己处理过的事。
2. 第三人称"她"——从头到尾别转成"你"，别变成对观众说教。
3. 说到"声音是抖的"这句要轻，像回忆，别演成感动。
4. "跟法律一点关系没有"——这句是认知转折点，平静地说，不扬。
5. 结尾"迟早会算账"往下走，像自言自语，不是宣告。
6. 不站老板那边，也不站员工那边。讲故事的人不站队。
7. 【作业】处——朱律师拍的时候自己想起来哪个细节就讲哪个，一句带过，别展开。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

开头：她是对员工最好的老板。但她的员工集体罢工了。

一个老板找我帮忙。跟法律没关系。
她把工时从七小时调成八小时。
员工冲进办公室。
然后集体罢工。
这家公司一直是七小时工作制，双休。

在徐州这条件不多见。
老板是大家长式的人——
【思考：你见过的一个具体画面。比如中秋手写卡片、员工孩子生病她怎么帮的——随便一个细节，让人感觉到"这老板是真的对员工好"】

说白了，她把公司当成了家。
员工也把她当成了家人。
转折发生在上周六。
临时有个事，她打电话让员工来加班。
对方直接就拒绝了。
不是商量，不是说"老板这周不太方便"。
很直接说：不去就不去。
她很生气。
第二天把制度改了。
七小时调成八小时。
然后就炸了。

几个老员工带头冲进办公室。
当面指着她说公司违约。
说以前的加班从来没给过钱。
吵到整层楼都能听见。

当天下午人全走了。办公室空了。生产线停了。
她给我打电话的时候声音是抖的。
她说朱律师，这些员工我平时对他们那么好，他们怎么能这样。

我说你先冷静。

这件事的解决办法，跟法律一点关系没有。
造成今天这个结果，是长期的管理问题。
你作为老板，跟员工之间没有边界。你请吃饭，发福利，你以为这是关心。但员工不这么想。他觉得这是你应该的。
你不给他才是欠他的。
你跟他没边界，他跟你就不讲道理。

已经罢工了，不要激化。
不要在群里骂人，不要开全员大会，不要发公告。
一个个谈。
毕竟是你在发工资。
员工的同盟没有你想的那么坚固。
找几个刺头，先攻下来。
剩下的自己就散了。

这件事给我的触动很大。
对员工好是好事。
但管理不能只有好。
你对一个人好到没有边界，最后他会觉得你欠他的。
边界感的缺失，迟早会算账。
