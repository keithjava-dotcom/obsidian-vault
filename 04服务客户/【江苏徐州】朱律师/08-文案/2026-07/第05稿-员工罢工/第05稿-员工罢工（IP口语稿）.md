# 第05稿 · 对员工最好的老板，员工集体罢工了

## 🎬 封面标题

封面标题：对员工最好的老板，员工集体罢工了
封面文字：对员工最好的老板，员工集体罢工了
平台标题：七小时工作制，双休，老板对员工好到没有边界。加班一次被拒，改成八小时——员工直接冲进办公室。她给我打电话，声音是抖的。我说这事跟法律一点关系没有。

## 🧭 结构走线

```
【开场】
0帧扔反差。最好老板 vs 集体罢工。

她是对员工最好的老板。但她的员工，集体罢工了。

【舒适区】
先铺"这公司有多好"。不说她人好，说她做了什么。

七小时工作制，双休。在徐州不多见。

【触发】
转折点。加班被拒，重音在"直接"。

上周六有个临时的事。她打电话让员工来加班。对方直接就拒绝了。

【爆发】
全篇最高冲突。动作和声音还原现场，不渲染。

她很生气。第二天把制度改了。七小时调成八小时。几个老员工带头冲进办公室。指着她说，公司违约。当天下午，人全走了。

【声音是抖的】
情绪最低点。复述，不是诉苦。

她给我打电话的时候，声音是抖的。她说，我对他们那么好，他们怎么能这样。

【认知】
全篇转折。平静，笃定。不是炫耀，是看穿了。

我说你先冷静。这件事的解决办法，跟法律一点关系没有。造成今天这个结果，是长期的管理问题。

【收口】
收在判断上。像跟自己说的，不像对镜头说的。

对员工好是好事。但管理不能只有好。边界感的缺失，迟早会算账。
```

## ⚠️ 注意事项

1. 整条姿势：复盘，不是上课。像跟另一个老板在茶桌上聊自己处理过的事。
2. 第三人称"她"——从头到尾别转成"你"，别变成对观众说教。
3. "声音是抖的"这句要轻，像回忆，别演成感动。
4. "跟法律一点关系没有"——平静地说，不扬。
5. 结尾"迟早会算账"往下走，像自言自语，不是宣告。
6. 不站老板那边，也不站员工那边。讲故事的人不站队。
7. 禁止：说教（"老板们要注意"）、反问（"你说说看"）、鸡汤（"真心换真心"）、法律科普。
