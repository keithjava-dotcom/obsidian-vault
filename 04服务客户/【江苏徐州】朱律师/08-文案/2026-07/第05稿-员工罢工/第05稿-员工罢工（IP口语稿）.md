# 第05稿 · 对员工最好的老板，被员工集体罢工了

## 🎬 封面标题

封面标题：对员工最好的老板，被员工集体罢工了
封面文字：对员工最好的老板，被员工集体罢工了
平台标题：七小时工作制，双休，逢年过节福利没断过。加班一次被拒，老板把工时调成8
小时——员工冲进办公室，集体罢工。她问我怎么办，我说这事跟法律一点关系没有。

## 🧭 结构走线

```
【结论先行 · 反差砸出来】
注：第一句就是最大反差。老板最好 vs 集体罢工。

例："她是对员工最好的老板，但她的员工，集体罢工了。"

【这公司有多好 · 事实堆叠】
注：不夸她人好，列事实。七小时双休，徐州不多见。

例："她公司一直是七小时工作制，双休。在徐州，这条件不多见。员工孩子生病她第一个帮忙
，逢年过节福利没断过。说白了，她把公司当成了家。"

【触发 · 加班被拒】
注：转折点。重音在"直接"。

例："上周六有个临时的事，她打电话让员工来加班。对方直接就拒绝了，不是商量。"

【爆发 · 冲进办公室】
注：全篇最高冲突。动作还原，不渲染。

例："她很生气，第二天把制度改了，七小时调成八小时。结果几个老员工带头冲进办公室，指
着她说公司违约。当天下午，人全走了。"

【她打电话 · 声音是抖的】
注：情绪最低点。复述不诉苦。

例："她给我打电话的时候，声音是抖的。她说，朱律师，我对他们那么好，他们怎么能这样。"

【我的判断 · 与法律无关】
注：全篇转折。平静笃定。

例："我说你先冷静。这件事的解决办法，跟法律一点关系没有。造成今天这个结果，是长期的
管理问题。"

【解法 · 逐个击破】
注：具体做法，老板听得懂。

例："已经罢工了，不要激化，容易造成公司停摆。一个个谈。毕竟是你在发工资，员工的同盟
没那么坚固，找几个刺头先治一下，剩下的自己就散了。"

【收口 · 戴律式判断】
注：收在管理认知上。像跟另一个老板聊天。

例："对员工好是好事，但管理不能只有好。你跟他没边界，他跟你就不讲道理。"
```

## ⚠️ 注意事项

1. **第一句就是结论**："她是对员工最好的老板，但她的员工，集体罢工了。" — 
反差即钩子。
2. 
**去打字机**：句子流动，不断行。参照"她说，朱律师，我对他们那么好，他们怎么能这
样" — 一句带引号的话整句讲完。
3. **不站队**：不替老板骂员工，也不替员工喊冤。讲故事的人不站队 — 
这是柯哥明确要求的。
4. **"跟法律一点关系没有"** — 平静说，不扬。这是给企业主的提醒核心。
5. **姿势**：像在跟另一个老板聊天 — 
"你猜我怎么跟她说的"的熟稔感（但不用"你猜"这个词）。
6. 
**禁止**：说教（"老板们要注意"）、反问（"你说说看"）、鸡汤（"真心换真心"）、打字
机断行。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。朱律师理解了结构之后用自己的话说。

她是对员工最好的老板，但她的员工，集体罢工了。

一个老板找我帮忙，跟法律没关系的事。她公司一直是七小时工作制，双休，在徐州这条件
不多见。员工孩子生病她第一个帮忙，逢年过节福利没断过。说白了，她把公司当成了家，
员工也把她当成了家人。

上周六有个临时的事，她打电话让员工来加班。对方直接就拒绝了，不是商量，不是"老板
这周我不太方便"，很直接，不去就不去。

她很生气，第二天把制度改了，七小时调成八小时。

然后，就炸了。

几个老员工带头冲进办公室，当面指着她说公司违约，说以前的加班从来没给过钱。吵到整
层楼都能听见。当天下午，人全走了，办公室空了，生产线停了。

她给我打电话的时候，声音是抖的。她说，朱律师，这些员工我平时对他们那么好，他们怎
么能这样。

我说你先冷静。这件事的解决办法，跟法律一点关系没有。造成今天这个结果，是长期的管
理问题。

你请吃饭，发福利，你以为这是关心，但员工不这么想。他觉得这是你应该的，你不给他，
才是欠他的。你跟他没边界，他跟你就不讲道理。

已经罢工了，不要激化，容易造成公司停摆。一个个谈，毕竟是你在发工资。员工的同盟没
那么坚固，找几个刺头先治一下，剩下的自己就散了。

对员工好，是好事。但管理，不能只有好。
