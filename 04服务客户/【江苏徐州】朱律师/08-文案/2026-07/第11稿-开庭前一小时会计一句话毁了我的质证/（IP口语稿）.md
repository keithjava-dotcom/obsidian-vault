## 🎬 封面标题建议

**封面标题**（3选1）：
1. 开庭前一小时，会计一句话毁了我的质证
2. 准备了五个小时，一句话就废了
3. 这官司原本不用打

**封面文字**：实战律师 · 开庭翻车
**平台标题**：开庭前1小时被一句话背刺｜三十万毁掉质证，三四万诉讼费白花

## 🧭 结构走线

```
【开庭前一小时 · 0:00-0:12】
→ 上来就砸"开庭前一小时"，别铺垫。观众直接进那个下午。
"开庭前一个小时，我还在去宿州中院的路上。"

【准备了五个小时 · 0:12-0:30】
→ 讲这天早上怎么开始的——几点、多久。时间数字就是反差。
"早上八点到下午一点，五个小时就写这一套。"

【打电话碰思路 · 0:30-0:50】
→ 讲打电话这个动作，不是讲法律论证。前面那么多准备，现在要跟当事人碰一下。
"我打电话跟他说这个质证思路，他会计在旁边。"

【她说了一句话 · 0:50-1:10】
→ 会计说的那句话。不预判、不解释。让观众自己听到。
"她说退税到了我们账户，三十万。"

【早说就不用打了 · 1:10-1:30】
→ 不愤怒。只陈述事实——早说不用打、钱白花。
"如果开庭前她告诉我，这官司根本不用打。"

【收口 · 1:30-1:50】
→ 停在经理的电话+后来的改变。不是教训，是"我后来就这么干了"。
"后来经理给我打电话，我俩都不知道该说什么。"
```

## ⚠️ 注意事项

1. 这条不是控诉会计，不是抱怨当事人——就是陈述一件发生过的事。语气平，不加重"愤怒"。
2. 别说"你说气不气""你猜怎么着"——你不是这个语气。
3. "三十万""三四万诉讼费"这两个数字说清楚就行，别展开解释。
4. 说到"都不知道该说什么"的时候，真的停一秒。那个沉默比任何话都重。
5. 最后那句"从那以后开庭前我都会追着再确认一遍"——不是说教训，是说"我后来改了这个习惯"。别念成感悟。
6. 回到当时的状态：你那天早上想出了一个很得意的思路，写到下午，信心满满。然后一句话全毁了。不是愤怒，是那种"我还能说什么"的感觉。
