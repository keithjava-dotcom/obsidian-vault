# 第一部分：先说清你帮谁解决什么问题

## 一、你的视频到底给谁看

**一个人 + 一个阶段 + 一个问题**

- **一个人**：大连本地家里乱得不想回家的人，或者失业/带娃后想找个能挣钱手艺的女人
- **一个阶段**：家里已经影响到心情了（不是"想收拾"，是"受不了了"）；或者职业空窗期、不知道干什么、年纪不上不下
- **一个问题**：自己整不明白——不是懒，是不知道从哪下手；或者想转行但不知道这个行业值不值得进

→ **一句话定位**：一个干了七年、大连唯一被晚报和电台电视台全采访过的整理师，告诉你的家怎么整、这个活怎么干、什么事别上当。


## 二、目标用户深度画像（种子用户叫"杨姐"）

### 来源群体

- **种子顾客**（现在能服务）：大连本地30-45岁有家庭的女人，家里乱影响心情、有消费能力但没时间整理；或者35-50岁中年女性，失业/带娃后想找条路
- **理想顾客**（账号成熟后服务）：全大连有整理收纳+搬家需求的中产家庭，以及想入行做整理师的东北地区学员
- **边缘围观**：刷到整理视频觉得"好爽"但不一定付费的年轻人

### 杨姐的画像（种子顾客）

1. **学历**：大专或本科
2. **经济水平**：家庭月入1-3万，有房贷但压力不大
3. **消费理念**：孩子的课外班几千不眨眼，自己买件大衣纠结半天；**愿意为"省时间"和"专业服务"付费**——266元团购试一下，服务好直接升全屋收纳2000+
4. **婚姻**：已婚，老公嫌她东西多但不舍得扔
5. **生活节奏**：白天上班/带娃，晚上躺着刷抖音缓解焦虑——看到家里乱就更烦躁
6. **愿意为什么付费**：时间（不想自己整）、专业（"我整不明白"）、安心（"别把我东西弄坏了"）
7. **此刻关心什么**：家里乱到什么程度才需要找整理师？整理完会不会三天就复乱了？要多少钱？值不值？
8. **刷视频习惯**：晚上10点后刷抖音，看生活类/家居类/宝妈类内容 ⚠️（推断）

### 敌人列表（刘晶的"我反对"）

1. 割韭菜的——"收你1980说教你所有东西，他连价都没报我"
2. 把成功简化为话术的——"活干好干赖无所谓，客户懂个屁"这种话她说出来带着不屑
3. 什么东西都做、哪样都不精的——"王一冉就是哪个行业都做，怎么可能都做好"
4. 自己没干过就站上面教人的——"保育师培训，她做都没做过"
5. 抱怨客户的同行——"我们团队绝对不要这种人"


## 三、商业变现设计

内容积累 → 团购引流（266元4小时） → 二次升单（干不完加时→全屋收纳2000+，升单率80-90%） → 培训（2980/3580收纳+自媒体课）+ 搬家一条龙

- **不追求快速成交，追求信任前置**：看到视频→信任这个人→有需求自然找她
- **客单价与周期**：服务单2000-5000/单，培训2980-3580/人；养号1-2周内容起量，第2-3周咨询进账（她现在就有底子），第2-3月培训开始招生

# 第三部分：你出镜时要给人什么感觉

## 七、情绪基调

**主基调：平视务实。** 像邻居大姐在你家沙发上跟你说："你看，这个柜子这样整，你下次就好找了。"

**辅基调：忍不住怼。** 说到行业乱象、说到不值那个价的课、说到客户被骗——她那个"我跟你说"就出来了，是真实的火气，不是演的。

**参考博主**：（待柯哥搜索确认，关键词：`大连 整理师 抖音` / `收纳师 IP 短视频`）

**配套元素**：
- 音乐：不用，或者干活现场自然音
- 光线：自然光，干活现场的灯够了
- 语速：正常说话，不背稿不加速
- 姿态：**平视**——不教你，跟你说


## 八、视觉符号

- **手写笔记本**：出镜时放旁边或偶尔出镜——"这是我七年前手写的"
- **干活穿的围裙/工具包**：不是制服，是她的装备
- **客户家真实的柜子、药箱、衣橱**：比任何布景都真实——每一个都是她真干过的活

> 这些是她本来就有的东西，不是硬摆。
