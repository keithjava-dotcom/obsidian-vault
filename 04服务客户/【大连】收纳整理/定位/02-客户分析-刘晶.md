# 刘晶 · 客户分析（2A 六维度 + 2B 七维度）

> 素材来源：两次沟通记录（00-第一次沟通记录-整理版 / 03-第二次沟通记录-整理版）+ 计划书


## 2A · 基础六维度分析

### 1. 语感特征

- **高频词**："反正""说白了""就是""我觉得""能干""没用""对吧""说实话"
- **句式**：短句为主，不爱铺垫。"市面上80%的从业者干了五年分类都分不明白"——一句话把行业打穿；"我就是想有人帮我写文案帮我拍，我负责干活"——需求不包着说。反问用得多："这不明摆着是拖吗？""那能多少钱呢？"
- **情绪基调**：务实、直接、有火气但不炸。不苦情、不煽动、不吹嘘。
- **绝不说的**："赋能""成长""赛道红利""认知升级"——这些词从她嘴里出来是假的。

### 2. 核心差异化（六字箴言对照）

| 字 | 匹配度 | 分析 |
|---|---|---|
| 正 | ❌ | 不跟大机构比"专业"——那是理想家干的事 |
| **反** | ✅⭐ | 行业讲"断舍离"，她讲"老子干了七年告诉你断舍离根本没那么简单"；行业收2980讲三天，她敢说"我去沈阳听了一天就教了"——敢说同行不行 |
| **和** | ✅⭐ | 收纳+搬家一条龙——别人只整房间，她连搬家都做；整理师+培训——不是只卖服务，还能教你变成整理师 |
| **跨** | ✅ | 导游→服装管理→带娃→整理师的职业跳跃，本身就是跨界故事 |
| **入** | 🟡 | 大连本地市场——沈阳理想家进不来（一城一店制），本地壁垒 |
| **弱** | ✅⭐ | 她说"没时间没精力"——这不是弱，是**有订单没产能**。忙不过来本身就在证明活好 |

**最强维度：反 + 和 + 弱 叠加。** "反"行业（敢说同行不行、敢说知识不值那个价）、"和"差异化服务（收纳+搬家）、"弱"建立信任（忙不过来=真本事）。

### 3. 变现目标

- 客户想从账号得到什么：**服务端——更多收纳+搬家单、培训端——招学员（收2980→3580）**
- 最适合的变现路径：团购引流（266元4小时）→ 二次升单（干不完加时→全屋收纳，升单率80-90%）→ 培训（2980/3580收纳课）
- 时间预期：账号内容跑起来1-2周，咨询进账第2-3周（她有底子），培训第2-3月

### 4. 内容潜力

| 方向 | 素材储备 | 爆款潜力 |
|---|---|---|
| 整理前后对比 | ⭐⭐⭐ 每天干活都有，素材随手录 | 高（视觉冲击+钩子逻辑） |
| 行业真相/反共识 | ⭐⭐⭐ 她原话里全是弹药 | 最高（"干了五年分类分不明白""那个课我不听就讲了"） |
| 客户故事 | ⭐⭐ 强迫症客户去7次/80元案例/搬家60箱 | 高（真人真事=信任） |
| 搬家全流程 | ⭐⭐ 她强调"连搬家都做" | 中高（差异化、有过程） |
| 知识分享（断舍离/陈列美学） | ⭐⭐⭐ 手写笔记本已分类 | 中（需要翻译，否则变工具人） |

### 5. 风险提示

- 时间：她忙（孩子+旺季），素材容易断——得靠"随手录+"机制，不能指望她专门拍
- 过度工具人风险：手写笔记本的内容如果直接拍成"干货合集"，就是视频版百度百科——只收藏不关注。必须用她的原话（"干了五年分不明白"）做观点钩子，知识只是架子上的肉
- 培训过早风险：她急着加新媒体课（2980→3580），但"先有订单基础再做培训"是她自己原话——服务闭环没跑稳之前不做培训内容，避免引流来的人无法服务
- 决断力：她目前AB不坚定（要培训还是要服务），需要摆数据让她二选一

### 6. 免费策略（路径1·有明确变现目标）

她的变现目标明确：收纳服务+培训。免费分享什么？分享"别人花钱才学到的"：
- 分类方法（"药先看日期再分口服外用"——单这一句就值钱）
- 升单逻辑（"我去基本能达到80-90%二次升单率"——不是炫耀，是利润模型）
- 行业真相（"这个行业不会多，因为费用太高"）


## 2B · 人设挖掘七维度

### 1. 故事性

⭐ **"抓人的变成帮人辩护的"同款弧光**——刘晶的是："导游→服装管理→带娃→整理师"。这不是跳槽，是一个人试了四种活法后终于找到自己能干明白的事。**这条弧光可以从N个角度反复讲**：为什么开始做收纳（带娃期间把自己家整明白了）、为什么坚持七年（别的活干过都放手了，就这个放不下）、为什么选择做IP不躲着（"别人天天直播我佩服"）。

另外："大连唯一被晚报+99.1电台+电视台采访过的整理师"——媒体三角是她自认为的背景交代，但对观众是最硬的信任基石。别的整理师花钱请媒体、买通稿，她坐在家里被记者找上门——**"记者问我这些问题我提前准备了，因为我知道别人也想知道"**，这个心态本身就是人设。

### 2. 性格品行

- **务实**：不说虚的。"加盟费三万差点交，被拦住"
- **敢说**：当面说王一冉骗子；说沈阳老师"刚出视频时什么也不会"；说自媒体课"学了也没学"
- **人品底线**：团队筛选标准"人品第一，抱怨客户、抱怨老板、抱怨同伴的绝对不要"
- **不吹**："一个月也就一万多块钱，去了十几万开销剩十多万"
- **倔**：对象不支持她发视频，"把网络屏蔽了"（这是伤害，但她说出来不怕）

### 3. 与观众的关系

**姿态选择：服务者/手艺人 → 同道中人。**

表面是服务者（"我去你家里帮你整"），深层是同道中人（"我没时间没精力，跟你一样"）。不是"我教你整理"，是"我干了七年，你的问题我都有答案"。

### 4. 三观/意识形态

**认可的**：
- 真本事（不是证书，是干出来的）
- 人品先于能力
- 先有订单再做培训
- 踏实、不装、不学割韭菜

**⭐ 坚决反对的**：
- 割韭菜（王一冉："1980就是骗子逻辑""收1980就给你所有东西，他能教啥"）
- 把成功简化为话术（"理想家说活干好干赖无所谓、客户懂个屁"——她复述时带着不屑）
- 哪个行业都做、哪样都不精（"王一冉就是哪个行业都做，怎么可能都做好"）
- 自己没干过就教人（"保育师培训，她做都没做过"）

### 5. 愿望/渴望

- 短期：有人帮她拍、帮她写（"我缺的就是拍摄和文案"）
- 中期：培训线和自媒体打通（"2980→3580把自媒体课带进去"）
- 长期：做大连第一的整理收纳+培训平台（"整合各家公司"）
- ⭐ **软肋**：对象不支持（"我对象不让我整、把网络屏蔽了"）+ 孩子中考分散精力

### 6. 情绪基调

**主基调：平视务实。** 不仰望专家，不俯视学员。"我干了七年，你说的问题我差不多都见过"——这种平静本身就是底气。

**辅基调：敢怼。** 行业乱象、割韭菜的人、不值那个价的课——她忍不住要说"这不是忽悠人吗"——不端着、不装，这才是真IP

**参考博主**：（待柯哥搜索确认，关键词矩阵见对标账号）

**配套元素**：自然光（干活现场的灯就行）、手机原声、不加过度特效。她的内容不在"好看"，在"她说的对"。

### 7. 思维习惯（推断·待刘晶测MBTI）

基于原话推断：SJ型——务实、按规矩来、强调分类和秩序、重视经验。对应内容形态：**讲故事 + 匠人匠心**。"讲故事"讲客户案例，"匠人"展示干活过程和专业判断。
