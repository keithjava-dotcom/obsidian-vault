# 收纳整理 × 保洁 × 新媒体 —— 合作项目计划书（初版）

> 一句话：**我们几个人，各出各的专业，一起把"家政服务 + 新媒体获客 + 培训变现"做成一个完整闭环。**

> **五个人，五个单独打不穿的瓶颈，在这张桌上有一个共同答案：跑通"流量→转化→交付→培训"闭环。** 刘晶要确定性、袁姐要破天花板、小九要方法论变现、毛姐要稳定位子、柯要样板案例——需求不同，解是同一个。

### 1.2 现状事实（不吹不藏）

- 家政服务本身能赚钱，但**获客靠老客户和运气**，不稳定
- 账号有，但内容断断续续，没有系统打法
- 行业里有人靠"割韭菜"赚钱（王一冉模式），**我们不学那种，我们靠真本事**
- 现金流是慢活：**第一个月必须保证现金流进来**，这是硬目标

## 二、我们要做成什么（目标）

### 2.1 短期目标（第 1 个月）——跑通闭环

**"内容 → 获客 → 服务"完整流程跑通一遍，且现金流进账。**

- 每人账号有固定内容产出（刘晶收纳、袁姐保洁、小九开荒/门店）
- 内容带来的咨询和订单可追踪（团购核销、私信、电话）
- 第一个月有真金白银进账——不管多少，证明这条路通

### 2.2 中期目标（第 1-3 个月）——固化流程

- 账号稳定更新，锁定哪些内容有流量（数据说话）
- 服务增量稳定，升单链路跑顺（266 团购 → 2000 服务）
- 培训线启动：先从沙龙/短期班试水

### 2.3 长期目标（3 个月后）——培训成为利润中心

- 培训产品线：收纳（刘晶）+ 保洁（袁姐）+ 门店运营（小九）+ 新媒体（柯建军）
- 家政服务矩阵：收纳 + 保洁 + 开荒 + 家政，互相导流
- **把这套做成样板：大家都能拿得出手的完整案例**

## 三、合作原则（宣教部分 · 一起说好）

1. **一起做，匀速做。** 不是谁帮谁，是合伙干一件事。谁也别猛冲，谁也别掉队——按自己的节奏，但都要动。
2. **各出各的领域。** 专业的人干专业的事：你讲你的收纳，我讲我的新媒体，他讲他的门店。不越界，不客串。
3. **阶段性总结、阶段性反馈。** 定期碰头，看数据，看问题，调整打法。不闷头干，不秋后算账。
4. **总运营操盘：柯建军。** 内容策略、发布节奏、数据复盘、整体调度由柯负责。大家认这个，效率才有。
5. **信任靠协议，不靠人情。** 一页纸协议先立住：账号归属、客户归属、分钱规则。丑话说前面，后面才好做朋友。
6. **存量不归个人，比例大家定。** 大家的存量业务柯个人一分不抽，但存量按大家商定的比例贡献进团队公池（投流/工具/场地/活动）——比例开会定；线上业务先进公池，先刨成本再按毛利分——服务老师拿大头，谁都不吃亏。
7. **第一个月现金流优先。** 先跑通能收钱的闭环，再谈放大。

## 五点五、公共线索池与私域转化（关键机制）

### 为什么要有它

**流量进来没人接，等于白来。** 所有账号的咨询、私信、电话、团购核销，统一进**公共资源池**——不归任何个人私有，是团队共同的资产。谁来接？**毛姐专职做销售转化。**

### 线索池规则

1. **所有线索进池**：四个账号（刘晶/袁姐/小九/柯）+ 直播 + 团购的咨询，统一登记（来源账号/客户需求/联系方式/跟进状态）
2. **池子公有，转化专职**：线索不属于"谁的粉丝"，属于团队；毛姐统一承接，避免自己人抢单
3. **成交归属明确**：谁跟进成交，业绩算谁的——登记在案，防撬客也防扯皮

### 私域流程（SOP 初版）

```
线索进来（私信/评论/电话/团购核销）
    ↓ 30分钟内响应（黄金期，晾久了客户就跑了）
建档：来源账号 + 需求类型 + 区域 + 预算 + 意向时间
    ↓
首次沟通（毛姐话术：不硬推，先问清需求）
    ↓
报价（统一价目：收纳/保洁/开荒/家政，各有人报价权）
    ↓
约单（定时间、定人 → 对应服务团队接单）
    ↓
成交后：服务群 + 3-7天回访
    ↓
复购 / 转介绍（服务完开口要，别不好意思）
```

### 毛姐的转化指标（月度看）

- 线索响应率（30分钟内回没回）
- 咨询→约单转化率
- 成交单数、成交金额
- 回访率、转介绍数

> 流量端柯负责（来客），转化端毛姐负责（接客），服务端刘晶/袁姐/小九负责（干活）。
> **三个人干三个活，流水线才转得起来。**

## 七、分润（原则先立，比例开会碰）

**核心逻辑：先刨成本，再分利润；各自产品互相导流、各自分成。谁都不占谁便宜，共赢。**

### 7.1 服务线：先刨成本，再分利润（比例开会定）

**前提：服务费 ≠ 可分配利润。** 每一单先刨掉服务成本（工时 + 物料），剩下的"可分配毛利"才参与分配。

```
例：收纳服务单 2000 元
  工时成本（服务老师干活）：占服务费的大头
  物料/杂费：实报实销
  ──────────────
  可分配毛利：剩余部分
    ├─ 服务老师（干活的人）：拿大头
    ├─ 销售转化（毛姐）：成交提成
    ├─ 运营操盘（柯）：操盘分成
    └─ 团队公池：投流/工具/场地/活动
```

**前提共识（比例全部开会碰）**：
- 服务老师永远是拿最大头的——活是他们干的，这个不能含糊
- 毛姐的提成是**成交提成**，从毛利里出，不是从服务老师兜里掏
- 柯的分成锚定**毛利**，不是流水——流水里大半是成本，按流水分会算出一笔虚账
- 团队成本如拍摄剪辑费用、**刘晶培训基地的使用折价**等，按约定计入团队成本或公池支出
- 具体比例不在这定，开会逐条谈，谈完写进协议

### 7.2 培训线：各自产品、互相导流、各自分成

**大家各有各的课，学员资源互相推荐，推荐人拿推荐分成——你的学员来我这，我赚了给你分；我的学员去你那，你赚了给我分。**

| 产品 | 讲师 | 学员来源 | 推荐分成 |
|---|---|---|---|
| 整理收纳课 | 刘晶 | 全团队推荐 | 推荐人拿约定比例 |
| 保洁实操课 | 袁姐 | 全团队推荐 | 推荐人拿约定比例 |
| 门店运营课 | 小九 | 全团队推荐 | 推荐人拿约定比例 |
| 新媒体课 | 柯建军 | 全团队推荐 | 推荐人拿约定比例 |

**好处**：
- 推荐人有钱赚，才愿意真推——**利他即利己**
- 各自交付各自的课，不抢课、不内耗
- 团队任何一个人的学员想学新媒体，你就有收入；你带的学生想学收纳，刘晶就有收入——**流量在团队内部循环**

### 7.3 柯的立场（原话保留）

1. **零工资，纯分润。** 前期没分润=没收入，这就是柯的投入。
2. **存量不抽个人，但进公池。** 大家现有的单子、老客户，柯个人一分不抽；但成为团队后，**存量业务按大家商定的比例贡献进团队公池**——比例大家说了算，柯不先开价。公池的钱是团队的（投流/工具/场地/活动），不是柯的。
3. **只分线上业务的可分配毛利。** 服务线按毛利分，培训线按各自产品分。
4. **具体比例，开会大家提。** 柯不先开价，大家觉得怎么分合理，拿到桌面上谈。

> 柯的心里话：**签了协议，这事就是自己的事，全力以赴。分钱的事，大家都不容易，定一个大家都舒服的比例，比什么都强。我不占大家便宜，我讲课、我操盘、我出内容——大家共赢。**

## 八、退出机制（先立规矩，后面才好做朋友）

1. **退出提前约定周期。** 任何一方退出，提前约定周期书面告知（如 30 天），留交接时间。
2. **账号是共同资产，不可单方带走。** 签约期间运营的账号归团队共有，退出方不可主张单独带走账号或粉丝。
3. **客户归属按贡献比例协商。** 退出时的客户分配，按签约到退出期间的贡献比例友好协商——协议里有框架，约定前不用细算。
4. **已收款项按协议结算。** 退出前已成交但未分配的服务/培训款项，按已有分润规则结清。

> 这一节写入正式协议。目的是**大家进来时安心，退出时也不伤和气**。
