# 收纳整理 × 保洁 × 新媒体 —— 合作项目计划书（初版）

> 一句话：**我们几个人，各出各的专业，一起把"家政服务 + 新媒体获客 + 培训变现"做成一个完整闭环。**
> 本文档给大家开会用的底稿。看两遍，开会时我们逐条碰，碰完出最终版，按最终版干。

---

## 一、我们为什么一起做（现状）

### 1.1 各自有什么、缺什么

| 人 | 专业/资源 | 缺什么 |
|---|---|---|
| **刘晶** | 整理收纳 7 年、3-5 人团队、培训基地 106 平、服务能交付、客户信任 | 营销获客、内容生产、时间（孩子+旺季） |
| **袁姐** | 保洁业务、出镜潜质、已验证能起量（柯已免费运营 1 个月，月入 1.4W） | 新媒体体系、单量稳定、培训能力 |
| **小九** | 开荒保洁、手下有团队、想做培训、懂门店运营和营销活动 | 内容生产、系统打法 |
| **毛姐** | 家政服务、做事踏实、宝妈转行有亲和力 | 时间（带孩子，弹性参与） |
| **柯建军** | 新媒体操盘（十几个行业经验）、内容流水线、数据判断力、培训课程 | 服务端交付（自己干不了活，也不该自己干） |

**结论就一句话：大家缺的正好是别人有的，这个合作才成立。**

### 1.2 现状事实（不吹不藏）

- 家政服务本身能赚钱，但**获客靠老客户和运气**，不稳定
- 账号有，但内容断断续续，没有系统打法
- 行业里有人靠"割韭菜"赚钱（王一冉模式），**我们不学那种，我们靠真本事**
- 现金流是慢活：**第一个月必须保证现金流进来**，这是硬目标

## 二、我们要做成什么（目标）

### 2.1 短期目标（第 1 个月）——跑通闭环

**"内容 → 获客 → 服务"完整流程跑通一遍，且现金流进账。**

- 每人账号有固定内容产出（刘晶收纳、袁姐保洁、小九开荒/门店）
- 内容带来的咨询和订单可追踪（团购核销、私信、电话）
- 第一个月有真金白银进账——不管多少，证明这条路通

### 2.2 中期目标（第 1-3 个月）——固化流程

- 账号稳定更新，锁定哪些内容有流量（数据说话）
- 服务增量稳定，升单链路跑顺（266 团购 → 2000 服务）
- 培训线启动：先从沙龙/短期班试水

### 2.3 长期目标（3 个月后）——培训成为利润中心

- 培训产品线：收纳（刘晶）+ 保洁（袁姐）+ 门店运营（小九）+ 新媒体（柯建军）
- 家政服务矩阵：收纳 + 保洁 + 开荒 + 家政，互相导流
- **把这套做成样板：大家都能拿得出手的完整案例**

## 三、合作原则（宣教部分 · 一起说好）

1. **一起做，匀速做。** 不是谁帮谁，是合伙干一件事。谁也别猛冲，谁也别掉队——按自己的节奏，但都要动。
2. **各出各的领域。** 专业的人干专业的事：你讲你的收纳，我讲我的新媒体，他讲他的门店。不越界，不客串。
3. **阶段性总结、阶段性反馈。** 定期碰头，看数据，看问题，调整打法。不闷头干，不秋后算账。
4. **总运营操盘：柯建军。** 内容策略、发布节奏、数据复盘、整体调度由柯负责。大家认这个，效率才有。
5. **信任靠协议，不靠人情。** 一页纸协议先立住：账号归属、客户归属、分钱规则。丑话说前面，后面才好做朋友。
6. **不碰存量，只分增量。** 大家现有的老客户、老单子，一分不动；新媒体带来的新订单才参与分账。
7. **第一个月现金流优先。** 先跑通能收钱的闭环，再谈放大。

## 五、内容怎么生产（协作机制）

1. **素材采集**：干活时随手拍（手机就行），按"整理前/中/后 + 贴标签"的习惯来，网盘分类归档
2. **翻译生产**：柯每周出选题和稿子，把大家的专业翻译成短视频语言
3. **发布与复盘**：发布节奏统一，每周看数据：完播/点赞/评论/私信/核销
4. **频次约定**：每人每周至少 2-3 条（商量着定，先跑起来再调）

## 五点五、公共线索池与私域转化（关键机制）

### 为什么要有它

**流量进来没人接，等于白来。** 所有账号的咨询、私信、电话、团购核销，统一进**公共资源池**——不归任何个人私有，是团队共同的资产。谁来接？**毛姐专职做销售转化。**

### 线索池规则

1. **所有线索进池**：四个账号（刘晶/袁姐/小九/柯）+ 直播 + 团购的咨询，统一登记（来源账号/客户需求/联系方式/跟进状态）
2. **池子公有，转化专职**：线索不属于"谁的粉丝"，属于团队；毛姐统一承接，避免自己人抢单
3. **成交归属明确**：谁跟进成交，业绩算谁的——登记在案，防撬客也防扯皮

### 私域流程（SOP 初版）

```
线索进来（私信/评论/电话/团购核销）
    ↓ 30分钟内响应（黄金期，晾久了客户就跑了）
建档：来源账号 + 需求类型 + 区域 + 预算 + 意向时间
    ↓
首次沟通（毛姐话术：不硬推，先问清需求）
    ↓
报价（统一价目：收纳/保洁/开荒/家政，各有人报价权）
    ↓
约单（定时间、定人 → 对应服务团队接单）
    ↓
成交后：服务群 + 3-7天回访
    ↓
复购 / 转介绍（服务完开口要，别不好意思）
```

### 毛姐的转化指标（月度看）

- 线索响应率（30分钟内回没回）
- 咨询→约单转化率
- 成交单数、成交金额
- 回访率、转介绍数

> 流量端柯负责（来客），转化端毛姐负责（接客），服务端刘晶/袁姐/小九负责（干活）。**三个人干三个活，流水线才转得起来。**

## 七、分润（原则先立，比例开会碰）

**柯建军**的立场，先讲清楚：

1. **零工资，纯分润。** 前期没分润=没收入，这就是柯的投入。
2. **不碰存量。** 大家现有的单子，一分不抽。
3. **只分新媒体带来的增量。** 新订单、新学员，参与分账。
4. **具体比例，开会大家提。** 柯不先开价，大家觉得怎么分合理，拿到桌面上谈。

> 柯的心里话：**签了协议，这事就是自己的事，全力以赴。分钱的事，大家都不容易，定一个大家都舒服的比例，比什么都强。**

## 九、阶段性复盘机制

- **每周**：群里同步数据（发布、播放、咨询、成交），柯发周报
- **每月**：线下碰头一次，看大盘：哪条内容有用、哪个环节卡住、下月怎么调
- **原则**：看数据说话，不凭感觉；对事不对人
