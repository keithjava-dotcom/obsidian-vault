# 第01稿 · 同一个当事人，第一次我帮他无罪，第二次我说不行

## 🎬 封面标题建议

**封面标题**：第一次帮他无罪，第二次我说不行

**封面文字**：前刑警·现刑事律师

**平台标题**：同一个当事人两次找我——第一次无罪，第二次我说不行。什么案子能做无罪辩护？

---

## 🧭 结构走线

```
【他又来找我了 · 0:00-0:12】
→ 从第二次的拒绝瞬间切入，别铺垫。这句本身就是钩子——观众想知道为什么。
"过了几年，还是这个当事人，又找到了我。"

【十三年半 · 0:12-0:42】
→ 第一案背景。数字砸脸，过程用短句说。不解释"重不重"，数字自己会说话，语气越平越有分量。
"他被控合同诈骗。量刑建议，十三年半。"

【为什么能赢 · 0:42-1:00】
→ 不是炫耀，是拆穿。能赢是因为案子本身就是错的。这里自然带出经侦/反贪履历——不是背简历，是解释你为什么能看穿证据。
"那个案子事实不清，证据不足，是错案。判断证据链有没有问题——这是我当年在经侦、反贪的老本行。"

【我说不行 · 1:00-1:15】
→ 情绪转折点。从"上次赢了"直接切到"这次不行"——拒绝那句放轻，越轻越狠。
"他跟我说：于律师，这次还想请你帮我做无罪辩护。我说，不行。"

【五十多亿 · 1:15-1:40】
→ 为什么不行。数据一个接一个，不用说严重——观众看完数字自己知道分量。
"涉案金额五十多亿。受害群众上万人。他是核心资金用款方。"

【从轻 · 1:40-1:55】
→ 转折。不是不帮，是换一种帮法。从"争取无罪"转向"争取最轻"——这才是对当事人负责。
"放弃不切实际的无罪诉求。全力争取最轻处罚。"

【结尾 · 1:55-2:10】
→ 不引导观众，不命令观众。说一个自己越来越清楚的判断——观众自己会去想"我遇到的是哪种"。
"打了这么多年官司，我越来越清楚一件事。打官司最怕的不是对手强。是你的律师，不敢对你说不行。"
```

---

## ⚠️ 注意事项

1. **别演。** 就是坐下来跟一个人说话。对面坐着你想象中的那个企业家朋友。你不是在上课，是在聊天。
2. **"我说不行"这句放轻。** 越轻越有分量。不是在拒绝一个人——是在告诉他一件事。语气像"外面下雨了，今天走不了"。
3. **人设植入别背简历。** 「判断证据链有没有问题——这是我当年在经侦、反贪的老本行」——说这句的时候语气是"这本来就是我该干的"，不是"你看我多厉害"。拍的时候可以自然加一句"后来到了纪检也是干这个"，别刻意。
4. **数据别读。** "五十多亿""上万人"——说的时候脑子里过一下那个画面，说完停一拍。于律师的镜头语言就是"说完停一拍让信息落地"。
5. **最怕拍成三种腔**：老师上课（"无罪辩护有三个要件"）、工作总结（"我在XX年办理了XX案件"）、悲情英雄（"我冒着多大压力"）。出现任何一种，重来。
6. **气口**：于律师语速偏慢。一句一个意思。说完停一下。

### 🎤 开拍时补讲

拍的时候顺着稿子自然带出来：
- 第一个那个合同诈骗案，是哪一年的事？跟第二个案子隔了几年？
- 第二个非吸案最后判了多少年？从轻之后的结果能说吗？
- 第一个案子的具体地区能说吗？不方便就继续用"北方"兜住——不勉强。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。于律师理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

过了几年，还是这个当事人，又找到了我。

几年前，他被控合同诈骗。
量刑建议，十三年半。

我带队，全程跟进。
多次开庭。反复核对案卷。
庭审中，我们一再申请休庭，要求检察院补充核心证据。

程序上的漏洞，一条一条被我们翻出来。

打到后来，法院的态度很明确——
要么依法判无罪。
要么检察院主动撤诉。

检察院选择了撤诉。
他无罪释放。

那个案子事实不清，证据不足，是错案。
打无罪，有基础。
判断证据链有没有问题——这是我当年在经侦、反贪的老本行。

隔了几年。
他又被抓了。
这次是非法吸收公众存款。

他记得我上次帮他打到了无罪。
跟我说：于律师，这次还想请你帮我做无罪辩护。

我说，不行。

这个案子，涉案金额五十多亿。
受害群众，上万人。
他是核心资金用款方。
平台所有的吸存行为、资金流转——他全程明知，全程参与。

证据完整。
事实清晰。

这种情况下强行打无罪——不专业。
对当事人也不负责。
只会让他错失从轻处罚的最佳时机。

我给他的方案是：
放弃不切实际的无罪诉求。
全力争取最轻处罚。
主打量刑从轻。

打了这么多年刑事官司。
我有一条原则。

辩护，不迎合当事人的期待。
只忠于事实。
忠于法律。

该无罪的，全力争取清白。
该从轻的，全力降低刑期。

打了这么多年官司，我越来越清楚一件事。
打官司最怕的不是对手强。
是你的律师，不敢对你说不行。
