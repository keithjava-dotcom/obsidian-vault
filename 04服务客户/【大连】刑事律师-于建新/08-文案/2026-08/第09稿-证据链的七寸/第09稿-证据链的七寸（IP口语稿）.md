# IP口语稿 · 证据链的七寸

## 🎬 封面标题建议

**封面标题**（3选1）：
1. 别的律师看案卷找辩点。我看案卷，在找我当年自己会犯的错。
2. 我查过案子，所以我知道公诉方的牌在哪
3. 一份案卷几百页，关键就三页。这三页我查过

**封面文字**：前刑警 · 现刑事律师

**平台标题**：我查过案子，所以我知道公诉方的牌在哪 / 为什么找当过警察的律师不一样

## 🧭 结构走线

```
【开场 · 0:00-0:15】
→ 不讲方法论，讲一件事——坐下来看案卷，看到的东西不一样。
"我干了15年查案。后来做律师，坐下来看案卷。同一沓纸，看到的跟别人不一样。"

【他们看罪名我看漏洞 · 0:15-0:40】
→ 落差。不是贬别的律师，是讲两种训练的区别。
"别的律师翻案卷，先看起诉书定什么罪，再去翻法条找辩点。我不一样。"

【勘查报告那页纸 · 0:40-1:10】
→ 一个具体场景，不抽象讲方法论。经侦审计→讲他送过的经历。
"我在经侦的时候，送过多少份审计报告去鉴定。我知道一份审计在什么条件下会不准。"

【🎤 一眼看穿那一页 · 1:10-1:35】
→ 补讲具体案例。于律师讲一个自己办过的：哪个案子里看到了什么。

【十五年长出来的 · 1:35-1:50】
→ 简短收口。不讲价值不讲使命。
"这个不是理论。不是一个技巧。是十五年，一个一个案子查出来的。"
```

## ⚠️ 注意事项

1. **"同一沓纸，看到的跟别人不一样"**——不是炫耀，是陈述事实。语气要平。
2. **🎤 段**——拍摄时于律师补上具体案例。有那一个案例，整条就从"方法"变成"故事"。
3. **收口不提"价值""护城河"**——"十五年一个一个案子查出来的"就够了。
4. 🔴 不出现城市名、当事人信息。

## 📝 口播文案示例
⚠️ 这是示例，不是逐字稿。
⚠️ 这是示例，不是逐字稿

我干了15年查案。
刑警、经侦、反贪、纪委。

后来辞职做律师。
坐下来看案卷。
同一沓纸，看到的跟别人不一样。

别的律师翻案卷，先看起诉书定什么罪。
再翻法条，找辩点。
这是法学院教出来的。

我不一样。
我翻案卷，先翻现场勘查报告。
勘查的时候，去了几个人？
谁签的字？

我在刑警队待过。
勘查该怎么走，哪些环节容易漏——
我做过。

翻到审计报告的时候，我更慢。
我在经侦的时候，送过多少份审计报告去鉴定。
我知道一份审计在什么条件下会不准。
什么情况下，结论是推出来的，不是查出来的。

反贪做的口供笔录。
一页一页对。
我做过一样的笔录。
我知道哪句话是被引导出来的。

🎤 开拍时补讲一个具体的：你接手哪个案子时，一眼看出证据有问题？是什么问题？那种纯律师视角发现不了的。

这不是理论。
不是一个技巧。
是十五年，一个一个案子查出来的。

你找一个没查过案的律师。
法条他一定比我熟。
但他看案卷的时候，少了一双眼睛。
