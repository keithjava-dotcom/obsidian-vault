# IP口语稿 · 辩护席上见老同事

## 🎬 封面标题建议

**封面标题**（3选1）：
1. 开庭那天，对面坐着我以前的同事
2. 我的第一场辩护，公诉人是我抓人时的搭档
3. 从反贪局辞职后，我第一次开庭就回了原来的地盘

**封面文字**：前刑警 · 现刑事律师

**平台标题**：开庭那天，对面坐着我以前的同事 / 我的第一场刑事辩护

## 🧭 结构走线

```
【开场 · 0:00-0:18】
→ 身份锚两句砸完。不讲经历，讲一个位置——"那个地区，基本上都是我查的"。
说完停半秒。
"我在反贪局当过5年大要案主任。那个地区的职务犯罪，基本上都是我查的。"

【第一场 · 0:18-0:32】
→ 辞职到开庭一句话跳过。两个"就"字把戏剧感压住。
"辞职做律师以后。我接的第一个案子，就在那个地区开庭。"

【对面是谁 · 0:32-0:55】
→ 公诉人、审计，两个身份一个一个翻出来。不渲染。
"支持公诉的，是我以前的同事。申请出庭做审计说明的，也是老熟人。"

【角色对调 · 0:55-1:08】
→ 全稿最核心的停顿。两句干净过，说完停一秒。
"开庭那天，他们站在指控席。我坐在辩护席。"
"角色对调了。"

【怎么打的 · 1:08-1:35】
→ 动作串，四五个动词，不加评论。
"带团队，反复会见当事人。案卷从头翻到尾。出去取证。跟法官沟通了好几次，申请审计出庭。"

【关系没变 · 1:35-2:00】
→ 于建新原话保留。先讲庭审再讲私下，最后一句回到大格局。
"法庭上该争的争该辩的辩。一句不让。但开完庭，私下该打招呼打招呼。"

【收口 · 2:00-2:20】
→ 平静收。不讲大道理，不讲初心。就是一句换了一个位置。
"在反贪局的时候，我是查案的那个人。现在我坐在辩护席上。还是为了同一件事。"
```

## ⚠️ 注意事项

1. **开头"那个地区"**——不用城市名，但语气里要有分量。像是提到一个你很熟悉的地方。
2. **"角色对调了"**——四个字说完停一秒。全稿最安静的时刻。不补后半句。
3. **动作串那段**——不展开任何一个动作。像在翻台历，一笔带过。
4. **"工作是对手，私下是朋友"**——于建新原话，照着念就行，不要加情绪。
5. **收口不提"初心""使命"**——就用"换了一个位置"收住。
6. 🔴 城市名、当事人信息全部不出现。

我在反贪局当过5年大要案主任。
那个地区的职务犯罪，基本上都是我查的。

辞职做律师以后。
我接的第一个案子，就在那个地区开庭。
支持公诉的，是我以前的同事。

申请出庭做审计说明的，也是老熟人。
我在经侦的时候，跟这家会计师事务所合作了很多年。
他出的审计报告，我看了不下几十份。

开庭那天，他们站在指控席。
我坐在辩护席。

角色对调了。

这个案子我带了团队，反复会见当事人。
案卷从头翻到尾。
又调取了大量证据。
跟法官沟通了好几次，申请让审计出庭说明理由。

法庭上该争的争，该辩的辩。
一句不让。

但开完庭，私下该打招呼打招呼。
工作是对手，私下是朋友。

立场变了，但我们要的东西一样。
查清楚事实，让当事人受到公正的惩罚。

在反贪局的时候，我是查案的那个人。
现在坐在辩护席上。
还是为了同一件事。

只是换了一个位置。
