# IP口语稿 · 辩护席上见老同事

## 🎬 封面标题建议

**封面标题**（3选1）：
1. 开庭那天，公诉人是我以前的同事
2. 我坐在辩护席上，对面全是熟人
3. 三个曾经一起查案的人，今天各站各的

**封面文字**：前刑警 · 现刑事律师

**平台标题**：开庭那天，公诉人是我以前的同事 / 我的第一场刑事辩护

## 🧭 结构走线

```
【开庭 · 0:00-0:18】
→ 坐下，抬头，认识。不铺垫，直接进。
"开庭了。坐下。抬头。公诉席上坐的是我以前的同事。"

【第二个人 · 0:18-0:48】
→ 不止一个熟人。三把椅子三个人。
"我们申请审计人员出庭。人走进来。经侦时的老搭档。"

【庭审 · 0:48-1:12】
→ 该怎么打怎么打，打完不伤感情。
"庭审开始。该说的说。该争的争。庭审结束。抬头。看了一眼。"

【收口 · 1:12-1:40】
→ 念头自己冒出来，不是总结。
"立场变了。看的东西没变。工作是对手。私下是朋友。"
```

## ⚠️ 注意事项

1. **别煽情**。画面本来就够强了——三个人、三个位置、一间法庭。让画面自己说话。
2. **语速偏慢**。跟第一稿一样，每句话落定了再下一句。
3. **说到"又认识"时可以停一下**——不用加表情。不是无奈不是讽刺，就是陈述。
4. **"没有话说"**——说这句时表情平静。不是尴尬不是沉重，庭审完了就是完了。
5. **结尾不要用力收**。"工作是对手，私下是朋友"说完就停。别补。
6. **两个【🎤 开拍时补讲】**是留给于律师自己填的。他自己的话比我写的有力量。
7. **城市名不要说**。稿子里没有地名，安全。

开庭了。
我坐下。
抬头。

公诉席上坐的是我以前的同事。

那是我辞职以后，接的第一个刑事案子。
开庭的地方不陌生。
反贪局当大要案主任时那片辖区。

我们申请了审计人员出庭作证。
门开了。
人走进来。

又认识。

经侦时合作过多年的会计师事务所老友。

他站证人席。
同事站公诉席。
我坐辩护席。

三个曾经一起查案的人。

庭审开始。
该说的说。
该争的争。

【🎤 开拍时补讲：庭审里一个具体的交锋——他说了什么，你回了什么。一个来回。你自己的话比我写的有力量。】

庭审结束。
抬头。
看了一眼。

没有话说。

立场变了。
看的东西没变。

还是证据链。
还是程序。
还是哪里不对，哪里有漏洞。

【🎤 开拍时补讲：对视那一瞬间，有没有一个念头冒出来？不用完整句子，一两个字都行。】

以前破案抓人。
现在维护当事人权益。

殊途同归。

工作是对手。
私下是朋友。
