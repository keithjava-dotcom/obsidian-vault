## 🧭 结构走线

```
【开场 · 0:00-0:12】
→ 数字砸脸，不讲废话。

【专案组卡住了 · 0:12-0:30】
→ 不讲"我很优秀"，讲"他们缺人干活"。三重经验一笔带过。
"当时我还是反贪局大要案主任。专案组遇到瓶颈了。全省抽调人。"

【🎤 怎么突破的 · 0:30-1:00】

【挽回一个多亿 · 1:00-1:15】
→ 结果两个数字收，不渲染。
"侦查终结，移送审查起诉。挽回一个多亿。因为这个案子，我调进了纪委。"

【纪委不一样 · 1:15-1:45】
→ 不讲大道理，讲一个认知转变。公安和纪委的逻辑差异，一句说清楚。
"公安查案，讲证据链、讲程序。纪委不一样。它是政治机关。"
```

## ⚠️ 注意事项

1. **🎤 标记段**——拍摄时于律师自己补上那个瓶颈细节。有这一步，整条就立住了。
2. **"专案组遇到瓶颈了"**——不展开解释，观众知道"有困难"就行。留白。
3. **收口不评价纪委**——只讲事实上的逻辑差异，不褒不贬。
4. 🔴 国企名称、城市、董事长姓氏全部不出现。

一个国企董事长，贪污国有资产，一个多亿。
2012年，省纪委抽调我去查一个案子。

当时我还是反贪局大要案主任。
专案组遇到瓶颈了。
从全省抽调办案能手。
我有刑侦、经侦、反贪三重经验，被选进去了。
后期整个侦查工作，是我牵头的。

🎤 开拍时补讲：这个案子最难突破的是哪一步？你进专案组后第一件事做了什么？当初为什么卡住了？讲一个具体动作或画面。

侦查终结，移送审查起诉。
挽回一个多亿的损失。
因为这个案子，我被正式调到了纪检监察机关。

在纪委待了这几年，我有一个感受。
公安查案，讲的是证据链、程序正义。
每一步都要经得起法庭质证。

纪委不一样。
纪委是政治机关。
第一件事不是查案，是讲政治。

辞职做律师以后我才真正明白。
刑事辩护律师，必须懂官场生态。
不懂这个，你辩不好。

不是叫你妥协。
是叫你知道，案子背后的东西是什么。
