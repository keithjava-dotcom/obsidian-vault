# IP口语稿 · 刑警首案·抛尸

## 🎬 封面标题建议

**封面标题**（3选1）：
1. 我第一次出现场，是个抛尸案
2. 没有监控没有DNA，命案怎么破
3. 看了二十多年案卷，看的东西没变过

**封面文字**：前刑警 · 现刑事律师

**平台标题**：我第一次出现场，是个抛尸案 / 那会儿我还在用BP机

## 🧭 结构走线

```
【开场 · 0:00-0:15】
→ 上来就是现场。不铺垫不自我介绍。"师父说"三个字把紧张感架起来。
"尸体在郊外，现场干干净净。我师父说：这案子不好破。"

【现场 · 0:15-0:35】
→ 带着观众一步一步看——没有血迹没有厮打，推翻第一现场假设。
"没有血迹没有挣扎。杀人的地方，不在这儿。"

【年代 · 0:35-1:05】
→ 三个物件钉死年代。用"有什么、没什么"代替"那时候苦"。
"我腰里别着BP机。队里最好的车是212吉普。"

【走访 · 1:05-1:35】
→ 没有监控怎么破？靠人走。身体要在场——冰天雪地。
"冰天雪地的，刺骨的风。一家一家问。"

【🎤 补讲：关键线索】
→ 走访时哪个人、哪句话让你觉得"就他了"——自己的话比任何文案都真实。

【真相 · 1:35-2:05】
→ 从奔走追查落到起因是喝酒。巨大落差。"一条人命"三个字收住。
"一条人命。就因为喝了一顿酒。"

【刑警的话 · 2:05-2:40】
→ 两句原话不动字。说完停一下，让话落地上。
"做警察没做过刑警，等于没干过警察。好人不愿干，坏人干不来。"

【收口 · 2:40-3:15】
→ 刑警→经侦→反贪→纪委→律师一句带过。翻开案卷看的还是那些东西。
"当年在雪地里一步一步走出来的东西，现在还在用。"
```

## ⚠️ 注意事项

1. **别念成回忆录**。不是"当年多辛苦"，是"当年怎么干的"——区别在：前者自我感动，后者让人看见。
2. **语速偏慢**。每句话落定了再下一句。你不是在赶时间，是在跟一个人说一件真事。
3. **说到"好人不愿干坏人干不来"，可以笑一下**。不是苦笑——是"这份活就是这样"的了然。
4. **"我师父说：这案子不好破"**——说这句的时候不要加重。师父说这话的时候是平静的，你回忆的时候也是。
5. **结尾不要用力收**。像话说到一半突然想到的——"现在还在用"就是收口，别再多说。
6. 🔴 城市名用"北方某市"即可，不需要说具体地名。
7. **两个【🎤 补讲】**是留给于律师自己发挥的——他自己的话比任何文案都真实。拍之前跟他过一遍这两个点。

尸体在郊外。
现场干干净净。
没有血迹。
没有厮打的痕迹。

我师父说：这案子不好破。

那是我从中国刑警学院毕业，分到重案大队的第一年。
学了四年侦查。
到现场才知道，学校教的和眼前的东西，是两回事。

杀人的地方，不在这儿。

那年头什么也没有。
没有监控。
没有DNA。
没有大数据。
腰里别的是BP机。
想打电话，得找公用电话。
队里最好的车是212吉普。
桑塔纳是领导坐的。

就这些。

案子怎么办？
靠人。

一户一户走。
冰天雪地的，刺骨的风。
一家一家问。

【🎤 开拍时补讲：你走访的时候，哪个人、哪句话让你觉得"就他了"？把那个瞬间说出来。】

最后查出来了。
起因是喝酒。

两个人喝酒，一方把另一方打了。
被打的那个人，觉得伤了面子。
心里憋屈。
找了个机会，把打他的人杀了。
扔到郊外。

一条人命。
就因为喝了一顿酒。

当年刑警队有两句话。
做警察没做过刑警，等于没干过警察。
还有一句：好人不愿干，坏人干不来。

难的不是危险。
是你得把自己放进去。

后来我去了经侦。
去了反贪局。
去了纪委。

现在我是律师。
坐在辩护席上看案卷。
看的还是那些东西。

哪里不对。
哪里矛盾。
证据链哪个环节少了什么。

当年在雪地里一步一步走出来的东西。
现在还在用。
