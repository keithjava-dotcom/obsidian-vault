# IP口语稿 · 银行非法放贷案·一个案子让我换了单位

## 🎬 封面标题建议

**封面标题**（3选1）：
1. 我给银行追回了近一个亿，立了一个二等功
2. 一个案子，我从公安调到了检察院
3. 查到一半发现不对：这案子不归公安管了

**封面文字**：前经侦大队长 · 现刑事律师

**平台标题**：我给银行追回了近一个亿，立了一个二等功 / 银行报的案，我查着查着发现不归公安管了

## 🧭 结构走线

```
【开场 · 0:00-0:15】
→ 三个结果直接甩出来。不讲背景不铺垫，每句之间不停、句号后略顿。
"我给银行追回了近一个亿。因为这个案子立了二等功。然后调去了检察院。"

【银行来报案 · 0:15-0:35】
→ 平铺直叙。不加情绪，像在跟人讲事。
"地方银行违法发放贷款。巨额资金被挪到外省做了固投。短期借款变长期。钱回不来。"

【查到一半发现不对 · 0:35-0:55】
→ 全稿最核心的一句。"发现不对"要轻，不是惊叹，是查着查着意识到。
"带着人开始查。查到一半发现——这个案子不归公安管了。"

【最高检指定管辖 · 0:55-1:15】
→ 管辖链条快速过。不用解释每个环节。
"涉案近20人。跨省。联合专案组。层层报上去。最高检反贪总局指定管辖。"

【全国各地抓人 · 1:15-1:45】
→ 动词串起来。数字压住。"全是我亲自带队"可以稍重。
"将近两年。全国各地抓人。近20人全是我亲自带队。查封冻结几千万。"

【近一个亿 · 1:45-2:00】
→ 回到开头，闭环。不说"最终"。
"追回近一个亿。二等功。调检察院。反贪局大要案主任。"

【收口 · 2:00-2:20】
→ 不吹自己。碰上了，接住了。说完停住。
"一个案子让一个人从公安到了检察院。不是多厉害。碰上了。刚好我接住了。"
```

## ⚠️ 注意事项

1. **开头三个短句一气呵成**。"近一个亿""二等功""调检察院"，句号后略有停顿但节奏紧凑。
2. **"查到一半发现不对"**——语气要轻。不是突然发现惊天秘密，是查着查着意识到管辖权不在自己手里。说完略停。
3. **"全是我亲自带队"**——可以有一点点重，但不过。是陈述事实，不是炫耀。
4. **收口"碰上了，刚好我接住了"**——不是谦虚，是于律师对自己的真实评价。说完停住，别补。
5. 🔴 城市名、银行名称、具体省名全部不出现。

## 📝 口播文案示例

我给银行追回了近一个亿。
因为这个案子，我立了一个二等功。
然后我从公安调到了检察院。

当时是地方银行来报的案。
违法发放贷款。
一笔巨额资金被挪到了外省，做了固定资产投资。
短期借款变成了长期占用。
钱回不来。
银行面临巨大的损失。

我带着人开始查。
查到一半，发现不对。

这个案子涉案将近二十个人。
大量的资金流转、合约关系，已经超出了公安机关的管辖范围。
是检察机关的事。
而且地域上，也超出了我所在的省。

市委政法委牵头，公安、检察成立联合专案组。
层层报上去申请管辖。
最终是最高检反贪总局指定管辖。

接下来将近两年。
全国各地抓人。
涉案将近二十人，全是我亲自带队抓回来的。
查封、冻结、扣押了几千万。

最终给银行追回了近一个亿。

这个案子结束以后，我立了个人二等功。
也因为办这个案子，我被检察机关作为专门人才调走。
去了反贪局，任大要案主任。

一个案子，让我从公安到了检察院。
后来我在反贪局又干了五年。

不是因为我多厉害。
是这种案子，刚好让我碰上了。
也刚好我接住了。
