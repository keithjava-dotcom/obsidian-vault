## 第〇节：咱俩的分工（开播前先立明白）

**规则你研究，内容我研究。** 平台规则这种"查得到的"，你比我细（你连客服都问了）——这块你出师了，以后规则你说了算，我只帮你盯"规则会变"的坑（比如抖音资质每年复审）。

但内容这块，**交给我**：

| 你擅长 | 我负责 |
|--------|--------|
| 规则、合规、办案 | 观众为什么愿意看、愿意信、愿意找你 |
| 法律知识 | 把"你的经历"变成"观众的故事" |
| 严谨、准确 | 讲案子不讲法条、讲人话不讲官话 |

**一句话定调：你的账号不是涨粉用的，是"攒信任"用的** — 目标是让看到你的人想找你办案，不是让观众觉得"学到了"。所有内容都围绕这个设计。

## 第一部分：内容框架（60分钟标准场）

### 一、定位（开播前想清楚，越垂直越精准）

**你是全平台唯一一个"查过案的律师"** — 刑警5年+经侦5年+反贪5年+省纪委+中纪委，全链条查案经历，这是你的独家赛道：

| 别人讲不了 | 你能讲 |
|-----------|--------|
| 法条、理论 | **办案内幕视角**：一个案子是怎么被查出来的、证据是怎么形成的、哪个环节最致命 |
| 通用普法 | **职务犯罪/经济犯罪**：贪污、受贿、挪用、集资诈骗、合同诈骗、非法放贷 |

**一句话定位**：办过全国最大集资诈骗案的刑警，转型刑辩律师，带你从"办案人视角"看懂刑事风险。

### 二、内容结构（60分钟）

| 阶段 | 时长 | 干什么 | 注意 |
|------|------|--------|------|
| **开场** | 5min | 我是谁（刑警→反贪→中纪委→刑辩律师）+ 今天讲什么 + 「有相关问题的扣1」 | 别念简历，一句话带出身份反差：**"我干了20年查案，现在干辩护"** |
| **干货** | 30-40min | 一个真实案例 → 讲透一个法律知识点 | **以案释法，讲案子不讲法条**。故事优先，知识点藏故事里 |
| **答疑** | 15min | 挑评论区问题回答 | 具体个案**只给方向不给意见**（见注意事项第2条） |
| **收尾** | 5min | 总结要点 + 引导关注 + 预告下场 | 别说"关注我"，说"点个关注少走弯路" |

### 三、选题方向（按你的独家素材库）

**1. 办案视角类（你的王牌）**：
- "集资诈骗案是怎么被查出来的"（你办过全国最大的）
- "一个案子，公安是怎么锁定嫌疑人的"
- "口供是怎么形成的？为什么说'零口供'也能定罪"
- "纪委查案，先查什么？"

**2. 刑事风险提醒类**：
- "老板最容易踩的刑事红线（采购回扣/挪用/虚开发票）"
- "公司出事，法人、财务、业务员谁先被抓"
- "家属被带走后，黄金37天能做什么"

**3. 反常识/颠覆认知类**：
- "为什么说'请律师要趁早'——早了和晚了差别有多大"
- "很多案子，其实是家属自己说坏的"

**4. 蹭热点类**：
- 明星/企业家出事 → 讲同类罪名怎么定罪、怎么辩护
- 注意：**热点只做引子，3分钟内必须回到你的案例和知识点**

### 四、每场直播的通用骨架

```
开场（5min）：身份反差一句话 + 今日主题 + 互动提问
├─ 案例开场：讲一个真实案子的开头（悬念）
├─ 展开：这个案子怎么查的/怎么辩的（办案视角，讲故事）
├─ 知识点：这个案子里藏的法律点（自然带出，不硬讲）
├─ 延伸：普通观众/老板/家属，分别要记住什么
└─ 答疑互动：挑3-5个问题（含预埋的问题）
收尾（5min）：一句话总结 + 关注引导 + 下场预告
```

## 第二部分：注意事项（三条硬线 + 三条软线）

### 🔴 硬线（碰了出大事，一条都不能碰）

**1. 不给具体个案出法律意见**
- 观众问具体案子：永远不直接回答"你这个能判几年/能不能赢"
- 标准话术：**「您的情况比较复杂，为了给您负责任的建议，建议您带齐材料到律所面谈，或者加我微信预约咨询。」**
- 原因：直播环境无法核实事实，口头意见一旦被录屏传播，就是执业风险

**2. 不谈在办案件**
- 正在办理的案子（无论自己还是同行办的），一个字都不提
- 保密义务 + 避免舆论干扰司法

**3. 不承诺结果**
- 禁止"这个案子我肯定能办成""保证无罪""有关系"等任何承诺性表述
- 律师宣传红线，违者吊销执业证

### 🟡 软线（影响观感和合规形象）

**4. 别讲成普法课**
- 你的差异化是"办案人视角"，不是"法条搬运工"
- 检验标准：如果这段话换个律师也能说，就删掉重讲

**5. 敏感信息脱敏**
- 所有案例必须脱敏：当事人用"王某/某企业"，地点模糊化
- 办案机关名称、专案组细节、涉及国家机密的内容一概不讲
- 你档案里自己说过："有很多东西不便于说出来"——这个分寸保持住，观众反而更信你

**6. 内容红线**（平台审核层面）：
- 不聊具体政治案件、不评论司法个案审判结果
- 不制造对立情绪（"律师就是帮坏人说话"这种话题不接，容易引战）
- 不引导站外交易（别说"私聊我""加我微信"太频繁，用"主页有联系方式"替代）
