# 个人IP行业知识提取：从张伟实战中学到的

## 一、陪伴型博主：第三种定位

市面上博主分两种：导师型（我成功了教你）和干货型（我给你方法）。张伟让我们看到第三种：**陪伴型博主**。

核心公式不是「我教你」，是「我还在路上，走给你看」。

适用人群：负债者、迷茫期、转型中、还没成功但有真实经历的人。这类人最忌讳包装成成功者——观众不傻，一眼识破。把「还没成功」从弱点变成卖点：我冲在前面排雷、避坑、刷失败经验。

**落地动作：** 第一条视频第一帧就亮身份——「我是负债者」，不铺垫，不解释。不是博同情，是建信任。

## 二、侦察兵差异化

还没成功但有真实故事的客户，差异化策略只有一条：做侦察兵，不做将军。

- ❌ 包装成成功者 → 被质疑
- ❌ 回避失败经历 → 失去最大武器
- ✅ 「我还在探路，先把前面有什么告诉你」

「冲在前面排雷避坑刷失败经验」比「我帮你成功」更有信任感。因为观众知道后者是吹牛，前者是真的。

**适用判断：** 客户如果已经成功 → 走导师型。客户如果正在路上 → 走侦察兵型。关键不是成没成功，是承不承认。

## 三、知识类→观点分享类：平台语境的切换

张伟爱读书（毛选、纳瓦尔、道德经），如果做成「知识讲解」→ 平台判定为说教，限流。

转换公式：**知识有对错，观点没对错。** 把「毛选里这句话的意思是XX」改成「毛选里这句话，我是这么理解的」。

三个动作：
1. 永远加「个人观点，不代表对」
2. 每引用一个典故，立刻用大白话翻译一遍
3. 不让观众觉得「他在上课」，要让观众觉得「他在跟我聊天」

## 四、负债/困境类IP的内容边界

负债者身份是双刃剑——真实，但容易触发「卖惨」质疑。

**边界线：**
- ✅ 说「我现在欠XX万，正在一点点还」
- ❌ 说「我好惨，帮帮我」
- ✅ 核心信息是「我在爬起来」
- ❌ 核心信息是「我有多惨」

**操作标准：** 每期涉及负债的内容，结尾必须落在「行动」上，不能落在「情绪」上。今天做了什么、还了多少、学到了什么——让观众记住的是行动力，不是悲惨度。

## 五、典故引用规则：一拖一

张伟的口头表达习惯是先铺典故再回主题（王阳明龙场悟道、OPPO广告、段永平）。这是他的思考风格，但搬到短视频里容易「飘」。

**规则：每个典故必须「一拖一」**——引用一个典故，立刻跟一句大白话翻译。不能只丢典故让观众自己悟。

例句转换：
- ❌ 「就像王阳明龙场悟道一样」
- ✅ 「王阳明在龙场躺了三年，不是躺平，是在聚能。我现在也是这样。」

## 六、前6条冷启动策略：混合打法

纯立人设的前6条 → 观众不认识你，凭什么看你的故事？

**调整策略：** 干货和立人设混合。
- 第1条：纯立人设（「我是负债者」）→ 开场即定调
- 第2-4条：干货+人设混合 → 用价值留住观众
- 第5条：引流案例 → 真实数据
- 第6条：建信任收尾

1000粉前不做变现内容。先让人认识你，再让人信任你，最后才谈钱。

## 七、「赌注」选题法

每条选题必须标注一个「赌注」——这条视频凭什么让观众停下来。

张伟前6条的赌注：
| 选题 | 赌注 |
|------|------|
| 我是负债者 | 负债者不卖惨，反而有力量 |
| 负债后读毛选 | 毛选不是老古董，能解决当下困境 |
| 为什么不去打工 | 不打工不是懒，是算过账 |
| 纳瓦尔一句话 | 一句话比一本书有用 |
| 自媒体第1天数据 | 真实数据比吹牛有信任感 |
| 不以目的为目标 | 反直觉的价值观让人停下来想 |

**赌注检验标准：** 如果赌注是「这个观点很新颖」→ 太弱。如果赌注是「观众看完会转发给一个正在负债的朋友」→ 够强。

## 八、客户沟通中的信号识别

从张伟的沟通记录中提取的关键信号：

1. **「我不知道自己有没有表达清楚」** → 不自信信号。不是他表达不清楚，是他对自己要求高。应对：直接告诉他「你刚才说得很好，就是那个意思」，而不是帮他重说一遍。
2. **「有点扯远了哈」** → 自我打断信号。他的思考是发散型的，需要有人帮他拉回来。不是打断他，是用一个问题帮他聚焦。
3. **典故引用** → 思考深度信号。他用典故不是掉书袋，是真的在用经典理解自己的处境。尊重这个习惯，同时帮他做「大白话翻译」。
