# 把灵感变成视频：以戴律请回答《别贪》为模板

## 为什么用这个例子

你昨天在灵感里说的那个案子——客户开完庭才找律师，自己说的话全对自己不利——本质和戴律的"别贪"是同一种素材：**一个具体的案子 + 一个值得讲的教训**。

区别只在于：戴律知道怎么把素材**组织成品**。下面拆给你看。

---

## 第一步：戴律《别贪》的结构拆解

整条视频就三层：

### 第一层：开头（5-8秒）——扔一个钩子

```
"别贪，开庭会被同事围观，
人教人学不会，事教人一教就会。"
```

**他在干嘛？**
- 直接跟观众对话（不自我介绍、不铺垫）
- 给一个反直觉的画面：开庭被同事围观
- 一句金句收尾：人教人学不会，事教人一教就会

**公式**：一个具体场景 + 一个引发好奇的结论 = 观众想往下看

---

### 第二层：故事主体（60-80秒）——用画面感讲故事

戴律用了几招，每一招都可以照搬：

| 戴律的做法 | 为什么有效 | 你怎么用 |
|-----------|-----------|---------|
| **场景还原**：阶梯报告厅座无虚席、一两百号人、金属铐子碰撞声 | 让观众"看到"画面，不是"听到"信息 | 还原你那个案子的庭审现场：当事人站在被告席上，法官问一句他答一句，每句话都在自爆 |
| **对话引用**："你是否申请回避？""你认罪吗？""你大声一点！" | 对话比叙述有力量十倍，观众自动脑补场景 | 引用庭审笔录里的原话——他说了什么对自己不利的话？法官什么反应？ |
| **法律知识自然带出**：职务侵占vs贪污、非公受贿的量刑标准 | 知识不是硬塞的，是故事讲到那儿了自然需要解释的 | 讲完当事人自爆后，自然解释：为什么没律师在场，你说的每句话都可能变成判决书上的依据？ |
| **情绪对比**：村支书甩锅 vs 老母落泪 | 一个故事有好人坏人，观众才有情绪投入 | 当事人后悔 vs 你接手后的无力感 vs 最终说服法官的转机 |

**关键规律**：戴律不是"普法"，他是"讲一个案子里发生的事，顺便让你学到了法律"。顺序永远是**故事在前，知识在后**。

---

### 第三层：结尾（10-15秒）——一个立场

```
"莫伸手，伸手快去自首，
大数据时代无所遁形。"
```

**他在干嘛？**
- 不总结全文（那是学生作文）
- 给一个鲜明的个人态度：不是"大家要注意"，是"罪有应得"
- 一句话钉在观众脑子里

---

## 第二步：对照——你的灵感长什么样，戴律会怎么讲

### 你的原始素材

> 客户开完庭才来找我。庭审笔录一看，他没找律师，说的话全对自己不利。法官印象已经形成。我要求重开，法官说"不能因为换律师就重开"。最后我说服了法官，带新证人进去。

### 用戴律结构重新组织

**开头（钩子）**：

> 开庭不带律师，等于把刀递给对方自己捅自己。
> 这个案子，当事人就是这么干的。

两个版本供参考，看你喜欢哪种风格：
- 冷峻版：「开庭不带律师，等于把刀递给对方自己捅自己。」
- 故事版：「我最近接了一个案子——当事人开完庭才来找我。我一看庭审笔录，倒吸一口凉气。」

**故事主体（需要你补充细节）**：

用戴律"场景还原+对话引用+情绪对比"三招：

1. **场景还原**：当时那个法庭什么样子？你在哪坐着？拿到庭审笔录时什么感觉？
2. **对话引用**：当事人笔录上说了什么把自己坑了的话？（这个最有杀伤力）法官当时什么态度？
3. **关键转折**：法官说"不能因为换律师就重开"——你是怎么说服他的？这个"说服"的过程就是全片最精彩的部分。你在走廊里堵的？在办公室谈的？用了什么法律依据？
4. **知识自然带出**：讲完这个案子后，一句话点破——程序规则决定了你能讲多少理。法律不是谁有理谁赢，是谁能按规则把理讲清楚谁赢。

**结尾（立场）**：

> 法庭不是说理的地方，是讲规则的地方。
> 你不懂规则，有理也是输。

或者更锐利一点：

> 我不是在普法，我是在告诉你：等你觉得需要律师的时候，已经晚了。

---

## 第三步：为什么这个结构好用

一条视频就是一个"故事袋子"：

```
开头 → 扔一个冲突/反直觉的事，让人停住
中间 → 讲一个具体的故事，把知识缝进去
结尾 → 给一个鲜明的态度，让人记住你这个人
```

你不需要"总结全文"，不需要"大家好我是XXX律师"，不需要"今天给大家讲一个知识点"。

你就是讲一个你接过的案子，让观众看完觉得：
1. 这个律师真有经验（故事证明的，不是你自夸的）
2. 我懂了点东西（知识是顺便的）
3. 这人挺有意思的（你有立场、有态度）

---

## 你的下一步

上面那个"故事主体"标了 **"需要你补充细节"** 的地方，就是你要回去想的东西。

具体来说，补这几样就行：

1. 庭审笔录里，当事人说了哪几句话最致命？（原话，不是概括）
2. 法官拒绝重开时，原话怎么说的？
3. 你说服法官的那个瞬间，发生了什么？（在哪、怎么说的、法官怎么改口的）

补完这三样，立刻就能拍。
