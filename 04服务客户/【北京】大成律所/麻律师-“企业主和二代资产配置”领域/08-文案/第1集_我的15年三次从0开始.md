# 第2集 · 我的15年，三次从零开始

> ⚠️ 逐字稿是举例，让她感受语感方向。用自己的话说。
> 🎯 目标用户：30+女性，想换行但不敢换
> 📍 情绪线：共鸣→被激励→我也想试试

---

## 【第一段：开头钩子】

### 骨架提示
```
身份叠出来（数学→金融→公务员→律师）→ 观众好奇"为什么一直换"
→ 反抛给观众："你是不是也想过换，但没敢？"
```

### 逐字稿举例
我本科读的是数学。
后来去英国读了金融。
回来考了公务员，就是财政局和司法局，干了10年。
然后辞职，做了律师。

就是，很多人会问我，你为什么一直在换。

### → 开放式问题
1. 四个身份你怎么用一句话说出来？
2. 最常被问的问题是什么？
3. 对着镜头问——"你是不是也想过换，但一直没敢？"

### → 注意事项
🔴 开头不报名字 | 🟡 身份只叠不解释


## 【第二段：公务员辞职】

### 骨架提示
```
30多岁辞掉10年铁饭碗（困境1：所有人说疯了）
→ 最难的前两年：凌晨律所、堆成山案卷、被拒绝（困境2：没人信）
→ 5年后最年轻合伙人+连续两年创收奖（解决方案：深耕）
→ 落点：不是"我很厉害"，是"我当时也不知道能不能成"
```

### 逐字稿举例
其实当时辞职的时候，我已经30多了。

不是刚毕业的小孩，可以随便试。
辞掉一个10年的公务员——
所有人跟我说，你是不是疯了。

刚出来的那两年，真的难。
没有人脉，没有资源。
以前在体制内，你是被服务的。
出来做律师，你是去服务别人的。
这两个角色，完全反过来。

比如说，凌晨的律所我见过。
堆成山的案卷我见过。
被拒绝、被质疑，我都见过。

然后5年之后，我成了大成最年轻的合伙人之一。
连续两年，拿到了所里的创收奖。

### → 开放式问题
1. 最难的一个瞬间——具体：几点、在哪、什么感觉？
2. 什么时候觉得"这一步走对了"？一个案子还是一个人？

### → 注意事项
🔴 "凌晨的律所"换成你的时间——凌晨几点？ | 🟡 创收奖说完就过


## 【第三段：做自媒体】

### 骨架提示
```
现在拍短视频（又一次从零开始）→ 说实话也不知道能不能做好
→ 但我还是来了（跟前面一样的节奏：先做了再说）
```

### 逐字稿举例
然后现在，算是第二次从零开始。做自媒体。

对着镜头说话这件事，我以前从来没干过。
就是，说实话，我今天坐在这录这条视频——
拍之前我也不知道能不能说好。
但我觉得，试一下。

### → 开放式问题
1. 第一次拍视频什么感觉？
2. 做得好好的为什么来拍视频？

### → 注意事项
🔴 不说"我很自信" | 🟡 "拍之前也不知道能不能说好"——真实的紧张


## 【结尾收束】

### 骨架提示
```
五个身份串联 → 每一次身边人都说不行 → 我都走下来了 → 报名字
```

### 逐字稿举例
数学，到金融，到公务员，到律师，到现在对着镜头拍视频。
每一次，身边的人都说不行。

但我都走下来了。

我是麻思文，大成律所合伙人。

### → 注意事项
🔴 不说"你也可以" | 🟡 报名字干净利落
