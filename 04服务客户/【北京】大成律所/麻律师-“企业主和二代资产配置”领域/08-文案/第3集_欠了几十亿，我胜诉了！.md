# 第4集 · 欠了几十亿，我胜诉了！

> ⚠️ 逐字稿是举例，让她看语感。用自己的原话讲案例和故事。
> 🎯 目标用户：潜在客户。看到麻律师的底线——有原则地赢。
> 📍 情绪线：震惊→理解→信任

---

## 【开头钩子】

### 骨架提示
```
抛出最冲击的案子 → 几十亿、胜诉了 → 停半秒（让观众脑子撞一下）
```

### 逐字稿举例
就是，我办过一个案子。

政府这边确实欠了对方几十亿。
几十亿。

但是最后，我们胜诉了。

### → 注意事项
🔴 说完"胜诉了"停半秒


## 【案子怎么赢的】

### 骨架提示
```
事实层面输了（确实欠了几十亿）
→ 程序层面赢了（对方起诉程序错了）
→ 结果：卡住了，挽回几十亿国有资产
→ 轻描淡写收：怎么样我胜诉了
```

### 逐字稿举例
其实不是从事实层面胜诉的。
是从程序层面。

对方起诉我们的程序错了——
他不应该在这个诉讼里跟我们要钱。
应该通过其他方式。

最后对方就卡在那了。
相当于给政府挽回了数十亿的国有资产。

怎么样，我胜诉了。

### → 苏格拉底式提问（她自问自答）
1. 我们确实欠了钱，几十亿。那怎么办？
2. 为什么最后赢了？因为程序。所有案子，事实是一方面，程序是一方面。程序不正确，实体再对也不行。

### → 注意事项
🔴 不讲法条 | 🟡 "几十亿"说两遍


## 【价值观：为什么帮欠钱的人】

### 骨架提示
```
观众质疑：欠了钱还帮，公平吗？
→ 回应：法律不看谁欠谁，看程序、证据、道理
→ 底线：不能为了赢教客户做不道德的事 ← 🔴 语气硬
→ 落点：深耕认真负责，客户自己会观察你
```

### 逐字稿举例
有人问，欠了人家钱，你还帮他打赢，这公平吗？

我跟你说，法律不是看谁欠了谁。
是看程序是不是正当。
证据能不能站住。
道理在谁那。

就是，我是原告的律师也好，被告的律师也好——
肯定有一方是不对的。
但是你不能为了赢，教客户做不道德的事。

你只要合理合法地把问题解决了。
深耕，认真，负责。
客户自己会观察你。

### → 苏格拉底式提问
1. 有人问你"公平吗"，你第一反应是什么？
2. 见过律师为了赢教客户不道德的事吗？（点到为止）
3. 怎么跟客户说"这个我做不了"？用"是就是，不是就不是"。

### → 注意事项
🔴 "不能做不道德的事"——语气硬，停一下 | 🟡 不展开讲那个不好的律师


## 【那个观察我五年的人】

### 骨架提示
```
讲故事（不是讲道理）
→ 十多年的关系 → 当科员时拨过款 → 做律师后没求过他
→ 他有自己的团队 → 但一直在观察 → 五六年
→ 今年突然给了好几个案子 → 我都没营销他 → "帮大哥一个忙"
```

### 逐字稿举例
比如说，有一个房地产老板，我认识他十多年了。

我当科员的时候给他拨过款。
后来出来做律师，就是我从当律师最一开始的时候，就没有求过他。
他有自己的顾问团队。
但他一直在看。

观察了我五六年。
今年突然找到我，给了我好几个案子。

其实我都没营销过他。
只是跟他说，这个事，我当帮大哥一个忙。

### → 开放式问题
1. 这个人你认识多久了？怎么认识的？
2. 你出来做律师后他没找你？他在观察什么？
3. 今年怎么找到你的？你当时怎么回？

### → 注意事项
🔴 "十多年""五六年"保留 | 🟡 "帮大哥一个忙"——原话别改 | 🟢 讲完不总结
