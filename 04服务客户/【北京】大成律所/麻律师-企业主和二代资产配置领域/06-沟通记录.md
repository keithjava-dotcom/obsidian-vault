
# 2026-04-29 与麻律师首次面谈记录

## 📋 核心议题摘要

### 一、服务范围明确
- **柯哥提供**：账号定位、选题方向、文案策划、内容复盘（"内功"部分）
- **柯哥不提供**：拍摄和剪辑（可推荐人，约4500-6000元/月，15-20条）
- **逻辑**：内容策划和画面执行是两层，分开更高效

### 二、跨行业方法论
- 所有行业底层逻辑一样：分析目标用户 → 反推关心话题 → 设计选题
- 短视频本质是"组词套公式"：开头（钩子）→ 中间（持续看下去的动力）→ 结尾（引导互动）
- 举例：行业内幕、展示过程、三段论等都是可跨行业套用的公式
- 专业知识由IP自己输出，柯哥负责结构和表达

### 三、合作流程
1. 麻律师先看柯哥课程（包含定位、选题、文案、拍摄、剪辑基础）
2. 课程有作业，做完作业柯哥出定位方案
3. 麻律师日常记录灵感（语音转文字），每周碰一次排优先级
4. 麻律师出初稿 → 柯哥修改点评 → 定稿拍摄
5. 初期300-500字稿，适应后可增加

### 四、内容策略
- **账号三件事**：我是谁 → 我在做什么 → 我凭什么做这个
- **三类内容**：立人设（过往经历）→ 日常工作故事 → 客户关系与行业解读
- **销售逻辑**：覆盖率（引流）→ 建立信任 → 转化 → 服务 → 新一波覆盖率
- **画面公式**：名词+动词=素材（如说"喝水"就拍喝水动作）

### 五、工具讨论
- **Obsidian**：知识管理工具，本地存储、Markdown格式、神经元链接
- **DeepSeek API**：便宜（10元起充），国内无需翻墙，可接入Obsidian插件
- **Claude**：最好用但需翻墙，API可通过淘宝商家部署
- **灵感记录**：苹果自带语音输入法 → 备忘录/文件助手 → 周末统一整理
