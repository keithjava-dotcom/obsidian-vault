# 第3集 · 律师工作流程大公开

> ⚠️ 逐字稿是举例，让她看语感方向。用自己的细节、自己的案例去填骨架。
> 🎯 目标用户：潜在客户。看完觉得"这个律师靠谱"。
> 📍 情绪线：好奇→原来如此→信任

---

## 【开头钩子】

### 骨架提示
```
开庭两小时（反差钩子）→ 为了这两小时我做了什么 → 今天全公开
```

### 逐字稿举例
一个案子开庭，可能就两个小时。

但是为了这两个小时，我做的事情，其实你们看不到。

今天，律师工作流程大公开。

### → 注意事项
🔴 第一句就砸。不报名字 | 🟡 "大公开"可以用——因为是真的在展示


## 【五步流程】

### 骨架提示
```
第一步：沟通→出案情分析报告
第二步：拿着报告跟客户分析风险胜算
第三步：签代理协议（一笔带过）
第四步：列大事记+案例检索（🔴 核心差异，必须展开细节）
第五步：庭前写好法官要的材料（🔴 判决都让我写——具体案例）
→ 收：庭上两小时最不值得一提
```

### 逐字稿举例
就是，我跟你说一下我接一个案子的流程。

第一步，跟当事人充分沟通。
不是聊两句就完了。
是出一份完整的案情分析报告。

第二步，拿着报告跟客户分析——
这个案子你的风险在哪，胜算在哪。
让客户看完报告，自己心里就有数了。

第三步，签代理协议。

第四步，列大事记。按时间顺序、事件顺序，把事实脉络理清楚。
同时做案例检索——全国类似的案子怎么判的，全部翻出来。
这个就是诉讼可视化。
很多律师只拿嘴跟客户讲。
我有报告，有大事记，有案例。

第五步，庭前把法官要的代理意见、证据目录，全部写好。
就是，没等他要，我就交上去了。
这样一来，法官下判决的效率大大提高。
甚至判决都让我去写。

庭前认真准备，庭后积极跟法院沟通。
庭上那两小时——
是最不值得一提的。

### → 🔴 必须用自己的细节替换的地方

| 步骤 | 你要填的具体细节 |
|------|----------------|
| 第一步 | 报告多少页？包含什么？举个真实案子——哪个报告你做了一周？ |
| 第二步 | 哪个客户看完报告说了什么？"原来有这么多风险"？ |
| 第四步 | 大事记多长？全国翻了多少判决？法官看到你的大事记说过什么？ |
| 第五步 | 哪个案子的判决是你写的？提前多久交的？ |

### → 注意事项
🔴 一个细节=一个信任点。不说"大概""很多"，说数字
🟡 "很多律师只拿嘴跟客户讲"——语气硬一点
🟢 五步之间用"然后""接下来"过渡
