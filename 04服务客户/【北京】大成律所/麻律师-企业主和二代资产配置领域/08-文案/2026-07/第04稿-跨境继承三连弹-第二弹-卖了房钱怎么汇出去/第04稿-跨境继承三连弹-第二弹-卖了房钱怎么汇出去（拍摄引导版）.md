# 🎬 封面标题建议

**封面标题**：八百万在卡里，转不出去。

**封面文字**：跨境财富传承律师

**平台标题**：继承了国内的房子，卖了钱却汇不出去——这一步大多数人不知道。

---

## 📋 开拍前说明

麻律师，这条接着上一弹走。上一弹讲的是"绿卡和入籍继承规则不同"，这一弹讲"钱到了你卡里，不等于你能弄出去"。

对面坐着一个刚继承完国内房产的人。他以为事情结束了，来找你纯粹聊聊天——结果你告诉他，后面还有一关。

你的语气：不是吓唬他，是"我见过太多人卡在这一步了，我来帮你理一遍"。

## 🧭 结构走线

```
【开场 · 0:00-0:15】

→ 口播引文：我有一个客户，国内房子卖了，八百万到账了。他跟我说：麻律师，这钱怎么转到国外去？他以为这就是个转账的事儿。

→ 设计说明：直接从故事中间开始。不铺垫"今天讲讲跨境汇款"。这个客户是活的——他有名字吗？没有名字也行，但要有行业、身份，让观众能对上："这个人是做实业的还是做贸易的？"一句带过就能让故事落地。

穿插问题①【开放式·问自己】：带我看看这个客户。他做什么的？房子在哪？卖房是因为继承还是自己决定变现？这八百万现在就是安全地在卡里，还是他已经在焦虑了？——不用全回答，挑一个最让你印象深刻的细节讲就行。


【障碍 · 0:15-0:40】

→ 口播引文：可以转，有正规通道——个人财产对外转移，不是灰色地带。但这扇门不随便开。

继承权公证书。房屋买卖合同。完税证明。资金合法性说明。一套材料要串成一条链。少一个环节，打回来。重新排队重新等。一两个月白等。

→ 设计说明：罗列材料的时候慢一点，每一样之间给半拍停顿——让观众在脑子里过一遍"我有没有这些"。不要恐吓，就是摆事实："你需要这些东西，缺一个就不行"。

穿插问题②【开放式·问自己】：你帮客户走过最典型的一个案例——材料在哪一步断了？等了多久？客户当时什么状态？最后怎么补上的？不用从头讲，就讲最卡的那个环节。一两分钟的事也行，但要有那个"我当时也觉得头疼"的真实反应。


【为什么我能帮你走通 · 0:40-1:00】

→ 口播引文：这些事，法律上证明"钱是你的"，程序上证明"钱可以出去"——两套逻辑。我在财政局待过九年，我知道规则在纸面上怎么写的，也知道规则在现实里怎么转的。

可能跟我本科学数学也有关系——材料链条有没有断点、时间节点能不能咬合，在我脑子里天然就是一张表。

→ 设计说明：这里不是炫耀，是解释"为什么我能帮到你"。财政局经历和数学底子说自然，不用加重语气。像在回答一个问题："你为什么懂这个？" "哦，因为我以前在财政局……"


【收尾 · 1:00-1:10】

→ 口播引文：继承只是第一步。钱到了你名下，不等于到了你手里。中间还隔着这套手续。提前把材料准备好，它就跟填表一样——不难，但你要知道有这个门。

→ 设计说明：落点是行动——让观众回去翻一翻自己手上有哪些材料。不劝关注不卖服务。就是"我跟你说个事，你自己回去看看"。
```

## ⚠️ 注意事项

1. **案例是你最大的武器**。外汇政策人人都能查，但你经历过的那些卡住、打通、客户从焦虑到放心——这些东西别人没有。大胆讲，越具体越好。
2. **财政局经历说一次就够**。不在全篇反复提。就那一句——"我在财政局待过九年"——够了。剩下的信任交给内容。
3. **数学底子同理**。一句话带过。"可能跟我学数学有关"——不用展开，观众自己会脑补。
4. **不要给观众"这事太麻烦了我不搞了"的感觉**。整条视频的态度是：这事正规、有流程、需要准备——但只要你提前准备了，它不难。
5. **语速控制**。罗列材料那一段尤其要慢——"继承权公证书。房屋买卖合同。完税证明。资金合法性说明。"每一样之间有空隙。
