**封面标题**：证明"你是你"——这件事比继承还难。

**封面文字**：跨境财富传承律师

**平台标题**：中文名、英文名、结婚改名——继承的时候，你得先证明这些名字是同一个人。

## 📋 开拍前说明

麻律师，这是三连弹最后一集。前两集讲了"规则不同""钱出不去"，这一集讲"你连继承资格都要先证明"。

对面坐着一个改过名字、或者拿过外国护照的人——他完全不知道这个名字变化在继承的时候意味着什么。

这条的节奏跟前面两条不一样：前面是"告诉你一个事"，这条带一点黑色幽默——荒谬是真的荒谬，但解决它不需要恐慌。

## 🧭 结构走线

```
【开场 · 0:00-0:15】
→ 捅穿荒谬感，不铺垫。你碰过这种客户没——中文名、英文名、改的名，继承时要证明三个名字都是同一个人，当时第一反应是什么？
"你证明一下你是你——这句话听着像个笑话。但在继承这件事上，它真的是一道关。"

【为什么会有这道关 · 0:15-0:35】
→ 三种场景每段停半拍——让观众自己对号。不用案例，这事人人能对上。
"三十年后回国继承——房产证上是出生时的中文名，银行账户是出国前的名字，护照名字跟这两个都对不上。"

【流程没有那么恐怖 · 0:35-0:55】
→ 同一人公证说清楚——在哪办、要什么材料。讲一个你帮客户做过最复杂的，名字变了几次、哪个环节最磨人。
"这事有解——同一人公证。有标准流程。但问题是你得先知道有这个流程。"

【什么时候该做 · 0:55-1:10】
→ 语气轻一点、快一点。像提醒朋友：改名字换护照的时候顺手做了。
"不是继承的时候才去办，是改了名字换了护照的时候就该顺手做。就跟备份一样。"

【收尾 · 1:10-1:20】
→ 三弹收束。把第一第二弹的刺点串回来，最后一句慢下来像画句号。观众听完会回头找前两条——不用喊关注，内容自己会拉。
"规则不同是第一关，钱怎么汇出去是第二关，得先证明这些名字都是你是第三关。"
```

## ⚠️ 注意事项

1. **黑色幽默，不要恐怖。** "你证明一下你是你"这件事本身就荒谬——让观众感受到荒谬而不是被吓到。笑一下也行，没关系的。
2. **罗列场景的时候慢。** "出国用了英文名。结婚改了姓。入籍有了新名字。"每个变化之间留空隙，让观众自己对号。
3. **同一人公证的具体流程你要自己确认过。** 我说的材料清单是基于常识写的——你自己做过的案子更准。如果某一项材料写错了，录的时候用你自己的版本。
4. **三弹互链自然收。** 最后把三弹串起来的那句话不要念得像片尾字幕——就是一句话带过，像聊天聊到一个话题结尾了。
5. **这条风格跟前面两条不同。** 前面两条是"告诉你一个专业的事"，这条带一点"这世界有时候挺荒诞的"——你的个人气质可以多露一点。
