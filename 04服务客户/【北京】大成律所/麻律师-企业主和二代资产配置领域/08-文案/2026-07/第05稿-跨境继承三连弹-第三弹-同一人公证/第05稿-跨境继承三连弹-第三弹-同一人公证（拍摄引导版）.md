# 🎬 封面标题建议

**封面标题**：证明"你是你"——这件事比继承还难。

**封面文字**：跨境财富传承律师

**平台标题**：中文名、英文名、结婚改名——继承的时候，你得先证明这些名字是同一个人。

---

## 📋 开拍前说明

麻律师，这是三连弹最后一集。前两集讲了"规则不同""钱出不去"，这一集讲"你连继承资格都要先证明"。

对面坐着一个改过名字、或者拿过外国护照的人——他完全不知道这个名字变化在继承的时候意味着什么。

这条的节奏跟前面两条不一样：前面是"告诉你一个事"，这条带一点黑色幽默——荒谬是真的荒谬，但解决它不需要恐慌。

## 🧭 结构走线

```
【开场 · 0:00-0:15】

→ 口播引文：你证明一下你是你——这句话听着像个笑话。但在继承这件事上，它真的是一道关。

→ 设计说明：
第一句直接捅穿荒谬感。
不要铺垫、不要解释。
让观众愣一下——"你在说什么？"——然后你往下讲，他就会听。

穿插问题①【开放式·问自己】：
你有没有碰过这样的客户？
中文名字、英文名字、结婚改的名、移民改的名——继承的时候要证明这三个名字都是同一个人。
你当时第一反应是什么？是觉得"这怎么证明"，还是立刻知道流程？把那个瞬间说出来。


【为什么会有这道关 · 0:15-0:35】

→ 口播引文：出国的时候用了英文名。
结婚的时候改了姓。
入籍的时候有了新的法律姓名。

三十年后父母走了，你回国继承财产——国内房产证上是你出生时的中文名字。银行账户是你出国前的名字。你拿到手的外国护照，名字跟这两个都对不上。

不动产登记中心说：请证明这些名字是同一个人。

→ 设计说明：三段式罗列名字变化的场景，每段之间停顿半拍——让观众自己在脑子里对号入座。"我有没有改过名？我护照上的名字跟身份证一样吗？"——这个反应就是最好的内容。

这里不需要案例，因为每一种名字变化观众自己就能对上。你的任务是把场景罗列清楚。


【流程没有那么恐怖 · 0:35-0:55】

→ 口播引文：这事有解——同一人公证。

你拿着新旧护照、出生证明、改名证明、结婚证明，到你目前居住地的公证处或者中国驻外使领馆，做一份公证，证明这些名字指向的是同一个人。

有标准流程。但问题是——你得先知道有这个流程。很多人到了继承那天才知道，然后慌了。

→ 设计说明：把"同一人公证"说清楚。什么是同一人公证、在哪做、要什么材料。越具体越好。"到你目前居住地的公证处或者中国驻外使领馆"——这句话就是行动指南。

穿插问题②【开放式·问自己】：你帮客户做过最复杂的一个同一人公证——名字变了多少次？材料需要几份？哪个环节最磨人？讲出来。这个案子不需要大，但一定有个最折腾的细节——就讲那个细节。


【什么时候该做 · 0:55-1:10】

→ 口播引文：这件事在继承发生之前最好就做完。不是你继承的时候才去办，是你改了名字、换了护照的时候，就应该顺手把公证做了。

就像备份。平时做不觉得有多大用，到了要用的时候没有——那个成本就高了。

→ 设计说明：态度像在提醒一个朋友。不是什么惊天大发现，就是"我跟你说个事，你回去弄一下"。语气轻一点、快一点——前面已经把最荒诞的部分讲完了，收尾不要拖。


【收尾 · 1:10-1:20】

→ 口播引文：绿卡入籍的规则不同，是第一关。钱怎么合法汇出去，是第二关。第三关，你得先证明这些名字都是你。三道关，每一道都有解——但你得提前知道有这些关。

→ 设计说明：三连弹收束。把第一弹和第二弹的刺点串回来——"规则不同""钱出不去""得先证明你是你"。观众听完这条会回头找前面两条——这个互链本身就是账号粘性。不用喊"关注我"，内容自己会拉。

最后一句话稍微慢一点点，像画句号。
```

## ⚠️ 注意事项

1. **黑色幽默，不要恐怖。** "你证明一下你是你"这件事本身就荒谬——让观众感受到荒谬而不是被吓到。笑一下也行，没关系的。
2. **罗列场景的时候慢。** "出国用了英文名。结婚改了姓。入籍有了新名字。"每个变化之间留空隙，让观众自己对号。
3. **同一人公证的具体流程你要自己确认过。** 我说的材料清单是基于常识写的——你自己做过的案子更准。如果某一项材料写错了，录的时候用你自己的版本。
4. **三弹互链自然收。** 最后把三弹串起来的那句话不要念得像片尾字幕——就是一句话带过，像聊天聊到一个话题结尾了。
5. **这条风格跟前面两条不同。** 前面两条是"告诉你一个专业的事"，这条带一点"这世界有时候挺荒诞的"——你的个人气质可以多露一点。
