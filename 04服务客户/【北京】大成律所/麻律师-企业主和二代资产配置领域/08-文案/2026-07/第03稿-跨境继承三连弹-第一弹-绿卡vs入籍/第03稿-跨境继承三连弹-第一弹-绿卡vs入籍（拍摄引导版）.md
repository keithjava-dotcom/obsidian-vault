# 🎬 封面标题建议

**封面标题**：绿卡，还是入籍？继承的时候差几百万。

**封面文字**：跨境财富传承律师

**平台标题**：90%的人分不清绿卡和入籍的区别，到了继承这一步才知道代价。

## 📋 开拍前说明

麻律师，这条视频讲给谁看——

海外有身份的人，或者子女拿了绿卡/入了籍的人。他们默认"绿卡和入籍差不多"，从没想过这个区别在继承的时候后果完全不同。

你今天是帮他们提前避坑的那个人。不是念法条，是"我跟你说个事，你可能从来没想过"。

对面坐着一个刚拿到绿卡的朋友，他不知道这意味着什么。你帮他理一遍。

## 🧭 结构走线

```
【开场 · 0:00-0:15】

→ 口播引文：绿卡和入籍，你觉得有区别吗？到了继承那天，分不清的代价，可能是几十万、几百万。

→ 设计说明：直视镜头，直接提问。不要解释背景，不要铺垫。这句话本身就是钩子——谁听到"几十万几百万"都会停下来。

穿插问题①【开放式·问自己】：你见过最典型的一个案例——客户因为绿卡和入籍的区别，在继承上吃了大亏。是什么情况？大概损失了多少？——讲这个故事的时候不要念稿，就是回忆。讲完了这15秒自然结束，不要着急收。


【讲清楚 · 0:15-0:45】

→ 口播引文：绿卡，永久居留权，你还是中国人，拿中国护照。继承国内财产，适用中国法律，跟国内一样。

入籍，你是外国公民了。继承的时候，你的身份是"外国人"。房产还好——不动产适用不动产所在地法，中国房子走中国法。但存款、理财、股权这些动产——适用被继承人死亡时的经常居所地法律。这意味着什么？同一个家庭、同一笔遗产，入籍的和没入籍的人，适用的可能是两套法律。分配比例不一样。税务处理也不一样。

→ 设计说明：用最口语的话把两个概念区分开。"房产还好"就是口语化支撑——让观众感觉你不是在讲课，是在聊天。讲到"适用被继承人死亡时的经常居所地法律"时可以稍微停顿一下，给人消化。

这整段都是法律事实，不用自由发挥——但说出来的时候不要像背书。就是"我跟你说啊，绿卡是这么回事，入籍是那么回事，差在哪呢，差在这里"。像在咖啡厅解释给朋友听。


【给画面 · 0:45-1:00】

穿插问题②【开放式·问自己】：有没有一个具体的客户，因为入籍，继承的时候发现分配比例跟没入籍的兄弟姐妹不一样？或者税务上多交了多少？把那个场景说出来——谁、什么身份、什么遗产、怎么发现不对劲的。哪怕就说两三句也行，观众要的就是这一个真实画面。

→ 设计说明：这一段靠你现场发挥。不用准备，就回忆一个案子。观众听完前面"两套法律、分配不一样"的抽象讲解，需要一个活人来验证——"真的有人因为这个吃亏了"。


【不是偏袒谁 · 1:00-1:15】

→ 口播引文：这不是法律偏袒谁。规则就是这样——国籍变了，继承链条上每一环的适用规则跟着变。你知道了，提前规划就好。不知道，等继承发生的时候再来处理，成本就高了。

→ 设计说明：收住"恐怖感"。不能让人觉得"太吓人了我不搞了"。态度是：这件事没那么复杂，但你需要早知道。


【收尾 · 1:15-1:25】

→ 口播引文：我是麻律师。如果你或者你家里人有海外身份，先搞清楚你是绿卡还是入籍——差的不只是护照，差的是你父母留给你的东西，能不能安全落到你手里。

→ 设计说明：不劝关注不劝私信。落点是让观众看完想去查一下自己的身份状态——这个行动本身就是信任。
```

## ⚠️ 注意事项

1. **别演**。就是平时跟客户聊天的状态。有人问你"绿卡和入籍有啥区别"，你怎么说就怎么说。
2. **别念数字**。"几十万几百万"就够了，不用精确数字——这个视频卖的是"你从没想过这个区别"，不是算账。
3. **穿插问题是你即兴发挥的空间**。讲到那个位置，自然停下来讲个案子——案子越具体越好，一两句话够用。
4. **别踩同行**。就讲自己的专业，不做对比。
5. **语速放慢**。"被继承人死亡时的经常居所地法律"这句话，说快了观众跟不上——慢一点，像在帮人理一理。
