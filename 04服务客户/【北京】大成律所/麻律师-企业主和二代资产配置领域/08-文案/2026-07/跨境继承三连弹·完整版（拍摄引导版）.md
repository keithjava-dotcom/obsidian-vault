# 🎬 封面标题建议

**封面标题**：继承国内财产，这三道关很多人到死都不知道。

**封面文字**：跨境财富传承 · 大成律所合伙人

**平台标题**：绿卡还是入籍？钱怎么汇出去？怎么证明你是你？——跨境继承三连问。

---

## 📋 开拍前说明

麻律师，这条是三弹合一的长视频，大概三到四分钟。

递进逻辑：第一关，绿卡和入籍继承规则不一样。第二关，继承完了钱未必出得去。第三关——也是最荒诞的——你得先证明你是你。

语气：咖啡厅聊天。"我跟你讲三个事，你可能一个都没想过。"

---

## 🧭 结构走线

```
【第一关 · 绿卡vs入籍 · 约1分钟】

【开场 · 0:00-0:15】
→ 口播引文：绿卡和入籍，你觉得有区别吗？到了继承那天，分不清的代价，可能是几十万、几百万。
→ 设计说明：直视镜头，直接提问。这是整条视频的钩子，一个问题把三关全打开。不铺垫。

穿插问题①【开放式·问自己】：你见过最典型的案例——客户因为绿卡和入籍的区别在继承上吃了亏。是什么情况？大概损失多少？讲的时候就是回忆，不要念稿。

【讲清楚 · 0:15-0:45】
→ 口播引文：绿卡，永久居留权，你还是中国人，拿中国护照。继承国内财产，适用中国法律，跟国内一样。
入籍，你是外国公民了。继承的时候，你的身份是"外国人"。房产还好——不动产适用不动产所在地法，中国房子走中国法。但存款、理财、股权这些动产——适用被继承人死亡时的经常居所地法律。同一个家庭、同一笔遗产，入籍的和没入籍的人，适用的可能是两套法律。分配比例不一样。税务处理也不一样。
→ 设计说明：用最口语的话把概念区分开。不要像背书。"房产还好"就是口语化支撑。讲到"经常居所地法律"时停顿一下。

穿插问题②：有没有客户因为入籍，分配比例跟没入籍的兄弟姐妹不一样？或者税务上多交了？说出那个场景。

【转场 · 0:45-0:55】
→ 口播引文：这是第一关——规则不同。还有第二关。
→ 设计说明：短转场，不废话。


【第二关 · 卖了房钱怎么汇出去 · 约1分钟】

【入题 · 0:55-1:10】
→ 口播引文：钱到了你名下，不等于到了你手里。我有一个客户，国内房子卖了，八百万到账了。他问我：麻律师，这钱怎么转到国外去？他以为这就是个转账的事儿。
→ 设计说明：从故事中间开始。八百万是画面，"以为是转账"是反差。

穿插问题③：带我看这个客户。他做什么的？房子在哪？最让你印象深刻的细节是什么？

【障碍 · 1:10-1:35】
→ 口播引文：可以转，有正规通道——个人财产对外转移。但这扇门不随便开。
继承权公证书。房屋买卖合同。完税证明。资金合法性说明。一套材料要串成一条链。少一个环节，打回来。重新排队重新等。一两个月白等。
→ 设计说明：罗列材料时每样之间停顿半拍——让观众在脑子里过一遍"我有没有这些"。

穿插问题④：你在哪一步见过客户被卡住？等了多久？怎么补上的？就讲最卡的那个环节。

【能力说明 · 1:35-1:50】
→ 口播引文：这些事，法律上证明"钱是你的"，程序上证明"钱可以出去"——两套逻辑。我在财政局待过九年，我知道规则在纸面上怎么写的，也知道规则在现实里怎么转的。
→ 设计说明：一句话带过，不是炫耀。

【转场 · 1:50-1:55】
→ 口播引文：这是第二关。还有第三关——这关最荒诞。
→ 设计说明：带一点调侃，预告"接下来有意思了"。


【第三关 · 同一人公证 · 约1分钟】

【入题 · 1:55-2:10】
→ 口播引文：你证明一下你是你——这句话听着像个笑话。但在继承这件事上，它真的是一道关。
→ 设计说明：直接捅穿荒谬感。前面两关是专业壁垒，这关是黑色幽默。笑一下也行。

穿插问题⑤：有没有客户，中文名、英文名、结婚改名、移民改名——继承时要证明这些名字都是同一个人。你第一反应是什么？

【场景罗列 · 2:10-2:30】
→ 口播引文：出国的时候用了英文名。结婚的时候改了姓。入籍的时候有了新的法律姓名。
三十年后父母走了，你回国继承财产——国内房产证上是出生时的中文名字。银行账户是你出国前的名字。外国护照上的名字跟这两个都对不上。
不动产登记中心说：请证明这些名字是同一个人。
→ 设计说明：三段罗列，每段停顿半拍。让观众自己对号入座。

【解决方案 · 2:30-2:55】
→ 口播引文：这事有解——同一人公证。
拿着新旧护照、出生证明、改名证明、结婚证明，到公证处或者中国驻外使领馆，做一份公证，证明这些名字指向的是同一个人。有标准流程。
这件事在继承发生之前最好就做完。不是继承的时候才去办，是改了名字、换了护照的时候，顺手做了。就像备份。平时不觉得有多大用，到了要用的时候没有——那个成本就高了。

穿插问题⑥：最复杂的一个同一人公证——名字变了几次？材料几份？哪个环节最磨人？就讲那个细节。

【收尾 · 2:55-3:10】
→ 口播引文：绿卡入籍的规则不同，是第一关。继承完了钱怎么汇出去，是第二关。你得先证明这些名字都是你，是第三关。三道关，每一道都有解——但你得提前知道有这些关。
→ 设计说明：三关收束。速度慢慢降下来。最后一句画句号。
```

## ⚠️ 注意事项

1. **语速分段控制。** 第一关偏慢（法律定义要消化），第二关中等（故事推进），第三关稍快（幽默需要节奏）。总体比单条略快——长视频太慢观众会走。
2. **转场干脆。** 两个转场不加废话，一句话切过去。
3. **穿插问题能答几个答几个。** 六个优先答印象最深的。某一关没有对应案例就跳过穿插问题——法律事实本身就硬。
4. **第三关的黑色幽默是你个人的东西。** 前面两关你是专业律师帮人避坑。第三关多一点"这世界有时候挺荒诞的"——笑一下没关系。
5. **别踩同行，别喊关注。** 内容就是最好的转化。
6. **超时就砍穿插问题。** 每关约一分钟，超了砍穿插问题不砍结构——穿插问题是加分项不是必选项。
