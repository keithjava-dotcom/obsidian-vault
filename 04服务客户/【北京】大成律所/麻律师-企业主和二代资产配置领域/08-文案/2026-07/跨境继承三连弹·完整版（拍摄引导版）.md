# 🎬 封面标题建议

**封面标题**：继承国内财产，这三道关很多人到死都不知道。

**封面文字**：跨境财富传承 · 大成律所合伙人

**平台标题**：绿卡还是入籍？钱怎么汇出去？怎么证明你是你？——跨境继承三连问。

---

## 📋 开拍前说明

麻律师，这条是三弹合一的长视频，大概三到四分钟。

递进逻辑：第一关，绿卡和入籍继承规则不一样。第二关，继承完了钱未必出得去。第三关——也是最荒诞的——你得先证明你是你。

语气：咖啡厅聊天。"我跟你讲三个事，你可能一个都没想过。"

## 🧭 结构走线

```
【第一关 · 绿卡vs入籍 · 约1分钟】

【开场 · 0:00-0:15】
→ 第一句就捅破代价——几十万几百万，别铺垫。这儿带你碰过的一个案子——客户因为绿卡和入籍的区别在继承上吃了亏，讲那个画面。
"绿卡和入籍，你觉得有区别吗？到了继承那天，分不清的代价，可能是几十万、几百万。"

【讲清楚 · 0:15-0:45】
→ 绿卡和入籍两笔账算清楚。房产走中国法，存款理财走经常居所地法——同一个家庭、两套法律、分配比例不一样。别像讲课，就是咖啡厅跟朋友说。
"绿卡，你还是中国人。入籍，继承的时候你是'外国人'。"

【转场 · 0:45-0:55】
→ 一句话转，不带包袱。
"这是第一关——规则不同。还有第二关。"

【第二关 · 卖了房钱怎么汇出去 · 约1分钟】

【入题 · 0:55-1:10】
→ 从故事中间开始。八百万在卡里转不出去——客户以为就是个转账。把你印象最深那个客户的画面带出来。
"我有一个客户，国内房子卖了，八百万到账了。他以为这就是个转账的事儿。"

【障碍 · 1:10-1:35】
→ 念材料清单时慢一点，每样之间空半拍——让观众自己对"我有没有"。不是恐吓，是摆事实。
"可以转，有正规通道。但这扇门不随便开。少一个环节，打回来。一两个月白等。"

【能力说明 · 1:35-1:50】
→ 一句话带过财政局九年——不是炫耀，是"我刚好懂这个"。
"法律上证明钱是你的，程序上证明钱可以出去——两套逻辑。"

【转场 · 1:50-1:55】
→ 带点调侃，预告接下来有意思了。
"还有第三关——这关最荒诞。"

【第三关 · 同一人公证 · 约1分钟】

【入题 · 1:55-2:10】
→ 捅穿荒谬感，不铺垫。
"你证明一下你是你——这句话听着像个笑话。但在继承这件事上，它真的是一道关。"

【场景罗列 · 2:10-2:30】
→ 三种名字变化的场景，每段停半拍——让观众自己对号入座。不用案例，这事人人能对上。
"出国用了英文名。结婚改了姓。入籍有了新法律姓名。三十年后回来，三个名字对不上。"

【解决方案 · 2:30-2:55】
→ 同一人公证说清楚——在哪办、要什么。讲一个你办过最折腾的，名字变了几次、卡在哪个环节。
"这事有解——同一人公证。有标准流程。"

【收尾 · 2:55-3:10】
→ 三关串回来。第一弹第二弹的刺点收束，最后一句慢下来画句号。
"规则不同是第一关，钱怎么汇出去是第二关，得先证明这些名字都是你是第三关。"
```

## ⚠️ 注意事项

1. **语速分段控制。** 第一关偏慢（法律定义要消化），第二关中等（故事推进），第三关稍快（幽默需要节奏）。总体比单条略快——长视频太慢观众会走。
2. **转场干脆。** 两个转场不加废话，一句话切过去。
3. **穿插问题能答几个答几个。** 六个优先答印象最深的。某一关没有对应案例就跳过穿插问题——法律事实本身就硬。
4. **第三关的黑色幽默是你个人的东西。** 前面两关你是专业律师帮人避坑。第三关多一点"这世界有时候挺荒诞的"——笑一下没关系。
5. **别踩同行，别喊关注。** 内容就是最好的转化。
6. **超时就砍穿插问题。** 每关约一分钟，超了砍穿插问题不砍结构——穿插问题是加分项不是必选项。
