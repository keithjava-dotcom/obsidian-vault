# 拍摄指南 · 第1集：数学系出身的律师

> ⚠️ 本文件不是逐字稿。是"结构引导+开放式问题+注意事项"格式。
> 麻律师用自己的话讲，用自己的语感录，不背稿。
> 柯哥的目标：让她学会，不是替她写。

⏱ **建议时长**：2分钟左右
🎯 **目标**：让人记住"数学系律师做财富传承"这个标签
📍 **情绪线**：好奇 → 被场景击中 → 信任


## 【第一段：开头钩子（前15秒）】

### → 你要说什么
说出你身份的"不搭"——数学系毕业、英国读金融、政府干10年，最后做了律师。制造好奇。然后一句话点出"为什么"：因为发现中国有钱人最大的风险不是投资亏损。

### → 开放式问题引导
1. 用一句话说出你的多重身份（数学系→英国金融→政府10年→律师）
2. 你在政府期间看到了什么具体的事，让你意识到"财富传承"是个大问题？（必须是一个你亲眼见过的场景，不要抽象的"很多家庭"）
3. 为什么这个场景让你睡不着觉？

### → 注意事项
- 🔴 开头7秒不要铺垫，第一句就直接砸身份反差："我是数学系毕业的，后来去英国读了金融，在政府干了10年——然后辞职做了律师。"
- 🟡 不需要介绍"我叫麻思文，是律师"——名字留到结尾说
- 🟡 不要解释"数学系为什么适合做律师"——这条不是讲逻辑的，是打认知的
- 🟢 你亲眼见过的那个场景，说具体点。什么人、出了什么事、结果多惨。让观众有画面。


## 【第二段：核心内容（约80秒）】

### → 你要说什么
讲一个案例（不用真实名字）——某企业家突然走了，家人以为一切正常，结果3个月内资产缩水40%。然后自然过渡到"这不是有钱人才需要想的事"。

### → 开放式问题引导
1. 你经手过或者见过的案例里，哪个最让你觉得"这人要是提前安排好了，根本不会这么惨"？用你自己的话讲出来。
2. 这件事里，损失最惨重的是谁？（配偶？孩子？合伙人？）TA当时的处境是什么样的？
3. 如果这个人在出事前一年做了安排，结局会有什么不同？
4. 你平时怎么跟客户解释这件事的重要性？用你跟朋友喝咖啡聊天的方式说出来。

### → 注意事项
- 🔴 不要变成讲法条、讲继承法第几条——你的语言风格指南说得很清楚：你不喜欢讲干货，你擅长讲故事+结论
- 🟡 案例里用你习惯的"自问自答"：比如说"那怎么办？"——然后你自己答。这是你的庭审思维，保留
- 🟡 说到具体数字的时候，大胆说。观众不怕听数字，怕听虚的
- 🟢 情绪不需要煽情。你是内敛的人，案例讲完轻轻带过就行——"这件事本来可以很简单…结果搞成这样。"就是你的味道


## 【第三段：结尾收束（约25秒）】

### → 你要说什么
不是有钱人才需要想这件事。有房产、有公司、有孩子在海外——就需要。关注我，用最直白的方式说清楚。

### → 开放式问题引导
1. 你最想让哪类人看到这条视频？（创一代？富二代？有海外资产的家庭？）对着镜头像跟TA说话一样
2. 你希望观众看完这条做什么？（关注？评论区说说自己最担心什么？）
3. 用一句话收住全片，这句话要让人记住你是谁——试着用你自己的方式说"我是做什么的"

### → 注意事项
- 🔴 结尾不要"求关注""求点赞"——你是律师，不是博主。"关注我，我们慢慢聊"，这是你的温度
- 🟡 名字留到结尾说。最后3秒："我是麻思文，大成律所合伙人，专注做财富传承。"干净利落
- 🟢 如果结尾你说了"关注我"，说完之后停留0.5秒再切——给观众一个接收的缓冲
