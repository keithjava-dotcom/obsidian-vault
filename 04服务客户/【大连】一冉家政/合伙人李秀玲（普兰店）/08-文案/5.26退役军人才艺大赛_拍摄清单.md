# 5.26 退役军人才艺大赛 · 拍摄清单

> ⚠️ 逐字稿是举例，让她看语感方向。用自己的话说，不一定非得背稿。
> 🎯 这条视频目的：展示李总的公益身份+公信力。让人知道"这个做家政的，在给退役军人当评委"。

> 📸 拍摄人：全程跟拍，不摆拍。

## 一、活动前：到场 + 准备（约15秒素材）

### 拍摄清单
- [ ] 到活动现场门口，拍一个全景（能看到"退役军人才艺大赛"横幅或背景板）
- [ ] 李总走进活动现场，拍背影或侧面（不要让她看镜头，自然走）
- [ ] 评委席桌上的名牌——"李秀玲"三个字，特写

### 注意事项
🔴 不要让她对着镜头说"我今天来参加XX活动"——太像汇报
🟡 画面自己会说话。横幅→背影→名牌，三个镜头够了


## 二、口播1：为什么我在这（约30秒）

> 📍 找个相对安静的角落。活动开始前或间隙。固定手机或让助理手持，看镜头。

### 骨架提示
```
今天在这 → 退役军人才艺大赛 → 我是评委
→ 为什么请我当评委？（因为一直在帮退役军人）
→ 一句话收：做家政和做公益，是一件事
```

### 逐字稿举例
今天在普兰店，退役军人才艺大赛。

我是评委。

往后，很多人会问我，你做家政的，怎么跑来给退役军人当评委了？

实际上，这些年我一直在做一件事——
就是帮退役军人。
我是莲城之光的理事长，就是专门做这个的。

我做家政，往后做公益，对我来说是一件事。
都是用双手创造价值，用服务温暖人心。


### → 注意事项
🔴 "往后"是她的口头语——保留
🟡 "做家政和做公益是一件事"——这句话要说得轻，不是喊口号。像在跟朋友解释
🟢 说完不用等，直接切画面进入下一个环节


## 三、活动中：评委现场（约30-40秒素材）

### 拍摄清单
- [ ] 选手上台表演的镜头（唱歌/乐器/书法都可以，拍2-3个不同类型的）
- [ ] 李总在评委席认真看表演、写评分表——拍侧面或斜后方，不要打扰她
- [ ] 选手领奖的画面（如果有颁奖环节）
- [ ] 🎤 现场声——选手表演的声音、掌声。全程开着收现场声

### 注意事项
🔴 不要让她对着镜头点评选手——太像领导发言
🟡 画面+现场声就够了。让观众"在场"
🟢 如果有选手表演得特别好的瞬间，多拍几秒——那是情绪的峰值


## 四、口播2：我看到的东西（约25秒）

> 📍 活动中段或结束后，找个安静角落。对镜头，像在跟朋友分享感受。

### 骨架提示
```
今天看到什么（一个具体画面）→ 这些人是谁（退役军人）
→ 他们站上舞台不容易 → 这就是我做这件事的意义
```

### 开放式问题引导
1. 你今天在台下看到哪一个选手，让你心里动了一下？具体一点——他表演了什么？你当时什么感觉？
2. 退役军人这个群体，跟你平时帮助的人有什么不一样？他们最打动你的地方是什么？
3. "传承红色基因，彰显军人本色"——这是你原话。用你自己的方式说出来，不要念稿的语感。

### 逐字稿举例（参考语感）
刚才坐在台下，看他们一个一个上台。

有唱歌的，有写书法的，有跳舞的。

其实这些人，以前在部队里，可能是班长、是指导员、是立过功的人。
今天站在这个舞台上，他们就是一个普普通通的老兵。
但是一站上去，那个精气神，还是不一样。

我认为，今天的比赛没有输赢高低。
每一位站上舞台的退役军人，都是最耀眼的光。


### → 注意事项
🔴 一定要有一个具体画面——不要"很多选手都很棒"。说"有一个唱XX的""有一个写书法的"
🟡 用她的语气——娓娓道来，不赶
🟢 "我认为"——她的口头语，保留


## 五、收尾口播（约15秒）

### 骨架提示
```
我会继续做这件事 → 也希望更多人加入 → 为这群最可爱的人撑起一片天
```

### 逐字稿举例
未来，我也会带着莲城之光，往后一冉家政的初心，
继续为退役军人服务。

也希望能有更多人加入我们，

### → 注意事项
🔴 不说"欢迎大家来找我做家政"——这条不是打广告
🟡 收在公益上。公信力本身就是最好的广告
🟢 说完停1秒再关。让结尾沉下来
