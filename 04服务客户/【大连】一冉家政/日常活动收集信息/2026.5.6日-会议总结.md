# 2026.5.6日-一冉集团会议总结

[[2026.5.6日-会议记录]]
> 原始记录长度：4250行语音转文字
> 会议主题：家政社区项目启动 + 月度30万目标拆解

---

## 一、核心决策

**自己做，不先帮代理商。**

毛总和杨总（代理商）已启动社区运营，但冉总决定一冉自己先做5个社区，跑通样板。理由：代理商会中途停、没有自驱力、帮他们改是反推。"求人不如求己，自己做硬了，代理商自己过来学。"

**关键句：**
> "我们能不能把这个事做实？别人做毛总中间可能停，做杨总中间可能停，只有我们自己才能完成。"

---

## 二、目标与拆解

| 指标 | 数值 |
|------|------|
| 月度产值目标 | 30万 |
| 社区数量 | 5个（大连湾街道） |
| 主推社区 | 华润大连湾（房价14000，社区较大） |
| 备选社区 | 福佳新城等 |
| 99元服务订单 | 3000单 |
| 1980元合伙人 | 15个 |
| 日均订单 | 61单（按10人团队，30天） |

**打法：**
- 楼长推单（每楼长推10单）
- 电梯广告（亚克力牌锁定单元楼）
- 地推进场 + 公益宣传 + 电视台采访
- 先进订单，再招合伙人（用订单数据说服合伙人交1980）

## 三、人事与责任

| 角色 | 人员 | 职责 |
|------|------|------|
| 项目主负责人 | 岳春 | 社区项目总控、目标拆解、团队驱动 |
| 辅助 | 传新 | 全流程懂，擅长和楼长打交道 |
| 订单执行 | 郭凡新、刘继坤 | 各自认领300单 |
| 探店线 | 刘吉坤等 | 200家店探店延后，优先保社区 |

**冉总对岳春的推动（会议核心张力）：**
- 岳春对目标没概念、状态退缩
- 冉总反复逼："你是狼性的，不能退"
- "如果这事完成不了，我做老大的心里有数能兜底"
- "你在我们面前帮别人设计侃侃而谈，到自己身上不行——干不了活都是虚的"

---

## 四、探店线的取舍

200家店探店刚有热度，但决定**这个月集中做社区**。逻辑：
- 社区做好后，可以长期跑（一年甚至三年不用再做社区）
- 探店不差这一个月
- "一个月干一件事，做好做落地"

---

## 五、会议情绪曲线

```
战略争论（帮代理商vs自己做）
→ 定方向（自己做5家）
→ 选社区（大连湾哪几个小区）
→ 拆目标（30万→3000单→15合伙人→61单/天）
→ 压责任（岳春退缩→冉总逼→冉总兜底→岳春"空了"）
→ 收尾定调（用实力说话，不是虚晃一枪）
```

## 六、潜在素材点

1. **冉总的管理风格**：直接、逼人、兜底，"你是狼性的你就得上"
2. **"求人不如求己"**：不把命运交到代理商手里
3. **目标拆解实况**：30万怎么拆成一单99元
4. **选社区的判断**：房价→消费力→面多少钱一碗
5. **团队情绪管理**：有人空了，怎么填回来
