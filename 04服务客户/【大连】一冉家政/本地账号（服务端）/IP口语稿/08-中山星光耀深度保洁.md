# 中山星光耀 · 100平深度保洁

中山星光耀广场。
100平，深度保洁。

（抹一把灶台，伸到镜头前）
你看这油——
老厚了。
能写字儿。

客户放话了。
先试一块儿给我看。
过关了，
后面好几套房子等着你。

没过关？
那我今天就白来了。

（停）

这房子吧，
远看还行。

近看——
死角全是灰。
厨房油污都包浆了。
窗槽缝里全是黑泥。

（停）

这种活怎么干？
表面擦一遍？
没用。

我们一冉的做法是——
柜门打开，
手伸进去，
摸最底层那块板。

这个地方最容易落灰。
也是客户最容易漏检查的地方。

清干净。

（停）

你怎么知道真干净了？
白手套。

（演示：白手套伸进死角，慢慢划过去）

你看——
划过去，
手套是白的。

（停）

在干活，
不看表面光不光滑。
看手摸得到的地方。
看你看不到的地方。

（停）

这就是一冉的标准。
不是嘴上说的。
是手套摸出来的。

（停）

今天这单，
先试一块儿。

过了，
后面还有活儿。

没过？
那不可能。
