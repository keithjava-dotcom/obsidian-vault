## 🎬 柯老师导戏卡

```
【给谁看】大连本地的市场、商超、门店经营者，后勤负责人——手里有场地要开荒、或者有长期保洁需求的人；也想看"家政公司到底怎么挑活"的人。

【处境】场地要开荒，找的队伍要么报价乱来，要么活干得糙。他怕的不是活小，是后面长期的活找不到靠谱人。他想找一个"第一天就让人放心"的团队。

【为什么今天说】东港蔬菜农贸市场，1800平开荒，2块钱一平——活小、价低，但后头挂着长期的日常保洁。这种"小活背后有大活"的事，最能讲明白一冉的接单逻辑。

【姿态】不是汇报，是有人问你"2块钱一平的活你们也接？"你端着碗回一句："接啊，为啥不接。"然后把为什么讲清楚。像聊天，不像宣讲。

【第一口气】"东港蔬菜农贸市场，1800平，开荒保洁。2块钱一平。"——数字先砸，再用"有人说"把质疑摆出来，接住它。

【必讲点】1. 活本身轻：地面一层浮尘、入口大玻璃，6个人1天能完 2. 为啥接：市场开业后天天要保洁，后头挂着一年的活 3. 标准不降：地面无浮灰无杂物、玻璃透亮 4. 敲门砖逻辑：开荒这一单干利索了，长期的活人家才放心交给你

【不能讲成】❌ 说"这单不赚钱/白干"（2元/㎡对基础开荒是正常价，素材没说亏）❌ 说"已经拿下长期合同"（还在洽谈，素材明写"待开荒交付后跟进深度洽谈"）❌ 把菜市场讲成脏乱差（素材：工况简单，无重油污）❌ 贬低同行 ✅ 讲"为啥接小活"的判断力

【画面】市场空场拍：大面积地面、入口大玻璃。地面浮尘、玻璃反光都是现成的画面。说到"敲门砖"，可以指指脚下的地。
```

## 🧭 结构走线

```
【2块钱一平 · 0-8秒】
注：数字先砸。1800平+2块一平，反差感自己会说话。第二句"有人说"把观众心里的质疑替他说出来。

例："东港蔬菜农贸市场，1800平，开荒保洁。2块钱一平。有人说，这个价，你们也接？"

【接。为啥不接 · 8-18秒】
注：接住质疑，再讲活本身——轻、快、不复杂。地面浮尘、大玻璃、6人1天，三句讲完，证明不是逞能接的。

例："接。为啥不接？地面一层浮尘，扫干净、拖干净。入口的大玻璃，擦到透亮。6个人，一天，干完。"

【图的是后面的活 · 18-30秒】
注：转折点。话锋一转："但你不是记着——"把视线从这一单拉到后面的一年。讲"信任"，不讲"钱"，这是刘总的格局。

例："但你记着，我们接的不是这一天的活。菜市场，开业以后天天都要保洁。后头挂着的，是长期的活。我们图的是往后一年、两年的信任。"

【标准不能降 · 30-42秒】
注：活轻但标准不降——这是这条的灵魂。浮灰、杂物、水痕，都是看得见摸得着的标准。最后一句"第一天就糊弄，后面谁敢再找你"是刘总敢说的狠话。

例："这种活，看着简单，标准不能降。地面拖完，不能有浮灰，不能有杂物。玻璃擦完，不能有水痕。1800平的场子交给你，第一天就糊弄，后面谁敢再找你？"

【敲门砖 · 42-52秒】
注：点题。"开荒，就是敲门砖"——把这一单的意义说透。素材小结的原话逻辑：用高效交付建立专业印象，为长期合作打信任基础。

例："开荒，就是敲门砖。这一单干利索了，长期的活，人家才放心交给你。"

【一冉家政，靠谱 · 52-60秒】
注：落点。接在"放心交给你"后面，顺理成章，不是叫卖。

例："一冉家政，大连本地的，靠谱。"
```

## ⚠️ 注意事项

- **时态铁律：这单还没进场**（场地租赁未落定，素材明写）。口播只能讲"为啥接"和"标准不能降"，一个字都不能讲"我们干完了"
- **数字保真**：1800平、2元/㎡、6人1天。3500元/月是"匹配预算"不是合同，口播里不提具体月钱，讲"长期的活"就行
- **别说"这单不赚钱"**：素材写工况简单、难度低，2元/㎡是基础开荒的正常价——这条讲的是"挑活的眼光"，不是"亏本接单"
- **别说"已经拿下长期单"**：还在洽谈阶段，讲"图的是后面的机会"
- **"有人说"是引子不是树靶子**：就是朋友间打趣，别把"有人"讲成同行冤家
- **用"我们"不用"我"**：一冉是团队活
- **结尾不加"欢迎咨询/私信"**：停在"一冉家政，大连本地的，靠谱"
