# 红星海郡墅 · 140㎡样板开荒 · 讲戏卡 + 口播文案示例

---

## 🎬 柯老师导戏卡

### 这条是讲给谁看的

大连本地准备装修/开荒的业主——尤其是改善型住房、二手房翻新的人群。红星海片区的高端业主。

### 他现在卡在什么处境里

刚拿到一套二手房，翻新完发现：柜体是旧的，黄垢沉淀了好几年；装修残留的胶迹到处都是。想请人开荒，又怕保洁糊弄——"反正你看不出来"。

### 你为什么今天非说这件事

这套房140㎡，报价5500，配了10个人进场。为什么？因为这是红星海的样板工程——不是赚这一单的钱，是让这一片的人看见：一冉的开荒，是可以当样板看的。

### 你不是在上课，而是在

**立标杆** —— 讲这一单怎么抠细节，就是告诉所有业主：你的家值得被这样对待。

### 第一口气

"红星海这一户，140平，我配了10个人。有人问我，是不是报价高、人凑数？不是——这一户，我是按样板标准来做的。"

### 必须讲清的 3-5 个点

1. **这房什么情况**：二手房半翻新，140㎡，地板换了，柜体全保留——柜体表面沉积多年黄垢、装修残留胶迹，比新房开荒难得多
2. **为什么配10个人**：不是人海战术，是留足打磨细节的时间——棚顶除尘、玻璃精细擦拭、瓷砖缝隙、理石去渍、除胶除垢，所有可见面不留死角
3. **专项活**：业主把全屋灯罩拆下来，我们深度清洗；1张床垫深度清洗；蒸箱、烤箱各1台
4. **老柜体怎么处理**：除垢要把控药剂力度、保护原有漆面——这是老柜子跟新柜子最大的区别
5. **落点**：这一户交付够硬，就是红星海片区的活广告。口碑不是喊出来的，是一户一户做出来的

### 不能讲成

❌ "我们很专业"的空喊 / 把5500当卖点炫耀 / 贬低别的保洁 / "快来下单"

✅ 就是认真做了一户难做的房，告诉你为什么这么配人、这么抠细节。底气是交付效果，不是报价单。

### 拍的时候先想象的画面

在红星海这套房里拍——最好有柜体除垢前后的对比画面，或者工人蹲在地上抠瓷砖缝隙的特写。"10个人干140平"的画面感，比说十遍"精细"都强。

## 🧭 结构走线

```
【开头 · 0-8秒】反常识钩子
"红星海这一户，140平，我配了10个人。
有人问我：是不是报价高、人凑数？
不是。这一户，我是按样板标准来做的。"
→ 用"140平/10个人"的反差立钩子，先接住质疑

【中段一 · 8-22秒】这房难在哪
"二手房半翻新，地板换了，柜体全保留。
柜体表面沉积了好几年的黄垢，
装修残留的胶迹，到处都是。
比新房开荒，难的不是一点半点。"
→ 用"黄垢""胶迹"让观众看见难度，不抽象

【中段二 · 22-40秒】10个人怎么用
"我为什么配10个人？
不是人海战术，是留足打磨细节的时间。
棚顶除尘、全房玻璃精细擦拭、瓷砖缝隙深度清理、
卫生间厨房理石去渍提亮、全屋除胶除垢——
所有可见面，不留死角。
业主把全屋灯罩拆下来，我们深度清洗；
一张床垫，深度清洗；蒸箱、烤箱，各一台，深度清洗。"
→ 列举要快但清晰，让人感觉到"活是真的多"

【中段三 · 40-52秒】老柜体的讲究
"最费心思的，是老柜体。
除垢要把控药剂的力度，保护原有漆面——
老柜子跟新柜子不一样，劲儿大了就伤漆。
这是要手上有分寸的活。"
→ 这一段的"分寸"是全片专业感的最高点

【收尾 · 52-65秒】落点
"这一户，我按样板标准做。
5500的报价，不是为这一单赚多少钱，
是让红星海这一片的人看见——
一冉的开荒，是可以当样板看的。
口碑不是喊出来的，是一户一户做出来的。"
→ 四字收尾："一户一户做出来的"
```

## 📷 拍摄提示

1. **场景**：红星海这套房内——最好有柜体除垢前后的对比
2. **状态**：讲"老柜体"那段时最认真——那是全片专业感的最高点
3. **节奏**：列举专项活时节奏快一点，让人感觉活多；讲老柜体时慢下来，像在说手艺
4. **B-ROLL 建议**：
   - 柜体除垢前后对比特写（最强证据）
   - 工人蹲着抠瓷砖缝隙
   - 灯罩深度清洗、床垫清洗、蒸箱烤箱清洗的画面
   - 10个人同时在屋里干活的场面 → "配10个人"不是空话

---

## ⚠️ 注意事项

- **"报价5500"别藏着**：这是钩子，大方说。但说的时候是"我为什么值这个价"，不是"我多贵"
- **别把业主描述成矫情**：素材里写了"业主不是矫情客户"——这是业主的优点，不是吐槽点，别讲
- **"样板"是核心词**：全片所有细节都往"样板"上收
- **结尾别加"关注我们"**：四字收尾"一户一户做出来的"就停

## 📝 口播文案示例

> ⚠️ 这是示例，不是逐字稿。冉总理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

---

红星海这一户，140平，我配了10个人。

有人问我：是不是报价高、人凑数？

不是。这一户，我是按样板标准来做的。

二手房半翻新，地板换了，柜体全保留。柜体表面沉积了好几年的黄垢，装修残留的胶迹，到处都是。比新房开荒，难的不是一点半点。

我为什么配10个人？不是人海战术，是留足打磨细节的时间。

棚顶除尘、全房玻璃精细擦拭、瓷砖缝隙深度清理、卫生间厨房理石去渍提亮、全屋除胶除垢——所有可见面，不留死角。

业主把全屋灯罩拆下来，我们深度清洗。一张床垫，深度清洗。蒸箱、烤箱，各一台，深度清洗。

最费心思的，是老柜体。除垢要把控药剂的力度，保护原有漆面——老柜子跟新柜子不一样，劲儿大了就伤漆。这是要手上有分寸的活。

这一户，我按样板标准做。5500的报价，不是为这一单赚多少钱，是让红星海这一片的人看见——一冉的开荒，是可以当样板看的。

口碑不是喊出来的，是一户一户做出来的。
