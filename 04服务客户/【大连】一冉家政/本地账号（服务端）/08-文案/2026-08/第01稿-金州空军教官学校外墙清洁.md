# 外墙清洁 · 金州空军教官学校 · 讲戏卡 + 口播文案示例

---

## 🎬 柯老师导戏卡

> 写给出镜人刘基坤。
> 先进入情境，再开口。
> 不是策略报告，是导演给演员讲戏。

### 这条是讲给谁看的

大连本地有外墙保洁需求的单位——学校、办公楼、物业、园区。以及所有看过"高空蜘蛛人"画面的人。

### 他现在卡在什么处境里

楼面脏了好几年，不是不想洗，是怕——怕高空作业出事、怕游击队糊弄、怕洗了跟没洗一样。

### 你为什么今天非说这件事

今天刚在金州空军教官学校干完一栋两层外墙。灰厚得发绿、粘得冲水都带不下来——这种活最能展示"工序"和"安全"两条线。你把这些摊开讲，就是告诉所有人：一冉干高空，是有死规矩的。

### 你不是在上课，而是在

**现场复盘** —— 刚收工，人还站在楼下，抬头看洗透的墙面，边看边说。不是宣讲，是"干完活的那口气"。

### 第一口气

"金州空军教官学校，一栋两层楼的外墙，我们刚干完。"

### 必须讲清的 3-5 个点

1. **这楼脏到什么程度**：两层楼，常年没专业清洁，厚灰+发绿尘垢，粘得牢，普通冲水洗不下来
2. **工序死规矩**：涂水器+刮板先刮透厚垢 → 清水全面喷淋冲净润透 → 一冉专业药剂渗透分解 → 人工逐面精细化，边角缝隙不留死角
3. **安全线**：大太阳晒着，曲臂车全程防护，护栏内绑安全绳，登高规范半点不马虎
4. **落点**：越是这种一眼看全的外墙活，越不能偷工减料。工序走全了、安全盯紧了，才对得起客户的信任

### 不能讲成

❌ 广告词 / "我们多专业"的空喊 / 吓唬人（"高空很危险"） / 价格推销

✅ 就是今天干了一栋特别脏的楼，干完心里踏实。工序和安全是用行动讲的，不是用嘴讲的。

### 拍的时候先想象的画面

人在楼下或楼顶平台，背后是刚洗完的墙面（对比感最强）。如果能在曲臂车旁边拍更真实。天气好，阳光打在墙面上，"洗透亮"是看得见的。

## 🧭 结构走线

```
【开头 · 0-8秒】直接上活
"金州空军教官学校，一栋两层楼的外墙，我们刚干完。"
→ 直接给结论，人站着说，不铺垫

【中段一 · 8-25秒】这楼脏到什么程度
"这楼在金州空军教官学校院里，两层。
外墙常年没做专业清洁，积了厚厚一层灰，
还附着一层发绿的尘垢，粘得特别牢——
普通冲水洗，根本带不下来。"
→ 用"发绿""粘得牢"让观众看见脏，不是听你说脏

【中段二 · 25-45秒】工序死规矩
"进场前我就跟两个师傅交代：
外墙清洁的死规矩，半分不能松。
头一遍，涂水器配刮板，把墙面浮灰、表层污渍整体刮透；
刮完第二遍，清水全面喷淋，冲净浮渣、把墙体润透；
接着打上一冉的专业清洁药剂，等它渗透分解；
最后人工逐面精细化走一遍，边角缝隙全部处理到位。
省一步，都不行。"
→ 四步工序像口诀，节奏要稳，一步一顿

【中段三 · 45-58秒】安全线
"大太阳晒得人发懵，高空的安全弦也得一直绷着。
曲臂车全程防护，护栏内也得绑好安全绳，
登高规范，半点都不马虎。"
→ 安全不是口号，是动作——说的时候可以指一下绳子/护栏

【收尾 · 58-70秒】落点
"干家政这么久，越是这种一眼看全的外墙活，越不能偷工减料。
工序走全了，安全盯紧了，墙面洗得透亮干净，
才对得起客户这份信任。
下午六点收工，活儿干完，心里是稳的。"
→ 不煽情，四字收尾："心里是稳的"
```

## 📷 拍摄提示

1. **场景**：外墙现场——刚洗完的墙面做背景，有对比才有说服力
2. **状态**：刚收工的状态，有点累但踏实。不是打鸡血
3. **节奏**：讲工序时一步一顿，让四步口诀有节奏感；讲安全时语速放慢一点，认真
4. **B-ROLL 建议**：
   - 洗之前墙面特写（发绿尘垢）→ 洗之后墙面特写（透亮）——最强对比
   - 涂水器刮板的动作特写
   - 曲臂车升降、安全绳系扣特写 → "安全是动作"的证据
   - 工人逐面精细化擦边角缝隙

---

## ⚠️ 注意事项

- **别让工序变成清单**：四步口诀要说得像师傅带徒弟交代活，不是念SOP
- **"死规矩"三个字是钩子**：开场"死规矩半分不能松"就要立住——观众想听规矩到底是什么
- **安全线别讲成害怕**：是"盯紧"不是"怕"，是专业的从容
- **结尾别加"关注我们"**：四字收尾"心里是稳的"就停

## 📝 口播文案示例

> ⚠️ 这是示例稿，不是逐字稿。刘基坤理解了上面讲戏卡之后，用自己的嘴巴说出来，不用照着念。现场有感觉的地方可以自由发挥，只要方向不跑偏就行。

---

金州空军教官学校，一栋两层楼的外墙，我们刚干完。

这楼外墙好几年没专业清洁了，积了厚厚一层灰，还有一层发绿的尘垢，粘得特别牢。普通冲水，根本带不下来。

干这种活，工序一道都不能省。

头一遍，涂水器配刮板，把浮灰厚垢整体刮透。第二遍，清水全面喷淋，冲净浮渣、把墙体润透。然后打上一冉的专业清洁药剂，等它渗透分解。最后人工逐面精细化走一遍，边角缝隙全部处理到位。

省一道，后面就返工。

高空作业，安全弦也不能松。曲臂车全程防护，护栏内绑好安全绳，登高规范半点不马虎。大太阳晒着，人发懵，绳子不能松。

干家政这些年，越是这种一眼看全的外墙活，越不能偷工减料。工序走全了、安全盯紧了，墙面洗得透亮，才对得起客户的信任。

单位楼面脏了好几年、一直没洗的，可以找我们。

一冉家政，大连本地的，靠谱。
