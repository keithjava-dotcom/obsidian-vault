# 金地中央公园 · 270套开荒 · 讲戏卡 + 口播文案示例

---

## 🎬 柯老师导戏卡

### 这条是讲给谁看的

大连本地做实体的老板——装修、建材、房产中介、物业、工厂——还在线下蹲点等客户，觉得"线上那玩意儿跟我没关系"的人。

### 他现在卡在什么处境里

每天坐在店里等客户上门，或者靠请客喝酒拉关系拿单子。累，还不稳定。知道线上有用，但觉得自己"不是那块料"，或者觉得"拍视频丢人"。

### 你为什么今天非说这件事

刚签了金地中央公园270套开荒。这单不是靠喝酒喝出来的，是客户刷到你的短视频，自己找过来的。
实话不用包装——把签约过程从头到尾讲一遍，就是最好的证明。

### 你不是在上课，而是在

**复盘** —— 像一个干了件漂亮事、压不住想跟人说道说道的状态。
不是"我教你做生意"，是"我跟你说个真事儿，你听听看"。

### 第一口气

"金地中央公园的保洁大部队前脚刚撤场，我连口水都没顾上喝，后脚就跑去签了下一个合同。"

直接进场景。人在干活、在跑、在签单。不铺垫。

### 必须讲清的 3-5 个点

1. **活有多大**：270套旧房改造开荒，不是两三户的小活儿
2. **怎么来的**：没请一顿饭没喝一口酒，客户刷短视频自己找来的——这才是刺点
3. **客户怕什么、你怎么破的**：甲方最怕草台班子。你没跟他扯资质案例，直接带他看交付调度系统、自研药剂库、特种设备——"我进场的是一整套标准化特种部队"
4. **落点到提醒**：都2026年了，实体生意再不上线，路只会越走越窄。你在线下拼破头求的那点人脉，线上可能就是一条视频的事儿
5. **收尾不是展望，是承诺**：10天后，270套全部交付，白手套验收，拿结果说话

### 不能讲成

❌ 销售话术 / 招商广告 / "快来跟我学" / 炫耀 / 说教

✅ 就是刚签完一个大单，压不住兴奋想跟人分享。底气是自己干出来的，不是喊出来的。

### 拍的时候先想象的画面

最好就在金地中央公园项目现场拍——后面有工人在干活，有设备在运转，"进场了"不是一句话，是画面。
如果现场拍不了，就在你办公室或者车里——刚签完合同回来，身上还带着那股劲。

## 🧭 结构走线

```
【开头 · 0-12秒】行动锚点直接进
"金地中央公园的保洁大部队前脚刚撤场，
我连口水都没顾上喝，后脚就跑去签了下一个合同。"
→ 不打招呼不自我介绍，直接拉着人进场景

【中段一 · 12-25秒】规模 + 张力
"270多套旧房改造的开荒保洁，不是两三户的小活儿。
放以前，你要想拿下这种单子——
陪多少笑脸？喝多少顿大酒？求多少层关系？
但我告诉你们，这单，我没请一顿饭、没喝一口酒。"
→ 先立规模，再拉对比，把"以前怎么干"和"这次怎么来的"摆在一起

【中段二 · 25-45秒】签约故事
"客户就是刷到我的短视频，大老远跑来公司考察。
这种大工程甲方最怕什么？草台班子。
他盯着我：270套，工期10天，你能吞得下吗？
我没扯资质案例，直接带他看——
交付调度系统、自研药剂库、高空深度的特种设备。
我说，在一冉这儿，不是去劳务市场给你抓50个大姐对付。
我进场的是整套标准化特种部队。
客户看完，当场拍板签字。"
→ 故事节奏不能赶，每个细节都是证据

【中段三 · 45-60秒】落点到提醒
"我今天拿刚签的合同跟你们聊这个，
不是显摆王一冉多牛。
是想给还在干实体、天天坐店里愁客户的老板提个醒：
都2026年了，实体生意再不碰线上，路只会越走越窄。
你线下拼破头求的那点人脉，
在线上，可能就是一条视频的事儿。"
→ 口气从兴奋转诚恳，不是居高临下，是真想拉一把

【收尾 · 60-75秒】承诺
"今天7月15号，大部队已经进场打样了。
10天之后，270套全部交付。
白手套验收，拿结果说话。"
→ 不放慢不煽情，"拿结果说话"四个字落稳
```

## 📷 拍摄提示

1. **场景**：优先在金地中央公园项目现场——后面有真工人在干活，有真设备在转。"进场了"不是一句话，是画面。备选：办公室/车里，刚签完合同的状态
2. **状态**：刚干完一件事，有点兴奋但收着。不是打鸡血，是"我跟你说个事儿"那种自然的分享欲
3. **节奏**：开头和中段偏快，讲签约故事那段自然放缓——因为你在回忆当时的对话。收尾"拿结果说话"慢下来，看着镜头，点一下头
4. **B-ROLL 建议**（口播拍完后另补，剪辑时插进去）：
   - 项目现场全景/工人干活的画面 → 对应"大部队进场"
   - 调度系统屏幕/药剂库/特种设备 → 对应"带他看"那段
   - 合同签字特写（打码客户信息） → 对应"当场拍板"
   - 你在现场跟工人交代细节 → 证明你人在一线

---

## ⚠️ 注意事项

- **别演播客**：不是坐下来给大家上课。是你刚干了件高兴事，压不住想说
- **别加形容词**：270套、10天、没喝酒、当场拍板——数字和动作本身就有力量，不需要"太震撼了""超级大单"
- **别踩同行**：那句"草台班子"是甲方说的，不是你评价别人的。保持大气——你讲的是自己怎么干，不是别人怎么不行
- **别赶签约那段**：整个故事最精彩的就是你跟客户的对话，节奏放慢，让人能看见那个场景
- **"拿结果说话"别躲**：这是整个视频的落点。说的时候看镜头，停半秒，不用说"谢谢"不用加尾句

## 📝 口播文案示例

> ⚠️ 这是示例，不是逐字稿。冉总理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

---

金地中央公园的保洁大部队前脚刚撤场，我连口水都没顾上喝，后脚就跑去签了下一个合同。

270多套旧房改造的开荒保洁。
不是两三户的小活儿。

放以前，干过工程、搞过装修的人都知道——你要想拿下270套的开荒单子，得陪多少笑脸？
喝多少顿大酒？
求多少层关系？

这单，我没请一顿饭。
没喝一口酒。

客户就是刷到我的短视频，大老远跑到公司来考察。

这种大工程，甲方最怕什么？
最怕你是个草台班子。
他盯着我问：270套，工期满打满算给我10天，你能搞定吗？

我没跟他扯虚的。
直接带他看——
总部的交付调度系统，自研药剂库，高空深度的特种设备。

我说：在一冉这儿，不是去劳务市场临时给你抓50个大姐对付。
我进场的，是一整套标准化的服务老师。

客户看完，二话没说，当场拍板签字。

我今天拿刚签的合同跟你们聊这个，不是为了显摆。
是想给还在干实体、天天坐店里愁客户的老板们提个醒——

都2026年了，实体生意再不碰线上，路只会越走越窄。
你在线下拼破头求的那点人脉，在线上，可能就是一条视频的事儿。

今天7月15号，大部队已经进场打样板间了。

10天之后，270套房子全部交付。
咱们白手套验收，拿结果说话。
