# 十万平厂房开荒 · 讲戏卡 + 口播文案示例

---

## 🎬 柯老师导戏卡

> 写给出镜人刘基坤。
> 先进入情境，再开口。
> 不是策略报告，是导演给演员讲戏。

### 这条是讲给谁看的

大连本地企业后勤、行政主管、物业经理、工厂负责人——手里有大型清洁需求，但找不到靠谱团队的人。

### 他现在卡在什么处境里

大型清洁项目要找人干——问了几个家政公司都说接不了，或者接了但现场管不住，最后拖工期、质量差、出了事没人兜。
每次外包都提心吊胆。
他在找的，不是最低价，是"这事交给你，我省心"。

### 你为什么今天非说这件事

刚接了十万平厂房开荒，这是硬通货。
不说"一冉很强"，说"你看这个活我们怎么干的"。
让人看完觉得：这家有章法，不是吹牛的，我的活可以交给他们。

### 你不是在上课，而是在

**复盘** —— 跟同行或潜在客户，把这个项目从头到尾怎么管的，摊开来聊一遍。

像一起吃个饭，别人问起最近在忙啥，你说"接了个大活，十万平厂房开荒"，然后聊下去。

### 第一口气

"金州十三里，十万零八百平厂房开荒。两天半工期，凌晨5点必须交活。"

不铺垫，不解释背景。数字自己会说话。让懂行的人第一秒就知道：这不是小打小闹。

### 必须讲清的 3-5 个点

1. **活有多大**：十万零八百平，两天半，7月1号凌晨5点交——这三个数字砸出去，立住了
2. **难点在哪**：现场金属建材堆满，不能挪，干活得绕着走；350人同时在场上，没章法肯定乱
3. **怎么管的**：分区包干责任到人（谁的片区谁负责），错峰轮班人歇活不歇（两班倒不含糊）。巡检和班前交底可以一句话带过
4. **为什么能管住**：不是吹牛，是一单一单攒出来的——从几十平到十万平，每一单都在攒经验
5. **落地收束**：同行接不住的大活，一冉能接住。给行业打个样。有大型清洁需求，找一冉

### 不能讲成

❌ 老师上课 / 工作汇报 / 招商PPT / 参数播报 / 企业文化宣传稿

✅ 就是你跟人吃饭聊天复盘，"我们最近接了个大活，十万平厂房开荒，我跟你说这活怎么干的"

### 拍的时候先想象的画面

站在厂房中间，你人显得小，空间显得大——才有"十万平"的感觉。
后面能看到乱堆着的金属建材、远处在干活的工人——现场感就是最好的证据。
你不是在演，你就是这个项目的人。

## 🧭 结构走线

```
【开头 · 0-10秒】数字砸脸
三个数字直接砸，不铺垫：
"十万零八百平。两天半。凌晨5点交活。"
→ 让懂行的人第一秒就知道分量

【过渡 · 10-15秒】个人成长线（轻触即走）
"搁前几年，我连现场都看不明白。现在？心里越来越有底。"
→ 一句话带出进步感，不展开，不煽情

【中段一 · 15-25秒】难点展示
"金属建材堆满，不能挪，干活全程绕着走。
350个人，一百多号人同时在场上——你没章法，肯定乱套。"
→ 把难处摊开，让观众感受到"这活不好干"

【中段二 · 25-40秒】管理方法（挑两招展开）
"分区包干，谁的片区谁负责，出问题直接对到人。"
"错峰轮班，人歇活不歇。两班倒，饭轮流吃，不浪费一分钟。"
"巡检盯现场，班前交底，当天活当天完。"
→ 分区包干和错峰轮班展开说，巡检和交底一句带过
→ 每招说完自己停半拍，像真在跟你解释怎么管

【收尾 · 40-55秒】底气 + 格局
"从几十平到十万平，一冉是一单一单攒出来的。"
"同行要么接不到这种大活，要么接下来管不住，最后赔钱砸招牌。"
"一冉能接住，靠的是实战经验。"
"给行业打个样——家政公司，也能接大单、管大活。"
→ "给行业打个样"放慢，抬头，这是一口气的落点

【转化 · 最后5秒】
"家里或者单位，有大型清洁需求？
一冉家政，大连本地的，靠谱。"
→ 不是叫卖，是给信息。看镜头，点头，完
```

## 📷 拍摄提示

1. **场景**：站在厂房中间或门口，你人小空间大——"十万平"的气势才能出来。场地越没收拾越好，后面的杂物就是最好的证据
2. **走位**：开头站定 → "金属建材"那里走到障碍物旁边指着说 → 收尾人往前走（厂房往后拉，镜头跟） → 转化站定看镜头
3. **收音**：厂房大回音重，离近收。后期配音也行，现场如果机器噪音大别硬录
4. **B-ROLL 建议**（拍完口播后另拍，剪辑时插进去）：
   - 无人机从高空俯拍整个厂房全景 → 展示"十万平"的视觉冲击
   - 地面堆着的金属建材堆、设备 → 展示"障碍物绕开作业"的真实感
   - 工人分区在干活的中景 → 展示"分区包干"不是吹的
   - 你在现场跟工人说话、看进度 → 展示你在现场

---

## ⚠️ 注意事项

- **别演**：不是新闻联播，不是汇报PPT。就是跟人吃饭聊天复盘，"我跟你说这活我们这么干的"
- **别憋**：数字和事实本来够硬，不用加"太震撼了""超级难"这种词。说实话就够了
- **别删**："给行业打个样"别说小了，你觉得大，在同行眼里它就是标杆
- **别赶**：每甩一个信息点，自己停半拍让人消化。一口气念完=全没记住
- **别端**：你心里有底气，但嘴上别端着。厉害的人不用装厉害

## 📝 口播文案示例

> ⚠️ 这是示例稿，不是逐字稿。刘基坤理解了上面讲戏卡之后，用自己的嘴巴说出来，不用照着念。现场有感觉的地方可以自由发挥，只要方向不跑偏就行。

---

金州十三里，十万零八百平。

我们刚接了个开荒的活。

两天半工期，7月1号凌晨5点，必须交活。

甲方就一句话：活干到位、干漂亮就行。

没有条条框框的验收标准，但你得自己心里有数。

搁前几年我碰上这种单子，说实话，连现场我都看不明白。
十万平的厂房站在中间，东南西北都分不清，人往哪摆、先干哪块、从哪下手，脑子是空的。
现在不一样了。
从几十平到几百平，几百平到几千平，几千平到十万平——一单一单跟过来的。
量完现场尺，图纸一铺，人员怎么分、节奏怎么卡，心里清清楚楚。

这个场子有一点特别棘手。
甲方是做汽车电池的，场地上堆满了金属建材物料。
不能挪。
你干活得全程绕着它走——带着障碍物抢进度。

350个人，每天一百多号人同时在场上。
你想啊，一百多号人散在十万平的场子里，没章法的后果就是：这块干重了、那块没人管、衔接断档、人站着等活。
乱一次，工期就悬了。

我们四招管住。

第一招，分区包干，责任到人。
谁负责哪一片区，清清楚楚。出了问题直接对到人，不扯皮。

第二招，错峰轮班，人歇活不歇。
两班倒，饭轮流吃，交接的时候活不能停。
不浪费一分钟。

巡检的人一直在现场转——盯总进度、盯重点难点、盯衔接节奏、盯安全。
每天进场前十分钟班前交底，讲清楚今天的任务、今天的标准、今天的安全。
收工再碰一遍，当天活当天完。

同行好多要么资源不够接不到这种大活，要么接下来了现场管不住，最后赔钱砸招牌。

一冉能接住，不是运气好。
是一单一单干出来的。
从几十平到十万平，每一单都在攒经验、攒方法、攒底气。

这个活干满意了，后面还有下一遍。
甲方不换人，说明你管住了。

给行业打个样。
家政公司，也能接大单、管大活。

家里或者单位，有那种别人不敢接的活？
一冉家政，大连本地的，靠谱。
