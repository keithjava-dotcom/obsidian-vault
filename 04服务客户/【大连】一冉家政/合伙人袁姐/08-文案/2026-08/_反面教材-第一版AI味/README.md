# ⛔ 反面教材库 · 第一版（AI味版）

> 2026-08-02 柯哥拍板：把第一版全部归档当反面教材，**以后不可以那样写**。
> 当前基线 = 第二版（情绪推动版），后续优化都在第二版上做。

## 为什么存这个

第一版"结构对、没血肉、情绪推不动"——是 AI 写稿的典型病。存下来是为了：
1. 以后写任何 IP 的稿，先对照这里避雷
2. 柯哥审稿时，可以直接指"这篇还有第一版的病"
3. 训练 AI 的判断：哪些句子是 AI 味，哪些是人味

## 八大AI味病症（从这8篇里提炼）

| # | 病症 | 第一版例子 | 第二版改法 |
|---|------|-----------|-----------|
| 1 | **结尾读后感/总结句** | "这活，干得值""这份信任，我接住了""这活儿，我干得心里热乎" | 停在画面/原话/反问 |
| 2 | **解释意义，替观众下结论** | "你干活的时候，有人递你一张纸"（解释20块的意义） | 只摆事实，观众自己品 |
| 3 | **情绪核一带而过** | "我有3个儿女，都挺孝顺"→"我寻思，是啊" | 停住+加表情（"眼睛亮亮的"） |
| 4 | **升华拔高** | "这也是一种孝""邪恶到底能邪恶到什么程度" | 删。原话/画面比拔高有力 |
| 5 | **书面腔混入口语** | "真真切切体会了一把""老人东西不能乱动" | 口语化（"你可别给他挪地方"） |
| 6 | **说教/总结道理** | "这信用，补不回来""这买卖，不能这么干" | 反问代替说教（"那往后，人家还敢信你吗"） |
| 7 | **语音转写残留** | "孩子孩子阿姨""完我说" | 压缩清理，保留一个 |
| 8 | **俗语口号** | "夫妻同心，其利断金"（直接引用） | 用具体画面代替俗语 |

## 使用规则

1. 写稿时对照"八大AI味病症"自查，命中任何一条 → 回改
2. 柯哥审稿说"有第一版的病" → 对照本库定位是哪条，改完汇报
3. 新发现的 AI 味病症 → 追加到本 README 表格
