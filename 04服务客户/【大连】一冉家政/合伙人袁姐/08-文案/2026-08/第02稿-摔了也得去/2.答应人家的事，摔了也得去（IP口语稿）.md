# 第02稿 · 摔了也得去

## 🎬 封面标题

封面标题：答应人家的事，摔了也得去
封面文字：答应人家的事，摔了也得去
平台标题：去粉丝家的路上摔了一跤，胳膊都磕青了——我还是去了。因为答应人家了，就得算数。

## 🧭 结构走线

```
【钩子 · 摔了】
→ 黑石礁干完活往旅顺返，地铁上客户（粉丝）来电话，着急。
→ 客户一着急，我也着急。下地铁骑电动车，摔了。
→ 摔得挺严重。

【一般人 · 就不去了】
→ 一般人想：哎呀这是个事儿，算了别去了。
→ 我想了想：不行。答应人家了。

【到了 · 实话实说】
→ 到客户家，跟他说：刚才着急，摔了一下胳膊。
→ 他说：那你行不行啊？
→ 我说：没事儿，能干活，坚持干。

【才知道 · 他也在等我】
→ 后来才知道，客户为了等我，接他妹妹下飞机都没去。
→ 我想：咬咬牙，这活得给人干完。

【汗水 · 只有自己知道】
→ 屋里热，闷。我和徒弟，衣服全湿透了。
→ 看着我们挣这份钱，背后这汗，只有自己知道。

【收口 · 答应的事】
→ 摔一下，胳膊青了，几天就好。
→ 答应人家的事要是黄了，这信用，补不回来。
```

## ⚠️ 注意事项

1. 摔跤这段是钩子——说得轻一点，别卖惨（"有点疼，但还行"）
2. "一般人可能会想……"是袁姐的对比论证句式，用上
3. "客户接妹妹下飞机都没去"是全文最重的情节点——说到这语速放慢
4. 结尾落"信用补不回来"——这是袁姐"挣的不是钱"的价值观变体
5. 禁止：诉苦、夸张伤势、教观众"做人要诚信"（说出来就是教育，要让她自己干的事说话）

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

昨天上午在黑石礁干活。

干完，往旅顺返。

地铁上，客户来电话了，挺着急。

他着急，我也着急。

下地铁，骑上电动车，一着急，摔了。

摔得挺重，胳膊磕青了。

说实话，那一下真挺疼。

一般人寻思，哎呀，这算个事儿了，别去了吧。

我寻思，不行。

答应人家了。

到客户家，我说，刚才着急走，摔了一下。

他说，那你行不行啊？

我说，没事儿，能干活，坚持干。

后来我才知道，他为了等我，接他妹妹下飞机都没去。

我就寻思，咬咬牙，这活也得给人干完。

屋里热，闷。

我和徒弟，衣服全湿透了。

累是累。

但你说，人家把家都交给你了，你摔一跤就不去了？

那不行。

摔一下，胳膊青了，几天就好。

答应人家的事要是黄了。

这信用，补不回来。
