# 第04稿 · 隔着半个地球下单

## 🎬 封面标题

封面标题：人在西班牙，把家钥匙交给我
封面文字：人在西班牙，把家钥匙交给我
平台标题：客户在西班牙看了我半年视频，回国下飞机第一件事——约我上门收拾房子。

## 🧭 结构走线

```
【钩子 · 从西班牙来的客户】
→ 今天见的客户有点特殊：从抖音来的。
→ 在西班牙的时候，就看我的视频。

【通话 · 六七个小时时差】
→ 之前在抖音上通过话。
→ 他那边下午3点，我这边晚上8点。
→ 隔了六七个小时的时差。

【缘分 · 隔一条道】
→ 聊到最后才知道：他家跟我家，就隔一条道。
→ 我俩名字还都带个"英"字。
→ 他说：姐，我关注你老久老久了。从你发作品就开始看。

【回国 · 下飞机就约】
→ 他说：我上午的飞机，下午1点，你过来。
→ 房子半年没收拾了，老脏了。
→ 我说：行，姐过去给你收拾。

【收口 · 停在"隔一条道"上】
→ 你想想，人在国外，天天刷你的视频。
→ 回国第一件事，不是休息，是约你上门。
→ 结果你猜怎么着？他家跟我家，就隔一条道。
```

## ⚠️ 注意事项

1. "隔一条道"+"名字都带英字"是全文的缘分点——说到这观众会"哎哟"
2. "关注我老久老久了，从你发作品就开始看"是客户原话——保留，别整理
3. 时差那段别讲成科普——"他那边下午3点，我这边晚上8点"就够了
4. 结尾把"缘分"放最后揭晓——先讲信任，再揭"原来这么近"，情绪是往上走的
5. 禁止：讲成"网络营销成功案例"、夸平台、升华成"互联网时代真好"、感谢平台（素材最后那段是获奖感言腔，删）

后来聊着聊着，我才知道。

他家跟我家，就隔一条道。
