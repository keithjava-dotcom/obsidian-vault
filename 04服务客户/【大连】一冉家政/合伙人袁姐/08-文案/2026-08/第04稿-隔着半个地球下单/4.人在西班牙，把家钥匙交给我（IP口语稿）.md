# 第04稿 · 隔着半个地球下单

## 🎬 封面标题

封面标题：人在西班牙，把家钥匙交给我
封面文字：人在西班牙，把家钥匙交给我
平台标题：客户在西班牙看了我半年视频，回国下飞机第一件事——约我上门收拾房子。

## 🧭 结构走线

```
【钩子 · 从西班牙来的客户】
→ 今天见的客户有点特殊：从抖音来的。
→ 他在西班牙的时候，就看我的视频。

【通话 · 六七个小时时差】
→ 我们俩在抖音上通过话。
→ 他那边下午3点，我这边晚上8点。
→ 隔了六七个小时的时差。

【缘分 · 隔一条道】
→ 聊到最后才发现：他家跟我家，就隔一条道。
→ 我俩名字都带个"英"字。
→ 关注我老久老久了，从我发作品就开始看。

【回国 · 下飞机就约】
→ 他说：我上午的飞机，下午1点，你过来。
→ 房子半年没收拾了，老脏了。
→ 我说：行，姐过去给你收拾。

【收口 · 网络的信任】
→ 你想想，一个人在国外，天天看你的视频。
→ 回国第一件事，不是休息，是约你上门。
→ 把家交给一个没见过面的人。
→ 这份信任，我接住了。
```

## ⚠️ 注意事项

1. "隔一条道"+"名字都带英字"是全文的缘分点——说到这观众会"哎哟"
2. "关注我老久老久了"是客户的原话，保留口语味
3. 结尾落"把家交给一个没见过面的人"——信任的重量，不落"感谢平台"
4. 素材最后"感谢平台"那段别用——太像获奖感言，袁姐不说这种话
5. 禁止：讲成"网络营销成功案例"、夸平台、升华成"互联网时代真好"

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

今天下午见的这个客户，有点特殊。

他是从抖音上来的。

在西班牙的时候，就看我的视频。

我们俩之前在抖音上通过话。

他那边是下午3点，我这边是晚上8点。

隔了六七个小时的时差。

聊到最后我才知道——他家跟我家，就隔一条道。

我俩名字还都带个"英"字。

他说，姐，我关注你老久老久了。

从你发第一个作品，我就开始看。

他说，我上午的飞机。

下飞机以后，下午1点钟，你过来一趟。

这房子半年没收拾了，老脏了。

我说，行。

姐过去给你收拾。

你想想，一个人，在国外。

天天刷你的视频，看了半年。

回国第一件事，不是倒时差，不是休息。

是约你上门，把家交给你。

一个没见过面的人。

这份信任，我接住了。
