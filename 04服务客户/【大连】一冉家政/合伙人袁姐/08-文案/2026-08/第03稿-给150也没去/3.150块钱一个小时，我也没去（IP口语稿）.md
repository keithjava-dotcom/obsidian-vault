# 第03稿 · 给150我也没去

## 🎬 封面标题

封面标题：150块钱一个小时，我也没去
封面文字：150块钱一个小时，我也没去
平台标题：晚上10点，客户说一小时给150让我上门，我没去。不是嫌钱少——是我真干不动了。

## 🧭 结构走线

```
【钩子 · 150块没去】
→ 晚上快10点，美团来电话。小老妹儿，家里有狗，味儿太大，受不了。
→ 她说明天就不在家了，干24休24，就今晚有空。
→ 她说：姐，我给你150，你来不来。

【我为什么没去 · 三件事】
→ 我刚从客户家回来，饭还没吃完。
→ 今天一连干了十多个小时。
→ 我家孩子明天早上4点半起来练车。

【说实话 · 不是钱的问题】
→ 我说：老妹儿，不是钱的问题。我干不动了。
→ 去了也是糊弄你。擦不干净，你白花钱，我还砸招牌。
→ 这买卖，不能这么干。

【给她出路 · 加微信】
→ 你先把我微信加上。休息那天喊我，我过去给你好好收拾。
→ 提前约，别等不赶趟儿了才找人。

【收口 · 停在"没去"上】
→ 150块，不少。
→ 但我干不动了，就是干不动了。
```

## ⚠️ 注意事项

1. "干24休24"是理解这个客户的关键——她不是不想提前约，是真的只有今晚。这点要讲清，观众才不会觉得袁姐冷漠
2. "去了也是糊弄你"是全文的底气——这句要说得慢、说得稳，不解释
3. "我干不动了，就是干不动了"——重复不是废话，是袁姐的"我意已决"
4. 结尾不补"以后你就不信我了"（上一版太说教）——就停在"没去"上，拒绝本身就是态度
5. 禁止：讲成拒单教学、炫耀"我不差钱"、教育观众提前预约（点一句就够）
