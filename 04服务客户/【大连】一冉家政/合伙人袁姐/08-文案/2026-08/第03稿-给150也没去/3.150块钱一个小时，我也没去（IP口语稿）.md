# 第03稿 · 给150我也没去

## 🎬 封面标题

封面标题：150块钱一个小时，我也没去
封面文字：150块钱一个小时，我也没去
平台标题：晚上10点，客户说一小时给150让我上门，我没去。不是嫌钱少——是我真干不动了。

## 🧭 结构走线

```
【钩子 · 150块没去】
→ 晚上快10点，美团来电话。
→ 小老妹儿，家里有狗，味儿太大，受不了。
→ 我说加钱，一小时150，你来不来。

【我为什么没去 · 三件事】
→ 我刚从客户家回来，饭还没吃完。
→ 我家孩子明天早上4点半起来练车。
→ 我今天一连干了十多个小时，真干不动了。

【说实话 · 不是钱的问题】
→ 我说：不是钱的问题。我干不动了。
→ 去了也是糊弄你，擦不干净，你白花钱，我还砸招牌。

【教大家 · 提前约】
→ 收拾卫生这事儿，真得提前约。
→ 别等不赶趟儿了才找人，那时候啥都来不及。

【收口 · 实话比挣钱重要】
→ 150块，不少。
→ 但我干不动了就是干不动了。
→ 糊弄你一次，以后你就再也不信我了。
```

## ⚠️ 注意事项

1. 这篇的钩子就是"150块/小时没去"——反常识，观众会想"为啥"
2. "去了也是糊弄你"这句是全文最狠的实话——说到这停一下
3. "孩子4点半起来练车"是拒绝的理由里最有人味的一个——放在第二个说
4. 结尾落"实话比挣钱重要"，不是"教大家预约"——预约只是顺带，别讲成科普
5. 禁止：讲成"拒单教学"、炫耀"我不缺钱"、教育观众要提前预约（点一句就够）

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

昨天晚上快10点了，美团来个电话。

一个小老妹儿，挺着急。

她说，姐，我家有狗，屋里味儿太大了。

我实在受不了了，你今晚能不能来一趟？

我说，老妹儿，这电话打得确实有点晚。

我刚从客户家回来，饭还没吃完呢。

她说，姐，我给你加钱。

你不是60一小时吗？我给你150，你过来一趟。

150。

说实话，这钱不少。

但是我没去。

为啥？

第一，我今天一连干了十多个小时，真干不动了。

第二，我家孩子明天早上4点半就要起来练车。

我要是硬撑着去了，擦不干净，糊弄你。

你白花钱，我还砸自己招牌。

这买卖，不能这么干。

我说，老妹儿，你先把微信加上。

等你休息那天喊我，我过去给你好好收拾。

她说明天她就不在家了，干24休24，就今晚有空。

那也没办法。

收拾卫生这事儿啊，真得提前约。

别等到不赶趟儿了才找人，那时候啥都来不及。

150块，不少。

但我干不动了，就是干不动了。

糊弄你一次。

以后你就不信我了。

这钱，我挣不了。
