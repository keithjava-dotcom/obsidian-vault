# 第08稿 · 一天900这么挣的

## 🎬 封面标题

封面标题：一天挣900，我老公下班来帮忙
封面文字：一天挣900，我老公下班来帮忙
平台标题：34度，我从早上干到下午4点，我老公下班了，围裙都没摘又来帮我擦玻璃。一天900，是这么挣出来的。

## 🧭 结构走线

```
【钩子 · 900块】
→ 一天900，怎么挣的？
→ 不是运气。是一点儿间隙都没有。

【上午 · 碧桂园5小时】
→ 上午在碧桂园，干了5个小时。
→ 回来到我家跟前儿，又擦两家玻璃。

【34度 · 老公来了】
→ 昨天34度，我擦到4点，浑身全是汗。
→ 我对象下班了：你过来帮我擦一下。
→ 他拿着玻璃刮就过来了。

【玻璃 · 擦两遍】
→ 那玻璃老脏了，一年多没擦了。
→ 正常一遍能擦干净，他家得擦两遍。
→ 俩人擦了快两个半小时。

【围裙没摘 · 去下一家】
→ 擦完，围裙都没摘。
→ 又去另一家，连擦玻璃带收拾卫生。
→ 干到晚上8点半。

【老公说 · 不许再接了】
→ 我对象说：再也不许接活了。
→ 一天900。就是这么挣出来的。

【收口 · 停在"不许接活了"上】
→ 夫妻同心，其利断金。
→ 这话以前就是听听。
→ 昨天，是真体会到了。
```

## ⚠️ 注意事项

1. "围裙都没摘"是全文最硬的画面——一天的累都在这一句里，不用再多说
2. "再也不许接活了"是老公的原话——又心疼又骄傲，说到这观众会笑
3. "擦两遍"是专业的细节——不用说自己专业，这个细节就是
4. 结尾"这话以前就是听听，昨天是真体会到了"——这是袁姐的朴素感慨，不是总结道理
5. 禁止：炫耀收入、苦情卖惨、教育观众要夫妻同心（让事实自己说话）
