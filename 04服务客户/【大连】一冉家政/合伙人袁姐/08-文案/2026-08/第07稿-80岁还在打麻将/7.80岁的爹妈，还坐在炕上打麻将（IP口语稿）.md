# 第07稿 · 80岁还在打麻将

## 🎬 封面标题

封面标题：80岁的爹妈，还坐在炕上打麻将
封面文字：80岁的爹妈，还坐在炕上打麻将
平台标题：女儿在开发区，让我去给80岁的爸妈家做深保。进门一看——老两口正打麻将呢，这画面我记一辈子。

## 🧭 结构走线

```
【钩子 · 80岁打麻将】
→ 客户让我去给她爸妈家做深保。
→ 一进屋：80岁的老两口，正打麻将呢。旁边还坐着仨牌友。
→ 屋里那个热闹。

【你来啦 · 该打打】
→ 老太太慈眉善目：你来啦。
→ 我说：您该打打，我不影响您。她真坐回去接着打。

【干活规矩 · 听老人的】
→ 客户交代：以收拾卫生为主。老人东西自己搁哪儿自己能找着——别乱动。
→ 挪了，他回头找不着，该着急了。

【做完 · 阿姨说】
→ 3个半小时。做完录视频给客户看。
→ 阿姨：哎呀妈呀，这油烟机咋擦这么干净？用的油污净。
→ 哦，怪不得呢。那个表情，老高兴了。

【儿女的孝】
→ 客户：以前都是我帮爸妈忙活，现在我腰间盘突出，动不了。先给我妈做。
→ 老人：我有3个儿女，都挺孝顺。说这话的时候，眼睛亮亮的。
→ 客户：我不想按我的要求来要求他们。年龄大了，想咋样就咋样。

【收口 · 画面收】
→ 出门回头看了一眼：老两口又坐回去打麻将了。
```

## ⚠️ 注意事项

1. "屋里那个热闹"——一进屋先给声音和画面，别急着讲故事
2. "你可别给他挪地方"——这是干这行的人才懂的规矩，比说"专业"强一百倍
3. "那个表情，老高兴了"——说到这要停，让观众看到老太太的脸
4. "眼睛亮亮的"是全文的情绪核——老人说儿女孝顺时的表情，比话本身重
5. 客户那句"不想按我的要求来要求他们"是素材里的原话，必须保留——儿女对父母的尊重，比"孝"字更具体
6. 结尾不总结、不升华，就停在"又坐回去打麻将了"——首尾呼应，观众自己会品
7. 禁止：总结"这也是一种孝"、教育观众要孝顺、拔高成"爱的传递"

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

客户让我去给她爸妈家做深保。

她爸妈，80岁了。

一进屋，我愣住了。

老两口正打麻将呢。

旁边还坐着仨牌友。

屋里那个热闹。

老太太抬头看我，慈眉善目的：

你来啦。

我说：哎，您该打打，我不影响您。

她就真坐回去，接着打。

我寻思，80岁了还能打麻将。

这脑子，老好了。

干活的时候，客户交代了：

以收拾卫生为主。

老人东西自己搁哪儿，自己能找着。

你可别给他挪地方。

挪了，他回头找不着，该着急了。

我就按着这个来。

擦油烟机，擦厨房，擦卫生间。

干了3个半小时。

做完，我录了个视频，发给客户。

老太太过来一看，哎呀妈呀：

这油烟机，咋擦这么干净？

我说：阿姨，用的油污净。

她说：哦，怪不得呢。

那个表情，老高兴了。

后来客户跟我说：

以前都是我帮我爸妈忙活。

现在我腰间盘突出，动不了了。

先给我妈做，做完，再给我家收拾。

老太太拉着我说：

我有3个儿女，都挺孝顺。

她说这话的时候，眼睛亮亮的。

我寻思，可不是嘛。

儿女没空来。

找人把家收拾得干干净净。

这也是孝。

客户还跟我说了一句：

我不想按我的要求来要求他们。

他们年龄大了，想咋样就咋样。

让他们自由。

我出来的时候，回头看了一眼。

老两口，又坐回去打麻将了。
