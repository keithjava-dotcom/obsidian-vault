# 第07稿 · 80岁还在打麻将

## 🎬 封面标题

封面标题：80岁的爹妈，还坐在炕上打麻将
封面文字：80岁的爹妈，还坐在炕上打麻将
平台标题：女儿在开发区，让我去给80岁的爸妈家做深保。进门一看——老两口正打麻将呢，这画面我记一辈子。

## 🧭 结构走线

```
【钩子 · 80岁打麻将】
→ 客户让我去给她爸妈家做深保。
→ 一进屋：80岁的老两口，正打麻将呢。
→ 我第一感觉：80岁了还能打麻将，这脑子，老好了。

【老人说 · 你来啦】
→ 老太太慈眉善目：你来啦。
→ 我说：您该打麻将打麻将，我不影响您。
→ 4个牌友，该打打。

【怎么干 · 听老人的】
→ 客户交代：以收拾卫生为主。
→ 老人东西自己放哪儿自己能记住——不能乱动。
→ 3个半小时深保。

【做完 · 阿姨说】
→ 做完录视频给客户看。
→ 阿姨说：哎呀妈呀，这油烟机咋擦这么干净？
→ 我说：用的油污净。
→ 阿姨：哦，怪不得呢。

【儿女的孝】
→ 客户说：以前都是我帮爸妈忙活，现在我腰间盘突出，动不了。
→ 先给我妈做，做完再给我家收拾。
→ 老人说：我有3个儿女，都挺孝顺。

【收口 · 爱的传递】
→ 儿女没空亲自来，但找人把父母家收拾得干干净净。
→ 这也是一种孝。
→ 这活儿，我干得心里热乎。
```

## ⚠️ 注意事项

1. "80岁打麻将"是全文的开门画面——进门前先有这个画面，观众就留下了
2. "老人东西不能乱动"是专业的体现——不用说自己专业，这句话就是
3. "哎呀妈呀，这油烟机咋擦这么干净"是阿姨原话，必须保留——这是全文最亮的证据
4. "我有3个儿女都挺孝顺"是老人亲口说的——比任何夸奖都有分量
5. 结尾落"爱传递"，不落"我多专业"——袁姐的价值观句式（挣的不是钱）
6. 禁止：讲成"适老化服务"、教育儿女要孝顺、把老人当道具煽情

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

客户让我去给她爸妈家做深保。

她爸妈，80岁了。

一进屋，我愣住了。

老两口正打麻将呢。

80岁了还能打麻将。

这脑子，老好了。

老太太慈眉善目的，跟我说：你来啦。

我说：哎，您该打打，我不影响您。

4个牌友，该打打。

客户交代了：以收拾卫生为主。

老人东西自己放哪儿，自己能记住。

不能乱动。

我就按着这个来，干了3个半小时。

做完，我录了个视频发给客户。

老太太过来一看：哎呀妈呀。

这油烟机，咋擦这么干净？

我说：阿姨，用的油污净。

阿姨说：哦，怪不得呢。

后来客户跟我说：

以前都是我帮我爸妈忙活。

现在我腰间盘突出，动不了了。

先给我妈做，做完，再给我家收拾。

老人跟我说：我有3个儿女，都挺孝顺。

我寻思，是啊。

儿女没空亲自来。

但找人把父母家收拾得干干净净。

这，也是一种孝。

这活儿，我干得心里热乎。
