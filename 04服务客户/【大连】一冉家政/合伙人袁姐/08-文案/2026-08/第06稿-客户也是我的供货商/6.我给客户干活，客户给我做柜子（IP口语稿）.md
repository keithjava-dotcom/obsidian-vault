# 第06稿 · 客户也是我的供货商

## 🎬 封面标题

封面标题：我给客户干活，客户给我做柜子
封面文字：我给客户干活，客户给我做柜子
平台标题：我给客户家擦玻璃收拾卫生，客户家是做板材定制的——我这小屋的柜子，就找她做。活和活，就这么换着来。

## 🧭 结构走线

```
【钩子 · 客户也是供货商】
→ 今天这个客户，是从视频号来的。
→ 干完活聊起来：她家是做板材定制的。
→ 我家小屋想做个定制柜子——正好找她。

【干活 · 衣服堆成山】
→ 上午擦玻璃，下午收拾卫生。
→ 她家衣服堆得跟山似的。
→ 收拾了4个小时。

【孩子 · 说什么也不干】
→ 中途我订了个外卖。
→ 孩子自己在家，我说：孩子，阿姨请你吃饭。
→ 孩子说什么也不干。

【互相支持】
→ 客户有需要的时候，找我。
→ 我有需要的时候，找她下单。
→ 她碰着客户需要板材，我也帮她推荐。

【收口 · 停在"孩子"上】
→ 人和人能碰上，都不容易。
→ 你拉我一把，我拉你一把。
```

## ⚠️ 注意事项

1. "衣服堆得跟山似的"是全文最具体的画面——收拾4小时的辛苦都在这句话里
2. "孩子说什么也不干"是全文最暖的小细节——说到这笑一下，别展开（素材里就一句，别加戏）
3. 结尾别总结"这买卖就做长了"（说教）——就停在"你拉我一把，我拉你一把"，观众自己接
4. "板材定制"说一遍就行——观众记住"客户做柜子的"就够
5. 禁止：讲成"异业合作案例"、炫耀人脉广、教育观众要互相帮助

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

今天这个客户，是从视频号来的。

她家那衣服，堆得跟山似的。

上午擦玻璃，下午收拾卫生。

收拾了4个小时。

中途我订了个外卖。

孩子自己在家。

我说，孩子，阿姨请你吃饭。

孩子说什么也不干。

最后我自己订了一份，自己吃了。

干完活跟客户聊天，才知道她家是做板材定制的。

我一听，正好。

我家小屋想做个定制柜子。

我说，姐，那正好，我这柜子就找你了。

她说，那敢情好。

客户有需要的时候，找我。

我有需要的时候，找她。

她要是碰着客户需要板材，我也帮她推荐推荐。

人和人能碰上，都不容易。

你拉我一把，我拉你一把。
