# 第05稿 · 交钱前后两副脸

## 🎬 封面标题

封面标题：交钱之前把你当祖宗，交钱之后把你当猴耍
封面文字：交钱之前把你当祖宗，交钱之后把你当猴耍
平台标题：钱没交之前，你是祖宗。钱交了以后，你是猴。这话，干过买卖的人都懂。

## 🧭 结构走线

```
【钩子 · 这句话】
→ 有一句话，干过买卖的人都懂。
→ 交钱之前把你当祖宗，交钱之后把你当猴耍。

【我们4个人去了】
→ 头几天，我们4个人一块儿去的。
→ 到公司，把人挨个数落了一遍。
→ 人家说了：能退，但得一个个来。
→ 说白了，就是拖。

【他挺嚣张】
→ 那态度，老嚣张了。
→ 说我们联系的部门，都跟他联系了，他都不怕。
→ 说他不是靠这些人起来的。

【报警了 · 警察说】
→ 后来他还报警了。
→ 警察来了，问清楚情况，跟他说：
→ 人家没闹事儿，正常过来，正常说话。你这是错误报警。

【收口 · 停在"正义怎么写"上】
→ 我的钱其实不多。
→ 但其他合伙人的钱，真的多。
→ 我就是想看看，正义这两个字，到底是怎么写的。
```

## ⚠️ 注意事项

1. ⚠️ 敏感处理：涉及投诉、报警、政府的细节一律模糊化——重点放在"交钱前后两副脸"的大众共鸣，不具体说哪个公司哪个部门
2. "警察说是错误报警"是全文的硬证据——对方不占理，警察都说了。说到这停一下
3. "能退，但得一个个来"——"说白了，就是拖"这句是袁姐的解读，保留那个判断
4. 素材里"他领导都打点好了"这类话删掉——说了等于指名道姓，容易惹麻烦
5. 结尾停在"正义两个字怎么写"——这是袁姐的真实想法，不是拔高
6. 禁止：具体公司名、具体金额单位、教观众怎么维权（不是教程，是经历）、"邪恶到底能邪恶到什么程度"这句结尾别加（太重，容易引战）

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

有一句话，干过买卖的人都懂。

交钱之前把你当祖宗。

交钱之后把你当猴耍。

我这两天，真真切切体会了一把。

头几天，我们4个人一块儿去的。

到那儿，把人挨个数落了一遍。

人家说了，能退。

但得一个个来。

说白了，就是拖。

那态度，老嚣张了。

说我们联系的部门，都跟他联系了，他都不怕。

说他不是靠这些人起来的。

我寻思，这话说的。

后来他还报警了。

警察来了，问清楚情况，跟他说：

人家没闹事儿。

正常过来，正常说话。

你这是错误报警。

我的钱其实不多。

但是其他合伙人的钱，真的多。

我觉得，这事儿不能就这么算了。

我就是想看看。

正义这两个字。

到底是怎么写的。
