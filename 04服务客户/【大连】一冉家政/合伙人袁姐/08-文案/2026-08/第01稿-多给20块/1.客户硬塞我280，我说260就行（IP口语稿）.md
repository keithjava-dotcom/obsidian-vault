# 第01稿 · 多给20块

## 🎬 封面标题

封面标题：客户硬塞我280，我说260就行
封面文字：客户硬塞我280，我说260就行
平台标题：干完活我说给260就行，客户非转280。这多出来的20块，比工资都让人踏实。

## 🧭 结构走线

```
【钩子 · 多给的20块】
→ 直接扔结果：我说260，她转280。多20块。
→ 这20块不是钱，是"我干活她看见了"。

【这客户 · 静脉曲张不敢蹲】
→ 江山帝景，新买的房子，乔迁。
→ 大哥静脉曲张，不敢蹲，擦玻璃收拾卫生全靠配合我。
→ 不是他懒，是真蹲不下。

【配合 · 递纸巾】
→ 我出汗，他紧忙递纸巾。
→ 一个递一个接，活干得顺。

【260还是280】
→ 干完我说：哥，给260就行。
→ 他说：拜拜，给你280，发发发。
→ 转了280。

【收口 · 干活有人看见】
→ 不是钱多钱少的事。
→ 是你干的时候，有人递你一张纸。
→ 这活干得值。
```

## ⚠️ 注意事项

1. "发发发"三个字要笑着说，这是东北人图吉利的小心思
2. 静脉曲张这段别讲成科普，就一句"他蹲不下，我蹲"就够
3. 递纸巾是全文的眼睛——说到这停一下，让观众看见那个画面
4. 结尾落在"被看见"，不是落在"客户大方"——这是袁姐的价值观句式
5. 禁止：教育观众"好人有好报"、升华成"人间有真情"、总结道理

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

昨天在江山帝景干活儿。

那大哥静脉曲张，不敢蹲。

擦玻璃，收拾卫生，全是他在旁边配合我。

他干不了的，我干。

我干不了的，他递。

我出汗出得满脸都是，他紧忙给我递纸巾。

就这个动作，我这心里头，老暖了。

活干完了，我说，哥，给260就行。

他说，拜拜，给你280。

发发发。

我说不用，他说拿着。

就多这20块。

你说，我差这20块吗？

不差。

我是觉得，我这汗没白出。

你干活的时候，有人递你一张纸。

这活，干得值。
