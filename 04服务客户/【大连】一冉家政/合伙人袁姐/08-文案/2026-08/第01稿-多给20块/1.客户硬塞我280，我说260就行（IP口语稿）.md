# 第01稿 · 多给20块

## 🎬 封面标题

封面标题：客户硬塞我280，我说260就行
封面文字：客户硬塞我280，我说260就行
平台标题：干完活我说给260就行，客户非转280。这多出来的20块，比工资都让人踏实。

## 🧭 结构走线

```
【钩子 · 多给的20块】
→ 干完活我说：哥，给260就行。
→ 他说：拜拜，给你280，发发发。
→ 多20块。为啥？往下听。

【这客户 · 静脉曲张不敢蹲】
→ 江山帝景，新买的房子，乔迁。
→ 大哥静脉曲张，不敢蹲。
→ 擦玻璃、收拾卫生，全是他在旁边配合我。

【递纸巾 · 全文的眼睛】
→ 我出汗出得满脸都是。
→ 他紧忙给我递纸巾。
→ 就这个动作。

【260还是280】
→ 活干完了，我说260就行。
→ 他说：拜拜，给你280，发发发。
→ 转过来280。

【收口 · 停在"递纸巾"上】
→ 你说我差这20块吗？
→ 不差。
→ 我是觉得，这汗没白出。
```

## ⚠️ 注意事项

1. "发发发"三个字要笑着说——东北人图吉利的小心思
2. 静脉曲张别讲成科普，就一句"他蹲不下"就够
3. "紧忙给我递纸巾"是全文的眼睛——说到这停一下，让观众看见那个画面
4. 结尾别总结"干活有人看见"——就停在"这汗没白出"，观众自己会接
5. 禁止：教育观众"好人有好报"、升华成"人间有真情"、解释20块的意义

## 📝 口播文案示例

⚠️ 示例，不是逐字稿。袁姐理解了走线，用自己的话说。

昨天在江山帝景干活儿。

那大哥，静脉曲张。

不敢蹲。

擦玻璃，收拾卫生，全是他在旁边配合我。

他干不了的，我干。

我够不着的，他递。

我出汗出得满脸都是。

他紧忙给我递纸巾。

就这个动作。

我当时心里头，老暖了。

活干完了，我说，哥，给260就行。

他说，拜拜，给你280。

发发发。

我说，不用不用。

他说，拿着。

就多这20块。

你说，我差这20块吗？

不差。

我是觉得，这汗，没白出。
