# 文案1：家庭共振向上

## 🗺️ 大纲

| 维度 | 内容 |
|------|------|
| **锚定对象** | 观点——"好的家庭长什么样"，从袁姐每天上户的观察中提炼 |
| **结构** | 清单式（几个并列的观察→收束到一个观点） |
| **核心刺点** | 她每天进别人家干活，看到的不只是脏不脏，是家怎么经营 |
| **受众靶心** | 大连30-50岁家庭女性，在意家庭氛围的 |

【发散出的点】
1. 每天至少跑两个家庭，十几年下来进了几百个家门
2. 黄泥川客户家那晚：男主人7点到家马上做饭，女主人看电视做手工，孩子安静学习——三个人各干各的但在一起
3. 她看到的共性：父母有教养，孩子有边界感，情绪稳定，爸爸疼妈妈
4. 齐家治国平天下——她没上过大学，但在客户家里看到了这句话的真人版
5. 反着说：一个人连家都经营不好，怎么管一个公司
6. 女人的幸福感不应该靠男人给钱——自己挣钱，自己在家里就有分量

【砍掉】
- 习近平携夫人 → 太远太敏感，跟袁姐日常语感不符
- "上流社会" → 她不会用这词。换成"那些过得好的人家"

【找链接】所有点都在说一件事：她在客户家看到的家庭规律。并列关系，清单式。

【信息量体检】
- 🟢 具体细节类 2个（黄泥川场景、她自己的职业身份），抽象判断类 4个——抽象偏多
- 🟡 建议补一个具体场景：除了黄泥川那家，再回忆一个反面案例——进过什么样的家，一进门就知道这家不对
- 🟡 "齐家治国平天下"和"自己挣钱"之间跳跃略大，收束需要更顺

## 🎬 文案举例

我是袁姐，在大连干家政十几年了。

每天至少跑两个家庭。
十几年下来，我进过几百个家门。

你们都说我是去干活的。
其实我觉得，
我在看别人怎么过日子。

昨天晚上去黄泥川，
7点钟从客户家出来。

男主人刚到家，包一放，进厨房洗菜做饭。
女主人坐在沙发上看电视，手里做着十字绣。
孩子在自己房间安安静静写作业。

三个人，各干各的。
但都在同一个空间里。
那种感觉，我说不上来。
就是很稳。

我干这么多年发现，
那些过得好的家庭，有几个一模一样的地方：
父母有教养。
孩子知道分寸。
家里情绪是稳的。
爸爸疼妈妈。

反过来，有些家你一进门就觉得不对。
东西不差，房子不小。
但是哪儿哪儿不对劲。
后来我明白了——
家里那条线断了。

我们老祖宗说，齐家治国平天下。
我高中没毕业。
但我在客户家里，看到了这句话。

一个人，连家都理不顺，
外面的事，你做不大。

我出来挣钱，不是为了证明我比谁强。
是我发现，
我在家说话的音量，
跟我一个月挣多少钱，
是有关系的。

说一个事儿。

我以前在一家公司干的时候，
有个同事，跟我岁数差不多。
每天骑摩托车跑活。

有一年，出事故了。
人没了。

在龙王塘。

走一条小路。

碰到一个男的。
怎么说呢。
就是那种。

我当时第一反应就是大声呵斥了一下。
然后拔腿就跑。

我不太怕。
因为我工具包里啥都有。
有棍子。

但是我有时候想起这个事儿，

要是一个二十出头的小姐妹碰到这个呢？

她可能吓傻了。

干我们这行的，
天天在路上。
早上出门天没亮，晚上回来天黑透。

想跟同行姐妹们说一句：
不管活儿多急，
走亮处，别抄近道走暗路。
包里放个防身的。
到了客户家，给家里人发个定位。

咱们挣的是辛苦钱，
命比钱重要。

# 文案3：以信任为己任，承担责任

## 🗺️ 大纲

| 维度 | 内容 |
|------|------|
| **锚定对象** | 人（袁姐自己——用一件事讲她怎么对得起信任） |
| **结构** | 发展式（决定刷单→自掏腰包→完成服务→信任成立） |
| **核心刺点** | 两三个月白干，换一句"我相信你" |
| **受众靶心** | 潜在客户——看完就知道这个人靠得住 |

【发散出的点】
1. 在原公司平台，客户买了4000、5000、8000的单
2. 袁姐离职后，客户想退单——平台要扣掉一半多（5000剩不到2000）
3. 客户不想让别人干，只认袁姐
4. 袁姐做了个决定：把所有单刷到自己名下，自己一个个干完
5. 刷了大概两万块钱的单
6. 每单出行费30块全自己掏——算下来两三个月白干
7. 冬天，年前，把单全干完了
8. 别人说她傻：你这不是自掏腰包吗
9. 袁姐说她没想那么多——客户信她，把几千块钱转她个人，她不能让人家亏
10. 信任比钱重

【砍掉】无

【找链接】发展式——离职→面临困境（客户的钱要被扣）→做决定（刷到自己名下）→付出代价（两三个月白干）→完成→信任。每个节点推下一个节点，顺序不能乱。

【信息量体检】
- 🟢 料够肥：具体数字（2万、30块一单、冬天年前）、具体动作（刷单、一个个干完）、真实代价（两三个月白干）
- 🟢 发展式成立，逻辑链完整，没有硬缝
- 🟡 唯一问题：没有画面。全是口述。建议袁姐找一张那时候干活的照片（冬天的、在客户家门口的、或者聊天记录截图），哪怕只有一张，比纯口播强十倍。

---

## 🎬 文案举例

讲一个事儿。
这个事儿我没跟太多人说过。

我在上一家公司干的时候，
很多客户通过平台买单。
四千的，五千的，八千的。

后来我离职了。
有客户想退单。

平台那边说，退可以。
但是要扣钱。
一个客户剩五千，
退回来就剩一千多。

客户不干了。
她们说，我不要别人，
我就要袁姐来。

那时候我也不知道哪来的胆子。
我做了个决定——

把所有客户的单，
全部刷到我个人名下。

一共两万多块钱的单子。

每干一单，出行费三十块。
原来是公司出。
现在全是我自己掏。

别人问我：你是不是傻？
你这不是自己搭钱帮别人干活吗？

我没想那么多。

那个冬天，
年前最冷的时候，
我把所有单，
一个一个，
全给干完了。

算下来，
那两三个月，
基本白干。

但客户把钱转给我的时候，
他们没犹豫。

不是因为我多会说话。
是因为他们信我。

这种东西，
拿钱买不来。

# 文案4：女人如何兼顾事业与家庭

## 🗺️ 大纲

| 维度 | 内容 |
|------|------|
| **锚定对象** | 观点——家庭和事业不是二选一 |
| **结构** | 清单式（从客户家学到的几个道理→自己的体会） |
| **核心刺点** | 她没上过大学，但在有钱人家里学到了怎么经营人生 |
| **受众靶心** | 30-50岁女性——正在纠结家庭和工作的 |

【发散出的点】
1. 天天在条件好的家庭干活，看他们怎么分配时间、怎么对家人
2. 在医院看到保洁大姐——一边干活一边顾家
3. 现在社会都说挣钱难、不想结婚
4. 她自己的体会：家庭责任维系好了，财运自然来
5. 这是她在客户家里一点点学的
6. "财富是关系的副产品，关系是能量的循环体，家庭是能量流动的核心"——这句话从她嘴里说出来，意外但有分量

【砍掉】
- 去医院录视频那段（那是拍摄计划不是文案素材）

【找链接】并列观察。清单式。

【信息量体检】
- ⚠️ 抽象严重偏多——具体细节几乎为零。只有一句话是具体的（"在客户家里一点点学的"），其他全是道理。
- ⚠️ 最大问题："财富是关系的副产品"这句结尾太硬核，前面的内容撑不住它。需要一个具体故事当梯子。
- 🟡 建议：袁姐说过她客户帮她孩子规划高考志愿——这就是现成的故事！把这条拿出来，讲"我的客户为什么愿意帮我孩子"，然后自然接到"家庭关系"和"财富是关系"这个结论上。不靠硬讲道理。

【补拍提问 · 开关式】
- 【开关1】"你上次说客户帮你家孩子报志愿的时候，你自己当时是什么感觉？你就说那一刻。"
- 【开关2】"你在客户家里，有没有看到过那种——你觉得这家太会过日子了——的一个细节？就说那个细节。"

## 🎬 文案举例

我高中没毕业。

但我上了十几年"社会大学"。

我在大连做家政，
每天进不一样的家门。

有的家，一进门你就觉得舒服。
不是装修好。
是那个氛围。

我观察过，
那些过得好的家庭，
有一个共同点：

他们不信"女人就该在家"这套。
也不信"拼事业就别管家"那套。

他们信的是——
两个人一起，
把家里那条线缝住。

我在客户家学到的，
不是怎么擦地。
是学到了怎么过日子。

我客户帮我孩子报过高考志愿。
不是客套。
是真的一起坐下来，研究学校、专业。
我自己都看不懂那些。

你说我一个做保洁的，
凭什么能让人家这么对我？

后来我想明白了。
不是因为我活干得多好。
是我进这个家门的时候，
我没把自己当外人。

关系这个东西，
不是你求来的。
是你先给出的。

我最近看到一句话，特别对：
财富是关系的副产品。
关系是能量的循环。
而家庭，是能量流动的核心。

我一个干保洁的，说这个可能有点奇怪。
但这确实是我在几百个客户家里，
一点一点看出来的。

# 文案5：急单·年轻人

## 🗺️ 大纲

| 维度 | 内容 |
|------|------|
| **锚定对象** | 事——一次急单经历，颠覆对年轻人的印象 |
| **结构** | 发展式（接到急单→去干→客户多给钱→约下次→感悟） |
| **核心刺点** | 以为年轻人难搞，结果比谁都敞亮 |
| **受众靶心** | 大连本地有家政需求的年轻家庭+普通受众（故事好看） |

【发散出的点】
1. 下午干完活，6点半接到电话——美团上来的，着急
2. 骑电动车过去，很近，就在家门口
3. 进屋一看，90后年轻人
4. 收拾了一会儿，小伙拿100块钱出来——姐，不用找了
5. 正常干一小时，袁姐给干了一个半小时
6. 走的时候，小伙说：门给我关上就行
7. 约了礼拜一擦玻璃
8. 袁姐的感慨：年轻人办事，有时候比我们想象中更敞亮

【砍掉】无

【找链接】发展式推动很自然：接单→到现场→干→客户给钱反转→信任建立（门关上就行）→约下次。每个节点有推进，没有废话。

【信息量体检】
- 🟢 这条最完整：具体时间（6点半）、具体动作（骑电动车、拿100块）、具体场景（第一次见面就信任）、反转（以为年轻人不好沟通→结果很敞亮）、收尾（约了下一次）
- 🟢 发展式成立，节奏好，没有逻辑缝
- 🟢 不需要补拍——袁姐下次去擦玻璃的时候顺便录一段就行，但这条现在就能讲

## 🎬 文案举例

昨天下午干完活，
6点半。
一个电话打进来。

美团上来的。
说我着急。
就在我家附近。

我说行。
骑上电动车就过去了。

一进屋，
是个小伙子。
90后。

我进去就开始干。
收拾了没一会儿，
他走过来。
手里拿着100块钱。

他说：
姐，这钱你拿着，不用找了。

我当时一愣。
正常我就干一小时。
我想着，人家这么敞亮，
我多干一会儿。

那天我干了一个半小时。

走的时候，
我跟他说我先走了。
他说：
姐，你收拾完帮我把门关上就行。

第一次见面。
让我帮他关门。

我走到楼下还在想——
我们总说年轻人这不行那不行的。
但我碰到的这个，
比谁都会办事。

礼拜一，我还去。
给他擦玻璃。
