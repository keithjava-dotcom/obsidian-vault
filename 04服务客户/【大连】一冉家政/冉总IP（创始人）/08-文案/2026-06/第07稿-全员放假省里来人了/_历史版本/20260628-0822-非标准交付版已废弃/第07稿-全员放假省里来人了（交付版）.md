# 第07稿「全员放假省里来人了」

## 柯老师导戏卡

- **这条是讲给谁看的**：对家政行业有偏见的人；想进入家政行业但犹豫"这行到底有没有前途"的人
- **他/她现在卡在什么处境里**：听别人说干家政就是伺候人、没门槛、干不出名堂——他犹豫要不要信
- **你为什么今天非说这件事**：省里刚授完牌——这不是一张纸，是你选的路被看见了。趁热砸出商业信号
- **你不是在上课，而是在**：打偏见。用事实告诉那些人——家政行业正规军的标准已经立起来了
- **第一口气**：对抗——"谁再跟你说干家政就是买块抹布伺候人"
- **必须讲清的3-5个点**：
  1. 授牌=资格证报考直通车——正规的，不是外面糊弄人的
  2. 主任原话：你们场域符合省里考点标准——这句话比我赚十万还提气
  3. 标准化不是口号——链接一老一小，背后是家庭，糊弄不起
  4. 下一步：双进家培训总考执行 + 帮女性拿证上岗 + 帮人低成本创业
  5. 砸锤：低端出苦力的没饭吃了，未来拿专业和资质说话
- **不能讲成**：新闻稿、感动中国、朋友圈早安、招商路演
- **拍的时候先想象的画面**：冉总在办公室，牌匾摆在桌上或者拿在手里。硬气、自豪、不表演不煽情。像刚接完省里的电话，出来跟旁边的人说——你知道这意味着什么吗
