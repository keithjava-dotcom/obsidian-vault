# 第03稿 · 星加坡社区，我们自己打进去的

这周四，进一个社区。
大连本地的，星加坡。

"星加坡"不是新加坡——没有"新"字。

之前在别的社区上，我们都有沟通过
有的嘴上说好，后面推不动。

其实很简单：你们社区老百姓，99块钱做一次家庭保洁，能不能接受？

推开社区办公室的门，书记坐对面。
墙上挂着网格化管理图，密密的名字和电话。

我把方案摊桌上——一张A4纸，手画了几笔。没带PPT。
我跟他说：你不用现在答应我。你帮我问问你们楼长。问完了再跟我说行不行。

书记翻了翻本子，看了几个数据。抬头说了一个字——能。

我心里有数了。

三十多个楼长，先免费做服务。但不是白送。每个楼长满意了，推15户。

楼长是社区里说话最管用的人。
把你家擦干净了，他嫂子来串门——"谁擦的？"
这不比你发传单管用。

同步在社区里招人。
宝妈、下岗的、想学个手艺的——现场招，现场培训。
培训完，社区的活自己人干。

不是带人进去干完拍屁股走。
是帮这个社区里，长出自己的人。

万一楼长推不动呢？

我想过。
推不动，就做公益。

免费洗100户。
帮三类人——年纪大的老人，在家带孩子的宝妈，上学的孩子。
老人，彻底清洁一次。
宝妈，家政技能培训，让她能挣一份钱。
孩子，教收纳整理——书包、书桌、房间。

100户。成本大概一万。
一万块让整个社区知道一冉，值不值？
值。
周边社区也知道了——下一个进去就好谈了。

好多人觉得进社区得有关系。

不是。
关系是做出来的。
你带着方案进去，不是求着进去。
先给价值，再换信任。

星加坡，我们自己打进去的。周四进场。
下一个社区——也是。
