# 第27稿 · 你以为的麻烦可能是一扇门（IP口语稿）

## 🎬 封面标题建议

1. 麻烦来的时候，你不知道它还带了谁来
2. 他在那面墙前面站了很久
3. 塞翁失马，以前以为是安慰，今天知道是真的

**封面文字**：冉总 · 一冉家政创始人

**平台标题**：公司来了两拨人，其中一个人站了十分钟，今天就拍板了

---

## 🧭 结构走线

```
【两拨人进了门】
→ 不铺垫。第一句砸画面，观众自己会想知道什么人什么事。
"一拨需要我解决问题的。一拨帮我解决问题的。"

【他在教学区站了很久】
→ 帮忙的人里面，有一个没坐下。他停在了一面墙前面。
"帮我们的人里面，有一个人没坐着。他在家电清洗区站着。"

【我还有半个月能用】
→ 他不是被逼的，是主动找路。这个区别很关键。
"上个月休那半个月不知道干什么。刷手机。时间就刷没了。"

【今天见面，当场拍了】
→ 讲了真实情况，不画饼。他听完就说行。
"他说行。8月就学。当场拍板。"

【送走他之后】
→ 那个麻烦我是不想让它发生，但它带了一个人进来。
"塞翁失马这四个字。以前觉得是安慰。今天知道了。"
```

---

## ⚠️ 注意事项

- 坐那说话。刚见完一个人回来的状态。语调不兴奋不平淡——有点感慨，但不煽情。
- 开头「两拨人进了门」不解释特殊事件是什么。语速正常。"两拨人"这个画面观众脑子里会自己补。
- 「他在教学区站了很久」是第一个情绪转点——说到这视线可以偏一下，像在想那个画面。
- 「我还有半个月」这段放慢。冉总在讲一个她欣赏的人——不是可怜他，是觉得这个人有意思。"刷手机。时间就刷没了。"轻放。不加评判。
- 「今天见面」说实话就行。不是吹牛——他问了，你讲了，他拍了。
- 收尾「送走他之后」不是总结——是真实内心。"我是真不想让它发生。但它发生了。"这两句之间停半秒。
- 🎤 那面墙上到底有什么让他停下来？拍的时候现场说一句。
- 🎤 聊到哪个点他说"8月就学"的？那个瞬间什么感觉？拍的时候现场说。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。冉总理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

前两天公司来了两拨人。
一拨需要我解决问题的。
一拨帮我解决问题的。

那天的气氛你是知道的。
特殊事件。
两边人坐进来，说实话有点头大。

但我注意到一个细节。
帮我解决问题的人里面，有一个人没坐在那。
他在我们家电清洗教学区站着。

那面墙天天在那摆着。
我自己都看习惯了。
但他在那站了很久。

后来他走过来问我。
冉总，家电清洗学了能接单吗。

我说能。
我们现在缺的就是干得了的人。

他说他每个月能休半个月。
上个月休那半个月，不知道干什么。
刷手机。时间就刷没了。

他想学个手艺。
接单赚钱。

他不是那种"我干不下去了想转行"的。
他是"我还有半个月可以用"。

我说好。约今天聊。

今天一见面，聊得特别投缘。
我跟他讲了这行的真实情况。
不画饼。
讲完了。
他说行。8月就学。

当场拍板。

送走他之后我坐那想。

两天前那个特殊事件。
我是真不想让它发生。
但它发生了。

它还带了一个人进来。
这个人如果不来公司，看不见那面墙。
看不见那面墙，没有今天这个决定。

塞翁失马这四个字。
以前觉得是安慰。
今天知道了。
是真的。
