## 🧭 结构走线

```
【开场】
月度总结里突然跳出这句话——什么都没铺垫
"写到第三段，中间有一句话——不在烂人烂事里消耗。"

【代价】
被自己选的合伙人举报起诉——这句话从格局变成了咽下去的东西
"不是竞争对手。不是外面的什么人。合伙人。她自己选的。"

【行动】
咽下去之后手上没停——四个数字一口气砸下来
"78个课时。270多套。九层楼。200套新房。"

【验证】
看明白了才选择不消耗——不是傲慢，是一件一件事验出来的
"表面高知实则低维。正因为看明白了，才选择不消耗。"

【收束】
不是问观众，是让她问自己
"你说值多少钱。"
```

## ⚠️ 注意事项

1. 别演委屈。被举报起诉那段——说到"不是外人"和"她自己选的"的时候，口气越轻越对。这不是控诉，是陈述事实。
2. 数字那段不要赶。78个课时、270多套、九层楼、200套——一句一个数字，每个数字后面留半秒气口，让观众有时间消化。
3. "你算算"三个字轻说。像在跟朋友摊账本，不是质问也不是炫耀。
4. "表面高知实则低维"——不说教，不judge。说的是她验证过的事，不是她的偏见。
5. 最后一句"你说值多少钱"——看着镜头，停两到三秒，说完就走。别等答案。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。

前两天在写月度总结。四段话。培训、服务、资方、还有对一些事自己的看法。

写到第三段的时候，中间有一句话——不在烂人烂事里消耗。

写的时候没当回事。就是一句总结嘛。

但你如果知道，说这句话的人经历过什么——她刚被自己选的合伙人举报起诉。

不是竞争对手。不是外面的什么人。合伙人。她自己选的。

那这句话就从总结变成了别的东西。

不是智慧。不是格局。是她咽下去的东西。

委屈。愤怒。想解释的冲动。想反击的念头。全咽下去了。

咽下去之后呢？手上没停。

双进家培训，78个课时。金普、中山、西岗、长海县，四个区，全部跑完。

服务端270多套改造房，正在开荒。明天要去见一个九层楼的企业。月扫三次。签年保。

今天还跟着合伙人去了一个楼盘。200套新房。8月30号交付。

你算算。从被捅那一刀到现在，她做了这么多事。

不在烂人烂事里消耗——不代表看不明白。

她说过四个字，表面高知实则低维。这不是傲慢。是一件一件事验出来的。

正因为看明白了，才选择不消耗。

那句话不是感悟。是伤疤。

值多少钱？值她咽下去那一切之后，手上还捏着的这几件事。

你说值多少钱。
