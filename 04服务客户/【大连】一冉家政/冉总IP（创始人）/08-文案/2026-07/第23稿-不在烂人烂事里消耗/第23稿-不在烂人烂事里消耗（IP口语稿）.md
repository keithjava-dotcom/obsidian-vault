## 🧭 结构走线

```
段1｜开场·放这句话｜0:00-0:25
前两天在写月度总结。四段话。培训、服务、资方、还有对一些事自己的看法。写到第三段的时候，中间有一句话——不在烂人烂事里消耗。写的时候没当回事。就是一句总结嘛。
→ 逆向悬疑开篇：先把这句话放出来，没有任何背景交代。观众以为她要分享月度总结——实际上是在给后面埋钉子。语气要日常、轻描淡写，像在跟朋友闲聊。

段2｜代价·烂人烂事是什么｜0:25-0:55
但你如果知道，说这句话的人经历过什么——她刚被自己选的合伙人举报起诉。不是竞争对手。不是外面的什么人。合伙人。她自己选的。那这句话就从总结变成了别的东西。不是智慧。不是格局。是她咽下去的东西。委屈。愤怒。想解释的冲动。想反击的念头。全咽下去了。
→ 重量翻转：一句话从"智慧总结"瞬间被真相压成"血换的"。不控诉不哭诉——只陈述事实。那句"她自己选的"是刀口——不是说给别人听，是说给自己听。越平静越有分量。

段3｜行动·咽下去之后做了什么｜0:55-1:35
咽下去之后呢？手上没停。双进家培训，78个课时。金普、中山、西岗、长海县，四个区，全部跑完。服务端270多套改造房，正在开荒。明天要去见一个九层楼的企业。月扫三次。签年保。今天还跟着合伙人去了一个楼盘。200套新房。8月30号交付。你算算。从被捅那一刀到现在，她做了这么多事。
→ 数字冲击波：四个核心数字一口气压下来。前面太克制了，这一段把能量释放。一句一个数字，每个数字后面留半秒气口，让观众跟着算账。不是炫耀营业额——是被捅刀之后还在往前走的物证。"你算算"轻说，像在跟朋友摊账本。

段4｜验证·她看懂了什么｜1:35-1:55
不在烂人烂事里消耗——不代表看不明白。她说过四个字，表面高知实则低维。这不是傲慢。是一件一件事验出来的。正因为看明白了，才选择不消耗。
→ 防守：这句话可能被误解为"高高在上评断别人"。用"一件一件事验出来的"化解——不是偏见，是实证。跟段2的"咽下去"形成闭环——先消化自己，再看懂别人。

段5｜收束·这句话值多少钱｜1:55-2:15
那句话不是感悟。是伤疤。值多少钱？值她咽下去那一切之后，手上还捏着的这几件事。你说值多少钱。
→ 半问句收口：不替观众下结论。问题抛出去，让观众自己在心里算。最后一句"你说值多少钱"——看着镜头，停顿两到三秒，说完就走。不是问观众，是让她问自己。
```

## ⚠️ 注意事项

- 别演委屈。被举报起诉那段——说到"不是外人"和"她自己选的"的时候，口气越轻越对。这不是控诉，是陈述事实。
- 数字那段不要赶。78个课时、270多套、九层楼、200套——一句一个数字，每个数字后面留半秒气口，让观众有时间消化。
- "你算算"三个字轻说。像在跟朋友摊账本，不是质问也不是炫耀。
- "表面高知实则低维"——不说教，不judge。说的是她验证过的事，不是她的偏见。
- 最后一句"你说值多少钱"——看着镜头，停两到三秒，说完就走。别等答案。
