# 第26稿 · 急活找你才是真口碑（IP口语稿）

## 🎬 封面标题建议

**三个候选（只写标题）：**

1. 急活为什么第一个想到你
2. 去年洗了次玻璃，今天电话打回来了
3. 部队大院来电话了

**封面文字**：冉总 · 一冉家政创始人

**平台标题**：急活电话来了，对接的人说：第一个想到的就是你

---

## 🧭 结构走线

```
【这种又急又难的，第一个想到的就是你 · 0:00-0:18】
→ 电话直接砸进来。对接人的原话就是开场，别铺垫任何事情。
"第一个想到的就是你。"

【去年就洗过一次 · 0:18-0:35】
→ 回头补。当时觉得就是个普通玻璃活，干完就完了。这是"顺"——别渲染，平着讲就行。
"就是个普通活。干完就完了。"

【楼顶没有固定点 · 0:35-0:55】
→ 到现场发现坎了。吊板下不去。这是整篇的低谷。停顿要留够。
"换了一般公司，到这就结束了。不是不想接，是接不了。"

【我们是干过抢工的人 · 0:55-1:15】
→ 情绪转折。不喊不叫，用事实点燃——锅炉厂房开荒、270多套同时进场。
"高空车我们有。人我们有。随时能调。"

【有一瞬间我在想 · 1:15-1:35】
→ 干完坐下来，脑子里冒出来的念头。这是整篇的心脏——不是"我们很厉害"，是"去年那个普通活，今天救了一次急"。
"如果去年那个玻璃我没洗呢。如果那天随便糊弄过去了，今天这个电话是谁接的。"

【收尾 · 1:35-1:42】
→ 一句话。别解释。
"口碑不是好评。是你急了的时候第一个想到谁。"
```

---

## ⚠️ 注意事项

1. **前半段故意压着讲**——"去年就是个普通活，干完就完了"要平淡，不要有情绪。就是为了让后面"吊板下不去"那一刻掉下去。前面越平，后面越扎人
2. **"我们是干过抢工的人"这句要收紧下巴**——不是炫耀，是陈述自己经历过什么。锅炉厂房开荒、270多套，这两件事她真干过，说出来就有分量
3. **"有一瞬间我在想"是整篇唯一的情感释放**——前面全是事实，到这里才把心打开。这句她可以慢一点，甚至可以笑一下再说
4. **别踩同行**——"换了一般公司到这就结束了"是事实，不是说别人不行。后面紧接"不是不想接，是接不了"就是在降火

### 🎤 开拍时补讲

- 高空车升上去开始作业那一刻，你站在底下看着，心里什么感觉？
- 去年给他们洗玻璃那次，当时觉得就是个普通活吧？干完就走了？有没有想过一年后电话会打回来？

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。冉总理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

对接的人说，这种又急又难的，第一个想到的就是你。
部队大院，楼体长了苔藓泥灰，上级要来检查，今天必须干出来。

去年给他们洗过一次玻璃。厨房也洗了。
就那一次。
我当时觉得，就是个普通活，干完就完了。

一年后电话又来了。
带刘总去看现场。两层楼。楼顶没有固定点。吊板下不去。
换了一般公司，到这就结束了。不是不想接，是接不了。

但我们是干过抢工的人。
锅炉厂房开荒干过。270多套同时进场也干过。
高空车我们有。人我们有。随时能调。
当场报价，定方案，领导那边批了，我们车就动了。

下午一点进场。上面开始干，我在底下看着。

干完了我坐了会儿，喝了口水。
有一瞬间我在想，如果去年那个玻璃我没洗呢。如果那天随便糊弄过去了，今天这个电话是谁接的。

口碑不是好评。是你急了的时候第一个想到谁。
