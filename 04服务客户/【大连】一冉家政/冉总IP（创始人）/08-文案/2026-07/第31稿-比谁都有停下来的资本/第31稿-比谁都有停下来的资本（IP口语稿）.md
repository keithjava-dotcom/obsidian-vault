# 第31稿-比谁都有停下来的资本（IP口语稿）

## 🎬 封面标题建议

- 比谁都有停下来的资本
- 壹冉，你不累吗
- 签几万块不兴奋，看他们签一万块开心

**封面文字**：王壹冉

**平台标题**：我比任何人都有停下来的资本。但没停。有人问我"壹冉你不累吗"。我愣了一下。

---

## 🧭 结构走线

```
【开场 · 0:00-0:06】
→ 第一口气直接砸。反常识——有条件停但没停。勾住再给场景。
"我比任何人都有停下来的资本。但我没停。"

【场景+问题 · 0:06-0:15】
→ 睡前。群消息。有人问。三下交代完。
"晚上八点。刚到家。群里有人问我。壹冉。你不累吗。"

【愣住+爸妈 · 0:15-0:38】
→ 被问愣住。第一反应不是回答——是想到爸妈。一个具体记忆替代"条件好"。
"我愣了一下。想到我爸妈。去年过年回去。他们没问我公司怎么样。就问我吃了没。"

【没说 · 0:38-0:52】
→ 两个"没说过"——第一次是对爸妈，第二次是对外人。越短越重。
"但我从没说过。不想干了。"

【兴奋 · 0:52-1:20】
→ 全篇最高点。一个动作一个画面——不是"有兴奋劲"，是"转一圈"。
"转了一圈。给每人都看了一眼。那是真的高兴。"

【山谷 · 1:20-1:55】
→ 摔下去。不是总结"不兴奋了"——是签完放一边就开会。低谷多沉一层：不确定能不能成。
"签了。放一边。接着开会。有时候也在想。这事能不能成。不知道。"

【转折 · 1:55-2:30】
→ 往上走。不是"看到他们签单"——是往上滑的动作、截图内容、一排恭喜。
"有人发了一张截图。一万块。入户签约。下面一排恭喜。"

【收口 · 2:30-2:50】
→ 不总结不升华。发现的口气，不是宣布。
"我自己签的反而没什么感觉了。第一年的我不会懂。现在懂了。"
```

---

## ⚠️ 注意事项

- **腔**：回想。不是解释不是上课。从"转了一圈"开始——那是全篇唯一嘴角上扬的地方；到"放一边接着开会"——不是叹气，就是那样了；到"一排恭喜"——心里动了一下。
- **过山车**：砸脸开场→愣住→爸妈记忆（暖）→第一年兴奋（全篇最高）→现在签完就过了（摔）→不确定能不能成（沉）→群里截图（心里动了一下）→落地。隔两行一个冲突点。
- **换行**：一句一行。行间不空行。

但我没停。

群里有人问我。

壹冉。你不累吗。

想到我爸妈。
就我一个。

去年过年回去。
他们没问我公司怎么样。
就问我吃了没。
瘦了没。

就好像我做什么。
不做。
都行。

但我从没说过。
不想干了。

以前签第一单的时候。
几万块。
我在办公室转了一圈。
给每人都看了一眼。
那是真的高兴。

现在。
几万块的订单。
签了。
放一边。
接着开会。

这事能不能成。
不知道。

但是没想过停。

我打开合伙人造富群。
往上滑。

有人发了一张截图。
一万块。
家政保洁。
入户签约。
下面一排恭喜。

我看了很久。

比我自己签了多少钱。
还高兴。

我自己签的。
反而没什么感觉了。

第一年的我不会懂。
现在懂了。
