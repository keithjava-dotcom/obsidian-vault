# 第32稿-签完放一边，接着开会（IP口语稿）

## 🎬 封面标题建议

- 签完，放一边，接着开会
- 壹冉，你不累吗
- 第一年我比现在兴奋多了

**封面文字**：王壹冉

**平台标题**：晚上八点到家开会。有人问我壹冉你不累吗。我想了一下。我是真的有停下来的资本，但我选了拼。第一年签几万块兴奋得不行，现在签完就过了——我打开群里，看到别人签一万块的单子，比我自己的还高兴。

---

## 🧭 结构走线

```
【开场 · 0:00-0:10】
→ 直接进场景。两句话交代完。
"晚上八点到家。开了腾讯会议。有人问我。壹冉你不累吗。"

【愣住+我有的选 · 0:10-0:28】
→ 被问愣了。不是诉苦——是陈述事实：我有的选。
"我想了一下。我跟别人不一样。我是真的有停下来的资本。女孩子。独生子女。家里条件不说好。但也不差。"

【选了就得认 · 0:28-0:52】
→ 从"可以不拼"到"但选了"。两件事：选→认→负责。不确定成不成但不放。
"我本可以不拼的。但这是我自己的选择。选了就得认。认了就得负责到底。这件事能不能成。我不知道。但我不会因为难就放。"

【意义反转 · 0:52-1:12】
→ 一个人的成功不算成功。帮别人成才算。
"再说了。一个人的成功。算什么成功。如果我能帮到别人。让别人也成。那才是努力真正的意义。起心动念是正的。结果会替你买单。"

【兴奋点转移 · 1:12-1:40】
→ 全篇核心。不兴奋了→打开群→往上滑→看到别人签单→开心。动作推进。
"我真的觉得。现在你让我签几万块的单子。我不像第一年那么兴奋了。但是我打开合伙人群。往上滑。看到有人签了一万块的单子。签了个什么客户。我比自己签了。还高兴。"

【收口 · 1:40-1:45】
→ 不总结不升华。一句落。
"这就是最大的收获。"
```

---

## ⚠️ 注意事项

- **整体腔调**：平静回想，不解释不宣言。像对朋友聊天——被问了一句"你不累吗"，想了五秒才开始说。
- **说到「我跟别人不一样」时**：不是炫耀。就是陈述事实——我是真的有选择不拼的。语气放平。
- **说到「起心动念是正的」时**：这句话别人说出来是口号，她说出来是对自己选的这条路的最短解释。不要加重语气。
- **说到「我不像第一年那么兴奋了」时**：不是叹气、不是丧。就是发现了这件事。像在讲一个自己都没注意到的变化。
- **说到「往上滑」「签了个什么客户」时**：这里有画面——打开群、手指往上滑、看到截图。说的时候脑子里真有这个画面。
- **收口不总结**：「这就是最大的收获」说完就停。不要多加一句。
