# 第30稿 · 两百多人的组织，是他在带（IP口语稿）

## 🎬 封面标题建议

1. 两百多人的组织，是他在带
2. 他在公司等了半个多小时，空调坏了
3. 对的人怎么都会走到一起

**封面文字**：冉总

**平台标题**：今天去见李院长。苏总说有个朋友想见。做装修的。两百多人的一个组织，他在带。现在半待业状态。我以为等不了那么久。回来他还在。坐下来聊。聊完就一个感觉。对的人怎么都会走到一起。

## 🧭 结构走线

```
【开场】
→ 数字砸。两百多人的组织+带头的这个人。制造好奇：他现在怎么在我公司。
"两百多人的一个组织。他在带。做装修的。"

【他的状态】
→ 反差。带两百多人的人，现在半待业。苏总介绍的。
"现在半待业状态。苏总介绍的。"

【等】
→ 具体场景。我不在。以为走了。回来人还在。热。但这个细节不能煽情。
"我今天在外面。去见李院长。以为他等不了那么久。"

【满头是汗】
→ 一个细节让人记住——空调没开。但他不在乎。
"推开公司门。人还在。两个人满头是汗。空调没开。"

【坐下来聊】
→ 老乡。聊了很多。他之前就知道我。
"也是黑龙江的。聊了很多。以前。现在。以后。"

【互相认可】
→ 有能量的人。但现在也在找方向。跟我一样。
"有能量的人。有号召力。但他现在也在找方向。"

【收口】
→ 自己的感悟。不是结论。念头。
"对的人怎么都会走到一起。不对的人硬捏也捏不住。"
```

## ⚠️ 注意事项

1. 开头数字砸完不要停
2. 空调那段别煽情——说事实就行。他不在乎，你也别替他感慨
3. 收口往下落。是念头不是金句
