# 第30稿-两百多人的组织（IP口语稿）

## 🎬 封面标题建议

- 两百多人的组织，他在带
- 干了很多年，突然半待业了
- 江湖再见，来的还是那些人

**封面文字**：王壹冉

**平台标题**：一个带两百多人组织的大哥，半待业了。等了我很久。坐下来聊完，他说没见面之前就听说过我。

---

## 🧭 结构走线

```
【开场 · 0:00-0:12】
→ 第一句就砸数字。不介绍自己，不铺垫。观众被数字勾住了再往下说。
"两百多人的组织。他一个人带。"

【消息 · 0:12-0:22】
→ 你在外面。消息进来了。你说回来再说——以为很快就能回来。
"苏总跟我说的时候。我在外面。"

【推开门 · 0:22-0:42】
→ 推开门看见的画面。热的。在等。没走。你心里动了一下但嘴上没说。
"衣服湿透了。脖子上全是汗。"

【聊开了 · 0:42-1:00】
→ 聊的内容不报流水账。只留两个钩子——老乡（关系近了）和他那句原话。
"没见面之前就听说过王壹冉。"

【心里动了一下 · 1:00-1:20】
→ 不是因为高兴。是一个你没想到的事实——有人在看。
"你以为你在外面跑。没人看。"

【收口 · 1:20-1:40】
→ 不总结。不升华。回看那个人——等了很久，没说什么。最后六个字落回自己。
"善良。带点锋芒。"
```

---

## ⚠️ 注意事项

1. **口气**：坐着说的。回想一个下午。不是汇报、不是讲课。说到哪算哪，允许自己顿一下。
2. **情景重建**：7月28号。你匆忙赶回来。苏总说有个朋友想见你。你说回来再说——以为很快。推开公司门——人没走。热成那样。你心里动了，但嘴上说的是"不好意思"。把那一刻找回来。
3. **别拍歪**：不是宣传、不是讲课、不是煽情。
4. **不暴露身份**：不用说老大哥具体是谁、什么组织。
5. **🎤 采集**：「名不虚传」是什么语境下说的？聊开了之后有没有哪句话让你心里动了一下？送走他之后你一个人想了什么？

有能量。有号召力。
