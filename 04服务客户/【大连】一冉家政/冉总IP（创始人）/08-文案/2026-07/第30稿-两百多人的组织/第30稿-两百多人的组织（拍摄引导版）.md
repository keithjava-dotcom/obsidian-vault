# 第30稿-两百多人的组织（拍摄引导版）

## 🎬 封面标题建议

- 两百多人的组织，他在带
- 我去见了李院长，他躺在那等我
- 江湖再起时，来的人还是那些人

**封面文字**：一冉家政 王壹冉

**平台标题**：一个带两百多人组织的老大哥，现在半待业。在我公司等了一个小时。满头是汗。

---

## 🧭 结构走线

```
【开场 · 0:00-0:12】
→ 数字直接砸，别铺垫。停顿一秒再说"他在带"。
"两百多人的组织。他在带。做装修的。现在半待业了。"

【人来了 · 0:12-0:25】
→ 讲那天你在哪——见了谁，什么事绊住了。自然带出苏总和这位大哥。
🎤 穿插（开放式·问冉总）：那天见李院长是什么事？花了多久？你当时想的是"回来再说"还是"今天怕是见不到了"？
"那天我在外面。见李院长。苏总说有个朋友想见一见。做装修的。我说回来再看。"

【等在那里 · 0:25-0:45】
→ 推开门那个画面——人没走。重点不在空调，在"他竟然还在"。
🎤 穿插（开放式·问冉总）：你推开门的瞬间，心里第一反应是什么？是"啊他还在"还是"坏了让人家等这么久"？他跟苏总坐在那是什么状态？热的程度你说一个细节。
"回来以后。推开公司门。人还在。苏总也在。两个人。满头是汗."

【不好意思 · 0:45-0:55】
→ 空调那件事——说真话，别美化。他坐那说没事，这不煽情。
"空调没开。林总助忘了检查。我说不好意思。他坐在那。说没事。"

【坐下来聊 · 0:55-1:15】
→ 聊的什么不说太细。重点是——聊着聊着发现，原来是老乡。节奏从紧张到放松。
🎤 穿插（开放式·问冉总）：坐下来从哪一句开始就不觉得尴尬了？聊的过程中有没有哪句话让你心里动了一下？
"坐下来聊。曾经、过往、现在、未来。一聊。也是黑龙江的。老乡。"

【他听说过我 · 1:15-1:35】
→ 这块是情绪的转折点——原来我不在的时候，有人在看。口气要轻，不是得意。
🎤 穿插（半开放式·问冉总）：他具体说"没见面之前就听说过"是在什么语境？是在夸你的事，还是夸你的人？他说的时候你的感受是什么——被看见？还是有点意外？
"他说。没见面之前就听说过王壹冉。今天见了。果然名不虚传."

【脑子里冒出来的念头 · 1:35-1:55】
→ 别总结。别教做人。就是坐下来之后脑子里自然冒出来的东西。像跟朋友聊完天回家的路上在想。
🎤 穿插（开放式·问冉总）：送走他之后你一个人在想什么？有没有一个念头一直在脑子里转？"对的人怎么都会走到一起"这句话是你当时想的，还是后来总结的？
"对的人。艰难险阻也会走到一起。不对的人。强捏在一起也会散。"

【收口 · 1:55-2:10】
→ 最后一句。不解释。不扣题。说完就停。
🎤 穿插（开放式·问冉总）：你说"善良里带点锋芒"——这句话在你心里是谁的形象？是你对自己的要求，还是你在说这个大哥？
"善良。带点锋芒。"
```

## ⚠️ 注意事项

1. **情景重建**：7月28号那个下午。你匆忙见了李院长回来，想着苏总介绍的人可能走了。推开门——人还在。把那天的身体感觉找回来：你进门的时候热吗？是热还是闷？坐下来聊的时候，是办公桌对面，还是沙发上？

2. **口气**：淡淡地说。不激动、不总结、不升华。你是在回想一个下午，不是在"讲一个道理"。

3. **三个不拍歪**：
   - 不拍成公司宣传腔（"看，多厉害的人都来找我了"）
   - 不拍成道理总结腔（"所以创业最重要的是…"）
   - 不拍成感动煽情腔（"那一刻我热泪盈眶"）

4. **那段话不用背**：到"老乡"之后，后面的都是你脑子里会自然冒出来的东西。不用想结构，就是顺序往下说。

5. **穿插问题**：上面走线里🎤标注的问题，拍之前让助理问一遍。不用回答我——你的回答就是素材，拍完我根据你的回答写正式稿。

6. **采集单向题**（拍完顺手记）：
   - 具体等了多久？
   - 他的组织具体做什么角色？
   - 聊的过程里有没有哪句话让你印象特别深？
