# 第29稿 · 一个老大哥（IP口语稿）

## 🎬 封面标题建议

1. 他做工程机械的时候，我还在体制内上班
2. 一个老大哥坐我对面，聊了两个多小时
3. 环境不好，但不是所有人在等

**封面文字**：冉总

**平台标题**：今天见了一个人。黑龙江的老乡。他以前做工程机械的。当年房地产最好的时候，生意做得很大。后来一夜之间，地产不行了。他没有停。去了别的行业，从头开始。今天坐下来，聊了两个多小时。

## 🧭 结构走线

```
【开场】
→ 时间差砸出来。他当年风光的时候我在上班。制造悬念：这个人今天怎么会坐我对面。
"他做工程机械的时候。我还在体制内上班。"

【风口】
→ 不是说他多厉害。是说"真忙成那样"——让观众看见画面。
"那几年赶上房地产最好的时候。做得是真大。设备一批一批往外拉。"

【一夜之间】
→ 整个行业没了。关键不是行业垮了，是跟他同一批的人的反应。
"后来地产不行了。一夜之间的事。跟他一批的。回老家的回老家。在家待着的在家待着。"

【他没停】
→ 别人不动了，他去干了完全陌生的行业。从零开始。
"他没有。去做了机器人代理。没干过的行业。从头摸。"

【坐下来】
→ 今天聊了什么。两个方向。不提结果，只提过程。
"今天坐下来。聊了两个多小时。带了东西来的。"

【同频】
→ 不是客套。是具体的事一件一件都对上了。
"聊着聊着我就一个感觉。同频。他想的跟我想的。不谋而合。"

【互相看见】
→ 他经历过风口也经历过低谷。反过来也在我身上看到东西。
"他上过风口。也从风口上掉下来过。不管什么环境都在动。"

【收口】
→ 自己的念头。不是结论，是聊完之后脑子里冒出来的。
"聊完他走了。我坐那想了很久。环境不好。但不是所有人在等。"
```

## ⚠️ 注意事项

1. 开头不铺垫
2. 别说教
3. 结尾往下落。是念头不是总结
