# 第28稿 · 贵人不是运气，是你往上走的时候（IP口语稿）

## 🎬 封面标题建议

1. 你趴在地上的时候，贵人也看不见你
2. 贵人不是运气
3. 跟一拨人走到一半，走散了

**封面文字**：冉总 · 一冉家政创始人

**平台标题**：最近处理了很多事，今天遇到了一个人，他说了几句话

---

## 🧭 结构走线

```
【事情不难，难的是人】
→ 开门就进。不解释什么事。让经历过的人自己代入。
"跟一拨人走到一半，走散了。"

【人在局里看不清】
→ 这话是冉总自己的——「当局者迷」的口语版。说到这语气放低。
"站在各自的角度，都觉得自己对。"

【今天遇到了一个人】
→ 不是正式场合，很平常。朴素到观众会好奇——这么平常，能改变什么？
"就聊了一会。很平常的对话。"

【心里那团东西松开了】
→ 收慢。不是被感动哭，是「通了」的感觉。允许留白。
"是我有能力自己看清楚了。"

【贵人不是运气】
→ 翻转。魂在这——贵人不是命好，是你在往上走。
"跟着苍蝇找厕所。跟着蜜蜂找花朵。"
```

---

## ⚠️ 注意事项

- 这条不是对镜头说话，是关上门坐下来跟自己说话。全程内心独白语气。
- 语调收着。不是倾诉，是回想——事情过了，坐下来理一理。
- 「越想看清越看不清」是第一句有情绪重量的词。放慢。冉总说这句的时候应该像在跟自己确认。
- 「今天遇到了一个人」这句之前停半拍。前面的都是缠在一起的乱麻，到这突然静了。
- 「心里那团东西松开了」——不用形容词解释"松开了"是什么意思。冉总自己知道，观众也知道。
- 「跟着苍蝇找厕所跟着蜜蜂找花朵」说出来会有观众反应——等半秒。后面接"以前觉得是骂人的，今天知道是实话"——笑完之后那一下是重点。
- 最后一句「我没有趴下」轻放。不拔高不煽情。就这一句，说完。
- 🎤 那个人说了什么让心里松开的？拍的时候如果方便现场补一句。不便补就保持模糊——稿子现在的写法不影响。
- 坐那拍。不要走动。不要B-ROLL。这条就是冉总一个人的脸。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。冉总理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

最近在处理一些事情。
事情不难。难的是人。

跟一拨人走到一半，走散了。
不同频。
站在各自的角度，都觉得自己对。

人在局里的时候是看不清的。
越想看清，越看不清。

今天遇到了一个人。

不是正式见面。
就聊了一会。
很平常的对话。

但他说了几句。
我心里那团东西松开了。

不是告诉了我什么道理。
是我有能力自己看清楚了。

他走之后我坐那想。

如果我是以前那个我。
遇到事只会硬刚。
他跟我说什么，我听不进去。

但这次我听进去了。

贵人不是运气。
是你在往上走的时候，他刚好路过。
你趴在地上他也看不见你。

跟着苍蝇找厕所。
跟着蜜蜂找花朵。

这句话以前觉得是骂人的。
今天知道是实话。

你在哪个圈子里。
就会遇到什么样的人。
能接住什么样的帮助。

最重要的不是他出现了。
是他出现的时候，我没有趴下。
