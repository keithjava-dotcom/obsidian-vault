# 第28稿 · 贵人不是运气，是你往上走的时候（IP口语稿）

## 🎬 封面标题建议

1. 贵人不是你命好，是你在往上走
2. 他在你身边，你心就定了
3. 跟着苍蝇找厕所，跟着蜜蜂找花朵

**封面文字**：冉总 · 一冉家政创始人

**平台标题**：跟一拨人走不下去了，今天有个人让我想通了

---

## 🧭 结构走线

```
【最近一堆事】
→ 0帧起手。混乱感直接砸，不铺垫。
"最近一堆事。全搅在一起了。"

【走不下去了】
→ 不在怪谁——说"人在局里看不清自己"这个状态。
"人在局里的时候你看不清。你觉得全是对方的问题。但你不是他。"

【今天有个人】
→ 贵人出场。写他怎么听，不写他是谁。安安静静地听你讲完。
"今天有个人跟我说了几句话。不是来教育我的。我把最近这些事从头讲了一遍。"

【他让你安静】
→ 不说对方多厉害——说自己的感觉。很久没感受过这种定了。
"你跟他待在一起，心就是定的。不是兴奋。是那种让你终于能安静下来的感觉。"

【是我没停】
→ 翻转收束。不是运气好遇到贵人——是你没停才会被看见。
"这个人不是运气。是我在最乱的时候没停。我要是停了，他路过也看不见我。"

【跟着苍蝇找厕所】
→ 烟火气收口。以前那个圈子只会互相撕，换了圈子遇到的是让你静下来的人。
"以前那个圈子里，遇到事只会互相撕。你撕我我撕你，撕完了问题还在。换了圈子之后不一样了。"
```

---

## ⚠️ 注意事项

- 关上门跟自己说话。不是发表感言，不是正能量演讲。语调：回想——有点感慨但不煽。
- 开头「最近一堆事」正常语速，像跟熟人讲"你猜我最近怎么着"。
- 「走不下去了」第一个情绪下沉点。"但你不是他"这句是醒悟，不是指责。
- 「今天有个人」转机来了不抬高音量。讲一个她尊重的人，不是吹。说到"他就在那听着。安安静静地听"——这个细节是关键：贵人不是教你，是让你说。
- 「他让你安静」是全稿的核。"很久没有这种感觉了"停一拍。说到"终于能安静下来"声音放轻。
- 「是我没停」翻转收束。说到"他路过也看不见我"是说给自己听的，不教观众。
- 「跟着苍蝇找厕所」语气一转。烟火气上来。"撕完了问题还在"——说的时候带一点"现在回头看真挺傻的"。
- 🎤 把事从头讲了一遍——拍的时候说一两句具体是什么事，给观众锚点。
- 🎤 他安安静静听完后说的那几句是什么？不方便复述原话就算了，但可以说个方向。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。冉总理解了讲戏卡之后，用自己的话说。现场有感觉的地方自由发挥，方向不跑偏就行。

最近一堆事。
全搅在一起了。

之前跟一拨人因为想的不一样。
走不下去了。

人在局里的时候你看不清。
你觉得全是对方的问题。
但你不是他。
你看不到他那一边。

今天有个人跟我说了几句话。

不是来教育我的。
也不是来安慰我的。
我把最近这些事，从头讲了一遍。
他就在那听着。
安安静静地听。

然后他说了几句。
不是劝我别往心里去那种。
是帮我把心里那团东西，一根一根理开了。

他这个人有一点不一样。
你跟他待在一起，心就是定的。

不是那种让你兴奋的人。
是那种让你终于能安静下来的人。

我很久没有这种感觉了。
就是身边坐一个人。
什么都不用说。
你就踏实了。

后来他走了。
我坐那想。

这个人不是运气。

是我在最乱的时候没停。
我要是停了，他路过也看不见我。

跟着苍蝇找厕所。
跟着蜜蜂找花朵。

不是骂谁的意思。
是你得往对的方向走。

以前那个圈子里，遇到事只会互相撕。
你撕我我撕你。
撕完了问题还在。

换了圈子之后。
你遇到的是能让你静下来的人。

走着走着，对的人就出现了。
