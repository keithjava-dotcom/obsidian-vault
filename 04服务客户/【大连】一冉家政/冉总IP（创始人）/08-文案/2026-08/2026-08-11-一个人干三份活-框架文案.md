# 冉总 · 一个人干三份活 · 我带出来的兵样样精通

## 🎬 封面标题建议

封面标题：一个人干三份活，你公司是不是没人了？
封面文字：一冉家政月度例会
平台标题：今天开月度例会，郭总一个人汇报了合伙人、总助、培训老师三个板块。有人问我——你让一个人干三份活是不是公司没人了？我说：哪个优秀的老板创业初期不是样样精通？我带出来的兵，也必须样样精通。

## 🎬 柯老师导戏卡

```
【给谁看】自己做企业的老板、带团队的管理者——尤其是创业初期一个人顶三个人的那种。以及正在纠结"要不要让人多学点"的管理者。
【处境】公司发展期，人手不够，一个人干好几个岗位。外面的人看觉得你公司不行，但你知道这不是缺人，是你要带出能独当一面的兵。
【为什么今天说】今天开了月度例会，郭总一个人汇报了三个板块。两周没开会了，今天开完发现每个人都自己往前跑——这种状态比什么都踏实。
【姿态】开完会的状态，心里是热乎的。不是炫耀团队，是分享一种"我看到了"的踏实感。像坐车里跟旁边人聊今天公司发生的事。
【第一口气】"今天开完月度例会，我心里特别踏实。"——直接入场，不介绍、不铺背景。
【必讲点】
1. 郭总一个人三个身份——有人质疑，这是我的选择
2. 哪个优秀的老板创业初期不是样样精通？所以我带出来的兵也必须样样精通
3. 新媒体部柯总学AI给全员培训、服务部刘总急着去看7500平现场、总助林雪监督执行省心一半——团队自动在转
4. 老板是定海神针。开完会发现大家精神头都不一样
【不能讲成】❌ 炫耀团队 / 自夸"我们公司多好" / 踩同行"你看别的公司就不行" / 给员工打鸡血煽情 / 念员工名册
✅ 今天开了个会，看到了每个人的状态——这种感觉比签了大单还踏实
【画面】办公室会议桌前坐着说的前半段，然后站起来走到窗边说的后半段。窗外下午的光或者傍晚的灯。B-ROLL：郭总汇报时的背影、刘总急着拿包出门、林雪在笔记本上记东西——全是抓拍，不是摆的。
```

## 🧭 结构走线

```
【开场 · 0-10秒】⭐状态锚点+质疑
注：冉总的语感要用"状态锚点"开场——不是"今天我们开了个会"，而是"我心里特别踏实"。观众被"为什么踏实"抓住。马上接质疑——"有人问我：郭总一个人又是合伙人又是总助又是培训老师，你公司是不是没人了？"这个质疑本身是钩子——观众也会这么想。
例："今天开完月度例会，我心里特别踏实。
两周没开会了——上一周在出差，这一周当月度例会来开。
各部门一个一个汇报。
然后有人问我一句话。
他说：冉总，你们郭总一个人又是合伙人、又是总助、又是培训老师——你公司是不是没人了？"

【我的回答 · 10-25秒】
注：先不反驳。先承认——"他确实一个人干三份活。"然后用自己的经历拉平——"我创业初期也是样样精通。"这句话让所有创过业的老板点头。最后给出价值观："所以我带出来的兵，也必须样样精通。"——不是"没人"，是"我要这样的人"。
例："我说——他确实一个人干三份活。
但哪个优秀的老板，创业初期不是样样精通？
我当年也是这样过来的。
所以我带出来的兵，也必须样样精通。
不是没人。是我要的就是这样的人。"

【团队自动在转 · 25-50秒】⭐峰值的佐证
注：不一个一个介绍员工——观众不关心你员工叫什么。每个人只用一句话+一个画面。新媒体柯总两句话带"学AI+全员培训"——转。服务部刘总用一个动态画面收——"开完会第一个走，因为7500平现场和明天别墅进场等着他"——画面比文字有力量。总助林雪一句话——"有了她真是省心了一半"。这段节奏跟前面的"价值观表态"形成对比——前面是笃定的慢速，这里是快节奏的"你看我们团队在动"。
例："这不，你再看我们团队现在的状态。
新媒体部柯总——有过创业经历，做事认真、有原则。
我们让他研究AI，给全员培训。
服务部刘总——开完会第一个走的。
为什么？因为有一个7500平的现场等着他去看。
明天还有个别墅进场。
所以他汇报的时候那个急啊——急着说完、急着走。
这就是活来了，人在动。
总助林雪——她把监督执行干得非常到位。
工作效率、严谨度，有了她真是省心了一半。"

【落点 · 50-60秒】
注：收尾"老板是定海神针"是冉总原话。不煽情，就是一句判断。最后回到开头的踏实——"开完会发现每个人都在自己往前跑"——和开头的"心里踏实"闭环。结尾用"拭目以待"——冉总风格的四字收尾，不卷大气。
例："什么是一个企业的定海神针？
老板一定是。
你会发现——回来了以后开完会，大家干活的精神头都不一样。
每个人都在自己往前跑。
接下来，让我们拭目以待。
明天关注一下那个别墅进场的老客户——会不会让他失望。"
```

## ⚠️ 注意事项

- "他心里特别踏实"——说的时候自己感受一下那种热乎。不是激动，是踏实
- "你公司是不是没人了？"——带一点点笑意，不是被冒犯
- "我当年也是这样过来的"——声音可以沉一点，是一句轻描淡写但有分量的话
- "急着说完、急着走"说快——刘总的状态要出来
- "老板一定是"——顿一下。这四个字收得笃定
- 禁止：煽情BGM、慢镜头感动、念名册、"感谢我的团队"类口号
