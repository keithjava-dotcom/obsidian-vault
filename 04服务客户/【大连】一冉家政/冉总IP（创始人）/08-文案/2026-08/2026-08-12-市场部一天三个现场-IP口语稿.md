# 冉总 · 市场部一天跑了三个现场 · 我心里特别踏实

## 🎬 封面标题建议

封面标题：140平到2100平，一天跑完
封面文字：一冉家政 · 市场部看现场
平台标题：昨天市场部跑了三个现场：140平样板级开荒、2100平日资工厂、1500平重油污厂房——大的小的脏的严的全看了。看现场，就是一冉接单的第一道关。

## 🎬 柯老师导戏卡

```
【给谁看】大连本地做企业的老板、带团队的管理者——尤其是自己也在跑业务、盯现场的人；以及想看"家政公司到底怎么接单"的普通人。

【处境】很多老板的常态是：业务员在外面跑，自己在家里焦虑——不知道团队是真干还是在混。冉总要讲的是：当老板看到团队一个现场一个现场认真跑的时候，那种踏实，比签单还实在。

【为什么今天说】昨天市场部跑了三个现场：红星海郡墅140平样板级、金州十三里2100平日资工厂、董家沟1500平重油污厂房。三个现场，大的小的脏的严的全有——市场在动，单子在排队，这种状态值得拍。

【姿态】不是汇报工作，是"我看到了"的踏实。像晚上收工坐车里，跟旁边人说说今天这口气顺不顺。不夸团队口号，只讲看见的事实。

【第一口气】"昨天市场部跑完现场回来，我心里特别踏实。"——状态锚点开场，观众想知道：为啥踏实？

【必讲点】1. 当老板的都懂：最怕团队糊弄（共情一句）2. 三个现场各一句，每句带一个看得见的动作：灯罩拆好了等着洗 / 地面不能碰水、金属面不能上刀片 / 油糊到棚顶，搭着脚手架擦 3. 大的小的脏的严的，全看了；能碰什么、用什么药剂、上几个人，回来一项一项列明白 4. 冉总的立场：现场没看明白就报价、进场加钱，是干家政这些年最看不上的 5. 落点：团队在认真做事，我就睡得着觉——四字收尾

【不能讲成】❌ 教学式自问自答（"为啥要看现场？因为…"——死穴）❌ "不是…而是…"扣题总结回马枪 ❌ 报菜名式把三个现场讲成三单生意 ❌ 夸团队喊口号（"我的团队最棒"）❌ 把干活细节讲成刘总单条稿的深度（这里只用动作当证据，不展开工序）✅ 讲"看见"和"踏实"，让画面自己说话

【画面】坐在公司里拍，或者车里拍。语气是收工后的放松，不是打鸡血。说到三个现场可以掰手指头数，说到"睡得着觉"带一点笑。B-ROLL：市场部看现场的照片/视频（有拍就插，没拍不补）。
```

## 🧭 结构走线

```
【昨天跑完现场回来 · 0-8秒】⭐状态锚点
注：冉总的定式开场，从状态进不从事件进。"踏实"和昨天那条的"兴奋"正好错开——一收一放。

例："昨天市场部跑完现场回来，我心里特别踏实。"

【当老板的都懂 · 8-15秒】⭐共情
注：冉总档案标杆句式的用法——共情式自省，不居高临下。一句就把做企业的观众按进座位：最怕的不是活多，是团队糊弄你。市场部真跑没跑，你一听就知道。

例："当老板的都懂，最怕团队糊弄你。市场部跑没跑现场、看没看明白，你一听就知道。"

【他们回来跟我讲 · 15-32秒】⭐三个现场 + 引语血肉
注：三个现场别自己报——借市场部的嘴讲出来（"他们回来跟我讲"），一下就有了画面感。每个现场只带一个看得见的动作：灯罩拆好等着洗（红星海素材）、不能碰水不能上刀片（金州十三里素材）、搭着脚手架擦（董家沟素材）。动作是证据，不是工序科普。

例："他们回来跟我讲：红星海郡墅，140平，业主把全屋灯罩都拆了，就等着咱们去洗。金州十三里，2100平的日资工厂，地面不能碰水，金属面不能上刀片。董家沟，4层楼1500平的重油污厂房，油从地面糊到棚顶，得搭着脚手架擦。"

【大的小的脏的严的 · 32-42秒】
注：四个字把三个现场收成一件事——跨度。"能碰什么、用什么药剂、上几个人"把"理得清清楚楚"落到实处（素材里的物料/人员配置），不是空话。

例："三个现场，一天跑完。大的、小的、脏的、严的，全看了。能碰什么、不能碰什么，用什么药剂、上几个人，回来一项一项都给我列明白了。"

【我干家政这些年 · 42-52秒】⭐冉总的立场
注：从"看了"到"怎么看"。不教学，给立场——现场没看明白就报价、进场就加钱的，是干家政这些年最看不上的。这是冉总见过世面的话，比讲流程硬。

例："我干家政这些年，最看不上的就是那种活——现场都没看明白，价先报了。进场就加钱，最后全是扯皮。一冉的现场，从来不是走马观花。活看得细，报价才准。"

【团队在认真做事 · 52-56秒】⭐老板视角
注：回到"踏实"。不夸口号，就是一句大白话——市场部在跑，服务部在干，团队在认真做事，我就睡得着觉。

例："市场部一个现场一个现场地跑，服务部一单活一单活地干。团队在认真做事，我就睡得着觉。"

【行稳致远 · 56-60秒】⭐四字收尾
注：四字收尾定式。昨天"大有可为"是骄傲，今天"行稳致远"是踏实——情绪区分开。

例："一冉家政，行稳致远。"
```

## ⚠️ 注意事项

- **数字保真**：140平、2100平、1500平、4层、三个现场、一天。其余数字不加
- **三个现场只借动作当证据**：灯罩、刀片、脚手架——点到即止，工序细节是刘总单条稿的菜
- **时态**：红星海郡墅暂定本周二进场，还没施工——这条只讲"看现场"阶段
- **冉总死穴自查**：禁教学式自问自答（"为啥要看现场？因为…"）、禁"不是…而是…"回马枪、禁"首先其次最后"、禁铺垫前置
- **"他们回来跟我讲"是转述不是演**：市场部说的时候那种"活儿到手了"的劲儿，冉总复述时带出来
- **"最看不上的就是那种活"是立场不是骂街**：说的时候是过来人的笃定，不是怼同行
- **结尾四字收尾**："行稳致远"，不加"欢迎咨询/合作私信"
