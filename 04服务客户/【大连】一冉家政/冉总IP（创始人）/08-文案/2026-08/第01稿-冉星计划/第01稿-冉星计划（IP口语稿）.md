# 冉星计划 · 三年前我上门洗油烟机（IP口语稿）

## 🎬 封面标题建议

封面标题：三年前我上门洗油烟机，客户说十年没洗过
封面文字：一冉家政冉总 · 从洗油烟机到冉星计划
平台标题：别人还在猜我们订单怎么来的，我们下一轮已经开始了

## 🎬 柯老师导戏卡

```
【给谁看】想学一门手艺/想进家政行业的人（18-55岁）+ 想合作的伙伴
【处境】冉星计划启动第一天，你站在培训场地里
【为什么今天说】今天正式启动冉星计划，技能培训开课招生，这事值得说
【姿态】不是招商PPT，是跟人唠你这三年怎么过来的——从上门洗油烟机唠到今天
【第一口气】"22年，我拎着机器上门给客户洗油烟机。人家说，十年八年，头一回洗。"
【必讲点】1.冉星计划四门课 2.面向全市18-55岁 3.东北三省当年没有这门课 4.三年，全国各地的人来了 5.种子客户年年回来复购
【不能讲成】❌ 招商口号腔 ❌ 自夸 ❌ "赋能/闭环"黑话 ✅ 讲故事，数字说话
【画面】培训场地/教学场景，你边看边说，让观众看见你在哪
```

## 🧭 结构走线

```
【三年前我上门洗油烟机】
注：第一句就是反差——现在的冉总，三年前在拎机器上门。

例："22年，我拎着机器上门给客户洗油烟机。"

【十年八年头一回洗】
注：客户的话直接砸出来，不用解释。

例："好多客户家里，十年八年，才头一回洗。"

【东北三省没有这门课】
注：从客户的事转到行业的事——当年想学都没地方学。

例："那时候我想学家电清洗，东北三省，没有这个培训，也没有场地。"

【今天，冉星计划】
注：落到今天——冉星计划第一件事，就是开课。

例："今天我们的冉星计划启动了，第一部分就是技能培训。"

【四门课，18到55】
注：具体到能报名的人——保洁、收纳、养老照护、清洗服务，面向全市。

例："保洁技能、收纳整理、养老照护师、清洗服务师，面向全市，18到55岁都能报名。"

【全国各地的人来了】
注：三年这个时间跨度要砸实——从什么都没有，到外地人慕名来。

例："短短三年，全国各地的人奔着一冉来。有的学运营管理，有的学技能。"

【种子客户年年回来】
注：订单端的事——不用开发客户，客户自己回来。

例："现在服务端，我已经不用开发客户了。种子客户年年复购，高净值客户自己会选我们。"

【别人还在猜】
注：收势——别人还在猜我们订单怎么来的，我们的下一步已经开始了。

例："别人还在猜我们订单怎么来的，我们的新一轮战略，已经势在必行。"

【敢想敢拼】
注：收在冉总自己的话上，不追加升华。

例："创业也好，人生也好，就是敢想、敢拼。乘风破浪，勇往直前。"
```

## ⚠️ 注意事项

- 数字保真：22年、三年、18-55岁、四门课——素材里有的才能说，别加码
- 别演：这是你亲历的事，讲的时候就像跟朋友唠
- 别用黑话：不说"赋能""闭环"，说人话
- 结尾停在"乘风破浪，勇往直前"——这是你的话，说完就停，不追加总结
