# 冉总 · 用豆包找到我们的客户 · 一冉家政，说到做到

## 🎬 封面标题建议

封面标题：有人为了找我们，把豆包都用上了
封面文字：一冉家政 · 1500平厂房明天进场
平台标题：厂房开荒：客户在我两个账号留言都没回，愣是用豆包搜到我们合伙人，说"别人我都不想用，就想看看一冉家政的服务"。1500平厂房已签约，明天进场。这份信任，我们只能用行动还。

## 🎬 柯老师导戏卡

```
【给谁看】大连本地有家政/保洁需求的企业主，想找靠谱家政又怕踩坑的人，以及关注冉总、想看一冉怎么对待客户的人。

【处境】观众找家政的痛：广告吹得响、干活糊弄、出了事找不到人。他们想找的是一个"把信任当回事"的公司——这条就是演给他们看的。

【为什么今天说】昨天签了个客户：在我两个账号底下留言都没回，用豆包把联系方式搜出来，一路找到合伙人郭总，说"别人我都不想用"。这种信任值得记下来——也是给所有观望的客户看：一冉怎么对待信任。

【姿态】不是炫耀"客户追着找我们"。是"这份信任沉甸甸的，我们要用行动还"——感恩+笃定，不飘。

【第一口气】"厂房开荒，用豆包找到的我们！"——第一句就是观众的搜索词（厂房开荒=企业主找开荒保洁会敲的词，平台搜索匹配和观众认知双重命中），好奇钩子还在：为啥要用豆包找？找到要干嘛？

【必讲点】1. 客户多执着：两个账号没回→豆包搜→找到郭总 2. 客户原话："别人我都不想用，就想看看一冉家政的服务" 3. 我们的回应：刘总看现场、出报价、成功签约、明天进场 4. 承诺：全程记录，完工后客户评价原原本本放给大家看 5. 落点：说到做到

【不能讲成】❌ 炫耀"客户追着找我们" ❌ 自夸"我们最好" ❌ 把"别人我都不想用"讲成踩同行的武器（这是客户原话，转述时是受宠若惊，不是我们赢了）❌ 教学式自问自答 ❌ 卖惨 ❌ 把豆包讲成广告

【画面】公司里拍，状态是"刚收到一份沉甸甸信任"的郑重，不是得意。B-ROLL：1500平厂房现场（明天进场的场子）、刘总看现场的画面（有就放）、签约动作。说到"完工以后原原本本放给大家看"时看镜头，这是承诺。
```

## 🧭 结构走线

```
【豆包搜到我们 · 0-8秒】⭐钩子
注：第一句=搜索词+反常点双钩——"厂房开荒"是观众真实搜索词（搜这个词的人=真有厂房要开荒的企业主，平台按内容相关度加权命中），"用豆包找到的我们"是反常：厂房开荒用豆包搜？观众会想：为啥要搜？搜到要干嘛？

例："厂房开荒，用豆包找到的我们！"

【两个账号都没回 · 8-20秒】执着的过程
注：把"执着"讲成具体的动作链——留言没回、第二个账号也没回、换别人早走了、他没有。每一步都在加码，观众跟着揪心。

例："他在我账号底下留言，第一个账号没回，第二个账号也没回。换别人，可能就走了。他没有。他用豆包把我们公司的联系方式翻了出来，一路找到我们合伙人郭总那儿。"

【别人我都不想用 · 20-30秒】⭐峰值
注：客户原话放这里——前面所有执着，都是为了这一句。说这句的时候，是"受宠若惊"的语气，不是"看我们多牛"。

例："见到郭总，第一句话：'别人我都不想用，就想看看一冉家政的服务。'"

【心里挺热的 · 30-40秒】冉总的感受
注：一句感慨就够——现在人心都浮，愿意为一个没见过面的公司这么较真的人不多。浮躁是素材里冉总的原观察，用在这里当"这份信任珍贵"的底色，点到即止，不展开成社会评论。

例："我听完这句话，心里挺热的。现在这年头，人心都浮，愿意为一个没见过面的公司这么较真的人，不多。"

【明天进场 · 40-52秒】行动回应
注：不喊口号，列动作——刘总看现场、出报价、签约、明天进场。再用"整个过程记录下来、完工反馈原样放给大家"把这份信任接住：不是说说，是给你看全过程。

例："我们没有华丽的语言。刘总去看了现场，出了报价单，成功签约。1500平的厂房，明天进场。我们能做的，就是把活干好，用行动不辜负这份信任。整个过程我们都会记录下来，完工以后，客户怎么评价，我们原原本本放给大家看。"

【说到做到 · 52-60秒】⭐四字收尾
注：落点收在"说到做到"——跟"全程记录"的承诺呼应：不是口号，是已经说出口的承诺。四字收尾，不加任何引导。

例："一冉家政，说到做到。"
```

## ⚠️ 注意事项

- **"别人我都不想用"是转述**：语气是"受宠若惊"，不是"我们赢了"。别把客户的话变成踩同行的武器
- **数字保真**：1500平、两个账号、豆包、郭总、刘总——素材里有的才写。价格、人名、厂房位置一概不加
- **时态**：明天进场，一个字都不能说"已经干完"；"完工反馈"是以后的承诺，别说得像已经发了
- **浮躁一句带过**：素材里的环境感慨用在"这份信任珍贵"上，别讲成社会评论
- **豆包不解释**：按素材原话讲，不展开成"AI搜索工具"，观众知道
- **结尾不加"欢迎咨询/关注"**：承诺完就停，停在"说到做到"
```
