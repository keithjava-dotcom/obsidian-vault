# 冉总 · 东软老年大学校长主动来访 · 不是去干活，是去上课

## 🎬 封面标题建议

封面标题：大学校长，主动来家政公司考察
封面文字：一冉家政 · 2000平场地
平台标题：东软老年大学校长昨天主动来一冉考察谈合作——不是让我们去干活，是让我们去上课。家政干到东三省头一份，是种什么体验？

## 🎬 柯老师导戏卡

```
【给谁看】大连本地想做家政、在干家政的人，关注冉总的人；以及潜在的B端合作方（学校、机构、企业）——看到"老年大学校长主动上门"这件事，觉得这家家政不一样的人。

【处境】很多人对家政的印象还停在"低端、不正规"，干家政的人自己都怕被看轻。这条要讲的是：这个行业，正在被正经机构看见。观众要的不是卖惨，是那种"被人看见"的骄傲。

【为什么今天说】昨天东软老年大学的校长主动来一冉考察、谈合作。之前是我们登门去拜访人家，昨天人家主动来的——这种"被看见"的时刻，值得拍，而且必须趁热拍。

【姿态】兴奋、外放，但字字都是事实——是"我憋不住想说"，不是"快来夸我"。刚送走贵客的那个热乎劲儿，就是最好的状态。

【第一口气】"昨天，我特别兴奋。"——状态锚点开场，观众想知道你为啥兴奋，钩子就挂上了。

【必讲点】1. 之前我们登门拜访，昨天校长主动来（姿态反转）2. 校长看完2000平场地的话：干到这么大、这么正规，东三省头一份 3. 合作内容：不是让我们去干活，是让我们去上课——教收纳整理、母婴护理、月嫂这些技能 4. "这不你看"转折：家政被正经机构看见了 5. 90后把家政干到2000平、干到正规——骄傲，四字收尾

【不能讲成】❌ 炫耀"校长求着我们合作"（是考察+谈合作，不是求）❌ 说合作已落地、已开课（还在洽谈阶段）❌ 教学式自问自答（"为什么校长会来？因为…"——死穴）❌ 扣题总结腔（"这才是家政被看得起的原因"——死穴）❌ 哭诉行业委屈、卖惨（"被看不起"是背景，一句带过，落点要落在骄傲上）✅ 兴奋的骄傲，让事实自己说话

【画面】2000平场地里拍——设备区、药剂墙、实景培训区，就是校长昨天走过的地方。状态是刚送走贵客的兴奋劲儿。B-ROLL：场地全景、校长来时走过的路线（有拍就插）。
```

## 🧭 结构走线

```
【昨天，我特别兴奋 · 0-8秒】⭐状态锚点
注：冉总的开场永远从状态进，不从事件进。不是"昨天校长来了"，是"昨天我特别兴奋"——观众被"为啥兴奋"抓住。

例："昨天，我特别兴奋。东软老年大学的校长，来我们一冉了。"

【之前我们登门，昨天人家主动来 · 8-18秒】
注：姿态反转要讲透——先是我们上门拜访（姿态低），昨天人家主动来（姿态高）。"主动"两个字是这条的骨头。

例："之前是我们登门去拜访人家，昨天，人家校长主动来的。"

【校长的一句话 · 18-30秒】⭐峰值一
注：校长的话按柯哥转述的口径讲，不加工不加戏。这句话的分量在于它是"外人"说的——自己说自己牛没用，校长说的才算数。

例："他在我们2000平的场地里走了一圈，看完说了一句话：家政能干到这个规模，这么正规，东三省你们是头一份。"

【不是干活，是上课 · 30-42秒】⭐峰值二
注：全条最大的反转。观众以为合作是"去老年大学做保洁"，结果——是去当老师。这个反差是这条的灵魂，讲的时候自己先笑出来。

例："但最让我兴奋的，不是这句夸奖。是接下来谈的合作——不是让我们去干活，是让我们去上课。教这些退休的老师们、企业家们，收纳整理、母婴护理、月嫂——都是过日子用得上的真本事。"

【这不你看 · 42-52秒】⭐转折
注："这不你看"是冉总原生气口。行业被看轻是背景，一句带过；落点必须是骄傲——"被看见了"，不卖惨。

例："这不你看，以前干家政，在很多人眼里低人一等。现在，大学的校长，主动来请我们讲课了。我90后，把家政干到2000平，干得这么正规——说实话，我挺骄傲的。"

【一冉家政，大有可为 · 52-60秒】⭐四字收尾
注：四字收尾是冉总的定式（"拭目以待""大有可为"）。收在骄傲上，不卷大气，不加"欢迎咨询"。

例："东软老年大学，我们好好干。一冉家政，大有可为。"
```

## ⚠️ 注意事项

- **时态**：合作还在洽谈阶段，不能说"已经开课""已经签约"，只能讲"谈的合作是……"
- **冉总死穴自查**：禁教学式自问自答（"为什么…因为…"）、禁"首先其次最后"、禁扣题总结（"这才是…的原因"）、禁铺垫前置（"今天跟大家分享"）
- **"三嫂"口播统一说"月嫂"**：通用说法，避免歧义
- **校长的话按柯哥转述口径**："东三省头一份"照说，不加细节、不编原话
- **"低人一等"一句带过**：背景板，不是主题；主题是"被看见了"
- **兴奋但不飘**：全是事实——登门→回访、2000平、东三省头一份，不需要形容词堆砌
- **结尾四字收尾**："大有可为"，不加"欢迎咨询/合作私信"
