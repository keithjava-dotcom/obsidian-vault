# 当年没收钱的客户，今年把别墅开荒交给我

## 🎬 柯老师导戏卡

```
【给谁看】本地做家政的同行、正在找靠谱家政的高端业主——以及所有相信"做事先做人"的生意人。

【处境】同行们在打价格战、抢单子，越抢越累；业主被"便宜开荒"坑过，不敢信任何人。两边都缺一个"信任是怎么来的"的答案。

【为什么今天说】明天就要进场红星海别墅开荒——这单不是靠低价抢来的，是两年前没收一分钱、转介绍同行种下的因。真实的事，就是最好的故事。

【姿态】讲一件真事——不是"我教你做生意"，是"我跟你说说我这单怎么来的"。语气是压不住想说，不是端着讲道理。

【第一口气】"当年没收他一分钱、还给他介绍同行的那个客户，今年，把别墅开荒交给我了。"
直接砸因果反转。不铺垫、不介绍、不上价值。观众自己会问：凭什么？

【必讲点】
1. 没收钱的原因：自己没合适的人，不打着旗号上工赚差额——这是原则，不是话术
2. 行业背景："不少同行是这么干的"——先接一下，再转"我没这么做"
3. 因果回报：今年别墅翻新，直接找我，当季拍板——种因收果
4. 收费高于市场：但客户说"信你这个人，就信你这个团队"——信任大于价格
5. 落点：搞定高端客户不打价格战——靠没人看见的时候怎么做事

【不能讲成】❌ 销售话术 / "我们一冉多专业" / 贬低同行 / 炫耀大单 / "快来联系我们"
✅ 就是两年前一个没收钱的选择，今年长出了一单生意。信任是攒出来的，不是谈出来的。

【画面】明天进场红星海别墅现场拍——背景是工人进场、工具摆放、分工调度。"进场"不是一句话，是画面。如果明天拍不了，今天在公司讲也行，但状态要带着"明天要干大事"的那股劲。
```

## 🧭 结构走线

```
【开头 · 0-8秒】因果反转直接砸 ⭐开头即钩子
"当年没收他一分钱、还给他介绍同行的那个客户，
今年，把别墅开荒交给我了。"
→ 没收钱→还成交，观众自己追问"凭什么"
→ 中间留半拍停顿，让反转落地

【中段一 · 8-20秒】补故事
"有人可能好奇：没收钱，怎么还能成交？
2025年6月，这个客户找到我，想找个白班保姆。我手里，当时真没有合适的人。"
→ 用观众的疑问接故事，不自己硬转

【中段二 · 20-35秒】关键选择 ⭐价值观峰值
"没有合适的人，也能接啊——随便派一个，先把钱赚了再说。不少同行是这么干的。
我没这么做。"
→ "我没这么做"四个字，停顿，是全片最重的一句

【中段三 · 35-50秒】因果回报
"今年，客户在红星海翻新了一套别墅，找到我，说：冉总，这套房子的开荒，交给你。"
→ 前面种下的因，这里收果

【收尾 · 50-65秒】落点
"搞定高端客户，不打价格战。靠的从来不是话术，是你在没人看见的时候，怎么做事。"
→ 不说"找我"，价值观收尾
```

## ⚠️ 注意事项

- 开头那句因果反转，语速放慢，说到"今年"顿一下再落"把别墅开荒交给我了"
- "我没这么做"是第二峰值，说完停一秒，别急着解释
- 别加"我们一冉最专业"之类的自我评价——故事自己会说话
- 结尾不喊口号不升华，"怎么做事"收住就行
- 明天进场拍的素材是下一条视频，这条不要提前预告太多，一句带过

## 📝 口播文案示例

> ⚠️ 这是示例稿，不是逐字稿。冉总理解了上面讲戏卡之后，用自己的嘴巴说出来，不用照着念。现场有感觉的地方可以自由发挥，只要方向不跑偏就行。

---

当年没收他一分钱、还给他介绍同行的那个客户，今年，把别墅开荒交给我了。

有人可能好奇：没收钱，怎么还能成交？

2025年6月，这个客户找到我，想找个白班保姆。
我手里，当时真没有合适的人。

没有合适的人，也能接啊——随便派一个，先把钱赚了再说。不少同行是这么干的。

我没这么做。

我直接跟他讲：我这儿暂时没有合适的，我帮你介绍同行。一分钱没收。

为什么？我的原则就一条——自己没人的时候，不打着我们一冉的旗号去上工。赚那个差额服务费，我心里过不去。

这事过去快一年，我其实都快忘了。

今年，客户在红星海翻新了一套别墅，找到我，说：冉总，这套房子的开荒，交给你。

服务部负责人先去看了现场，定了施工方案。客户当季就拍板了。

说句心里话，我们收费，是高于市场的。

但客户跟我说了一句话：我信你这个人，就信你这个团队。

你看，高端客户从来不是靠价格打下来的。是靠一件一件小事，攒出来的信任。

明天进场，我会把整个过程真实记录下来——怎么进场、人员怎么分工、服务怎么干、到最后客户怎么验收。

这条视频，就当给同行们交个底：

搞定高端客户，不打价格战。
靠的从来不是话术，是你在没人看见的时候，怎么做事。
