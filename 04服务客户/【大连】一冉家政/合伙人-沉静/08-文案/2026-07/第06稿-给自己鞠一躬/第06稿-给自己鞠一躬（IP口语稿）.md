# 沉静 · 第06稿 · 给自己鞠一躬

## 🎬 封面标题建议

封面标题：你敢拿放大镜验收吗
封面文字：VIP年卡客户｜600平交付
平台标题：干完600平想给自己鞠一躬 / 敢不敢拿放大镜验收

## 🧭 结构走线

```
【钩子】
→ 第一句就出情绪。倒叙。
"干完活，真想给自己鞠一躬。"

【干活】
→ 抹布白的→干了有印子→再擦。
不是列工序，是让人感觉"不在现场就看不见这些"。

【跟自己较劲】
→ "第三遍的时候我告诉自己可以了。站起来。又蹲下去了。"
不是文案设计，是真实反应。

【标准是长出来的】
→ "后来我们给这种验收起了个名字"——
放大镜验收不是一开始就有的，是干出来的。

【转身·踏实】
→ 不说崇高。说踏实。
"这东西你干过了，没糊弄自己。"
```

## ⚠️ 注意事项

1. 腔调：别端、别喊。刚干完活边走边说的感觉。声音可以有点累。
2. "站起来。又蹲下去了。"——中间有空拍，不是连着说。
3. "看见了你就过不去。"——轻说。不是喊口号，是真话。
4. "脱鞋套。收工具。"——现在时。动作正在做，不是完成了。
5. 禁止：过渡词、自问自答、扣题总结、画外音描述画面。

## 📝 口播文案示例

⚠️ 这是示例，不是逐字稿。

干完活，真想给自己鞠一躬。
不是客气。
是真觉得自己干到位了。

今天最后一趟。
vip年卡那家。
600多平。
地下两层地上四层。
去了四个人。

这种房子跟普通保洁不一样。
不是大不大的问题。
是材料。
大理石。
实木。
窗子好几层。
这些材料，你光使力气没用。
你得趴上去。
把脸凑到跟前。
光靠站着看一看——
你觉得干净了。
你蹲下来。
不是那么回事。

地板。
我们跪着擦。
一手一块抹布。

不跪不行。
你不跪，脸贴不到地面——
那道痕，你站着看不见。

大理石岛台。
高。得爬上去。
爬上爬下。
第一遍上去，抹布是白的。
你觉得行了。
干了一看，那层印子又返上来了。
再来一遍。
还不是。

第三遍的时候我告诉自己可以了。
没人看得出来。
站起来。
又蹲下去了。

不是强迫症。
是你自己看见了。
看见了你就过不去。

到第五遍。
从底下往上看。
什么都没有了。

四个人。
七个小时。
活干完才知道衣服全湿了。
什么时候湿的都不知道。
脸上跟汗蒸一样。

后来我们给这种验收起了个名字。
放大镜验收。
不是写文案的形容词。
就是拿个放大镜。
一块一块过。
过了才叫过了。

干完了。
脱鞋套。收工具。
转身。
那一刻，真想给自己鞠一躬。
不是客气。
是踏实。
这东西你干过了，没糊弄自己。

谁以后再比比划划吹自己家保洁多牛。
让他来找我。
拿放大镜。
验完再说话。
