# 第06稿 · 给自己鞠一躬

## 🎬 封面标题建议

**标题候选**：
1. 你干的活敢不敢拿放大镜验收

**封面文字**：VIP年卡客户｜600平交付实录

**平台标题**：干完600平想给自己鞠一躬 / 敢不敢拿放大镜验收

## 🧭 结构走线

```text
【进场 · 0:00-0:10】
→ 别端，像干完活坐车里跟旁边人说话。平着进。
"今天又去了vip年卡那家。600多平。"

【怎么干的 · 0:10-0:35】
→ 不讲辛苦，讲"为什么非得这么干"。跪地擦不是炫，是脸不贴地面看不见那道痕。
"你站着擦，脸不贴地面，那道痕看不见。"

【验收 · 0:35-0:45】
→ 四个字说完。七个小时衣服湿透，像收工报了个数，不叫苦。
"放大镜验收。不是形容词。"

【转身 · 0:45-0:55】
→ 最重的一句。说完停住。不解释不铺垫。
"那一刻，我真想给自己鞠一躬。"

【怼同行 · 0:55-1:00】
→ 问完就停，视频结束。
"你干的活，敢不敢拿放大镜验收？"
```

## ⚠️ 注意事项

- 开头"今天又去了"——"又"字带出来，说明不是头一回来
- "房子大不是重点"一句带过就进干活，不拖
- 跪地擦那段是认知翻转——语气平静，不是教育人。"你站着擦，脸不贴地面，那道痕看不见。"像在说一个事实
- "放大镜验收。不是形容词。"——两个短句中间留一口气。说完"验收"停一拍，再"不是形容词"
- 岛台"爬上爬下擦了五遍"——就这一句，不展开
- "那一刻，我真想给自己鞠一躬"——最轻的一句也是最重的。别用力，说出来就行
- 结尾从"以后再有保洁公司跟你吹"到"敢不敢拿放大镜验收"——逐渐加速，最后六个字砸下来，问完停
