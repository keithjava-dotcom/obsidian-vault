# 沉静 · 第06稿 · 给自己鞠一躬

## 🎬 封面标题建议

封面标题：你敢拿放大镜验收吗
封面文字：VIP年卡客户｜600平交付
平台标题：干完600平想给自己鞠一躬 / 敢不敢拿放大镜验收

## 🧭 结构走线

```
【进场】
→ 别端，干完活坐车里跟旁边人说话。最后一趟交付。
"最后一趟了。600多平。地下两层地上四层。"

【干活】
→ 不讲辛苦，讲必须这么干。过手、贴地、五遍。
"你得一件一件过手。"

【验收】
→ "没夸张"——真人才会跟的三个字。
"放大镜验收。不是写文案的形容词。就是拿放大镜看。"

【转身】
→ "转身。"单行停住。最安静的一句。
"那一刻，真想给自己鞠一躬。"

【怼同行】
→ 不收反问，收陈述。
"拿放大镜。验完再说话。"
```

## ⚠️ 注意事项

1. 腔调：别端、别喊。衣服湿着、干完活跟旁边人说话。声音可以有点累。
2. "没夸张"——这三个字不是技巧，是人说真话之后会跟的口头禅。别念重。
3. "脸贴不了地"重复两遍——第一遍是动作，第二遍是停顿后的强调。中间别连读。
4. "不是写文案的形容词。就是拿放大镜看。"——不解释它不是什么，直接说它是什么。
5. "转身。"单行一句。说完停一拍，再出"那一刻"。
6. 禁止：过渡词、自问自答、扣题总结、画外音描述画面。
