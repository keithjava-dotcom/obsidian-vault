# 沉静 · 第06稿 · 给自己鞠一躬

## 🎬 封面标题建议

封面标题：你敢拿放大镜验收吗
封面文字：VIP年卡客户｜600平交付
平台标题：干完600平想给自己鞠一躬 / 敢不敢拿放大镜验收

## 🧭 结构走线

```
【进场】
→ 最后一趟交付，像干完活坐车里跟旁边人说。平进。
"最后一趟了。600多平。"

【干活】
→ 不是列工序，是让人感觉"你不在现场看不到这些东西"。
远看还行，近看不是那么回事。

【验收】
→ "不是比喻"四个字把前面所有辛苦变成一句实话。
我们给自己定了个标准。

【转身】
→ "转身。"单行停住。最安静的一句。不解释。
那一刻，真想给自己鞠一躬。

【怼同行】
→ 不收反问，收陈述。东西在话才有。
拿放大镜。验完再说话。
```

## ⚠️ 注意事项

1. 腔调：别端、别喊。衣服湿着，干完活跟旁边人说。声音可以有点累。
2. 干活段可以看旁边人一眼开头——"你看这个地板"或者侧头一句，让话落在一个在场的人身上。
3. "脸贴不了地"重复两遍——第二遍是停顿后的强调，别连读。
4. "不是比喻"——说完别加重，当口头禅一样带过去。
5. "转身。"单行一句，停一拍再出"那一刻"。
6. "真看"——叠在"就是拿放大镜看"后面，像改口强调。别念成两个句子。
7. 禁止：过渡词、自问自答、扣题总结、画外音描述画面。
