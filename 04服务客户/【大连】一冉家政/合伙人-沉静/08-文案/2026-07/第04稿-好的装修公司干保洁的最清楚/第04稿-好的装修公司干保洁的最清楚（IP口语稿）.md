## 🧭 结构走线

```
【开场 · 0:00-0:10】
→ 进门就说，跟刚干完活一样。口气轻松，不是要讲大道理，就是今天遇到个好事想说说。
"今天开荒一个40平的小户型。一进门就知道，这家装修公司靠谱。"

【现场证据 · 0:10-0:25】
→ 一个一个指出来，边走边拍。水泥印子、腻子块、油漆点——这些都是开荒保洁最烦的东西，今天全没有。
"地板上没有水泥大白印子。墙角没有腻子块。窗台上没有油漆点。"

【行业真相 · 0:25-0:50】
→ 这句话是全文最重的一句。慢下来，像在说一个你干了这么久才发现的秘密。
"保洁是最后一个进场的。前面所有人的活，到你这全暴露。"

【对比 · 0:50-1:05】
→ 接地气，说人话。不用多渲染，干过的都懂。
"有的装修现场，开荒保洁跟干工厂一样。粉尘碎屑堆一地。"

【收 · 1:05-1:20】
→ 像顺口说的，不喊。表扬就是表扬，不是广告。
"好的装修公司，不光让业主省心。也让后面干活的人省心。"
```

## ⚠️ 注意事项

- 别演！口气就是刚干完活跟朋友分享——今天遇到个好装修公司，跟你说说
- "行业真相"那段放慢，像在说一个干了好多年才发现的秘密，不是炫耀，是分享
- 对比段不要咬牙切齿，就是陈述事实
- 最后一句不要加力，像随口说的
- 🎤 开拍补讲：这家装修公司叫什么？做了哪些保护特别到位？蹲下来摸摸墙角再起来说——身体动作比说话有说服力

今天开荒一个40平的小户型。
一进门就知道，这家装修公司靠谱。

不是我说了算，是现场说的。
地板上没有水泥大白印子。
墙角没有腻子块。
窗台上没有油漆点。
厨房台面干干净净。
不是运气好。
是装修公司把保护做到位了。

跟你说个行业真相。
装修请完保洁，你以为保洁是进去打扫的？
保洁是最后一个进场的。
水电、瓦工、木工、油漆，前面所有人的活。
到你这，全暴露。
谁认真谁糊弄，不是看出来的。
是擦出来的。

有的装修现场，开荒保洁跟干工厂一样。
粉尘碎屑堆一地，擦了好几遍才能看。
地上全是水泥印子。
真不是保洁的锅。是前面没做好。
今天这个40平，轻松。
不是活简单。
是前面的人，把活干好了。

好的装修公司，不光让业主省心。
也让后面干活的人省心。

今天这家装修公司，得表扬。
