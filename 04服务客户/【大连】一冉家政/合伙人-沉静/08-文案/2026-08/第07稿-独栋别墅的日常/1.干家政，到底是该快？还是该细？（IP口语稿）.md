# 沉静 · 第07稿 · 干家政，到底是该快？还是该细？

## 🎬 封面标题建议

封面标题：干家政，到底是该快？还是该细？
封面文字：干家政，到底是该快？还是该细？
平台标题：四个人两天干不完一栋别墅，被说墨迹。这活到底该快还是该细？

## 🧭 结构走线

```
【被人说墨迹】
→ 上来就出冲突。不铺垫直接进事。不用解释这是什么活，后面会展开。
"这活干得墨迹不出活。"验收的时候，旁边有人说了这么一句。

【别墅长什么样】
→ 让观众看见为什么快不了。每一样东西都需要时间。
四层别墅。地下还有一层。十三个房间。加一个车库。第一天我们四个人只干了两层。

【旋转楼梯和水晶灯】
→ 一个具体例子，让"慢"有画面。
每级台阶都是大理石，每根廊柱上面都挂着水晶灯。光擦这些灯，够站一下午。

【男孩的手办房间】
→ 最细的活——毛刷刷手办。不是行业外的人能想象的。
一个男孩的房间，整个柜子全是手办。小的比指甲盖大不了多少。不能拿抹布一抹了事。得拿着毛刷，一个一个地刷。刷完灰尘，原样摆回去。你摆错了他回家一眼能看出来。

【说墨迹那句话的意思】
→ 转折：我明白为什么被说——但这不是快活。
说墨迹，我明白他什么意思。很多同行愿意干快活。一套房半天搞定，下午再接一单，多挣一份。但这不是快活。

【到底细在哪】
→ 身体在场的细节：窗子擦不亮、大理石得凑到跟前看。
窗子好几层。玻璃擦一遍不亮，两遍还不行——阳光一照，指印全在。大理石地面，站着看觉得干净了。你得把脸凑到跟前。蹲下去，不是那么回事。

【返工后的那句话】
→ 从这里引出核心：如果我不查出来，损失的是信任。
那天验收发现了一大堆小地方不到位。全返了。延时了。但我跟自己说——如果这些问题不是我查出来的，是客户自己发现的。损失的不是这一单的钱。是他以后不会再叫你了。

【结尾 · 抛争论】
→ 不扣题不升华。把"快vs细"的争论抛给观众。
所以你看，墨迹和细，有时候是一回事。这活是该干快，还是该干细？
```

## ⚠️ 注意事项

1. 腔调：刚干完活的状态。声音可以有点累，别端。不是演讲。
2. "把脸凑到跟前"——边说可以边比划动作。
3. "你摆错了他回家一眼能看出来"——语气里带点对那个男孩的尊重，不是嫌麻烦。
4. 整条视频站在别墅里拍，别在空房间拍。后面就是大理石楼梯最好。
5. "站着看觉得干净了。蹲下去，不是那么回事。"——蹲一下。不蹲也行，看机位。
6. 禁止：过渡词、自问自答、扣题总结、"做家政不容易"类煽情、BGM 煽情。
