# 沉静 · 第10稿 · 最难的不是活，是35度

## 🎬 封面标题建议

封面标题：最难的不是活，是35度
封面文字：80平开荒 · 衣服拧出水
平台标题：80平开荒，装修公司干得漂亮，现场保护得干净，是最近最顺的一户。活不重，但35度高温，每个人全身湿透，衣服能拧出水。这就是干家政的本色吧。

## 🎬 柯老师导戏卡

```【给谁看】大连本地请过保洁、或者家里装修完要开荒的业主——以及所有觉得"开荒就是擦擦灰"的人。

【处境】业主怕开荒的人糊弄：墙面粉尘没擦净、吊顶空调口藏着沙砾、胶印没清干净。同时没人想过——干活的人在35度里是怎么撑下来的。

【为什么今天说】这一户是最近最顺的活：装修公司干得漂亮，现场干净，活不难。但真正的难处是35度——身体扛着高温，活还得干细。这种"顺里的难"，比脏乱差的难更真实。

【姿态】收工回来的状态，人还热着，像刚洗完澡坐在风口下说话。不卖惨，就是讲今天这个活。

【第一口气】"今天这户，80平开荒。干得比想象中顺——装修公司干得漂亮。"
先立"顺"，让观众放下戒心，后面转折才有劲。

【必讲点】
1. 装修公司干得漂亮——大白水泥印子少见、胶打得直，先立顺利
2. 业主重点提墙面粉尘——除尘纸上去灰挺多，吊顶空调口沙砾多
3. 办法——吸尘器+静电吸尘纸，一遍过完
4. 35度——衣服湿透，能拧出水 ⭐
5. 落点——这就是干家政的本色

【不能讲成】❌ 抱怨天气 / 卖惨"我们太辛苦了" / 自夸"我们多专业" / 暗示业主多事（重点提粉尘是正常要求）
✅ 就是讲一户顺的活：活不难，但热。热也得干细。活儿上见。

【画面】在开荒完成的现场拍——干净的房间做背景。讲到35度时，可以拍一件湿透的工作服搭在窗台上，让"拧出水"看得见。
```

## 🧭 结构走线

```【先立顺】开场不铺垫
→ 开头直接说"顺"，跟观众预期（开荒=脏乱差）反着来。
"今天这户，80平开荒。干得比想象中顺——装修公司干得漂亮。现场保护得干净，大白水泥印子都少见，胶打得也直。"

【墙面粉尘】业主的讲究
→ 讲业主要求时不动声色，接住"顺"：顺是因为前头干得好，但我们该干的细活一样没少。
"业主重点提了墙面粉尘。除尘纸上去，灰是真的多。二级吊顶、空调口，沙砾一层。我们用吸尘器加静电吸尘纸，一遍过完，干干净净。"

【35度】⭐身体是本钱
→ 全场最重的一段。不喊累，讲身体反应：衣服湿透、能拧出水。镜头感最强的画面。
"但这户最难的，不是活。是35度。每个人全身湿透透的。衣服脱下来，能拧出水。"

【干家政的本色】收尾
→ 素材原话直接搬。不解释，让这句自己落。
"这就是干家政的本色吧。"
```

## ⚠️ 注意事项

1. 腔调：收工回来的状态，人还带着热。不卖惨，讲今天这个活。
2. "干得比想象中顺"——说的时候带一点意外，因为装修公司干得漂亮是少见的情况。
3. "除尘纸上去，灰是真的多"——"是真的多"三个字带点重量，让观众知道你干了才看见。
4. "35度"和"衣服脱下来能拧出水"——全场最重的两句，说的时候不用加重，平静说出来反而更沉。
5. 结尾"这就是干家政的本色吧"——不用升华，不用解释，说完收。带一点"你们可能不知道，但这就是我们每天过的日子"的意思。
6. 禁止：抱怨天气、卖惨、自夸、煽情BGM。
