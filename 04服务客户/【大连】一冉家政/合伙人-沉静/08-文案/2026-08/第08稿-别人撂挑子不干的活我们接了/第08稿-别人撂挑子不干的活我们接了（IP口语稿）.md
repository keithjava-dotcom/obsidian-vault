# 沉静 · 第08稿 · 别人撂挑子不干的活，我们接了

## 🎬 封面标题建议

封面标题：别人撂挑子不干的活，我们接了
封面文字：瓦房店98平开荒保洁，干了八小时
平台标题：到了瓦房店才知道前面干活的人跑了——98平开荒保洁，32度没风，整整八个小时。活上见。

## 🧭 结构走线

```
【到了才知道，前面的人跑了】
→ 不铺垫。不稳定状态直接进场。不解释是什么活，后面会说。
"今天跑了个远道。瓦房店。到了才知道——前面干活的人，跑了。"

【现场什么样】
→ 陈述事实，不评判。但"粗开过一半"和"说不过去"就够了。
到的时候现场被粗开过一半。实话也真说不过去。

【业主是什么人】
→ 解释为什么前面的人跑了——不是业主不讲理，是标准高。腔调：不抱怨业主，像在说一件合理的事。
业主是干质检的。职业病，对现场很严苛。他那要求，差不多就是拿放大镜验收了。

【他们跑了，我们接了】
→ 两个动作：看一眼→开干。中间没有任何话。
前面那拨人受不了，撂挑子走了。我们接过来先看了现场。啥也不说，直接开干。

【这活有多难干】
→ 32度开场，然后三个"看不见的脏"。不用概括，直接把东西摆出来。
32度。开窗没风。白色装修。各面墙上地上全是乳胶漆点子。白碰白，不凑上去根本看不出来。柜体加深的，伸手够不到背板。白色美缝——全是黄色木屑和胶。玻璃也全是白点。

【八小时】
→ 锚在"说出来可能被嘲笑"。不是卖惨，是"我说了你也不信——那你来看"。
整整八个小时。98平。说出来不看现场都可能被嘲笑——这活咋能干这么长时间。

【活上见】
→ 三个字。不解释。视频结束。
但咱活儿上见。
```

## ⚠️ 注意事项

1. 腔调：干完活的状态，声音可以有点累。不是演讲，像坐车里跟旁边人讲今天发生了什么事。
2. "前面干活的人，跑了"——说这句不带情绪。不是控诉，不是得意。就是陈述事实。
3. 整条视频在现场拍，背景就是白装修的房子。站到柜体加深处旁边——让观众看见伸手够不到的那个深度。
4. "32度。开窗没风。"——边说可以边擦一下汗，别夸张。
5. "放大镜验收"是沉静的标志词，这稿里不带引号说——不是喊口号，是顺嘴一提。
6. "白碰白，不凑上去根本看不出来"——说的时候可以指一下墙面，让观众明白不是没脏，是它跟你捉迷藏。
7. 禁止：抱怨前面的人、骂业主难伺候、卖惨、自夸、"做家政不容易"类煽情、BGM煽情。
8. 最后"但咱活儿上见"不要喊。平静说完，三个字收。视频结束。
