## 🎬 柯老师导戏卡

```【给谁看】大连本地做工程、物业、商业管理的老板，手里有大面积场地要保洁外包的甲方——以及所有觉得"保洁就是找几个人擦擦"的人。

【处境】手里有大面积场地要外包，怕找的队伍干不了、中途撂挑子；或者压根不知道，这种活对保洁公司的实力要求有多高。

【为什么今天说】西岗7500平老破旧，甲方几句话就免了竞标——这种"专业被当场认出来"的时刻，比说一百遍"我们专业"都值钱。

【姿态】看现场回来的状态，坐在车里跟人讲今天遇到的事。讲到脏的地方有身体反应，讲到免竞标有点压不住的劲。

【第一口气】"今天去了西岗。7500平。八层公寓。"
直接进场，不铺垫。

【必讲点】
1. 现场多脏——摆事实+身体反应（摸灰、踩地板、侧身走）
2. 甲方什么要求——商业管理公司，整体外包，要实力承接
3. 几句话+预报价→免竞标——甲方替我们说话
4. 第二现场——砖扔在前头，后面藏了一大块玉（4000平，明年初交付）

【不能讲成】❌ 自夸"我们多专业" / 贬低之前的保洁 / 卖惨"十几年没人管" / 炫耀大单 / "快来联系我们"
✅ 就是今天去看了个现场，电梯门一开吓了一跳，甲方几句话就把活定了。活儿上见。

【画面】电梯门打开的一瞬间拍——先拍脏，再拍人往里走。摸壁画框灰的手部特写。破沙发、建筑板子。第二现场拍在建的楼体，灰扑扑的工地就是"玉"的伏笔。
```

## 🧭 结构走线

```【电梯门一开】开场直接进场
→ 不铺垫。7500平+八层公寓先立规模。楼下听见机器声，是听觉先行——还没看见就听见了。
"今天去了西岗。7500平。八层公寓。还没进楼，楼下就能听见拆扒的机器声。那声音，你站在外面都能听见——整个楼都在动。"

【十几年没碰过】现场摆事实+身体反应
→ 报事实，但人得有反应：侧着身走、鞋踩上去粘脚、摸灰掉渣。不是相机在拍，是人走进去的感觉。
"电梯门一开，顶棚压得低。走廊又长又窄，两边堆满杂物，人得侧着身走。地板油黑的，不是脏，是油。胶粘的，鞋踩上去粘脚。我顺手摸了一下壁画框——手指上一层灰，厚到掉渣。回廊里，陈年垃圾。建筑板子。破沙发。破得都认不出原来是什么颜色了。十几年，这楼没做过一次像样的保洁。"

【这活不是谁都能接】甲方要求
→ 不喊"我们有实力"，讲这活的门槛。一句"你光有人不行，你得有底子"把话说透。
"甲方是商业管理公司。人工、器械、物料，整体外包。这种活不是谁都能接的——你光有人不行，你得有底子。"

【不用竞标了】⭐甲方替我们说话
→ 全场最重要的一句，是甲方说的。前两句讲"聊了什么"，加一个细节"数字给得快，他愣了一下"——那是专业被当场认出来的瞬间。
"现场聊了几句。问工期，问基数，问怎么算。我们直接报：人工工时基数，预报价。数字给得快，他愣了一下。项目总听完说了一句：不用竞标了。"

【砖扔在前头，玉藏在后面】第二现场
→ 素材原话直接搬。加一句"灰扑扑的工地，地基刚起来"——让"玉"看得见。
"临走，他又领我们看了第二现场。四层楼，快4000平。还在土建，明年初交付。灰扑扑的工地，地基刚起来。砖扔在了前头，后面藏了一大块玉。"

【活儿上见】收尾
→ 三个字。不解释。视频结束。
"那是一场过瘾的硬仗。活儿上见。"
```

## ⚠️ 注意事项

1. 腔调：看现场回来的状态，平稳但带着今天经历过的余劲。不是演讲，像坐车里跟旁边人讲今天发生了什么事。
2. "电梯门一开——"后面停一拍，再报现场。
3. 讲脏的地方要有身体反应：摸灰、粘脚、侧身走——观众跟着你的手和脚看见现场，不是听你报参数。
4. "不是脏，是油"——这种纠正是沉静的劲儿，说到"油"字可以皱一下眉。
5. "不用竞标了"是全场最重的一句——是项目总说的。说的时候不用加重，原样转述，停半秒。
6. "砖扔在了前头，后面藏了一大块玉"——全场唯一的情绪上扬，稍微提起来一点。
7. 禁止：抱怨现场、贬低之前的保洁、自夸、卖惨、煽情BGM。
8. 最后"活儿上见"不喊，平静说完，三个字收。
