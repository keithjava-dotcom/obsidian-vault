# 沉静 · 第02稿 · 家政这行，你确定你能干？

## 🎬 封面标题建议

封面标题：家政这行，你确定你能干？
封面文字：家政这行，你确定你能干？
平台标题：35度高温，在别人豪宅里干保洁第二天——我连门都不会开。

## 🧭 结构走线

```
【钩子 · 不会开门】
→ 上来就砸最荒诞的事实。不是标题党，是真事。
今天是我干这活的第二天。我还是不会开他家的大门。

【酒柜 · 一瓶都不认识】
→ 体力不是障碍，障碍是你根本不属于这个空间。
酒柜要擦。但里面每一瓶酒我都不认识。不敢拿。不知道哪瓶该从哪头拿。擦完放回去，位置不能错。比擦这事本身费劲多了。

【球杆 · 不敢离手】
→ 上一个例子是知识盲区，这个是肉体紧张。升级。
高尔夫球杆。每一根长得不一样。擦了不敢离手——马上放回原来的位置。对号入座。这事搞错了，比你没擦还严重。

【星空顶 · 干活倒挺有氛围】
→ 自嘲。节奏松一下，让观众喘口气再往下读。
音响上面六七个遥控器。碰了一个，不知道碰的是哪个。抬头一看，星空顶亮了。当了基础照明了。我跟伙伴说：行，今天干活还挺有排场。

【缝里 · 没人在看你】
→ 从自嘲转回现实。最重的一段。
客厅里二十几个人。小孩七八个。跑的跑闹的闹。我钻在柜子里擦灰，趴在地上抠地缝。没有一个人往这边看。不是故意的。是根本看不见你。

【大门口 · 眼里有泪光】
→ 不卖惨。拍照是证据，泪光是事实，不说"难受"两个字。
干满了。每个人都在中暑的边缘，身体发烫。我给伙伴们在大门外拍了张照片。没人说话。但每个人眼里都有星空顶里的泪光。

【收口 · 进来你就知道了】
→ 不是"这行不容易"。是"你觉得你行，你进来试试"。留话头。
所以别人问我，家政好干吗。我说好干。你来试试能不能出这个门。不是锁了。是你打不开。
```

## ⚠️ 注意事项

1. 腔调：干满了不喊累的状态。平静里带刺。不是诉苦，是陈述。
2. "我还是不会开他家的大门"——停顿一下，字幕打"第二天"。效果拉满。
3. "一瓶都不认识"——可以加一个自嘲的笑，转瞬即逝。
4. "今天干活还挺有排场"——语气是自嘲，不是炫耀。说完嘴角动一下。
5. "没有一个人往这边看"——轻说。最重的句子最轻的说法。
6. "眼里都有星空顶里的泪光"——说到"星空顶"三个字，镜头切回门口的合照。这句是整篇的记忆点，别念太快。
7. 禁止：卖惨腔、抱怨腔、"做家政值得尊重"式拔高、BGM 煽情。
