# 第06稿 · 端午特别：总有人在守护你的家

> 冉总出镜口播，端午切入，核心讲招商。
> 制作建议：今天拍今天剪，赶明天（端午）发。

<font color="#f79646">【画面】冉总坐在办公室或公司走廊，背靠日常环境。自然光。她穿着平时的工作便装，没刻意化妆。镜头离得不远，像朋友在对面坐着聊天。</font>
<font color="#f79646">（不要打灯，不要摆拍感。她要说的第一句话，是"想好了"才说的状态，不是"准备好了"的状态。）</font>
<font color="#f79646">（素材说明：冉总口播主镜头，一条到底，中间不打断，让她自然说。）</font>

<font color="#f79646">冉总开口。</font>

今天是端午。按理说我该坐家里包粽子。
但我没回去。

<font color="#f79646">【画面】切——一冉团队蓝色工装在某个现场干活的手部特写。擦玻璃，泡沫划过。</font>
<font color="#f79646">（声音不切，一直是冉总的旁白。从已有现场素材选取。）</font>

不是我多勤快。
是今天下午有一组外地的客户过来。
他们专门挑端午放假来大连，就想看看一冉到底长什么样。

<font color="#f79646">【画面】回到冉总。她笑了笑，或者正常接话。</font>

这种事最近越来越多。
哈尔滨的，沈阳的，吉林的，山东的。
自己坐高铁过来，到现场看一看，聊一聊。
然后回去，打电话说"姐，我干"。

<font color="#f79646">【画面】现场素材穿插——社区活动现场、工人作业、开荒现场。3-4个画面各1.5秒。</font>
<font color="#f79646">（冉总声音持续。从已有现场素材选取，选有"正在干活"感的画面。）</font>

我就想——他们到底看中了一冉什么？

后来我想明白了。
他们看中的不是一冉接了多少单。
是那些单背后——大单位、港口、政府、妇联、社区书记——
这些人为什么把活交给一冉。

<font color="#f79646">【画面】回到冉总。她语气没有变激昂。</font>

家政这个行业，信任比技术值钱。
技术可以学，三周就学会了。
但你的客户愿不愿意把家门钥匙交给你——
这件事，三年都未必学得会。

一冉15个月，99块钱干到大单位。
不是因为我们广告打得好。
是因为每一个干过的现场，都成了下一个现场的推荐人。

<font color="#f79646">【画面】切一组"人的画面"——冉总跟合伙人聊天、团队开会、收工后一起吃东西。要有烟火气，不摆拍。</font>
<font color="#f79646">（从已有"人与团队"素材选取，选有日常感的。）</font>

然后我就发现——这个模式可以复制。
在大连能跑通，换一个城市，换一个合伙人，也能跑通。

<font color="#f79646">【画面】回到冉总。她看着镜头，语气稍微落一落。</font>

所以我今天没回家包粽子。
我在等那组客户。

不是每一个端午都能等到想干事的人。
但今天我看这个日子挺好的。

<font color="#f79646">【画面】画面慢下来。一冉logo淡入。屏幕下方出字幕。</font>

<font color="#f79646">【字幕】一冉家政 · 全国合伙人招募中</font>

### 制作要点

| 项目 | 内容 |
|------|------|
| 总时长 | 约80-90秒 |
| 画面占比 | 冉总口播 60% / 现场素材穿插 40% |
| 拍摄方式 | 冉总口播一条到底，不打断，自然说 |
| 配音 | 冉总本人（没有第二条声音） |
| 音乐 | 可不要，或铺很低的底乐，不要抢话 |
| 素材来源 | 已有现场素材库 + 今天拍冉总口播 |
| 补拍要求 | 今天拍冉总口播即可，现场素材用现成的 |

### 导演提示

1. 冉总说的时候，让她用跟人聊天的节奏，不用背稿感。说顺了一遍过，说不顺就当她跟一个人讲一件事。
2. 穿插画面不超过2秒，不要打断她说话的节奏。
3. 不要任何特效转场，硬切就行。
