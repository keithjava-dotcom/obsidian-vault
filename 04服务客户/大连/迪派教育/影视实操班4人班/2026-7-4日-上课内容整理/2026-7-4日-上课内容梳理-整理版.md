# 影视实操班 · 文案写作与拍摄实操课

## 一、文案写作核心教学（胡屹鑫文案逐句拆解）

### 1.1 基本原则：遇标点换行

写文案有原则：遇到标点符号就换行。

原句：「如今，26岁的我放弃了6年的汽车工作，开始了新媒体行业的探索。」

书面没问题，但说话时不能这么说，太啰嗦了。改成：「26岁啊，放弃了。」或者「26岁放弃。」

「放弃月入过万的…你修车是什么，领导、厂长吗？」改成：「26岁，放弃了月入过万的小团队长，我辞职了。」干脆明了。

删减判断标准：删了影不影响主题？主题是26岁换行还来不来得及，以及对新媒体的期望。核心是换行转折这件事。

> 「26岁，放弃月入过万的修车团，我辞职了。」

**目标用户**：正在迷茫的年轻人，正在纠结换行、想拍视频、想从事新媒体行业的人。

### 1.2 冲突设计

删除多余解释，制造冲突。

方案一：父母理解你吗？——冲突不够，父母这事对你来说太顺了。

方案二：「我很多朋友都问我为啥又不干了？」——**有冲突才好看**。选朋友不选父母，因为"你为啥不干"才是冲突。

内容不能太顺。有冲突才精彩。

下一个冲突：「我也不知道选择新媒体能否有结果。万一失败了呢？我可能连回去拧螺丝的工作都找不到了。」

**承接**：「好在爸妈说了句……」

结构：**故事背景 → 冲突 → 父母承接**。

### 1.3 学习过程+选择理由

「所以我来到了这里。在众多课程中，我选择了最全面的课程。为什么最全面？因为我不想只学皮毛。」

突出：来到迪派，选择系统课。花了多少钱？——引入具体数字增加真实性。

**技巧·信息重叠**：能在手机上叠加多层信息。
- 表现力OK → 演出来
- 表现力没信心 → 加花字/注释

**举例**：「修车的时候我就懂——换劣质机油、底盘糊弄人。做内容也一样，片子糊弄、运营糊弄就是糊弄自己。」——用自己的本行经验类比，有说服力。

### 1.4 观众获得感

全文最后必须给观众"得到什么"。不然看完只知道你怎么想、怎么做，对我没帮助。

**方法**：
- 假设你的用户在迷茫、在纠结换行
- 给一个真实的观点：「如果你想换行，一定要做新媒体。因为新媒体是可以练脑的职业。」
- 讲做新媒体会得到什么具体好处

观众有获得感之后，再做情绪升华——**不要说"要加油"，来一个真实的情绪收束**。

### 1.5 文案核心原则总结

1. **冲突隔行放**：冲突不要过多，最好隔两行。保证完播率，不容易被划走。
2. **足够具体**：少说"纠结""眼睁睁"这类抽象词，少用形容词，要求具体。
3. **控制时长**：前期尽量拍短。流量高时因为你知道什么是流量，不知道时会焦虑。前期拍短一点。

**作业**：「用相同的思考方法，回去再写两到三篇。」

## 二、通用创作方法论

### 2.1 过山车理论：不能平

太平的内容没人看：
- 你可以极其不好
- 你可以极其多
- 你可以极其闹腾
- **就是不能太平了**

如果人特别平凡，只有一个办法：**提升认知、思维逻辑、脑力**。你总得有一个地方不平凡，才可能被看到。

**情绪曲线 = 过山车**。卡丁车为什么刺激？因为有起伏。一旦平了就不好玩了。

**案例**：
- 马云不说融资30多次跑遍北京上海，你觉得他成功容易感人吗？
- 刘强东不说寒门子弟，有什么值得说的？
- 董明珠不说做了20多年车间工人，怎么有故事？

**先有落差，才有人设**。全球人都喜欢草根逆袭、个人英雄主义——这是人性共性，不是国人专属。

### 2.2 持续创作=信任积累

持续发十条、二十条、三十条。某天一定会有小爆款——平台给你发奖励。

有了爆款，大量人会点你主页看你是谁。一看，原来你是这样的人，就有信任感，**变现力度才更强**。

### 2.3 集中工作法

高效工作流：
1. **每天**：积累灵感
2. **集中**：花一下午或两三个小时深度思考，复盘灵感，集中写
3. **集中拍**：一次拍三条
4. **集中剪**

原理：集中起来脑子会进入心流状态，下一篇一定比上一篇更快。写3-5篇后大脑适应这种强度，就越来越快。

**商业现实**：「一天最少拍五个片子才能赚到钱，要不然不赚钱。」

**服务客户同理**：收集信息→集中写→集中拍→集中剪。一周七天去客户那两天，还能休息一天。一个人做仨账号是轻松的。

### 2.4 作业安排

多写多拍，只有这样才能在作品里看到更多缺陷，才能更好进步。作业做好发群里。

## 三、程钰佳（护士转行）专项辅导

### 3.1 账号诊断

程钰佳账号：95后大连女护士转行自媒体。

开篇：「这是我的第一条vlog，我是一名95后大连女生前护士转行做自媒体。」

**建议**：「以后所有视频都加上这个标签，再干50条。」

**变现分析**：护士个人号变现会比较慢。如果走达人路线，6-8个月没收入。但如果是服务老板拍视频——一个月接两单4000-6000元就过万了。

**两条腿走路**最合适：一边做自己号，一边给老板拍。一个月接两个活就不接了，排满下个月。

**数据现实**：「1000个人自己发，大概只有三四个人能起来。大部分人没学过就开始，你们不用焦虑——你们是学过的。」

### 3.2 账号变现植入

建议在内容里植入一个变现点：
- 爱好方向：看书、看电影、化妆（她追星）
- 或：卖课提成——只需把账号流量做起来，不用交付
- 或：明确「00后在大连自己辞职出来，转行给老板拍视频」——每一条都发这个定位，自然有人找

**核心理念**：「拿相机拍，价格会更贵；拿手机拍，价格上不去。」

## 四、程钰佳文案逐句拆解：护士故事线

### 4.1 开头设计

「如今我坐在桌前，翻出一堆旧物」→ 删掉前面铺垫，直接：「这是我的大学录取通知书。」

故事不讲「怎么上大学」，而是**垂直回忆**：
- 当初高考填志愿，一直以学护理为初心
- 家里姑姑就是护士，受姑姑影响
- 喜欢护理、向往这份职业

**这是"顺"的部分，在推情绪。**

### 4.2 巨大落差：冲突核心

第二部分：正式参加工作，赶上疫情，义无反顾穿上防护服参与救援。

那个时候满身拼劲，满心都是职业和理想。

**关键：**「等到潮水退去才看清理想」——然后来一个**巨大的落差**。

**为什么要巨大：**
- 前面太顺了——受家庭影响、干这个行业、干得很好
- 必须来一个彻底推翻前面所有判断的事情，才精彩
- 否则「这么顺我看什么？」

**真实素材**（学员A提供）：
- 护士长天天找事、职场霸凌
- 因为扎针的事被刁难、被告到护理部
- 长期高压导致身体出问题、吃药的经历

**柯建军的判断**：「一个小女孩，因为家庭影响喜欢这个职业，当上护士，参加工作，参与抗疫，浑身拼劲——然后突然遭遇职场霸凌。因为这个事生病了、抑郁了。花了很长时间才走出来。」**这个故事能火。**

**建议**：
- 不要只说具体小事（扎针被刁难），说大一点、夸张点
- 不说哪个医院就行
- 低谷持续时间：不要说两个月，说六个月
- 「在低谷期，我做过哪些努力？」→ 走出→获得新生→开始学新媒体

### 4.3 第三条视频：护理笔记

「翻看护理笔记，回想每页笔记，表达如此热爱」——这个时候你是有坚定感、信念感的。

**技巧**：把你书桌上的所有物件全总结出几个故事——
- 录取通知书 → 故事一
- 护理笔记 → 故事二
- 毕业证书 → 故事三
- 旧照片 → 故事四

**每个东西讲两到三个故事，这就是起号的全部内容。**

### 4.4 故事结构总结

**必须有结构**：推情绪 → 非常顺非常顺 → 突然掉下来 → 低谷 → 走出 → 新生。

你代表了一类人，观众会代入。

**拍摄建议**：
- 翻点现在照片，翻点以前照片
- 走着拍，再走出来——有情绪曲线在里面
- 让观众坐过山车

### 4.5 成片审阅+封面设计

程钰佳提交了第一条成片。柯建军逐句审阅并提供封面设计指导：

- 画面要干净，主题表达要清晰
- 封面字体建议用正式一些的风格
- 不建议太个人化的花哨字体
- 对比竞品封面：主流都是简洁干净的字体风格

## 五、拍摄与场景实操

### 5.1 场景匹配IP

场景是多维度的：
- 看IP长啥样、气质如何
- 偏甜的 → 白天拍，明调，活泼颜色，丰富艳丽
- 偏深情的 → 蓝调时刻拍
- 偏酷的 → 硬光、硬核场景
- 偏艺术的 → 有设计感的墙

**要匹配IP的性格特点和视频的调性。**

「你在大连能把这个做出来且实施，一个对手都没有。这个是审美，一般人也很难学会。」

**场景示例**（胡屹鑫）：
- 讲过往故事 → 路灯下的台阶，旁边盒饭/酒瓶/半盒烟
- 蹲在台阶上，包放膝盖，边吃饭边说话
- 讲故事时用这个场景 → 更加动人

### 5.2 开放式提问拍摄法

核心技巧：老板背不出稿子，也不能背。我们用**提问来得到他的话**。

**操作**：
1. 知道主题是什么
2. 设计问题问他
3. 让他自然说出来
4. 后期把你的问题剪掉，只剩他的话

**示例**："你今年干了几年？" → "我干修车干了六年。" → "最高工资多少？" → "最高工资一万二。"

把你的话减掉，就剩他的话。根据脚本内容设计提问——这个方法非常实用。会了这个，拍视频可以不用脚本，只需要想好几个主题。

**注意**：「不要告诉老板这是你的技巧，这是你的东西。他学会了就不找你了。」

### 5.3 拍摄技法

**慢门拍法（情绪镜头）**：
- 相机快门调慢，主体保持不动，对焦锁上
- 周边环境虚化 → 代表内心迷茫、混沌
- 适用场景：坐在星海台阶坐到半夜的情境
- 拍路灯、大楼熄灯——都是内容素材

**高光时刻拍法**：引导IP做积极的动作——快走、转身、微笑

**模板关键词搜索法**：拿这些关键词去抖音搜，看好的作品模仿。现在学习就是多模仿，学完直接提高收入。

**焦段组合制造张力**：
- 中远景：24-50mm
- 特写：70mm+
- 组合：中景+特写、远景+特写、中远景+特写 → 构图上的张力

### 5.4 色调的情绪属性

- 迷茫、混沌的内容 → 冷调、暗调
- 成功的喜悦 → 暖调、亮调
- 色调不同，观众就有坐过山车的体验

## 六、学员问答

### 6.1 就业方向

**学员问**：学完能不能找到工作？不是专业出身人家会要吗？

**柯建军**：有作品就能说话。你们上完课，出去就能干活。

**现实**：在短视频行业，上班也干不长。外企运营不太依赖线上，国内是结果导向。你能操盘就去操盘，否则就去公司当拍摄或剪辑。

**创业建议**：你们四个组个团——一个拍、一个写、一个剪、一个接活。做一个号「我是00后，在大连勇闯老板拍视频」。把日记变视频发出去——今天学了什么、有什么收获、明天学什么。想找活不难。

### 6.2 TikTok/海外

逻辑一样，只不过用户变成外国人，同样需要分析海外市场。但那很难做。

### 6.3 线上剪辑兼职

**学员问**：线上剪辑视频兼职靠谱不？

**柯建军**：不靠谱。

### 6.4 设备选购

- 补光灯：相机和手机通用的小方块灯就行，要有常亮+闪光两种模式
- 手机自拍支架+灯组合
- Pocket有附赠补光灯
- 稳定器：省钱法——用袋子做三角形结构就很稳。有钱可以买DJI mini

## 七、账号策略

### 7.1 标签机制

平台根据内容给账号打标签。不是高级东西，是普通机制。

如果账号里杂七杂八啥都发——明星、生活、美食、旅游，平台识别不了你是什么账号，不知道怎么推，就不推了。

**解决**：把其他类视频全部转私密，只保留一种内容类别。专注做生活vlog就只发vlog。

### 7.2 学员C账号诊断

学员C发过400多个作品（追星、生活混发），播放量极低。

**建议**：
1. 所有作品全部转私密（不删，留着）
2. 然后重新开始发统一类别的内容
3. 追星内容有风险，容易被明星起诉
4. 建议方向：个人vlog，带自己的观点和看法

**核心**：「自媒体就是所有事情与我相关。比如"我觉得肖战真帅"——这是你的看法，可以说。」

## 八、封面设计实操

### Photoshop封面步骤

以「凤城火锅霸王餐」封面为例，完整演示：

1. **抠像**：复制两个图层→上层转智能对象→自动抠人→描边（虚线/实线可选）
2. **主标题**：选字体+字号→用吸管取画面颜色→加描边
3. **背景**：加色块背景→调低不透明度→让字突出
4. **关键词放大**：「霸王餐」单独加大字号，换红色（吸引眼球）
5. **副标题**：手写体/卡通体，绿色/白色，加描边+阴影
6. **排版**：价格字号放大但不挡脸

**设计原则**：颜色和画面呼应，主次分明，干净清晰。

## 内容判读

### 辨伪

- **「1000人只有3-4个做起来」**：这是经验数据，不同平台、不同时段的成功率差异大。作为激励学生认真学习的说法有效，但不建议作为对外宣传的精确数据。
- **「在大连一个对手都没有」**：鼓励性质的说法，非客观竞争分析。
- 本轮未发现明显错误。其余内容为实操经验分享，真实有效。

### 补充

- **冲突设计**：选朋友不选父母的原理是**冲突的烈度决定观看动力**。最强冲突来自"本可能安稳却选择冒险"——这刚好是胡屹鑫"放弃月入过万"故事线的核心驱动力。
- **过山车理论**：电影剧本中称"情绪节拍表"（Beat Sheet），好莱坞主流结构是"顺境→打击→低谷→反弹→高潮"。课堂上讲的就是这个闭环。
