# 第一部分：先说清你帮谁解决什么问题

## 一、你的视频到底给谁看

🔴 **最清楚的定位 = 一个人 + 一个阶段 + 一个问题**。

- **一个人**: 小雯——法语专业大四，不知道该找什么工作
- **一个阶段**: 大学毕业前后，专业技能有（法语），但不想走"法语老师/翻译"的老路，迷茫中
- **一个问题**: 除了本专业，我还能做什么？我想试试新媒体但不知道怎么开始，家里人也不理解

→ **一句话定位**: 给那些"有一技之长但不知道往哪走"的文科生，看一个法语专八的女孩怎么从0开始学新媒体，用真实过程告诉你：你不只有一条路。

## 二、目标用户深度画像（一个具体的人 + 来源群体）

### 目标用户昵称
- **名字暂叫**: 小雯

### 来源群体

- **种子顾客**（现阶段能服务到的）: 外语专业/文科在读或刚毕业的大学生。她们和茉莉雨有相似的处境——专业"不实用"、不知道能做什么、对新媒体的好奇大于恐惧。为什么：茉莉雨就是她们的镜子，她懂她们的迷茫。
- **理想顾客**（账号成熟后要服务的）: 20-26岁有专业积累但想转行的年轻人，不限于文科。律师助理想做自媒体、会计想转运营、护士想做博主……凡是"有一样本事但不想被框住"的。为什么：茉莉雨的底层问题是"专业技能怎么变成新的可能性"，这个问题跨行业通用。
- **边缘围观**（可能围观，不付费）: 对个人成长、语言学习、新媒体感兴趣的泛人群。她们来刷一条就走，不一定会转化，但能贡献播放和评论。

### 具体目标用户·8字段

1. **学历**: 本科在读或刚毕业，法语/外语/文科专业
2. **经济水平**: 月生活费1500-3000元，或刚毕业月薪4000-6000元 ⚠️（推断）
3. **消费理念**: 愿意为"能让自己变好"的东西花钱——报班、买课、买设备，但每一笔都掂量值不值。3000块的课可以，30块买了没用的东西心疼。花之前会反复确认"这钱花了我能有回报吗"。
4. **婚姻/恋爱状态**: 单身或有男朋友，感情不是当前生活的重心
5. **生活节奏**: 不是传统学霸——刷抖音、刷小红书，碎片时间多但不知道怎么用。想学东西但容易拖延。睡前躺床上刷视频，刷完更焦虑。
6. **愿意为什么付费**: 能带来实际改变的课程/方法/工具——不是"改变认知"那种虚的，是"教我怎么剪第一条视频""法语怎么自学过B2"这种能动手的。
7. **此时此刻关心什么**: "我到底能做什么？""学了这个专业是不是就只能干这个？""家里人催我考公/找稳定工作，但我不想。""看别人做自媒体赚了钱，我能不能也试试？"
8. **平时刷视频的习惯**: 抖音为主，晚上10点后刷得最多。刷的内容：学习方法类、个人成长类、偶尔刷到有趣的脑洞/创意视频。刷的时候觉得"这人讲得好有道理"，刷完继续躺着。

### 谄媚陷阱自检

- 你的内容打扮/语气/选题在讨好谁？→ 年轻女孩、迷茫的同龄人。✅ 对得上。
- 那个人是不是你真正的张小阳？→ 是。小雯就是茉莉雨自己的镜子。
- 有没有下意识讨好其他群体（比如法语专业的人、家长、体制内的人）？→ 内容不要写成"给法语生看的"，要写成"给迷茫年轻人看的，法语是我的武器不是我的牢笼"。

### 敌人列表

茉莉雨的账号必须明说"我反对什么"。以下既是她的立场声明，也是最强的内容筛子——不对的人看到这些会自动取关：

1. **"以稳定之名扼杀可能性的保守思维"** — 不是体制不好，是"只能体制内"这个唯一答案在扼杀年轻人。
2. **"把教育做成话术流水线的工厂"** — 逼单、制造焦虑、卖课不管效果的教培套路。
3. **"用廉价娱乐替代真实价值的流量逻辑"** — 装疯卖傻、擦边、制造对立只为了播放量。
4. **"未经思考的从众"** — 别人考公你就考公、别人考研你就考研、别人做自媒体你就做自媒体——从来没问过自己"我到底想做什么"。

## 三、商业变现设计

内容积累（信任）→ 主页/评论区 → 私域/微信 → 轻付费产品 → 代运营/深度服务

**节奏逻辑**:
- 不追求快速成交，追求"她讲的东西对我有用"的信任积累
- 前3个月：纯内容积累，不推任何产品
- 3-6个月：开始提供免费资源（法语学习工具包、新媒体入门清单）引流到私域
- 6个月后：轻付费产品（9.9-99元的法语学习小课/新媒体入门指南）
- 12个月后：如果自己账号数据好，可以接代运营

**客单价与周期**:
- 轻付费产品: 9.9-99元
- 代运营: 按市场价（取决于账号阶段）
- 0-3个月养号期 → 3-6个月信任积累 → 6-12个月初步变现


# 第二部分：别人为什么愿意相信你

## 四、终局课题

- **茉莉雨3年后应该被定义为**: "年轻人第二曲线探索"领域的陪伴者。不是法语老师，不是新媒体教练——是那个"从法语转行新媒体成功了"的例子，她的存在本身就在告诉同类人：你可以。
- **终局课题**: "专业技能不是牢笼，是你可以带走的武器。"——她帮年轻人看到，你学的那门专业不是只能做那一行，它是你的差异化底牌。
- **当前阶段做的内容如何指向终局**: 她每天都在展示"法语生怎么学新媒体"这件事。观众不是来学法语也不是来学剪辑，是来看"一个人怎么把学过的本事变成新的可能性"。这个行为本身就是终局课题的证明。

## 五、为什么你能

- **你已经有的**: 法语专八——这证明你有学习能力，不是随便说说
- **你经历过的**: 高三转学、2个月减20斤、辩论队从一辩到四辩拿最佳辩手——你认准的事干得成
- **证明你行的**: 从"不敢跟陌生人说话"到"你说的不对我就想跟你沟通"——你被辩论改变了性格，现在你能面对镜头
- **你正在做的**: 每天在迪派学影视实操、拆片子、拍视频——你不是空想，你在动手

## 六、人设标签与阶段释放

### 6.1 人设标签

**身份标签**（最多4个，真实可验证）:
- 法语专八
- 大学辩论队最佳辩手
- 迪派影视实操班学员
- 2个月减重20斤的狠人

**性格标签**（最多3个，来自真实表达）:
- 真诚不装（自己承认拖延、啰嗦）
- 有反骨（全家体制内但坚决不走）
- 认准的事豁得出去

**价值标签**（最多3个，对用户的好处）:
- 带你看真实的新媒体入门过程
- 法语学习方法可以抄作业
- 年轻人职业选择的另一种参考答案

### 🔴 突出 ≠ 社会地位

茉莉雨的突出不是学历和证书——法语专八不值钱，值钱的是**她选了法语专八之后却跑去学拍视频这个决定**。

- **审美**: 她不喜欢"装"的内容，对真实有本能的好恶判断
- **角度**: "我已经有一门技能了，但我偏要从头学另一门"——这不是失败者的故事，是选择者的故事
- **故事**: 辩论队改变了她的性格——这是私人经历里最能立人设的一段
- **软肋**: 怕让家人失望、怕投入没回报——这不丢人，这是真实，观众共情的就是这个
- **坚定立场**: 反对教育行业的销售套路，反对"只有一条路"的思维

### 6.2 阶段性释放节奏

- **早期（0-3个月）单点突破打的标签**: 法语专八 + 正在学新媒体 + 真诚不装。第一印象只钉3个词：**有本事的普通人、正在学、说真话**。
- **中期（3-6个月）释放的标签**: 辩论训练的逻辑能力 + 减重20斤的执行力 + 反骨性格。这时候观众已经信你了，可以放更多面。
- **后期（6-12个月）立体化方向**: 从"正在学"到"学到了"的过渡。身份从学员变成有成果的人，可以带别人了。
- ⚠️ 警告: 不要上来就把所有标签堆出来——"我是法语专八+辩论最佳+减肥20斤+体制内反叛者+自媒体新人"——观众精神分裂。早期只钉3个词。


# 第三部分：你出镜时要给人什么感觉

## 七、情绪基调定调

- **主基调**: 陪伴成长——真诚、不装、边走边分享。"我不是已经做到了，我是正在做，你来看着我怎么做。"
- **辅基调**: 偶尔的锐利——辩论训练留下的逻辑拆解能力，在分析行业现象、拆片子、怼套路的时候露出来。
- **参考博主**: ⚠️ 待搜索确定。建议方向：年轻女性成长类、陪伴学习类、个人IP从0到1记录类。
- **音乐风格**: 轻快温暖，有节奏感。不要太"emo"也不要太"燃"，选"一个人认真做事的背景音"。
- **光线建议**: 自然光。白天窗边、夜晚台灯——生活场景，不要摄影棚感。
- **语速建议**: 偏快但句间有停顿。她本身说话语速不慢，辩论训练有加成。关键是：像对朋友说话，不是念稿。
- **说话姿态**: 平视。坐在桌前、靠在沙发、走在路上——就是"咱俩聊一聊"的感觉，不是"我给你讲个课"。

## 八、视觉符号大原则

### 整体色调/时间感
自然光为主，暖调偏好。白天拍优先——阳光+干净的画面，传递"正在成长"的朝气。

### 恒定人设符号（物件）

- **法语书籍/笔记**: 替她说"我不是随便说说，我真是法语专业的"。桌上摊开的法语书、手写笔记——不是摆拍，是她的日常。
- **Pocket4/拍摄设备**: 替她说"我在认真学这个"。设备不是炫耀，是"我投入了，我是认真的"。
- **运动装备（跳绳/骑行头盔）**: 替她说"我不只动脑子，我还动身体"。2个月减20斤的证明。

⚠️ 3个够了。不要加一堆——书架上的小说、毛绒玩具、化妆品跟她的人设没关系，硬摆就是装。

# 第四部分：前期先拍什么内容

## 九、三大内容支柱

### 支柱一：新媒体学习日记（占40%）
记录她每天在学什么、遇到什么问题、怎么解决的。拆片、拍摄练习、剪辑踩坑、设备使用心得。
- 选题方向: "第一次拍口播，我NG了37次""拆了一条爆款视频，发现了一个万能开头公式""剪辑软件差点把我逼疯的3个瞬间"
- 目标: 立人设 + 拉新（这种内容最容易引起同行和同阶段学习者的共鸣）

### 支柱二：法语/语言学习方法（占30%）
分享她怎么学法语、怎么过专八、语言学习的底层方法。不是教法语——是分享学习方法论。
- 选题方向: "我过专八用的不是刷题，是这一件事""学了法语再看英语，发现了很多好笑的事""法语和中文思维方式的根本区别"
- 目标: 展示专业性 + 提供实用价值（这是她的核心武器）

### 支柱三：成长故事和态度（占30%）
讲她自己的经历和观点。辩论改变性格、体制内家庭的反叛、减重20斤、年轻人的职业选择。
- 选题方向: "我全家都在体制内，只有我在学拍视频""INFP是怎么被辩论改变性格的""我2个月瘦了20斤，不是靠自律是靠恨自己"
- 目标: 情绪共鸣 + 传播引流（这类内容最容易出爆款）

# 第五部分：接下来怎么执行，哪些坑先避开

## 十一、平台策略

| 平台 | 定位 | 理由 |
|------|------|------|
| 主战场 | **抖音** | 她自己说爱刷抖音、什么都知道一点；年轻用户集中；成长类/学习类内容有流量 |
| 辅助 | 小红书 | 年轻女性用户多，学习/成长/生活方式类内容匹配；图文可以做学习方法总结 |
| 暂不做 | B站、视频号 | 原因: B站长视频对新人难度高；视频号用户偏大龄，不是她的张小阳 |

## 十二、你可能面临的问题

| 问题 | 应对方式 |
|------|---------|
| 投入了没看到回报就开始焦虑 | 前3个月不看数据只数条数——发了20条再说。回报不是前几条就能看到的，筛子需要时间搭 |
| 家里人催、不看好 | 不解释、不争辩，用第一条视频数据说话。哪怕只有500播放，也比"我在努力"有说服力 |
| 完美主义拖慢节奏 | 定死规则：一条视频从拍到发不超过3天。烂的发了比好的没发有用100倍 |
| 被熟人看到觉得尴尬 | 前10条发完就习惯了。而且你的张小阳不是熟人——他们看不看无所谓 |
| 方向太多分心 | 死磕一个账号、一个主方向。情侣账号和代运营是半年后的事，现在想就是分散精力 |

## 十三、做了你会得到什么

- **1个月**: 发出6-8条视频，找到"拍视频的感觉"，不再对着镜头紧张
- **3个月**: 20条以上内容，有1-2条数据明显好于其他的，知道什么方向观众爱看
- **6个月**: 有稳定的更新节奏，有一小批固定观众（不是粉丝数，是每期都会来看的人），开始有私域流量
