## 选题A：课间饿——「为什么零零后永远在课间买吃的」

### 交接卡
- 任务链ID：迪派·零食姑娘-002
- 含金量分级：A
- 状态：待拍板
- 上游：素材卡S02（第三天课堂）
- 递给 fanwen 的一句话：零零后课间必须吃东西的真实原因，不是嘴馋，是科学。最后落回「怎么吃才对」。

### 谁会看

**画像**：高中生，每天第三节课后肚子开始叫。心里知道该吃点什么但不知道什么最扛饿。

**人群往外扩**：所有学生党 + 刚毕业还记得课间饿的年轻人。刷视频场景：课间刷到，或者晚上饿了刷到。

### 含金量体检

| 六闸 | 结果 | 证据 |
|---|---|---|
| 意识形态性 | ✅ | "饿是真实需求不是罪过"——年轻人买账 |
| 速判性 | ✅ | 标题就是真实生活，瞬间代入 |
| 高效性 | ✅ | 数据(课间时间)/对比(不同零食扛饿效果)/科学解释(代谢)/推荐/价格 |
| 时效性 | ✅ | 学生永不过时的话题 |
| 原子性 | ✅ | 可拆独立推荐块 |
| 刺激性 | ✅ | "你不是嘴馋"这个反转给情绪 |

**分级**：A 级。

### 骨架卡

- **锚定对象**：观点——「零零后课间饿不是嘴馋，是身体在求救」
- **结构**：清单式｜骨架动力：③共鸣性推进 + ④理性逻辑（先扮演反方）
- **最高任务**：种草（用知识带出产品推荐，自然不硬）
- **对抗轴**：
  - 开头：人与众人（「大家都觉得你嘴馋」→ 打掉这个标签）
  - 中段：人与内心（「那我到底该吃什么」→ 提供判断标准）
  - 结尾：人与世界（「吃这些，第三节课后满血复活」）

### 发散点

**素材卡引用**：本条用 S02

**核心原文**：
> 「很多人他在学校有的时候吃不饱，真吃不饱」「我们饿得快，年轻嘛」「课间必须下楼买点儿吃的」

**怎么拍（从开头到结尾）**：

**开头（10秒定生死）**：
- 镜头对着学校走廊/课间的人群，上课铃刚好响完
- 第一句话：「你身边有没有这种人——第三节课必须吃一包干脆面，不然熬不到放学。你以为ta嘴馋？来，我们看一组数据。」
- 【反方】「有人说：忍一忍不就过去了，课间十分钟还吃东西不嫌麻烦？」→ 然后打掉这句话

**展开（干货+推荐）**：
1. 为什么高中生特别容易饿（生长激素+大脑消耗+身体代谢——10秒讲完，不要上课腔）
2. 最常见的课间零食误区：膨化食品→血糖过山车→第三节课更困；含糖饮料→短暂提神后崩溃
3. 【推荐·你的店穿插】拿出3-4样零食，逐个说：
   - 「这个——全麦饼干，扛饿指数最高」
   - 「这个——坚果条，能量密度够又不会犯困」
   - 「这个——无糖酸奶，比含糖的奶茶强十倍」
4. 穿插对比实验：一手拿膨化食品一手拿推荐零食——「左边吃完20分钟就饿，右边撑到放学」

**结尾（金句+落点）**：
- 「你不是嘴馋。你的身体在长、你的大脑在烧、你的代谢在飞。粮食选对了，它才是你的队友。」


## 选题B：偷偷卷——「大家在玩的时候，我偷偷做了什么」

### 交接卡
- 任务链ID：迪派·零食姑娘-003
- 含金量分级：B（挂：时效性一般，「偷偷卷」概念已被多次使用，但素材真实可补救）
- 状态：待拍板
- 上游：素材卡S03（第三天课堂）
- 递给 fanwen 的一句话：揭示零零后「假装佛系、偷偷内卷」的真实心态。零食是陪他们偷偷努力的道具。

### 谁会看

**画像**：高中/大学生，嘴上说着「没事我都没复习」，背地里在偷偷学。他们有一种「被发现努力就会不好意思」的微妙心态。

**人群往外扩**：所有经历过「偷偷努力」阶段的人——上班族学技能、考公考研党，心理完全一样。刷视频场景：深夜刷到，内心莫名被戳中。

### 含金量体检

| 六闸 | 结果 | 证据 |
|---|---|---|
| 意识形态性 | ✅ | 「偷偷努力不丢人」——正向价值观 |
| 速判性 | ✅ | 「偷偷卷」三个字年轻人都秒懂 |
| 高效性 | ⚠️ | 信息点3-4个，边缘——需靠深度共鸣补 |
| 时效性 | ⚠️ | 「卷」已被广泛讨论，但「偷偷卷+不表现」的细腻心态是新的 |
| 原子性 | ✅ | 可拆：现象/心理分析/我的做法/零食助攻 |
| 刺激性 | ✅ | 「这不是我吗」共鸣强刺激 |

**分级**：B 级（挂高效性和时效性各半格，但素材真实+心态细腻可补救）。

### 骨架卡

- **锚定对象**：事——「一个偷偷内卷的零零后的真实24小时」
- **结构**：发展式｜骨架动力：③共鸣性推进（从凑热闹到逐步共鸣）
- **最高任务**：人设（建立「我懂你」的信任感）+ 种草（零食是陪你努力的伙伴）
- **对抗轴**：
  - 开头：人与内心（「我想努力，但我不想被人看出来」）
  - 中段：人与世界（周围都在玩→我偷偷做自己的事）
  - 结尾：人与内心（「努力不需要表演给别人看」）

### 发散点

**素材卡引用**：本条用 S03

**核心原文**：
> 「内心卷，不表现出来」「他们都去吃饭了，我再学一会儿」

**怎么拍（从开头到结尾）**：

**开头**：
- 教室里大家都在聊天/吃饭，声音嘈杂
- 你端着饭盒但低头在看笔记本/手机刷题——画面要让观众看出「这个人在偷偷干啥」
- 旁白/字幕：「我从来没跟任何人说过我晚上回去复盘笔记。因为说了，他们就会说'你好卷啊'。」

**展开**：
1. 【共鸣】「有没有人跟我一样——在外面说'哎呀都没复习'，回到家把错题本翻了三遍」
2. 「大家都去吃饭的时候，我终于可以安安静静地——写完这篇英语阅读」（镜头：你一个人坐在空教室里吃着一袋零食旁边是打开的练习册）
3. 「但我不是那种朋友圈发大夜学习的卷王。我连我爸妈都不知道我晚上几点睡。」
4. 【零食桥段】「这是我最喜欢的深夜款——不太甜，不会腻到犯困。吃完刚好做完最后三道题。」
5. 「还有一种是考前的——考前紧张到什么都吃不下的时候，吃这个最舒服。」

**结尾**：
- 回到「大家都去吃饭了，我再学一会儿」的场景——这次镜头拉远，你笑了一下
- 「努力不需要表演。你觉得我佛，是因为我只在自己的时间里拼。」


## 选题C：社交破冰——「我用一包零食，换了一个故事」

### 交接卡
- 任务链ID：迪派·零食姑娘-004
- 含金量分级：A
- 状态：待拍板
- 上游：素材卡S04（第三天课堂）+ 柯老师课堂建议
- 递给 fanwen 的一句话：一包零食换一个真心话/愿望。拍街头社交实验，用零食做破冰道具。真正的爆点在路人的真实反应。

### 谁会看

**画像**：社恐的年轻人，想认识新朋友但不知道怎么开口。想看看「别人是怎么做到的」，可能是好奇、可能是想学、可能是单纯喜欢看真实的陌生人互动。

**人群往外扩**：所有喜欢看温暖/有趣真人互动的观众——不一定是社恐。刷视频场景：晚上无聊刷到，被某一段对话打动。

### 含金量体检

| 六闸 | 结果 | 证据 |
|---|---|---|
| 意识形态性 | ✅ | 人与人的善意连接——天然正向 |
| 速判性 | ✅ | 2秒看懂：「这个人拿零食跟陌生人换什么东西」 |
| 高效性 | ✅ | 每条至少3-5个路人，每个路人都是一个信息点 |
| 时效性 | ✅ | 社交实验类内容持续热门 |
| 原子性 | ✅ | 每个路人的互动是独立单元 |
| 刺激性 | ✅ | 不可预测的路人反应=天然的悬念和笑点 |

**分级**：A 级。

### 骨架卡

- **锚定对象**：事——「我拿着零食在街头问陌生人：你想换什么？」
- **结构**：清单式（每段换一个人）｜骨架动力：②戏剧性推进（每个路人都是一场迷你故事）
- **最高任务**：获客（让观众记住「这家店的零食能破冰」）
- **对抗轴**：
  - 每段：人与人（你vs陌生人——打破社交距离的迷你对抗）
  - 整体：人与内心（「我能做到吗」→ 越做越顺）

### 发散点

**素材卡引用**：本条用 S04 + 柯老师补充的社交实验方向

**核心原文**：
> 「我们同学自己带点糖，而且是韩国进口糖」「用零食换一个愿望、换真心话」
> 「人的底层内心还是挺善良的」
> 「用一个零食换你一个愿望，换点真心话」

**怎么拍（从开头到结尾）**：

**开头**：
- 你站在学校门口/商场门口/街头，手里举着一袋包装好看的零食
- 第一句话：「今天挑战——用一包零食，跟10个陌生人换他们的一个故事。没有人能拒绝零食，对吧？」

**形式**：固定套路，每个路人30-40秒
- 走上前：「你好，送你一个零食——但有个条件，你要回答我一个问题。准备好了吗？」
- 路人反应（这部分是真的，不能演）
- 问题库（轮换用）：
  - 「今天最开心的事是什么？」
  - 「你最近一次哭是因为什么？」
  - 「跟一个人说一句你从来没说出口的话」
  - 「许一个今晚就会实现的愿望」
  - 「你手机里最舍不得删的照片是什么，为什么」

**剪辑节奏**：
- 快速过2-3个拒绝你的人（好笑的那种：「不用谢谢」「你是不是骗子」）→活跃节奏
- 重点放3-5个有趣的回答（好笑+感动+意外）
- 结尾用最打动人的那一段

**结尾**：
- 你看着最后一个路人离开的背影
- 「零食是个借口。其实是我想听你的故事。」
- 画面定格在零食袋和笑脸。

**注意事项**：
- 真的送，不是演。路人反应越真实越好看。
- 给路人打码或征求同意。
- 心态：有人拒绝你=视频更好玩，不怕被拒。
- 选颜值高的进口零食（比如韩国糖、日本巧克力）——送人不会太差。

## 📋 拍摄通用备忘

**打光和拍摄**：
- 室内：找自然光好的位置，或者买个几十块的环形灯
- 小红书：把零食拍出高级感——选颜值高的零食、背景干净、光线柔和（柯老师的原话：把零食拍成他买不起的样子）
- 横屏16:9拍抖音，竖屏9:16拍小红书（分开拍，不用同一条发两个平台）

**剪辑节奏**：
- 前3秒必须给信息（不能是黑屏+字幕，不能是慢慢走进来）
- 字幕要加大，年轻人不看小字幕
- 背景音乐挑活泼的，但声音不要盖过说话

**账号信息**：
- 【作业】你的账号名称是什么？告诉我，我帮你做过账号档案。
- 【作业】你的个人小红书号也在做吗？目前什么方向？
