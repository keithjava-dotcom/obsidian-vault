# 许老师 客户分析

## 2A · 基础六维度分析

### 1. 语感特征

- **高频词和口头语**："属实""其实""然后""就是""这样子""对……对……"；提问句式多（"你想想……""他是不是……"），习惯用提问引导而非直接下结论
- **句式习惯**：中长句为主，逻辑链条清晰，不跳跃。喜欢"先讲观点→再举例→最后总结"的三段式。不用华丽辞藻，用朴素语言说透一件事
- **情绪基调**：理性沉稳为主，带温暖真诚。不是热情洋溢型，是靠谱稳重型。说话有"我在帮你分析问题"的感觉，没有压迫感
- **绝对不会说的话**："限时优惠""名额有限赶紧报名""学完月薪过万"——夸张营销话术；过度承诺；贬低同行的话

### 2. 核心差异化（按竞争力六维度对照）

| 维度 | 适用性 | 分析 |
|------|--------|------|
| 正（相同价值更专业） | ❌ 不推荐 | "最专业的教培销售"没有记忆点，也难和大机构IP竞争 |
| **反（相反价值）** | ⭐⭐⭐ 最强 | **"教培销售都功利，我偏不"**。行业刻板印象=销售忽悠你交钱。她反着来：先帮你做职业规划，课程只是工具。这是最强差异化的根基 |
| **和（交叉合并）** | ⭐⭐⭐ 叠加 | 教培销售 + 职业生涯规划师 + 考证达人。不是"卖课的"，是"帮你找到方向的人"。三重身份叠加，辨识度远高于单一标签 |
| 跨（跨界冲击） | ⭐⭐ 可用 | 用教练技术做销售——提问而非推销。这也是反行业常规的做法 |
| 入（下沉/利基） | ⭐⭐ 可用 | 深耕大连本地就业技能培训，切"想转行但不知道该学什么"的痛点 |
| 弱（以弱胜强） | ⭐ 辅助 | 她不是技术专家，但"最懂转行路径的教育顾问"——这个"不专业"恰恰强化了"不说专业术语、只说人话"的信任 |

**推荐策略**：反 + 和 叠加。"教培行业的另类销售"是人设锚点，"销售+规划+考证"是内容弹药。

### 3. 目标受众

**第一受众（理想顾客）**：在大连的、25-35岁、想学一门技能转行或提升收入、但对培训机构不信任、怕被忽悠的年轻人。学历背景：大专到本科为主。他们刷短视频时会搜"学什么技术好找工作""转行学PLC靠谱吗"。

**第二受众（种子顾客）**：有工作但想考证/学新技能做职业储备的人。他们不急着报名，但会持续关注有价值的信息。

**平台聚集**：抖音为主（搜索+推荐），小红书为辅（职业规划类内容）。

### 4. 变现目标

- **核心变现**：通过内容建立信任 → 引导到迪派教育线下咨询/体验 → 报名课程
- **辅助变现**：线上课程推广（远期）
- **时间预期**：前3个月打信任基础，6个月后稳定获客

### 5. 内容潜力

**能持续输出的方向（5个）**：

1. **"教培销售跟你说实话"**：哪个技能值得学、哪个是坑、企业招聘时到底看什么——以销售身份说行业真话，天然有反差
2. **学生真实案例**：帮日本工作签学生的故事、帮转行迷茫的人找到方向——每个案例都是信任资产
3. **考证真相**：建工证/会计证/消防证到底值不值得考？投入产出比是多少？——她自己考过一大堆，有资格讲
4. **行业趋势解读**：PLC电气自动化、工业机器人、AI——这些技能未来几年需求怎样，什么人适合学
5. **职业规划问答**：用教练式提问帮观众理清"我到底适合学什么"——用她最擅长的提问方式做内容

**最有爆款潜力**：方向1。"教培销售说大实话"这种反行业刻板印象的内容，天然自带传播力。

**内容储备**：充足。十几年接触上千个学生案例，行业认知深，考证经历丰富。

### 6. 风险提示

| 风险 | 说明 |
|------|------|
| 内容广告感太强 | 她已自述"营销性太强导致流量少"。原因是口播内容在"介绍学校"而非"提供价值"。解决：前6条不提迪派，先立人设 |
| 文案功底弱 | 自述"文案功底不是很好"，需要借助AI或他人。但她有想法——用提问激发比替她写好更有效 |
| 理性气质vs短视频网感 | 她不幽默、理性。这不一定是缺点——真诚稳重的教培IP反而稀缺。但需要注意：理性不是"干讲干货"，要用案例和故事包裹 |
| 期望管理 | 她希望"高投入产出比"，但账号前期播放不会高。需提前说清楚：精准获客50个播放比泛流量5万播放值钱 |

## 2B · 人设挖掘七维度

### 1. 故事性

**核心反差点**：原本最讨厌销售的人 → 成了教培行业最受信任的销售。这不是技巧的结果，是价值观的结果。

**关键故事素材**（一个素材可从N个角度反复讲）：

- **面试转折**：刚毕业时不喜欢销售（觉得销售=坑蒙拐骗）→ 入职迪派遇到校长 → 校长说"一个家庭把孩子和钱都给了学校，你凭什么不好好对他们负责" → 这句话让她接受了销售工作
- **最高光时刻**：新加坡本科毕业的孩子想留学日本 → 她建议"学日语+学开发技术，走工作签" → 省掉每年几万块语言学校费用 → 学生和家长特别感谢 → "帮一个学生改变了职业生涯，比赚钱更有自豪感"
- **身份反差**：她是销售，但客户说她"不像销售，更像规划师"

**每个故事都在讲同一件事**：这个销售不卖你东西，她帮你做选择。

### 2. 性格、品行、人格魅力

**真实特质（不是凹出来的人设）**：
- ✅ 真诚不功利：钱赚得心安理得，学员有收获她才觉得对等
- ✅ 理性沉稳：说话不夸张、不煽情，用分析和提问代替推销
- ✅ 责任感强：校长的话影响了她十几年，对学生的责任感已经内化
- ✅ 持续学习者：每年考证让自己增值，PLC、AI都想学
- ✅ 共情能力强：能理解学生和同事的想法、情绪
- ✅ 民族自豪感：为自己是大连人、中国人感到自豪

**⚠️ 删掉这些博主想象词**：接地气、活泼、搞笑、帅气——她不是这个路线，别硬凹。

### 3. 与观众的关系（五种姿态选择）

**主姿态：服务者/手艺人**

她不是要"开宗立派"创造新概念，也不是要当高高在上的导师。她提供的是一项具体服务：用十几年的经验和上千个案例，帮你找到适合自己的学习方向。

**辅助姿态：同道中人/灵魂伴侣**

对学生群体——"我也是这么过来的，我陪你走"。

> ⚠️ 她说想做"导师状态"，但在短视频里，"导师"容易变成说教（"你应该学XX""你必须考XX"）。**更安全更有效的姿态是"解惑者"**：我见过足够多案例，我帮你分析，你自己做决定。这和她的教练式提问习惯完全一致。

### 4. 三观/意识形态

**她认可的**：
- 教育要对得起学生和家长的信任
- 销售的本质是匹配，不是忽悠
- 人要持续学习、不断增值
- 钱赚得心安理得，比赚得多重要

**她坚决反对的**：
- 坑蒙拐骗式的销售
- 为了业绩推不适合的课程给学员
- "黑红"路线——用负面形象博流量

**个人简介建议**：履历 + 三观混合，不写"我是XX销售"，写"在迪派教育十几年，帮过上千个学生找方向的人。我相信教育要对得起信任。"

### 5. 愿望/渴望/个人目标

- **短期目标**：账号粉丝过万，有稳定精准获客
- **中期目标**：成为大连教育行业有辨识度的个人品牌
- **长期目标**：建立线上+线下课程体系
- **个人喜好**：考证、学习新技能（PLC、AI、工业机器人）
- **软肋/局限**：不幽默，做不到搞笑路线；文案功底弱

### 6. 情绪基调（早期单点定调）

**主基调：理性真诚 + 沉稳可靠**

- 不是激情澎湃型，不是幽默搞笑型，不是温情催泪型
- 是那种"安静听她说完，你觉得这个人不会骗你"的感觉
- 像一个你信任的前辈，坐下来帮你分析问题

**辅基调**：偶尔温暖——在讲学生案例时可以流露真实情感

**参考博主方向**：教培/职业规划领域，说话不紧不慢、靠内容密度和真诚度留住人的类型

**配套元素**：
- 音乐：安静有质感的背景音乐，不抢人声
- 光线：自然光或暖调，不冷
- 语速：中等偏慢，有思考感，不赶

### 7. 思维习惯（MBTI对照）

**推测类型**：STJ/SFJ 方向（务实、责任驱动、关注具体结果）

**对应内容形态**：
- ✅ 讲知识（抽象逻辑）——适合做考证分析、行业趋势、技能对比
- ✅ 讲故事（过去经历）——适合做学生案例、个人转折点
- ❌ 匠人匠心（沉浸小天地）——不符合
- ❌ 生活日常（活在当下）——不符合

**最佳内容组合**：用具体案例切入 → 引出行业洞察/职业规划方法论 → 回到观众自身（"你现在的情况，可能是……"）
