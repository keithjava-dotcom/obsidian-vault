## 一、咨询背景

江苏合伙人冯丽（冯总）在江苏做家政，发了几组对标账号给柯建军看，寻求账号定位和内容方向建议。

## 二、对标账号诊断

### 1. 张家港做家政的牛牛

| 项目 | 内容 |
|------|------|
| 类型 | 软广 |
| 柯建军判断 | 一看就是团队运营做的 |
| 评价 | 内容能做出效果，但偏运营驱动，缺人设 |

### 2. 张家港的张惠妹

| 项目 | 内容 |
|------|------|
| 类型 | 本地网红/本地生活类 |
| 内容特点 | 讲张家港本地习俗、新鲜事、观点评论 |
| 示例 | 讲张家港"第一次见面送什么礼物、红包给多少"这类本地话题 |
| 柯建军判断 | 适合做**本地生意**的参考模式——把自己做成本地小网红 |
| 评价 | 本地人看本地事，天然有信任感，好理解 |

### 3. 小吉做家装

| 项目 | 内容 |
|------|------|
| 类型 | 知识口播 |
| 内容特点 | "装修完工开荒别选错"——抄知识类内容 |
| 柯建军判断 | 跟第一个类似，抄知识路线。有活人感，但讲的内容一般 |
| 评价 | 有真实感但内容深度不够，不推荐 |

### 4. 晓华姐（陈建）

| 项目 | 内容 |
|------|------|
| 类型 | **人设打法**（强人设） |
| 内容特点 | 从百万女老板到负债500万，从病床上爬起来创业，结合专业讲内容 |
| 柯建军判断 | 她的人生经历本身就是内容——抗癌+专业，天然有情绪穿透力 |
| 评价 | **标杆参考**——如果冯总有类似的人生经历/故事，这是最推荐的路线 |
| ⚠️ 注意 | 这条路吃人生经历，不是每个人都有。冯总要评估自己有什么故事 |

### 5. 果然生活

| 项目 | 内容 |
|------|------|
| 类型 | 后期技巧/视觉效果 |
| 内容特点 | 讲音效、后期技巧，跟家政内容本身无关 |
| 柯建军判断 | 后期技巧不难学，但前提是内容方向定了 |
| 评价 | 跟冯总的情况不直接相关 |

## 三、柯建军诊断结论

### 第一步：先搞清楚一个选择

> **做本地生意，还是做全国生意？**

| | 本地生意 | 全国生意 |
|--|---------|---------|
| **路线** | 做本地小网红 | 做人设IP |
| **参考** | 张家港张惠妹 | 晓华姐（陈建） |
| **内容** | 讲本地新鲜事、好奇事、大家关心的点 | 挖掘自己的人生经历+专业结合 |
| **优势** | 本地人信任感强，转化路径短 | 天花板高，可全国获客 |
| **适合谁** | 手上没有特别人生故事可讲的 | 有独特人生经历/案例可挖的 |

### 第二步：建议方案

1. **先跑跑看，试一个月**——不要想太远，先做一个月，看数据再调
2. **需要后期全权配合**——柯建军出方向，后期执行，冯总出镜
3. **内容方向参考**：目前所有对标账号的本质都一样——**讲人设的故事，结合自己的专业，再结合每天发生的事情**

### 第三步：柯建军原话

> "目前的所有内容都是大差不差，都是通过讲人设的故事，结合自己的专业，再结合自己每天发生的事情，去把这个账号塑造起来。首先你要确定第一步，我们到底是做本地生意还是做全国生意？"
>
> "如果说我们要做本地生意的话，那你就讲，就像那个张家港张惠妹一样，就做个本地小网红就可以了，去讲一讲本地的新鲜的事情，好奇的事情，大家关心的点。"
>
> "如果说你要做全国的话，那你就得发掘自己，挖掘自己人生案例。"
>
> "我觉得第一步得搞清楚自己的目的到底是什么，这个才最重要。我们可以先跑跑看，先试一个月呗，跑跑看，然后后期调。这时候需要你们的后期的全权配合我。"
