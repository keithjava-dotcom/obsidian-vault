## 标注稿

【景别】中景
省妇联双进家项目，要进长海县了。

我们是承接方。

【景别】中景
长海县——大连最远的县，在海岛上。

我们过去不是做保洁。

是去教。

教什么？
擦玻璃、油烟机清洗、收纳整理、家电清洗、深度保洁。

【景别】中景
不是随便上去讲两句就完了。

有系统课程。

有实战场地——产教融合中心，近2000平，1:1还原教学场景。

课上学完，就能实操。

【景别】中景
一冉是省妇联的重点关注单位。

这可不仅仅是口头合作。

有持续扶持项目在跑。

第一年做怎么样、第二年做了什么、今年能配合什么——
妇联的人心里有数。

【景别】中景
这次去长海，两件事。

第一，教会人真本事。

社区里想学一技之长的宝妈、下岗女工——
不是来听PPT的。

她们学完回去，是客户愿意给她们转介绍的那种。

第二，我想跟所有人说，
一冉不光在大连市区有名气。

海岛我们也到。

【景别】近景，收尾
等从长海县回来，

我告诉你们，都教了谁、
她们学完之后，都能干什么。

## 发布配文

省妇联双进家项目，进长海县了。我们是承接方。
去大连最远的海岛，教技能，不是走过场。
有系统课程、近2000平实训基地。
等回来，告诉你都教了谁。

## 【删填词扫描报告】(IP 句法派系:删减派)

🔴 逐段扫描结果:

**段1**·"省妇联双进家项目，要进长海县了。我们是承接方。"
→ 0处填词。直接陈述事实。

**段2**·"长海县——大连最远的县，在海岛上。我们过去不是做保洁。是去教。"
→ 0处填词。一句一信息。"不是做保洁"是事实说明(去培训≠去干活)，不是扣题。

**段3**·"教什么？擦玻璃、油烟机清洗、收纳整理、家电清洗、深度保洁。"
→ ⚠️ 位置1:
  → 原文:"教什么？"
  → 类型:边界问题·承接上句"是去教"的自然列举，非独立自问自答。柯哥编辑版保留。
  → 建议:保留。
  → 柯哥/出镜人拍:☑留 / ☐删 / ☐改

**段4**·"不是随便上去讲两句就完了。有系统课程。有实战场地——产教融合中心，近2000平，1:1还原教学场景。课上学完，就能实操。"
→ ⚠️ 位置2:
  → 原文:"不是随便上去讲两句就完了。"
  → 类型:边界问题·"不是...就完了"格式。事实对比(有系统课程vs随便讲)，非扣题总结。
  → 建议:保留。如果觉得啰嗦，可精简为"我们有系统课程"直接进。
  → 柯哥/出镜人拍:☑留 / ☐删 / ☐改

**段5**·"一冉是省妇联的重点关注单位。这可不仅仅是口头合作。有持续扶持项目在跑。"
→ 0处填词。柯哥编辑版用语，强调事实。

**段6**·"第一年做怎么样、第二年做了什么、今年能配合什么——妇联的人心里有数。"
→ 0处填词。自然收尾，不扣题。最后一句有劲。

**段7**·"这次去长海，两件事。"
→ 0处填词。直接说事，不铺垫。

**段8**·"第一，教会人真本事。社区里想学一技之长的宝妈、下岗女工——不是来听PPT的。她们学完回去，是客户愿意给她们转介绍的那种。"

  → 类型:边界问题·"不是...是..."格式。但这里是事实对比，非扣题。
