# 小红书宝妈案例（拍摄标注稿）

‹全片基调：中景 / 冉总坐办公桌前，刚送走客户，转过头来跟人唠›

**【对白】**
此时此刻，刚送走一个客户。
小红书来的。
大连本地的宝妈。

**【对白】**
这人关注家政一年多了。
问了好几家。
有一家跟她说——
一万块钱，
我给你一堆群资源。
你自己在里面发、自己去琢磨。

**【对白】**
她觉得不对。
这叫买材料，不叫学东西。
（停）

**【对白】**
然后她来我们公司了。
看了我们的东西，聊了一个多小时。

**【对白】**
最后成为我们合伙人

‹切近景·客户原话，最有力量›
**【对白】**
她跟我说了一句话——
钱要花在买经验上。
要么花在市场上，
自己闭门造车，
浪费时间还要交学费。
（停）

**【对白】**
你知道她是什么条件吗？
普通宝妈。
不是有钱人，
不是有什么资源的人。
（停）

**【对白】**
但她有一点——
认知。
（停）

**【对白】**
什么叫认知？
就是看得到——家政这个行业，什么时候都有人要。
就是算得过来——学费交给市场，不如交给经验。省时间，不绕路。
（停）

**【对白】**
我跟你说实话。
你条件可能比她好。
你能力可能比她强。

**【对白】**
你什么都不比她差。

‹切近景·直接看镜头，对着屏幕前那个人›
**【对白】**
你差什么？
差给自己一个开始。
（停）

**【对白】**
你来了，
我全力以赴，保你成。

## 出镜人·给冉总

你刚送走韩梦瑶，坐回办公室。脑子里还转着她说的话。不是"我要录个视频"——是你转头跟旁边人（或者跟自己）说了一嘴。

中间的"普通宝妈"要顿一下，"认知"要单独出来——重音不在音量，在停顿。

"什么叫认知？"后面两句——"看得到"是对行业的信心，"算得过来"是对我们的信心。这两句别念成PPT，就正常唠。

"差给自己一个开始"——最后三个字"一个开始"轻一点、慢一点。不是喊口号，是把一个东西放在对方手里。

## 给摄影师

‹全片基调：中景 / 冉总坐办公桌前›

自然光，不补大灯。冉总坐办公椅上，刚忙完的状态。切近景两次：第一次在复述客户原话"钱要花在买经验上"，第二次在"你差什么？差给自己一个开始"。两个近景不需要刻意打光，保持真实感。

## 本次调用笔记
- 语言风格指南 → "此时此刻"开头 + "她觉得不对"句式 + 克制不煽情
- 定位方案内容支柱一（创业故事切片）→ 用别人的故事反射自己的价值
- 舒老师标题方法论 → "花在市场上是白走弯路"意外感强
- DONT_DO_THIS → 不讲加盟政策、不用"大家好我是XXX"、不做行业黑话
