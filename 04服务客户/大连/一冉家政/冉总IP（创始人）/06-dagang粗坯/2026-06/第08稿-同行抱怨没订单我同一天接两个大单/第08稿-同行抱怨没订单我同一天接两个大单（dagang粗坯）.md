## 含金量体检结果

### 致命组

- **闸1 意识形态性**：✅ 通过。素材底层价值观是"感恩母亲+目标明确做成事+劳逸结合"，目标受众（创业女性）天然共情——她们也在平衡家庭和事业。不是纯信息陈列，有情感厚度。
- **闸2 速判性**：✅ 通过。整体感受是"一个做成事的人平静讲述她的一天"，不端着、不说教。日入六位数是结果不是炫耀，同行抱怨是现实不是贬低。

### 补救组

- **闸3 高效性**：✅ 通过。独立信息点≥9个：①妈妈生日感恩 ②妈妈是精神支柱 ③单元房开荒大单 ④10万方厂房开荒 ⑤日入六位数 ⑥同行抱怨没订单（反差）⑦品牌定位要清晰 ⑧目标明确才能成事 ⑨新人加入+带妈妈放松。
- **闸4 时效性**：✅ 通过。角度有新鲜感——不是"家政怎么做"教程，而是"别人没订单我订单不断"的反差叙事。普通素材（一天流水账）因反差生出看点。
- **闸5 原子性**：✅ 通过。每个信息点可独立拆解——妈妈的故事、日入六位数、同行抱怨、品牌定位论、新人报到、带妈妈放松，拆开来各有传播价值。
- **闸6 刺激性**：✅ 通过。核心情绪钩子明确——"同行在抱怨没单，她同一天接两个大单日入六位数"。典型的"别人不行我行"反差。

**事** —— 冉总的一天。锚"事"而不是"观点"，因为这篇素材的含金量在**事件之间的反差**——表面流水账，内核是"为什么别人没单我有单"，这个反差需要靠事件的自然展开来呈现，不能一上来就讲道理。

## 发散出的点

1. 今天妈妈生日 → "妈妈辛苦了，我爱你" → 真实情感开场
2. 从小到大妈妈支持她的每一个选择 → "学习、成长、事业，都是默默支持" → 才有今天的一冉
3. 妈妈是她的精神支柱 → "只要有她在，我永远可以勇敢向前"
4. 同一天接到单元房开荒 + 10万方厂房开荒 → 两个大单砸来
5. 日入六位数 → 具体数字不展开，留悬念
6. 很多家政同行在抱怨订单少、不知道怎么获客 → 形成强烈反差
7. 她为什么有单？品牌定位一开始就清晰 → 开展思路 → SOP → 售后跟踪 → "这些都相当关键"
8. "想去哪儿"自己得先明确 → "只有自己目标明确了，这件事才有可能达成"
9. 下午两个新人报到学保洁技能 → 公司还在扩大，不只是在接单
10. 晚上带妈妈放松 → "生活应该充实，劳逸结合，有条不紊"

## 找链接 · 认结构

**清单式 — 兴趣点推进 + 共鸣性推进混合。**

原因：这一天的事件之间没有强因果链条（妈妈生日不会导致大单），但观众逐点看下去，会从"她好暖" → "她好厉害" → "原来是这样" → "她还在扩张" → "收尾舒服"，情绪一层层往上走。不是靠"因为A所以B"推，是靠"你继续看，发现越来越有东西"拉。

## 骨架动力类型

- **大类**：清单式
- **动力类型**：共鸣性推进（具体场景逐步进入"原来我也能这样"）
- **判定依据**：素材没有强戏剧冲突（不像从低谷爬起来），而是"一个做成事的人平静分享她的一天"，观众被具体事件逐步带入她的世界
- **对抗维度**：
  - 点1-3（妈妈）：人与内心 —— 感恩和责任感，在跟自己对话
  - 点4-5（大单+日入六位数）：人与世界 —— 市场给的回报，对抗的是"家政不赚钱"的偏见
  - 点6-7（同行反差+解密）：人与人 —— 她和抱怨的同行，对抗的是"行业不行"的借口
  - 点8（目标论）：人与内心 —— 对抗的是"不知道往哪走"的迷茫
  - 点9（新人）：人与世界 —— 公司成长，对抗的是"小打小闹"的标签
  - 点10（收尾）：人与内心 —— 对抗的是"创业者只能拼命不能生活"的刻板印象

## 导演讲戏原料

- **这条是讲给谁看的**：25-45岁想创业的女性，她们晚上刷到这条，脑子里想的是"我能做到吗？"
- **他/她现在卡在什么处境里**：想做事但不知道从哪开始，身边的人都在说"现在不行""市场不好"
- **出镜人为什么今天非说这件事**：今天妈妈过生日，同一天接到大单，刚好印证了她一直说的"目标明确才能成"——这不是编的脚本，是她的真实一天
- **这条不是在上课，而是在**：分享——"我今天很开心，顺便告诉你为什么"
- **必须讲清的 3-5 个点**：
  1. 妈妈是她的底气（不是煽情，是事实）
  2. 同一天两个大单日入六位数（不是炫耀，是结果）
  3. 同行抱怨没订单——为什么她有？因为品牌定位一开始就清晰
  4. 下午还在进人，公司没停
  5. 晚上陪妈妈，不耽误生活
- **拍的时候先想象的画面**：冉总坐在办公室或者家里，自然光，不化妆也可以，就是"我今天想跟你说个事"的状态。前半段说到妈妈时眼睛可能会亮，说到大单时平静，说到同行抱怨时有一点点不认同但不说重话，收尾带妈妈出去时是轻松的笑

## 说话气口交接

- **出镜人 / 人称**：冉总 / 第一人称"我"
- **第一口气**：这个人为什么今天非说这件事——"今天我妈生日，我很开心。同一天又接了这么大的单。我突然觉得，今天这个日子值得说。"
- **对谁说**：对屏幕那头想创业但还在犹豫的女人说
- **开头入口**：先甩画面——"今天是我妈妈的生日。"（不是甩判断"品牌定位很重要"，是甩一个具体的、温暖的画面）
- **必须像人说的 3 句**：
  1. "我妈就是我的幸运女神，只要有她在，我什么都不怕。"
  2. "很多同行在那说，哎呀现在订单少，不知道怎么办。"
  3. "你想去哪你自己得先知道——你自己都不知道，别人怎么跟你走。"
- **禁止写成**：新闻稿 / 工作汇报 / 参数播报 / 招商PPT / 教学课件
- **停顿与呼吸**：说到妈妈时慢一点，说到日入六位数时停一下让观众消化，说到"同行抱怨"时可以用一个轻微的"嗯"停顿——用冉总自己的口头禅节奏
- **这条不是在说明**："家政创业的方法论"，而是在跟对方说："你看，我不是运气好——我想清楚了，所以结果来了。你也可以。"
