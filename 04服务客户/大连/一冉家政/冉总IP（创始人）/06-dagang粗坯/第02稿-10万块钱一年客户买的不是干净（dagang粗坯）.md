- 来源：定位方案读取（冉总IP 03-定位方案）
- 摘要：想创业的女性和潜在加盟商。关心"我能不能做到"，愿意为能落地的方向付费。视频号为主，碎片时间刷。

【含金量体检结果】
- 致命组：✅ 意识形态性 — "信任是一单一单干出来的，不是吹出来的"，和目标受众价值观高度一致。✅ 速判性 — 开门就是具体画面（700平别墅、猫猫狗狗），不说教。
- 补救组：✅ 高效性 — 独立信息点≥7个（700平、5天7人、宠物在、收纳/保洁/软装分工、活干完了、客户主动办10万年卡、钥匙交付）。✅ 时效性 — "信任定价"这个角度在家政赛道没人讲过。✅ 原子性 — 可拆成独立小块，每个工种、每个细节都是独立信息点。✅ 刺激性 — 10万年卡有数字冲击，"猫猫狗狗在场"有情感温度，反差组合够狠。
- 证据：集团号第10稿IP口语稿。

【锚定对象】
事 — 一次别墅保洁，从上门到客户主动办10万年卡。不是讲"一冉做高端保洁专业"，是讲"信任在这个行业里到底值多少钱"。

【骨架动力类型】
- 大类：发展式
- 动力类型：共鸣性推进
- 判定依据：从具体服务场景进入，一层一层往上走——从"怎么干的活"到"客户怎么反应"到"信任到底怎么被定价"，观众跟着冉总的视角重新理解"家政不是体力活，是信任生意"。
- 对抗维度：
  - 点1（活怎么干）：人与世界 — 用专业分工对抗"家政就是擦擦地"的偏见
  - 点2（宠物在场）：人与人 — 客户把家（和猫猫狗狗）交给你，是对抗不信任
  - 点3（活干完了，客户说了什么）：人与内心 — 收工那一刻你以为结束了，客户一句话改了所有
  - 点4（10万年卡意味着什么）：人与众人 — 家政行业的信任，是可以被定价的。但大多数家政老板没想明白这件事

【IP 类型】
B 类料太多型 — 冉总高端客户案例多，本选题只取一个切口：从一次服务到一张年卡，中间是什么让它发生。

【发散出的点】
1. 东港那个700平独栋别墅，6层，一冉干的
2. 5天时间，7个人——不是随便7个人，每个工种对号入座：4个收纳、2个深度保洁、1个专门洗软装
3. 家里有宠物，猫猫狗狗在，干活得额外小心——不是怕被抓，是怕惊着它们
4. 奢饰品收纳、软装清洗，每个环节都不能掉链子
5. 活干完了，收拾工具准备走——客户说了句话
6. "还有什么要弄的？"——不是。客户说：办个年卡。10万。
7. 我没有当场接。我问了一句：你确定？
8. 不是谦虚。是因为我知道——10万块钱一年的保洁，他买的不是干净。他买的是：钥匙只交给一个人。
9. 家政这行，接一单是一单的人太多了。但一冉不是。一冉是——接一个活，拿下一个客户。
10. 信任不是一次谈成的。是700平，一平一平干出来的。

【素材卡引用】
- 本条选题使用素材：集团号第10稿「东港独栋别墅10万年卡」IP口语稿
- 核心原文摘录：
  > "大连东港那个六层独栋别墅，700平，一冉干的。"
  > "5天，7个人。4个做收纳，2个做深度保洁，1个专门洗软装。"
  > "家里还有宠物。猫猫狗狗在，干活得额外细心，不能惊着。"
  > "干完这单，客户直接办了10万的年卡。"
  > "信任不是一次谈成的。是700平，一平一平干出来的。"

【找链接 · 认结构】
发展式 — 递进推进：服务现场（怎么干的）→ 收工时刻（客户说了什么）→ 认知升维（10万年卡买的到底是什么）。
不是并列罗列服务项目，是"从劳动到信任"这条暗线一层一层往上走。

【信息量体检 · 非改写仅提示】
- 报警项：
  - 点5-6之间的转折（"客户说了句话" → "办个年卡10万"）太跳跃，中间缺一个"冉总当时的心理活动"。不是缺补料，是结构上需要这里做一个停顿——让观众有时间消化"客户这句话有多重"。
  - 点8"他买的是钥匙只交给一个人" — 这句话如果冉总自己说出来，比她现在的口吻更轻。建议交给冉总用她自己的话重新说一遍。
- 全局质感：具体细节5 / 抽象判断3 / 对比反转2 — 具体占比够，结构合理。

【补拍提问】
B 类开关式 — 锁冉总真实反应：

1. 客户说"办个年卡，10万"的时候，你第一反应是什么？心里想的是什么？（不是"感动"，是真话）
2. 在这之前，有没有客户跟你说过类似的话？还是这是第一次？
3. 你有没有问过他"为什么"？他当时怎么回答的？
4. 宠物那个细节——你记不记得是什么品种？你在现场有没有一个瞬间特别小心/紧张？

【IP可读结构翻译】
- 这条不是在讲：一冉做高端保洁有多专业、700平别墅多厉害
- 这条普通人能听懂的说法：一个客户让我去他家干活。活干完了，我准备走，客户叫住我，说"我想办个年卡，10万"。那一刻我明白了——他买的不是我干活多干净。他买的是：以后他家的钥匙，只交给我。
- IP 看到后应该明白的 3 件事：
  1. 我先说什么：去东港一个700平别墅干活，怎么干的（具体，有画面）
  2. 中间拿什么证明：活干完了，客户说了什么，我当时什么反应
  3. 最后落到哪里：10万块钱一年，他买的不是干净——他买的是"钥匙只交给一个人"。信任这个东西，在家政行业是可以被定价的。
- 不能给IP/客户看的内部话术：含金量体检 / 锚定对象 / 骨架动力 / 对抗维度 / 信息量体检术语

【大模型备注】
- 脑内轻判时的对象/IP类型：事 / B类料太多型 — 正确
- 换角度看时的发现：如果锚"物"（700平别墅）会变成炫项目；锚"观点"（信任定价）会变成说教；锚"事"最对——让事件本身说话，观点从事件尾部自然长出来
- 隐约不对劲的地方：集团号稿已经写了"信任不是一次谈成的，是700平一平一平干出来的"——这句话很好，但口语稿里已经有了。冉总IP版本需要不同的话，不能照搬。建议让冉总自己重新说"信任怎么长的"。
- 跟 DNA 可能打架的点：DNA 要求"开头反常识"——开篇直接进干活画面够直接，但反常识不够。可以考虑第一句换成："有人觉得家政就是擦擦地。但10万块钱一年的保洁，擦的不是地。"
