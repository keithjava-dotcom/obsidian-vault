# 09-探探大连2000平的家政"店"_IP口语稿

导航到大连后盐7号门，一冉集团。
或者你直接搜"一冉集团"，也能找着。

这就是咱东三省最大的家政店。
2000平有多大？

（停）

你拿麻将室算。
东北人爱打麻将，你常去的那种棋牌室，按一个屋20平算——
一百多个麻将室，摞一块儿。
就这么大。

（停）

走，带你看看。

进门右手边，一整面墙。
药剂。
全是咱自己研发的清洁药水。
不是贴牌，不是代理。
自己搞的。

（停）

左手边，这些大家伙。

（自己说，给观众一个一个介绍——这些机器叫啥、洗啥用的。洗管道的是哪个、洗烟道的是哪个。你知道的比我多，放开讲。）

（停）

往前走。
扫地机、洗地机。
家用的、商用的，各种型号这排一溜。

重头戏来了。
看这一片——

（停）

咱真把家搬公司里了。
这边是客厅，沙发、茶几、地毯。
那边是厨房，油烟机、灶台。
再往里走是卧室，床、柜子、窗帘。

我们的人，在这练出来的，去了你家才不会手生。
不是看PPT学的，是真趴地上擦出来的。

（停）

再往里走。
商用清洗区。

管道清洗机器人——商场的管道、酒店的排烟，全靠这玩意儿。
旁边烟道清洗机，比人都高。

大到十几万的机器人，小到几毛钱的小刷子，咱全有。

（自己说，家电清洗区这些设备你也给介绍介绍——油烟机、空调、洗衣机、热水器。展示一下。）

（停）

旁边是我们的合伙平台。
一冉现在不止自己做保洁。
你有点手艺，想自己干，我们带你。
（自己说，合伙这块有什么能展示的，讲讲。）

（停）

最后说一嘴。
为什么叫"店"，不叫"公司"？

因为你来，能亲眼看见。
药水是不是自己研的，你来看。
设备齐不齐，你来看。
人怎么练的，你来看。

不用靠想象。
这就是一冉。

在大连，找家政，来一冉看看。
