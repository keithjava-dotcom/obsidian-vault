# 第01稿 · 星加坡社区 · 毛总口吻

## 封面文字候选

> 按舒老师"有情绪/有特点/意外感或收获感至少占一个"写。

| 版本 | 文案 | 标尺 |
|------|------|------|
| A | 楼长才是社区推广的钥匙 | 收获感 ✅ 意外感？偏理性 |
| B | 做社区活动，跑十趟不如让一个人点头 | 意外感 ✅ 有情绪 |
| C | 我跑了三个月社区悟出的一句话 | 意外感 ✅ 有情绪 |
| D | 社区推广的秘密不在领导在楼长 | 意外感 ✅ 陌生感 |

**推荐：B或C**，有市井口语的温度，不PPT腔。


## 逐字稿

说实话，

今天去了一趟星加坡社区，

参加家政进社区的惠民活动。

怎么说呢，

去之前我以为最难的是跟社区领导沟通——

场地怎么协调、

时间怎么安排、

居民怎么通知。

但真到了现场才发现，

最关键的其实是另一步：

**你怎么让楼长们认可你。**

你想想，

楼长是什么人？

她是这栋楼里住得最久、

每家每户什么情况她心里最清楚的人。

她不点头，

你活动办得再热闹，

人家也只是出来逛一圈就走了。

她要是点头了，

都不用你喊，

她自己去帮你推：

"这家的服务我试过了，确实不错。"

比什么广告都好使。

但问题是——

楼长凭什么信你？

不是凭你发一张传单，

也不是凭你跟她说"我们服务很好"。

说实话，

她见得多了。

每到周末都有各种活动，

她凭什么信你这一家？

所以我们的做法是：

**先让她体验。**

不是走马观花发个体验券，

是实实在在地让她感受我们的服务怎么做——

怎么擦玻璃、

怎么处理死角、

怎么打扫完还帮你把工具归位。

让她亲眼看到，

这个团队是认真的，

不是来走过场的。

等她亲身体验完了，

觉得"这个确实不一样"，

她才会放心地去帮我们推。

这一步过了，

后面的复盘、

数据同步、

问题跟踪、

集中派单——

才有一步一步往下走的底气。

当然，

这只是第一场活动。

社区推广不是一场活动就能搞定的事，

是一场一场做出来的信任。

但至少方向对了——

**楼长信任了，这事就能跑起来。**


## 语感自检（对照风格指南）

| 检查项 | 结果 |
|--------|------|
| 有"说实话""怎么说呢"等口头语 | ✅ |
| 娓娓道来，不抢话 | ✅ |
| 先给结论再解释 | ✅ |
| 温和不煽情 | ✅ |
| 没有违禁词（加盟/招商/绝对化） | ✅ |
| 没有PPT腔（赋能/闭环/矩阵） | ✅ |
| 开头没用"我们" | ✅ — 以"说实话"开头 |
| 没有"柯哥"内部称呼 | ✅ — 全程未出现 |
| 换行（句号/问号/感叹号换行） | ✅ |


## 补拍/补充清单（毛总需确认）

1. **"你想想，楼长是什么人"那段** — 如果你记得哪个楼长具体什么反应，加一句会更生动
2. **封面文字** — 你挑B/C/D，或者你有自己想好的
3. **语感** — 念一遍，哪些词不像你说的，告诉我改
