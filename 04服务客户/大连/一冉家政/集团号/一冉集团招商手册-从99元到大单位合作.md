## 第一章：序 · 一份99元订单的15个月

### 「那天挺冷的。」

2025年3月8日。一冉家政第一次下现场做活动。

99元——外出家电清洗加日常保洁。说出去都嫌便宜的价格。

但就是那次，第一组客户把家门钥匙交给了冉总团队。
家政这行，钥匙都不给你，活不可能做好。
钥匙给了，信任就来了。

从那之后，15个月，100多条现场记录。[[04服务客户/大连/一冉家政/集团号/2026.5.22日-集团号-记录集团事件|集团事件记录]]里，每一行都对应一个现场。

从万科资产过亿会员的别墅，到大单位的后厨。
从99元社区活动，到8000平港口幕墙清洗。
从一个人想试试，到几十个合伙人在不同城市同时跑。

**一冉不是做大的。**

**是一单一单干大的。**

这个跃迁，不是运气。

是一个一个现场，一个一个人，积累出来的信任资产。

## 第二章：业务版图——这15个月，一冉干了什么

### 板块一：日常保洁 → 高端深度保洁

一冉的起家基本功。但难的是，能把99元的社区保洁，做到资产过亿的会员家里去。

| 时间 | 事件 | 看点 |
|------|------|------|
| 2025.03 | 99元活动，第一次下现场 | 起步点 |
| 2025.03 | 维多利亚公馆 · 资产过亿会员家保洁 | 客户层级的第一次跃迁 |
| 2026.01 | 红星海别墅 · 初次服务就办会员 | 新客转化会员的速度 |
| 2026.02 | 红星海别墅 · 二次上门，全屋深度保洁 | **复购验证** |
| 2026.01 | 沙河口前部长家 · 常规日常保洁 | 政界圈子渗透 |
| 2026.02 | 妇联主席家 · 上门洗窗帘 | 官方背书+家庭服务双场景 |
| 2026.02 | 南山600平别墅 · 老房翻新开荒 | 旧改市场 |

**摄影师拍到的东西**：维多利亚公馆的入户大堂，水晶吊灯从6楼垂下来。冉总跟会员在客厅里聊的不是"保洁多少钱"，是"家里那个大理石怎么养护"。这是一个家政公司被当成"家庭资产管理顾问"的时刻。

高空作业是家政行业的分水岭。能做普通保洁的公司多，能做高空的公司少。能做高空+大单位+特种作业的，大连一只手数得过来。

|------|------|------|
| 2025.06 | 大单位擦玻璃 · 看场地 | **首次大单位入场** |

| 2025.11 | 金州吉林银行 · 6层高空擦玻璃 | 金融级别高空作业 |
| 2025.12 | 大窑湾大楼 · 港口办公楼外墙5层 | 工业物流场景 |
| 2026.01 | 开发区大楼 · 外玻璃幕墙清洗 | 城市地标级 |
| 2026.01 | 大连湾大连港码头 · 主楼外玻璃幕墙 | **8000平玻璃** |
| 2026.01 | **实验室操作箱内部清洁 · 有毒物质清除** | **特种作业** |

**摄影师拍到的东西**：大连港码头那个现场。绳子从28楼放下来，人在40多米的高空吊着擦玻璃。底下是码头，货车在跑，海风在吹。摄影师站在地面仰拍，画面里人那么小、楼那么大。剪片子的时候他说了一句："这活儿真不是谁都能干的。"

这句话，就是一冉的技术壁垒。

## 第三章：谁在信一冉——15个月积累的信任资产

> 一家公司值多少钱，看谁信它。

### 🏆 大单位

```
2025.06 → 大单位擦玻璃 · 看场地
2026.03 → 大单位后厨 · 烟灶清洗
```

大单位不是一个好进的圈子。审批多、标准高、预算严。一冉从一张"看场地"的单子开始，做到了"后厨清洗"复购。

大单位选供应商，不看你广告打得多响，看现场干得多干净。一冉进去了，没出来。

### 🏛️ 政界

```
妇联主席家 · 上门洗窗帘
社区书记家 · 深度保洁
前组织部部长家 · 日常保洁
社区合作 → 海军广场、大连湾、前关
```

从个人服务到社区合作，一冉的政界渗透路径清晰：
**→ 先做个人家里**
**→ 再做社区落地**
**→ 再进政企合作**

这不是谁介绍的问题。是书记们用过你家服务，觉得行，才放心让你进社区。

### 🏢 企业

```
中粮厂房 → 央企
吉利工厂 → 汽车工业
大连港码头 → 港口物流
吉林银行 → 金融
东港酒店 → 酒店服务
金石滩科技馆 → 科技产业
科兴 → 医药产业
蓉达物业 → 物业合作
```

**行业覆盖：国企、央企、金融、工业、科技、医药、物业、酒店。** 没有一个家政公司能靠运气覆盖这么多行业。

### 👤 个人客户

```
维多利亚公馆 · 资产过亿会员 → 会员服务
红星海别墅 → 初次服务就办会员 → 二次复购
东港别墅4000平 → 单户大单
南山别墅600平开荒 → 旧改市场
```

**红星海的两次上门，是一冉最值钱的数据。** 做保洁不稀奇，做完了客户愿意让你再来一次——你才算真正过关。

### 🤝 合伙人

```
虎滩羊汤后厨 → 合伙人介绍活
异业合作：菊子美业、羊汤馆李总
1980异业合伙人：已有多位签约洽谈中
天津合伙人刘总 → 独立运营
合伙人袁姐 → 全职入局
合伙人郭传鑫 → 讲师体系
```

一年时间，从一个人干到多城市合伙人体系。这不是画出来的组织架构图，是现场、合同、复购撑起来的。

```

```

```
近万平学校大楼 ← 2025年7月
```

### 证据三：受信群体扩展

```
↓ 个人客户（起步）
```

### 证据四：体系化建设

2026年5月，总助张跃春带着团队做了一件事——把一冉所有部门的**岗位职责和管理制度从头到尾梳理了一遍**。

- 各部门灯独立开关改造完成
- 全部监控安装到位
- 装修收尾，办公室正式投入使用
- 管理制度初稿定稿
- 代理商工作流程梳理

**一个家政公司，能不能从一家店变成连锁体系，看的从来不是接了多少单。**
**看的是内部有没有一套能复制到每个城市的规矩。**

一冉在"干活"之外，正在干一件更难的事——建体系。
