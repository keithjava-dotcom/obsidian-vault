# 集团号 · 微记录拍摄手册

> 给拍剪师的现场操作指南。每条视频3-5分钟，横版16:9，旁白+现场收音。
> 后期根据回收的素材生成旁白文案和剪辑框架。

---

## 一、每次外拍必须带回的四样东西

拍剪师不是去"拍画面"，是去"收集故事"。
每次收工前自检，缺一样就补拍。

### 1. 背景（谁、在哪、干什么）

**要拍的：**
- 场地的全景和细节（社区门口、培训教室、冉总办公室）
- 人物的日常工作状态（不是在镜头前说话，是在干活）
- 环境声（小区里的声音、培训现场的对话、街上车流）

**不要拍的：**
- 人物对着镜头介绍自己
- 摆好的合影
- 空镜当任务凑数

### 2. 冲突（遇到了什么坎）

**要拍的：**
- 被拒绝的瞬间（物业不让贴广告、居民不接传单）
- 数据不达标的焦虑（冉总说"这个数不对"、团队沉默）
- 学员的困惑（"这个我不会""我觉得我做不了"）
- 任何让现场气氛变了的时刻

**怎么发现冲突：** 拍剪师在现场，看到冉总皱眉头了、语速变了、沉默了——立刻开机。不要等人说"你拍吧"再拍。

### 3. 疑问（这件事能不能成）

**要拍的：**
- 当事人自己说出来的不确定（"这个社区真能做出来吗""30万能完成吗"）
- 团队讨论中的分歧（两个人意见不一样）
- 学员问师傅的问题（"姐，这个怎么弄"）

**怎么捕捉：** 旁听。不要打断。让对话自然发生，摄影机在角落收着。

### 4. 答案（怎么解决的、结果是什么）

**要拍的：**
- 第一单成交的瞬间
- 一个学员从"不会"到"独立上单"
- 冉总说"这个数对了"的时候
- 客户的一句真实反馈
- 妇联考察时的一句正面评价

**注意：** 答案不是冉总总结出来的"我们成功了"。是片段里自然出现的——一个人的表情变化、一句话、一个动作。拍到就是答案。

## 二、现场拍摄规范

### 设备设置

- 横版 16:9
- 同期声全程开着，不要关
- 不上稳定器没关系，手持的微晃是纪录片质感
- 光线不够就暗着拍，不要打灯——打灯就假了

### 拍摄节奏

- 到现场先开机。不要等人"准备好了"再拍
- 一段素材不少于30秒。不要3秒一切
- 拍人的时候，拍手、拍表情、拍背影。不要只拍正脸

### 素材标注（每天收工后做）

每段素材在手机/电脑上标一个简短备注，方便后期找：

```
格式：日期-事件-关键词
例：0507-华润社区第一天-冉总跟物业谈广告位
例：0508-培训教室-苏州学员第一次上单
例：0509-妇联考察-冉总介绍背景故事
```

## 三、后期工作流

### 拍剪师交付给后期（Hanako）的材料包

```
每条视频一个文件夹：
├── 原始素材（标注后的）
├── 现场笔记（txt就行，写几句当天发生了什么）
│   - 谁在现场？
│   - 发生了什么？
│   - 你觉得最有意思的瞬间是哪个？
└── 时间线参考（哪段素材是你觉得最重要的）
```

### Hanako 的产出

收到材料包后，我会输出：
1. 旁白文案（对应素材时间码）
2. 剪辑结构（哪段素材接哪段、哪里用现场原声、哪里铺旁白）
3. 成片的叙事框架

拍剪师拿到这三样，照着时间码剪就行。

## 四、第一条试拍建议

建议先从「社区30天」第1集开始试。拍一天，素材拿回来跑一遍流程，看看缺什么再调。

**第一条的拍摄清单：**

- [ ] 一到现场，先拍30秒环境（小区门口、街道、周边）
- [ ] 冉总跟团队在小区门口讨论选哪个楼（别打断，收现场声）
- [ ] 贴第一张广告——贴之前冉总说什么、贴的时候怎么贴、贴完谁说了什么
- [ ] 被拒绝的瞬间（如果有人摆手、不接传单、关门）
- [ ] 收工前，冉总说的一句话（不管说什么，最后一句很重要）
