# 代理商扶持 · 活动挑战VLOG拍摄模板

> 给摄影师跟拍用的通用框架。适用于任何"冉总去扶持代理商"的跟拍场景。
> 核心思路：**挑战是骨架，人是血肉，冲突是钩子。**

---

## 🧭 每集通用骨架

一条代理商VLOG的天然结构，四段不可跳：

```
┌─────────────────────────────────────┐
│ ① 开场 · 立目标（30秒-1分钟）       │
│    这集要干成什么？数字+时间+赌注    │
├─────────────────────────────────────┤
│ ② 进场 · 到了现场（1-2分钟）         │
│    看到什么、跟谁碰头、第一反应      │
├─────────────────────────────────────┤
│ ③ 冲突 · 卡在哪了（1-2分钟）         │
│    目标&现实的差距、代理商的顾虑     │
├─────────────────────────────────────┤
│ ④ 破局 · 推进了一寸（30秒-1分钟）    │
│    解决了什么、下一个目标是什么      │
└─────────────────────────────────────┘
```

⚠️ 每集只讲一件事。同一天做了三件事→拆三集，不塞进一集里。

## 📋 摄影师 · 现场必拍清单

到现场后，按顺序收这五样。收不齐不准收工。

### ① 开场画面（30秒环境声）

| 拍什么 | 怎么拍 | 为什么 |
|--------|--------|--------|
| 出发前/下车后第一个画面 | 固定机位跟一段冉总走路的背影 | 带观众"进场" |
| 代理商门店/场地的全景 | 站远一点拍，收环境声 | 交代地点 |
| 冉总跟代理商碰面的第一句话 | 远处收声，不要打断 | 第一反应最真 |

不要拍：冉总对着镜头说"今天我们去XXX"——开场旁白后期加，现场不需要交代。

### ② 冉总跟代理商交流（核心素材）

全程开机，不要停。拍剪师是透明人。

**关键节点（遇到了就开机，跑不掉才关）：**

- ⚡ 代理商说"我做不了""客户不认""没人啊"——这是冲突素材，**拍电影的命根子**
- ⚡ 冉总说"那我给你弄""你看我的"——这是解决方案素材，跟冲突配对用
- ⚡ 两人一起看手机/对账/翻单子——不说话的画面比说话的画面更有信息量
- ⚡ 冉总皱眉头了、放慢语速了、沉默了——**立刻开机**，情绪变化的大信号

**不需要拍的：**
- 冉总对着镜头总结"今天收获很大"——后期旁白解决
- 摆拍的合影、握手——像慰问，不像扶持

### ③ 代理商单独的画面

| 拍什么 | 怎么拍 |
|--------|--------|
| 代理商干活的手 | 特写，拍他在做的事 |
| 代理商的表情变化 | 近景，在他不知道你在拍的时候 |
| 代理商门店/工位/工具的细节 | 中景，交代他的环境 |
| 代理商跟客户/员工/家人的互动 | 远距离收，别打扰 |

### ④ 冲突&疑问的画面

拍剪师的标准不是"有没有拍到"，是"能不能剪出这段来"——

- 代理商说"我不确定能不能行"的时候，他的表情、他的手、他看的方向
- 冉总说"没事没事"的时候，她是真没事还是强撑
- 数据/单子/账本——实物的特写，数字最有说服力

### ⑤ 收尾画面（黄昏/夜色/收工）

一天结束。不用是大场景。冉总上车、车开走、门店的灯关了——都行。
**最后留一个"还有明天"的感觉，不是"结束了"的感觉。**

## 🎤 开放式提问脚本（给冉总路上问代理商用的）

> ⚠️ 原则：开放式提问，不诱导答案。
> ✅ "你觉得最难的是哪一步？" → 真实的答案
> ❌ "是不是觉得客户不认特别难？" → 诱导的答案

到现场后，冉总跟代理商单独坐下来的时候，按顺序挑着问。不用全部问，挑2-3个够一集就行：

### 开场类（了解现状）

1. 这两天接了几单？感觉咋样？
2. 你觉得跟之前比，最大的变化是什么？
3. 现在最卡你脖子的是哪一块？

### 冲突类（挖故事）

4. 有没有哪一单你觉得肯定拿不下来的？
5. 客户拒绝你的时候，你心里想什么？
6. 你团队里的人最近有没有说"不想干了"？

### 反思类（挖成长）

7. 你跟以前比，觉得自己最大的进步是什么？
8. 如果让你回到刚加入那天，你会对自己说什么？
9. 你觉得一冉给了你什么，是你在别的地方拿不到的？

### 展望类（给未来做铺垫）

10. 三个月后你希望你自己的店变成什么样？
11. 如果有一天你也能带新人了，你最想跟他说什么？

### 现场行动类（配合当天行动）

12. 那个谁谁谁的单子，现在到哪一步了？
13. 今天想让我帮你看哪一块？

**给冉总的口诀**：问得越具体，答案越好看。"咋样"不如"哪一单"；"难不难"不如"哪一步最让你头疼"。

## 📝 后期剪辑框架（给剪师）

### 每集标准节奏

```
00:00-00:30  环境声进入 → 冉总出发/到现场（不要解说）
00:30-01:00  目标字幕弹幕："帮XX一个月做到XX单"
01:00-02:00  冉总跟代理商碰面 → 了解情况（现场收音为主）
02:00-02:30  代理商说困难（冲突点）→ 冉总说"那我看看"（转折点）
02:30-03:30  行动过程——冉总带着干了什么（快节奏剪辑）
03:30-04:00  结果画面——没完成也没关系，"明天继续"也是结果
04:00-04:30  收尾
```

### 画面选择原则

| 要 | 不要 |
|----|------|
| 干活的手、工具、单子 | 摆拍的笑脸 |
| 对话的剪影（窗外拍室内） | 正脸大特写背词 |
| 数字（单量、金额、时间）的字幕弹幕 | 空镜凑数 |
| 被拒绝/卡住的沉默 | 配乐填满所有空白 |
| 代理商自己说的话（原声） | 旁白替代理商总结 |

### 音乐选择

- 前期（到现场、了解情况）：轻量、有节奏感但不是欢乐感
- 中期（遇到困难、讨论）：偏沉，不要悲伤，是"思考"的感觉
- 后期（行动、收工）：偏暖、朴实、有温度

不要用"励志音乐"（像宣传片的那种）。用日常的、接地气的。

## ⚠️ 注意事项

### 坑1：冉总讲太多，代理商没声音
解法：冉总的任务是**问问题**，不是**给答案**。让代理商多说。

### 坑2：冲突被跳过了
解法：拍剪师看到气氛变化→立刻开机。没有冲突的VLOG是"我们去扶了代理商"的汇报片，不是"代理商怎么被扶起来"的故事片。

### 坑3：数字出不来
解法：单量、金额、时间——这些信息通过画面（手机屏幕、账本、签单）自然呈现，不是冉总念出来的。"你自己看"比"我给你说"强十倍。

### 坑4：每集太平，没有情绪起伏
解法：dagang脑子——发展式推进必须有"卡住→解决"的切换。如果一集里从头顺到尾→素材不够，不是事不够。回去翻素材找"卡住"的瞬间。
