# 燕窝女老板 · 6条选题拍摄大纲

## ⚠️ 拍摄前必读

- **全部竖版**，pocket3手持
- **画面**：主体干净、清晰。后厨的冰箱和炖品柜收拾整齐再拍
- **光线**：优先靠窗自然光。暖光场景也OK，炖品的暖色调天然好看
- **节奏**：这个IP说话平实、不煽情。她的力度在"我就是这么干的"——别催她，让她用自己的节奏讲
- **引导原则**：问题是开关，不是剧本。她答完一个，顺着往下追问。答得好的地方让她再说细一点，不用干扰她，但是要围绕主题把东西挖掘出来。

## 选题1：315曝光了同行的后厨，我一点不怕——带你看我家

### 骨架

```
[钩子] 315曝光 → "我不怕" → 为什么 → 带你进我家后厨
    ↓
[后厨] 冰箱（打开）→ 炖品柜 → 工作台
    ↓
[落点] "我80%生意来自外卖，外卖上只有图片。所以我喊所有顾客——来店里看看。"
```

### 现场引导提问

**开场：**
- "315你看了对吧？同行的后厨被拍成那样，你当时第一反应是什么？"
- "你说你一点不怕——为什么？你底气在哪？"

**冰箱：**
- "你家冰箱跟别人有什么区别？打开给我看看。"
- "这些原料你们怎么分装的？为什么要这么分？"
- "那一份一份的，标签上写的是什么？你自己写的吗？"

**炖品柜：**
- "这一柜全是今天炖的？一天要炖多少？"
- "打开一罐看看——这一罐里面都有啥？"
- "有没有哪一款是你自己最满意的？为什么？"

**落点：**
- "外卖上顾客只看到一个塑料碗，看不到店。你心里着不着急？"
- "如果有一个顾客看了你的外卖图犹豫了，你对她最想说的一句话是什么？"

## 选题2：桃胶60一斤 vs 8块一斤，挖一勺给你看差别

### 骨架

```
[钩子] 两碗桃胶摆桌上 → "挖一勺，差别就来了"
    ↓
[对比] 她家：整颗、Q弹、透亮 → 普通：碎渣、浑浊
    ↓
[冲突] "工厂劝我用便宜的，我说不行——吃进嘴里的东西。"
    ↓
[落点] "你吃得出来。"
```

### 现场引导提问

**开场：**
- "桃胶这个东西，外行看着都一样。你能不能用最简单的话告诉我，好的跟普通的，差在哪？"
- "你说60块一斤，市面上还有8块的——差7倍多，为什么差这么多？"

**对比展示：**
- "来，两碗放一块。这一勺挖下去，你看到了什么？描述给我听。"
- "好的桃胶挖出来是什么样？普通的呢？颜色、形状、大小，都说一下。"
- "泡发之前长什么样？泡发之后呢？能不能拿干的也给我看看？"

**她的选择：**
- "工厂什么时候劝你用便宜的？原话怎么说的？你怎么回的？"
- "你坚持用60块的，成本高了多少？有没有人说过你'傻'？"
- "你有没有算过，一碗桃胶炖奶用60块的和用8块的，成本差多少？卖价呢？"

**落点：**
- "你觉得顾客吃得出来吗？她吃了你家一次，再去吃别家的——她能感觉到什么区别？"

## 选题3：从家庭主妇到6家店，我干了10年

### 骨架

```
[钩子] "10年前我还是个家庭主妇" → 在家备孕、自己吃燕窝
    ↓
[转折1] 微信卖了6年，没开过店 → 为什么后来想开店了？
    ↓
[转折2] 百威年亏了四年 → "但证明了品牌"
    ↓
[现在] 6家店，全在大连最好的地段
    ↓
[落点] "不是我多厉害，就一个道理——东西好。"
```

### 现场引导提问

**开场：**
- "10年前你在干嘛？那时候你的生活什么样？"
- "你从什么时候开始自己吃燕窝的？吃的第一口有什么感受？"
- "从自己吃到开始卖，是怎么发生的？是朋友问你要，还是你自己觉得这事能成？"

**微信阶段：**
- "微信上卖了6年，没开店。那6年你怎么做的？就靠熟人推荐？"
- "6年没开店，是不想开，还是开不起，还是觉得没到时候？"
- "哪一刻你觉得微信不够了，必须要开个店？"

**第一个店：**
- "第一个店开在哪？为什么选那个位置？"
- "百威年亏四年——那四年你怎么熬过来的？有没有哪个晚上你回家觉得'算了不干了'？"
- "你说亏了四年但证明了品牌。这个'证明'，体现在哪？有人说过这句话吗？"

**现在：**
- "6家店开出来，哪家对你最有意义？为什么？"
- "从1家到6家，如果让你选一个最难的时候，是哪一步？"

**落点：**
- "现在回头看，这10年，你觉得支撑你走下来的那个东西，到底是什么？"

## 选题4：进了达沃斯晚宴，我要开始准备了

### 骨架

```
[钩子] "我们的产品要进达沃斯晚宴了" → 达沃斯门槛有多高
    ↓
[为什么能进] 品质 + 检测 + 标准 → "不是运气，是10年的结果"
    ↓
[现在在干嘛] 展示筹备过程 → 记录式
    ↓
[落点] "这对我来说不只是一个背书。" + "等我更新进展"
```

### 现场引导提问

**开场：**
- "达沃斯晚宴——普通人听到这四个字什么感觉？门槛到底有多高？"
- "你接到通知那一刻，什么反应？你第一个告诉谁了？"

**为什么能进：**
- "凭什么选了你家？他们看了什么？检测了多少项？"
- "你那个第三方检测报告，能不能拿出来给我看看？上面写了什么？"
- "10年前你在微信上卖燕窝的时候，想过自己有一天进达沃斯吗？"
- "如果有人说'这就是运气好'，你会怎么回答？"

**现在在准备什么：**
- "现在在准备什么？是调整产品，还是做新包装，还是什么？"
- "有没有什么具体的东西可以让我拍到？你在写的单子、在挑的东西。"
- "你紧张吗？如果不紧张——为什么？"

**落点：**
- "这件事对你来说，除了背书之外，意味着什么？"

## 选题5：下午茶别喝奶茶了，这个20块一杯不香吗

### 骨架

```
[钩子] "你每天下午点一杯奶茶，20多块。换成这个试试。"
    ↓
[展示] 2-3款炖品 → 好看、挖一勺、不贵
    ↓
[日常感] "我自己平时就喝这个，6家店外卖都能点。"
    ↓
[落点] 不强调功效，只展示品质和颜值
```

### 现场引导提问

**开场：**
- "你平时下午自己喝什么？是炖品还是也喝奶茶咖啡？"
- "你店里最受欢迎的那几款下午茶，哪三个？帮我排个序。"

**产品展示（每款都问一遍）：**
- "这个叫什么？里面有什么？多少钱？"
- "这个你自己喝得多吗？什么时候喝？"
- "挖一勺给我看看——里面什么东西最多？"
- "好喝在哪？别用'好喝'两个字，换个说法。"
- "如果是第一次来店的顾客，你会推荐哪一款？为什么？"

**外卖：**
- "6家店外卖都能点——你打开手机给我看看，具体怎么点？"
- "外卖送过去，跟在店里吃，区别大吗？你怎么保证口感？"

**落点：**
- "有人说炖品是'养生的、贵的、老太太喝的'，你听到这种话什么反应？"
- "你想对天天喝奶茶的女孩子说什么？不用'应该说'，就说你想说的。"

## 选题6：有个顾客一年点了我285次，我至今不认识她

### 骨架

```
[钩子] "美团年终报告——有个顾客一年点了我285次。"
    ↓
[展开] "我不认识她，她从没找过我。" → 只靠东西好吃
    ↓
[背后的道理] "她不认识我，但信任我。这种事不是营销能做到的。"
    ↓
[落点] "如果你也在大连，你就知道我说的是什么了。"
```

### 现场引导提问

**开场：**
- "美团那个年终报告，打开给我看看。那个285次，你看到的时候什么感觉？"
- "365天点了285次——等于隔一天就吃一次。你能想象她是什么样的人吗？"

**故事展开：**
- "你完全不知道她是谁？没有微信、没有留言、没有来过店里？"
- "你有没有想过联系她？为什么没联系？"
- "这种事你遇到过几次？还有没有别的让你记住的顾客？"

**背后的道理：**
- "一个不认识你的人，一年买你285次。你觉得她信任的是什么？"
- "有人说'做生意一定要跟顾客认识'，你好像不是这么干的？你怎么看？"
- "这种事营销做不到——为什么？营销能做什么、做不到什么？"

**落点：**
- "如果这个顾客有一天突然来了店里，你见到她，第一句话想说什么？"
- "你在大连开了10年店，你觉得大连人跟你是一种什么关系？"
