# 姜胖子-短剧脚本拍摄指导记录

> 2026-06-12 · 柯哥通过微信语音指导姜胖子拆解短剧脚本拍摄

## 背景

姜胖子去了大连一家拍短剧的公司做拍摄，需要掌握短剧拍摄技巧。柯哥用了一段短剧片段做案例，逐帧拆解教学。

## 核心教学框架

### 一、短剧脚本的四段结构（所有短剧通用）

1. **人物出场** → 2. **冲突强化** → 3. **英雄身份（第三者介入）** → 4. **正能量深化**

> 面馆版本同理：人物出场（老太太+老板）→ 冲突（吃不起面）→ 英雄（正能量的人转一万块）→ 深化

### 二、前5秒构建人物关系

- 动作开场（起身拿瓶子）— 2秒
- 主角出场（小美）
- 反派出场（小帅）
- 爆发点（撞一下）— 5秒内交代背景+制造冲突

### 三、景别与构图

| 要素 | 要点 |
|------|------|
| **景别** | 远、中、近、特。没有运镜也能拍好 |
| **三分构图** | 经典构图法 |
| **视角** | 仰拍=高大强势，俯拍=弱小弱势，平视=中性无情绪 |
| **正反打** | A过肩 → B过肩 → A+B同框（全景）= 一场对话完成 |
| **三角关系** | 前景+中景+后景构建人物关系。四个人同理，全框进去 |
| **偷窥视角** | 观众视角，躲在角色后面拍 |

### 四、强化情绪的技法

- **小情节推进**：单纯撞一下不足以让观众恨反派。加情节让反派越来越过分→观众越来越恨→同情主角
- **特写对比**：脚（强壮）踩手（弱小）= 被欺负关系的视觉化
- **俯拍强化弱小**：用男性视角俯拍女性，突出柔弱
- **前景遮挡**：用女性鬓角头发做前景，强化弱势感

### 五、剪辑节奏

- 每个镜头不超过3秒
- 快速剪辑（正反打各0.5秒）
- 避免视觉疲劳→适时拉回全景
- 硬切为主，考虑动作衔接关系

### 六、柯哥给姜胖子的作业

> **"你带着这个思维去拆他所有的视频，拆个5条到10条，基本上你脑子里就有概念了。"**

**姜胖子需要掌握的2个基础**：
1. 景别（远景、中景、近景、特写）
2. 构图 + 角度（三分构图 + 俯/平/仰视角变化）
