**怎么用**：下面每个选题，分成了几块。每一块下面是举例——你看着举的例子，用自己的话说就行。不用背，不用照着念。

## 01 什么叫"内在小孩"？我用打架的事讲明白

```
① 开头 → 说一件自己都觉得"至于吗"的事
② 解释 → 那不是两个成年人在打，是两个小孩
③ 方法 → 看见它就行，不用赶它走
④ 结尾 → 下次发脾气问自己一句话
```

---

**① 开头——这么说：**

我跟前夫打了一辈子架！

最莫名其妙的一次——他打牌赢了两块钱回来，笑嘻嘻的。我把钱撕了摔他脸上。我俩打了一架。打完第二天继续过日子。

你说怪不怪？两块钱的事，至于吗？

**② 往下讲——这么说：**

后来我上了菲菲老师的课才懂。那不是两个成年人在打架，是两个小孩。他三岁，我两岁，两个受伤的小孩碰上了就干。

你看我管他管得多狠——不许抽烟，不许喝酒，不许交朋友。他的朋友我说全是狐朋狗友。我当时觉得自己特别有道理，我这是为你好啊！

现在回头看，那个管他的赵姐，不是五十岁的赵姐。是那个小时候看着爸爸抽烟喝酒，心里害怕的小姑娘。那个小姑娘没长大——她觉得我得管住你，管不住我就没有安全感了。

**③ 给方法——这么说：**

那咋办？不用打它，不用赶它走。

你只要能看见——哦，刚才那个生气的，是八岁的我。你看见的那一下，你就已经不是那个八岁的小孩了。你是现在的你，现在的你可以抱抱那个小孩。

**④ 收尾——这么说：**

下次你跟老公孩子发脾气的时候，停一秒。问自己一句：现在是谁在生气？是现在的我，还是小时候那个害怕的我？

能问出这一句，你就已经开始不一样了。

我是赵姐。一个活了五十多年才把自己看明白的普通女人。想少走弯路的，来找我。

## 02 为什么你控制不了情绪？情绪不是敌人，是信号

```
① 开头 → 说我以前觉得"我有毛病"
② 解释 → 情绪不是来害你的，是来报信的
③ 方法 → 三步——停、认、问
④ 结尾 → 你不是脾气差，你是没学过
```

---

**① 开头——这么说：**

我以前觉得自己有毛病。真的。

打完架他走了，我一个人在家哭。不是哭他打我，是哭我自己——我怎么又控制不住了！我跟自己说了一万遍"下次不能这样了"，没用。

**② 往下讲——这么说：**

后来我懂了。不是我有毛病，是我从来没问过——这个脾气，它到底想说什么。

有一次别人说了我一句不好听的，我当场就炸了。以前我就发出去——你凭啥这么说我！然后难受三天睡不着觉。

现在不一样了。现在气上来了我先停，问自己：赵姐，你为什么气？不是因为他说得难听，是因为这话让我想起了小时候——小时候总被人看不上，总有人说你不行。所以现在谁一说我不好，那个小时候的疼就翻上来了。那个气，不是因为今天这句话，是因为三十年前那无数句话。

你看，情绪不是来害你的。它是来报信的——它在告诉你，你这里有个旧伤，还没好。

**③ 给方法——这么说：**

那怎么听呢？三步。

第一步，停。脾气上来别急着发，也别压着，就停三秒。

第二步，认。给这个情绪起个名字——我现在是气？委屈？害怕？就一个字。起完名字，你就跟它分开了，你还是你，它是它。

第三步，问。问这个情绪一句——你想告诉我什么？不用动脑子想答案，就这么一问，那个要炸的劲儿就下来一半了。

**④ 收尾——这么说：**

我跟你说实话，我现在也不是每次都能做到。有时候气上来太快了，三步走不进去。那怎么办？先待着，允许自己很糟糕。不用骂自己，告诉自己——我现在很难受，这是正常的。缓过来了再做那三步。

姐妹们，你不是脾气不好，你是没学过怎么看情绪。我以前也不知道，我还咬自己胳膊呢。这是能学会的。我五十多才学会，你比我早。

我是赵姐。一个从情绪里爬出来的普通女人。如果你也在被情绪折腾，来找我。

## 03 你的掌控欲是哪来的？我在前夫身上看到了我爸

```
① 开头 → 说我最狠的"管"
② 解释 → 管的是他，还是我爸？
③ 转折 → 我现在怎么做的
④ 结尾 → 问观众一个问题
```

---

**① 开头——这么说：**

我管他管到什么程度？不许抽烟！不许喝酒！不许交朋友！他的朋友我说没一个好东西，全是狐朋狗友。我当时觉得自己理直气壮——我这是为你好，帮你变成更好的人！

现在回头看，那叫帮吗？那就是控制。他连出去玩的自由都没有了。

**② 往下讲——这么说：**

后来上了菲菲老师的课我才明白。我爸抽烟喝酒耍钱，我小时候特别不喜欢我爸那样。所以我找老公的时候就想，我要找一个不抽烟不喝酒的。

但人是会变的。我发现他有苗头了，我就疯狂地想按住。我按住的不是他，是我小时候的恐惧——我怕他变成我爸。我越想不让我爸那样，就越在我自己老公身上管他。

**③ 转折——这么说：**

现在我还是会有想管的时候。但差别在哪？我能问自己一句——赵姐，你现在想管的，到底是谁？问完这句话，那个想管的手就松开了。不是不管了，是我分清了一件事——我的恐惧是我的恐惧，跟他没关系。

**④ 收尾——这么说：**

你回去想一想，你对谁的控制欲最强？那个人身上，有没有你最害怕的东西？你怕的那样子，是像谁？

不用跟我说，你自己心里过一遍就够。

## 04 转念不是鸡汤——一个能用的方法

```
① 开头 → 怼"想开点"三个字
② 举例 → 我上次被别人说了不好听的话
③ 方法 → 转念三步
④ 收尾 → 留一个小作业
```

---

**① 开头——这么说：**

"你想开点"——我听到这句话就想骂人！我要能想开，还用你告诉？

今天赵姐不跟你说想开点，我跟你说怎么转。

**② 举例——这么说：**

上个月有人说了我一句不好听的。我当时第一反应：他怎么这样？我对他这么好他这么说我？

以前我就气三天。现在我问了自己三句话。

第一句，我现在是什么情绪？生气。

第二句，这个生气是因为什么？因为他那句话让我觉得他不尊重我。

第三句，为什么"不被尊重"这么戳我？

问到第三句我就看见了。不是因为这个人，是因为我小时候从来没被人尊重过感受。我爸妈打架，没人管我怎么想。我十八岁嫁人，没人问我愿不愿意。所以长大了谁一让我觉得不被尊重，那个开关就打开了。那个气不是因为他今天这句话，是因为三十年前那个没被尊重过的小孩。

看懂了这个，气就散了。不是我想开了，是我看懂了——原来不是他在伤害我，是我身上有个旧伤，被他碰了一下。

**③ 给方法——这么说：**

三步再给你说一遍。

第一步，停。问问自己——我现在是什么情绪？就一个词。

第二步，往里面看。这个情绪从哪来的？不是今天这件事，是以前。具体是哪？什么时候？

第三步，对自己说。看懂了就对自己说——知道了，这是旧伤，不是今天的事。

**④ 收尾——这么说：**

我跟你说实话，我现在也不是每次都能转。转不过来没关系，允许自己气一会儿。能觉察到"我现在转不过来"，这本身就转了一半了。

你今天就可以试。遇到不舒服的事，停一下，拿张纸，写三个字：我在气什么？写完再往下写：这个感受，我以前有过吗？写到第三层你就知道了——你气的不是今天这件事。

我用了五十多年才学会这个。你现在可能三十多，四十多——你比我早。

我是赵姐。一个学会了转念的普通女人。想学的，来找我。

## 05 你活得那么累，因为你在证明给别人看

```
① 开头 → 前夫那句话，我记了半辈子
② 解释 → 我为什么拼命证明
③ 转折 → 不证明了是什么感觉
④ 结尾 → 问观众一句话
```

---

**① 开头——这么说：**

"就你那个熊样！你还能干家政公司？是人都能干！"

我前夫这句话，我记了半辈子。不是恨他，是我为了证明他错了，累了好几年。

**② 往下讲——这么说：**

我拼命干，干成了，赚了十多万。开心吗？不开心。因为证明完这一个，下一个等着我证明的人又来了。

我从小到大都在证明。小时候证明给我爸妈看——你们看不上我，我能行。长大了证明给老公看——你说我不行，我非要行。后来证明给社会看——我一个没文化的农村妇女，我也能做公司。

但证明这件事永远没有头。你要的不是做成事，你要的是别人一句"我错了，你行"。这句你永远等不到。

**③ 转折——这么说：**

现在我做视频，不是证明给谁看，是我真想干。以前出门怕别人看我，怕人家觉得我土。现在爱咋看咋看。

不证明之后，最轻松的不是别人对你的评价变了，是你自己不累了。你那口气不用一直顶着，人就不累了。

**④ 收尾——这么说：**

你现在最拼命做的那件事——到底是在做自己想做的，还是在证明给谁看？给你妈看？你老公看？还是前夫看？

如果你发现你是在证明，那这个事你做再好，都不会真正快乐的。

## 06 你讨厌的人身上，有没有你自己？生活是一面镜子

```
① 开头 → 我这辈子最不想变成我爸那样
② 解释 → 越怕什么越来什么
③ 方法 → 把别人当镜子照自己
④ 结尾 → 留一个安静的问题
```

---

**① 开头——这么说：**

我这辈子最不想变成我爸那样！他抽烟喝酒耍钱，不务正业。我找老公的时候就一个标准——绝不能像我爸。

结果呢？我前夫就是个抽烟喝酒打牌的。我越怕什么越来什么。

**② 往下讲——这么说：**

后来我才懂。你越排斥什么，什么就越缠着你。因为你排斥的时候，你眼里全是它。你越盯着"不要"，你越往"不要"那边走。

还有一层更深的——我看不惯我前夫不务正业。后来我发现，我看不惯的不是他，是我自己身上那个"想自由"的劲儿。我从小被管得死死的，心里也想自由，但我不敢。所以我看见他出去玩我就难受——不是他错了，是他替我做了我自己不敢做的事。这就是镜子。你讨厌别人的那个点，往往是你自己身上也有的。

**③ 给方法——这么说：**

现在谁让我特别不舒服，我不先想"他怎么这样"。我先想——他身上这个东西，为什么这么戳我？戳我的原因只有两个。要么是我身上也有但我藏起来了，要么是我小时候被这个东西伤过。你找到原因了，你对他的气就消了——因为你知道你不是在气他，你是在气你自己。

**④ 收尾——这么说：**

你现在最看不惯的那个人——如果他是你的一面镜子，他在照出你的什么？

不用告诉我。你今晚安静的时候，想一想。那个让你最烦的人，可能是你最重要的老师。

## 07 什么叫"能量调频"？最简单的东北话解释

```
① 开头 → 以前的我跟现在的我，像两个人
② 解释 → 什么是频率
③ 方法 → 怎么调
④ 结尾 → 一个小挑战
```

---

**① 开头——这么说：**

以前的我跟现在的我，简直是两个人！

以前早上睁开眼就不想起，觉得这一天没什么好期待的。出门看谁都不顺眼，谁跟我说话我都烦。结果呢？越烦越倒霉，越倒霉越烦。

现在我睁开眼就想——今天会发生什么好事？我也不知道，但我就是相信会有好事。结果真的一件一件来。

**② 往下讲——这么说：**

什么是频率？就是你身上散发出来的那个味儿。你苦着脸，浑身散发出的是"别理我"，那身边的人就不理你。你笑着脸，散发出的是"来呀来呀"，好人好事就往你身边凑。这不是迷信——你自己试试，你今天出门对三个人笑，你看这一天顺不顺。

**③ 给方法——这么说：**

怎么调？我以前早上起来先想——完了，今天又要干嘛干嘛。现在早上起来先跟自己说一句：赵姐，新的一天来了，今天一定有好事。我不骗你，就这么一句话。说完之后身体是能感到那个变化的。

**④ 收尾——这么说：**

咱们做个小实验。从明天早上开始，连续三天，早上第一件事别摸手机。跟自己说一句：今天有好事情。三天之后你看看，是不是不一样。

我一个五十多岁的人都能调过来，你更能。

## 08 原生家庭欠你的，怎么自己还给自己

```
① 开头 → 我小时候最缺什么
② 解释 → 为什么不能等别人给
③ 方法 → 怎么自己给自己
④ 结尾 → 给自己小时候写一句话
```

---

**① 开头——这么说：**

我小时候什么都不缺，就缺一句话——"你可以"。

三叔跟我说过一句"你比昨天跑得快了"，这句话我记了一辈子。因为没有别人跟我说过。我爸妈从来没说过。

所以我这一辈子都在找人说这句话。找老公找不着，做家政证明给别人看——全是想听这一句。

**② 往下讲——这么说：**

我等了好多年。等老公肯定我，他不给。等客户肯定我，给了也不够。等儿子肯定我，他长大了有自己的事。

后来我才懂——你等别人给你，永远不够。那个洞是小时候留下的，只有小时候那个人的声音能填。但那个人已经不在那个位置上了。所以不是别人不给，是给不了。你自己不填，谁填都不好使。

**③ 给方法——这么说：**

我现在对自己说——赵姐，你可以。不用说给别人听，就自己心里说。别人否定我的时候，我不急着难过，我先抱抱那个小时候的赵姐：没事，他说的不算。

你也试试。知道你小时候缺什么吗？如果不知道，去问你妈一句：妈，我小时候你最常说我什么？如果她说"你怎么这么笨"——那你欠自己的就是一句"你不笨"。每天对自己说一遍。不是开玩笑，真管用。

**④ 收尾——这么说：**

我想对那个八岁的、口吃的、胆小的、总被人欺负的小姑娘说一句话：你不用改了，你挺好的。你以后会变成一个特别厉害的大人——不是多有钱多成功，是你终于不用再害怕了。

如果你现在也是那个小时候的孩子，你来我直播间，我跟你说——你不用改了，你挺好的。

## 09 吵架后怎么哄自己？赵姐的情绪急救三步

```
① 开头 → 我咬自己胳膊的事，不瞒了
② 方法 → 三步急救
③ 实话 → 不是每次都灵
④ 结尾 → 专给还在伤害自己的人
```

---

**① 开头——这么说：**

我咬过自己胳膊！咬到青紫！我还撞过墙，撞成脑震荡！

那时候就觉得——身体疼了，心就不那么疼了。

现在想起来心疼啊。姐妹们，如果你现在也有这种——不是你想伤害自己，是你真的不知道还能怎么办。

**② 给方法——这么说：**

第一步，停。不咬自己，不砸东西，不打人。就停三秒。告诉自己——我现在有情绪了，这是正常的。

第二步，认。给这个情绪起个名字——是愤怒？委屈？害怕？就一个词。起完名字，你就不是它了，你是那个看见它的人。

第三步，问。这个情绪在保护我什么？比如愤怒——愤怒在保护"我不被看见"这件事。找着这个了，那个要炸的劲儿就下来了。

**③ 说实话——这么说：**

老实说，我现在也不是每次都能三步走。有时候气上来了，两步都走不了。

那怎么办？先把自己放在一个安全的地方——别伤害自己，别伤害别人。然后告诉自己：我允许自己现在很糟糕。就待在这个糟糕里，什么都不用做。等你缓过来了，再做那三步。允许自己不行，这也是一种能力。

**④ 收尾——这么说：**

如果你现在还在伤害自己——不管是用身体还是用话——你听赵姐一句。你攻击的那个身体，是你这辈子最好的朋友。它陪着你熬过了一切的苦。它没有错。你不要伤害它了。

你难受了可以找我。你不知道怎么做，我教你。但是别打自己了。你值得被好好对待。

## 10 什么叫"活明白了"？不是没烦恼，是你能看懂自己

```
① 开头 → 同样的事，以前和现在的我
② 解释 → 什么是"看懂自己"
③ 方法 → 怎么开始
④ 结尾 → 赵姐的收尾
```

---

**① 开头——这么说：**

同样有人说了我一句不好听的话——以前我难受三天！三天睡不着觉！越想越气越想越没用！现在呢？难受一分钟，看懂了，该干嘛干嘛。

差别在哪？不是不在乎了，是我看懂了。

**② 往下讲——这么说：**

活明白是什么？不是什么都懂了，是你往回看，看得清了。

你看我的路——十八岁早婚，因为我爸妈打架，我想逃。十年抑郁，因为我在婚姻里又活成了我妈。来大连，因为我儿子来了。做家政成功又失败，因为我一直在证明给别人看。遇到菲菲老师，因为我前一脚的失败让我终于放下了证明这件事。

你看，每一笔都有原因。以前我看不懂，觉得自己命苦。现在看——看懂了，就不苦了。

**③ 给方法——这么说：**

怎么开始？不是看书上课。往回看就行。你拿张纸，从你有记忆开始，把人生里每一次大决定写出来。搬家、换工作、结婚、离婚、跟谁吵架——都写上。写完之后在旁边写：当时我是因为什么做这个决定的？那时候心里怕什么？追什么？

写到第五个，你自己就看出来了——你的模式。那个模式一直在循环。你看见了，就已经开始明白了。

**④ 收尾——这么说：**

我用了五十多年才活明白。你现在可能三十多，四十多——你比我早。你不需要再用二十年去撞我撞过的墙。

我是赵姐。一个五十多岁才活明白的普通女人。想少走二十年弯路的，来找我。

## 拍的时候记住三件事

1. **坐着拍**，正面看镜头，背景干净就行
2. **语速慢一点**，每句话说完停一下，不用赶
3. **照着举例说自己的话**就行，不用背，不用一模一样——你自己怎么说话就怎么来
