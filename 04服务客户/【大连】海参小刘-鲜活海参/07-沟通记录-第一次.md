# 第一次沟通记录 · 海参小刘（清洗版）

## 背景

小刘的店8月开业，想做短视频。之前被科技公司骗过，觉得柯老师做内容不吹牛、接地气、靠谱。家里全是做生意的——各行各业都有，想拿自己做打样，做得好了整个家族都跟上。

## 沟通要点

### 1. 实体店进度
- 店址已签合同，上家还没搬走，还没装修
- 做现货海参，实体店模式
- 柯老师提醒：签合同、装修过程全部录素材——开业用得上

### 2. 合作方式（4980/年）
- **柯老师负责**：出选题、出文案、数据复盘、思域运营、直播人设搭建
- **拍摄**：尽量教会小刘自己拍（A肉集中拍+B肉自己拍）→ 柯老师去现场拍两三次做示范 → 目的是让小刘自己能拍，长期成本低
- **剪辑**：可外包，成本低（8元/条）
- **直播**：柯老师不带货直播，但有团队可以教小刘搭直播间→每周1-2场挂品，其他场次做人设扩流导私域
- **起号周期**：3-6个月见流量

### 3. 小刘的顾虑
- 怕自己拍不好——想找柯老师这边的人直接拍
- 柯老师的回答：别人拍没自己拍的"真"——24小时不能跟拍
- 小刘接受：先让柯老师来拍两三次教他，学会之后自己拍

### 4. 小刘的资源和优势
- 有海参养殖/捕捞源头资源
- 现场拍摄（养殖海域、加工车间）比城市里拍感觉好
- 家里全是做生意的——各行各业——做好了是家族样板

### 5. 小刘怎么评价柯老师
- "论您的想法也好，在这系列人品我觉得比较靠谱"
- "在科技公司待过，都是骗人的，我上不来"
- 看中的是：内容不吹牛、接地气

### 6. 待定事项
- 小刘先跟妈妈商量，再确认合作
- 合作确认后：先学课→拉齐认知→收集信息→出选题出内容

## 柯老师的建议（落地动作）

1. **现在就可以录素材**：签合同、装修过程
2. **取景建议**：去养殖海域拍摄——比城市里更有质感
3. **现场拍摄 > 摆拍**：海参行业的核心是"真"——现场挑参、装货、发冰袋、切开展示，比任何文案都有力量
4. **成本最低路径**：4980一年 + 剪辑外包8元/条——月成本几百块
