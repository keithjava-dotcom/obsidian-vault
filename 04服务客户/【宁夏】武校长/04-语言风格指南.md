# 04-语言风格指南：武校长

> 写武校长的文案前必读。她的语言底色：**闷声扛——最狠的话平静说，最重的事淡淡讲。**

## 语感特征

**数字说话**：她天然用数字锚定事实——"5张信用卡""30万""3年""1000多万""6年""7天不休"。不需要形容词。

**行动 > 感受**：她说"办了5张信用卡，刷出30万"，不说"我当时很绝望"。**写稿时把感受翻译回行动。**

**平铺直叙**：按时间顺序讲——"先是……后来……然后……就这样……"不跳跃、不倒叙。

**"我觉得"句式**：比"我认为"更亲近、更口语。

**自我复盘习惯**："确实，我想了想……"——这种停顿可以保留进文案。

## 情绪浓度

**低浓度。** 她讲最难的事的时候，情绪反而是最平的。

唯一有力量感的地方在讲"坚持"时——"从未间断过"。

**不要替她煽情。** 她的经历本身就有重量，加情绪反而是削弱。

## 真实语料

从素材里提取的她原话或接近原话：

| 场景 | 她的表达 |
|---|---|
| 讲出身 | "我是宁夏医科大学药剂专业毕业的。在急救中心药房干了3年，又去税务局上了3年班。" |
| 讲困境 | "干了一年以后，大家都不服管。" |
| 讲决绝 | "我深知唯一的出路只有不断学习。办了5张信用卡，刷出30万，全国各地去学习。" |
| 讲被割 | "有被割过韭菜，有被骗过，也学到了很多知识。" |
| 讲成果 | "3年时间，把驾校做到了银川比较靠前的驾校。5年时间，还清了所有债务。" |
| 讲坚持 | "从2020年每天坚持拍视频，已经拍了6年，从未间断过。即使播放量是0，我也没有放弃。" |
| 讲跨行 | "我感觉驾校行业越来越智能化……在一次学习中听到了低空经济，我毫不犹豫开始转型。" |
| 讲现状 | "一周七天没有休息，但我觉得很充实。人在年轻的时候就应该不断努力。" |
| 讲心态 | "只要咬牙坚持往前走，就会遇到能帮我的贵人。只要不放弃，一切皆有可能。" |

## 改写示例

❌ "我当时非常痛苦，所有人都不看好我。"
✅ "干了一年以后，大家都不服管。"

→ 删"痛苦"，留事实。她的痛苦在行动里。

❌ "我非常自律，一直坚持学习。"
✅ "从2020年每天拍视频，已经拍了6年，从未间断过。"

→ 删"自律"，用行动证明。

❌ "我是一个积极向上正能量的人。"
✅ "觉得很充实，觉得这才是年轻人该有的样子。"

→ 不说"我是谁"，说"我在做什么、我什么感觉"。

## 禁用

### 禁用词
- 赋能、闭环、抓手、颗粒度等内部黑话
- "心法""秘籍""诀窍"——跟她气质不符
- "精英""高端""名师""专家""权威"——她不是这个路子
- "你必须""你一定要"——制造焦虑

### 禁用句式
- "作为XX领域的XX"——报告体
- "随着XX的发展"——空泛开场
- "总而言之""综上所述"——写完自动删

### 禁用模式
- **煽情模式**：配悲情BGM + "那段日子我真的……"——不要
- **喊话模式**："家长们注意了！"——不要
- **讲课模式**："今天给大家分享三点……"——不要
- **机构腔**："我们拥有专业的教练团队……"——自杀

## 判断标准

写完文案后，想象她在银川的训练场边、傍晚收工后，对着手机平静地讲这段话——**如果别扭、如果像在"表演"，就改。**

她的金句不是设计出来的，是经历本身。把它们放在对的位置，力量就出来了。
