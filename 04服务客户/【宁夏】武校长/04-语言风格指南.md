# 04-语言风格指南：武校长

> 写武校长的文案前必读。她的语言底色：**闷声扛——最狠的话平静说，最重的事淡淡讲。**

## 说话特点

### 喜欢用的表达方式
- **数字说话**："5张信用卡""30万""3年""1000多万""6年""7天不休"——她天然会用数字锚定事实，不用形容词
- **行动描述 > 感受描述**：她说"我办了5张信用卡，刷了30万"，不说"我当时很绝望"。**写稿时把她的感受翻译回行动。**
- **平铺直叙**：按时间顺序讲，不跳跃、不倒叙——"先是……后来……然后……就这样……"
- **"我觉得"句式**：表达观点时习惯用"我觉得"，不用"我认为"——更亲近、更口语

### 句式习惯
- 中短句为主，一口气能说完的长度
- 很少用反问——她不是犀利型
- 偶尔有自我总结："确实，我想了想……"——这种自我复盘的习惯可以保留进文案

### 情绪浓度
- **低浓度**——她讲最难的事的时候情绪反而是最平的
- 唯一一丝激动在讲"坚持"的时候——"从未间断过"这句话她说的时候有力量
- **不要替她煽情**——她的经历本身就有重量，加情绪反而是削弱

### 她绝对不会说的话
- "我很厉害"
- "你一定要……""你必须……"（命令式）
- "相信我"（她不需要说，她用事说话）
- 任何煽情的话（"那段日子我哭了很多次"——她不会这么说，她会说"我办了5张信用卡"）
- "妈妈们"这种群体称呼（她用"家长"，更中性）

## 可以用的表达

### 从素材里提取的真实句子（可直接用或稍作调整）

| 场景 | 她的原话/接近原话 | 适用内容 |
|---|---|---|
| 讲创业起点 | "我是宁夏医科大学药剂专业毕业的。在急救中心药房干了3年，又去税务局上了3年班。2017年，父亲突发心脏病，我回家接手了驾校。"| 翻盘故事开头 |
| 讲不被看好 | "作为银川唯一的女校长，又是外行，年龄最小的——所有人都不看好。"| 逆境叙述 |
| 讲孤注一掷 | "我深知我唯一的出路只有不断学习。办了5张信用卡，刷出30万，全国各地去学习。"| 核心转折点 |
| 讲学习经历 | "有被割过韭菜，有被骗过，也学到了很多知识。"| 学习故事——真实、不自夸 |
| 讲成果 | "3年时间，把驾校做到了银川比较靠前的驾校。5年时间，还清了所有债务。"| 成果展示——平实、有数字 |
| 讲坚持 | "从2020年每天坚持拍视频，已经拍了6年，从未间断过。即使播放量是0，即使播放量不高，我也没有放弃。"| 坚持力体现 |
| 讲跨行 | "我感觉驾校行业越来越智能化，学驾照的人会越来越少。在一次学习中听到了低空经济，我毫不犹豫开始转型。"| 商业嗅觉 |
| 讲无人机 | "一年里做到了6个联盟店，招了100多个小学员，带着孩子们去打国赛。"| 成绩展示 |
| 讲现状 | "一周七天没有休息，但我觉得很充实。人在年轻的时候就应该不断努力。"| 日常感 |
| 讲心态 | "只要咬牙坚持往前走，就会遇到能帮我的贵人。只要不放弃，一切皆有可能。"| 结尾总结 |

### 改写示例（对文案同学）

**素材**："我当时很痛苦，大家都不服管。"
**武校长会说**："干了一年以后，大家都不服管。"
→ 删"痛苦"，留事实。她的痛苦在行动里——"我一个人背着包袱出去学习"。

**素材**："我非常自律，坚持学习。"
**武校长会说**："从2020年每天拍视频，已经拍了6年，从未间断过。"
→ 删形容词"自律"，用行动证明。

**素材**："我是一个积极向上的人。"
**武校长不会这么说**——她会说"我觉得很充实，觉得这才是年轻人该有的样子"。
→ 不说"我是谁"，说"我在做什么、我是什么感觉"。

## 绝对不能用的表达

### 禁用词
- 赋能、闭环、抓手、矩阵、颗粒度（内部黑话）
- "心法""秘籍""诀窍"（跟她气质不符）
- "精英""高端""贵族"（不是她的用户群）
- "名师""大咖""专家""权威"（她不是这个路子）
- "你必须""你一定要""不……就……"（制造焦虑）

### 禁用句式
- "作为XX领域的XX"（报告体，不像人话）
- "随着XX的发展"（空泛开场，直接说事）
- "总而言之""综上所述"（写完自动删）

### 禁用模式
- **煽情模式**：配悲情BGM + "那段日子我真的……"——不要。她说事实就够了。
- **喊话模式**："家长们注意了！"——不要。她不是那种人。
- **讲课模式**："今天给大家分享三点……"——不要。她是分享经历，不是上课。
- **机构腔**："我们拥有专业的教练团队、先进的教学设备……"——自杀。

## 一句话概括语感

**"闷声扛"——最狠的话平静说，最重的事淡淡讲。她的力量不在嗓门大，在咬着牙做的事。**

**给写稿同学的判断标准**：写完文案后，想象她在银川的训练场边、傍晚收工后，对着手机平静地讲这段话——如果别扭、如果像在"表演"，就改。

**她的"金句"不是设计出来的，是经历本身：**
- "我办了5张信用卡，刷出30万"
- "从2020年每天拍视频，已经拍了6年，从未间断过"
- "愿意贴钱亏损去买经验"
- "只要不放弃，一切皆有可能"

这些不需要修饰——把它们放在对的位置，力量就出来了。
