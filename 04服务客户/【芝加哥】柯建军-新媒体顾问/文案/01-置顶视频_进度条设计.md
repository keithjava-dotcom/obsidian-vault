# 01置顶视频 · 进度条设计

## 视频总时长
目标 2:15-2:30（精剪后）

## 进度条视觉设计

```
样式：顶部横向进度条，高度约40-50px
背景：半透明黑（#000 50%）
当前段：白色文字 + 底部白色短线标记
已过段：灰色文字（#888）
未到段：深灰文字（#555）
段间分隔：竖线（#333）
字体：无衬线加粗，12-14px
```

## 六段进度条

```
  已过（灰）        当前（白+下划线）      未到（深灰）
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐

    0:00       0:06       0:17       0:30       1:08       1:38
                                                          ↓ 2:05(精剪后)
```

## 标签设计逻辑：为什么这些词

### 给算法看
```
抖音的OCR会对进度条文字做识别，用于：
  → 内容分类（知识类/生活类/剧情类）
  → 关键词标签（起号、案例、变现）
  → 推荐模型匹配（推给对"新媒体"感兴趣的人）

所以每个标签都含一个核心关键词：
  200粉 = 反差钩子
  凭什么 = 设问结构（互动型内容）
  起号法 = 方法类内容（收藏价值）
  案例 = 证据类内容（信任）
  赚钱 = 结果类内容（欲望驱动）
  交付 = 产品类内容（转化）
```

### 给观众看
```
观众扫一眼进度条就知道：
  → "我在看什么"（当前段高亮）
  → "还要看多久"（剩余段数）
  → "接下来有什么"（未到段预览）
  → "要不要跳过"（段名够不够吸引人留下）

设计心法：
  ✗ 不写"干货分享"——太泛，观众无感
  ✓ 写"搜索起号法"——具体，观众知道这段有东西

  ✗ 不写"我的故事"——自嗨
  ✓ 写"懒但赚钱"——冲突感，观众想听

  ✗ 不写"结尾"——无聊
  ✓ 写"我的交付"——观众想知道"他卖什么"
```

## 进度条切换时机

每段标签在当前段音频开始后 **0.5秒** 切换高亮。给观众半秒缓冲。

| 切换点 | 触发信号 |
|--------|---------|
| 1→2 "8年200粉"→"凭什么教你" | 口播"我比较隔路"开口时切换 |
| 2→3 "凭什么教你"→"搜索起号法" | 口播"就两个东西"开口时切换 |
| 3→4 "搜索起号法"→"真实案例" | 口播"大连一个老牌医美"开口时切换 |
| 4→5 "真实案例"→"懒但赚钱" | 口播"我确实有一个毛病"开口时切换 |
| 5→6 "懒但赚钱"→"我的交付" | 口播"我的产品跟别人"开口时切换 |

## 替换方案（如果觉得6段太密）

5段精简版：

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 8年200粉 │ 凭什么教你│ 搜索起号法 │ 真实案例  │ 我的交付  │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

合并"懒但赚钱"到"真实案例"中——因为懒+反转本质上是用个人真实来增强案例可信度。

**建议**：先做6段版，实际贴上后如果觉得密就切5段版。6段信息更丰富，对算法更友好。
