# 置顶视频剪辑执行指令

> 生成时间：2026-05-03
> 视频脚本：《200粉不到，凭什么教你》
> 视频时长：目标2:15-2:30（原版2:59）

---

## 一、配乐

整条视频用一首BGM就够了，根据情绪段落调音量。

| 时间段 | 情绪 | 配乐处理 |
|--------|------|---------|
| 0:00-0:06 | 诚实开场，反差 | 钢琴单音或极简吉他。不要多，让人听清"200粉不到" |
| 0:06-0:17 | "隔路"态度 | 音乐渐起，加轻鼓点。有态度但不抢戏 |
| 0:17-0:30 | 设问"凭什么" | 保持节奏，稳住 |
| 0:30-1:08 | 干货输出+案例 | 音量稍推，节奏微微加快，配合信息密度的上升 |
| 1:08-1:38 | 千万播放+农民 | **音乐转暖**。这是情感拐点——从数据展示切换到"最满意的作品" |
| 1:38-1:57 | 自嘲"懒"+ 反转变现 | 音乐收一点，让人听清。"不到200粉快忙不过来了"这里可以微微上扬 |
| 1:57-2:59 | 产品交付+承诺 | 音乐保持但不要喧宾夺主。到"你问越多得到越多"音量开始收 |
| 2:59 | "这就是我" | **音乐落，留白**。配合直视镜头3秒余韵 |

推荐BGM方向：坂本龙一《Merry Christmas Mr. Lawrence》纯钢琴版；或者Einaudi风格的钢琴曲。有起承转合，有温度，不抢戏。

## 二、封面标题

**方案A（推荐）**
```
200粉丝
凭什么教你？
```
深灰/黑底 + 白色粗体大字 + 红色问号做视觉锚点。

**方案B**
```
我做了8年新媒体
粉丝不到200
```
两行字，第一行正常大小，"不到200"放大加粗。反差即钩子。

设计要点：无衬线加粗字体、底色干净、不加花里胡哨。只在"200"或问号上用一抹红色或橙色。

## 四、Keynote B-roll动画方案

> 设计原则：**先解释，后防枯燥**。
> 只给观众听一遍可能没懂的段落加画面，其余全交给脸。
> 工具：Keynote。全片约10张幻灯片，Magic Move过渡，黑底白字为主。
> 不强行凑7秒节奏——需要解释的地方解释，不需要的地方不动。

### 需要解释的6处

#### ① "隔路"方言解释（0:14-0:15）

**问题**：南方观众听不懂东北话。

**画面**：黑底白字，一行——**"隔路：不一样，不随大流"**。出来1.5秒，够看懂就走。

**Keynote**：一张片子，文字渐入，0.3s。

---
*点评：这个不用解释，方言就是增加观众的好奇感，这种跟内容无关的名词，不需要解释*

#### ② 行业差异化分屏（0:16-0:23）

**问题**：口播连报七八个行业名，听一遍分不清你做啥不做啥。

**画面**：左右分屏。

| 左（红色叉） | 右（绿色勾） |
| 餐饮、本地生活 | 医美、医院、全国招商 |
| （被划掉） | 装修、汽修 |

底部标注：**"敏感行业、高客单价"**

**节奏**："我不做餐饮"→左边出，"我做的都是医美"→右边出。口播跟画面同时推。

**Keynote**：一张片子，构件分批出现。左边先出（灰色+红叉），右边逐行弹出（白色+绿色标签）。5-6个构件飞入。


*点评：这个跟主题也无关，可以插一插相机拍的素材，到不需要用文字来解释*
---

#### ③ 核心公式：用户心理+规则=可复制（0:27-0:34）

**问题**：抽象关系，口播说完观众可能没抓住。

**画面**：两张片子用Magic Move。
- 片子A：左圆"用户心理"，右圆"平台规则"，中间空着。
- 片子B：两圆向中间靠拢重叠，重叠区出"可复制的公式"。

**Keynote**：两张片子，Magic Move过渡，0.5s。唯一带"动画感"的，因为解释的是抽象逻辑关系。

*点评：这个创意不错，用图形来解释理论，比我的单纯用文字来表达 好多了。
*---*

#### ④ 搜索法分步演示（0:37-0:55）⭐ 核心干货

**问题**：观众要跟着你"脑子里想象搜索"，不如直接看见。

**画面**：4张片子串成搜索流程。

| 张 | 时间 | 画面 |
|----|------|------|
| 1 | 0:37 | 白色搜索框（圆角矩形），光标闪烁。输入"餐饮内幕" |
| 2 | 0:42 | 搜索结果列表弹出，3-4条标题，配一行小字"大家关心什么，讨论什么" |
| 3 | 0:49 | 箭头指向：**"老板回答 = 最好稿子"** |
| 4 | 0:53 | "起号特别快" + 一行标注"不是瞎说" |

**Keynote**：每张片子3-4秒，Magic Move过渡。搜索框用形状+文字做。
*点评：这个也不错*

*---*

#### ⑤ 案例数据卡（1:01-1:19）

**问题**：三个案例六七个数字，靠耳朵记不住。

**画面**：一张片子，三张卡片2秒出一张。

| 卡片 | 内容 |
|------|------|
| 1 | 老牌医美·大连 → 3个月起号·精准客资 |
| 2 | 科技招商 → 1000→1万粉·400万业绩 |
| 3 | 家政全国招商 → 2000→8000粉·130条/周 |

数字用红色或黄色标出。白卡+黑字+数字高亮，无装饰。

**Keynote**：一张片子三个形状，构件出现逐卡飞入（左→右→中下），间隔2秒。

*点评：这个不错，抓的很准，我做了*

*---*

#### ⑥ *产品交付时间线*（2:24-2:33）

***问题**："前3个月→后9个月→持续一年"，时间关系口播说容易乱。*

***画面**：一条横轴，三个节点。*

```
●━━━━━━━●━━━━━━━━━━━━━━━━●
0月      3个月             12个月
你出·我改    你写·我审      结束
```

*底部一行字：**"深度思考全过程，不是丢模板"***

***Keynote**：一条线用形状画，三个圆点+文字构件依次出现。*
*点评：这个也很好*

*---*

### 不需要加画面的段落

| 段落 | 原因 |
|------|------|
| 开场"8年+200粉" | 靠你的表情和语气，比画面有力 |
| "我怕人笑话" | 情绪，留脸 |
| "同行不敢接""没意思" | 态度，留脸 |
| "凭什么教你" | 反问句，眼神比画面狠 |
| "千万播放+农民" | 口播本身有画面，不加 |
| "懒"+"但是"反转 | 情绪拐点，脸比什么动画都好使 |
| "网红/IP"被划掉 | 你的语气就是划掉，不需要画面划 |
| "你问越多得到越多"+"割韭菜" | 结尾收情绪，脸 |
| "这就是我" | 不能有任何东西挡脸 |

**总结：6处B-roll，约10张Keynote片子，覆盖全片约60秒。其余2分钟全是脸。**

## 五、自查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 原创性 | ✅ | 诚实人设+200粉反差，市面上没有 |
| 前3秒 | ✅ | "8年+200粉不到"，反常识钩子直接成立 |
| 核心刺点 | ✅ | 一个：诚实是最大差异化 |
| 情绪曲线 | ✅ | 自嘲→自信→干货→感动→反转→承诺 |
| 获得感 | ✅ | "行业+内幕"搜索法可当场用 |
| 违规风险 | ✅ | 已删"4980""变现2万"等数字，当前安全 |
| 信息密度 | ⚠️ | 2:59偏长。案例部分可以收紧 |
| 时长 | ⚠️ | **建议精剪到2:15-2:30**。砍口语重复、合并案例表述 |

**精剪建议三个点：**

1. **0:13-0:17** "医美医院、全国服务类、汽修装修"——合并成"医美、医院、全国招商这些敏感行业"，省3-4秒
2. **0:43-0:59** 案例罗列——感受节奏，如果感觉拖就合并表述，省5-8秒
3. **2:05-2:59** 产品交付60秒偏长——剪掉口播中的重复和停顿，目标压到45秒以内
