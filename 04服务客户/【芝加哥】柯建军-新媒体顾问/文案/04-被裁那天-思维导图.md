### 明牌问题的设计

```
这条视频的明牌问题不能太抽象。02的明牌问题是"AI到底该扮演什么角色"——那是在讨论一个方法论。
04的明牌问题是"一个人到底能不能干过一个团队"——这是在回应一种生存焦虑。

02的观众：对AI好奇的人
04的观众：被裁/创业/一个人扛着的人

明牌问题要打到观众当下的处境里：
  → "我也被裁了，我也在一个人干，所以我需要这个答案"
```

### 情绪推动逻辑

```
这条的情绪不是"生气→释然"这么简单。它有一个更微妙的转变：

前期：替柯哥不平（"帮老板赚十万，他裁你？"）
中期：替他累（"一个人太辛苦了"）
后期：替他高兴（"找到路了"）
结尾：替自己想（"我是不是也可以？"）

关键：观众的情绪对象从"柯哥"转移到"自己"。
这不是一条"听别人的故事"的视频——这是一条"找自己的答案"的视频。
```

## 三、核心论点拆解

### 🎯 唯一刺点

```
被裁不是失败——是被迫找到了本来就属于自己的系统。
```

### 📐 支撑逻辑

```
传统模式：一个人 = 一个人的产出
  ├─ 写文案：自己写
  ├─ 拍摄剪辑：自己做
  ├─ 跑客户：自己跑
  └─ 结果：累死，且不可持续

外挂模式：一个人 + AI = 一个团队的产出
  ├─ Obsidian：存方法，下次直接调
  ├─ AI：搭架子，结构不用从头想
  ├─ 人：做判断，填专业内容
  └─ 结果：一个人干三个人的活，还更快

关键转折：不是"学会了新技能"，而是"重新发现了旧资产"。
  → 八年经验不是包袱，是弹药库。
  → 只是以前不知道怎么调用。
  → 裁员逼着他学会了调用。
```

### 🔑 触发点

```
被裁 → 没人可以依赖 → 必须自己想办法
  → 把自己知道的写下来 → 发现这是个系统
  → 加上AI → 发现一个人真的能干过团队
  → 回头看：那次裁员不是坏事

这条视频最狠的地方：不是抱怨被裁，是感谢被裁。
反常识——这才是真正有力的情绪。
```

## 五、内容技法 × 情绪技法拆解

### 开头：一句话就是一条视频

```
"我帮一个老板，把账号从0做到月入十万。他把我裁了。"

两句话。一个巴掌。
观众脑子里自动脑补了：什么老板？为什么裁他？后来呢？
不需要铺垫，不需要自我介绍。这两句话就是整条视频的预告片。
```

### 中段：从"替我累"到"替我高兴"

```
前半段让观众替你累：
  "没有团队，没有人帮你拍，没有人帮你剪"
  → 三个"没有"排比，让观众自己数一共少了多少东西

中间段让观众好奇：
  "直到我开始做一件事——把脑子里所有的方法、经验，全部写下来"
  → "一件什么事？" → 好奇心驱动继续看

后半段让观众替你高兴：
  "现在一个人，干以前三个人的活。还干得更好。"
  → 从累→好，情绪完成180度翻转
```

### 结尾：不打鸡血，打真相

```
不喊"被裁了别怕，你也可以的"
→ 说"你不是没能力，你只是还没被迫去找到自己的系统"

这不是鸡汤。这是一个经历过的人说的实话。
"被裁"和"被迫"是同一个字——被。
但"被迫"给的礼物是：你终于开始挖自己了。
```

### 三种武器（沿用02的技法框架）

#### 武器一：句长切换

```
长句铺：
  "白天跑客户跟他们对需求，晚上回来一个人坐在电脑前写文案，
   写到凌晨两三点剪视频，第二天早上九点接着跑客户"
  → 撑开时间感，让观众跟你一起熬

短句钉：
  "人要废了。"
  → 四个字砸下去。从长句铺陈突然收缩，就是一拳打在胃上
```

#### 武器二：措辞烈度递进

```
Level 1："没有团队了"（陈述事实，还没到情绪）
Level 2："没有人帮你拍，没有人帮你剪，没有人帮你写"（排比积累）
Level 3："人不分几个，客户只要结果"（压力上升）
Level 4："干了一个月，人要废了"（身体极限）
Level 5："这不是长久之计"（不是抱怨，是清醒的绝望）

从"没有团队"到"要废了"——观众不是被告知你很累，是被带着走了一遍你的累。
```

#### 武器三：代词切换

```
前半段全用"我"：
  "我帮一个老板""他把我裁了""我开始想""我试了""我发现"
  → 这是柯哥的故事

中间关键句切换暗示：
  "那些我觉得'没什么特别'的东西"——"别人眼里是值钱的方法论"
  → 从"我"到"别人"，建立对比，观众开始想"我是不是也有这种'没什么特别'的东西？"

结尾用"你"：
  "你不是没能力。你只是还没被迫。去找到自己的系统。"
  → 故事讲完了，现在是你的问题了
```

## 七、需柯哥补充的缺口

- [ ] 真实细节：那个老板是什么行业的？账号做了多久做到月入十万？被裁的具体场景是什么？
- [ ] 被裁后第一单：怎么接到第一个客户的？是自己找的还是别人介绍的？
- [ ] 一个人扛的具体感受：最崩溃的一个晚上是什么样的？有什么细节？
- [ ] 从"硬扛"到"写下来"的转折瞬间：是哪天、哪个事让你决定开始把脑子里的东西全写下来的？

## 九、可复用的模式

这条骨架适用于所有"被迫开始"类的故事：

```
适用场景："被迫做了X，结果发现X比原来的路更好"
骨架模板：
  0帧：一个反常识结果（好事来自坏事）
  明牌问题：一个人能不能…？
  阶段1：硬扛（真实的困难，不加滤镜）
  阶段2：转折点（一个具体瞬间）
  阶段3：发现（原来我有这个）
  答案：一个人+系统 > 一个团队
  结尾：不喊口号，给一个"你对号入座"的空间
```
