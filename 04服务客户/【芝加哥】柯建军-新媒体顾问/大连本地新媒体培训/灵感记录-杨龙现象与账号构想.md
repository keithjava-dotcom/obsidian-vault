# 大连本地新媒体培训——灵感记录

---

## 灵感原话（不动）

大连本地网红 **杨龙**（前库里自助餐老板）通过短视频扩了大量业务项目，在大连本地小老板圈子里有一定影响力。

**杨龙受众** vs **柯建军受众**——完全两个群体：

| | 杨龙受众 | 柯建军受众 |
|---|---|---|
| 人群 | 本地小老板 | 医生、律师、大学生、硕士 |
| 认知 | 看表面 | 有系统、有认知 |
| 心态 | 想以快求成 | 不要浮躁表面 |
| 需求 | 模仿成功路径 | 深度表达、慢下来做自己内容 |

杨龙受众的盲区：只看到杨龙现在的成功，没看到他背后那几年的失败。杨龙其实是个打不死的小强——很多非议、争议，但坚持做下来了。

**账号构想**：
- 形式参考：一条老师的形式——深度表达，为一个群体发声
- 内容切入：毛选的政治思维作为主题框架
- 核心定位：不是教怎么做短视频，是教怎么用新媒体做深度表达

## 向内折叠发散

### 轻量含金体检（两条致命闸）

✅ **意识形态性**：通过。价值观清晰——求真>求快，深度>表面。跟柯建军定位"不造梦""想清楚再走"完全对上。

⚠️ **速判性**：通过但需警惕。核心是"为高知群体发声"，底色是平视。但"毛选思辨"如果做成"我来教你毛选怎么用"就变成俯视。需在表达时保持一条老师的"平视叙事"——是"我们这群人面对浮躁市场的处境"，不是"我来给你们上课"。

**Q1 · 差异化判断**

→ 为什么你能这么笃定地做这个判断？
→ 你见过的最典型的"看表面"的小老板，说一个具体的人——他因为什么翻车的？

**Q2 · 杨龙这个样本**
杨龙的"打不死小强"，你跟他有什么共同的？有什么不同的？
→ 你也是跨行业走过来的人，看到杨龙被争议包围时，你心里怎么想？
→ 如果让你用一句话区分"杨龙的成功路径"和"你的成功路径"，那句话是什么？

**Q3 · 毛选框架**
毛选里的哪个具体框架你觉得最适合接新媒体？
→ "没有调查就没有发言权"？"矛盾论"？"实践论"？
→ 你用毛选的哪个概念解释过新媒体行业的浮躁现象？

**Q4 · 一条的形式**
你看一条的时候，哪条视频让你觉得"这就是我想要的表达方式"？
→ 一条的表达有什么特色是别人学不来的？
→ 如果柯建军做一条式的内容，你觉得自己最稀缺的资源是什么？（不是模仿一条，是用你的内核套一条的形式）

**Q5 · 受众画像**
你客户里哪个医生/律师让你觉得"这个人如果能用一条式表达，他的内容会炸"？
→ 他卡在哪？是不知道讲什么，还是不知道怎么讲？
→ 如果这个人来找你做"大连本地新媒体培训"的课程，你会先让他做什么？

## 梳理整理版

### 核心矛盾
大连本地市场被杨龙这类"成功故事"占据 → 吸引了大量只想模仿表面成功的小老板 → 但有一群高知人群（医生/律师/硕博）被忽视了，他们要的不是快，是深度表达。

### 差异化切口
| 杨龙们在卖 | 柯建军要卖 |
|---|---|
| "我做到了，你也可以" | "你想清楚了吗？你敢慢下来吗？" |
| 成功路径复制 | 思考框架搭建 |
| 本地网红影响力 | 毛选思辨 + 新媒体深度表达 |
| 对外扩张 | 向内折叠 |

### 内容锚点
- **不是教短视频**，是教"用新媒体做深度表达"
- **一条式**：节奏慢、信息密度高、为一个群体发声
- **毛选框架**：矛盾论（找主要矛盾）、实践论（先干再调）、没有调查就没有发言权（别瞎模仿）

### 目标受众再确认
跟柯建军现有受众高度重合：医生、律师、大学生、硕士群体。他们不是"想做博主"，是"有专业能力但不知道怎么用新媒体表达"。

### 潜在风险
- 毛选切入在大连本地市场可能过于"高冷"，需要找接地气的入口
- "一条式"对团队产能要求高，需要评估已有团队能不能撑

## 选题方向建议（待确认）

1. **"大连只有杨龙吗？"** — 借杨龙现象引出"另一群人被忽视了"，为高知群体正名。不谈杨龙不好，谈"市场缺什么"。
2. **"毛选教我的第一件事：没有调查就没有发言权"** — 用毛选框架拆解新媒体行业的浮躁现象（瞎模仿、追风口），拉起深度表达。
3. **"医生做短视频，别学网红那套"** — 具体到某个职业群体，讲他们该怎么做——不是拍段子，是把专业变内容。
4. **"我在芝加哥看大连：本地培训的另一种可能"** — 地理差带来的观察视角，讲为什么慢下来才是最快的路。
5. **"一条老师教会我的事：为一个群体发声"** — 拆一条的表达方法论，嫁接柯建军的内容体系。
