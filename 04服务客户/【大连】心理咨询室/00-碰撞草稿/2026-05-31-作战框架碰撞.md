# 2026-05-31 心理咨询室合作 · 作战框架碰撞

## 柯哥核心判断

> "各自都认为自己是创始人，导致各自都不开始干活。这是我非常忌讳的一个点。"

**根因**：股权身份和劳动身份没有分离。
创始人是结果证明的，不是先说好再干活的。先干活出结果，再谈身份。

---

## 一、目标：开一次课能赚多少钱

### 定价策略（柯哥确认版）

> **测试期（2-3期）：4980元/人**
> **正式期：15800元/人**
>
> ⚡ 策略：4980测试期标注"原价1.5万，首期内测价"——让早期学员觉得占便宜，让看到标价的人觉得4980是机会。跑通2-3期拿到口碑案例后正式提价。

### 每期人数

> 5-10人开班，**不超过10人**。超过10人交付精力跟不上，影响口碑。

### 算账

| 变量 | 估算 | 备注 |
|------|------|------|
| 课程定价 | 4980（测试期） | 2-3期后提至15800 |
| 每期人数 | 5-10人 | 上限10人 |
| 每期收入 | = 定价 × 人数 | 24900~49800（测试期） |
| 减去场地成本 | — ？ | ⚠️ 待确认：现有小办公室还是租长期 |
| 减去推广成本 | — ？ | 投放/物料 |
| 减去讲师分成 | — ？ | 柯/菲菲/付总各自分多少 |
| **每期净利润** | = ∑ | **这个数才是"能赚多少钱"** |

### 场地

> 现有小的办公地方。长期租还是慢慢跑？→ **待开会确认**

### 团队必须开销

- 房租 — 谁出？
- 拍摄设备、剪辑质量 — 谁出？
- **赵姐的角色**：要么拉新客户进来，要么出钱。不能既不出力也不出钱。

## 三、分工：谁干什么，对什么结果负责

> 核心原则：**讲课的讲课，交付的交付，该招人就招人，该落地就落地。互相推责的团队不值得投入。**

### 角色定义

```
┌──────────────────────────────────────┐
│              团队分工图               │
├──────────┬──────────┬───────────────┤
│  流量端  │  转化端  │    交付端      │
│ (拉新)   │ (收钱)   │   (服务)       │
├──────────┼──────────┼───────────────┤
│ 柯建军   │ 付总？   │ 菲菲           │
│ IP运营   │ 线下大课  │ 疗愈内容      │
│ 内容策略 │ 成交转化  │ 客户交付      │
│ 账号搭建 │ 资源整合  │               │
├──────────┼──────────┼───────────────┤
│ 结果：   │ 结果：   │ 结果：         │
│ 每月X条  │ 每期X人  │ 客户满意度     │
│ 播放/咨询 │ 成交额   │ 复购/转介绍   │
└──────────┴──────────┴───────────────┘
```

### 具体分工（提案）

| 角色 | 负责人 | 具体做什么 | 考核指标 |
|------|--------|-----------|---------|
| **内容+流量** | 柯建军 | 账号定位、选题、文案、拍摄指导、发布策略、线上引流 | 月度粉丝增长 / 咨询量 |
| **线下转化+资源** | 付总 | 线下渠道开拓、异业合作、大课成交、资源整合 | 每期课程报名人数 / 线下合作签约数 |
| **课程交付** | 菲菲 | 疗愈/心理课程内容设计+讲授、客户服务标准制定 | 客户满意度 / 复购率 |
| **运营协调** | 赵姐？ | 排期协调、场地对接、物料准备、财务管理 | 课程执行顺畅度 |

### 必须明确的三条

1. **分工之后，各自对结果负责**。没完成就是没完成，不找理由。
2. **该招人就招人**。不是所有活都要创始人干。拍剪、客服、排期这些可以招人或外包。
3. **先干活，再谈身份**。出结果的叫创始人，不出结果的叫股东。两回事。

## 课程融合方案（柯哥修正版）

### 核心逻辑：并行 + 互推

新媒体课和疗愈课**不是上下层，是第一层里的两条腿**：

```
你学了疗愈 → 你需要新媒体把你的知识推广出去、转化出来
你学了新媒体 → 你需要专业技能（比如疗愈）才有内容可做
```

**两个字：互补。** 疗愈给人专业技能，新媒体给人推广转化能力。缺一条，另一条都跑不远。

### 产品结构

```
第一层（并行）
├── 新媒体运营实战 · 柯建军
│   定价：4980（测试期）→ 15800（正式）
│   时长：7天半天制（上午上课，下午实习）
│   受众：想做新媒体的人
│
└── 疗愈经济商业化 · 菲菲
    定价：待定
    时长：待定
    受众：想在疗愈行业创业的人

第二层（待确认）
└── 营销大课 · 付总
    定位：？
    柯哥判断：有点像成功学，没听明白底层逻辑是什么。→ 待付总明确"到底讲什么、给谁讲、解决什么问题"
```

### 导流逻辑

| 场景 | 动作 |
|------|------|
| 学员报疗愈课 | → 推荐新媒体课（帮他把疗愈推广出去） |
| 学员报新媒体课 | → 推荐疗愈课（让他有专业技能支撑内容） |
| 付总的线下资源（实体老板） | → 推新媒体课（帮他们做线上转化） |
| 新媒体/疗愈学员是老板 | → 推荐付总课程（线下成交能力） |

### 融合方式：先各开各的，交叉导流

- 不需要硬揉成一门课。各自主讲、各自定价、各自交付
- 通过**交叉推荐+返点机制**实现融合
- 你的课先开，菲菲的课准备好再开，不互相等

### 付总的问题

柯哥原话："付总的课程有点像成功学，我确实没太听明白它的底层是什么。"
**→ 开会时让付总讲清楚：你的课核心解决什么问题？给谁上的？讲完回去能干什么？** 讲不清楚就先不卖。

## 五、柯哥的底线，开诚布公

1. **我不负责"催人干活"**——分工说清楚了，各自认领，各自负责。谁没干，不是我催，是团队一起问责。
2. **先跑通一次课再谈股权**——课都没开过，分什么股份？第一次开课赚了钱，按贡献大小分。跑通三次课以上，再谈长期股权。
3. **我能出的是脑力**——内容策略、IP运营、选题文案。拍剪执行、线下协调、财务——这些需要其他人或招人解决。
4. **我需要看到别人也在动**——如果开完会分工完毕，两周后别人都原地踏步，我不陪跑。
5. **赵姐必须有自己的任务**——要么拉新客户，要么出钱。不能挂创始人名不干活。
