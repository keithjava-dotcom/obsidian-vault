## 第二层：还有哪些没搞明白？

> **目的**：让柯哥知道"他们看完还是懵的地方"。

看昨晚的会议记录，绕圈子的地方有6个。**这6个就是没真懂的信号。**

| # | 谁 | 困惑 | 一句话本质 |
|---|----|------|-----------|
| 1 | **菲菲** | "教他学" vs "合作分钱"分不清 | 两条路径在她脑子里打架——到底先卖他课，还是先跟他合作？你要告诉她：**先成交，再谈合作。成交完了想怎么合作都行。** |
| 2 | **菲菲** | 卖老板还是卖客户 | 活动升单升谁的单？**先升客户的单，帮老板赚到钱。老板赚到钱了自然愿意跟你继续合作。** |
| 3 | **菲菲** | 一对一交付 vs 集训 | 不是困惑，是**需求**——她想轻松交付。**集中集训可行，柯哥已确认过。** |
| 4 | **赵姐** | 短视频=连续剧 | 想做"系列内容"。**去掉这个念头。一条讲一个事，点击高才深挖。** |
| 5 | **赵姐** | 销售话术方向 | 问"你经营有困难"→**改问"想不想多赚钱"。** |
| 6 | **菲菲** | vlog拍什么 | 概念懂了，落到自己行业不知道拍什么。**拍谈单、拍活动、拍团队日常。** |

## 第四层：落地动作——各人版本

> **规则**：每个人看完自己的部分，不用看别人的。
> 今天只做一件。做完就赢了。

### 菲菲版

**今天（6/13）只做这一件：**

把39800产品用文字写清楚。

格式模板，照着填就行：

> **全程圈（39800）包含：**
> 1. 录播课：___个模块，每模块___节，共___小时
> 2. 季度线下课：一年___次，每次___天，地点___
> 3. 陪跑：___个月，每周___次，形式（语音/视频/文字）___
> 4. 额外交付物：___
> 5. 客户学完能：___

写完了发群里，@柯哥确认。

**其他事今天别管了。** 账号不用今天发，富姐不用今天谈。就这一件。

**这个月（到6/30）做到什么算赢：**
- ✅ 富姐合作谈下来（不需要签，谈出结果就算）
- ✅ 至少做1场异业门店活动（哪怕只来了5个人）
- ✅ 专业号发≥3条、思考号发≥10条、团队号发≥2条
- ✅ 总营收≥1单（目标3单，但1单就是胜利）

**遇到意外怎么办（不用问柯哥）：**

| 情况 | 动作 |
|------|------|
| 富姐说"再考虑考虑" | 说"行，下周我再找你"，不追。先推异业门店。 |
| 老板问"能不能免费试一场" | 不行，最多降到69。不免费。 |
| 客户想买但嫌贵 | 推2980，先入门。 |
| 今天不想写产品 | 那就想想：如果没有这个产品手册，下个月你还在原地。 |
| 不确定"这种算什么情况" | 超过2分钟想不明白→先成交再说。成交了再看算什么情况。 |

### 赵姐版

**今天（6/13）只做这一件：**

打开微信通讯录，写下10个你认识的店老板名字。
然后给他们发同一句话：

> "姐，最近咋样？最近我在跟一个心理疗愈团队合作，帮店里做增值活动，想不想多赚点钱？"

发完就算完成。不管他们回不回复。

**同一个店老板不要再发第二次。** 发了没回就当没这回事。

**话术禁忌**：
- ❌ 说"你经营有困难" → 人家不会承认
- ✅ 说"想不想多赚钱" → 所有人都会说想

**这个月（到6/30）做到什么算赢：**
- ✅ 10个名单全部发完消息
- ✅ 至少1家店愿意聊（不拒绝就算赢）
- ✅ 跟着菲菲做1场活动，负责拍摄记录

**遇到意外怎么办：**

| 情况 | 动作 |
|------|------|
| 老板问"具体怎么做" | "我们有老师，约个时间我带你老师来跟你面对面聊。" |
| 老板说"我没兴趣" | "没事姐，有需要找我。" → 标记。不纠缠。 |
| 老板问"多少钱" | "免费聊，聊完看适不适合你再说。不急着收钱。" |
| 不知道接下来该干啥 | 问菲菲：下一步活动定在啥时候？我来拍。 |
| 今天不想发消息 | 想想：不发明天也得发。早发完早轻松。 |

### 付总版

**今天（6/13）只做这一件：**

写一条视频文案。

标题固定：

> "老板，你的公司每个月在三个地方白花钱。"

内容结构：
1. 列举三个常见的浪费场景（具体，不要说"管理不善"这种虚的）
2. 用你自己的客户案例或经验佐证
3. 一句话结："想省钱？先看看这三点。"

写完发群里，@柯哥看。柯哥说"行"再拍。

**别想别的。** 别想第二条、别想做系列、别想账号名。就这一条。

**这个月（到6/30）做到什么算赢：**
- ✅ 视频号发≥4条（每周1条）
- ✅ 每条内容核心：帮老板省钱 或 帮老板赚钱
- ✅ 至少1条数据能看（播放>500就算赢，不要跟大号比）

**遇到意外怎么办：**

| 情况 | 动作 |
|------|------|
| 不知道写啥 | 翻翻你过去帮客户省钱的案例，提炼成一条 |
| 拍完不敢发 | 发群里让柯哥看，他说"可以"就发 |
| 发了没流量 | 正常。4条里能有1条有反应就是胜利。继续发。 |
| 不知道该不该做 | 做完发了再说，比想了2周没发强100倍 |

## 附录：决策锚点总图（不用问柯哥）

```
遇到一个老板
    │
    ├─ 她有钱想学 → 卖39800/9800/2980（按预算选）
    │
    ├─ 她有资源不想学 → 合作分钱（等柯哥确认分润比例）
    │
    ├─ 她既没钱又没资源 → 下一个
    │
    └─ 搞不清她属于哪种
        → 直接问："姐，你想不想学？"
        → 想学→卖。不想学→"那你有没有客户资源？"
        → 有→合作。没有→谢谢。
        → 超过3分钟搞不清→ 下一个。
```
