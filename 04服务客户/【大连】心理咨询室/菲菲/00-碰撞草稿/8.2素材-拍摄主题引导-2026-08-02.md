# 菲菲 · 8.2素材提炼 · 拍摄主题+结构+现场提问

> 使用说明：柯哥现场引导用。每个主题 = 一句话角度 + 短视频结构 + 现场提问（问题要具体到能勾起菲菲的记忆）。
> 筛选原则（7-29 碰撞定）：不做玄学派（多维存在/链接神明/灵魂不死太飘，菲菲讲了就变第二个卓子）；只做"落在具体人身上的个案+判断"。13条素材筛出 **7 个可拍主题**。

## 🔴 IP类型定位（2026-08-03 行业卡补入 · 拍摄前必读）

**菲菲 = 专业温和型疗愈IP**（心理咨询室三IP各占一型：菲菲专业温和 / 若溪强势转型 / 赵姐素人过来人）。

| 维度 | 菲菲应该的样子（行业卡原话） |
|------|---------------------------|
| 信用来源 | 专业背景 + 通透气质 |
| 内容形态 | **认知输出 + 案例拆解**（不是素人故事会） |
| 受众期待 | 「她懂，我想学」 |
| 第一帧 | **反常识认知**（不是"我第一次"故事开头） |
| 语速 | 慢、稳、有停顿 |
| 术语 | 适度使用 + 翻译（保留灵性词汇：维度/能量/本自具足） |
| 变现入口 | 认知信任 → 服务 |
| 核心赌注 | 「她说出了我感觉到但说不清的东西」 |

**信任公式（每条视频都要过）**：信任 = 痛苦的真实性 × 觉醒的可复制性 × 当下的感染力 — 三因子是乘法不是加法，任一为零全盘皆输。
- 痛苦真实性：不用术语要画面（"那一年我在黑龙江的村子，第一次想到了死"）
- 觉醒可复制性：不是"我觉醒了"，是"我是怎么觉醒的"（路径拆步骤：执念→痛苦→遇见→回溯→看清→不再向外抓取）
- 当下感染力：现在的状态本身就是内容（"你看看我现在"是最有说服力的）

**受众心理链条（每条视频必须完成前三步）**：①「她说的这个，我也有」→共鸣 ②「她走出来了」→希望 ③「她是怎么走出来的」→好奇 ④「我也想找她聊聊」→行动（留给主页/私信，不硬塞进视频）

**拍摄硬规则（明天现场直接用）**：
1. **顺光优先**：窗户在身后=逆光翻车；要么换方向拍顺光，要么前面打光大于背景光
2. **镜头与心口齐平**：太低显下巴大，太高显俯视
3. **停顿比B-ROLL有力量**：三个问题之间的停顿比补拍画面强；微表情本身就是内容
4. **案例用文字卡代替人物出镜**（保护隐私同时传递信息）
5. **剪辑五步**：音频粗剪剪气口→BGM按起承转合→气口精修（用耳朵听）→画面填空（敢留白）→字幕导出

**六问自检（每条拍完过一遍）**：①开头是具体事件/反常识认知吗？②痛苦段后有"我现在懂了"的翻转吗？③术语翻译成大白话了吗（灵性词汇保留）？④结尾是陪伴邀请不是导师说教？⑤观众能在里面看到自己吗（镜子效应）？⑥保留了她的灵性词汇吗？

## 主题一：家族业力（素材：卓子5）

**一句话角度**：你努力活不出想要的样子，可能不是你不努力，是你们家传下来的一套"活法"卡住了你。

**为什么适合菲菲**：评论区共鸣最强（"怎么觉醒""我已经活出来了"），且菲菲做觉醒陪跑营，这是她的主战场。讲个案，不讲玄学。

**短视频结构**（约90秒）：
1. 【开场】结论先行：一个客户跟我哭"我这么努力为什么活不出来"——我问她一句话，她愣住了
2. 【个案】讲那个客户的具体事：她家谁的模式传给了她（妈妈？外婆？）——不评价，只讲事实
3. 【认知】家族模式是怎么传的（不是玄学，是"你从小看的是谁的样子"）——用类比降维
4. 【转折】她什么时候开始松动的——那个具体的瞬间
5. 【收口】金句："你不需要替整个家族活。你活出来，就是替家族松绑。"（停在这）

**现场提问**（问出真事）：
1. 你记不记得哪个客户，一来就说"我怎么努力都没用"？她当时什么表情、坐姿？
2. 她家里谁的模式传给了她？你怎么看出来的——她说了哪句话让你确定的？
3. 她松动的那一瞬间，你做了什么？她说了什么？
4. 你跟她说的最狠的一句真话是什么？

## 主题二：心理学 vs 疗愈（素材：卓子8/9）

**一句话角度**：心理学告诉你"你哪里有问题"，疗愈告诉你"你本自具足"——一个在头脑层面打转，一个在能量层面换维。

**为什么适合菲菲**：这是她的差异化核弹——理工科出身+100次疗愈SOP，她能用"数据"讲玄学圈讲不清的事。行业真相型。

**短视频结构**（约75秒）：
1. 【开场】结论先行："我学了心理学，后来不讲了。因为我发现一个事。"
2. 【行业真相】心理学解决"知道"的问题，疗愈解决"做到"的问题——你知道自己原生家庭有问题，然后呢？（用她自己的转型故事）
3. 【数据锚】100次疗愈SOP的来由——为什么是100次，不是3次（理工科思维）
4. 【反常识】"很多人疗愈没效果，是因为一直在头脑里打转"
5. 【收口】金句："知道做不到，等于不知道。疗愈是让你做到的那条路。"（留白）

**现场提问**：
1. 你从心理学转到疗愈，是哪个具体时刻下的决心？那天发生了什么？
2. 你见过哪个客户，学了一堆心理学知识还是卡着？他卡在哪？
3. 100次SOP是你怎么总结出来的？第几次疗愈让你觉得"这条路对了"？
4. 你被哪个客户一句话问住过？

## 主题三：人生是自挖坑自爬（素材：馨月1）

**一句话角度**：你以为是命不好，其实是你自己挖的坑——但好消息是，坑是你挖的，你就能自己爬出来。

**为什么适合菲菲**：评论区共鸣炸裂（"只有折腾才能证明我还活着"），大众向，拉新主力。信念系统型。

**短视频结构**（约60秒）：
1. 【开场】结论先行："人这一辈子，就是自己挖坑自己跳，再自己爬出来。"
2. 【展开】用她自己或客户的折腾故事：赚钱→赔→再赚→再赔——中间那句"我图什么"（别解释，让观众自己品）
3. 【认知】为什么非折腾不可——你挖的每个坑，都是你要的功课（不评判）
4. 【收口】金句："坑是你挖的，你就能爬出来。爬不出来，是因为你还没认这是自己的坑。"（留白）

**现场提问**：
1. 你自己挖过最大的一个坑是什么？跳进去那会儿什么感觉？
2. 哪个客户的故事最像"挖坑爬坑"？他最后怎么爬出来的？
3. 你劝过谁"别折腾了"？他听了吗？

## 主题四：松弛才能成事（素材：馨月2）

**一句话角度**：大事都是轻而易举成的——你越紧绷，越成不了。

**为什么适合菲菲**：她的客户全是老板——老板最缺的就是"松弛"。评论区争议（"做过大事没"）反而是钩子。敢说型。

**短视频结构**（约70秒）：
1. 【开场】结论先行："我服务过的老板，越是大生意，谈的时候越松弛。"
2. 【个案】讲一个具体老板：谈判桌上他什么样（不紧绷、不较劲）——画面感
3. 【认知】为什么紧绷成不了事——你太想要的时候，能量是乱的（用她的语言，不用玄学词）
4. 【反常识】"努力"和"松弛"不矛盾——努力是准备，松弛是交出去
5. 【收口】金句："你放松地发一个念头，宇宙帮你跑。你攥着不放，谁也帮不了你。"（留白）

**现场提问**：
1. 你见过哪个老板，签大单的时候特别松弛？他当时什么状态？
2. 他跟你说了什么让你印象深的话？
3. 你自己有没有"越想要越得不到，放手反而来了"的经历？

## 主题五：外面没有别人（素材：莫子1）

**一句话角度**：你看到的别人的问题，都是你自己的投射——外面没有别人，只有你自己。

**为什么适合菲菲**：心理学+灵性交界，评论区有争议（"别人骂我我为什么羞愧"）——争议=互动。个案故事型。

**短视频结构**（约80秒）：
1. 【开场】结论先行："你讨厌的人，身上一定有你自己不接受的部分。"
2. 【个案】讲一个客户：她死盯老公的某个毛病（或死讨厌某个同事）——那个毛病跟她自己的什么对应
3. 【转折】她看到投射那一刻的反应——具体画面
4. 【认知】不是让你憋着，是让你看见："你改不了别人，但你一改，关系就变了"（呼应莫子3）
5. 【收口】金句："你以为是他在折磨你，其实是你自己没放过自己。"（留白）

**现场提问**：
1. 哪个客户最典型——她死盯别人的什么？你觉得那其实是她自己的什么？
2. 她看到投射那一刻，发生了什么？她说了什么？
3. 有没有客户当场反驳你"不是投射，他就是有问题"？你怎么回的她？

## 主题六：回到自己关系就顺了（素材：莫子3）

**一句话角度**：你越想改变伴侣，关系越糟——你回到自己，关系自己就顺了。

**为什么适合菲菲**：婚姻支柱（定位优先级2），视频号中高收入女性主力。评论区共鸣强。

**短视频结构**（约80秒）：
1. 【开场】结论先行："婚姻里最没用的三个字：你改改。"
2. 【个案】讲一个客户：她天天想让老公改——具体画面（她怎么说的、老公什么反应）
3. 【转折】菲菲让她做什么（不是忍，是回到自己）——她做了之后关系发生了什么变化
4. 【认知】"谁先痛苦谁改变"——不是谁对谁错，是能量问题
5. 【收口】金句："你改不了他。但你一变，他跟着就变。这就是婚姻的功课。"（留白）

**现场提问**：
1. 哪个客户的故事最典型？她一开始怎么跟你说的？
2. 她回到自己之后，老公先改变的那个瞬间是什么样的？
3. "谁先痛苦谁改变"——这是你从哪个客户身上总结出来的？

## 主题七：理工科出身，为什么信了"看不见的东西"（素材：卓子2 转化）

**一句话角度**：我是理工科出身，以前只信数据。后来一个事让我知道——有些东西，仪器测不出来，但它真实存在。

**为什么适合菲菲**：人设锚+反差。她的理工科背景是信任状（不是神婆），讲这个能立住"数据派疗愈师"人设。个人故事型。

**短视频结构**（约75秒）：
1. 【开场】结论先行："我理工科出身，以前谁跟我说能量，我让他拿数据。"
2. 【故事】那个改变她的事——具体到画面（时间/地点/发生了什么）
3. 【转折】她怎么验证的（用她的理工科方法：记录、对比、重复）——100次SOP的由来
4. 【认知】"我不是信玄学，我是信验证过的结果"
5. 【收口】金句："数据测不出来的，不代表不存在。只是现在的仪器还没造出来。"（留白）

**现场提问**：
1. 哪个具体事件让你从"只信数据"松动了？那天在哪、谁跟你说了什么？
2. 你第一次用"记录/对比"的方法验证疗愈效果，是什么时候？
3. 你被哪个客户说过"你们就是玄学"？你怎么回的？

## 📋 拍摄当天快速检查表（2026-08-03 行业卡补入 · 拍前扫一眼）

### 开拍前（设备/环境）
- [ ] 顺光：窗户在身后=翻车。要么换方向，要么前面打光大于背景光
- [ ] 镜头与心口齐平（太低显下巴大，太高显俯视）
- [ ] 背景干净不花哨（疗愈IP信任来自稳定，不来自炫酷）

### 每条开拍前（内容）
- [ ] 第一帧是反常识认知（不是"今天给大家讲"）
- [ ] 这个故事/判断，观众会"她说的这个，我也有"吗？（共鸣）
- [ ] 有"她走出来了/她怎么走出来的"吗？（希望+好奇）
- [ ] 痛苦段后面有"我现在懂了"的翻转吗？（没有=消费痛苦）

### 每条拍完（自检六问）
- [ ] 开头是具体事件/反常识认知，不是抽象概念？
- [ ] 痛苦后面有翻转（"我现在懂了"）？
- [ ] 术语翻译成大白话了？（灵性词汇保留：维度/能量/本自具足是辨识度，别洗掉）
- [ ] 结尾是陪伴邀请（"你不需要替整个家族活"），不是导师说教（"你应该"）？
- [ ] 观众能在里面看到自己？（镜子效应）
- [ ] 灵性词汇还在吗？（被洗掉=失去辨识度）

### 剪辑五步（回来做稿时用）
1. 音频粗剪：剪掉气口（"嗯""啊"、超1秒沉默）
2. BGM铺设：按起承转合分段铺，只调音量不调位置
3. 气口精修：逐段调停顿时长，用耳朵听不用眼睛看波形
4. 画面填空：B-roll插进去，不需要的地方敢留白（停顿比画面有力量）
5. 字幕导出：检查节奏，导出
