# 赵姐账号定位报告

## 一句话定位

> 一个从农村走出来、婚姻里挣扎了30年、靠疗愈彻底活明白的普通女人，帮同样迷茫纠结的你，少走20年弯路。

---

## 人设标签

| 标签 | 说明 |
|------|------|
| 普通人觉醒者 | 没有高学历、没有背景，靠自己一路跌撞走出来 |
| 过来人 | 早婚、抑郁、家暴环境、多次转行，全都经历过 |
| 疗愈引路人 | 不是导师，是同路人，用自己的故事唤醒别人 |
| 黑龙江大姐 | 直接、热情、不绕弯子，有烟火气 |
| 50+逆袭者 | 五十多岁才真正活明白，反差感强 |

---

## 差异化核心记忆点

赵姐最反常识的地方不是"她懂疗愈"，而是：

**她把自己30年的苦，活成了别人的地图。**

她不是从书本里学来的，她是从婚姻里、从农村、从抑郁、从一次次转行失败里，一点一点熬出来的。这种"我走过你现在走的路"的真实感，是任何包装都替代不了的。

---

## 目标受众

**核心人群：**
35-55岁女性，处于婚姻困惑、中年迷茫、情绪内耗、不知道自己要什么的阶段。

**她们的共同特征：**
- 觉得自己活得很累，但说不清楚为什么
- 在家庭和自我之间找不到平衡
- 想改变，但不知道从哪里开始
- 见过太多"大道理"，但没见过一个真实走出来的人

**赵姐能给她们的：**
不是方法论，是"你看，我这样的人都能活明白，你也可以"。

---

## 账号类型判断

**人设型账号**，不是内容型。

赵姐的核心资产是"她这个人"，不是某个知识体系。粉丝跟的是她的故事、她的状态、她的真实感。变现路径是：信任→私域→疗愈服务/招商。

---

## 内容方向（三大支柱）

**支柱一：人生故事线**
把30年的经历拆成一个个具体事件讲出来。
不是"我曾经很苦"，是"那一年，我在黑龙江的村子里，第一次想到了死"。
每一个故事都是一面镜子，让观众在里面看到自己。

**支柱二：觉醒认知输出**
把她从疗愈里悟到的东西，用最普通的话说出来。
不是术语，是"我以前不知道，原来我那么累是因为……"
每条视频一个认知点，简单直接，不绕弯子。

**支柱三：当下状态展示**
展示她现在每天的状态——开心、笃定、不纠结。
不是说教，是对比：以前的我 vs 现在的我。
让观众看到"活明白"是什么样子的。

## 前6条选题及文案框架

---

### 第1条｜自白型·建立人设
**选题：** 我18岁嫁人，全家反对，我说谁也拦不住我——然后我为这句话付出了30年代价

**结构：** 对白型，总-分-总
```
【开头·0帧起手，直接切入事件】
18岁，我嫁人了。
全家反对。
我说：谁也拦不住我。
（停顿）
然后，我为这句话，付出了30年。

【中间·事件切片，2-3个具体场景】
结婚第一年，我们就打架。
那时候我不知道，那叫抑郁。
我只知道，我不想活了。
但我有一个执念：
我自己选的，我不能认输。

【结尾·转折+当下状态】
现在我懂了。
那不是执念，那是原生家庭给我的枷锁。
但也是它，让我一路撑过来。
我是赵姐，一个活了50多年才活明白的普通女人。
如果你也在扛，来找我聊聊。
```
**拍摄备注：** 坐姿，正面对镜头，光线干净，不需要道具。语速稍慢，停顿要留够。

---

### 第2条｜故事线·建立共情
**选题：** 我在农村种了十年地，那时候我已经抑郁了，但我不知道

**结构：** 对白型，以事件带情绪
```
【开头·0帧起手，直接切入场景】
那时候，我们村里，
谁家要是不打媳妇，才叫不正常。

【中间·情绪还原】
我没有朋友。
大门不出，二门不迈。
总有一个声音在说：你怎么活成这样。
现在我知道了，那叫抑郁。
但那时候，我只是觉得——
我不想在这里了。

【结尾·共情收尾】
你有没有过这种感觉？
说不清楚哪里不对，
就是很累，很想逃。
我懂。
```
**拍摄备注：** 情绪要稳，不要哭腔。陈述事实，不是诉苦。

---

### 第3条｜转折型·引出觉醒
**选题：** 50岁之前，我一直在向外抓取——做家政、做护眼、做美业，全都失败了

**结构：** 对白型，列举+反转
```
【开头·0帧起手，直接列举反常识】
我做过家政，做过护眼，做过美业。
全都失败了。

【中间·挖根因】
你知道为什么吗？
不是方向不对。
不是时机不好。
是因为我不相信自己。
我一直在向外抓取，
总觉得外面有一个答案，
能救我。

【结尾·转折】
直到我遇到了疗愈。
我才明白——
我一直在找的那个答案，
从来都在我自己身上。
```
**拍摄备注：** 开头语速可以稍快，列举时有节奏感。"全都失败了"后停顿。

---

### 第4条｜认知型·输出观点
**选题：** 什么叫活明白？不是没有烦恼，是你能跳出来看自己

**结构：** 独白型，定义+解释+示范
```
【开头·0帧起手，直接给答案】
活明白，不是没有烦恼。
是你有烦恼，但你知道它从哪来。

【中间·给定义，用具体说抽象】
不是没有事。
我现在也有很多事。
活明白是：
你知道你为什么哭。
你知道你为什么累。
你能跳出来，看自己。

就像你站在河边，
以前你在河里扑腾，
现在你站在岸上，看着那个扑腾的自己，
说：哦，原来你是因为这个。

【结尾·邀请共鸣】
你现在，是在河里，还是在岸上？
```
**拍摄备注：** 语速慢，每句话之间留停顿。"站在岸上看自己"这个比喻是核心，说的时候可以配手势。

---

### 第5条｜共情型·展示"懂得"
**选题：** 我同学老公刚走，轻度抑郁，我跟她说了一句话，她说：赵姐你怎么知道我在想什么

**结构：** 对白型，讲故事+揭示
```
【开头·0帧起手，直接还原对话】
我同学跟我说：
"赵姐，你怎么知道我在想什么？"

【中间·还原对话】
我问她：你现在最难受的是什么？
她说：就是不知道自己还有没有用。
我说：你这不是悲伤，
你这是——你的价值感塌了。
她愣了一下，说：
赵姐，你怎么知道我在想什么？

【结尾·点题】
因为我经历过。
那种感觉，我太熟悉了。
如果你现在也有这种感觉，
你不是一个人。
```
**拍摄备注：** 讲故事时语气要温，不要急。"你怎么知道我在想什么"这句话是情绪高点，说完停顿。

---

### 第6条｜状态展示·引发好奇
**选题：** 很多人问我：赵姐你怎么能每天这么开心？我说，不是没有事，是我不用情绪来工作了

**结构：** 对白型，问答式
```
【开头·0帧起手，直接抛反常识】
我每天都很开心。
不是因为我没有事。
是因为我不用情绪来工作了。

【中间·反转回答】
我说：不是。
我也有很多事。
但我现在不用情绪来工作了。

以前，有人说我一句不好听的，
我能难受三天。
现在，我能在五分钟内转念。
不是我不在乎，
是我知道怎么放下了。

【结尾·留钩子】
这个能力，不是天生的。
是我用了很多年，
才学会的。
你想学吗？
```
**拍摄备注：** 开头可以带点笑意，状态要松弛。结尾"你想学吗"是CTA，说完可以看镜头停顿一秒。
