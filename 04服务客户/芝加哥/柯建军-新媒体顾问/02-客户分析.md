# 柯建军 客户分析

## 2A · 基础六维度分析

### 1. 语感特征

**高频词和口头语**：
「落地」「碾压同行」「实打实」「接地气」「干不下去了」「然后就」「反正」「挺好玩」「还不错」

**句式习惯**：
- 口语流水句为主，大量「然后……然后……」的自然连接
- 爱用反问让人代入（「你看是不是」「对吧」）
- 擅长用具体数字制造真实感（180斤减到120斤、6万粉做到13万粉、400多万流水、从几百到2万）
- 说话节奏快，想到哪说到哪，不像在"表达"，像在"回忆"

**情绪基调**：
理性逻辑打底，但有滚烫的内核。不煽情不矫情，但自嘲和自省是自然的（「现在想起来还挺可笑的」「眼高手低」）。骨子里是不服输——「我做任何事情都一定要比同行做得好，碾压同行」。

**绝对不会说的话**：
- 赋能、闭环、抓手、颗粒度（互联网黑话）
- 「希望这份建议能帮到你」（AI废话）
- 空洞励志、文艺腔
- 造梦话术、割韭菜话术
- 「我教你怎么样怎么样」（说教腔）

### 2. 核心差异化（按竞争力六维度对照）

**反（相反价值）**——最强维度
所有知识付费都在造梦，他偏要落地。
「我不会骗人，不会靠话术销售。我不会给你造梦，造完之后达不到。我可以做完之后肯定达到，帮你落地。」
→ 在这个"人人都在卖梦"的行业，"不造梦只落地"就是最强的反共识。

**和（交叉合并）**——第二强
新媒体操盘手 + AI工具深度应用者 = 会用AI做新媒体的老师。
不是单纯教新媒体，也不是单纯讲AI，是把AI嵌入新媒体工作流。
→ 大多数新媒体老师不懂AI，大多数AI博主不懂新媒体落地。

**弱（以弱胜强）**——第三强
高中辍学、摆地摊、开Uber、工地搬废铁、被骗过、疫情赔光……
不是"名校毕业的精英投资人"，是"从泥里爬出来的实战者"。
→ 对传统老板来说，"辍学生都做成了"的冲击力远大于"精英教你怎么做"。

**入（下沉/利基）**——有效补充
专注"传统老板怎么用新媒体+AI落地"，不是泛流量，是精准人群。
→ 大V在讲泛方法论，他讲"家政老板怎么拍、装修老板怎么拍"。

**跨（跨界冲击）**——地理优势
在芝加哥做中文新媒体。全球视野+中国实战。不是"我出国了所以牛"，是"我见过更远的市场，但我的手在帮你做最接地气的事"。

**正（相同价值更专业）**——不推荐
直接和大V比"谁的方法论更系统"没有优势。他的壁垒不是理论体系，是"真实经历+落地案例+AI工具"的三合一。

**维度叠加**：反 + 和 + 弱 = 「辍学生逆袭的AI新媒体实战派」

### 3. 目标受众

**第一受众（死磕）**：30-50岁传统行业老板
- 有行业经验，但不会做短视频
- 找过代运营但效果不好，想自己学
- 对AI有好奇心但不知道怎么用
- 怕被割韭菜，想要"真的能落地"的人

**第二受众（自然吸引）**：想做IP但卡在落地的个体户
- 律师、咨询师、心理师等专业人士
- 有内容但不会表达，需要方法论
- 想找一个人"带着做"，不是"教着听"

**第三受众（泛流量）**：对AI+短视频感兴趣的年轻从业者
- 新媒体行业从业者，想学AI提效
- 贡献转发和评论

**他们最关心什么**：
- 我能不能学会？（门槛）
- 学会了能赚到钱吗？（结果）
- 你跟别人有什么不一样？（信任）
- 你有案例吗？（证据）

**平台聚集**：
- 抖音（最大流量池，老板也刷）
- 视频号（朋友圈裂变，老板转发）

### 4. 变现目标

**客户想从账号得到什么**：
1. 吸引精准客户 → 卖4980新媒体技巧课
2. 建立个人品牌 → 「操盘过项目的新媒体老师」
3. 月收入10万+

**最适合的变现路径**：
短视频内容建立信任 → 吸引精准学员 → 4980课程转化 → 老学员推荐新学员
（课程是主产品，2个操盘客户是存量交付，不再接新的）

**时间预期**：
- 1个月：账号定位确认，拍摄形式跑通，开始稳定产出
- 3个月：第一条爆款出现，开始有学员转化
- 6个月：月度学员稳定，个人品牌初步建立

### 5. 内容潜力

**能持续输出的方向**：
1. **案例复盘**：带学员出结果的故事（凤城烧烤老板3条视频出客资）
2. **AI+新媒体方法论**：怎么用AI工具做选题、写稿、分析数据
3. **个人经历判断**：创业故事+行业观察+趋势判断
4. **传统老板诊断**：帮老板分析"你的账号为什么做不起来"

**最有爆款潜力的方向**：
案例复盘。真实的人+真实的结果+具体数字=不可复制的信任感。
「我带了一个凤城烧烤老板，他之前找代运营做的全不满意，跟我学完3条视频就出客资了」

**内容储备**：
极其充足。每带一个学员出结果就是一个案例，每天的行业观察就是一条内容。

### 6. 风险提示

**最容易踩的坑**：
1. **身份模糊**——卡在"老师"和"操盘手"之间。内容一会儿像在上课，一会儿像在谈业务
2. **表现力瓶颈**——自己承认卡在表现力上，横版打电话的形式是新尝试，需要验证
3. **自我压力**——自己做这行的，怕别人评价流量不好
4. **过度理性**——逻辑太强但情绪不够，观众"佩服"但不"喜欢"

**需要提前告知的现实**：
- 老师做自己的账号，比学员做账号难十倍——因为你知道太多，反而容易想太多
- 第一条视频不必完美，先跑通形式再打磨内容
- 「碾压同行」的野心是动力，但别让它变成包袱

## 2B · 人设挖掘七维度

### 1. 故事性

**反差点/戏剧性**：
- 高中辍学 → 自学编程 → 开Uber → 工地搬废铁 → 健身教练 → 疫情赔光 → 芝加哥做新媒体
- 干过至少8个行业，每一个都没干到底，但每一个都留下了经验
- 最戏剧性：在北京开店半年回本，正要起飞时疫情来了，六年积蓄全赔

**形象 vs 身份的反差**：
- 自称"长得像许三多"（自卑起点）→ 现在要做"碾压同行"的新媒体老师
- 芝加哥+中文新媒体——人在美国，服务中国市场

**核心故事角度（1个素材N个角度讲）**：
「一个高中辍学生，在8个行业里失败过，最后在短视频上找到自己的方法论」
- 角度A：励志线（从泥里爬出来）
- 角度B：方法论线（为什么跨行业经历让你更懂老板）
- 角度C：判断线（为什么你说"AI才是未来，短视频只是工具"）

### 2. 性格、品行、人格魅力

**真实特质**（不说博主想象词）：
- 不服输 ——「碾压同行」不是口号，是他的本能
- 学得快 —— 编程三个月比大学生强，健身学三个月就入行
- 实在 —— 不骗人、不造梦、靠实力销售
- 自省 ——「现在想起来还挺可笑的」「眼高手低」
- 有野心 —— 想做AI系统、想做数字分身、想建个人品牌

**删掉的博主想象词**：
- ❌ 「接地气」→ 太泛，换「说的话老板听得懂」
- ❌ 「活泼搞笑」→ 不是他的真实状态，换「偶尔自嘲」

### 3. 与观众的关系（五种姿态）

**主姿态：立派**
在前人基础上提出新概念——「新媒体+AI」的结合。
他不是在重复舒老师/花火/安先生的方法论，是在他们的基础上加了一层AI工具的应用层。

**辅姿态：同道中人**
他也失败过、也赔过钱、也换过行业、也焦虑过——和传统老板是同路人，不是居高临下的老师。

**为什么不开宗/服务者**：
- 开宗太狂，不符合他"实在"的形象
- 纯服务者太窄，他有方法论体系想输出

### 4. 三观/意识形态

**你所认可的**：
- 落地比造梦重要
- 学习能力比学历重要
- AI是伙伴不是替代
- 做内容先想"能给观众什么"，不是"我想说什么"
- 不骗人是底线

**你坚决反对的**：
- 割韭菜式知识付费（造梦→收钱→不交付）
- 纯流量思维（为数据做内容，不为结果做内容）
- 学历歧视（「很多大学编程人员赶不上我的技术」）
- 「老板就应该all in短视频」的极端主张

**个人简介应该写**：三观 > 履历
履历太乱（8个行业），但三观统一：不造梦、要落地、用AI放大能力。

### 5. 愿望/渴望/个人目标

**短期（0-6个月）**：
- 账号跑通，拍摄形式验证
- 4980课开始稳定出单

**中期（6-12个月）**：
- 月收入10万+
- 学员案例积累到可复用的程度
- AI工具系统初步搭建

**长期（1-3年）**：
- 数字分身落地
- 个人品牌成型
- 课程体系完整

**软肋/缺点**：
- 表现力需要打磨（自己承认的）
- 有时候想太多（自己懂太多反而不好下手）
- 对"别人怎么评价流量"有焦虑

### 6. 情绪基调（早期单点定调）

**主基调：哥们儿平视**
不是老师在上面讲课，是「一个过来人跟你唠嗑，告诉你他是怎么干的」。
横版+打电话+书桌+破第四面墙——这个形式天然匹配平视感。

**辅基调：偶尔犀利**
说到行业乱象、割韭菜手法时，可以收一收平视，来一句犀利的判断。
比如：「知识付费就是一个造梦的生意，只要你认可了，他就收你钱，落地？很难。」

**参考博主**：
- 安先生（横版打电话+平视+内容深度）
- 程前（哥们儿聊天感+行业洞察）

**配套元素**：
- 音乐：不需要BGM，纯对话感
- 光线：暖色调，书桌台灯感
- 语速：正常偏快，有脑子转得快的感觉

### 7. 思维习惯（MBTI对照）

**推测**：INTJ（策略型思考者）
- 善于系统化思考（知识管理系统、方法论体系）
- 关注底层逻辑而非表象
- 对效率有执念（AI工具重度使用）
- ⏳ 需实测确认

**对应内容形态**：
- 主：讲知识（抽象逻辑）—— 底层方法论、趋势判断
- 辅：讲故事（活在过去）—— 自己的创业经历、学员案例
- 慎用：匠人匠心（不适合，他做的不是手艺活）
- 慎用：生活日常（离变现太远，不是他当下的需求）
