# 02-外挂大脑 · 思维导图（柯哥演讲版）

> 对着这个说，不用逐字念。录音发我，我学你的语气。

---

## 开场（0-15秒）｜情绪：憋着，然后释放

```
脑子满 → 事情乱 → 想找找不到 → 一年白干
              ↓
        我做了8年新媒体
        啥都试过——记笔记、建文件夹
        全他妈没用
              ↓
        直到搭了这个东西
        28天、300小时、2000块
              ↓
        今天全公开
```

> 🎬 这里观众停不停？看"全他妈没用"说得够不够真。

---

## 展示大脑（15-30秒）｜情绪：摊开来给你看

```
我的大脑里现在有啥？
    ├── 行业经验
    ├── 日常灵感
    ├── 客户资料
    ├── 学习笔记
    └── 所有判断 + 失误

全在电脑里，文字形式

它能干嘛？
    ├── 提醒我缺点
    ├── 帮我判断选题
    ├── 给我方向
    └── 后台24小时在跑

你不需要懂技术
我已经跑通了
一步一步带着你做
```

> 🎬 这段要干净利落，不要啰嗦。观众不需要现在全懂，知道有这个东西就行。

---

## 工具一：Obsidian（30-50秒）｜情绪：你看，就这么简单

```
第一个——文本管理器，Obsidian

你看我怎么用 ↓

写稿写到一半 → 想到一个知识点
按两下键盘 → 连上了
不用翻文件夹，不用搜

跟人脑一样
想到什么，立刻调出来

事情本来就连着的
学习和工作是通的
这客户跟那项目是通的
这工具帮你接线
```

> 🎬 "按两下键盘"——手比划按的动作。这条要快、轻、像"这没什么"。

---

## 工具二：AI大脑（50-75秒）｜情绪：吐槽→反转→爽

```
第二个——装个大脑，DeepSeek + Claude

你看我怎么用 ↓

文件全扔进去 → 人判断，AI搭架子
删不删、改不改、发不发 —— 我定
它只负责串

说白了——以前你只能跟人协作

你那个猪队友 ↓
    开会不带脑子
    活儿全推给你
    出事了：你怎么没跟我说？
    但你没办法
    忍了

现在不一样 ↓
    跟你协作的 → 世界顶级大模型
    价值过亿的大脑在陪你

↑ 这句要慢。给观众一秒感受。
```

> 🎬 "开会不带脑子"到"忍了"——用你自己的吐槽语感说，不要念。"这感觉超爽"——真的笑一下。

---

## 工具三：手脚（75-95秒）｜情绪：演示，轻松

```
第三个——装个手脚，OpenClaw + Hanako

你看我怎么用 ↓

现在80%的活，用嘴干

演示（越随意越好）：
    "帮我整理昨天灵感，列一下今天事"
    "帮我把这项目做汇报，生成PDF"
    录着录着突然想到——
        长得丑可以做知识博主
        没人看你脸，都在听你讲

微信说句话 → 电脑上多出文件

iCloud一开 → 手机电脑同步
微信消息自动存 → 随时翻随时改
```

> 🎬 "长得丑可以做知识博主"——要像真的突然想到，不要像准备好的梗。越随意越好。

---

## 收尾（95-110秒）｜情绪：拉起来 → 落下去 → 真心话

```
有了外挂大脑 ↓
    知识、判断、经验在后台自己进化
    你睡觉、你玩 → 另一个你在努力
    每一天都在蜕变

（停一口气）

但是—— ↓

最后说句真心话 ↓

如果你想一键干活、一键生成
什么心都不想操——

别用AI了。
```

> 🎬 "但是——"停一拍。"别用AI了"——不是骂人，是认真。像朋友跟你说实话。
