
## 二、第一步：把你的知识存进Obsidian

### 2.1 安装Obsidian（5分钟）

1. 打开 https://obsidian.md
2. 下载对应你电脑的版本（Windows/Mac都免费）
3. 安装、打开

### 2.2 创建你的第一个"知识仓库"

打开Obsidian后，点"Create new vault"：

- **Vault name**：叫"我的外挂大脑"（名字随便）
- **Location**：选一个你找得到的位置，建议放桌面
- 点"Create"

进去之后你会看到一片空白——正常，你的知识还没往里装。

### 2.3 认识两个核心概念

Obsidian跟Word不一样。它只有两个东西你需要懂：

**① Markdown文件**
就是你写的每一篇笔记。文件后缀是`.md`。

你在里面写字就行，不用管格式。但如果你想排版，记住三个最常用的：

```
# 这是一级标题
## 这是二级标题
**这是加粗**
```

**② 双向链接**
这是Obsidian最值钱的东西。

你在A笔记里写 `[[B笔记的名字]]`，两条笔记就连上了。

比如你在"客户沟通技巧"这篇笔记里写：
```
跟客户沟通的时候，先用[[客户定位三步法]]判断他卡在哪。
```

以后你打开"客户定位三步法"这篇笔记，右边会自动显示"有哪些笔记链接到了这里"——你就能看到"客户沟通技巧"跟它有关系。

**这很重要：你存的不是一堆文件，你存的是知识之间的一张网。**

### 2.4 照这个结构建你的文件夹

在Obsidian左侧，新建这些文件夹：

```
📁 我的外挂大脑/
├── 📁 01_我的方法论/        ← 你自己的经验、套路、判断
├── 📁 02_行业知识/           ← 你服务行业的专业知识
├── 📁 03_客户资料/           ← 每个客户的背景、需求、进展
├── 📁 04_素材库/             ← 金句、案例、数据、截图
├── 📁 05_学习笔记/           ← 课程、文章、视频学完的笔记
├── 📁 06_灵感随手记/         ← 日常冒出来的想法，先扔这里
└── 📁 07_模板/               ← 常用文档模板（后面会给）
```

**建文件夹的方法**：在左侧空白处右键 → New folder → 输入名字。

### 2.5 先写你的第一篇笔记

打开 `01_我的方法论/`，新建一篇笔记，叫"我的工作心法"。

把你脑子里最重要的几条做事原则写下来。没有固定格式，想到什么写什么。比如：

```markdown
# 我的工作心法

## 做内容
- 先想清楚给谁看，再想写什么
- 开头三秒决定生死，不要自我介绍
- 一条视频只讲一件事

## 跟客户沟通
- 先听他说完，别急着给方案
- 问他"你觉得问题出在哪"，比告诉他问题在哪有用
- 报价之前先让他看到你的判断力

## 做判断
- 客户说的"优势"多半是包装的
- 真正的差异化藏在他们觉得"理所当然"的地方
- 不确定的时候，不做比做错强
```

**重点是：别追求完美。先写下来。以后随时改。**

### 2.6 存你的第一条行业知识

打开 `02_行业知识/`，针对你最熟悉的那个行业写一篇。

比如你做家政，就写"家政行业常见问题"：

```markdown
# 家政行业常见问题

## 客户端的痛点
- 不敢让陌生人进家
- 换了好几个阿姨都不满意
- 出了问题找不到人负责

## 阿姨端的痛点
- 客户要求越来越刁
- 中介抽成太高
- 没有稳定单量

## 我见过的坑
- 客户说"对阿姨没什么要求" = 要求最高
- 阿姨说"什么活都能干" = 可能什么都干不好
- 中介只撮合不负责 = 行业最大的问题
```

**写完这一篇，你就已经比90%的人强了。因为你的知识不在脑子里——在文件里。AI能读了。**

## 三、第二步：让AI连上你的知识

这部分需要一点技术操作，但不难。跟着做，半小时搞定。

### 3.1 安装Node.js（OpenClaw的运行环境）

1. 打开 https://nodejs.org
2. 下载左边的"LTS"版本（稳定版）
3. 安装——一路点"下一步"就行

装完之后验证一下。打开你电脑的终端：

- **Mac**：按 `Command + 空格`，搜"终端"，打开
- **Windows**：按 `Win + R`，输入 `cmd`，回车

在终端里输入：

```bash
node -v
```

如果出现一行数字（比如 v20.x.x），说明装好了。

### 3.2 安装OpenClaw

在终端里输入这一行：

```bash
npm install -g openclaw
```

等它跑完。

验证安装：

```bash
openclaw --version
```

如果出现版本号，装好了。

### 3.3 初始化OpenClaw

```bash
openclaw init
```

这一步会创建OpenClaw的工作目录和默认配置文件。

### 3.4 配置OpenClaw连接你的Obsidian知识库

找到OpenClaw的配置文件。一般在：

- **Mac**：`~/.openclaw/config.yaml`（或者 `config.json`）
- **Windows**：`C:\Users\你的用户名\.openclaw\config.yaml`

用任意文本编辑器打开它。

**关键配置**：让OpenClaw知道你的知识库在哪。找到或添加 `workspace` 相关的配置，指向你的Obsidian仓库路径。

比如你的Obsidian仓库在桌面：
- **Mac**：`/Users/你的用户名/Desktop/我的外挂大脑`
- **Windows**：`C:\Users\你的用户名\Desktop\我的外挂大脑`

> ⚠️ **如果这一步卡住了**——OpenClaw的配置项可能随版本变化。
> 直接去官方文档查最新配置方式：https://docs.openclaw.ai
> 
> 或者直接找我（柯建军），我帮你配。这也是我服务的一部分。

### 3.5 连接微信

在OpenClaw配置中添加微信通道。核心步骤：

1. 在配置文件中启用微信通道
2. 扫码登录（跟你登微信网页版一样）
3. 配置完成

> ⚠️ 微信通道的配置较复杂，且可能随微信政策变化。
> **建议**：先加我微信，我发你最新的配置教程。或者我直接帮你配好。
> 
> 这一步是我私域导流的关键——你卡住了，自然会来找我。

### 3.6 测试：跟你的AI说第一句话

配好之后，在微信上给OpenClaw发一条消息：

```
帮我找一下我的工作心法里关于"做内容"的部分。
```

如果它回复了你刚写的那几条，恭喜——你的外挂大脑跑通了。

## 四、第三步：建立你的工作流

系统跑通了，现在建立日常使用习惯。

### 4.1 你的工作流长这样

```
早上，你接到客户需求
       ↓
你在微信上说话：
"帮我调出XX客户的资料，再翻一下家政行业的常见问题，
 帮我写一个针对这个客户的短视频选题方向"
       ↓
AI翻你的Obsidian → 找到客户资料 + 行业知识
       ↓
3分钟，给你一版选题建议
       ↓
你看一遍
- 方向对 → 让AI继续写文案
- 方向不对 → 告诉它哪里不对，它重来
       ↓
文案出稿 → 你判断 → 发给客户
```

**你做的是判断。AI做的是翻文件、搭架子、组织语言。**

### 4.2 日常该往Obsidian里存什么

| 遇到了什么 | 存成什么 |
|-----------|---------|
| 搞定了一个难缠的客户 | 存进 `01_我的方法论/`，写清楚"他是怎么难缠的，你怎么搞定的" |
| 发现行业里一个普遍问题 | 存进 `02_行业知识/` |
| 来了一个新客户 | 存进 `03_客户资料/`，记下背景、需求、沟通要点 |
| 听到一句好文案 | 存进 `04_素材库/` |
| 学完一个课程 | 把你学到的东西用自己的话写进 `05_学习笔记/` |
| 突然想到一个灵感 | 随手扔进 `06_灵感随手记/`，别管格式 |

### 4.3 模板：几个常用的AI指令

直接把下面这些话复制到你的微信，改一下具体内容就能用：

**调客户资料：**
```
帮我调出[客户名字]的资料。我要他的背景、需求、目前的进度。
```

**做选题：**
```
基于[客户名字]的行业和定位，帮我出5个选题方向。每个方向给两句话说明为什么适合他。
```

**写文案：**
```
帮我写一条短视频文案。主题是[XXX]。目标受众是[XXX]。
风格要求：[口语化/专业一点/有情绪张力]
开头要0帧起手，不要自我介绍。
```

**优化已有文案：**
```
下面这段文案帮我优化一下：
[贴原文案]
要求：开头更抓人、句子更短、去AI味。
```

**复盘：**
```
帮我复盘一下上个月的工作。翻我的客户资料和工作记录，总结：
1. 搞定了哪些客户
2. 遇到了什么问题
3. 下个月应该在哪方面加强
```

### 4.4 一个重要的原则：AI搭架子，你填内容

AI写出来的东西，框架能用，但专业细节往往需要你补充。

比如AI写了一条家政文案，框架是对的。但里面说"我们提供专业保洁服务"——太泛了。

你改成："我们的阿姨进门前先换鞋套，擦完桌子用手指摸一遍——没有灰尘才算干净。"

**框架AI给，血肉你来填。这才是人机协作的正确姿势。**

## 五、常见问题

**Q：Obsidian要不要花钱？**
A：个人使用完全免费。只有你想多设备同步的时候才需要付费——但你可以用iCloud或坚果云免费同步。

**Q：我不会写代码，能搭起来吗？**
A：Obsidian零门槛。OpenClaw需要一点点终端操作——跟着上面的步骤做就能搞定。实在搞不定，找我。

**Q：我的知识太少了，存什么？**
A：从今天开始存。每次解决一个问题，就写一条。一个月后你就有几十条了。知识库不要求"全"，要求"在长"。

**Q：AI能完全替代我干活吗？**
A：不能。AI能翻文件、搭架子、组织语言。但判断"这个方向对不对"、"这个文案能不能发"、"这个客户该不该接"——只能你来。AI是外挂，你是大脑。

**Q：安全和隐私怎么办？**
A：Obsidian存在你本地电脑上，不上传任何服务器。OpenClaw调用的AI模型会读取你的文件——如果你特别在意隐私，可以用本地模型（技术门槛更高，找我聊）。
