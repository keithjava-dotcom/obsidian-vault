# 产品+故事 模板 · 炙野烧烤食材店

---

## 模板结构

```
产品：[产品名]
开头钩子：[一句话悬念/数字/冲突]
故事链：
  起点 → 为什么做这个产品
  经历 → 怎么做的/遇到了什么困难（信息密度+情绪）
  转折 → 怎么解决的/学到了什么
  结果 → 现在产品的品质怎么样
  结尾 → 正向引导·为顾客着想
```

---

## 已完成的示例

### 示例①：佳木斯拌面（第05稿）

| 环节 | 内容 |
|------|------|
| 产品 | 佳木斯拌面 |
| 开头 | "为了学个拌面，我开车1061.8公里去了佳木斯" |
| 起点 | 佳木斯拌面全国有名，凤城吃不到 |
| 经历 | 到了之后挨家吃→找到最好吃的→问老板能不能教 |
| 转折 | 能教，要花钱。"钱不是问题，要学就学最好的" |
| 结果 | 口味跟那边一样，凤城人也能吃到了 |
| 结尾 | "我替你跑过了，你只管来吃" |

### 示例②：跑全国选肉·和牛礼盒（第03稿）

| 环节 | 内容 |
|------|------|
| 产品 | 雪花牛肉/和牛 |
| 开头 | "你一个卖食材的，怎么懂这么多？" |
| 起点 | 本地肉做高端不够 |
| 经历 | 跑三省屠宰场（齐齐哈尔/山东/郑州）→ 齐齐哈尔牛肉物流出事 |
| 转折 | 十斤肉废五斤，后来有经验了 |
| 结果 | 每一块肉知道从哪来，和牛五A起 |
| 结尾 | "我不能替你吃，但我能替你先把关" |

## 模板应用清单（待补充素材）

以下产品已有素材可以套这个模板出稿，标⚠️的需要你补充信息：

| 产品 | 可用的故事点 | 结论 |
|------|-------------|------|
| ⚠️ **鸡爪** | 你说"XX学的鸡爪" | 待补充：在哪学的？什么过程？ |
| ⚠️ **凉菜** | 素材里有：谁家小菜好吃就去问、花钱学 | 可出，但具体学的是什么菜/过程需要你确认 |
| ✅ **现串串品** | 为什么不做半成品、试过很多次定配方 | 可出，素材够 |
| ✅ **排酸柜选品** | 专门选市面上最好的柜子，不是普通标准 | 可出，但偏知识性，故事性弱 |
| ⚠️ **烧烤酱料研发** | 素材有"同一串刷酱浓淡出来是两个味" | 可出，但具体研发过程需要你补充 |
| ⚠️ **XXX失败研究出来的肉品** | 你提到的这个方向 | 待补充：什么肉？失败了几次？ |

## 补充素材（你来说，我来写）

如果你想把鸡爪、凉菜、或者其他产品的故事补充进来，按以下格式给就行：

> 产品：[产品名]
> 在哪学的/怎么研发的：[过程]
> 失败了多久/几次：[细节]
> 现在什么样：[结果]

我收到后直接套模板出一条完整的标注稿。
