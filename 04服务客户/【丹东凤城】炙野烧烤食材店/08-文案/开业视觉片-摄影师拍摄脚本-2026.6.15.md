# 炙野开业视觉片 · 摄影师拍摄脚本

**⏰ 拍摄前核对清单**
- [ ] 确认11名出镜员工到位，各自熟悉一句话+一个动作
- [ ] 确认拍摄路线：前台→明档厨房→货架/肉类区→串品区→试吃区→用品区→和牛礼盒区→酒水区→海鲜/凉菜区→调料区→后厨
- [ ] 确认各区域道具到位（夹子/串/烤炉/礼盒/勺子等）
- [ ] 冰柜里要有冷气效果
- [ ] 后厨有师傅在真实干活（长镜头用）
- [ ] 全员统一着装（围裙/套袖/帽子）
- [ ] 开业优惠信息海报或字幕确认

## 【第二条：长镜头素材】

单独拍一个长镜头，准备在其他11段拍完后拍。

| 项目 | 内容 |
|------|------|
| 内容 | 后厨一位厨师从冰柜取肉→放案板→整块肉修边→切一斤肉片→整理摆盘 |
| 运镜 | 一镜到底，从厨师身后侧方缓缓推进 |
| 时长 | 约12-15秒 |
| 声音 | 无对白，后期BGM转舒缓 |
| 后期加字 | 切好摆盘那一帧弹字幕「十五年如一日」 |
| 关键 | **不要稳定器运镜**——保留一点呼吸感，像"记录片"不是广告片 |
| 关键2 | 厨师全程自然做自己的事，不抬头不看镜头，别演 |

## 【拍摄提醒】

1. **每人3-5条备选**——念错或者动作没卡上，再拍一次就行，不纠结
2. **每段拍之前先让员工自己说一遍**——他自己顺过一遍，录的时候更自然
3. **如果员工说太快/吞字**——提醒"慢一点，像跟隔壁桌说话"
4. **不要纠正口音**——凤城话就是这家店的识别度
5. **长镜头不用要求一次完美**——拍3-5条，留一条自然的
6. **收音**：每人说话时用领夹麦收音，后期BGM降底。长镜头不用收人声

---

## 【剪辑要点（给后期）】

1. **BGM路线**：前半段带鼓点的轻摇滚/电子（人声时降15%底）→ 长镜头转温暖吉他/钢琴 → 结尾全员亮相重新起节奏
2. **卡点铁律**：每人动作做到位的那一帧 = 0.2秒慢放 = 鼓点落下 = 切下一镜。三件事同时发生
3. **长短对比**：前45秒快节奏一人一句切 → 中段长镜头15秒不切 → 结尾又切回快闪。快-慢-快的节奏，不要从头快到尾
4. **调色**：偏暖不夸张，保持食物本色
5. **字幕**：每人说话时用字幕卡追字幕（同步显示他说的那句话），放在画面下方
6. **如果货架没摆满**：拍近景特写，避开稀疏全景
