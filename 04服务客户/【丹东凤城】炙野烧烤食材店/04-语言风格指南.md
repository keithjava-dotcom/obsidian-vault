# 04-语言风格指南 · 小舅子（炙野烧烤食材店出镜人）

**v1.2** · 2026-06-14（补充：小舅子深度访谈——跑全国选肉、失败经历、研发精神、产品哲学）

---

## 一、核心人设标签

> **"我就站在这店里，东西好就是好，东西不好我不卖。我就是爱研究这行。"**

- 身份：🔥 **从事烤肉行业15年** — 不是半路出家的店员，是内行
- 店铺定位：🔥 **凤城第一家烧烤食材店**（开创了这种一站式烧烤食材模式）
- 语气：哥们儿聊天，不是销售培训
- 态度：对产品有自信，不吹不虚
- 底色："爱研究、爱钻研"的匠人，不是"会说话"的生意人
- 背景：
  - 跑过全国屠宰场（齐齐哈尔/山东/郑州），亲自选肉
  - 因为物流问题废过十斤齐齐哈尔雪花牛肉（成本50+/斤，十斤废五斤）
  - 开车去佳木斯挨家吃拌面，花钱学做回来
  - 后厨有团队一起研发

**人设一句话**：这行我干15年了，全国的肉我都跑过，我研究的东西就是比别人的好。

## 二、说话节奏

### 1. 三段式递进（核心句式·高频出现）
先说现象/背景 → 再说问题/痛点 → 最后给方案

> "近两年流行户外烤串和烤肉。有些人喜欢烤肉，有些人喜欢烤串。但烤串目前存在一个弊端：很多人不擅长烤制，有时会烤糊，或者不会调味。我们这里是怎么做的呢？我们提供的是原味串品，您购买后，我们家有加工区，适合刷酱的会为您刷酱，适合撒料的会为您撒料。您回家后直接上炉烤制即可，无需二次加工。"

### 2. 爱用"反问连接"做过渡
"我们这里是怎么做的呢？"
"剩下这面区域是什么意思呢？"
——作用是自然带出下一段，不是硬转

### 3. 先说结论，再展开支撑
> "这个区域就是散装丸子，咱们家的丸子全是大品牌，全是安井的。因为安井这个牌子，在市场上已经多少年了，家喻户晓。这个品牌也是上市公司，所以值得信赖。"

### 4. 列举式表达
> "比如上脑、肋条、外脊、胸口"
> "从牛头到牛尾，哪个部位都有"
——配合镜头扫过实物，比干说"我们品种很全"有效

## 三、高频用词

### 身份词
| 用词 | 替代 | 说明 |
|------|------|------|
| 咱们家 | 我们店 / 我们家店 | **核心身份词**，拉近距离，有归属感 |
| 咱 | 我 / 我们 | "咱就一直选择安井" |
| 大家 | 顾客 / 消费者 | "大家都可以看见" |

### 口语衔接词
- "完了" / "然后" — 自然过渡，不必全删
- "像" — "像这个柜"、"像这种"
- "对" — 确认反馈

### 数据词（小舅子习惯用具体数字）
- "一百多个" / "五六十个"
- "两三块钱" / "二十块"
- "不到一分钟"
- "三天"
- "1000多平" ⚠️ 新数据

### 态度词
- "好的" / "最好的" — 选品标准
- "特别" — "特别好"、"特别卫生"、"特别简单"
- "简单、方便" — 高频收尾词
- "都有" / "全有" / "应有尽有" — 强调齐全

### 专业词（小舅子知道这些词，能用自然）
- 原切、纯原切
- 排酸、锁鲜、冷鲜
- 雪花牛肉、安格斯牛肉、和牛
- 五A级别

## 四、慎用/不用

| 禁用 | 原因 |
|------|------|
| "家人们" | 太抖音培训腔，不是他的说话方式 |
| "家人们谁懂啊" | 同理 |
| "首先.其次.再次" | 太书面，他不是这个节奏 |
| "没错.你没有听错" | 人工感太重 |
| 形容词堆砌（超级、极致、无敌） | 他的风格是"好的"就够了 |
| 模仿网红语气 | 小舅子自己说才真，一模仿就假 |

## 五、深度人设补充（来自补充访谈 🔥）

### 1. 产品哲学三要素
小舅子做产品的底层逻辑：
1. **选材** — 第一关，肉从哪里来决定了品质起点
2. **品相** — "眼睛是第一关"，出型要好看，摆要好看
3. **口味** — 适合大众，不能太个人化

### 2. 讲失败经历的自然状态
当被问到"研究过程中有失败过吗"，他直接讲了对齐齐哈尔牛肉事件，非常自然、不回避。
> "这一堆肉就等于白给了"
这是天然的真实感，这种内容最值钱，拍摄时要引导但不是导演他怎么说。

### 3. 讲学习经历的骄傲
当他说"开车去佳木斯""挨家吃""既然学肯定学最好的"的时候，语气里带自豪。
这条线是天然的"匠心人设"——不需要编，他有真料。

### 4. 匠人身份自洽
- "我是比较爱研究，我喜欢这个行业"
- "一个人再爱好一个东西，就是特别喜欢去研究、去钻研、去琢磨"
- 有后厨团队，有师傅一起研发
→ 他不是一个人埋头干，是有团队有体系的

### 5. 差异化意识
- "过去的传统烤肉模式已经过时了"
- 新店全部创新，做出差异化
- 不用本地牛肉，从全国找最好的
→ 他不是"我也干这行"，是"我要干得跟别人不一样"

## 六、说话方式要点

### ✅ 要保持的
1. **面向镜头像跟人聊天** — 想象对面站着一个凤城老乡，说给他听就行
2. **边说边指** — 指着实物说："你看这个，安井的"，配合镜头走
3. **用数字代替形容词** — "不到一分钟" > "很快"，"二十块" > "很便宜"
4. **先承认问题，再给方案** — "很多人不会烤，那我们怎么解决呢..."
5. **自然停顿** — 让话有节奏感，不是背稿
6. 🔥 **讲失败可以自然讲** — 齐齐哈尔牛肉事件他自己就能讲顺，不需要脚本
7. 🔥 **讲学习经历带自豪感** — "开车去佳木斯"这条线天然有情绪

### ❌ 要避免的
1. **不背稿** — 背了就变销售，不像真人了
2. **不硬塞术语** — 小舅子知道排酸，但对着顾客说"保鲜"也行，看谁说
3. **不刻意声音大/语速快** — 节奏跟着内容走，不是表演
4. **不假装热情** — 真情比热情真——他认真讲一个东西的样子反而更可信
5. **不让他说假励志** — 他的真实经历（废肉/跑全国/花钱学）已经够动人，不需要编"我从不放弃"这类套话

## 七、提问方式 ✅ 柯哥确认：开放式为主

小舅子表达逻辑非常好，可以用**开放式问题**为主：

> ✅ "你给大伙讲讲，你干这行多久了？"
> ✅ "咱们这个店跟别人家有什么不一样？"
> ✅ "这个和牛礼盒为什么是你们主推的？"
> ✅ "你跑过哪些地方选肉？"
> ✅ "听说你为了学个拌面开车去佳木斯？"

**什么时候用开关式**：
- 当需要锁一个具体话题收住的时候（"那烤炉多少钱，你给大家说说"）
- 但整体以开放式为主——他表达逻辑好，让他自己带节奏

**红爵酒水**：
> "这红爵跟雪花有啥不一样啊？"
> ——柯哥在旁边像随口问，让他自然答

## 八、拍摄协作

1. **先给话题，不给逐字稿** — 告诉他"今天拍一圈，你边走边介绍就行"
2. **每条拍之前，先讲一遍** — 让他自己说一遍，自然了再正式录
3. **柯哥在旁边接话** — "那烤炉多少钱？""这个为什么选安井？" — 用小舅子回答的最自然版本
4. **如果忘词了/说复杂了** — 不用停，让他重新说一遍就行，剪辑能剪

## 十、出镜人类型判定 ✅ 柯哥确认

- **类型**：表达逻辑好的深度钻研型（非常深度且爱钻研的人）
- **证据**：
  - 讲失败经历（齐齐哈尔牛肉：有时间线/数据/前因后果/情绪落脚）
  - 讲学习经历（佳木斯拌面：开车去/挨家吃/花钱学/学最好的）
  - 讲产品哲学（选材→品相→口味，三层逻辑自洽）
- **策略**：**以开放式问题为主**，让他在柯哥引导下自己带节奏。只在需要收住话题时用开关式
