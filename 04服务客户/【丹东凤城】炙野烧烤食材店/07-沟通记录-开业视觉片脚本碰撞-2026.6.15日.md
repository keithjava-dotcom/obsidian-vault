# 07-沟通记录-开业视觉片脚本碰撞-2026.6.15日.md

## 背景

柯建军与小龙针对炙野烧烤食材店开业预热视频进行脚本路径碰撞。此前（6/14）已产出第01-第09稿传统talk-head路线（小舅子逐区介绍），6/15柯建军实勘后提出全新视觉呈现方案。

## 核心碰撞过程

### Round 1 · 新方向定调（10:07）

柯建军提出全新视觉思路：
- 用运镜+服务员手势，展示店面环境及菜品
- 快剪+曲线变速，员工不说话，用手势代出区域
- 用一个长镜头展示一个动作全过程
- **"用视觉语言重构门店的空间秩序，镜头就是那个指挥棒"**

小龙产出**第10稿**初始版——纯视觉+零对白的55-65秒分镜头脚本。

### Round 2 · 每人一句话（10:12-10:18）

柯建军反馈：每个区域放一个服务员，**每人说一句话**，体现东西好和服务品质。
小龙产出11句各区域口播。柯建军进一步要求：

**三条要求**：
1. 押韵，朗朗上口
2. 数字、覆盖、痛点、承诺、服务——全融进去
3. 保证人话，不喊口号

### Round 3 · 柯建军亲自改稿（10:32）

柯建军拿出完整版11句口播，全部重写，押韵更强、东北话骨头更硬。
同时指出关键问题：**"别报幕"**——每人说完最后半句的同时配一个动作。

具体动作设计：
| 员工 | 动作 |
|------|------|
| 前台 | 伸手引导方向 |
| 明档厨房 | 夹子夹起肉展示纹理 |
| 货架区 | 手掌扫过货架 |
| 串品区 | 拿起一把串朝镜头一抬 |
| 试吃区 | 把串递向镜头 |
| 用品区 | 拎起炉子晃一下 |
| 和牛礼盒区 | 双手扶礼盒、轻轻一拍 |
| 酒水区 | 拉开冰柜门，冷气冒出 |
| 凉菜区 | 勺子一敲盆沿 |
| 调料区 | 舀起一勺料放下 |
| 后厨 | **拉上门，镜头被关在外面** |

### Round 4 · 双版本输出（10:33）

柯建军要求输出两份：
- **① 沟通协作过程**（本文档）
- **② 给摄影师看的脚本**（同步生成）

## 关键决策记录

| # | 决策 | 影响 |
|---|------|------|
| 1 | 从talk-head改为视觉片+每人一句话 | 片长从8问答压缩为70-90秒 |
| 2 | 押韵口播 | 便于记忆和传播，更"短视频友好" |
| 3 | 边念边动作，不报幕 | 动作帧做句号，鼓点下切，节奏紧凑 |
| 4 | 后厨拉门收尾 | 全片最后一个动作是「关门」，结束感强 |
| 5 | 保留长镜头段落 | 快剪之后的"慢"才有力量 |

## 最终结构

- **开场钩子（0-5s）**：炭火星→牛肉纹理→套袖→招牌，鼓点进门
- **空间重构（5-49s）**：11个岗位，每人一句话+一个动作，卡点切
- **长镜头（49-64s）**：后厨一人完整切肉，一镜到底
- **收场（64-75s）**：全员快闪→一排亮相→优惠信息→位置
