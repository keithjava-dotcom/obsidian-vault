### 敌人列表自检

定敌人，就是定边界。说清楚反对谁，才对的人知道你在为谁说话：

1. **反对**：把保险当纯理财产品卖，只讲收益不讲功能 → 哲学版：**"把人生规划简化成数字比较的功利主义"**
2. **反对**：利用老人对养老的焦虑制造恐惧，然后推销产品 → 哲学版：**"以恐惧为杠杆、以成交为目的的恐吓式营销"**
3. **反对**：对客户的需求不闻不问，只推自己佣金最高的产品 → 哲学版：**"把客户当业绩数字、不把客户当人的交易思维"**
4. **反对**：浮夸虚假宣传，明明做不到硬说能做到 → 哲学版：**"用过度承诺透支行业信任的短视主义"**
5. **绝不服务**：只追求收益最大化、不关心养老品质和传承安排的纯理财型客户——不是目标用户

### 6.1 人设标签

**身份标签**（真实可验证，最多4个）：
1. 泰康人寿高级理财经理
2. 养老社区规划顾问

**性格标签**（来自真实表达，最多3个）：
1. 理性克制——不煽情、不浮夸、有事说事
2. 真诚坦率——不会的就说不会，回去问了再告诉你
3. 节奏慢但稳——不求快，求每一步走扎实

**价值标签**（对用户的利益，最多3个）：
1. 帮你把钱安排得明明白白——养老+传承一步到位
2. 不跟你绕弯子——好的坏的都讲清楚
3. 长期在你身边——不是卖完就走的销售

### 突出 ≠ 社会地位

**不是**：学历（日本留学）、证书数量、从业年限、公司背书

**而是**：
- **审美**：日企严谨 + 小红书精致感 = 不张扬但有质感的视觉风格
- **角度**："保险不只是理财，是人生规划"——把保险从数字拉回人本身
- **故事**：第一单9个月才开、1.5年空窗期重新出发、打败5家同业——这些不是"惨"，是"韧"
- **软肋**：才做了一年多，还有很多在学——坦承不装懂，反而最可信
- **坚定立场**：反对功利主义保险销售，坚持"做人比做事重要"——这是筛子，把对的人筛进来

### 6.2 阶段性释放节奏

- **早期（0-3个月）单点突破打的标签**：真诚、专业、不功利 —— 用故事+科普反复钉这三个词
- **中期（3-6个月）释放的标签**：养老规划专家、财富传承顾问 —— 在信任基础上加深专业深度
- **后期（6-12个月）立体化方向**：行业洞察者、生活方式倡导者 —— 不只讲产品，讲养老是一种生活方式的选择
- ⚠️ 警告：不要上来就"啥都有"——又是专家、又是生活方式博主、又是行业评论员。第一印象只钉三个词：**真诚、专业、不功利**。

| （固定项）客户不够的焦虑 | 换参照系：不看播放看私域反馈。一个主动找你咨询的客户，比1000个点赞值钱 |
| （固定项）同行评价焦虑 | 大连分公司1000人几乎没人做内容输出，你是第一个吃螃蟹的。同行说啥都不重要，客户反馈才重要 |
| 内容枯竭 | 前3个月靠个人经历+行业知识足够。3个月后需要系统化选题机制：评论区捕捉+客户真实问题转化+行业动态跟进 |
| 镜头表达卡住 | 前100条当练习。第一条可能录10遍，第十条可能3遍。所有人都是这么过来的，不急 |
| 追求完美不敢发 | 记住：发了60分的视频，下一条可以做到70分。不发永远是0 |
| 合规风险 | 保险行业内容有审核要求。涉及产品细节和收益承诺的内容，提前跟公司确认 |

## 十三、做了你会得到什么

**1个月**：
- 发布6-8条视频
- 找到镜头前的感觉（从不自然到能说完整句子）
- 私域客户开始主动反馈"看了你的视频"

**3个月**：
- 发布30-40条视频，内容和风格基本定型
- 私域客户中有3-5个深度互动（主动约聊、咨询问题）
- 视频号粉丝量不重要，但评论区开始出现精准提问

**6个月**：
- 建立"大连高净值养老规划"的识别度
- 私域客户中至少1-2个进入成交洽谈
- 自己能独立完成从选题到拍摄到剪辑的全流程
