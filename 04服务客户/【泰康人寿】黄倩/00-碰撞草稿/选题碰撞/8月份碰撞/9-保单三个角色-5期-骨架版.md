# 保单三个角色与第二投保人 · 5期短视频文稿（骨架版）

> 标题保留。改了三样：①删所有"说白了"和"关注我" ②第5期砍掉大段回顾和导流 ③第1期开头从反常识进（不是科普腔）。

## 第1期：保单上的三个人，到底谁说了算

### 🎬 封面标题建议
- 封面标题：你以为投保人说了算？
- 封面文字：保单三个角色
- 平台标题：保单上的三个人，到底谁说了算

### 🎭 讲戏卡
- **对谁说**：买了保险但从来没仔细看过保单角色的人。他以为"我交钱我就是老大"——不是的
- **为什么今天非说**：三个角色谁说了算，不是科普——是"你填错一个名字，将来全家抢这张单子"
- **态度**：像跟朋友说一个他肯定不知道的规则。不卖课，不说"今天教你"——只是告诉你"有个事你可能搞错了"

### 🧭 结构走线

```
【你以为你交钱就是老大？换受益人还得别人点头⭐】
注：不介绍三个角色。先砸反常识。"投保人说了算"是所有人默认的——打破它观众才停下来。
例："你以为投保人交保费就是老大？你买的保险，换个受益人——还得别人点头。"

【投保人就是房东，被保人就是房子】
注：两个比喻十个字。不展开"股东/核心资产/遗嘱继承人"那种三段论——黄倩不会那么说。
例："投保人是房东——想卖就卖，想抵押就抵押。被保人是房子——所有事都围着它转。"

【受益人等那一天——但你不能偷偷写自己⭐】
注：反常识来了。最关键的钩子。"你给老婆买保险，受益人写自己——得她点头。"
例："受益人是等那一天来领钱的人。但有一点很多人不知道：你指定谁、改成谁，得被保人同意。"

【一个人把三个角色全占了？行——但有坑】
注：常见问题快答。不展开长篇，两个风险点：①身故受益人写自己=没指定 ②受益人换过结婚离婚要更新
例："能不能三个角色全占？可以。但注意——身故受益人写自己，等于没指定，走了之后走法定继承。"

【下一期：保单里的钱归谁——不是你以为的那三笔】
注：用具体信息吊胃口。
例："下一期我告诉你保单里到底有几笔钱——现金价值、生存金、身故金。每一笔归的人不一样。你可能搞错了。"
```

### ⚠️ 注意事项
- 第1期不要用"今天我用最简单的方式给你讲"——任何客户都不会对朋友这么说话
- 三个角色的权利用具体画面：房东=卖房抵押，不要讲故事说明
- 结尾不要"关注我"——用具体信息吊

### 📝 口播文案示例

你买了一份保险。保单上有三个名字：投保人、被保人、受益人。

你以为投保人交钱就是老大？不对。你买的保险，换个受益人——还得别人点头。

先说投保人。投保人是出钱的人，跟保险公司签合同的人。退保、拿现金价值、保单贷款、变更受益人——这些权利都是投保人的。好比房东：房子是你的，想卖就卖，想抵押就抵押。

再说被保人。被保人是保险保的那个人。如果这份保单有生存金、年金，领钱的是被保人。重疾理赔、医疗理赔，拿钱的也是被保人。被保人是房子的核心——所有事围着它转。

最后说受益人。受益人是等那一天来了领钱的人。身故保险金直接给受益人，不走遗产继承。但有一点很多人不知道：投保人指定和变更受益人，必须经过被保人同意。你给老婆买保险，想把受益人写自己——得她点头。

这三个角色能不能一个人全占了？可以。自己买、保自己、受益人也写自己。但注意——身故受益人如果写的是自己，走的时候受益人已经不在了，相当于没有指定受益人，身故保险金走法定继承，全家来分。所以身故受益人一般写别人。

还有个常见的事：受益人写了就一劳永逸？不是。结婚时受益人写的父母，有了孩子想改成孩子——去保险公司书面通知就行。离婚了呢？没改的话，理赔金还是打给前妻。

下一期我告诉你保单里到底有几笔钱——现金价值、生存金、身故金。每一笔归的人不一样。你可能一直搞错了。

## 第2期：保单里的钱，到底归谁

### 🎬 封面标题建议
- 封面标题：你以为给孩子买的保险，儿媳妇也能分
- 封面文字：保单里的三笔钱
- 平台标题：保单里的钱，到底归谁

### 🎭 讲戏卡
- **对谁说**：买了保险但搞不清楚里面到底有几笔钱的人。他以为"都是给家人的"——不是，现金价值是你的，法院能追
- **为什么今天非说**：现金价值能被法院执行、生存金可能变夫妻共同财产——这两个坑太平常了，不讲没人知道
- **态度**：不是讲课文。是告诉你"你可能踩的两个坑"，然后三笔钱各归谁自然就清楚了

### 🧭 结构走线

```
【上期说了三个人谁说了算——这期说钱归谁】

【现金价值是你的，法院也能追⭐】
注：不铺垫。直接说第一笔钱。用画面——"你欠了钱，法院能划你保单的现金价值"。
例："现金价值就是你退保能拿回来的钱。归投保人。你欠了钱，法院能追。"

【生存金归被保人——儿媳妇也有份⭐】
注：这才是扎人的。不讲"年金归被保人"这个概念，讲一个场景——爸爸给儿子买年金，儿子结婚了，离婚时儿媳妇来分。
例："爸爸给儿子买年金险，儿子结婚后年年领钱。后来离婚了——法院说：这笔钱是夫妻共同财产，儿媳有份。"

【身故保险金，绕过一切直接给】
注：最后一笔最特殊。不展开太多——"指定了受益人，这笔钱不经遗产、不经债务，直接给。"
例："身故保险金最特殊。指定了受益人——这笔钱不经遗产、不经债务，直接给。没指定——走法定继承，全家来分。"

【下一期：投保人突然走了，保单会怎样】
注：留一个最让人心慌的问题。
例："三笔钱知道了。下一期讲一个更急的问题——如果投保人突然走了，这份保单怎么办？现金价值变遗产，全家都得来签字。"
```

### ⚠️ 注意事项
- "儿媳妇也有份"这个说法要轻——不是吓人，是陈述事实
- 现金价值被追那个画面别展开太多——点一句够

### 📝 口播文案示例

上一期讲了保单上三个人谁说了算。这期说钱。

保单里的钱分三种，归属不一样。很多人买了好几年搞不清楚——等到要用的时候才发现跟自己想的不一样。

第一种：现金价值。就是你退保的时候保险公司退给你的钱。归投保人。谁交钱是谁的。

注意一个事：现金价值是投保人的财产——你在外面有债务，法院可以执行保单的现金价值。你的钱，债主能追。

第二种：生存金、年金、重疾理赔金。归被保人。

我给你讲一个场景。爸爸给儿子买年金险，爸爸是投保人，儿子是被保人。儿子结婚后年年领年金。后来离婚了——这笔年金算谁的？如果爸爸没有提前做约定，法院可能认定这是夫妻共同财产，儿媳也有份。所以很多做规划的人会在保单架构上动心思——让爸爸做投保人，同时通过赠与协议明确：这笔钱只给儿子一个人。

第三种：身故保险金。归受益人。

这笔钱最特殊。指定了受益人——身故金直接给，不走遗产继承，不还债，不跟其他继承人分。没指定受益人——走法定继承，所有第一顺序继承人平分，还要先还债。

下一期讲一个更急的问题：如果投保人突然走了，这份保单怎么办？现金价值变遗产，全家都得来签字。缺一个都不行。

## 第3期：投保人不在了，保单怎么办

### 🎬 封面标题建议
- 封面标题：你不在了，保单变成全家的战场
- 封面文字：保单继承 · 真实案例
- 平台标题：投保人不在了，保单怎么办

### 🎭 讲戏卡
- **对谁说**：自己当投保人、给家人买保险的人。他从没想过"万一我走了"这个场景
- **为什么今天非说**：老王案例是黄倩自己的客户——前妻的孩子也得分、现任妻子被卡住，这个画面够猛
- **态度**：不是吓人，是提醒。语气像讲一个自己见过的真事——"你知道谁能成为新投保人吗？全部法定继承人都得来签字。"

### 🧭 结构走线

```
【上期说了三笔钱——今天说投保人走了之后】

【现金价值变遗产⭐】
注：一句话把问题钉死。不铺垫。
例："投保人不在了——保单的现金价值变成投保人的遗产。所有第一顺序继承人都有份。"

【前妻的孩子也得来签字⭐】
注：全期峰值。讲老王。姓都不要——"有一个人"。画面是两个不往来的家人被要求坐到一张桌上签字。
例："老王给妻子买了保险，自己是投保人。他之前有过一段婚姻，和前妻有一个孩子。他走之后妻子去改投保人——保险公司说：所有法定继承人都得来签字。前妻的孩子也得来。人家凭什么配合你？"

【保费没交完——两年停缴，保单被强制解除】
注：加一层时间压力。不是"提醒你注意"，是一个更紧迫的画面——"你想保都保不住"。
例："还有时间问题。保费没交完，没人继续交——超过两年，保单被强制解除。现金价值直接变遗产来分。想保都保不住。"

【下一期：怎么提前解决——第二投保人】
注：不给解决方案不行。但这个悬念要留到下一期。黄倩的习惯不是卖关子——是直接告诉你"有办法，下期说"。
例："有办法提前解决。下一期讲第二投保人——你指定好接班人，不用等人来签字。"
```

### ⚠️ 注意事项
- 老王案例不带情绪——陈述事实本身就够猛。"人家凭什么配合？"是反问，不是指责
- "你想保都保不住"这句要让观众感到急——不是威胁，是提醒

### 📝 口播文案示例

上一期说了保单里三笔钱各归谁。今天说一个更急的：如果投保人突然不在了，这份保单怎么办。

投保人不在了——保单的现金价值变成投保人的遗产。所有第一顺序继承人都有份。想变更一个新的投保人让保单继续有效？可以。但需要全部法定继承人都到场——都同意、都签字放弃——指定其中一个人成为新投保人。

我给你讲一个事。

有一个人给妻子买了保险，自己是投保人。他之前还有过一段婚姻，和前妻有一个孩子。他走之后，妻子去保险公司想把投保人改成自己——保险公司一查：全部法定继承人都得来签字。前妻的孩子也得来。人家凭什么配合你？跟你不来往的人——你让人家跑来给你签字？缺一个人都不行。

还有时间问题。保费没交完，没人继续交——超过两年不交，保单被强制解除。现金价值直接变遗产来分割。你想保都保不住了。

所以买保险的时候，一定想清楚一个问题：如果有一天你不在了，这份保单能不能顺利地交到你想交的人手里。

有办法提前解决。下一期讲第二投保人——提前指定好接班人，到时候不用等人来签字。

## 第4期：第二投保人是什么，为什么一定要设

### 🎬 封面标题建议
- 封面标题：你的保单有个选项从来没勾过
- 封面文字：第二投保人
- 平台标题：第二投保人是什么，为什么一定要设

### 🎭 讲戏卡
- **对谁说**：上一期被老王的案例吓到了的人。他想知道"我该怎么提前准备"
- **为什么今天非说**：企业主案例——七十多岁、三张保单、三个孩子、每年去非洲——这个人就是他自己的客户。比任何讲解都有力
- **态度**：不是在介绍一个功能。是告诉你"有一个按钮你从来没按过——按了之后，你家人不用打架"

### 🧭 结构走线

```
【上期说了一个办法——第二投保人】

【第二投保人就是保单的遗嘱⭐】
注：一个比喻切入。"遗嘱是管全部财产的，第二投保人是管这一张保单的。"
例："你在保险公司指定一个人——我走了之后，他直接变成新投保人。不需要其他人来签字。"

【三个关键点⭐】
注：三个点快速过——不是逐一展开，是"记住这三件事"。黄倩的语感可以用自问自答推进。
例："记住三件事。第一：必须提前设，人走了再想设来不及。第二：要在两年内申请变更。第三：不是所有产品都支持——买的时候问清楚。"

【七十多岁的企业主，三张保单三个孩子】
注：案例收口。那个企业主的画面够了——不说"你想想"，让观众自己想。
例："一位企业主，七十多岁，三张保单全是他自己做投保人。他有三个孩子，还有老伴。我说：万一哪天你不在了——你觉得你的孩子们能不能坐下来好好谈？他听完就办了。"
```

### ⚠️ 注意事项
- "保单的遗嘱"比喻不要展开——一个词够用
- 企业主案例讲完就收——不加"所以你也应该"

### 📝 口播文案示例

上一期留了一个扣子：怎么解决投保人走了之后保单继承的问题。答案就是——第二投保人。

你在保险公司指定一个人，告诉保险公司：如果有一天我不在了，这份保单的投保人，直接变更为他。不需要其他法定继承人到场，不需要签字放弃，不需要打官司。

第二投保人就是你这张保单的遗嘱。你提前说好接班人——到时候不用一群人抢着来签字。

设的时候记住三件事。第一：必须在投保人健在时去办，人走了再想设就来不及了。第二：投保人身故后，第二投保人要在两年内向保险公司申请变更。第三：不是所有保险产品都支持——买的时候一定要问清楚：能不能指定第二投保人。

我接触过一位企业主客户，七十多岁了，手里三张保单，全是他自己做投保人，给孙辈买的。三个孩子，还有老伴。他自己身体不太好，每年还要去非洲出差。

我跟他说：你想想。万一哪天你不在了——你的孩子们能不能达成一致？会不会为了这三张保单打起来？他听完一句话没说。后来我们做的第一件事，就是赶紧把第二投保人设上。

最后一期，说一个更日常的事：什么时候该做保单检视。买了保险不是就万事大吉了——你的人生在变，保单也得跟着变。

## 第5期：什么时候该做保单检视

### 🎬 封面标题建议
- 封面标题：离婚两年了，你的保单受益人还是前妻
- 封面文字：保单检视 · 五个节点
- 平台标题：什么时候该做保单检视

### 🎭 讲戏卡
- **对谁说**：买了保险就锁抽屉的人。他不知道受益人不改的后果
- **为什么今天非说**：离婚忘改受益人的案例是真实的——前妻拿到了理赔金，现任妻子一分没有。这个刺激够强
- **态度**：最后一期不收在"关注我"。收在一个提醒上——"五个节点，你对照着看一遍。花不了多少时间。"

### 🧭 结构走线

```
【前四期讲完了——最后一期说什么时候该回头检查】

【离婚两年了，受益人还是前妻⭐】
注：不铺垫五个节点。直接砸案例。这是五期里最后的高潮——跟第3期老王案例形成呼应。
例："一位先生离婚后忘了改保单受益人。再婚了，他走了——身故保险金直接打给了前妻。现任妻子一分没有。"

【五个节点，对照着看】
注：五个节点快速打——别逐一展开。黄倩的自问自答节奏在这里刚好——"你结婚了吗？生了孩子吗？离婚过吗？" 五个节点从对话里自然出来。
例："家庭变了——结婚、离婚、生孩子、亲人走了。身体变了——投保人身体出问题。钱变了——收入涨了还是企业有风险。孩子成年了。每年至少看一次。"

【受益人写"法定"——等于没写】
注：最后一个提醒。不是讲道理，是"你翻出保单看一眼，如果受益人那栏写了这两个字，赶紧改"。
例："翻出你的保单看一眼。受益人那栏——写了'法定'吗？马上改。指定人的名字。"
```

### ⚠️ 注意事项
- 五个节点快速打——别逐一展开成小课堂
- 结尾不回顾全系列，不说"关注我后面还会聊更多"——停在一个动作提醒上

### 📝 口播文案示例

这是保单角色系列的最后一期。

前四期讲了三个角色谁说了算、钱归谁、投保人走了怎么办、第二投保人怎么设。今天说最日常的——什么时候回来检查。

先讲一件事。一位先生离婚后忘了改保单受益人。再婚了，他不幸走了。身故保险金直接打给了前妻。现任妻子一分没有。法律就是这样的——受益人写了谁就是谁，不会因为你离婚就自动改。

所以什么时候该做检视？五个节点。家庭结构变了——结婚、离婚、生孩子、亲人离世。投保人身体出问题。经济状况大变动——收入涨了或企业有风险，现金价值可能被追。孩子成年了。每年至少看一次。

翻出你的保单。看三样。投保人还是不是你想要的那个人。受益人那栏写了什么——如果是"法定"两个字，赶紧改成指定人的名字。第二投保人设了没。

就这样。花不了多少时间。你抽空看一遍。
