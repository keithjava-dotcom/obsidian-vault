# 黄倩稿 · 女儿躺平，女婿不上班，老太太一个人养全家

## 🎬 封面标题

封面标题：女儿躺平、女婿不上班，老太太一个人养全家
封面文字：女儿躺平、女婿不上班，老太太一个人养全家
平台标题：一个老太太，女儿研究生毕业一天班没上过，女婿也不上班，两个孩子全靠她养。她每个月给女儿一两万。她跟我说得最多的一句话：哪怕女婿出去挣个三四千，我也满意了。

## 🧭 结构走线

```
【开场 · 客户原话】
她的真实客户。直接进，不铺垫。

"有个阿姨，每次见面都跟我抱怨同一件事。她女儿研究生毕业，一天班没上过，在家躺平。女婿也不上班。两个孩子，全靠她一个人养。"

【具体 · 数字】
数字替人说话。

"她每个月给女儿一两万。女婿一分钱不挣，花她的钱，花得理所当然。"

【她的那句话 · 全稿核】
原话。克制复述，不评判。

"她跟我说得最多的一句话是：哪怕女婿出去挣个三四千，我也满意了。她接受女儿躺平。但接受不了女婿躺得理所当然。"

【转折 · 阿姨自己的保险】
她自己也买了。

"阿姨自己买了五百万的保险。给女儿买了二百万。她一分钱都不想给女婿买。"

【她的心理 · 为什么】
洞察。她看得懂客户。

"她不是心疼钱。她是气不过——女儿躺平，她认了，那是自己生的。女婿不上班，还要她养，她接受不了。怕的不是富二代吃喝玩乐。怕的是他盯着我兜里的钱。"

【方案思路 · 顺着聊】
她的职业做法。不评判，顺着客户的担忧聊。

"所以跟她聊，不是劝她'别管女婿了'。是聊她自己的养老——她五十六岁，钱都在女儿身上，自己老了怎么办。她女儿这笔钱，怎么给才能确定给到女儿和外孙，跟女婿没关系。"

【收口 · 她的判断】
克制收。不说教。

"这种客户，你听着是抱怨。其实她心里早就想明白了，只是需要有人帮她把方案做出来。"
```

## ⚠️ 注意事项

1. 开场是复述客户，不是评判客户 — 带着"我听过太多次"的熟稔，像讲一个认识的人。
2. "哪怕女婿出去挣个三四千，我也满意了" — 全稿的核，念慢，别加自己的评价。
3. "怕的不是富二代吃喝玩乐。怕的是他盯着我兜里的钱。" — 这是她的洞察，平静地说。
4. 方案段不推产品 — 是她的工作思路（聊养老、聊确定给到女儿），保单是工具不是广告。
5. 收口"她心里早就想明白了，只是需要有人帮她把方案做出来" — 她的职业信念，不煽情。
6. 禁止：评判躺平女儿/评判女婿/煽情（"可怜的老太太"）/恐惧营销（"你也会这样"）。
