# 黄倩稿 · 谢贤的信托（系列上期）

## 🎬 封面标题

封面标题：谢霆锋只分到5%，这反而是谢贤最清醒的地方
封面文字：谢霆锋只分到5%，这反而是谢贤最清醒的地方
平台标题：网传谢贤超1亿港元资产，90%通过遗嘱信托给两个孙子，谢霆锋和谢婷婷各拿5%。很多人说偏心——恰恰相反。今天拆三个维度，为什么这才是清醒的安排。

## 🧭 结构走线

```
【开场 · 反常识】
先扔结论。很多人会觉得偏心，其实是清醒。

"谢贤的遗产方案传出来，很多人第一反应：谢霆锋只分到5%？太偏心了吧。恰恰相反，这才是最清醒的安排。"

【第一维度 · 按需分配】
不是按人头，是按需求。谁最需要钱给谁。

"第一个维度，分配逻辑。不是按人头分，是按需求分。谢霆锋自己就是印钞机，不差钱。两个孙子呢？父母离异，一个19岁一个16岁，正需要大笔教育费和生活保障。谁最需要，钱就给谁。"

【第二维度 · 控制机制】
不是给钱，是给规则。遗嘱信托怎么锁死意志。

"第二个维度，控制机制。钱给孙子，万一被挪用了呢？万一挥霍了呢？方案的做法是——不直接给钱，通过遗嘱设信托。张柏芝只有代管权，支取限定教育、医疗、日常生活，大额支出要凭证审核。而且条款里写了：改嫁，自动丧失代管资格。人不在了，规则还在替他执行。"

【第三维度 · 隔代传承】
跳过子女直保孙辈，一道防火墙。

"第三个维度，传承结构。隔代传承，跳过子女，直接保孙辈。子女能赚钱，不需要你兜底；孙辈还没长大，最需要长期保障。而且孙辈变数多——父母离异、监护权变更、再婚资产混同。隔代传承，相当于加了一道防火墙。"

【金句 · 遗嘱和信托的区别】
全稿记忆点。

"遗嘱解决的是钱给谁的问题。信托解决的是钱怎么花的问题。"

【收口 · 下期预告】
给追更理由。

"但这个方案里藏着一个专业上很值得聊的点——它用的是遗嘱信托，不是生前信托。这两种的区别，恰恰是很多人踩坑的地方。下一期，拆遗嘱信托和生前信托到底差在哪。"
```

## ⚠️ 注意事项

1. 开场"太偏心了吧"是替观众说的，不是她的判断 — 说的时候带一点"我理解你们会这么想"的熟稔。
2. "改嫁，自动丧失代管资格"这句念慢一点 — 这是全场最让人记住的规则。
3. "人不在了，规则还在替他执行" — 克制地说，不煽情。她越平静，这句话越重。
4. 三个维度是她的逻辑链（第一…第二…第三…），因果清晰，不赶。
5. 收口预告下一期（遗嘱信托vs生前信托）— 系列感，给追更理由。
6. 禁止：八卦语气、评判谢家、煽情、"豪门恩怨"式标题党。
