# 黄倩稿 · 当年没考上大工，快40岁坐进了大工的课堂

## 🎬 封面标题

封面标题：当年没考上大工，40岁我坐进了它的课堂
封面文字：有人说是MBA，学费高舍不得——但工作给了我机会
平台标题：当年没考上大连理工，今年快40岁的我，因为工作，坐进了大连理工的课堂，上了一天的课。有人说这是经理学院读MBA的，学费高我也舍不得——但工作给了我一个机会。这一年半，我走过养老社区，走过东财，今天又坐在了大工的教室里。

## 🧭 结构走线

```
【开场 · 反差】
当年没考上，现在坐进来了。反差直接砸，不铺垫。

"当年，我没考上大连理工大学。今年，快40岁的我，因为工作，坐进了大连理工的课堂，上了一天的课。"

【让步 · 别人的话】
先接住别人的质疑（MBA学费高舍不得），再翻出转折（工作给了机会）。黄倩式"先让步再观点"。

"有人会说：这是经理学院，读MBA的地方，学费那么高，我也舍不得。确实是。但工作，给了我一个这样的机会。"

【走过 · 这一年半】
用她真实去过的地方做"具体"：养老社区、东财、大工。地名就是画面钩子。

"我做保险，一年半了。这一年半，我去过养老社区实地考察。去过东财，参加过研学。今天，又坐在了大工的教室里。慢慢地，医疗、养老这些事，我懂了一些。保险的专业知识不用说，还有传承、信托。"

【偏见 · 轻轻带过】
行业偏见素材里只有一句（没具体事件），压缩成两行，不展开。重心让给有料的部分。

"大家对这个行业，多少是有点偏见的。今天我不谈偏见。我只说我自己的变化。"

【变化 · 说实话】
压力挑战焦虑着急是她的原话，但用"刚入行那会儿"定位时间，不再铺开。素材里"接触不同的人听心声"落到客户。

"刚入行那会儿，压力、挑战、焦虑、着急，一样没少。现在这些也还在。但多了很多体验。接触了很多人，听他们的故事，他们的喜怒哀愁，他们的担忧。"

【为什么 · 快40岁的思考】
赚钱是首要目的，快40岁开始想意义。自问自答是她的推进方式。

"赚钱，当然是首要目的。但快40岁，我开始想一个问题：人活着，到底是为了什么？我每天多懂一点，多帮一个人，算不算数？"

【收尾 · 金句落地】
见天地见众生见自己——"众生在身边"用她真实接触的人落地（客户），不编虚构人物。

"有句话说：见天地，见众生，见自己。不是每天都有机会去见天地。众生，也不一定在远方。也许就在身边——在我每天见到的那一位位客户里，在他们的故事里，在他们的担忧里。我希望自己，是一个生动的人。然后，慢慢去见那个更真实的、不断前进的自己。"
```

## ⚠️ 注意事项

1. 开场两句反差念慢——"当年，我没考上"和"今年，坐进了"之间留1秒，让观众自己反应过来
2. "确实是。"——全稿最轻的三个字，也是最有力量的转折，别加重音，轻轻带过
3. 【走过】段的地名念清楚（养老社区/东财/大工）——这些是她真实去过的地方，画面在她脑子里，念的时候放慢，像"回头看自己走过的路"
4. "人活着，到底是为了什么？"——自问自答是她的推进方式，不是鸡汤，念完停一下
5. 收尾"我希望自己，是一个生动的人"——她的原话，压住情绪说，别升华
6. 禁止：煽情鸡汤（"人生值得"）/ 推销腔（"找我规划养老"）/ 抱怨行业（"我们被误解"）/ 励志口号（"逆袭"）
7. 画面：研学现场的素材（校园、教室、听课）配【走过】和【收尾】段；开头"没考上"段可用校园大门空镜
8. 这段素材本身没有具体事件画面（谁/什么动作），写稿只能用到"地名+时间+原话"这一层——等黄倩按公式补3个画面，稿子还能再实一层

当年，我没考上大连理工大学。

今年，快40岁的我，因为工作，坐进了大连理工的课堂，上了一天的课。

然后，慢慢去见那个更真实的、不断前进的自己。

## 📝 柯老师点评（这次作业的提醒）

**黄倩，稿子你收到了。但这条稿子我只能写到这个程度——不是我不想写实，是你给我的素材里，没有"实"。**

你这次记的灵感是：

> "我有机会来到理工大学学习一天，很开心。这些体验包含了成长。"

通篇都是**抽象**。没有一个人、一个画面、一个动作。

所以稿子里我只能用"养老社区""东财""大工"这些地名撑着——地名是真的，但**画面**没有。

### 记灵感的公式（就这一条，记住它）

```
你看到了什么具体的东西、具体的事件、具体的人、具体的动作
    ↓
从而想到了什么
    ↓
把众多个这样的"具体+抽象"攒起来
    ↓
合成一个主题
```

**具体是肉，抽象是骨。只有骨头，稿子立不起来。**

### 下次参加活动，当场记三样

1. **一个人**：谁让你多看了一眼？（长相/动作/说的话）
2. **一个画面**：什么场景停在你脑子里了？（教室/走廊/阳光/背影）
3. **一个想法**：那一瞬间你心里冒出来的那句话

每样写两行：**上面一行写看到的，下面一行写想到的。**

三组"具体+抽象"攒够，一个主题就自己长出来了。

### 这次的补法

你拍了素材，里面有画面。按公式挑3个发我：

- 你在教室里看到了什么？
- 校园里有什么让你停下来的？
- 那天哪一瞬间，你心里冒出了"当年没考上"的念头？

3个画面到位，这条稿子重写一遍，能比现在实一倍。

**下次研学、下次见客户、下次去养老社区——先记3个"具体"，再来找我。**
