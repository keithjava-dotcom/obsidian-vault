# 黄倩稿 · 当年没考上大工，快40岁坐进了大工的课堂

## 🎬 封面标题

封面大字：40岁，我坐进了当年没考上的大学
封面文字：有些遗憾，晚20年补上，也是补上了
平台标题：当年没考上大连理工，是我的遗憾。今年40岁，因为工作，我坐进了大工的教室。不是MBA，不是花钱买的——是工作把我送回来的。原来有些遗憾，不是让你放下的——是让你晚一点，去完成它。

## 🧭 结构走线

```
【开场 · 反差】
当年没考上，现在坐进来了。反差直接砸，不铺垫。

"当年，我没考上大连理工大学。今年，快40岁的我，因为工作，坐进了大连理工的课堂，上了一天的课。"

【让步 · 别人的话】
先接住别人的质疑（MBA学费高舍不得），再翻出转折（工作给了机会）。黄倩式"先让步再观点"。

"有人会说：这是经理学院，读MBA的地方，学费那么高，我也舍不得。确实是。但工作，给了我一个这样的机会。"

【走过 · 这一年半】
用她真实去过的地方做"具体"：养老社区、东财、大工。地名就是画面钩子。

"我做保险，一年半了。这一年半，我去过养老社区实地考察。去过东财，参加过研学。今天，又坐在了大工的教室里。慢慢地，医疗、养老这些事，我懂了一些。保险的专业知识不用说，还有传承、信托。"

【偏见 · 轻轻带过】
行业偏见素材里只有一句（没具体事件），压缩成两行，不展开。重心让给有料的部分。

"大家对这个行业，多少是有点偏见的。今天我不谈偏见。我只说我自己的变化。"

【变化 · 说实话】
压力挑战焦虑着急是她的原话，但用"刚入行那会儿"定位时间，不再铺开。素材里"接触不同的人听心声"落到客户。**补入新素材的具体证据：平时连自拍照都不拍的人，今年开始出镜做短视频了——"我变了"的硬证据。**

"刚入行那会儿，压力、挑战、焦虑、着急，一样没少。现在这些也还在。但多了很多体验。接触了很多人，听他们的故事，他们的喜怒哀愁，他们的担忧。今年，我还开始做短视频了。平时连自拍照都很少拍的人，竟然开始出镜露脸了。"

【为什么 · 快40岁的思考】
赚钱是首要目的，快40岁开始想意义。自问自答是她的推进方式。**补入她的原话金句：年轻想漂亮有钱，40岁想生动有趣。**

"赚钱，当然是首要目的。但快40岁，我开始想一个问题：人活着，到底是为了什么？年轻的时候，我想做一个漂亮的人，一个有钱的人。现在，我想做一个有新鲜感的人，一个生动的人，一个经历过更多、却依然有趣的人。"

【收尾 · 金句落地】
见天地见众生见自己——**新素材给了"见众生"的真实落地：每天听不同年龄段客户的担忧和故事。不编虚构人物。**

"有句话说：见天地，见众生，见自己。不是每天都有机会去见天地。众生，也不一定在远方。也许就在身边——在我每天见到的那一位位客户里，在不同的年龄段，他们的担忧和故事里。我希望自己，是一个生动的人。然后，慢慢去见那个更真实的、不断前进的自己。"
```

## ⚠️ 注意事项

1. 开场两句反差念慢——"当年，我没考上"和"今年，坐进了"之间留1秒，让观众自己反应过来
2. "确实是。"——全稿最轻的三个字，也是最有力量的转折，别加重音，轻轻带过
3. 【走过】段的地名念清楚（养老社区/东财/大工）——这些是她真实去过的地方，画面在她脑子里，念的时候放慢，像"回头看自己走过的路"
4. "平时连自拍照都很少拍的人，竟然开始出镜露脸了"——这句是新素材里的具体证据，念的时候带一点"自己都没想到"的轻笑意，别念成炫耀
5. "我想做一个有新鲜感的人，一个生动的人，一个经历过更多、却依然有趣的人"——她的原话金句，三连排比放慢，这是全稿的情绪高点
6. 收尾"我希望自己，是一个生动的人"——压住情绪说，别升华
7. 禁止：煽情鸡汤（"人生值得"）/ 推销腔（"找我规划养老"）/ 抱怨行业（"我们被误解"）/ 励志口号（"逆袭"）
8. 画面：研学现场的素材（校园、教室、听课）配【走过】和【收尾】段；开头"没考上"段可用校园大门空镜；"出镜露脸"段可配她手机拍短视频/在镜头前的花絮素材

## 📝 柯老师点评（这次作业的提醒）

**黄倩，稿子你收到了。但这条稿子我只能写到这个程度——不是我不想写实，是你给我的素材里，没有"实"。**

你这次记的灵感是：

> "我有机会来到理工大学学习一天，很开心。这些体验包含了成长。"

通篇都是**抽象**。没有一个人、一个画面、一个动作。

所以稿子里我只能用"养老社区""东财""大工"这些地名撑着——地名是真的，但**画面**没有。

### 记灵感的公式（就这一条，记住它）

```
你看到了什么具体的东西、具体的事件、具体的人、具体的动作
    ↓
从而想到了什么
    ↓
把众多个这样的"具体+抽象"攒起来
    ↓
合成一个主题
```

**具体是肉，抽象是骨。只有骨头，稿子立不起来。**

### 下次参加活动，当场记三样

1. **一个人**：谁让你多看了一眼？（长相/动作/说的话）
2. **一个画面**：什么场景停在你脑子里了？（教室/走廊/阳光/背影）
3. **一个想法**：那一瞬间你心里冒出来的那句话

每样写两行：**上面一行写看到的，下面一行写想到的。**

三组"具体+抽象"攒够，一个主题就自己长出来了。

### 这次的补法

你拍了素材，里面有画面。按公式挑3个发我：

- 你在教室里看到了什么？
- 校园里有什么让你停下来的？
- 那天哪一瞬间，你心里冒出了"当年没考上"的念头？

3个画面到位，这条稿子重写一遍，能比现在实一倍。

**下次研学、下次见客户、下次去养老社区——先记3个"具体"。**
