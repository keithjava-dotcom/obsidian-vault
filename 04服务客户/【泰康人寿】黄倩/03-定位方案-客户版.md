# 🚩 第一战区：商业破局靶心（定战场、定人、定钱）

## 一、你的视频到底打谁（靶心三件套）

- **一个人**：陈叔叔（或陈阿姨）
- **一个阶段**：65岁左右，退休前后，手上有几百万现金，开始认真想养老和传承的事
- **一个问题**：手里有钱不知道该放哪儿——存银行利率低，买理财怕踩雷，房子不想再买了。既想自己晚年有保障，又想把钱稳妥地留给子女，但不知道怎么做才周全

→ **一句话靶心**：陈叔叔/陈阿姨，退休前后，手里有七八百万现金不知道怎么安排，才能既保自己晚年、又稳妥传给下一代。

> 💡 养老规划的决策者中阿姨占了很大比例——她们往往是家庭财务的实际管理者。
> 所以你的内容既要打到叔叔，也要打到阿姨。
> 下面的画像以"陈叔叔"为典型展开，但阿姨的场景同样适用。

## 二、目标用户深度画像

**名字暂叫**：陈叔叔 / 陈阿姨

### 来源群体

- **现阶段能服务到的**：大连本地60-75岁退休老人，手上有现金500万-1000万，有子女，对养老品质有要求，不满足于居家养老或普通养老院
- **账号成熟后要服务的**：全国高净值退休人群及其子女（40-55岁帮父母规划养老的子女）
- **可能围观但不付费的**：保险同行、金融从业者、对养老话题感兴趣的年轻人

### 用户画像（8个维度）

1. **受教育水平**：高中到大专，部分有大学学历。不是知识分子型，但是"见过世面"——做生意、管企业、当领导过来的
2. **经济水平**：现金500万-1000万，有房产（可能多套），退休金+租金+理财收益。属于"有钱但不显富"的类型
3. **消费理念**：可以花200万买一张保单，但超市买菜会计较几块钱。对"值不值"的判断极度敏感——不是抠门，是精明了一辈子
4. **婚姻/恋爱状态**：已婚，子女已成年（30-45岁），大多已婚有孩子
5. **生活节奏**：退休后生活规律——早睡早起、散步、买菜、看新闻、偶尔旅游。不忙但也不闲着，最怕"没事干"
6. **愿意为什么付费**：为自己晚年的品质生活付费（不想拖累子女），为子女的未来保障付费（想给子女留钱），为"省心"付费（不想折腾）
7. **此时此刻关心什么**：钱放哪儿安全？银行利率越来越低怎么办？自己老了动不了谁来管？留给子女的钱会不会被女婿/儿媳分走？
8. **平时刷视频的习惯**：主要在视频号（微信里直接看），晚上8-10点，看新闻、健康养生、子女教育、房产相关内容。不太看抖音

### 内容方向提醒

你的内容站队在谁那边、反对谁，直接决定了谁会信任你：

**你反对的**：
1. 把人生规划简化成数字比较的功利主义
2. 以恐惧为杠杆、以成交为目的的恐吓式营销
3. 把客户当业绩数字、不把客户当人的交易思维
4. 用过度承诺透支行业信任的短视主义

**你不服务的**：只追求收益最大化、不关心养老品质和传承安排的纯理财型客户

**内容红线**：不要下意识讨好保险同行（他们夸你但不付费），不要用年轻人梗（陈叔叔/阿姨看不懂）。
你的内容只对陈叔叔/阿姨这类人说。

## 三、商业变现设计

内容积累（视频号持续输出）
→ 引流方式：视频号内容 → 评论区互动 → 私信/微信添加
→ 转化方式：私域持续触达（朋友圈+视频） → 信任建立 → 线下约见/社区参观
→ 产品/服务：大额保单（养老社区+财富传承，200万起）

**你的节奏**：
- 不追求快速成交，追求信任前置
- 200个私域种子用户 + 视频号新流量 → 2年积累期 → 2028年社区开业集中转化
- 一年2-3个大客户（单笔佣金7-10万+），以点带面——一个满意的客户身边一圈同圈层的朋友


# 🏰 第二战区：IP核心护城河（立灵魂）

## 四、终局课题

- **3年后你被定义为**："大连高净值养老规划"领域的个人IP——帮退休前后的有钱人做好养老+传承的双重规划
- **你的终局课题**：不是"怎么卖保险"，是"一个人如何为自己的晚年和下一代做负责任的安排"
- **现在的内容如何指向这个终局**：每一条视频都在告诉陈叔叔/陈阿姨——你可以为自己做负责任的安排的，而且有靠谱的人在帮你做

## 六、人设标签与阶段释放

### 你的人设标签

**身份标签**（真实可验证，最多4个）：
1. 泰康人寿高级理财经理
2. 养老社区规划顾问
3. 财富传承架构师
4. 前日企金融从业者

**性格标签**（来自你的真实表达）：
1. 理性克制——不煽情、不浮夸、有事说事
2. 真诚坦率——不会的就说不会，回去问了再告诉你
3. 节奏慢但稳——不求快，求每一步走扎实

**价值标签**（给用户的利益）：
1. 帮你把钱安排得明明白白——养老+传承一步到位
2. 不跟你绕弯子——好的坏的都讲清楚
3. 长期在你身边——不是卖完就走的销售

### 什么让你突出？

**不是**：学历、证书数量、从业年限、公司背书

**而是**：
- **审美**：日企严谨感 + 精致但不张扬的视觉风格
- **角度**："保险不只是理财，是人生规划"——把保险从数字拉回人本身
- **故事**：第一单9个月才开、1.5年空窗期重新出发、打败5家同业——不是"惨"，是"韧"
- **软肋**：才做了一年多，还有很多在学——坦承不装懂，反而最可信
- **坚定立场**：反对功利主义保险销售，坚持"做人比做事重要"——这是筛子，把对的人筛进来

### 阶段性释放节奏

- **早期（0-3个月）**：真诚、专业、不功利——用故事+科普反复钉这三个词
- **中期（3-6个月）**：养老规划专家、财富传承顾问——在信任基础上加深专业深度
- **后期（6-12个月）**：行业洞察者、生活方式倡导者——不只讲产品，讲养老是生活方式的选择
- ⚠️ 不要一上来就"啥都有"。第一印象只钉三个词：**真诚、专业、不功利**
