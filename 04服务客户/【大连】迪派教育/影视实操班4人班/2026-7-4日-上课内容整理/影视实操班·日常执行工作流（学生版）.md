# 影视实操班 · 日常执行工作流

> 把课上讲的知识点，变成你每天能照着做的流程。

---

## 总览：四条核心工作流

| 流程 | 用途 | 频率 |
|---|---|---|
| 流程一 | 写文案 | 每次写稿必走 |
| 流程二 | 拍摄前准备 | 每次拍摄前走一遍 |
| 流程三 | 日常积累（网感训练） | 每天 |
| 流程四 | 账号维护 | 每周一次 |

---

## 流程一：写文案（7步）

### 第1步：锁定主题

想清楚一件事：这条视频给谁看？

不要写"给所有人看"。具体到你认识的一个真实的人——比如"我那个26岁想换行又不敢的哥们"。

### 第2步：列故事线

用这个结构：

```
顺境铺垫（我是什么人，我曾经多好）
    ↓
遭遇冲突（发生了什么事）
    ↓
巨大落差（为什么干不下去了）
    ↓
低谷挣扎（持续多久，做了什么努力）
    ↓
走出新生（选择了什么新方向）
    ↓
观众收获（你可以从中学到什么）
    ↓
收束（真实的感悟，不要说"加油"）
```

### 第3步：写出初稿

三条硬规则：

1. **遇标点符号就换行。** 句号、逗号、问号、感叹号——碰到就另起一行。
2. **少用形容词，多用具体数字和画面。** 不要说"很纠结"，要说"躺在床上想了三个晚上睡不着"。
3. **冲突隔行放。** 两行平淡内容，来一行冲突。不要连续冲突让人累，也不要连续平淡让人划走。

### 第4步：删

把初稿从头念一遍。每念一句问自己：

> 删掉这句话，观众还能理解我的意思吗？

能 → 删。不能 → 留。

删到删不动为止。前期视频越短越好——你不知道什么是流量的时候，拍短一点，安全。

### 第5步：检查三件事

| 检查项 | 怎么做 |
|---|---|
| **钩子** | 前两秒能留住人吗？不能就换。不要"大家好"，不要"这是我的第X条视频" |
| **冲突** | 有"顺"也有"不顺"吗？全程顺=没人看，全程不顺=累 |
| **获得感** | 观众看完能得到什么？有具体的一句话吗？没有就加 |

### 第6步：念一遍

用手机录下来自己听。哪里结巴、哪里不像人话，改。

记住：你不是在写作文，你是在跟一个朋友聊天。

### 第7步：定稿

改完，念顺了，就定稿。不要来回纠结。

## 流程二：拍摄前准备（5步）

### 第1步：定场景

你的文案是什么情绪？选对应场景：

| 文案情绪 | 场景 | 时间 | 色调 |
|---|---|---|---|
| 向上、自律、希望 | 户外、日出、运动场景 | 日出 | 暖调、亮调 |
| 深情、回忆、故事感 | 海边、路灯下台阶、窗边 | 黄昏/蓝调时刻 | 偏暗、有质感 |
| 迷茫、困惑、低谷 | 城市夜景、空荡街道 | 夜晚 | 冷调、暗调 |
| 成功、喜悦 | 明亮室内、户外阳光 | 白天 | 暖调、亮调 |
| 知识、干货 | 干净桌面、书房 | 白天 | 中性 |

**一个原则**：场景要像你。偏甜的女生白天拍暖调，帮酷的人拍硬光，深情的人拍蓝调时刻。不要硬套。

### 第2步：列出名词画面

把你文案里所有名词（人、地点、物品）圈出来。每个名词至少准备一个画面。

比如"95后大连女生前护士"：

- 大连 → 星海广场、跨海大桥、有轨电车、海鸥
- 95后女生 → 毕业照、日常穿搭、照镜子
- 前护士 → 护士服挂在旁边、医院走廊

**拍了这些画面，你的视频信息密度才能上去。**

### 第3步：列出情绪画面

文案里哪些地方在表达情绪？用画面传达：

| 情绪 | 可以拍什么 |
|---|---|
| 内耗、焦虑 | 挠头、抽烟、喝酒、睡不着 |
| 迷茫 | 干枯的花、积灰的鱼缸、烂水果（以物传情） |
| 走出 | 快走、转身、微笑 |

### 第4步：准备BGM

提前选好音乐，不要拍完再找。

方法：平时听到有感觉的歌，立刻发微信文件助手，备注"什么情绪"。积累多了，做片子时直接调出来。

**音乐要和文案的情绪阶段匹配。** 开头低沉 → 中间激烈 → 结尾舒缓，BGM跟着切换。

### 第5步：拍

- A-roll（对着镜头说话）：说3-5遍，挑最自然的那条
- B-roll（空镜、环境、细节）：每个名词、每个情绪点都拍，多拍几个版本
- 不会说？用**开放式提问法**：让别人问你问题，你自然回答，后期把问题剪掉

## 流程三：日常积累（网感训练）

### 每天必须做

**看30-50条同领域视频。** 刷的时候带着三个问题：

1. 前两秒为什么留住我了？
2. 他的画面里放了什么东西？
3. 他的BGM怎么配合情绪的？

### 每天抽3-5条拆解

拆一条视频，写下来：

- 开头钩子是什么（一句话）
- 冲突点在哪里
- 结尾给了观众什么收获
- 画面：几个A-roll、几个B-roll、什么场景
- 我能抄什么（一个具体的东西）

### 每周：扫街拍素材

出门看到有意思的东西就拍下来：
- 路灯、台阶、旧物件
- 花、枯树、海
- 人走路的背影、车流

**先有素材库，再写文案，效率翻倍。**

## 流程四：账号维护（每周一次）

### 检查事项

| 检查项 | 标准 | 不达标怎么办 |
|---|---|---|
| 内容统一 | 账号里只有一种内容类型 | 混发的转私密，不删，留着 |
| 标签清晰 | 平台知道你是干嘛的吗？ | 坚持只发一类内容，别乱 |
| 持续更新 | 每周至少发1-2条 | 集中写→集中拍→集中剪，一次搞定好几条 |
| 播放量 | 本命播放2000-3000算起号 | 没到就一直发一类内容，别换方向 |

### 起号阶段（0-3个月）

第一阶段（0-1个月）：**我是谁。** 把你问卷里每个问题拍一条视频。内容稳，不功利，搭建信任。

第二阶段（1-3个月）：**我正在经历什么。** 学习过程、日常记录、本领域知识。日记体特别管用——每天做了什么、想了什么、有什么收获，写成文案发。

**3-4个月还没到2000播放，起新号。**

## 三个保命技巧

### 技巧1：开放式提问法（拍别人用）

老板背不下稿子？没关系。

1. 你先想好主题
2. 设计几个问题问他
3. 让他自然说出来
4. 把你的问题剪掉，只留他的话

> "你干了多少年？"→"我干修车干了六年。"→"最多赚多少？"→"最多一个月一万二。"

### 技巧2：信息叠加法（表现力不够用）

嘴说不清楚的内容，加花字/旁注在画面上，让观众同时看到、听到。

### 技巧3：焦段组合（画面张力）

- 中远景：24-50mm
- 特写：70mm以上
- 组合：远景+特写、中景+特写交替，观众不会看睡着

## 一周执行模板

| 天 | 做什么 |
|---|---|
| 周一 | 看30条视频，拆3条；积累灵感 |
| 周二 | 集中写3条文案（按流程一） |
| 周三 | 上午选场景+BGM，下午集中拍 |
| 周四 | 集中剪 |
| 周五 | 发1条；看30条视频，拆3条 |
| 周六 | 扫街拍素材；复盘本周播放数据 |
| 周日 | 休息；有灵感就记下来 |

## 自查清单（每次发视频前过一遍）

- [ ] 前两秒有钩子吗？没有"大家好"，没有"这是我的第X条视频"
- [ ] 遇标点换行了吗？
- [ ] 删到删不动了吗？
- [ ] 有冲突吗？（太平了=没人看）
- [ ] 观众看完能得到什么？（有具体的一句话）
- [ ] 场景和我匹配吗？（情绪、时间、色调）
- [ ] 名词都拍出画面了吗？
- [ ] BGM选好了吗？
- [ ] 结尾不是说"加油"吧？
