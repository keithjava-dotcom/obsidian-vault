## ① 个人账号定位【核心作业】

### 你需要写清楚：

1. **我的身份标签是什么？**
   - 年龄（如：98年、00后、01年）
   - 城市（如：大连人、沈阳人）
   - 经历（如：退伍军人、护士2年、马来西亚做气球2年）
   - 专业/技能（如：会剪辑、会拍摄、会外语、懂AI）

2. **我想干什么行业？**
   - 具体到行业名称（如：汽修、气球、制造业、美业、装修……）
   - 为什么选这个行业？

3. **我的目标用户是谁？**
   - 老板画像：什么行业的老板、有什么痛点

4. **我的人设核心是什么？**
   - 我区别于其他人的点在哪？

### 格式示例：
```
我叫XXX，XX年，大连人。
我的经历是：XXX
我想服务XX行业。
我的人设核心是：XXX
```

## ③ 写"自我介绍"大纲

### 模板：共情 + 解决方案

#### 第一部分：开头（身份+共情）
```
[年龄/城市/身份] + [发现了什么行业现象/老板困境]
```
**例子：**
- "98年的大连人，我发现……"
- "01年退伍军人，我在部队待了两年，我非常清楚……"
- "00后，在马来西亚做了两年气球，回到大连我看到……"

#### 第二部分：理解老板（共情）
表达你理解这个行业的老板在经历什么困难。
> **要点**：讨厌他讨厌的，喜欢他喜欢的。让他感觉"这小伙子/小姑娘懂我"。

#### 第三部分：解决问题（展示能力）
提出你能帮他解决什么问题。
- 如果有专业背景→结合专业给方案
- 如果没有→展示你的学习能力和执行力

#### 第四部分：行动召唤
> "我想收集/帮助100个这样的老板"

### 提交要求：
- 先出大纲（结构+要点），发群里
- 柯老师可以帮你改
- 不要直接让柯老师写——你得先做出来

## ④ 作业视频制作

### 大纲通过后，按以下流程做视频：

#### 拍摄
1. 找一个好看/舒服的地方拍A-roll
2. 按画面构成标准：确认景别、构图、视角
3. 拍完用**黑场标记法**标记稿子编号

#### 剪辑（七步法）
```
① 调音量 → 音波图12-20，降噪
② 初剪 → 去掉废镜头
③ 加字幕 → 逐句精修换行
④ 加B-Roll → 名词动词配对应画面
⑤ 加BGM → 起承转合拆分
⑥ 加音效 → 关键节点提示音
⑦ 加拟声音/环境音 → 增强质感
```

### 验收标准：
- 画面有构图意识（别乱拍）
- 声音清晰可听
- 按七步法完整剪辑
- 片子有质感
