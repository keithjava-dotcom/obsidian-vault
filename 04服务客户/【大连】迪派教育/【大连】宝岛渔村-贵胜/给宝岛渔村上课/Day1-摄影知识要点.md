> 柯老师口述，小龙整理+标注辨别

## 一、曝光三要素（摄影地基）

三件事互相拉扯，调一个就得调另外两个：

| 要素 | 数值↔画面 | 副作用 |
|------|----------|--------|
| **光圈 Aperture** | F值**越小**→进光**越多**→越亮 | 虚化越强 |
| | F值**越大**→进光**越少**→越暗 | 景深越大 |
| **ISO** | **越高**→越亮 | 噪点越多（雪花） |
| | **越低**→越暗 | 画面越干净 |
| **快门 Shutter** | **越慢**→进光越多→越亮 | 画面拖影/运动模糊（王家卫风格） |
| | **越快**→进光越少→越暗 | 可冻结高速运动（体育赛事） |

**💡辨别**：框架是对的，但新手容易把"正常曝光"当死目标。柯老师后面讲了——亮调暗调是创作选择。**先学会正常曝光，再故意偏亮偏暗。顺序不能反。**

**光圈特别记**：F4.0→F22，数字越大洞越小。初学者最容易搞反。

## 二、索尼屏幕 vs 直方图（🔴 重点）

**问题**：**索尼的屏幕不准**，业内出了名的"千年破屏"。柯老师原话。
按屏幕调曝光→翻车。尤其户外强光下更不准。

**解法**：看**直方图**（黑白柱状图，左边暗部右边亮部）

- **宁欠勿曝**：稍微偏暗（偏左），后期能拉回来
- **过曝**（偏右碰到边）：信息永久丢失，后期救不回
- 看屏幕**只看构图**，曝光**看直方图**

**💡辨别**：这个技巧值半台机器的钱。很多人拍完回去发现画面不对，就是信了屏幕。**实际效果以数字为准。** 不光是索尼的问题，但索尼尤其严重。

## 三、虚化（背景奶油化）

三要素，缺一不可：
1. **光圈够大**（F值小）
2. **焦段够长**（越长虚化越强）
3. **距离合适**（镜头离主体近 + 主体离背景远）

> 行话：背景如奶油般化开，主体如刀锋般锐利

**使用场景**：
- 拍单人 → 拉虚化（业内叫"糖水片"）
- 拍大合照 → 收光圈+拉高ISO，保证全部清晰

**💡辨别**："糖水片"是业内半调侃说法，不是贬义。新手容易沉迷虚化，但婚礼/商务场景要的是**所有人清楚**。知道什么时候**不用**虚化，比知道怎么用虚化更重要。

## 四、焦段——从视野到空间压缩

| 焦段 | 类型 | 视觉效果 | 适合场景 |
|------|------|----------|---------|
| 10-16mm | 超广角 | 视野极大，有畸变 | 星空、自拍 |
| 24mm | 广角 | 接近人眼视角 | 环境交代 |
| 35-50mm | 标准 | 自然舒服 | 日常、人像**黄金镜头 50 1.4** |
| 70-105mm | 中长焦 | **空间压缩感** | 人像首选 |
| 200mm+ | 长焦/超长焦 | 超强压缩 | 街拍/城市打卡/打鸟/动物 |

**口诀**：焦段不够，距离来凑。焦段越长，画面越抖。

**空间压缩感**：长焦把远近物体"压"到同一画面——楼和船同框、人和城市背景同框。这是物理控光的效果，手机算法仿不来。

## 五、大三元 vs 小三元

| | 大三元 | 小三元 |
|--|--------|--------|
| 光圈 | **F2.8**（恒定） | **F4.0**（恒定） |
| 镜片质量 | 更高 | 入门级 |
| 价格 | 💰💰💰 | 相对友好 |
| 三镜组合 | 16-35 / 24-70 / 70-200 | 同焦段 |
| 替代方案 | — | **24-105 F4**（柯老师用的一镜走天下） |

**💡辨别**：柯老师用24-105 F4是**务实选择**——干活包打天下。大三元专业但背三个镜头不现实。**先想清楚：赚钱选实用，玩才选规格。**

## 六、御三家（品牌定位）

| 品牌 | 强项 | 注意 |
|------|------|------|
| **尼康** | 抗噪强 | 风光/野生动物为主 |
| **索尼** | 镜头便宜、干活稳定、干活首选 | ⚠️ **屏幕不准**（柯老师特别强调）|
| **佳能** | 拍人脸好看，自带美颜效果 | 镜头价格**索尼的2-3倍** |

**推荐**：柯老师给宝岛渔村学员推荐的是**索尼A7m4**——干活稳定、双卡槽散热好、镜头便宜。佳能拍脸好看但镜头贵，对"干活赚钱"的团队不是最优选。

**💡辨别**：选器材看**拍什么+赚不赚钱**，不看品牌信仰。

## 七、拍摄格式与后期

| 格式 | 特点 | 用途 |
|------|------|------|
| **JPG** | 直出即用 | 日常快速出图 |
| **RAW** | 宽容度大，后期可调亮暗 | 专业创作 |
| **LOG/HDR（灰片）** | 画面灰蒙蒙，保留暗部亮部细节 | 电影感 → 还原 → 风格化 |

**色调服务于情绪**：
- 欢乐/生日宴 → 亮调
- 低谷/创业故事 → 暗调
- 爱情 → 鲜明甜美
- 港片/老故事 → 黄橙色
- 常见电影风 → 青橙对比

**💡辨别**：柯老师说"剪映滤镜底层是摄影知识"——理解了光圈/ISO/快门，你就知道为什么这个滤镜叫日系、那个叫港风。**学会原理，用剪映是降维打击。**

## 八、其他实用要点

### 构图基础
- **三分线构图+前景遮挡**：主体放三分之一线
- **框架构图**：利用前景框住主体
- **多抓拍，少摆拍**：人在真实情境里最好看

### 拍摄习惯
- 尽量不抖，双手持机（长焦更抖）
- 竖屏拍摄
- **先拍到，再考虑拍好看**

### 拍摄格式
相机/微单有**两种格式**：
1. 直出（JPG）= 电脑直接看
2. RAW = 用电脑校正色彩再导出（宽容度大）

## 九、给新手的三个习惯

1. **素材要多**：准备30个菜才能挑出8个好菜。拍的时候也是，多拍多剪。
2. **抓拍>摆拍**：人在做事时最自然。
3. **前2秒抓人，前5秒说明白**：用**数字化技巧**让第一句话就信息爆炸——"十个人、十六个菜、不到十张"，价格/人数/菜品量一次说完。
