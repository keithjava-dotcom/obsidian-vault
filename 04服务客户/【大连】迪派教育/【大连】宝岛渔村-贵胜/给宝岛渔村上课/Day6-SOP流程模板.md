# 宝岛渔村 · Day6 短视频实操SOP（剪辑 + 脚本）

> 本模板覆盖Day6课堂教的**剪辑四步法**和**脚本写作公式**。每个SOP可独立使用，照步骤执行即可出片。
> 配套：Day5-SOP（拍摄/选题/信息收集）先用，本SOP管剪辑和脚本。

---

## SOP 1：剪辑四步法（剪映）

**适用场景**：任何一条视频的后期剪辑。照顺序做，别跳步。

### 第一步：出片（排素材 + 加字幕）

1. 素材按脚本顺序拖到主轨道
2. 字幕打在屏幕中下方，字号适中
3. 检查：画面是否跟话对上——说"定制场景"就要有布置过的场景画面

### 第二步：调音频

| 检查项 | 标准 | 操作 |
|---|---|---|
| 人声音量 | 音波图 **0~6 之间** | 不够就加音量 |
| 响度统一 | 每句话差不多大声 | 先统一再降噪 |
| 环境音 | 保留，压到 **-10** | 炒菜声/放盘声是真实感，别删 |

### 第三步：加音乐

1. 选好音乐（平时攒音乐库/音效库，搜"营销"类教程积累）
2. 音量：波形图从 **-6~-2 降到 -12~-20**（最好 -20~-30），不能压过人声
3. 卡点：在**变调处分割**，按文案高光点对节奏

### 第四步：插B-roll + 花字 + 转场

| 操作 | 参数/做法 |
|---|---|
| 快切 | 4 秒放 4 个场景（一秒一个）；2 秒切 2 个画面 |
| 关键帧 | 静态画面推近放大；片尾缩小 150→100 |
| 出场/入场 | 动画方向相反（左滑出↔右滑入）才顺 |
| 花字 | 入场/出场/循环三种；素材滚动用"点击素材→动画→组合" |
| B-roll | 素材放字幕下方，素材之间加转场 |

### 出片自检清单

- [ ] 人声清楚（0~6），音乐垫底（-12 以下）
- [ ] 画面跟话走（说到啥出现啥）
- [ ] 4 秒内至少一次画面变化
- [ ] 片尾没有戛然而止（缩小/祝福语/手写体收尾）

## SOP 2：脚本写作公式（细节→冲突→口语）

**适用场景**：任何一条视频开拍前。先写脚本，再拍摄。

### 第 1 步：收集信息（接单/聊天时完成）

| 问什么 | 为什么问 |
|---|---|
| 谁办？多大年龄？ | 定故事主角和情绪基调 |
| 有没有外地来的？ | "欢迎外地老乡"天然带共鸣 |
| 家人情况（几世同堂/有没有老人） | 亲情故事线 |
| 对场地/菜品有什么特别要求？ | 需求差异=冲突=故事 |
| 预算敏感吗？ | 省钱=卖点 |
| 为什么选我们家？ | 真实决策理由 |

### 第 2 步：补充细节

- 把每句话换成有数字、有名字、有画面的说法
- 示范：❌"七八十岁的同学聚会" → ✅"78 岁的奶奶，加个 80 岁老头，俩人加起来快 200 岁，来订 38 中的聚会场地"

### 第 3 步：植入冲突（不损品牌、不坑自己）

| 冲突类型 | 怎么用 |
|---|---|
| 内部冲突① | "冻品便宜能赚更多，我们为什么坚决不用？" |
| 内部冲突② | "布置场景是收费的，我们为什么免费做？" |
| 正面冲突 | 老人想要氛围，我们怎么耐心帮他们排忧解难——讲过程 |
| 惊喜冲突 | 条幅是纸的容易坏 → 我们缝了一圈布 |

**红线**：不能跟观众对抗；不能影响品牌形象；不能承诺以后每个客人都送的东西。

### 第 4 步：优化口语（说 ≠ 写）

1. 写完**读一遍**（或直接对着手机说）
2. 用剪映"语音转文字"转出来
3. 自检三点：开头留人吗？中间会划走吗？结尾让他行动吗？
4. 别扭的地方改到顺口为止

### 脚本自检清单

- [ ] 开头 3-5 秒有"一句话钩子"（数字/反问/反差）
- [ ] 中间有细节（数字、人名、地名）+ 至少一个冲突
- [ ] 结尾有行动指令（评论/转发/咨询）
- [ ] 读一遍顺口，不像写作文

## SOP 3：一个素材出多条视频（多角度法）

**适用场景**：拍了一次素材，别浪费，换角度再剪。

| 角度 | 做法 | 示例 |
|---|---|---|
| 数字 | 把数字放标题/开头 | "加起来八千岁的同学聚会" |
| 反差 | 对比两代人/两个选择 | "40 后和 80 后的同学聚会有什么区别？" |
| 对抗 | 抛话题让评论区吵 | 90 后 vs 00 后（节奏自己把握） |
| 夸顾客 | 用数字夸请客的人 | "能花一万三请吃饭的人，他们三十年遇着一个" |

**提醒**：节奏一定要自己把握，别带跑偏。

## SOP 4：正能量题材拍摄流程

**适用场景**：没选题时，从生活里捡素材。以下题材已验证"必火"。

### 早市包老人菜

1. 找 80、90 岁还自己种地摆摊的老人（要真难、要社恐）
2. 先聊：老人有多苦、菜卖不掉
3. 再包：把他的菜全买下来（成本一百块以内）
4. 拍真实，别演——观众看得出假

### 工地送饭送水

- 拍"36 岁看着像 46 岁"的沧桑感
- 配正能量文案

### 后厨清单制探店（自己的店）

1. 从备料开始拍：早上来怎么备食材、怎么处理青菜、怎么处理肉
2. 清单制过一遍：**洗菜区→冷餐区→肉料区→热餐区**
3. 敢展示后厨 = 观众信任你

### 老板帮人 / 夸东北人

- 口播讲事 + 把当时的会场/画面拍出来
- 夸东北：实在、豪情、够意思——中年人有付费能力，共鸣强

## 七秒原则速查（所有视频通用）

| 时长 | 几个7秒 | 说明 |
|---|---|---|
| 21 秒 | 3 个 | 最短可用 |
| 35 秒 | 5 个 | 推荐长度 |
| 70 秒 | 10 个 | 内容够厚才用 |

**每 7 秒给观众一个新刺激。** 开头抓住人，后面观众有耐心（耐心倍增效应）。
