# 宝岛渔村 · 短视频实操SOP流程模板

> 本模板覆盖宴会型餐饮账号的完整内容生产流程。每个SOP可独立使用，照步骤执行即可出片。

---

## SOP 1：宴会视频拍摄标准流程

**适用场景**：婚宴、生日宴、寿宴、升学宴等所有宴会现场拍摄

### 一、拍摄前准备

1. **设备检查**
   - 相机：确认电池满电、存储卡空间充足（建议1T卡，拍不完）
   - 手机：备作辅助机位，确认存储空间
   - 三脚架/稳定器：长时间拍摄防抖

2. **人员分工**
   - 至少两人配合：一人主拍相机，一人手机补位
   - 忙时指定一人专职拍摄（指挥实习生/助手操作，自己负责剪辑）
   - 不要边接待边拍——精力不够，素材质量差

### 二、四类景别取景清单

| 景别 | 焦段 | 拍什么 | 怎么拍 |
|---|---|---|---|
| **全景** | 24mm广角 | 场地全貌、门口迎宾、整体环境 | 每段6-8秒，从室外拍到室内，多走几个角度 |
| **中景** | 35-50mm | 人物半身动作：主持人讲话、宾客互动 | 拍半身，跟动作走。一个人物拍完立刻转拍另一个 |
| **近景/特写** | 70mm+ | 侧脸、手部、话筒、嘴角、观众表情 | 观察谁在干嘛——听得认真的、小孩笑的、两人说话的，全部抓 |
| **大特写** | 微距/拉近 | 菜品、摆件、餐具、窗花、灯笼、食材 | 让物体占画面2/3，色彩和细节是第一位的 |

### 三、相机参数速查

| 场景 | 光圈 | ISO | 快门 |
|---|---|---|---|
| 室内人物/菜品 | 2.8（锁死不动） | 自动（暗光可拉至12,800） | 50-100 |
| 拍全家福/大空间 | 调至5-8（光线差可到9-11） | 自动 | 50-100 |

### 四、拍摄心法

1. **宁可多拍，不可少拍**：每个景别至少拍6-8秒，拍多了不用没事，缺素材才麻烦
2. **多角度切换**：不要举着机器站一个地方不动。拍完主持人→转过来拍观众→再拍菜品，来回切
3. **横屏拍摄**：宴会类建议横拍（画面更广、显档次）。竖屏可以水一点，横屏用户把手机横过来，就得给值的内容
4. **视觉冲击力**：全景+大特写组合（一大一小对比），适合放开头抓眼球，或视频中间重新拉回注意力
5. **手机也可用**：拿手机拍的时候横着拿，画面拍干净就行

### ⚠️ 激光安全

**会场激光灯不要用相机或手机直接拍！会烧坏传感器，不保修！**
站在激光侧面或背对激光方向拍摄。

## SOP 2：宴会短视频脚本创作流程

**适用场景**：婚宴、生日宴、寿宴、宝宝宴等宴会视频的脚本构思

### 第一步：收集信息（接客时完成）

接到宴会订单时，跟客户聊天，收集以下信息：

| 问什么 | 为什么问 |
|---|---|
| 是谁办？（新人/宝宝/老人）多大年龄？ | 决定故事主角和情绪基调 |
| 有没有外地来的？（湖南/黑龙江/山东…） | 这是爆点——"欢迎外地老乡"天然带共鸣 |
| 家人情况（几个孩子/几世同堂/有没有老人） | 亲情故事线从这里来 |
| 客户对场地/菜品有什么特别要求？ | 需求的差异=冲突=故事 |
| 预算敏感吗？想省钱还是想排面？ | 省钱=卖点（帮客户省钱不打折面） |
| 为什么选我们家？ | 挖出真实的决策理由 |

### 第二步：找冲突点

从信息中找到「一个有故事的地方」：

**婚宴示例**：
- 男方想省钱，女方要氛围感 → 冲突：怎么两头都满意？
- 新娘是外地的，远嫁 → 冲突：父母的舍不得 vs 新人的幸福
- 新娘妈妈从下车哭到酒店 → 冲突：娘家人的情感需求

**生日宴示例**：
- 98岁老人五世同堂 → 冲突：平时难得聚齐，这一顿多珍贵
- 43岁中年得子（已有两个女儿）→ 冲突：等了十多年终于儿女双全
- 三胎宝宝周岁 → 冲突：三胎被关注，家人重视

### 第三步：把冲突变成卖点植入

**核心原则**：在讲对方故事的时候，自然地带出我们做了什么——而不是"我们有多好"。

**婚宴折中方案**：
- 女方要氛围感 → 我们提前准备了灯光、布置，一生一次不留遗憾
- 男方想省钱 → 我们用当地特产海鲜压低成本，品质不差
- 结果：既满足女方的浪漫，又照顾男方的预算

**生日宴讲究**：
- 布置思路：为什么用中式？因为老人喜欢热闹。为什么用中国红？喜庆。
- 细节展示：窗花（鱼图案寓意年年有余）、桌布、沙发套、灯笼、摆件
- 服务亮点：免费赠送鲍鱼生日面、节目表演（唱歌/跳舞/喊麦）

**宝宝宴用心**：
- 场地布置用了多长时间（48小时/24小时）
- 考虑过卫生、空气流通、安全性
- 为孩子准备的特殊环节

### 第四步：写时间线脚本

**标准时间线模板**：

| 时间 | 内容 | 画面 |
|---|---|---|
| 0-5秒 | **钩子**：抓眼球 | 人多+声音（歌声/嘈杂）+全景/大特写组合，用视觉冲击力 |
| 5-15秒 | **主角出场** | 老人/新人/宝宝特写+互动画面，旁白交代身份 |
| 15-35秒 | **讲故事** | 中景+近景，交代故事背景（怎么认识的/等了多久/多难得） |
| 35-55秒 | **卖点植入** | 布置过程+菜品准备+服务细节，展示我们做了什么 |
| 55-75秒 | **高光时刻** | 祝寿/敬酒/送礼/孩子笑——真实发生的温馨画面 |
| 最后10秒 | **收尾祝福** | 端出特色菜（鲍鱼面等）+说祝福的话，自然结束 |

### 第五步：不同类型变体

**生日宴**：钩子=歌声+人多 → 主角=老人/宝宝 → 故事=家庭 → 卖点=布置+服务 → 高光=祝寿/送礼 → 收尾=特色面

**婚宴**：钩子=司仪主持+父母落泪 → 主角=新人 → 故事=南北结合/远嫁 → 卖点=折中方案 → 高光=敬酒/拥抱 → 收尾=祝福

**宝宝宴**：钩子=孩子笑脸+嘈杂 → 主角=宝宝+父母 → 故事=中年得子/儿女双全 → 卖点=布置+省钱 → 高光=送礼+长辈慈爱 → 收尾=健康成长

### ⚠️ 即时事件的原则

**先拍后写，不要反过来。** 你不知道现场会发生什么——先按四类景别把素材拍足，回来再根据素材写脚本。

## SOP 3：选题库日常维护

### 一、六大选题角度

| 角度 | 示例 | 拍摄方式 |
|---|---|---|
| **1. 反差故事** | "8岁小孩居然会品鉴海鲜" | 拍小孩+海鲜，旁白讲故事 |
| **2. 过程展示** | 买菜→洗菜→做菜全过程 | 跟拍，从凌晨市场开始 |
| **3. 幕后故事** | 这道菜怎么研发的？换了三次配方 | 采访厨师+试吃画面 |
| **4. 客户故事** | 本周印象最深的一桌客人 | 讲真实故事，改编保护隐私 |
| **5. 知识技巧** | 怎么挑海螺？点菜怎么花到位？ | 柯老师直接讲，拍食材特写 |
| **6. 争议话题** | "升学宴到底要不要办？" | 自拍口播，抛观点引讨论 |

### 二、两个永不枯竭的素材源

**1. 前台日记**：每天记录接待了什么客人、发生了什么对话。每个客人都不一样——差别就是内容。

**2. 后厨透明化**：直播挑菜、洗海鲜、备料过程。没人看也播——直播是靠养的，董宇辉播了半年才火。

### 三、选题自检清单

每次想选题时，问自己：
1. 这条跟"为本地家庭提供餐饮+服务"有关吗？（对定位）
2. 观众看前5秒会不会划走？（审片诚实看）
3. 信息够密吗？能不能加个花字/旁白？（高效性）
4. 能不能蹭最近热点？（节气/节日/高考/入伏）
5. ���不能刺激到观众？（"你在菜市场买的比饭店贵"）

## SOP 4：差评/投诉→视频转化流程

**核心逻辑**：不是"解释自己没错"，而是"展示我们怎么解决问题"。

### 道歉视频五步法

1. **道歉开头（2-5秒）**
   - "对不起"
   - 道歉本身自带吸睛属性——观众想看热闹

2. **简短解释（5-10秒）**
   - 不是长篇甩锅。就一句："夏天量大，一筐里有那么一两颗漏网之鱼，很正常"
   - 解释完立刻进入下一步，不要陷在解释里

3. **明确补偿**
   - "那颗坏的挑出来，这盘不要钱，再送你个小菜"
   - 补偿要具体、可感知

4. **进阶：求助观众**
   - "大家有没有更好的办法？评论区告诉我们"
   - 注意带好节奏，别被评论区带跑偏

5. **延伸引出正面内容**
   - "那以后挑海螺时我们开直播？透明厨房"
   - 用一件坏事带出更多好事

### 公关引导策略

**不是等出了事再道歉，而是主动发"问题解决得好"的内容：**

拍这样的故事："菜里有虫子→撤掉重炒→送果盘→顾客非常理解"

多发这种内容，来消费的人素质会变高——别人看到"有问题解决得好"，自己没渠道闹了。

## SOP 5：客户信息收集与录音流程

### 为什么需要录音

客户说的话 = 最真实的素材。之后写脚本时，直接从录音里找故事、找细节、找需求点。脑子里记不住那么多，录音不会骗你。

### 操作步骤

1. 接客户电话时，**开免提**
2. 拿另一个手机，**打开录音功能**，对着正在通话的手机
3. 正常工作沟通——你该聊什么聊什么
4. 挂断后，录音保存。发给柯老师提取信息点

### 也可记录的信息

- 客户对菜品/场地的特别要求
- 客户的个人故事（怎么认识的/为什么选这里）
- 客户的预算和顾虑
- 当天现场的有趣插曲

### ⚠️ 注意事项

- 询问客户是否愿意出镜（有些客户不想被拍到视频里）
- 如果客户不愿意，只用文字改编故事，不出现人脸
- 拍全家福可以作为敲门砖——"给您拍张全家福顺便我们自己做个视频"

## 附录：快速查阅卡

### 拍摄参数速记

> 光圈锁2.8，ISO自动，快门50-100。拍大场面光圈调到5-8。
> 全景24mm、中景35-50、近景70、大特写微距。
> 横拍宴会，多角度切换，每段6-8秒。

### 脚本结构速记

> 5秒钩子 → 15秒主角 → 20秒故事 → 20秒卖点 → 20秒高光 → 10秒祝福

### 三句话心法

1. **先拍后写**：即时事件别倒过来，素材拍足再说
2. **在讲对方的同时卖自己**：客户故事里自然带出我们做了什么
3. **宁可多拍不可少拍**：拍多了不用没事，缺素材没办法
