## 短视频创作工作流 · 知识点手册

> 给宝岛渔村团队 · 把知识点融入工作流，每一步都知道该做什么、为什么这么做。

---

## 工作流总览

```
灵感收集 → 梳理选题 → 写文案 → 拍摄 → 剪辑 → 发布 → 复盘
   ↑                                                         |
   └────────────────── 循环迭代 ─────────────────────────────┘
```

每一步下面：先讲**怎么做**，再讲**为什么**（知识点），最后给**检查清单**。

---

## Step 1：灵感收集

### 怎么做

灵感不是"专门想出来的"，是**随时随地在日常中捡到的**。三种主要来源：

**① 日常工作里的真事**
- 今天遇到什么客人？（豪爽的、难缠的、感动的）
- 后厨发生了什么？（研发新菜、切菜比赛、食材翻车）
- 采购有什么故事？（今天挑了条特别好的鱼）

**② 互相转发的内容**
- 看到好视频转发给同事，顺带说一句"这个可以试试"

**③ 本地新闻和热点**
- 长兴岛新闻、大连本地事件、节气节日

**收集方式**：对着手机微信给自己发语音或文字。用这个模板：

> 在哪儿 + 看到/发生什么 + 有什么想法

举例："今天在后厨看到一个小孩过生日，我们十个人忙了六个小时。感觉这可以拍成故事。"

**每天日报里加入素材收集**。记一笔今天碰到的素材。

### 为什么（知识点）

灵感池就像食材库——你食材多了，才能做很多菜。

很多人第一步就做错了：没有灵感直接硬写文案。就像没买菜就硬做饭，出来的东西一定不好吃。

**灵感的第一原则：真事比编的好一百倍。** 你的日常就是最好的素材。客人说的每一句话、后厨的每一个瞬间，都比网上的模板强。

### ✅ 检查清单
- [ ] 今天有没有记至少一条灵感？（微信给自己发）
- [ ] 日报写了素材收集吗？

---

## Step 2：梳理与选题

### 怎么做

有了灵感池之后，不是每条都要拍。要看**当前账号处于什么阶段**，决定拍什么。

**先看播放量，判断账号状态：**

| 播放量 | 状态 | 该做什么 |
|---|---|---|
| <1000 | 基本不合格 | 先找出问题（钩子？画面？文案？） |
| 1000-2000 | 稳定上升期 | 保持产出，等小爆款 |
| 3000-5000 | 趋于稳定（起号） | 刺激流量出爆款——增赞、增评论 |
| 5万-10万 | 小爆款来了 | 趁热做转化——提高含金量、增加收藏转发 |

**然后从灵感池里挑选题**，看你的账号现在最需要什么：

- 需要拉新？→ 反差、故事、争议话题
- 需要收藏？→ 技巧、知识类
- 需要评论？→ 对抗性观点
- 需要转化？→ 展示后厨真实、食材标准

**选题的好坏标准**：这条视频给谁看？看完他会不会想来？

### 为什么（知识点）

**"梳理"是运营动作，不是随机抽。** 很多账号发了几十条没起来，不是因为内容不行，是因为每一期都在随机做——今天是这个风格，明天是那个风格。没有根据数据调整。

**播放量的层级是你做内容的指南针。** 就像开车——你总得看油表、看导航，不能闭着眼踩油门。

**记住这个循环**：流量回落→做稳→尝试出爆款→爆款来了做转化→流量再回落→再稳住。

### ✅ 检查清单
- [ ] 今天账号播放量在哪个层级？
- [ ] 根据层级，这条视频该做拉新还是升级？
- [ ] 选题有明确的目标用户吗？（带老人吃饭的子女 / 找生日场地的家长 / 请客的本地人……）

## Step 3：写文案

### 怎么做

**底线**：你日常不这么说话，就不要写进去。短视频是手机——手机是你跟用户做朋友聊天的工具。

#### 3.1 开头钩子

不要陈述句，要**疑问或感叹**。

| 错了 | 对了 |
|---|---|
| "我们家菜比以前好吃多了" | "妈呀，80岁老太太来我家一顿啃了三个大骨头？" |
| "我们服务很用心" | "十个人忙了六个小时，就为了一个孩子" |

**为什么**：平台考核两秒跳出率和五秒完播率。两秒时间你说不完一句话——但一个感叹、一个反问就够了。观众手一停，就留下了。

**AI辅助**：告诉豆包"我的主题是XXX，开头要用感叹或疑问，帮我出5-10个版本"。

#### 3.2 骨架（内容推进）

两种方式：

**故事型**："为了一个小孩的生日，我们十个人忙了六个小时"→ 这个需求怎么来的？→ 我们怎么准备的？→ 小孩什么反应？→ 我们家为什么对每个客人都这样？

**清单型**："来我家点宴请，必点这三道菜"→ 第一道……→ 第二道……→ 第三道……

**关键**：持续给观众"下一句说什么"的期待，别让他滑走。

#### 3.3 互动植入

写文案的时候就设计好：观众看完会点赞吗？会评论吗？会收藏吗？会转发吗？

| 想要什么 | 怎么植入 | 餐饮例子 |
|---|---|---|
| **点赞** | 正能量 | "这个儿子特别孝顺，每次妈妈过生日都来我们这" |
| **评论** | 对抗点、争议点 | "老人过生日，该花钱摆排面还是直接给钱？" |
| **收藏** | 技巧、知识 | "大厨教你一道消暑菜，两步就搞定" |
| **转发** | 社交货币 | "男的记住：每周得给媳妇准备这样一道菜" |

**先独立后综合**：一开始不要追求一条视频四个维度都强。先学会做好一个——比如先做收藏型（教做菜），等数据稳了再加。

#### 3.4 写得像人话

**具体化示范**：

| 不要说 | 要说 |
|---|---|
| "厨师长反复研发了这道菜" | "厨师长带着后厨20个人试了36次，我们最近一直在吃锅包肉，快吃吐了" |
| "食材非常健康" | "我们的菜是老板凌晨四点去市场挑的。这块肉你摸一下，是这样的手感" |

**想显得有文化？** 说一句高级的，立刻用具体话解释。参考《舌尖上的中国》——"传统的美食往往需要最朴素的烹饪方式"→ 然后开始讲今天怎么做的。

**不要陷太深**：你在讲"烹饪火候标准"——观众（食客）只关心一件事：这道菜放我嘴里好不好吃、健不健康、卫不卫生。说卫生标准（"95度蒸汽消毒""案板每天怎么收拾"）比说火候标准有用得多。

### 为什么（知识点）

**竖版视频观众是随机刷到的，没有耐心。** 所以：
- 钩子（前两秒）：让他停住
- 骨架（中间）：让他看下去
- 情绪（全程）：让他互动

不是平台在"考核"你，是观众在用手指投票。两秒跳出率、五秒完播率、停留时长、互动率——这些就是观众的"脚"和"嘴"。

**文案的核心不是文采，是真诚。** "我们最近一直在吃锅包肉，快吃吐了"——这句话比一百句"精益求精"都有力量。因为这是人话。

### ✅ 检查清单
- [ ] 开头是疑问或感叹吗？（不是陈述句）
- [ ] 骨架推动情节了吗？（不是流水账）
- [ ] 设计了至少一个互动点吗？（点赞/评论/收藏/转发选一个）
- [ ] 大声念一遍——像人话吗？（不像就改）

## Step 4：拍摄

### 怎么做

**新手先拍竖版。** 竖版拍好了，基本不用管排版。

**画面设计**：先有文案再设计画面——文案说"食材源头把控"，就放采购画面；说"好品质的菜"，就放菜品特写。不要凭感觉乱插画面。

| 拍什么 | 在哪拍 |
|---|---|
| 讲菜品升级 | 去后厨！背景是一排炒菜的锅 |
| 讲食材 | 跟拍采购 / 后厨备菜 |
| 讲服务 | 大厅实景 / 宴会布置 |
| 讲真实日常 | 随手拍·真实即可 |

**曝光**：人物主体要亮。后厨光线暗就补光或调ISO。看直方图，稍微偏右。

**声音**：后厨吵→麦克风开降噪（绿灯）；环境安静→正常夹领口。

**镜头恐惧**：不用担心，多拍几次就习惯了。把镜头想象成你在跟一个朋友说话。

**一次拍多条**：灵感池够多的话，一上午或一下午能拍5-7条。保证日更，不用老拍。

### 为什么（知识点）

**横版 vs 竖版的核心区别**：

- 横版：观众要横过手机看 → 已经准备好了 → 含金量必须足（电影解说、干货、PPT）
- 竖版：观众随机刷到 → 随时可能划走 → 钩子要快、画面要抓人

**把手机屏幕当画板**：上下空间不要浪费。上面放标题，下面放字幕或食材特写——信息都放进去。

**新手先拍竖版。** 审美控制不好不要搞花活。

### ✅ 检查清单
- [ ] 场景跟文案匹配吗？（讲后厨就在后厨拍）
- [ ] 人物脸上的光够亮吗？（不够就补灯）
- [ ] 声音清楚吗？（吵就开降噪）
- [ ] 背景有信息吗？（空的墙不如热闹的后厨）

---

## Step 5：剪辑

### 怎么做

**前期比剪辑重要。** 如果前面设计好了——有A库（文案脚本）和B库（画面素材）——剪辑就是拼图。根据A插入B，加上音乐。

**节奏**：抖音热歌 + 画面切换快。不让观众有空隙划走。

**外包选项**：后期可以外包剪辑。市场价80-120元一条，量大（300以内预算）能压到50元/条。但前提是——你们自己先学会内容设计和文案。剪辑只是整个工作流的六分之一，前面的灵感、梳理、文案才是核心。

### 为什么（知识点）

**剪辑不是"修修补补"，是"组装"。** 如果你的素材池不够、设计没做好，剪辑再厉害也没用。

### ✅ 检查清单
- [ ] A库（文案）+B库（画面）都准备好了吗？
- [ ] 画面切换跟得上文案节奏吗？

---

## Step 6：发布与复盘

### 怎么做

**发布**：标题+话题标签+POI（抖音来客挂位置）。

**复盘**：发布后看数据。本地视频生命周期7天，一般看前3天就知道大概。

对照数据反推文案：
- 两秒跳出率高 → 钩子不行
- 五秒完播率低 → 钩子之后没接住
- 完播率低 → 骨架没推动情节
- 互动低 → 没植入互动点
- 播放量<1000 → 整体检查：是不是画面太暗？声音听不清？选题没意思？

**复盘→改进→下一条**。每条视频都是上一条的升级。

### 为什么（知识点）

**数据是裁判，不骗人。** 你觉得拍得很好，数据说不行——那就是不行。回到工作流里找哪一个环节出的问题。

### ✅ 检查清单
- [ ] 挂POI了吗？
- [ ] 三天后看了数据吗？
- [ ] 下一条改了上一条的问题吗？

## 专题：账号矩阵策略

### 不要把所有鸡蛋放一个篮子里

按部门起号，每个号做不同的事，最后流量汇聚到主号：

| 账号 | 内容方向 | 频率 |
|---|---|---|
| **接待部/公关部** | 读好评读差评、和观众互动、活动策划 | 每周1-2条 |
| **服务部** | 每场宴会的幕后故事（谁、什么需求、我们怎么做） | 来大单就拍 |
| **后厨** | 厨师才艺（颠勺、切菜）、菜品研发过程、备菜日常 | 随时拍 |
| **采购部** | 老板/采购挑菜的标准：怎么挑肉、挑海鲜、挑蔬菜 | 去采购就拍 |
| **企业蓝V** | 官方号，所有子号在简介里@主号 | 汇总转发 |

**读差评怎么玩**：选无关紧要的差评（地板脏、摆放不好看）→ 展示 → 告诉观众我们怎么改的。观众会觉得你很真实、很听劝。

**时间线**：严格执行两个月。素材收集加入日报，每天积累。两个月后看看数据。

## 专题：AI辅助创作

### 豆包怎么用

**前提**：你得先知道知识（什么是钩子、什么是骨架、什么能引发评论），才能用好AI。AI是你知道路之后帮你开车的，不是你不认路时替你开车的。

**常用提问模板**：

1. 想钩子：*"我的主题是XXX，开头要用感叹或疑问。帮我出5-10个。我是做餐饮的。"*
2. 想评论：*"我拍了条XXX内容的视频，效果不错。接下来想提升评论量。抖音餐饮类什么话题评论多？出几个方案。"*
3. 想收藏：*"想做一些数据均衡的选题。美食餐饮类，什么样的选题数据比较均衡？"*
4. 改文案：*"把这个文案改得像人说话。去掉书面语。按这个标准：你日常不这么说话就不要写进去。"*

不满意就让他换，直到拿到合适的。

## 总检查清单（每次发视频前过一遍）

**内容**
- [ ] 灵感来自真实日常（不是网上抄的段子）
- [ ] 选题有明确目标用户（不是"谁来都行"）
- [ ] 账号当前层级决定了这条视频做什么（拉新/升级）

**文案**
- [ ] 开头是疑问或感叹（不是陈述句）
- [ ] 骨架是故事型或清单型（推动情节了）
- [ ] 互动点至少设计了一个（点赞/评论/收藏/转发）
- [ ] 读起来像人话（不像新闻稿）

**拍摄**
- [ ] 场景匹配文案（讲后厨就拍后厨）
- [ ] 光线够亮、声音清楚
- [ ] 竖版/横版选择有理由

**发布**
- [ ] 三天后看了数据

---

> 记住：这套工作流不是"做完一次就完了"，是**每一次都在上一次的基础上进步**。
> 灵感池越做越大、素材库越来越丰富、对数据的判断越来越准
