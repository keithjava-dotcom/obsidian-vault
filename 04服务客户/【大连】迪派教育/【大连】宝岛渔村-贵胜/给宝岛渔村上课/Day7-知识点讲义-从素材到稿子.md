# Day7 知识点讲义 · 从无聊素材到值得看的稿子

> 主线一句话：**素材是砖头，角度是图纸。** 砖头堆一起是工地，按图纸砌才是房子。
> 三个模块串成一句话：**角度定方向，骨架定节奏，文字定血肉。**

---

## 模块一：选题角度——素材是砖头，角度是图纸（核心·40分钟）

### 1.1 先搞明白：素材和角度是两回事

| | 素材 | 角度 |
|---|---|---|
| 是什么 | 记录：有什么拍什么 | 表达：带着判断去看 |
| 例 | 菜、环境、老板、顾客、聚会 | "同学聚会没人想去，不是因为忙，是因为比" |
| 问题 | 拍完了，不知道讲什么 | 有了它，素材才会活 |

**判定一句**：这个角度换一份别的素材还成立吗？成立=没找到角度，只是复述（还停留在"话题分类"，比如"从餐饮的角度讲"——换任何饭店都成立，不是角度）。

### 1.2 角度从哪来：六字真言（正·反·和·跨界·入·弱）

| 字诀 | 意思 | 渔村/聚会例子 |
|---|---|---|
| **正** | 直接碾压：细分 | 别人教全部，你教一块——渔村拍"海鲜怎么挑，饭店不告诉你的三招" |
| **反** | 对抗市场主流：所有人都这么拍，你反着干 | 所有人拍"聚会真好"，你拍"同学聚会为什么越来越没人想去" |
| **和** | 交叉优势：一个小众价值+一个大众价值 | 餐饮+情感："AA制的同学聚会，藏着成年人的体面" |
| **跨界** | 打包能力换赛道 | 把选菜的本事讲成"选人"？把待客之道讲成做人的道理 |
| **入** | 借助外部资源 | 借节日/借热点：毕业季、开学季、年底聚会季 |
| **弱** | 以弱胜强：拿短板做内容 | 小店、后厨忙乱、老板的笨功夫——真实感就是武器 |

要点：
- **90%的创新靠组合**（和字诀最容易出效果）
- **反字诀最出效果，也最容易翻车**——为反而反=抬杠；要有真判断撑着
- 弱字诀最贴合渔村：不装大店，把"真实"做成风格

### 1.3 三个提问：把无聊素材切出角度（操作步骤）

1. **反常点**：素材里最不像平常的是什么？（聚会上没人玩手机？当年的班长一句话不说？）——反常才有钩子。注意：反常≠反差，是"熟悉中的陌生"
2. **判断/不服气**：你对这件事最想反驳的一句话是什么？——那句话就是角度
3. **观众咯噔点**：观众看到哪一秒，心里会动一下？（情绪触点：点赞/评论/收藏/转发/关注，点不一样，写法不一样）

### 1.4 角度自检三连（写完角度问三句）

- 换一份素材还成立吗？（成立=复述，重找）
- 有没有"判断"在里面？（没有=还在记录）
- 观众的反应是"哦？"还是"哦"？（哦？=有钩子；哦=平平）

### 1.5 课堂演示：同学聚会作业的三个角度（现场用）

从同一堆"无聊素材"（吃饭/合影/敬酒/聊天）切出：

**角度A（反）**：同学聚会越来越没人想去——不是因为忙，是因为比。
开头："毕业十年，同学聚会一年比一年人少。不是大家忙，是大家怕。"

**角度B（和）**：AA制的同学聚会，藏着成年人的体面。
开头："成年人的聚会，从AA制开始，才是真体面。"

**角度C（戏剧）**：毕业十年，混得最差的那个，反而最忙。
开头："昨天同学聚会，混得最差的那个，全场最忙——他一直在给大家倒酒。"

演示方法：先让学生看素材（都一样），再亮三个角度，问"哪个想看完？"——让他们自己体会：素材没变，变的是看它的眼睛。

## 模块二：骨架6种推进——角度定方向，骨架定节奏（30分钟）

### 2.1 为什么先讲骨架

- **99%没数据的原因不是情绪刺激不够，是骨架**（骨架优先级高于一切修饰）
- 骨架=这条视频怎么"走"，不是模板。钩子/骨架/情绪是"成分"不是"环节"——可以叠加，可以在任何位置出现

### 2.2 六种推进（每种：是什么/适合啥/要领/聚会例子）

**① 兴趣点推进**（一切骨架的根本）
- 是什么：信息/事件/卖点/生活切片，一个个抛
- 适合：素材是"一堆好东西"时（菜单、流程、场景）
- 要领：颗粒度（每道菜一个镜头，别一桌菜一个镜头）；N+1情绪预埋（每讲一个点，埋一个"下一点是啥"的钩子）；**语速快≠节奏快**
- 聚会版：报菜名式——但聚会用这个=流水账，慎选

**② 戏剧性推进**（案例/经历）
- 是什么：构建期待→设置障碍→新信息重构剧情
- 适合：素材里有一个"事"（意外/变化/冲突）
- 要领：**关键场面必须释放，宁可过火不可不及**
- 聚会版："他迟到了两小时，进来先干了三杯"——期待（他咋了）+障碍（气氛尴尬）+重构（他刚离婚）

**③ 共鸣性推进**（情感/立场）——聚会首选
- 是什么：从凑热闹到逐步共鸣
- 适合：情绪类、情怀类
- 要领：**从凑热闹到逐步共鸣，反过来必死**（不能上来就"我们都懂"）；具象为主、抽象为辅；三步一喘息；**是我们共鸣观众，不是要求观众共鸣**
- 聚会版：热闹敬酒→聊到谁妈住院→全场安静→"聚的不是饭，是那段回不去的日子"

**④ 理性逻辑推进**（观点争议）
- 是什么：二元对立：**先真扮演反方**，再头也不回走认同方；认知碾压：讲在"似懂非懂之间"
- 适合：有观点、有争议
- 聚会版："有人说聚会就是浪费钱——对，如果只是吃饭的话。但聚会买的不是饭，是照镜子。"

**⑤ 节奏型推进**（入手最容易，上限最高）
- 是什么：卡点/排比/押韵/长短句
- 适合：混剪、快节奏成片
- 要领："内在的气"和押韵看天赋，不强求

**⑥ 销售型推进**（成交视频）
- 是什么：全程为"让观众行动"服务
- 适合：直接引到店、引到订餐
- 注意：营销视频和成交视频二选一，别夹中间（又讲情怀又要下单=两头空）

### 2.3 怎么选推进（给学员的操作）

1. 你的素材是什么类型？
   - 经历/案例 → 戏剧性
   - 情感/立场 → 共鸣性
   - 观点/争议 → 理性逻辑
   - 清单/枚举 → 兴趣点
   - 成片混剪 → 节奏型
2. 一个骨架可以主+辅叠加（例：共鸣性为主，中间穿插兴趣点保持信息量）
3. 同学聚会作业：**首选共鸣性或戏剧性**；选了兴趣点=报菜名，选了销售型=拍成广告

### 2.4 收尾三心法

1. **过程比结果重要**："别告诉我聚会很开心，带我经历一遍"——写"老三抱着酒瓶子哭"，不写"大家都很感动"
2. **构建势能不要蔓延**：情绪单向推高，到最后一刻才释放；别中途泄气
3. **不同行为情绪阈值不同**：点赞最容易、转发最难——别把最难的要求（转发）硬放在最后喊

### 2.5 进阶备用：两结构+三补法

- **清单式**（并列小点拼整体，默认）vs **发展式**（本以为A→否定→B→C螺旋上升）
- **三补法**（讲不动时）：向下细分（一道菜→做法→火候）/ 向上汇总（化妆讲不动→上升到变美）/ 向内折叠（放大镜抠细节）

## 模块三：文案优化进阶——骨架有了，字要配得上（20分钟）

### 3.1 回顾Day6公式（30秒带过）

细节 / 冲突 / 口语 + 七秒原则 + 三段论——作业已用上，今天往上叠四层。

### 3.2 进阶一：叙述变场景（过程>结果）

- 病句："大家都很开心""气氛特别好"——总结句，观众无感
- 改法："老三抱着酒瓶子哭，谁劝都不撒手"——谁+做了什么+什么反应
- 规则：删掉所有"形容词+名词"的总结，换成具体的人和动作
- 现场练：把作业里最"总结"的一句，当场改

### 3.3 进阶二：对抗轴（每段在跟什么较劲）

- 一段话必须有个对抗：人与人 / 人与内心 / 人与世界 / 人与众人
- 答不出"这段在跟什么较劲"=死段，删或改
- 例：敬酒这段在跟什么较劲？——跟"生疏"较劲：多年不见，举杯是为了打破尴尬
- 例：拍后厨在跟什么较劲？——跟"看不见"较劲：客人只看见菜，看不见汗

### 3.4 进阶三：信息密度（1分钟6-8个独立信息点）

- **先做加法**：所有想讲的点全列出来（哪怕10个，最后只用3个）
- **再做减法**：逐句删，删了不影响看懂的就删——重复3轮
- 注意：密度≠语速快；"不能只有密度，没有总量"（全是干货没有信息量也不行）

### 3.5 进阶四：结尾一句话就停

- 禁："点赞收藏关注""希望对你有帮助""大家觉得呢"——观众出戏
- 对：抛一句让观众心里翻江倒海的判断，然后停
- 例："同学聚会，见的不是同学，是当年的自己。"——停
- 判断标准：这句话如果是哥们对你说的，你会不会沉默一下？会=对了

## 课堂流程建议（知识部分约90分钟）

- 开场5分钟：作业收上来，每人报一句自己脚本的"主题"，先不细评
- 模块一40分钟（核心，演示三个角度花足时间）
- 模块二30分钟（六种推进逐个过，聚会例子现用）
- 模块三20分钟（四层进阶，现场改一句）
- 收口一句话：**角度定方向，骨架定节奏，文字定血肉**

## 作业指导衔接（知识部分结束直接接）

每人脚本过三关，顺序跟知识顺序一致（学员拿着工具自己也能评）：
1. **角度关**：你的脚本有没有"判断"？还是只是记录？→ 没有就回到模块一
2. **推进关**：你的脚本是哪种推进？适合吗？（聚会稿应选共鸣性/戏剧性）→ 选错就换骨架
3. **文字关**：有没有总结句没场景化？每段跟什么较劲？结尾是不是一句话就停？→ 逐句改
