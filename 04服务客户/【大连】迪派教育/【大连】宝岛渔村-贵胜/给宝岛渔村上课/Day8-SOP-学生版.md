# 宝岛渔村 · Day8 实操SOP（学生版）

> 主题：剪辑流水线 + 封面制作 + 服务行业选题
> 用法：每条SOP照顺序做就能出片；参数表贴电脑旁边当速查。

---

## 这节课带走的三句话

1. **剪辑就一条流水线**：剪主线 → 素材分类 → 插画面 → 加字幕 → 上花字。顺序别乱，第一个片子慢（40分钟），后面越来越快。
2. **不会编故事就用清单法**：把店里真实发生的事列成"让服务员崩溃的六个瞬间"，一条一个，每条不超过10秒。
3. **结尾必须正能量**：先放无理的画面，最后收在正能量上——视频是给观众看的，不能放任负能量。

---

## SOP 1：剪辑五步流水线（剪映，照顺序做）

| 步骤 | 做什么 | 要点 |
|---|---|---|
| ① 剪主线 | 只剪口播主线这一条 | 别管别的素材，先剪完主线；第一条慢（40分钟），后面心流越来越快 |
| ② 素材分类 | 日常拍的素材按四类归档 | 菜 / 顾客 / 服务人员 / 后厨 |
| ③ 插画面 | 把分类好的素材插进主线 | 说哪放哪，画面跟话走 |
| ④ 加字幕 | 字幕加完 | 到这一步片子完成 70% |
| ⑤ 上花字 | 看画面感觉补花字注释 | 花字是点缀，别抢字幕 |

**出片自检清单**
- [ ] 主线口播剪完了
- [ ] 画面跟话对上
- [ ] 字幕齐了
- [ ] 前后两段内容之间有转场衔接
- [ ] 图形没挡住画面（注意图层/遮挡）

## SOP 3：封面制作五步

1. **导出关键帧**：文件 → 三个点 → 导出关键帧 → 存进新建文件夹（得到一张图）
2. **抠出人物**：封面复制一层 → 智能抠像把人抠出来 → 剩下就是背景
3. **点掉字幕**：把屏幕字幕点掉，得到没字幕的照片
4. **切竖版**：格式调竖版——横版视频，封面也是竖版
5. **AI补背景**：没拍到的画面用AI生成，给AI提要求——"宝岛渔村"的字大一些、活泼一些、表情微笑、饭店带点欧式

**AI实操路线**：国外大模型国内访问不了，最省事的做法是——做好版面 → 把版面发给豆包 → 豆包按你的版面出图。
- 人物永远在最顶层，其他都是背景
- 封面定稿：识别不出来时按 **O键** 导出

## SOP 4：拍摄三招（拍的时候直接用）

| 招 | 怎么做 |
|---|---|
| 离远+广角 | 画面再离远一点拍，镜头调广角 |
| 平移运镜 | **相机不动，身子动**——沿机位线平移，画面质感更好；手持尽量稳 |
| 特写+环境音 | 全景中景之外加特写，冲击力更强；环境音留一点更真实，全处理干净反而假 |

- **多拍备料**：菜品等画面没拍到就补拍；拍得好看就先拍着，说不定哪天用上
- **竖版优先**：刚开始尽量拍竖版——观众看横版要把手机横过来；稳定器拍竖版把相机竖过来就行（快拆板可以竖过来，问京东客服要竖版教程）
- **雨景**：等下场雨拍，或者无人机喷水模拟

## SOP 5：选题清单法——"让服务员崩溃的六个瞬间"

**原则**：不会编故事就用清单法——把真实发生的事列出来，瞬间一、瞬间二……瞬间六。真实的事本身就是矛盾点，必然引发讨论。

### 你们的真实素材库（数字和细节都是你们店里的真事，直接用）

| #   | 瞬间   | 细节（素材）                                                            |
| --- | ---- | ----------------------------------------------------------------- |
| ①   | 例会被骂 | 四点开例会、跳健身舞，顾客瞅着骂"一群近视眼"                                           |
| ②   | 叫阿姨  | 30来岁女士被20岁小伙叫"阿姨"，顾客不依不饶"你侮辱我人格"，鞠躬道歉也不行，老板赔了200块平息               |
| ③   | 挑刺   | 13个菜加工费事件：一个菜加工费30、二斤的40-50；当天收加工费400，总消费780；房间平时卖1000，带食堂的菜来还嫌收费 |
| ④   | 必须打折 | "我家没有折扣，唯一折扣是会员九五折"；1388套餐砍价"不就1380嘛"也不行——菜量给最大，价钱一分不折            |
| ⑤   | 过分要求 | 蛋糕事件：奶油蛋糕造型一动就坏，服务员不能拿；顾客骂"泼妇"要求处置服务员                             |
| ⑥   | 醉酒骂人 | 安慰服务员话术："朵朵，你别难过。他像疯狗一样咬你，难道你也咬他吗？他那么没素质，我们就要做有素质的人。"             |

## SOP 6：六个瞬间怎么拍（每条不超过10秒）

1. **录原声**：当场把骂声录下来——骂声就是素材（脏话屏蔽掉）
2. **演一下**：拍自家服务员内心无奈的表情，把你的声音加进画面
3. **内心独白**：服务员不出声、不说话，配内心独白
4. **旁白**："大家不要总是一喝点酒就去骂服务员，服务行业跟这个是不一样的。"
5. **画面设计**：服务员站桌前拿托盘看向对方，下面打一行字"让服务员崩溃的一个瞬间"；外面是嘈杂的骂声，最后正能量台词说出来
6. **每条不超过10秒**
7. **结局必须正能量**：先放无理画面，最后收在正能量上——同时引导观众：称呼可能不是那样，醉酒骂人我们是这么应对的
8. **称呼玩梗收尾**：不叫阿姨，叫妹妹、叫老妹儿——搞笑收尾

## SOP 7：内容公式五法（选题定方向）

| 方法 | 做法 | 用你们的案例 |
|---|---|---|
| ① 细分 | 把各种情况1到6逐一罗列+解决 | "六个瞬间"本身就是细分 |
| ② 反着来 | 开头反问"凭什么服务行业就该挨骂？"→ 讲观点讲理由 → 结尾呼吁 | "服务员到底应该被骂吗？" |
| ③ 并置（透过动作看本质） | 一件小事上升为人品/做人 | 骂人不尊重别人的人，做生意、生活里也难成功——把矛盾事件上升为教做人做事 |
| ④ 借热点 | 借节日、借当地习俗 | 立秋、开海季——开海后海鲜更便宜、冬季菜品更新鲜，展示质量 |
| ⑤ 以弱胜强 | 把吃亏的事讲精彩 | 老板被顾客骂了，最后老板倒贴200块——体现老板实诚、人品好 |

**封面很重要**；从日常琐碎素材里把故事提炼出来。

### 选题四角度（六个瞬间能拍6-7期）

- **细数型**："这一周我被顾客骂了五次""这几个月我见了八种人"
- **对抗反驳型**："服务员到底应该被骂吗？""我们到底应不应该收那个钱？"——自带讨论度
- **透过现象看本质**：一个具体事件，上升为更深的社会现象——既为一群人发声，也教育另一群人
- **罗列评理**：罗列类似事件，让观众评理、思考——自带热点

## SOP 8：完播三技巧（让观众看完）

| 技巧 | 做法 |
|---|---|
| 信息颗粒度 | 清单内容一点一点推进，让观众有明显分节的感觉——每个瞬间7秒就看完了，一口气说完观众就滑走 |
| 戏剧性推理 | 先给期待（一次准备20桌婚宴），再摆阻碍（食材没了、调料没了）——阻碍越多越想看结尾；像唐僧取经，一个筋斗云取回来就不好看了 |
| 共鸣 | 从凑热闹到共情——让观众在故事里看到自己（程序员被自己写的系统坑了去跑外卖；十几岁出来打工的服务员） |

## SOP 9：两种口播风格

- **逻辑底线型**（理性、讲道理）：一环扣一环往下走——"为什么必须吃这道菜？原理是什么？"理清逻辑，一步一步走
- **节奏型**（押韵排比、生活流）：像东北那个节奏型口播博主，把声音关掉不知道他说什么，但有节奏就看得下去；**有了AI之后这个特别简单——原则、技巧，AI都能给你编排**

**口播是最简单、高效且最有用的一种方式**：把事说出来就行；演也行——把画面演一下，演完再说这个事。不需要分镜头。

## SOP 10：每周内容工作法 + 账号策略

### 集中选题法

1. 每周回顾近7-10天，罗列3-5个选题（可以混几个短段子/博流量的）
2. **集中2-3小时什么都不干，只想内容** → 得到6-10条选题
3. 找一个下午，把10条主线全开了——第一条慢（40分钟/半小时），后面越来越快
4. 日常随手拍B-roll，集中拍主线，集中剪——一天顶多一下午安排视频
5. 工作量太大，也可以找人专门干剪辑

### 内容配比

- **人设成交型**：讲后厨买食材的过程、食材新鲜、老板良心——细腻，看着人少，但人设需要
- **博流量段子型**：鸡汤励志博流量
- 一个账号全是段子会枯燥，两类结合：用段子的流量做转化——"我看你的段子，很难为你付费一万；但你讲你有多良心、讲你的案例、讲你为这次宴会做的准备，我可能会为你付费几万。"

### 账号策略（蓝V）

- 蓝V＝告诉平台"我要做生意了"：不花钱可能限流，平台会诱惑你投流
- **账号别全用蓝V**：蓝V和普通号搭配，各自发挥优点
- 平台不让挂品的，就留资——留电话、加微信
