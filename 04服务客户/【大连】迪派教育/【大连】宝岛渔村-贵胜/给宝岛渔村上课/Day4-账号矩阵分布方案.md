## 宝岛渔村 · 账号矩阵分布方案

> 柯建军承诺出品 · 给贵胜团队

---

### 核心理念

**不要把所有鸡蛋放一个篮子里。**

一个饭店里每天发生的事足够支撑多个账号。与其在一个号上赌，不如按部门分开起号——每个号做不同的事，最后流量汇聚到主号。

---

### 账号分布

#### 1. 企业蓝V（主号）

| 项目 | 说明 |
|---|---|
| **定位** | 官方门面，品牌大本营 |
| **内容** | 汇总转发子号爆款内容；发布官方活动、节日营销、品牌故事 |
| **频率** | 每周1-2条 |
| **运营要点** | 所有子号在简介里@主号 → 流量汇聚 |

#### 2. 接待部 / 公关部

| 项目 | 说明 |
|---|---|
| **定位** | 拓客+维护客户关系 |
| **内容** | ① 读好评读差评和观众互动 ② 活动策划记录 ③ 节日营销幕后 |
| **频率** | 每周1-2条，一周两小时能搞定 |
| **运营要点** | 差评选无关紧要的（地板脏、摆放不好看）→ 展示并告诉观众怎么改了；好评认真读、和观众互动 |

#### 3. 服务部

| 项目 | 说明 |
|---|---|
| **定位** | 讲客户故事，体现企业文化 |
| **内容** | 每场宴会/订餐/聚会背后的故事——谁来、什么需求、我们怎么满足 |
| **频率** | 来大单就拍（跟拍记录，无需额外策划） |
| **运营要点** | 化名保护客户隐私；故事公式：需求→挑战→我们做了什么→结果 |
| **选题示例** | "一个儿子为妈妈准备生日宴，提出了三个要求"、"小孩过生日，十个人忙了六个小时" |

#### 4. 后厨

| 项目 | 说明 |
|---|---|
| **定位** | 展示真实、建立信任 |
| **内容** | ① 厨师才艺（颠勺、切菜、摆盘，十几秒就够）② 菜品研发过程 ③ 备菜日常 ④ 大厨教做菜（收藏属性） |
| **频率** | 随时拍，日常收集；每周稳定出1-2条 |
| **运营要点** | 不追求精致，越真实越好；观众想看的是"后厨到底是什么样" |
| **选题示例** | "今天厨师长教你一个消暑菜，两步搞定"、"凌晨后厨备菜现场" |

#### 5. 采购部

| 项目 | 说明 |
|---|---|
| **定位** | 健康安全背书 |
| **内容** | ① 老板/采购挑菜的标准 ② 去市场全过程跟拍 ③ 食材前后对比 |
| **频率** | 去采购就拍（每周至少跟拍一次） |
| **运营要点** | 展示"挑剔"——对食材越挑剔，观众越放心；对比技巧（"教你三招挑海鲜"）天然收藏属性 |
| **选题示例** | "凌晨四点，老板亲自去市场挑菜"、"买海鲜记住这三招就够了" |

---

### 执行建议

**负责人分配**：每个部门指定一人负责。不需要专门拍——日常工作里顺便记录素材。比如采购去市场就拿手机边买边拍，后厨备菜就架手机在旁边录。

**素材收集嵌入日报**：每天日报里加一行——今天拍了什么素材。

**起步顺序**：
- 先启动后厨号（素材最容易积累，视觉冲击强）
- 再启动采购号（跟拍简单，信任感强）
- 接待部和服务部需要故事积累，可以先收集再集中产出

**时间线**：严格执行两个月。第一个月跑通流程，第二个月看数据调整。

**平台**：以抖音为主。所有号挂POI（地点定位），覆盖本地搜索流量。

### 技术配置

| 项目   | 说明                             |
| ---- | ------------------------------ |
| 拍摄设备 | 手机（够用）                         |
| 收音   | 麦克风（后厨必须开降噪）                   |
| 剪辑   | 剪映，如需外包，后期可外包（市场价：80-120元/条）   |
| 账号注册 | 各用各的手机号注册，不要一台手机切号（容易被平台判定营销号） |
| POI  | 所有视频发布时挂"宝岛渔村"地点               |
