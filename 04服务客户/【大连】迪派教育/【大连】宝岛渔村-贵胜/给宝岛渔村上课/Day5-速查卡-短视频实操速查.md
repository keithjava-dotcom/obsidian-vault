# 宝岛渔村 · 短视频实操速查卡

> 每天开工前扫一眼。宴会型餐饮账号从拍到发，全部操作要点都在这里。

---

## 一、拍摄参数速记

### 设备出发前检查
- 相机：电池满电、存储卡空间充足（建议1T卡）
- 手机：备作辅助机位，确认存储空间
- 三脚架/稳定器：长时间拍摄防抖

### 相机参数

| 场景 | 光圈 | ISO | 快门 |
|---|---|---|---|
| 室内人物/菜品 | 2.8（锁死不动） | 自动（暗光可拉到12,800） | 50-100 |
| 拍全家福/大空间 | 5-8（光线差到9-11） | 自动 | 50-100 |

### 四类景别取景清单

| 景别 | 焦段 | 拍什么 | 怎么拍 |
|---|---|---|---|
| 全景 | 24mm广角 | 场地全貌、门口迎宾、整体环境 | 每段6-8秒，从室外拍到室内，多走几个角度 |
| 中景 | 35-50mm | 人物半身动作：主持人讲话、宾客互动 | 拍半身，跟动作走。一个人物拍完立刻转拍另一个 |
| 近景/特写 | 70mm+ | 侧脸、手部、话筒、嘴角、观众表情 | 观察谁在干嘛——听得认真的、小孩笑的、两人说话的，全部抓 |
| 大特写 | 微距/拉近 | 菜品、摆件、餐具、窗花、灯笼、食材 | 让物体占画面2/3，色彩和细节第一 |

### 拍摄心法
1. **多角度切换**：别举着机器站一个地方不动。拍完主持人→转过来拍观众→再拍菜品，来回切
2. **全景+大特写组合**：一大一小对比，放开头抓眼球，或视频中间拉回注意力
3. **横屏拍摄**：宴会类建议横拍（画面更广、显档次）。横屏用户把手机横过来，就得给值的内容
4. **手机横着拿**：拿手机拍就横着拿，画面拍干净就行
5. **宁可多拍不可少拍**：每段至少6-8秒，拍多了不用没事，缺素材才麻烦

### ⚠️ 激光安全
会场激光灯不要用相机或手机直接拍！会烧坏传感器，不保修！
站激光侧面或背对激光方向拍摄。

## 二、宴会脚本时间线

### 标准结构

```
前5秒   钩子：人多+声音（歌声/嘈杂）+全景/大特写组合，视觉冲击力抓眼球
5-15秒  主角出场：特写+互动画面，旁白交代身份
15-35秒 讲故事：中景+近景，怎么认识的/等了多久/多难得
35-55秒 卖点植入：布置过程+菜品准备+服务细节，展示我们做了什么
55-75秒 高光时刻：祝寿/敬酒/送礼/孩子笑——真实发生的温馨画面
最后10秒 收尾祝福：端出特色菜（鲍鱼面等）+说祝福的话，自然结束
```

### 三类宴会变体

**生日宴**：钩子=歌声+人多 → 主角=老人/宝宝 → 故事=家庭团聚 → 卖点=中式布置+免费鲍鱼面 → 高光=祝寿/送礼 → 收尾=特色面

**婚宴**：钩子=司仪主持+父母落泪 → 主角=新人 → 故事=南北结合/远嫁 → 卖点=折中方案 → 高光=敬酒/拥抱 → 收尾=祝福

**宝宝宴**：钩子=孩子笑脸+嘈杂 → 主角=宝宝+父母 → 故事=中年得子/儿女双全 → 卖点=48小时布置+省钱用心 → 高光=送礼+长辈慈爱 → 收尾=健康成长

### 即时事件铁律
**先拍后写，不要反过来。**
你不知道现场会发生什么——先按四类景别把素材拍足，回来再根据素材写脚本。

## 三、信息收集问题表（接客时完成）

接到宴会订单时，边聊边记：

| 问什么 | 为什么问 |
|---|---|
| 是谁办？（新人/宝宝/老人）多大年龄？ | 决定故事主角和情绪基调 |
| 有没有外地来的？（湖南/黑龙江/山东…） | 这是爆点——"欢迎外地老乡"天然带共鸣 |
| 家人情况（几个孩子/几世同堂/有没有老人） | 亲情故事线从这里来 |
| 客户对场地/菜品有什么特别要求？ | 需求的差异=冲突=故事 |
| 预算敏感吗？想省钱还是想排面？ | 省钱=卖点，帮客户省钱不打折面 |
| 为什么选我们家？ | 挖出真实的决策理由 |

### 录音操作
1. 接客户电话时开免提
2. 拿另一个手机开录音功能，对着正在通话的手机
3. 正常聊——你该聊什么聊什么
4. 挂断后录音保存，发给柯老师提取信息点

客户说的话 = 最真实的素材。脑子记不住那么多，录音不会骗你。

### ⚠️ 出镜确认
询问客户是否愿意出镜。不愿意的只用文字改编故事，不出现人脸。
全家福可以作为敲门砖——"给您拍张全家福顺便我们自己做个视频"。

## 四、卖点植入公式

### 核心原则
**在讲对方故事的时候，自然地带出我们做了什么——而不是"我们有多好"。**

### 婚宴示例：折中方案=卖点
- 矛盾：男方想省钱，女方要氛围感（灯光+布置）
- 方案：兼顾双方——"一生只这一次，不留遗憾，同时兼顾男方预算"
- 展示：为场地做了哪些准备、食材选择上下过什么功夫、用了当地特产海鲜压低价格但品质不差
- 结果：既满足女方的浪漫，又照顾男方的预算

### 生日宴示例：讲究=卖点
- 为什么用中式？因为老人喜欢热闹
- 为什么用中国红？喜庆
- 细节展示：窗花（鱼图案寓意年年有余）、桌布、沙发套、灯笼、摆件
- 服务亮点：免费赠送鲍鱼生日面、节目表演

### 宝宝宴示例：用心=卖点
- 场地布置用了多长时间（48小时/24小时）
- 考虑过卫生、空气流通、安全性
- 为孩子准备的特殊环节

## 五、选题六角度

| 角度 | 示例 | 怎么拍 |
|---|---|---|
| 反差故事 | "8岁小孩居然会品鉴海鲜" | 拍小孩+海鲜，旁白讲故事 |
| 过程展示 | 买菜→洗菜→做菜全过程 | 跟拍，从凌晨市场开始 |
| 幕后故事 | 这道菜怎么研发的？换了三次配方 | 采访厨师+试吃画面 |
| 客户故事 | 本周印象最深的一桌客人 | 讲真实故事，改编保护隐私 |
| 知识技巧 | 怎么挑海螺？点菜怎么花到位？ | 柯老师直接讲，拍食材特写 |
| 争议话题 | "升学宴到底要不要办？" | 自拍口播，抛观点引讨论 |

### 两个永不枯竭的素材源
- **前台日记**：每天记录接待了什么客人、发生了什么对话。每个客人都不一样——差别就是内容
- **后厨透明化**：直播挑菜、洗海鲜、备料过程。没人看也播——直播是靠养的

### 选题自检
1. 这条跟"为本地家庭提供餐饮+服务"有关吗？
2. 观众看前5秒会不会划走？
3. 信息够密吗？能不能加花字/旁白？
4. 能不能蹭热点？（节气/节日/高考/入伏）

## 六、差评/投诉→视频转化

### 核心逻辑
不是"解释自己没错"，而是"展示我们怎么解决问题"。

### 五步操作

| 步骤 | 时长 | 内容 |
|---|---|---|
| 1. 道歉 | 2-5秒 | "对不起"——道歉自带吸睛属性，观众想看热闹 |
| 2. 简短解释 | 5-10秒 | 就一句，不甩锅："夏天量大，一筐里有一两颗漏网之鱼，很正常" |
| 3. 明确补偿 | — | "那颗坏的挑出来，这盘不要钱，再送你个小菜"——具体、可感知 |
| 4. 求助观众 | — | "大家有没有更好的办法？评论区告诉我们"——带好节奏 |
| 5. 延伸正面 | — | "以后挑海螺我们开直播？透明厨房"——用一件坏事带出好事 |

### 公关引导策略
**不是等出了事再道歉，而是主动发"问题解决得好"的内容：**
拍"菜里有虫子→撤掉重炒→送果盘→顾客非常理解"

多发这种内容，来消费的人素质会变高——别人看到"有问题解决得好"，自己没渠道闹。

## 七、人员与剪辑

### 人员配置
- 忙时指定一人专职拍摄——指挥实习生/助手操作，自己负责剪辑
- 不要边接待边拍——精力不够，素材质量差

### 剪辑思维
- 先整理素材再写脚本（即时事件不要反过来）
- 半天整理→批量拍摄→拼图剪辑
- 开场钩子用全景+大特写组合制造视觉冲击

---

## 附：三条铁律

1. **先拍后写**：即时事件素材拍足再写脚本，别倒过来
2. **宁可多拍**：拍多了不用没事，缺素材没办法补救
3. **电话录音**：客户说的就是最真实的素材，录音不会骗你
