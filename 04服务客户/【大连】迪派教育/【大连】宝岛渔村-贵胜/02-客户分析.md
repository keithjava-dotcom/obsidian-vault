## 宝岛渔村 · 贵胜 — 客户分析

---

### 基本信息

| 字段 | 内容 |
|---|---|
| 客户名称 | 宝岛渔村 · 贵胜 |
| 城市 | 大连 · 长兴岛 |
| 行业 | 餐饮（中餐） |
| 规模 | 中型餐饮，含接待/服务/后厨/采购多部门 |
| 负责人 | 贵胜团队（2名学员主导新媒体） |
| 合作方式 | 迪派教育新媒体课程（柯建军授课） |

---

### 目标用户画像（张小阳）

| 维度 | 描述 |
|---|---|
| 谁 | 长兴岛/大连本地家庭，30-50岁，有老有小 |
| 场景 | 周末/节假日带家人出来吃饭；给孩子办生日；宴请朋友同事；给老人祝寿 |
| 消费力 | 中产及以上（宴请型消费） |
| 最关心 | 菜好不好吃、食材安不安全、环境适不适合老人小孩、有没有面子 |
| 刷视频习惯 | 抖音为主，随机刷，没耐心；本地推荐流 |
| 决策路径 | 刷到→感兴趣→看其他视频→搜索→打电话/私信→到店 |

---

### 账号现状

| 维度 | 现状 | 方向 |
|---|---|---|
| 内容焦点 | 偏到"人好看"上 | 回到"菜好吃、食材安心、服务好" |
| 制作方式 | 过度制作（影视技法） | 轻量化（手机+麦克风） |
| 内容形式 | 段子+模糊主题 | 用事情讲卖点 |
| 目标 | 不清晰 | 先想清楚：你到底要什么 |
| 播放量 | 不详（未获取具体数据） | 目标：稳定3000-5000后冲刺爆款 |
| 之前方向 | "美女+"路线 | 停掉，转"菜品/食材/服务" |

---

### 学员能力画像（2026-07-07课堂观察）

| 维度 | 评估 |
|---|---|
| 新媒体基础 | 较弱，但学习意愿强 |
| 镜头恐惧 | 无（不恐惧镜头，可出镜） |
| 文案能力 | 能写（"俺俩写好了"），但需提高口语化和具体化 |
| 执行力 | 强，愿意立刻动手 |
| 时间约束 | 日常忙（餐饮行业特性），需要化整为零 |
| 审美/设计能力 | 不确定，建议先不走复杂排版路线 |

**能力定位**：零基础但有执行力的新手。需要的是"跟着做就能出片"的清晰指引，而不是更多理论知识。

---

### 内容策略建议

**核心原则**：通过"事情"讲卖点——不是靠说，是靠做。

**坚决不要做**：
- ❌ 段子、搞笑日常
- ❌ 影视级后期
- ❌ 焦点停在出镜人颜值上

**账号矩阵**：按部门分布（接待/服务/后厨/采购+蓝V），详见 [[给宝岛渔村上课/Day4-账号矩阵分布方案]]

**内容支柱**：
1. 菜品品质（研发故事、后厨日常）
2. 食材安全（采购标准、源头展示）
3. 服务故事（客户宴会幕后）
4. 真实互动（读好评差评、观众留言回应）

**当前课程阶段**：Day4完成——已掌握竖版结构（钩子/骨架/情绪）、互动四维、七步工作流、账号矩阵策略。下一步：按工作流产出一批视频进入实操验证。
