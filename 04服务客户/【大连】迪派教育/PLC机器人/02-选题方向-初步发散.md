# PLC 机器人 · 选题方向（初步发散）

> ⚠️ 基于肖校长已有档案 + 语音讨论素材做初步发散。定位问卷回收后更新。

---

## 账号定位判断

**校长号做的事**：一个温柔的人坐下来听你说 → "帮迷茫的孩子找方向" → 品牌信任、温度、教育理念

**PLC 号要做的事**：让正在找工作/想转行的人看到——"这里有一条路，有人走过，走得通" → 信息、结果、真实感

**两个号怎么分工**：

| | 校长号 | PLC 号 |
|------|--------|--------|
| 谁看 | 迷茫的年轻人 + 家长 | 想学技术的人 + 企业 HR |
| 给什么 | 被理解的感觉 | 具体的出路 |
| 怎么变现 | 品牌信任 → 到校咨询 | 招生直接转化 |
| 语气 | "我理解你" | "你看这个人，跟你一样" |
| 肖校长出镜 | 主讲人 | 偶尔出现，更多让学员和老师讲 |

---

## 内容核心公式

```
谁来了 → TA 以前干嘛 → 为什么来 → 现在学什么 → 以后去哪 / 挣多少
```

一条视频讲一个人、一件事。不贪多。不讲理念，讲结果。

## 选题发散（6 大类）

### 一、学员故事（最强方向，占 60%）

| 选题 | 素材 | 赌注 | 为什么拍 |
|------|------|------|---------|
| 23岁，中专毕业，月薪一万——但他辞职了 | 豪森接线工 | 生活型羡慕 | 有故事弧线：不安于现状→行动→改变 |
| 在豪森干了四年半接线，他说"我不想一辈子干这个" | 同上，聚焦转折点 | 生活型羡慕 | 一句话击中观众——"我是不是也在接线" |
| 985 研究生，为什么来学 PLC？ | 学员结构 | 观点型反常识 | 打破"只有低学历才学技术"的偏见 |
| 他之前送外卖，现在在学机器人编程 | 需补充 | 生活型羡慕 | 反差大，代入感强 |
| 40 岁转行来学工业机器人 | 需补充 | 生活型羡慕 | 打破年龄焦虑——"什么时候都不晚" |
| 一个女学员在学 PLC——不是只有男的能干 | 需补充 | 观点型反常识 | 性别反转，话题性 |
| 学员第一天 vs 第三十天——同一个人的变化 | 需跟拍 | 步骤型落地 | 可视化成长过程 |

**结构模板**（拿豪森接线工举例）：
```
开头（3秒）："他23岁，月薪一万多，辞职了"  ← 一句话钩子
过去（15秒）：在豪森干什么、干了多久、为什么不干了
转折（15秒）：怎么知道迪派的、来的时候什么状态
现在（20秒）：在学什么、最难的是什么、说一句心里话
结尾（5秒）：学完想去哪
```

## 优先拍这 5 条（开号第一批）

| 优先 | 选题 | 理由 |
|------|------|------|
| 1 | 23岁豪森接线工辞职学编程 | 有人物、有数字、有转折——完整故事，最有可能第一条就爆 |
| 2 | 现在的工厂已经没人在焊接了 | 反常识开篇+机器画面视觉冲击，适合冷启动拉新 |
| 3 | 学工业机器人到底能挣多少？ | 直接回答目标用户最关心的问题，有搜索价值 |
| 4 | 带你看真实的 PLC 基地 | 环境展示建立信任，降低"报名"的心理门槛 |
| 5 | 这个教室里都有谁？（群像） | 多人物低门槛，展示"谁都可以学" |

## 和校长号的配合

```
第1周：PLC号发豪森接线工故事 → 校长号发"这个孩子让我想起另一个学生"
第2周：PLC号发收入真相 → 校长号发"帮孩子找方向比让他报名更重要"
第3周：PLC号发基地展示 → 校长号发"二十几年前为什么选了职业教育"
```

两个号互相导流：PLC号展示"这里有出路" → 校长号展示"这里有人在乎你" → 形成信任闭环。
