# 学生实操计划：怎么给老板拍视频

这次实操任务：给迪派教育的肖校长拍 PLC 和工业机器人培训的内容。

你拿这份计划去现场，按步骤跑就行。
别想太多，先拍回来再说。

---

## 一、每条问题都是一条视频

别想着"先搞清楚再拍"。搞清楚的过程直接拍下来，就是一条视频。

下面每条选题都给你设计了问题逻辑。按顺序问，别跳。
结构是这样跑的：

```
钩子开头（第一句话把人的耳朵抓住）
   ↓
开放式引入（让对方讲故事，别给答案）
   ↓
封闭式追问（压出细节、数字、具体场景）
   ↓
开放式收尾（给对方一个"说金句"的机会）
   ↓
关键词自然植入（让算法知道这条视频在讲什么）
```

## 二、采访技巧（三条，记牢）

上面每条选题都写了要问谁、问什么。下面三条是怎么问——比问什么更重要。

**第一条：别怕沉默。** 对方说完一句话停了，你等 3 秒。往往后面那句才是真的。

**第二条：追着问。** 对方说"这学校挺好"——你就问"具体好在哪？"对方说"月薪挺高的"——你就问"多少？"

**第三条：让对方重说一遍。** 第一遍说太正式了，"你能不能换大白话再说一遍？"——第二遍往往就是能用的。

**问之前记住一件事：** 别问"你觉得怎么样"——这问出来的一定是"好""不错""还行"，拍了也白拍。问具体的事，问具体的数字，问具体的场景。

## 三、B-ROLL 清单：采访现场必须拍的画面

B-ROLL 不是在采访结束后"顺便拍一点"。是必须拍。下面这个清单，拍完一条划一条。

### 基地环境（每条片子都能用）

- [ ] 基地建筑外观——站远点，仰拍，让建筑显大
- [ ] 基地门牌/校名——正面，横移扫过去
- [ ] 走廊全貌——边走边拍，稳
- [ ] 教室全景——门口拍进去，有人的没人的各一条
- [ ] 墙上的证书/奖牌/课程表——特写，扫过去
- [ ] 窗外自然光——早上和下午光线好，拍一条

### 设备（工业机器人账号的灵魂）

- [ ] 机器人在运作——中景到特写，拍机械臂的运动轨迹
- [ ] PLC 控制面板——屏幕特写，有人在操作
- [ ] 编程电脑屏幕——拍屏幕上的代码界面，有人在敲
- [ ] 焊接机器人（如果有）——火花四溅的画面，抖音上最吸睛的工业画面
- [ ] 搬运机器人（如果有）——拍它抓取、移动、放下的完整动作
- [ ] 设备细节——机械臂关节、传感器、线缆——工业美感

### 学员镜头（故事的主角）

- [ ] 学员操作设备的手——特写：按按钮、碰屏幕、调参数
- [ ] 学员看屏幕的专注表情——侧拍，自然光，别让人看镜头
- [ ] 老师指导学员——两人同框：一个在讲，一个在听
- [ ] 学员之间聊天——下课休息的时候抓拍
- [ ] 学员进门/出门——带设备带背包，自然状态
- [ ] 学员桌上的东西——笔记本、教材、水杯

### 氛围镜头

- [ ] 阳光照进教室——慢移，光影
- [ ] 休息区——学员在闲聊
- [ ] 从教室窗户拍出去——基地外面的街道
- [ ] 肖校长或徐老师的背影/侧影——自然地拍到，别盯着拍
- [ ] 时钟/课程表——特写

### 加分项（有就去拍）

- [ ] 合作企业工厂里的机器人——"学完就去这"，比什么话都有说服力
- [ ] 企业来基地招聘现场——学员和 HR 在聊
- [ ] 已毕业学员的工作环境——返图也行

### B-ROLL 三条铁律

1. **手要稳。** 靠墙、靠桌子、用支架。抖的画面没法用。
2. **每条至少 10 秒。** 3 秒一个片段后期剪不了。
3. **同一个东西多角度拍。** 全景一条、中景一条、特写一条。回来再挑。

## 四、拍摄当天怎么跑

### 最少几个人

两人的话：一个采访+一个拍。三人最舒服——再加一个专门拍 B-ROLL 的。

### 时间线（半天）

按 17 条选题的顺序跑。先拍肖校长（她是老板）、再拍学员、再拍徐老师。基地展示两条穿插在间隙拍。

```
09:00  到基地，架设备，先拍环境空镜 + 机器运转画面（趁采访还没开始）
09:30  选题1：跟肖校长聊"为什么偏偏是 PLC"
09:45  选题2："这行凭什么不被淘汰"
10:00  选题3："你们跟别人有什么区别"
10:15  选题4："什么情况下你会劝退"
10:30  课间——拍学员交流、基地氛围（B-ROLL 补）
11:00  选题8：采访 23 岁豪森接线工（最重要的一条，多拍）
11:20  选题10：拍一个转行学员
11:40  选题11：学员第一天 vs 现在
12:00  选题13+14+15：采访徐老师
12:20  补拍遗漏的 B-ROLL，对着清单划
12:30  选题16+17：基地展示 + 机器运作（如果有漏的补上）
```

> 时间不用卡太死。聊到好东西就多聊一会儿。少拍一条选题没关系，聊透比聊全重要。

### 几条提醒

- 被采访的人紧张了？说"就当聊天，这个不会直接发，我会剪的"——他就放松了。
- 注意噪音：空调声、机器声。采访的时候背对噪音源。
- 光线：别让人站窗户前面——逆光，脸黑。让人面对窗户。
- 电量：每隔一小时看一眼。

## 五、拍完怎么整理素材

### 当场就记

别等回去再整理——回去就忘了。

每一条 A-ROLL 采访在手机上上记：
- 谁 / 说了什么金句 / 大概在几分几秒 / 这条能用在什么选题

B-ROLL 对照清单看什么没拍，趁人没走赶紧补。

### 素材交付最低标准

| 类目 | 最低要求 |
|------|---------|
| A-ROLL 采访 | 至少 3 个人，每人 5 分钟以上 |
| B-ROLL 画面 | 至少 30 条有效画面（不抖、10 秒以上） |
| 环境空镜 | 至少 5 条 |
| 设备运作 | 至少 10 条 |
