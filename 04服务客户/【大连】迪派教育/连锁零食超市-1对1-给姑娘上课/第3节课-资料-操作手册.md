# 第3节课 · 拍摄与脚本操作手册

> 本手册按上课内容整理为**可执行的操作流程**，每一步包含知识点 + 操作指引。
> 按顺序执行，遇到问题随时在群里问柯老师。

---

## 第一步：搞清楚平台怎么认识你的内容

### 知识点

抖音给你的内容打标签，不是靠人工识别，是靠算法。算法抓三个东西：**画面里有什么、声音里说了什么、文字里写了什么**。

新账号的内容会被推进一个初始流量池（一般是200-500次曝光），平台根据完播率、互动率等数据判断要不要继续推。这个就叫**赛马机制**——所有新创作者一起跑，数据好的跑出去。

### 怎么做

**1. 用对关键词。**
你想让大连的年轻人刷到你，就在视频标题/文案/口播里说"大连"、"大连的00后"。算法就懂了。

**2. 用平台的"灵感"功能。**
打开创作者中心→灵感→找热门话题→结合自己的想法去发。平台会给你加内容标签。

**3. 做分享，不做广告。**
你的零食超市账号，目的是**影响年轻人的零食决策**——让他们因为相信你推荐才买。不是直接叫卖"这东西好吃快买"。分享型和广告型的最大区别：

| 分享型（你做这个） | 广告型（不要做） |
|---|---|
| "这个搭配真的好绝" | "快买这个，限时优惠" |
| 视频里可以出现产品，但不刻意拍logo | 刻意展示商家名字和二维码 |
| 用户相信你→长期忠诚复购 | 用户看一次→买完走人 |

平台其实是希望创作者能变现的——你账号跑起来之后，可以挂橱窗、挂团购、做探店。变现工具很多。前提是你的内容先能留住人。

## 第二步：画面构成——用手机拍出好看又有叙事感的画面

### 知识点

画面的四个基本要素：**景别、构图、视角、运镜**。它们可以跟乐高一样自由排列组合，创造无限可能。

---

### 2.1 景别：拍多宽

| 景别 | 手机怎么调 | 拍什么 | 什么时候用 |
|---|---|---|---|
| **远景** | 0.5倍广角 | 人+环境的关系 | 交代"我在哪"——店门口、机场、景点 |
| **中景** | 1~2倍 | 叙事推进 | 坐下吃饭、走路、拿东西、说话 |
| **近景** | 拉近一点 | 表情、动作 | 夹菜、点单、看菜单 |
| **特写** | 贴很近 | 局部细节 | 食物、手、嘴、账单、表情 |

**记忆口诀**：远交环境，中讲故事，特写给细节。

**一个例子就能记住**——假设你拍"去吃西湖醋鱼"：
1. 远景：高铁站前打卡，告诉大家"我到杭州了"
2. 中景：坐下，一盘鱼上桌
3. 近景：夹起一块
4. 特写：吃了一口吐掉，表情扭曲

这四画面不用任何文案，观众也完全知道发生了什么。这就是**画面语言的力量**。

---

### 2.2 构图：怎么摆

| 构图 | 方法 | 适合拍 |
|---|---|---|
| **居中构图** | 主体放画面正中间 | 封面、口播、产品展示 |
| **三分构图** | 主体放九宫格三分线位置 | 打卡照、人像、风景 |
| **前景构图** | 用前景元素+后景主体制造空间层次 | 上课、探店、货架前吃零食 |

**拍摄技巧**：手机用**2倍焦段**拍，画面有轻微的空间压缩，比1倍更自然更好看。

**前景构图实战**：
- 拍上课：用学生的肩膀或头当前景，老师在后讲课 → 谁在听、谁在讲一目了然
- 拍零食：你站前面吃，后面整排货架当背景 → 有空间感，好看

---

### 2.3 视角：从哪看

| 视角 | 观众看到的是 | 适合拍 |
|---|---|---|
| **第一视角** | 你的眼睛看到的 | 逛超市、吃零食、旅行沉浸式 |
| **第二视角** | 你对着镜头说 | 口播、分享、推荐——观众感觉你在跟他说话 |
| **第三视角** | 第三人在旁边看你们 | 采访、跟拍、纪录片感 |

**一句话区分**：
- 第一视角 = "我看到的"
- 第二视角 = "我跟你说"（对着镜头讲话）
- 第三视角 = "别人看我们"

**采访技巧**：如果对方背不下稿子——正常聊天、问问题、后期把你的提问剪掉、只留他的话。这就是**开放式提问引导法**。

---

### 2.4 运镜：怎么动

| 运镜 | 动作 | 制造什么感觉 |
|---|---|---|
| **推** | 向前靠近 | 聚焦、紧张、"重点来了" |
| **拉** | 逐渐远离 | 拉开一个更大的信息量 |
| **摇** | 原地转动 | "扫一眼"、连接两个东西 |
| **移** | 横向移动 | 展示一排货架、逛街感 |
| **跟** | 跟着主体走 | 参与感、动感 |

运镜也能制造情绪——刻意晃动的镜头能制造紧张感。关键是：**不要一直把手机架在那里不动，会单调死板。** 动起来！

---

### 2.5 排列组合——像乐高

四种元素可以自由组合：

> 景别 × 构图 × 视角 × 运镜 = 无限可能

**举个完整的叙事镜头**：
1. 远景 + 居中 → "这家店就在这"（交代你在哪）
2. 跟拍 + 中景 → 你走进店里
3. 中景 + 三分 → 坐下，面前放了一桌零食
4. 特写 + 推 → 咬一口，表情满足

**初学者先保证**：远景和特写交替拍，镜头不要一直不动，基本就有张力了。

---

### 拍摄前自检清单

拍一条视频前问自己：
- [ ] 有没有远景？（交代环境）
- [ ] 有没有特写？（给细节和情绪）
- [ ] 手机动了还是架着不动？
- [ ] 用的是什么视角？对观众说话还是沉浸式？
- [ ] 试试用2倍焦段拍？

## 第三步：建立素材库——不要每次从头拍

### 知识点

**素材库建好之后，你的核心工作就从"拍什么"变成了"想什么内容、什么梗、什么创意"。**

拍摄和剪辑的时间大幅减少，重心放在创意碰撞上。不管你是一个人干还是搭团队干，这个事情必须得干。

### 怎么做

以零食超市为例，按场景分类积累素材：

```
零食超市素材库
├── 仓库：放货、理货、送货（车、司机、卸货）
├── 门店外观：店招、店面、不同门店的环境（东港店、金马路店……）
├── 门店内部：地面、收银台、货架、零食陈列
├── 人物：店长一/二/三、顾客（背影或手部特写保护隐私）
├── 送货场景：车→卸货→入库全流程
└── 其他：节日装饰、活动布置、新品上架
```

**每个分类下面，用不同景别和运镜去拍**。同一个货架——远景扫一眼、中景慢慢移过去、特写给某款零食的包装。日积月累，素材库就满了。

### 作业

今天就开始建素材库。拿手机去店里拍一轮——每个场景远景+特写都来一遍。不用剪辑，存进手机相册分类就行。

## 第四步：旅行怎么拍——"大动作拆小动作"

### 知识点

**拍摄的本质不是"拍什么"，而是把每一个大动作拆成一连串小动作。拆得越细，越知道怎么拍。**

用这个方法，你去杭州去苏州去任何地方，拿出手机就知道该拍什么。

### 怎么做

把行程拆开。比如"从大连飞杭州"：

| 步骤 | 拍什么 | 景别 |
|---|---|---|
| 出发 | 大连机场，你人在环境里 | 远景（0.5倍） |
| 取票 | 手拿机票 | 特写 |
| 过安检 | 走过去的过程 | 中景+跟拍 |
| 候机 | 机票放腿上、你看窗外 | 中景+特写 |
| 上飞机 | 找座位、坐下 | 跟拍 |
| 起飞 | 窗外云层 | 远景 |
| 空中 | 你在看书/看窗外 | 中景 |
| 下飞机 | 到了！机场走廊 | 远景 |
| 打车 | 车窗外杭州街景 | 中景 |
| 到酒店 | 酒店外观 | 远景 |
| 前台 | 拿房卡 | 特写 |
| 房间 | 环境、灯、床单、小摆件 | 远景+特写 |

**核心原则**：每个小步，远景和特写交替拍。远景交代"在哪"，特写给细节给情绪。

### 延展到其他场景

- **吃饭**：美食街环境→找摊位→食物特写→吃的时候的表情
- **景区**：大门远景→景区介绍牌→走进去→项目体验→尖叫/惊讶表情特写
- **园林**：门口→房檐拱门雕花→特写拍细节（这些细节最有味道）

### 关于旅游和零食账号

零食超市账号可以发旅游内容吗？**看账号目的。**
- 如果账号是为了给店里带业绩 → 不发旅游
- 如果想要突出个人人设 → 可以单独开个人号发
- 零食账号也可以发零食相关的旅行内容 → 比如"在杭州吃了三天，还是大连零食最懂我"

> 旅行是你的人设。你今天去了哪里、玩了什么、学到了什么、有了什么想法——说就好了。

### 作业

去杭州的行程里，用"大动作拆小动作"的方法拍。回来把所有原始素材带回来，不要删任何东西。

## 第五步：用录音工具积累自己的素材

### 知识点

**每天对着录音工具说一段话**，积累的是你自己的思考原石。后期用文案技巧洗稿，就能变成内容。

拍摄时的录音最有价值——真情实感的流动，话是可以听出来的。AI写不出那种"真"。

### 怎么做

**1. 买一个得到录音卡。**
京东搜"得到录音卡"，大概800-1000块钱。功能：
- 录完自动识别你讲了什么
- 自动起标题、整理归类
- 比如"新媒体文案和视频拍摄"、"短视频创作思路"

**2. 每天对着它说话。**
不用正式——今天是几月几号，我去了什么地方，干了什么事，有什么想法。说完关掉。

**3. 不用直接发。**
这些录音素材是拿来洗稿用的。随口说的东西比较乱，后面用文案技巧整理成结构化的内容。

### 作业

买录音卡（或者先用手机备忘录替代），从今天开始每天录一段。不要求质量，要求数量。

## 第六步：学会写脚本——从用户到故事

### 知识点

**脚本创作路径：分析用户 → 确定主题 → 选结构 → 编故事 → 写分镜头。**

脚本结构分两种：
1. **清单式**：信息枚举（"夏天必吃的5款零食"）
2. **故事式**：有冲突有解决（"吃烧烤太辣怎么办→给你三招"）

能让观众记住的，大多数是故事式。

### 怎么做

**第一步：分析用户。**
- 谁会看？（你们的目标是年轻人，00后）
- 什么季节？（夏天）
- 这个季节他们有什么需求？（想吃烧烤，又想解暑，又怕胖）

**第二步：确定主题。**
把多个需求合并成一个主题。"夏日清凉美食，还不胖的搭配。"

**第三步：设计故事框架。**
```
背景：夏天吃烧烤太爽了
冲突：太辣！怕胖！带外地朋友众口难调！
方案：你的零食搭配方案
```

**第四步：写故事脚本。**
你的创意（课上学生想出来的）：
> 大连人夏天都有个习惯——吃烧烤和晒太阳。
> 但吃烧烤总有几个问题：太辣、怕胖、招待外地朋友不知道点什么。
> 今天教你三招，让你的烧烤局舒服又过瘾。

**第五步：拆成分镜头。**
把脚本的每一句话对应一个画面，标注景别、构图、视角、运镜。

### 作业

1. 把上面的"夏日零食·烧烤三招"故事，写成一个分镜头脚本。每个镜头标注：景别、构图、视角、运镜。
2. 写完发给柯老师改。改完再拍。
3. 用"100元挑战"（100元预算在零食超市采购→带朋友吃烧烤→解决三个痛点）的思路，再想一个自己的故事脚本，也写成分镜头。

## 第七步：理解平台反馈——不要找朋友刷赞

### 知识点

**你在平台上发的内容，你朋友家人不点赞——这不是问题。** 他们不是你的目标用户群。

平台给你的账号推荐就说明内容方向是对的。你第一条视频只有20个播放，但平台已经给了你"生活分享"标签并奖励了流量——说明算法认可你的内容类型。

### 怎么做

1. **不要找朋友刷赞。** 只有凭自己能力跑出来的数据，你才知道内容是好还是不好。不好就改。刷来的数据只会骗自己。

2. **看平台反馈，不看家人朋友圈。** 平台说"很多用户觉得你分享的信息很实用"——这个信号比你妈说你视频好看重要一万倍。

3. **持续更新。** 平台有任务体系和升级机制。你坚持更新、完成任务，账号就会不断获得更多流量权限。

## 总结：本课核心公式

```
平台认知（赛马+分享≠广告）
    ↓
画面构成（景别×构图×视角×运镜）
    ↓
素材库（按场景分类积累）
    ↓
拍摄方法（大动作拆小动作）
    ↓
录音工具（每天积累思考原石）
    ↓
脚本创作（用户→主题→结构→故事→分镜头）
    ↓
真实数据反馈（不看朋友圈，看平台）
```
