## 整理版正文

### §1 平台思维：算法怎么认识你的内容

#### 1.1 赛马机制与内容标签

柯建军：平台都希望新的创作者进来，会让他们赛马。你打开创作者中心，有"同类作者"推荐——当你的视频跑起来后，平台会给你匹配同类作者、匹配你的内容。

平台还有一个"灵感"功能，里面是热门话题。针对这些灵感，结合自己的想法和实际情况去发同样的话题，平台就会慢慢给你加标签。

学生：我可以学习模仿。

柯建军：对，模仿。后面我会教你怎么去拆解，拆解完加上自己的东西，慢慢迭代。平台所有东西都是代码机制。

#### 1.2 分享 vs 广告的核心分界线

学生：我这个视频里没有明确体现商家名字，是不是有点太隐晦了？

柯建军：你这个属于分享，不算广告。什么是广告？就是说"这东西给他买""这卖点什么好""什么好吃的怎么做"，叫卖式的。

学生：但我看别人都会把袋子上的名字拍一下，视频里会有商家logo。

柯建军：**这就是信息流和人设账号的区别。** 我们做视频，目的是影响年轻人买零食的决策——这是我们的原则。因为你能影响他们的决策，你推什么他们都会买，他们才会忠诚地买。

如果你去做信息流（付费投放）、找达人推广，那是完全不同的路径。不用担心他们怎么买、方不方便。只要账号吸引他们，之后哪怕挂橱窗、挂团购、探店——平台会提供非常多的变现工具。因为平台也希望优质创作者来变现。

实际上平台更希望信息流这种内容，因为它直接给平台交钱、花钱买流量。所以自己问的那个问题，你可以再想想。

#### 1.3 平台对内容的偏好

核心原则：**你们要做分享，不要做广告。** 平台对内容的偏好是——内容能不能被平台直接变现（信息流），或者能不能留住用户（优质分享）。两条路都可以走，但你需要想清楚你要走哪条。

### §2 画面构成：把故事用画面讲出来

#### 2.1 景别：远景、中景、近景、特写

手机相机里：
- **远景** = 0.5倍广角，拍得特别广
- **中景** = 1倍到2倍，常规构图
- **近景/特写** = 拍局部

每个景别的功能：
- **远景**：交代主体和环境的关系。例如去杭州打卡——你在高铁站或机场拍一张人和背景的合影。
- **中景**：叙事推进。例如你在餐馆坐下，面前放了一盘西湖醋鱼。
- **特写**：强调情绪和细节。例如吃了一口鱼吐掉的表情，或者拍鱼本身、拍嘴巴、拍垃圾桶。

柯建军用一个无文案的四画面演示：
> 想象一下：你站在高铁站拍照打卡 → 来到一家西湖醋鱼店 → 坐下，前面放了一盘鱼 → 吃了一口吐掉了。

即使没有文案，观众也知道发生了什么——这就是**视觉语言**。

#### 2.2 构图：居中、三分、前景

**居中构图**：把主体放在九宫格正中，适合封面。

**三分构图（黄金构图）**：把主体放在九宫格的三分线位置（左或右都可以）。

**前景构图**：用前景元素来构建空间关系。例如拍上课——用学生的肩膀或头部当前景，老师在后景讲课，观众自然知道谁在听课、谁在讲。用于打卡照时，"你站在前面吃零食，后面是整排超市货架的零食"——有空间感，可以做丰富的版面设计。

拍摄技巧：用手机2倍焦段，有一点空间压缩效果，拍出来更好看。

#### 2.3 视角：从哪个角度看

| 视角 | 说明 | 例子 |
|---|---|---|
| 第一视角 | 观众看到的就是你的眼睛看到的 | 运动相机挂身上、手持手机边走边拍 |
| 第二视角 | 人物对着镜头说话 | 口播视频就是第二视角 |
| 第三视角（上帝视角） | 两人互动、第三人在旁边拍 | 采访式、跟拍式 |
| 打破第四面墙 | 角色突然对镜头外的观众说话 | 《死侍》电影的标志手法 |
| 航拍视角 | 无人机 | 大场景、空间感 |
| 其他 | 360相机、水下无人机、宠物视角等 | 新鲜感刺激 |

**采访技巧**：如果你不想出镜、但要引导别人说话——
> 假设我要给老板拍视频，老板背不下稿子。我就跟他正常聊天，问问题，之后把我的话剪掉，只留他的话。这个叫**开放式提问法**。

#### 2.4 运镜：推、拉、摇、移、跟

| 运镜 | 动作 | 效果 |
|---|---|---|
| 推 | 主体不动，设备向前靠近 | 节奏紧凑，聚焦注意力 |
| 拉 | 主体不动，设备逐渐远离 | 拉出更多信息、展现环境关系 |
| 摇 | 主体不动，设备原地转动 | 扫视多处、连接关系 |
| 移 | 设备横向移动 | 拍摄多个物体，横向叙事 |
| 跟 | 主体移动，设备跟随 | 动感、参与感 |

运镜可以制造情绪——很晃的镜头、刻意甩动，可以制造紧张感。

关键是：**不要一直把手机架在那里不动，会单调和死板。**

#### 2.5 排列组合：画面像乐高

四种元素（景别、构图、视角、运镜）可以自由排列组合，跟乐高一样。你可以：
- 只用景别+构图
- 景别+构图+视角+运镜一起用
- 任何组合都可以，创造新鲜感

**任何一个知识点，我们都可以去排列组合，去创造更多。**

### §3 素材库建设：分类与积累

#### 3.1 素材的分类思路

以零食超市为例：

```text
零食超市素材库
├── 仓库场景：放货、理货、送货（车、司机、卸货过程）
├── 门店外观：店招、店面、环境（东港店、金融街店、城市路店……）
├── 门店内部：地面、收银台、货架
├── 人物：店长一/二/三、顾客
├── 送货场景：车→卸货→入库过程
└── 其他
```

每个分类下面，用不同景别、运镜去拍，积少成多。

#### 3.2 为什么必须建素材库

建立素材库后，核心工作就变成了——**在集思广益地去想内容、想梗、想创意**。

我们不再为拍摄和剪辑花太多时间。有了AI之后，AI还能帮我做一部分。主工作重心放在内容和创意的碰撞上，效率会大大提高。

> 不管你是一个人干，还是搭团队干，这个事情必须得干。

同样的方法用于创始人IP拍摄——分析这个人的一天、工作场景、日常动作、喜好、细节，都能拍。

### §4 旅行拍摄实操：大动作拆成小动作

#### 4.1 核心方法

学生说自己要去杭州旅游，柯建军以此为例演示拆解方法。

**原则：把每一个行程都拆分成小步。**

例：从大连飞杭州：

| 步骤 | 可拍内容 | 景别建议 |
|---|---|---|
| 出发 | 大连机场、人物与环境关系 | 远景（0.5倍） |
| 取票/登机牌 | 手拿机票 | 特写 |
| 过安检 | 安检过程 | 中景/跟拍 |
| 候机 | 机票、座位上等待 | 中景+特写 |
| 上飞机 | 找座位、坐下 | 跟拍 |
| 起飞 | 窗外 | 远景 |
| 等待 | 看书/看窗外 | 中景 |
| 下飞机 | 到达 | 远景 |
| 打车 | 出租车窗外杭州街景 | 中景 |
| 到酒店 | 酒店外观 | 远景 |
| 前台 | 领房卡 | 特写 |
| 房间 | 环境、灯、床单、摆饰 | 远景+特写 |

**每个小步——远景+特写交替拍，画面就有张力。**

#### 4.2 延展到其他场景

同样的方法：

- **吃饭**：美食街环境（远景）→ 具体摊位（中景）→ 食物特写 / 吃的时候的表情
- **景区**：景区环境 → 项目介绍 → 具体项目体验 → 尖叫/惊讶表情（特写）→ 美的细节
- **夜市/农家乐**：环境 → 特色（中国风建筑、园林）→ 特写（拱门、雕花、装饰）

学生谈到苏州园林：园林门口、房檐、拱门、雕花——都是值得拍特写的。

#### 4.3 账号定位决定拍什么

学生问：零食超市账号能不能发旅游内容？

柯建军：**看账号的目的。**
- 如果账号有公用目的（为店增加业绩），就不要发
- 如果你想突出个人人设，可以单独一个号
- 零食超市账号也可以发零食，但不是旅游vlog的形式

> 这个（旅游）是你的人设。我今天去这里玩了，今天我学到了什么，我玩了什么。你去了什么地方，干了什么事情，有了什么想法——说就好了。

### §5 录音工具与内容生产

#### 5.1 得到录音卡

柯建军推荐：**得到录音卡**，约800-1000元。功能：
- 录音后自动识别讲的什么内容
- 自动起标题、整理归类
- 例如：这篇是"新媒体文案和视频拍摄"，那篇是"短视频创作分析"

#### 5.2 怎么用

**每天对着录音卡说话**：今天是几月几号，我去了什么地方，干了什么事，有什么想法。说完关掉就行。

这些录音不是为了直接发，而是**拿来洗稿用的**。因为我们随口说的东西没有目的性、会比较乱——后面用文案技巧重新整理。

**关键场景**：拍摄时的录音。真情实感的流动，话是可以听出来的——这个最有价值。

### §6 AI时代：个人思考才是壁垒

#### 6.1 趋势判断

柯建军：未来我们都是数字化了。AI是通用化模型——很通用，能做的事非常多。那么什么东西变得越来越值钱？**知识。**

> 你的思考如果能形成，它就非常值钱。我对去杭州这件事怎么看？我认为00后怎么样？我的想法、我的所思所想。一切你的思考都是独特的。你的思考足够真实且像你——用它（录音）加上它（AI），就能等于一个数字化的你。

这就是柯建军正在做的事：**数字化的人。**

#### 6.2 对00后的判断

柯建军：你们这个年代其实挺卷的，没什么大风口。父辈赶上房地产，80后有经济开放，90后有互联网和短视频。到你们，风口小、竞争大。

年轻人不努力，不是懒——是因为努力也没什么用，很难在这个市场上突出。

> 我这个观点会被数字化和记录。我可以出一期内容——不要说00后不努力，我们要理解00后。我想吸引你们，我是不是可以为你们发声？

#### 6.3 行动建议

在AI时代，一定要**保留更多的个人思考和个人的指纹**。这能让未来有更多竞争力。

### §7 脚本创作实操：从用户到故事

#### 7.1 用户分析

柯建军引导学生分析用户：

- 用户定位：年轻人（00后）
- 当下的季节：夏天
- 用户在这个环境下的核心需求是什么？

学生：想吃烧烤，又想解暑，又想不长胖。

柯建军引导：这是三个需求，能不能合并？**夏日清凉美食，还不胖的搭配。**

#### 7.2 脚本结构选择

柯建军：脚本结构分两种：
1. **清单式**：信息枚举
2. **故事式**：有冲突有解决

这题选故事式。

#### 7.3 故事框架

```
背景：夏天吃烧烤
冲突：太辣 / 怕胖 / 招待外地朋友众口难调
解决方案：你的零食清单
```

或者更具体的学生创意：

> 我带着两个人去吃烧烤，想让两个人吃好。一个人太辣了，我直接把一个黄桃（袋装果冻）递给他，"你先喝水再吃这个"。另一个人怕胖，我把魔芋贡菜/笋递过去。最后说"太好吃了"。

痛点找到了三个：**辣、胖、众口难调**。方案就是你的零食。

#### 7.4 地域关键词的运用

学生问：怎么让大连人刷到？

柯建军：算法抓取账号信息通过三个渠道——**画面、声音和文字**。你在标题/正文/口播里说"大连"，出现"大连的00后"，算法就知道推给谁。

学生创意：
> 大连人夏天都有个习惯——吃烧烤和晒太阳。在吃的时候，总感觉太辣、怕胖、招待外地朋友众口难调。今天教你们三招……

#### 7.5 分镜头落地

柯建军：把你刚刚说的想法，按照前面学的景别+构图+视角+运镜，写成分镜头脚本。写完我帮你改。

学生创意：
> 先去买零食，以我个人视角，带两个人去吃烧烤。想让两个人吃好。一个人太辣→直接怼嘴里黄桃→他说太好吃了。

柯建军认可了这个创意方向（"你这个是具体原因"），让学生写成正式脚本，他帮改。

#### 7.6 平台反馈

学生分享：平台刚刚给了我流量奖励，说"很多用户觉得你分享的信息很实用"。平台把账号归为"生活分享"类——"抖音上98%的内容都可以拍，你属于这块"。

柯建军：你持续更新，完成任务可以升级——你就这么理解。不要在乎现在粉丝少（20个播放），那条视频你朋友家人不看，因为他们不是你的用户群。

### 辨伪

- 柯建军说"年轻人不努力是因为努力没什么用" → 偏好而非共识，需标注为个人观点，用于内容创作而非学术引用
  - 说明：这是对宏观经济趋势的感性判断，适合作为"00后账号"的内容角度，不适合包装成行业结论
- "AI时代知识越来越值钱" → 方向正确但边界需明确
  - 说明："通用知识"在贬值（AI可替代），"个人独特思考和经验"在升值——柯建军在授课中已说明这个区分，表述准确
- 第三方视角术语"打破第四面墙" → 没问题，电影专业术语，使用正确
- 手机0.5倍=远景、2倍=长焦等 → 教学简化，不是严格学术定义（柯建军已主动说明"不严谨，但可以这么去理解"）
- 得到录音卡800-1000元 → 需确认当前实际售价，建议核实

### 补充

- 景别教学内容中提到的"五到八位"→ 指的是中景构图的人数范围（2-4人或5-8人的群像），补充了这个解释可以帮学生理解
- 关于平台"赛马机制"：补充说明——平台给新账号的初始流量池较小（通常200-500播放），根据完播率、互动率等指标决定是否推入更大流量池
- 构图部分只讲了三种（居中、三分、前景），柯建军提到"一共七种经典构图"，七种完整列表未在本次讲解

### 优化

- §2画面构成四个要素（景别/构图/视角/运镜）的信息密度非常大，对于零基础学生，建议后续整理成一张速查卡（已完成部分，见对客资料）
- §4旅行拍摄方法可作为一个独立方法论提取——"大动作拆小动作"是可复用的拍摄教学法
