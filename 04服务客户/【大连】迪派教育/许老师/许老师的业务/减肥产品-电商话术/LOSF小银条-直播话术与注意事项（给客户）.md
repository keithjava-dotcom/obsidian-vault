# LOSF小银条 · 直播话术与注意事项

> 产品：LOSF蔓越莓固体饮料（小银条）
> 定价：59.9元 / 3-6天试喝量
> 合规底线：**食品类，禁用任何减肥/瘦身/燃脂/减重相关词**

---

## 一、旧版话术为什么需要改

| 问题 | 新版怎么改 |
|------|-----------|
| 开场太普通（"欢迎新进直播间的姐妹们"） | 用痛点场景/反常识开场，3秒内让人停下来 |
| 卖点用户感知不到（"原料采购成本四百多万一公斤"） | 把品质翻译成用户能懂的东西："你看配料表第一个成分是什么" |
| 灰区词太多（"体态轻盈""线条不一样"仍可能违规） | 全部换成主观体验描述 |
| 篇幅冗长、信息重复 | 结构化：钩子→产品→信任→试用→促单 |
| 缺乏差异化 | 用具体细节替代抽象大词 |

## 四、直播注意事项

### 4.1 绝对禁用的词

| 类别 | 禁用词 |
|------|--------|
| 减肥相关 | 减肥、瘦身、燃脂、减重、掉秤、瘦了XX斤、一个月瘦XX、脂肪 |
| 功效承诺 | 保证有效、一定瘦、包你满意、无效退款（食品不能说"无效"） |
| 医疗暗示 | 排毒、清肠、通便、治疗、调理 |
| 数据承诺 | 7天瘦X斤、腰围减少X厘米、体重下降XX |
| 歧视性表述 | "胖子""身材差""肥胖""臃肿" |

### 4.2 灰区词替换

| 别说 | 改成 |
|------|------|
| 体态轻盈 | "清清爽爽""整个人利落了" |
| 身材线条 | "穿衣服的线条感""版型撑起来了" |
| 变瘦了 | "感觉不一样了""状态变好了" |

### 4.3 安全表达指南

**可以说的方向：**
1. 产品本身——口感、原料产地、包装、喝法、成分
2. 使用场景——上班、出差、下午茶、日常
3. 主观感受——"我觉得""有些姐妹反馈""我个人感受"
4. 品质和信任——产地故事、老客户复购、线下实体
5. 生活方式——投资自己、日常小确幸

**话术转换示例：**
- ❌ "喝了会瘦" → ✅ "喝过的姐妹说感觉自己状态不一样了"
- ❌ "7天见效" → ✅ "3到6天的试喝装，你亲自感受一下"
- ❌ "最好的减肥产品" → ✅ "我自己每天都在喝的东西"

### 4.4 直播节奏

| 阶段 | 时长 | 内容 | 关键 |
|------|------|------|------|
| 钩子 | 0-15秒 | 痛点/反常识开场 | 前3秒决定停留 |
| 产品展示 | 15-60秒 | 展示包装、配料表 | 镜头贴近产品 |
| 信任建立 | 60-120秒 | 讲品质、产地、复购 | 用细节代替形容词 |
| 试用引导 | 120-180秒 | 59.9低门槛、不满意退 | 降低决策成本 |
| 促单 | 180-240秒 | 引导下单、关注 | 给明确指令 |
| 循环 | 循环 | 新观众进来就回钩子 | 每轮按人数调整 |

### 4.5 违规风险点

| 风险 | 怎么规避 |
|------|---------|
| 话术暗示减肥 | 穿插讲产品本身（口感、喝法、配料）做稀释，别连续讲感受 |
| 弹幕问"能瘦吗" | 固定回答："这个是食品，好喝的固体饮料，你试一下自己感受" |
| 展示前后对比 | **不要做**——不能展示减肥前后对比图 |
| 第三方背书 | 只说自己的客户反馈，不说"XX明星在用"除非真有授权 |
| 夸大产地 | 说手里有的，不说"全球唯一""国内独家" |

### 4.6 弹幕应对

| 观众问 | 答 |
|--------|-----|
| "能减肥吗？" | "食品，好喝的蔓越莓固体饮料。我没法说减肥，但喝过的姐妹都说状态不一样了，你试一下感受。" |
| "多久见效？" | "日常喝的东西，不是药。3到6天试喝，你喝喝看自己的感受。" |
| "跟XX比怎么样？" | "不说别人家的。你拿回去看配料表，我们家第一个成分是什么，对比一下。" |
| "会不会反弹？" | "固体饮料不是药，不存在反弹。你喝着舒服就继续喝，就是一种日常饮品。" |
| "为什么卖这个价？" | "马来西亚进口，原料成本在那里。看配料表就明白了。" |

### 4.7 产品展示要点

1. **配料表拍清楚**——让观众自己看第一个成分
2. **有证书就展示**——SC认证、进口报关单是合规保障
3. **没有证书别硬说**——改讲原料故事、老客户复购、口感体验
4. **不做喝前喝后对比**——这是食品不是药
5. **口感示范要真实**——自己真喝，别夸张表演

### 4.8 如果被告违规了怎么办

**第一步：判断违规类型**

- **话术违规**（警告/断流）：立刻切到"安全模式"——只讲产地、口感、喝法、价格，不讲任何感受和效果
- **资质违规**（下架/封禁）：暂停直播，先补资质再开播，别硬播
- **核销违规**（团购版）：确保链接描述和实物完全一致，核销时不加塞其他产品
- **投诉违规**（退款纠纷）：主动退款不纠缠，59.9的损失比封店小一万倍

**第二步：违规时的"安全模式"话术**

> 好的姐妹们，我们继续。这款小银条，马来西亚进口的蔓越莓固体饮料，酸酸甜甜的果味。
> 怎么喝呢？温水一冲，或者直接含嘴里，特别方便。
> 包里放两条，上班、出差、跟闺蜜出去，想喝的时候来一条。
> 就是一款日常饮品，好喝的固体饮料。
> 59.9到手3到6天的量，喜欢这个口味的姐妹拍1号链接。

**安全模式铁律**：只讲产品事实，不涉及任何感受/效果/状态变化。

### 4.9 资质情况分级处理

根据你手里实际有的证书，决定直播怎么讲：

**如果你有SC认证+进口报关单：**
直接展示证书——"来，SC认证给你看，报关单给你看"。这是最强的信任方式。

**如果你只有部分证书：**
有什么展示什么，没有的不提。信任建立从"证书"转到"复购+时间"——
"这东西在线下卖了好多年了，老客户一箱一箱搬。你自己喝一口，舌头不会骗你。"

**如果你暂时没有证书：**
别说"给你看认证"——拿不出来是欺骗，平台抽查会下架。
用这三种方式建立信任：
- 原料故事——"马来西亚的蔓越莓，跟超市买的不一样"
- 个人体验——"我自己喝了大半年了，包里常备"
- 老客户复购——"评论区全是老粉，喝过的都来回购"
