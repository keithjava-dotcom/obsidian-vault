# 愈见SPA馆 · 课程学习计划

## 一、先纠正三件事（比学什么更重要）

**1. 别急着直播。**
直播就是实时版的视频——人、声音、内容，逻辑一模一样。你现在视频都没做过几条，直播上去讲什么？花钱推流，一天没流量；花200块推流，卖不出单怎么办？短视频能7×24小时帮你跑流量，直播下播就没了。先拍视频，打基础，直播后面自然来。

**2. 别急着找探店达人。**
自己号都没有，达人的流量你接不住——薅羊毛的人来完就走，转化不了。正确顺序：先自己起号（约一个月），再找达人往自己号里引流。一块钱要花在价值点上。

**3. 别问"一个月能不能做成"。**
你干啥事一个月能做成？但也不用怕——这门课两周学完，学完立马开干。方向对了，快慢都有意义；方向错了，越快越浪费。

## 二、学习内容（四周）

### 第一周：账号重开 + 认知建立

| 天数 | 内容 | 动作 |
|---|---|---|
| 第1天 | 旧账号注销（等7天，手机号可重新注册） | 立刻做 |
| 第2-3天 | 理解"获客三方式"：私域邀约 / 本地平台商品卡+门店卡 / 品牌企业号——先用①和②，③暂不考虑 | 写下来你的店适合哪几种 |
| 第4天 | 理解"运营=内容运营+粉丝运营"：你的客户想看什么、想听什么 | 写3条"我的客户最想知道的事" |
| 第5天 | 理解账号限流原理：打广告必被限流，内容要先给价值 | 记住：先有价值，后谈成交 |
| 第6-7天 | 锚定人群 ⭐：拒绝"男女都有20-40岁"，做具体——"30岁以上女性，上班+带娃，咳嗽气短" | 写出你的具体人群+痛点，柯老师帮你过 |

### 第二周：内容红线 + 讲故事能力（SPA行业关键）

| 天数 | 内容 | 动作 |
|---|---|---|
| 第1天 | ⭐行业红线：养生类不能讲科普——广告法不允许无执照宣传，平台会下架"轻养生"科普 | 记住：功效两个字永远不碰 |
| 第2-3天 | 学讲故事：不讲"肺不好怎么治"，讲"今天来了个顾客，上班心里不舒服，做了几次项目，改善了"——讲人、讲事、不讲功效 | 写一个你店里真实的故事 |
| 第4天 | 生活分享：秋天多吃梨、银耳——只讲吃法不讲功效 | 拍一条"入秋生活小常识" |
| 第5-6天 | 内容两种形式：口播（建立信任感）+ 旁白配画面（展示局部手法） | 各拍一条对比 |
| 第7天 | 内容两类：营销类（不挂东西）+ 成交类（推广项目） | 把前两条分类，规划你账号的前10条 |

### 第三周：创作基础三件套（课程核心）

| 天数 | 内容 | 动作 |
|---|---|---|
| 第1-2天 | 文字：文案怎么写——选题→大纲→结论的链条，先讲清楚再拍 | 用模板写一条完整文案 |
| 第3-4天 | 画面：拍什么、怎么拍——局部手法特写、店里的真实场景 | 拍3条画面素材 |
| 第5-6天 | 声音：怎么说话、配音/配乐选择 | 录音对比：自己念 vs 旁白 |
| 第7天 | 综合：一条完整的视频——选题+文案+画面+声音 | 出你账号的第一条正式视频 |

### 第四周：起号 + 引流

| 天数 | 内容 | 动作 |
|---|---|---|
| 第1-3天 | 新账号注册+发布：先发三五条，不要急着挂链接 | 保持每周3-5条节奏 |
| 第4-5天 | 运营基本功：评论区互动、粉丝私信→加微信→私域邀约 | 每天30分钟 |
| 第6天 | 探店达人怎么选：找跟粉丝契合的同类目博主（颜值/美食），看商品标价，谈合作 | 列3个候选达人 |
| 第7天 | 复盘：哪条数据好？为什么？下一批拍什么 | 跟柯老师过一遍 |

## 三、SPA行业特别提醒（写在前面）

1. **功效红线**：你叫"轻养生"没用，平台按养生类管你。广告法不允许没执照的人宣传科普——讲了必下架。
2. **出路是讲故事**：店里的真实顾客故事、生活分享——讲人讲事，绝不讲功效。
3. **信任感是你最大的资产**：顾客办会员卡（几千块）之前，得先在视频里认识你这个人。口播是必须的，别只发画面。

## 四、学习节奏（针对你的情况）

- **总时长**：4周（含1周账号注销等待期）
- **投入**：每天1-2小时
- **关键原则**：两周学完基础，第三周开始正式发布，边做边学——不要等"学好了"再动手，先发三五条再迭代
- **你的优势**：行业有内容矿（手法、场景、顾客故事都是素材）；**你的风险**：太着急——急着直播、急着达人、急着花钱。记住柯老师的话：你越着急，越要按正确的顺序快速行动

## 五、验收标准

1. 第2周末：能写出一条完整的"讲故事"文案（不碰功效）——通过柯老师点评
2. 第3周末：发布第一条完整视频（选题+文案+画面+声音全齐）
3. 第4周末：账号有5-10条内容，开始做私域邀约动作
4. 一个月后：能自己判断"这条为什么行/不行"——不再需要人盯着
