## 二、柯老师讲了什么

### 1. 课程整体设计与学习方法
- 课程流程：定位 → 选题 → 内容设计 → 拍摄 → 剪辑 → 发布 → 复盘（"把视频做出来之后，接下来要对流量负责，需要拿到市场上去单独验证一下。此外还有一个复盘环节，总结哪些地方好、哪些不好"）
- 学习方法：边学边实践，"我建议你在（背景）学习过程中实践，这样基本上完课后能做出几个成品，整个过程也会很清晰"；课后群里随时沟通
- 柯老师的教学思路："我上课的思路可能和别人不一样，我喜欢先做一个大纲，构建出整套内容，然后后续所有课程都围绕这个粗略的草稿进行迭代优化"
- 柯老师承诺：免费陪跑一个月，"如果说需要长期的话，可能需要单独付费"；讲课框架会发给学员复用

### 2. 账号定位
- **定位核心原则**（关键原话）："我们定位的前提是找到与用户的关系"，然后想清楚"为这类群体提供什么样的价值"——这两点就是定位的核心原则
- **关系案例**：
  - 董宇辉（东方甄选）：讲产品的故事、原理、历史，风格文艺，与用户是"老师和学生"的关系（很多人其实是来听课的）
  - 李佳琦：人设像"男闺蜜"，从口红开始"买买买，给你买买买"
  - 大杨哥、小杨哥、赵本山：娱乐关系，"我来逗你乐"，我在娱乐你
  - 丁香医生：互联网医院，与用户是"陪伴者"关系，用非常年轻化的方式互动
  - 深圳卫健委：会玩梗、与观众打成一片（人设"口口医生"【待确认，疑为"深小卫"】）
  - 罗永浩：与用户是"铁子"、兄弟关系；提供的价值是帮用户从众多优质货源里挑出便宜货——原价可能一万，朋友价七千，货真价廉
  - AI爽剧：提供的是"看得舒服、放松"的情绪价值
- **二甲的处境**（关键原话）："因为咱们是二甲，不是三甲。三甲可以宣传，二甲不能宣传。这个时候我们就换种形式，最常用也最好用的一种方法就是讲故事"
- **定位还要考虑出镜人**：有人说话会紧张、有人专业不够丰富、很多问题解决不掉——找出机构的优势，扬长避短
- **本院定位推导**：
  - 受众画像：60~70岁为主（结石的年龄层），偶尔50+、40~50
  - 出镜人：几个漂亮、性格活泼的小姑娘 → 与受众的关系 = "孙女与长辈、晚辈与长辈"
  - 晚辈对长辈能提供的价值（五大类内容）：
    1. **就医流程类**：挂号怎么挂、怎么找医生、医生开各科室检查、拿结果、怎么给医生看；体检流程、结石流程、住院手续办理流程——逐步细化，"可以再慢一点、缓一点，别那么快，然后详细一点，第一步、第二步、第三步、第四步"；这类内容转发量最高，"因为它实用"
    2. **患者家属服务**：如何给家人开中药、如何拿诊断报告等非常细致的指导
    3. **治疗前后**：手术术前准备、术后注意事项
    4. **生活常识**：高血压应该吃点什么、秋天来了要注意什么、有结石的人不能吃什么能吃什么（"每个科室的一些嘱咐"）
    5. **医患关系/情感需求**：通过讲故事展现医院的正向引导；子女成年在外、老人独居的情感需求，给建议（户外活动、找朋友聊天）
  - "当我的账号按照这种流程去做，五大类内容……以晚辈对长辈说话的调性，为他们提供五类价值。我们只需要在这五大类用户中，用各个小的选题去带就好……这就是定位的科学"

### 3. 用户剖析与选题
- 创作流程第一步：清楚定位后做选题，"选题一定是从用户的需求、用户痛点出发，因为我们的故事不自嗨"（关键原话："如果你自己讲故事，说我们的医院怎么干净怎么大，那就是自嗨了，因为这跟用户没有关系"）
- 剖析用户四件事：他们是一群什么样的人、痛点是什么、需求点是什么、时间点（哪些能满足、哪些满足不了；满足不了的用内容引导、侧面展示）
- **本院用户痛点**（学员提供）：
  - 专家难约：回访电话里反映最多（有几个学院专家定期出诊，但这个问题很难解决）
  - 医保报销比例不高（解决不了）
  - 不懂分级诊疗：老年人会到二级医院要求三级医院的设备（设备不能满足，级别就在那里）
  - 看病贵（学员自己觉得其实不贵）
  - 谁来了都想享受VIP待遇、想让大夫注意他
- **马斯洛需求五层次 → 选题模型**：
  - 生理需求：流量最大、大家都爱看（例子：315食品安全曝光、新能源汽车行业揭秘；"80岁老人千万不要……"；"老人睡觉前床前一定要放一杯水"——涉及生存问题）
  - 安全需求：吃得饱穿得暖之后，想吃得更好穿得更好
  - 社交需求：人是社会性动物（"抖音叫社交媒体，它就主打一个东西，就是社交"）
  - 尊重需求：被理解、被尊重；自我实现（韩红做公益）
  - **应用到本院选题**：生理层（"千万不能做什么"、睡前一杯水）；"活得更好"层（开海季之后大连老人哪些海鲜不能吃或应该少吃、年夜饭给老人准备什么、三高人群怎么吃）；社交层（医院有什么活动、老人参加社交的好处、老人如何在晚年找到伴侣朋友）
  - **流量逐层下沉**：越往上受众越少（"现实中，达到较高层次的人基本上不看这些内容"——学员也说领导基本不看短视频）；"我们做好这三大核心点就够了"
- **没流量的排查逻辑**（关键原话）："我们讲述的这个主题，是否触及到了目标人群的生理需求。如果没有触及到他，那他肯定不看……首先需要刺痛点，但刺痛之后，你要提供价值并促成改变。你不能光刺痛我，却不提供解决方案"
- 素材挖掘问法："或者最近你觉得天天发生什么事，你记得不清楚"

### 4. 内容设计：故事模型与清单式
- **故事模型四步**：背景 → 冲突 → 疑问 → 答案
- **现场示范案例（老慢支患者）**：
  - 背景：沙口【待确认，疑为"沙河口"】住的一位叔叔，70多，在我们医院附近住
  - 冲突：生活中突然觉得自己很喘，一检查是个老问题；爬楼梯、劳动都喘，根本运动不了，说话都喘
  - 疑问：来我们这治疗过两次，第一次效果非常好、明显改善，今年由于天气等原因又变得不好了（素材原型：70多岁女性患者，去年住一次院、一年多没犯病，今年三月份住一次、现在又住一次，效果不好）
  - 答案：温馨提示——日常饮食、日常护理、日常锻炼建议（每天慢走十分钟、二十分钟，多吃某些食物，教几个恢复肺功能的动作）
  - "这一类群体，他看到有相同的经历的话，会觉得这段视频对他有帮助"
- **素材具体化原则**（关键原话）："素材收集得越具体、越详细，故事就越真实"——年龄、性别、住哪、身高、穿什么样的衣服、来的时候什么感觉、走的时候什么表情；"只要把一个素材描述得越具体，观众就会以为是真的"（电影电视剧的脚本都非常详细，所以感觉真实）
- **情绪价值选题**（正能量故事，流量大）：
  - 邻居送老人看病（不是儿子也不是女儿，是邻居/外甥）→ "我们平时要多跟邻居搞好关系"；展示社会的正能量
  - 无保护老人【待确认，疑为"五保户"】：无儿无女的老人，医生看完病把自己的衣服送给他们；年轻护士非常有耐心，有的老人天天大喊大叫护士也不嫌弃
  - 儿子照顾父亲一个月：70岁老人，儿子40多岁、事业顶峰期，"说停就停下来"照顾
  - "谁说女子不如男"：接待的患者里将近70%是女人陪着，女儿跑上跑下给父母搬东西
  - 孙子照顾老人、朋友第一时间送发病老人就医（孩子在外地）
  - 柯老师补充："艺术来源于生活……我们只是找出不同的角度来去挖掘出来即可"
- **清单式模型**：背景 + 冲突 + 答案（例子："秋天不能吃的三种食物"、"70岁老人如厕之后一定要干的三件事"，一、二、三列举）——学员反馈客户基本都选这种清单式题目
- **公众号案例改造（失眠焦虑）**：
  - 原内容："失眠焦虑的福音"——问题：看完不知道能对自己有什么改变，太正统、平铺直叙
  - 改造示范："三招解除你的失眠和焦虑"：第一招脑电生物反馈（"脑电波是目前治疗失眠的最好办法，排名第一"），第二招中医针灸，第三招耳穴疗法
  - 结构：结论先行 → 是什么 → 为什么 → 如何做；"先说结论"
  - 清单式标题写法："十年焦虑每日必做的三个事情"；**多用数字**
  - 老年人看字费劲：要么字特别大，要么靠听
  - 细节填充：这个仪器每疗程十五分钟、一个月做几次
  - 标题要会"吆喝"（关键原话）："我们赶大集的时候看到过，他们也在喊喇叭、喊东西、吆喝。你得吆喝，你不能坐等他们来……先吆喝把人吸引过来……你要让观众对此有获得感，你要给他一个理由，他们为什么要看这个视频"
- **硬广改造示范（胃肠镜）**：
  - 学员现有视频（原话）："害怕胃肠镜麻烦耗时还要住院。大连金辰医院【待确认，疑为"机车"】胃肠镜彻底解决您的顾虑，当天就诊，当天检查，当天搞定。"
  - 柯老师点评："你这就叫硬广。我们把这个视频拍短一点"
  - 钩子开头示范：口气重 → "被女朋友嫌弃口气重怎么办？"（地铁里被嫌弃、自己刷了很多遍牙不管用、试过很多方法）→ 可能是你的胃出了问题 → 挂科室、做检查 → 出诊断；"但你不能说得太官方，一定要用交流对话的方式"
  - **同一内容三种形态**：①对话式检查诊断（10分钟解决）；②讲故事（开点玩笑，有洁癖的人为什么还会口臭，来医院一查）；③信息清单式（症状：胃疼、胃胀、反酸、口气重、拉肚子 → 原因一二三 → 做一次胃肠道检查，"十五到二十分钟，只需要二十分钟彻查"）
- **高血压视频改造**：原视频"前十秒到前十五秒，倒计时基本都是废话"；改成"一条视频教你十招控压小技巧"，一个大夫说三条；"你可以稍微慢一点……但是我们的信息颗粒度一定要清晰明亮"

### 5. 拍摄（画面三要素）
- **构图**：手机屏幕九宫格，**居中构图**，"把拍摄主体放在中间……这是最快可以拿来使用的构图方法"
- **景别**：远景、中景、近景、特写（"远中近特"）
  - 远景：0.5倍焦距，拍环境和主体的关系（人往公园里走）
  - 中景：把脚、上半身和道路拍进去（坐下、拿包、倒水）
  - 近景：动作（喝了一口水）
  - 特写：细节（写了什么字、针怎么插进去）
  - "它是通过画面的大小来讲故事。想象一下，即使没有任何文案，这四个画面加在一起，我们是不是大概知道这个人在哪、干了什么事"
- **镜头运动**：推、拉、摇、移、跟、甩
  - 推：主体不动，设备向前走——加深情绪（一个人惊恐时瞳孔放大，画面慢慢推近变大）
  - 拉：主体不动，设备向后走——展示更多信息、情绪由浓变淡（电影结尾常以拉回镜头结合大音乐结束）
  - 摇：主体不动，设备转动——展示更多信息（正面、侧面）
  - 移：主体不动，设备跟随移动
  - 跟：主体动设备也动，跟着拍——从一个方向到另一个方向、一个空间到另一个空间（办完手续穿过走廊找到第二个窗口）
  - 甩：主体不动，镜头从上往下甩过来，"没什么情绪传递，只是酷炫而已"，很少用
  - 应用示例：表现老人孤单→从他的脊背往回拉，拉出他看着窗外空旷的地方；表现老人笑得可爱→往前推，推到他的笑容
- **声画统一**（关键原话）："根据我们布置的文案，一句话一句话地把文本翻译成画面"……"我最起码要做到声画统一【原转写"深化统一"，待确认】，说到什么话就得放什么画面"
- **拍摄隐私**：患者不出镜、不露正脸，拍背影、侧脸，甚至可以去打光；"我们不太敢冒险，没签那个（授权），口头答应了没用"；医生护士可以拍
- **设备**：学员单位电脑只满足办公配置，柯老师说手机剪也行，"逻辑是一样的"

### 6. 剪辑与成片
- **A-roll**（原转写"A肉"【待确认】）：对着镜头一次性把文案说完（口播）
- **B-roll**（原转写"B肉"【待确认】）：把文案里出现的名词和动词拍下来（脑电波仪器怎么放耳朵上、医生插针的远中近特写），剪映里做画中画
- 音乐：找轻一点的、中国古风类背景音乐，"背景音乐淡一点"
- 花字：重点词（如"失眠焦虑"）加花字字幕
- "结构加血肉"：文案结构定了，默认往里填内容就好
- 全流程：拍好 → 剪 → 发布 → 优化

### 7. 发布、数据与引流
- **看数据**：自然流量、评论、转发、收藏；"有的视频可能点赞比较多，但是没有人评论；有的视频可能评论比较多，但是流量上不来"
- 学员现状判断：点赞、转发、评论都不太对 → "内容基本都没了……就是流量的问题，也是选题的问题"
- **视频号引流**：
  - 通过做好内容让观众主动来问，不要留电话号码（"咱们不要留电话号码……让对方发电话号码"）
  - 门诊、缴费处有大量流量，"贴个码"，扫码进私域
  - "填码之后一定要先提供一些对用户有用的价值，提供价值之后跟他们玩起来"
  - 私域就是微信加好友；做好一个内容往科室群里发、让大家转发（群里有在院患者、患者家属，还有出院的）
- **分发**：一条视频四大平台（抖音、快手、小红书、视频号）一起发，"我觉得花不了钱"
- **平台逻辑**（关键原话）：平台都在抢客户、抢用户，日活【原转写"热火"，待确认】直接影响股价；平台不希望看到广告（"你在我这个平台放广告相当于用我的免费资源给自己打广告，平台肯定不允许"）；平台喜欢的是"你拥有优质的拍摄能力和创作能力，能让更多人在这个世界上停留更长时间，这个是最重要的"
- **内容方向**（关键原话）："做内容……把一些看似像广告的东西变得不像广告，把一些比较枯燥无聊的内容变得更好玩一点"

### 8. 平台选择
- **抖音**：年轻群体最多，爱搞新东西、玩梗整活；从音乐流行起来，音乐传播力强；对创作者要求更高（"需要更有创意、更细腻"）；考核数据特别严：两秒跳出率、五秒完播率、停留时长、回看率；适合卖价格较低的专业类产品
- **快手**：三四五线城市、县城地区的人和中老年人；"是国内最早的（短视频平台），只不过后来他们的运营策略比较low，导致定位出现长期问题"；内容浮夸、八卦多；要做就"极其接地气，说白话一点"
- **小红书**：中高知人群、女性多；喜欢"种草"；内容质感要好（拍得低劣没人看）；**客单价高**（案例：运营护肤账号卖面膜，定价100元以内几乎无人问津，后来选一款三千多元的面膜，一场直播也能卖三五份，客单价可达数千甚至数万元）
- **视频号**：用户是社会上有地位、有身份的人+中老年（忙、离不开微信）；**信任度高**（微信好友之间有信任基础）；不冲动消费，但愿意为高价值的产品/服务付费（招商加盟类内容能从视频号获得更精准的客户；客单价三五万甚至十多万都能接受；用户看不到你的粉丝数据，"只要觉得你讲得对，就会为你买单"）；**新风口、前景好**（前三个平台已经非常内卷，腾讯社交强但电商不足）
- **账号与挂载**：抖音不能以单位申请、只能个人；视频号申请人是个人不是医院，上传商品需要生产资质，"个人最好用医院的名义……写员工"；跟绑定的手机号有关，可以重新认证、提交资料；体检科可以重新开一个号挂载

## 三、学员被指出的问题
1. **账号身份混乱**：抖音以单位申请不下来（企业+事业单位双重身份）；视频号是个人身份、没挂医院名义
2. **内容偏硬广、平铺直叙**："害怕胃肠镜麻烦耗时还要住院……"就是硬广；公众号官方腔、"比较正统"
3. **开头废话多**：高血压视频"前十秒到前十五秒，倒计时基本都是废话"
4. **标题不会吆喝**："失眠焦虑的福音"看完不知道对自己有什么改变；不会用数字、不会结论先行
5. **产出量小、人效低**：一周2条视频+每月4条公众号，量很小；每人每天只有半小时，时间不够
6. **数据差**：点赞、转发、评论都不行——"就是流量的问题，也是选题的问题"
7. **学员自己不刷视频、不看博主**（"你不想看，我没有时间"）——对内容形态缺少感觉
8. **团队能力断层**：没人专职、导诊学历低、学中文的同事被党建占满、单位进人难
