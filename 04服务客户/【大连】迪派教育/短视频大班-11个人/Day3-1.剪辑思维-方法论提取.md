# Day3 方法论提取 · 可复用知识框架

> 提取原则：只提取跨学员、跨账号可复用的判断框架和操作流程。个案建议不入库。

---

## 一、剪辑方法论（4条）

### 1.1 剪辑分层思维
> 剪辑不是一步到位，是逐层堆上去的。

分四层，按顺序做，不乱：
1. **智能剪口播** → 粗筛（机做，必须人工复核）
2. **粗剪** → 删不影响意思的废话（人做，不留情面）
3. **精修** → 气口保留0.3-0.5秒、字幕一行、画面质感（描边/取色/音乐）
4. **B-roll 插入** → 名词动词法填充画面

适用：所有视频类型，教学/口播/Vlog 均可用。

### 1.2 智能剪口播双保险
> 第一步用AI剪，但第二步必须人工检查。

- 剪映的智能剪口播只认字不认意——它会删掉关键内容
- 用户逐句过一遍，不能偷懒：关键词删了没？情绪断句切了没？别人问话那段保留没？
- 人工智能 = 帮你加速 + 你必须复核，不是帮你全自动

### 1.3 字幕一行原则
> 人眼一次只能聚焦一个点。

- 字幕两行 → 观众需要扫两次 → 注意力分散 → 划走风险增加
- 字幕一行 → 一眼看完整句 → 注意力立刻回到画面
- 宁愿删内容也不分行——因为分行的代价（跳失）> 删掉那半句的代价

### 1.4 画面质感=信任成本
> 画面质感决定了粉丝为你付出多少金钱和时间的成本。

- 字幕描边细（15-20）→"这东西精致"→ 愿意认真听
- 描边颜色取画面色块 → 字幕"长在画面里"不是"贴在画面上"
- 不用剪映默认花字/音乐 → 差异化从第一步就建立
- 字体不超过 2 种 → 少一分乱，多一分稳定

## 二、音乐方法论（1条）

### 2.1 起承转合匹配法
> 音乐有结构，故事也有结构，让两个结构对上。

- **起**（前奏/引入）：对应文案的吸引注意/抛出问题
- **承**（主歌/展开）：对应文案的背景叙述/细节展开
- **转**（高潮/转折）：对应文案的冲突点/关键信息/情绪爆发
- **合**（尾声/收束）：对应文案的结论/行动呼吁

操作方法：把 BGM 波形放大，找出四段的节点 → 把文案四段对准 → 多余的部分缩掉。音量参数固定：人声 0-6，BGM -20 到 -12，音效比 BGM 再低。

## 三、B-roll 方法论（3条）

### 3.1 名词动词法
> B-roll 就是给文案里的每个名词和动词配上画面。

- **名词法**：文案提到"超市"→ 拍超市门头。提到"凌晨"→ 拍窗外月亮。提到"辞职"→ 拍工牌/工位/公司logo
- **动词法**：文案说"收拾东西离开"→ 拍背包/关门。说"给孩子冲奶粉"→ 拍手晃奶瓶/倒水
- 心法：念一句文案 → 问自己"这句话里有几个名词、几个动词" → 每个配一个 5-7 秒画面

### 3.2 5-7秒原则
> 不是视频短，是每个画面的寿命短。

- 口播间隔有效，但 B-roll 的每个画面必须 ≤7 秒
- 观众看一个静止画面超过 7 秒 → 注意力衰减 → 开始加速/划走
- 前五秒建议 2-3 个画面快速切换（每个 1-2 秒）→ 信息密度达到最大

### 3.3 情绪空镜头
> 不只拍"对应的物体"，也拍"对应的情绪"。

- 沮丧 → 下雨的窗、空荡的房间
- 开心 → 阳光透过树叶、笑脸
- 寂寞 → 深夜的街灯、一个人的背影
- 这些画面不一定跟文案直接相关，但能把观众带到那个情绪里

## 四、设备与赛道方法论（1条）

### 4.1 设备=赛道=竞争难度
> 你用什么设备，就进什么赛道。

- 手机拍 → 跟普通人竞争 → 观众期待低 → 做得好容易超预期
- 相机拍 → 跟摄影师竞争 → 观众期待高 → 每一帧都要电影级 → 更难出圈
- 这是"降低预期→超预期交付"逻辑，不只与设备有关——起号期用最朴素的工具，跑起来再升级

> ⚠️ 柯老师教学中用"平台打随拍标签/摄影标签"做类比，实际平台的设备识别和处理比这更复杂。核心逻辑（降低预期→超预期）是通用的。

## 五、画面叙事方法论（4条）

### 5.1 四大景别速记口诀
> 0.5/1.5→远景（环境），1→中景（人物），2~4→近景（动作），4~8→特写（细节）

- 一条好视频至少用到三种景别
- 口诀不专业但实用——学生在手机上看四个数字，立刻知道该用什么镜头
- 练法：拿一句文案，拆成四个景别的画面描述

### 5.2 三分线构图
> 开网格线，主体放交叉点上。

- 手机设置 → 相机 → 打开网格线
- 人偏左/右 → 另一侧留环境 → 画面有呼吸感
- 居中构图 + 三分线构图交替使用 → 画面不单调

### 5.3 六种运镜的双目的
> 推拉摇移跟甩，先分清你要"展示信息"还是"强化情绪"。

- **展示信息**：慢推、慢摇、移 → 让观众看清
- **强化情绪**：快摇、甩、推近人脸 → 让观众感受到
- 一条视频 2-3 种运镜就够了，不炫技

### 5.4 俯仰视角=情绪语言
> 俯拍=渺小/脆弱/困境，仰拍=强大/权威/力量。

- 俯拍：人物挫折/失败/脆弱时使用
- 仰拍：人物觉醒/重新站起/坚定时使用
- 这两个视角不是技术选择，是叙事选择

## 六、能力训练方法论（2条）

### 6.1 看图编故事
> 有稿子按稿子拼图，没稿子看图编故事。

- 从素材库随便拿一条素材 → 立刻讲出"发生了什么 + 我的感受"
- 练法：每天关掉声音看一条视频，猜故事 → 打开声音验证
- 积累越多素材，这种直觉越强

### 6.2 情绪素材随手拍
> 每一次情绪波动都是素材。

- 开心/难过/不爽/惊喜 → 掏出手机拍 3-5 秒
- 不删。两个月后你会有 500 条用不完的素材
- 这是剪辑师的基本功——不是技术，是习惯
