# Day7 学生素材卡 · 短视频大班（11人）

> 用途：学生课后复习 + 实操练习清单。本卡从 Day7 课堂中提取可执行的知识点和练习任务。

---

## 一、核心知识框架（5分钟复习）

```
AI时代底层能力
  ├── 视听语言（画面叙事能力）
  ├── 编导思维（脚本写作能力）
  └── AI协同（提问+决策能力）

短视频工作流（五边形）
  定位 → 选题 → 大纲 → 脚本 → 拍摄/剪辑 → 复盘
    ↑___________________________________________↓
```

**一句话记住**：这个时代不需要你会（画图/剪辑/写代码），需要你会想、会提问、会决策。把专业知识告诉AI，让AI帮你执行。

---

## 二、学生实操练习清单

### 练习 1：给自己做账号定位（核心任务）

**工具**：打开5个AI（豆包/DeepSeek/智谱清言/通义千问/Kimi），逐个执行

**步骤**：
1. 用提问公式写一段精准的Prompt——角色（我是谁）+ 目标（我想做什么账号）+ 场景（我现在的状态）+ 问题（我应该怎么开始）
2. 把定位五问（你是谁/你知道什么/你想要什么/你的风格/你的顾虑）的答案告诉AI
3. 同样的问题问5个AI，对比答案，自己做决策
4. 把最终定位结果保存到本地文档——这就是你的**个人数字资产数据库第一步**

**提交**：下节课前完成定位初稿，可私发柯建军获得反馈

---

### 练习 2：给自己梳理故事线

**步骤**：
1. 打开手机相册，从最早的照片看到现在
2. 按时间线写出关键节点：教育经历 → 第一份工作 → 转折点 → 现在
3. 找出3个"有冲突"的故事——失败/赔钱/辞职/低谷/反差
4. 每个故事用一句话总结：发生了什么事 + 你怎么想的 + 结果是什么

**参考模板**（柯建军课上律师案例）：
- 从专科到律师——怎么考下来的？
- 无人机项目赔了15万——为什么自愿承担？
- 实习律师月薪750块——怎么熬过来的？

**判断标准**：你的故事能不能让陌生人听完后说"原来你是这样的人"？能=过了。

---

### 练习 3：把故事变成视频选题

**步骤**：
1. 从练习2的3个故事中，选1个最想讲的
2. 用三大板块框架归类：这是"故事类"还是"专业类"还是"观点类"？
3. 写一句选题标题（就是你视频封面上那行字）
4. 列3个你在这个故事里会提到的具体画面（名词）+ 动作（动词）

**示例**：
- 故事："我从纪检委辞职做律师"
- 分类：个人故事类
- 选题标题：从体制内裸辞，我赔了15万才明白的事
- 画面清单：纪检委大楼（名词）+ 辞职信（名词）+ 律师证（名词）+ 无人机残骸（名词）+ 他在法庭上站起来（动词）

---

### 练习 4：ARoll/BRoll 拆分实操

**拿练习3的选题，做以下拆分**：

| ARoll（你说的话） | BRoll（画面） |
|---|---|
| "2018年我从纪检委辞职" | → 纪检委大楼外景 |
| "所有人都觉得我疯了" | → 朋友的表情/聊天截图 |
| "我第一个月只赚了750块" | → 工资条/银行卡截图 |
| "现在我在徐州做工程律师" | → 法庭/工地/与客户签约 |

**口诀**：找出句子里的名词和动词，拍下来，剪进去。

---

### 练习 5：AI提问能力训练（每天必做）

**三个"不要"**：
- ❌ 不要只问一个AI——至少问3个，对比答案
- ❌ 不要把AI当许愿池——目标要可实现，不要浮夸
- ❌ 不要在一个对话框里聊太多问题——一个对话框只解决一个问题，解决了就换新的

**每日任务**：
1. 打开一个AI，用四要素公式（角色-目标-场景-问题）提一个跟短视频创作相关的问题
2. 看他怎么回答的
3. 反问一次："为什么你给出的建议是这样的？你的思考过程是什么？"
4. 把有价值的回答复制保存到本地文档

## 五、避坑提醒

1. **不要背稿子**——观众一眼看出假。用AI把结构润色成你的说话风格，对着镜头说，别念。
2. **一个对话框一个任务**——聊多了AI会变傻（上下文污染），定期清理。
3. **Token计费陷阱**——有些平台"一句话六块钱"，用之前搞清楚计费方式。
4. **警惕AI平台≠AI**——360 AI、腾讯元宝等是应用平台，不是底层大模型。
5. **先定位再选题，先选题再写文案**——这个顺序不能颠倒。
6. **数据放本地**——Word/飞书/Obsidian都行，但别只留在一个AI的聊天记录里。
7. ⚠️ **闲鱼代充Claude/GPT有账号安全风险**，请自行评估。
8. ⚠️ **本卡中柯建军操盘案例数据（大连家政300万/年等）为课堂口述，未经独立核实**，面试/汇报时建议用自己的实际案例替代。
