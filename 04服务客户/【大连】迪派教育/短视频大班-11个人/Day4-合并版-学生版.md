# 2026-07-18 迪派大班Day4 · 从工具到成片：一条视频的完整工作流

> Day4三节课串成一条线：先用对AI工具 → 学会诊断自己的视频 → 用自己的人生经历做内容 → 把稿子改好 → 拍出来。
> 每一节都能独立用，连起来就是你做一条视频的完整流程。

---

## 第一部分：AI工具箱 + 视频诊断框架（Day4-1精华）

### 你的AI工具箱：什么环节用什么AI

| 你要做的事 | 用什么 | 为什么 |
|-----------|--------|--------|
| 想选题、碰撞灵感 | **豆包** | 字节出品，训练数据是抖音的，更懂抖音用户 |
| 查资料、深度研究 | **DeepSeek**、**智谱** | DeepSeek性价比高逻辑强；智谱中文处理牛 |
| 写好初稿后精修文案 | **DeepSeek**、**千问** | 让它帮你加钩子和评论区引导点 |
| 视频发了看数据复盘 | **豆包** | 把稿子和数据一起发给它分析问题 |

**红线**：AI给的分析结论仅供参考——它不会为你的结果负责。决策还是你的判断力。

### AI能干什么、不能干什么

**能干的**：快速生成选题、帮写初稿（可以当起点）、分析爆款结构、提供数据复盘建议。

**不能干的**：
- 替你写最终文案——"短视频的逻辑是自我的表达，让别人替你说再转述出来就特别假"
- 替你做决策——AI有幻觉、没有人味、没有感情
- 替不懂剪辑的人剪出好片子——你得先懂节奏、起承转合，提示词写得够详细它才能干得好

> "未来三到五年，使用工具的技能越来越不值钱。但**系统思维能力和对工作流程的把控是AI学不走的。** 你的真实经历和体验感，AI没有。"

### 怎么诊断一条视频：声音·画面·文字三维检查法

**声音维度**
- 加音效抓人：打击音效、翻书声、倒水声
- 音乐要跟内容情绪动——别一条BGM铺到底

**画面维度**
- 最精彩的素材放前五秒
- 放冲突画面：有情绪爆发、动作、对比的画面优先
- 场景要真实——别站白墙前面拍

**文字/文案维度**
- 痛点要够痛：刺到"对，我就是这样的"
- 反常识开头：跟常识反着来，观众才想听下去
- 节奏不能平：前两秒钩子，中间不停抛新信息，结尾给行动点
- **获得感才是王道**：抖音考核"精选视频"看的是观众听完有没有收获
- **完播公式**：痛点 → 三步解决方案 → 一到两周预期改善 → 引导持续关注

## 第二部分：你的故事怎么讲（Day4-2精华）

### 个人故事结构化：时间线分阶段法

1. **大学时期** → 发生了什么事
2. **即将毕业时期** → 经历了什么转折
3. **上班时期** → 遇到了什么问题

每个阶段写一个小故事，每一年用一句话串起来。

> "我不是为了博取同情，我是想告诉更多和我一样的人要接纳自己。"

这句话把故事从"卖惨"变成了"帮助同类人"——观众听完不是同情你，是感谢你。

### 从生活习惯里挖选题：自问三步

1. **我有什么习惯或优势？**（比如每天五点半起床）
2. **我为什么要做这件事？**（早起是为了学习，不是为了做样子）
3. **这件事能给别人什么启发？**（宝妈也能自律、能挤出时间提升自己）

❌ "我五点起床" → 观众无感
✅ "我是宝妈，但我每天五点起床学XX，因为我想XX" → 观众觉得有东西

关键：生活习惯本身不是内容——**你通过这个习惯变成了什么样的人、达成了什么结果，才是内容。**

### 最重要的一条：先讲自己，再讲知识

> 你为什么能讲育儿技巧？因为你带过孩子、把孩子养得很好。没孩子的人讲育儿，观众本能不信。

1. **先用8条、10条、甚至20条自己的生活经历建立人设**——让观众认识你
2. **之后再讲专业知识**——观众翻你历史视频知道你是谁，再说知识信任感会强得多

**最简单的结构**：一条视频 = 一个自己的真实故事 + 一句跟故事相关的知识。

### 一个提醒

有些视频数据好但让你心虚——纯鸡汤、纯情感类。柯老师的判断：**"有人看，但没有你。"** 观众看完不知道你是谁。做账号不是做播放量，是让你自己的面孔、经历、观点刻在观众脑子里。

## 第三部分：改文案实操——从初稿到成片的每一步（Day4-3精华）

### 稿子先按三块拆开

| 部分 | 目的 | 你检查自己 |
|------|------|-----------|
| 开头 | 吸引观众 | 不相关的人会点进来吗？ |
| 中间 | 让人持续看下去 | 听一半会走吗？ |
| 结尾 | 互动/转化 | 听完知道该干什么吗？ |

### 改开头：把"窄"变成"广"

❌ "不知道有没有人和我一样，一门心思想把口吃改掉。"——只有口吃的人会继续看

用"以弱胜强"——主动暴露弱点，把它变成一个**所有人都想点进来的看点**：

✅ "口吃七年的零零后到底有多惨？一分钟带你看看我的工作、生活、交朋友的那些不便之处。"

**你改开头时问自己**：没经历过我这种事的人，会想点进来吗？不确定就换成——**XX年XX的我，到底有多惨/多难/多狼狈？**

### 改中间：两种结构 + 一个关键词"具体"

**清单式**（场景A→B→C）：适合展示"我的生活到处是这个问题"
**故事线**（背景→冲突→疑问→答案）：适合展示"一个事情怎么发生的"

两种可以结合。最关键的是**写具体**：

❌ "我因为口吃丢了很多工作机会"——太抽象
✅ "有一次交接工作，越着急越说不清楚，同事听不清也懒得听，活卡住了，领导觉得我推活儿。那种感觉又加剧口吃，形成死循环。"

柯老师现场做的一直是追问——"什么时候？什么事？跟谁？后果？"——直到挖出带画面感的具体事件。

**把低谷写够——用排比渲染**：

工作没了，朋友没了，女朋友也没了。父母说上学有什么用。那一刻，太阳照在身上都觉得烫。
→ 四个维度全封死：社会身份、社交、亲密关系、家庭——观众才能感受到被按到了底。前面越惨，后面改变越了不起。

### 改结尾：改变要具体，接纳要清醒

不是"我变好了"，是"我做了这些事"——"减肥50斤、地铁做过演讲、读过心灵成长的书、送外卖锻炼自己"——每件事观众都能想象。

结尾三层逻辑：
1. **比喻解释困境**："越对抗恐惧越重，像手里抓沙子，越用力流失越快"
2. **打消误解**："接纳≠摆烂认命"
3. **场景闭合**："现在我就这样站在视频里跟你讲话"

观众感觉：这个人不是放弃了，是找到了一条更聪明的路。

### 改稿完整流程

1. **写初稿**——别完美主义，先写出来。有bug正常，bug才是你来改的地方
2. **改三到五遍**——方法只有一个：**边读边改**。读着不顺就删，情绪没到就加细节，太平淡就回想要点
3. **AI只能在后面**——你先做，AI后做，别搞反了。你写完初稿→AI帮你润色；你缺画面灵感→AI帮你推荐情绪空镜头
4. **网感怎么练**——拆解。拆别人的好视频，拆到足够多自然有感觉

## 第四部分：从稿子到片子——拍摄流程

记住顺序别乱：

1. **定场景**——前半段低落找暗的地方，后半段明亮
2. **先拍A-roll**——对着镜头说
3. **先粗剪A-roll**——去掉废话
4. **闭眼听自己说的**——脑子里过"这句话放什么画面"，记下来
5. **再去拍B-roll**——补拍画面
6. **融合 + BGM + 后期**

> 闭眼听的时候，捕捉到的画面感觉是最准的。

### 没有素材怎么办：情绪空镜头 / 以物传情

| 想表达 | 拍什么 |
|--------|--------|
| 释然、放下 | 海浪拍岸、潮起潮落 |
| 安静、想家 | 夜晚路灯 |
| 希望、新生 | 绿叶、嫩芽 |
| 梦想破碎 | 路面裂缝 |
| 焦虑 | 满地烟头 |
| 回忆、美好 | 夕阳 |
| 沉重、低落 | 老人背影 |

这叫"以物传情"——用一个画面表达一种情绪。起步先做60分，有意识去拍这些空镜头。生活里碰到就随手录一段，存成素材库。

**光线也可以讲故事**：前半段低落→暗的地方拍；转折→从暗走到亮；结尾释然→亮的地方。不用专业设备，用空间和自然光就够了。

## 第五部分：马上行动（下次上课前完成）

### 必须做
1. **写清你的定位**——"我是谁、做什么方向、为谁提供什么价值"——没想清楚的私聊柯老师
2. **用起号模板拍第一条**——先讲你自己的故事，再讲该做的事
3. **出三条选题**——为你的账号选定三个选题方向
4. **拿你自己的稿子用三块法拆开**——开头够广吗？中间具体吗？结尾有力量吗？
5. **把最抽象的一段改成一个具体事件**——当时在哪？跟谁？发生了什么？结果？

### 长期习惯
6. **写下你人生的三个阶段**（大学→毕业→工作），每个阶段一个小故事
7. **找到你一个坚持超过一年的习惯**，问自己：为什么要坚持？做成了什么？
8. **拍一条"故事+知识"的视频**——先讲你的故事，再用一句话讲你能教别人的东西
9. **看看你手机里有没有能当情绪空镜头的素材**——路灯、树叶、海浪、夕阳
