# 作业3：拍第一条自我介绍视频

> 这是你的第一条A-roll。两分钟以内，拍好发群里。

---

## 脚本模板（填空就行）

### 第一段：我是谁（15-20秒）

```
大家好，我叫_______。

我是_______（身份/职业/学生）。

我目前在_______（城市/学校/公司）。
```

### 第二段：我在做什么、为什么做（30-40秒）

```
我做这个账号是因为_______。

我擅长_______。

我之前_______（经历/故事，1-2句话）。

（如果没经验）虽然我是新手，但_______（你打算怎么学/已经开始做什么）。
```

### 第三段：我能为你做什么、我的优势（20-30秒）

```
我能帮你_______。

因为_______（你的优势/特点/经历）。

我的优势是_______（老实/认真/有经验/愿意学/能坚持……都可以）。
```

---

## 拍摄清单

**开拍前检查**：

- [ ] 镜头擦干净了
- [ ] 人脸是亮的（顺光，站在灯下面，不要背对窗户）
- [ ] 声音清晰（有麦克风就用麦克风；没有就找安静房间，手机靠近嘴）
- [ ] 手机横屏拍（16:9）还是竖屏拍（9:16）：建议竖屏

**拍摄时**：
- 别紧张，就当对着朋友聊天
- 说错了没关系，可以重拍，也可以后期剪掉
- 不要念稿——看一眼记住大意，用自己的话说

**B-roll画面（选做）**：
- 把你说到的"名词"拍下来作为画面素材
- 比如你说"我在大连"→插入大连街景
- 你说"我喜欢宠物"→插入你和宠物的画面
- 新手可以先不用B-roll，先把A-roll拍好

---

## 音乐建议

- 00后、有活力、充满希望 → 欢快音乐
- 90后、经历过社会、想认真做事 → 有共鸣感的音乐
- 讲自己遇到过困难/挫折 → 不配欢快音乐，配《平凡之路》这类

**不知道配什么**：先不配。把视频拍好再说，音乐可以后面加。

---

## 发布前再看一遍

- [ ] 视频长度在两分钟以内
- [ ] "我是谁"说清楚了
- [ ] "我能做什么"说清楚了
- [ ] 画面清晰、声音清晰、人脸是亮的
