# Day3-2 沟通记录 · 数据操控思维与视频拆解方法论

## 课程概况

- 日期：2026-07-18
- 授课：柯建军
- 学生：11人
- 时长：约50分钟（含互动）
- 主题：互动行为底层逻辑 → 视频拆解方法论 → 就业实操

## 课程结构

1. **引入**：技法学习的核心是理解骨架——让观众持续看下去的动机
2. **互动行为深度剖析**：点赞/收藏/转发/评论/拉黑/进主页的心理学归因
3. **视频拆解表方法论**：七步维度 + 逐秒拆解法
4. **就业实操**：烧烤店→无人机教练套用演示 + 就业路径（大连最低150元/条）

## 核心交付

### 六大互动行为框架

| 行为 | 底层原因 | 植入方法 |
|---|---|---|
| 点赞 | 生理刺激/情绪/知识/压缩时长/正能量/猎奇 | 对应元素植入 |
| 收藏 | 工具性+技巧性 | 带数字的技巧类标题 |
| 转发 | 社交货币/教育他人/为人群发声 | 有态度/替某人群说话 |
| 评论 | 表达欲/争议触发 | 刻意设计讨论空间 |
| 拉黑 | 非目标用户 | 内容驱动粉丝筛选 |
| 进主页 | 意犹未尽/想付费 | 主页信息清晰 |

### 视频拆解表七步法

标题→发布时间+数据→账号分析→目标受众→核心痛点→画面截图+BGM→主题一句话

### 就业实训路径

接任务→搜行业关键词→拆50条→套用名词动词替换法→产出几十条选题→见老板

## 关键金句

- 「所有动作都是可操控且可预测的」
- 「抖音就是开卷考试，看学的是道还是技法」
