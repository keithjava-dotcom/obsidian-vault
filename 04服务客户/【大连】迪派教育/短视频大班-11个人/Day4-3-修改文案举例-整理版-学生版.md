# 2026-07-18 迪派大班Day4-3 · 改文案实操：从初稿到成片的每一步

> 这节课柯老师现场拿一个同学的文案，从头改到尾，把之前学的理论知识全串起来了。你跟着这个流程改自己的稿子，每一步都有方法。

---

## 一、你的稿子先按这三块拆开

拿到任何一版的稿子，先把它拆成三块：

| 部分 | 目的 | 你检查自己 |
|------|------|-----------|
| 开头 | 吸引观众 | 不相关的人会点进来吗？ |
| 中间 | 让人持续看下去 | 听一半会走吗？ |
| 结尾 | 互动/转化 | 听完知道该干什么吗？ |

---

## 二、改开头：把"窄"变成"广"

### 错误示范

> 不知道有没有人和我一样，一门心思想把口吃改掉。

❌ **问题**：只有口吃的人才会继续看——其他人直接划走。

### 正确方向

用"以弱胜强"——主动暴露你的弱点，把它变成一个**所有人都想点进来的"看点"**。

✅ **修改后**：

> 口吃七年的零零后到底有多惨？
> 一分钟带你看看我的工作、生活、交朋友的那些不便之处。

**为什么好**：
- 同类人 → 共鸣："我也是，看看他经历了什么"
- 其他人 → 凑热闹："零零后口吃七年，有多惨？"
- 加了年限 → "七年"比"有段时间"有分量
- 加了内容预告 → 观众知道后面会看到什么

### 你改开头时问自己

1. 我现在这个开头，没经历过我这种事的人，会想点进来吗？
2. 如果不确定 → 换成"以弱胜强"的句式：**XX年XX的我，到底有多惨/多难/多狼狈？**

---

## 三、改中间：两种结构 + 一个关键词"具体"

### 中间内容有两种写法

**清单式**：场景A → 场景B → 场景C
适合：你想展示"我的生活/工作/社交全都有这个问题"

**故事线**：背景 → 冲突 → 疑问 → 答案
适合：你想讲"一个事情怎么从好变坏再变好的"

**两种可以结合**。比如先用故事线讲背景，再用清单式展开具体场景。

### 最关键的技巧：写具体

❌ "我因为口吃丢了很多工作机会"——太抽象，观众无感
✅ "有一次交接工作，我越着急越说不清楚，同事听不清也懒得听，活儿卡住了，领导觉得我推活儿。那种感觉又加剧口吃，形成死循环。"

**柯老师现场的做法**：不停追问学生——"什么时候？什么事？跟谁？后果是什么？"——直到挖出一个**带画面感的具体事件**。

### 把低谷写够：用排比渲染

❌ "实在熬不住，只能离开"——太轻了
✅ "工作没了，朋友没了，女朋友也没了。父母说上学有什么用。那一刻，太阳照在身上都觉得烫。"

- 工作 → 社会身份丢了
- 朋友 → 社交没了
- 女朋友 → 亲密关系断了
- 父母 → 连家里都不理解

**四个维度全封死了，观众才能感受到你被按到了底。前面越惨，后面的改变观众越觉得了不起。**

---

## 四、改结尾：改变要具体，接纳要清醒

### 改变不是一句口号

> 24年10月，减肥50斤，地铁做过演讲，读过心灵成长的书，送外卖锻炼自己。

**每件事都是观众能想象的画面**——不是"我变好了"，是"我做了这些事，你看我是不是在拼命改？"

### 结尾三层逻辑（柯老师改出来的结构）

1. **比喻解释困境**："越对抗恐惧越重，像手里抓沙子，越用力流失越快"
2. **打消误解**："接纳≠摆烂认命"
3. **场景闭合**："现在我就这样站在视频里跟你讲话"

观众看完的感觉：这个人不是放弃了，是找到了一条更聪明的路。

## 五、改稿的完整流程（照着做）

### 1. 写初稿
不要完美主义，先写出来。有bug正常——bug才是你来改的地方。

### 2. 改三到五遍，方法只有一个：边读边改

- 读着不顺 → 删掉重写
- 情绪没到 → 加细节、排比、比喻
- 太平淡 → 回想课上学的技巧（结构、情绪、押韵）

### 3. AI只能在后面

> "你们先做，AI后做，不要搞反了。"

AI的用处：你写完初稿→AI帮你润色、你缺画面灵感→AI帮你推荐情绪空镜头。

### 4. 网感怎么练？

**只有一个方法：拆解。** 拆别人的好视频，拆到足够多自然有感觉。别问"怎么提高网感"问就是"拆得不够"。

## 六、从稿子到片子：拍摄流程

记住顺序，不要乱：

1. **定场景**（根据稿子情绪基调——前半段低落找个暗的地方，后半段明亮）
2. **先拍A-roll**（对着镜头说）
3. **先粗剪A-roll**（去掉废话）
4. **闭眼听自己说的** → 脑子里过"这句话放什么画面" → 记下来
5. **再去拍B-roll**（补拍画面）
6. **融合 + BGM + 后期**

> 柯老师说：闭眼听的时候，捕捉到的画面感觉是最准的。

---

## 七、没有素材怎么办：情绪空镜头 / 以物传情

如果你没有当时的真实画面记录，用这些来传递情绪：

| 想表达 | 拍什么 |
|--------|--------|
| 释然、放下 | 海浪拍岸、潮起潮落 |
| 安静、想家 | 夜晚路灯 |
| 希望、新生 | 绿叶、嫩芽 |
| 梦想破碎 | 路面裂缝 |
| 焦虑 | 满地烟头 |
| 回忆、美好 | 夕阳 |
| 沉重、低落 | 老人背影 |

这叫"以物传情"——用一个画面表达一种情绪。起步先做60分，有意识去拍这些空镜头。

### 光线也可以讲故事

- 前半段低落 → 暗的地方拍（关灯、凌晨）
- 转折 → 从暗走到亮
- 结尾释然 → 亮的地方

不用专业设备，用空间和自然光就够了。

## 马上行动

1. **拿你自己的稿子，用三块法拆开**——开头够广吗？中间具体吗？结尾有力量吗？
2. **把最抽象的一段改成一个具体事件**——当时在哪？跟谁？发生了什么？结果？
3. **看看你手机里有没有能当情绪空镜头的素材**——路灯、树叶、海浪、夕阳
