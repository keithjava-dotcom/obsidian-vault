## 第1步：理解互动行为——你的视频在操控什么？

### 要做什么
把用户对你的视频的所有「动作」，从"玄学"变成"可理解、可设计"的。

### 怎么做

每一个互动行为，背后都有一个确定的原因。把这个表记下来，做视频的时候有意识地往里放。

| 行为 | 用户为什么做这个动作 | 你在视频里怎么植入 |
|---|---|---|
| **点赞** | ①生理刺激（解压视频、吃播、颜值）②情绪价值（搞笑、感动）③知识/技巧 ④压缩时长（电影解说）⑤正能量（公益、救助）⑥猎奇（别人做不到的事） | 声音/画面解压、植入笑点、动物+公益（"带猫赶海送给孤独老人"）、干货够硬 |
| **收藏** | 有用——下次还能用。工具技巧类内容最容易被收藏。 | 带数字的技巧：挑海鲜3个秘诀、变美5个思路、带娃8个方法 |
| **转发** | ①社交货币（太好玩了转给朋友）②教育别人（"你看人家怎么做的，你做不到"）③为某人群发声（小个子穿搭、宝妈痛点） | 要么好玩，要么替一部分人说话，要么教育另一部分人 |
| **评论** | ①想表达 ②被争议触动 ③被刻意设计的错误引导 | 说一个有态度的观点。不怕人杠——有人杠就有人帮你说话，两边一打评论就起来了 |
| **拉黑/划走** | 不感兴趣、不是目标用户 | 主动说目标用户以外的人不爱听的话，把不对的人赶走，保护粉丝画像 |
| **进主页** | ①意犹未尽想看更多 ②想找你付费/合作 | 作品质量够了，主页能看到你是谁、做什么业务的 |

### 为什么这样做
柯老师说"所有动作都是可操控且可预测的"。你做视频不是碰运气，是理解了观众的大脑之后，在视频里放"按钮"——按下去观众就会做动作。

## 第2步：回归常识法——你自己的反应就是最好的素材

### 要做什么
不要猜用户会怎么反应——问你自己。你自己会为什么视频点赞、收藏、转发？

### 怎么做

拿张纸，写下：
1. 你最近点赞的3条视频 → 你当时为什么点？
2. 你最近收藏的3条视频 → 你想什么时候用？
3. 你最近转发的3条视频 → 你转给谁了？为什么转？

然后对照第1步的表格，看看你的行为落在哪一栏。这个落点，就是你的视频里应该放的东西。

### 为什么这样做
你做视频的人和看视频的人是同一种生物。你自己的反应模式，基本就是你的目标用户的反应模式。这是"回归常识"——不玄学、不靠猜、不靠运气。

## 第3步：挖掘你的猎奇点——你身边有什么别人不知道的？

### 要做什么
找到你身上/你的行业里「外行人不知道但想知道」的东西。

### 怎么做

问自己三个问题：
1. 你每天做的工作/生活里，有什么是圈外人完全想不到的？
2. 你所在的地方、行业、经历里，有什么数据/现象会让普通人惊讶？
3. 你能不能把这个东西拍成一个"第一视角"的视频？

柯老师举例：
- 海边长大二十多年，坐船出海才发现浪有两三米高（表面风平浪静）
- 中国有8亿人没看过海——你看腻了的东西，对别人是猎奇
- 养男孩的10个奇葩事
- 第一视角渔船打鱼

### 为什么这样做
猎奇是最原始的点赞动机——"我做不到但他做到了"。你习以为常的事情，在圈外人眼里就是内容。

## 第4步：掌握视频拆解表——把你看到的爆款扒光

### 要做什么
拿到任何一个视频，把它拆到"什么都不剩"。

### 怎么做

用下面这张表（可用飞书免费版做）：

| 拆解维度 | 填什么 | 为什么填这个 |
|---|---|---|
| 标题 | 视频的标题原文 | 标题是第一钩子 |
| 发布时间+关键数据 | 点赞/收藏/评论/转发数 | 知道它爆到什么程度 |
| 账号分析 | 谁发的、做什么的、粉丝量 | 知道谁在做 |
| 目标受众 | 这个视频是给谁看的？ | 理解选题方向 |
| 核心痛点 | 它解决了观众的什么问题？ | 理解价值 |
| 画面截图 | 关键帧截下来 | 视觉分析 |
| BGM | 什么音乐？（用听歌识曲） | 情绪氛围 |
| 主题一句话 | 看完你觉得讲了个什么事？ | 训练概括能力 |
| **逐秒拆解** | 时间——字幕——画面——镜头——音乐 | 这是核心——把视频还原成脚本 |

### 为什么这样做
柯老师说：**拆100条视频，你就成了运营高手。** 

抖音是开卷考试。爆款已经告诉你答案了——你要做的不是发明，是看懂别人怎么做的，然后拿来用。

## 第5步：拆解→套用——从看懂到做出自己的

### 要做什么
拆完别人的视频，套到你身上。

### 怎么做

**方法：名词动词替换法**

别人视频里所有代表身份的词，全换成你的。所有代表行为的词，全换成你做的。

实操案例（课堂演示）：
- 原视频：烧烤店老板——"从摆摊到开分店，我用了16年。我是陆军，很多老顾客叫我烧烤王。最早在夜市摆了七年的路边摊……2015年不让摆路边摊……"
- 套用后：无人机教练——"从无人机教练到孩子王，我用了三年。我是刘继浩。很多家长爱开玩笑叫我孩子王。那会儿在艺培机构，一群小孩天天围着我转……现在干无人机也已经三年了……"

替换公式：
- 身份词换身份词：烧烤老板 → 无人机教练
- 时间词换时间词：16年 → 3年  
- 地名换地名：夜市 → 艺培机构
- 情感词保留：那份感情不变

### 为什么这样做
刚开始你不会原创，就先"抄结构不抄内容"。抄多了你就有了肌肉记忆，看到任何一个行业、任何一个视频，脑子里自动跑出"这套东西能不能套到我身上"。

## 第6步：就业实操——接单/面试/上班就用这套

### 要做什么
不管你接什么行业的客户，你不需要先"懂这个行业"，你需要先"看懂这个行业的视频"。

### 怎么做

1. **接到任务 → 不着急拍**，先去抖音/search 搜行业关键词
2. **拆50条这个行业的账号**（按第4步的表格）
3. **挑出3-5个爆款结构**，套用到客户身上（按第5步的方法）
4. **拿着几十条选题去见老板/客户**——你说"我对你行业不太熟但我拆了50条"，对方看到工作量和你拿出来的东西，就知道你不是在摸鱼

### 为什么这样做
柯老师原话：**"不要指望自己多聪明能快速进入一个行业。唯一的捷径就是大量看短视频和评论区。"**

大连市场行情：拍一条视频最低150块。你学会拆解→套用这套方法，不管什么行业你都能接。

## 作业

### 基础作业（必做）
1. **回归常识清单**：写出你最近点赞/收藏/转发的各3条视频，标注为什么（对照第1步表格）
2. **猎奇清单**：写出你的行业/生活里3个"外行人不知道但想知道"的点

### 进阶作业（建议做）
3. **拆解5条视频**：用第4步的拆解表，选一个你感兴趣的赛道，完整拆5条爆款视频
4. **套用1条**：挑一条你拆过的视频结构，用名词动词替换法套到自己身上，写一段

### 柯老师提醒
> 下节课会有作业检查。拆100条，你就超越大部分运营了。唯一快的方式就是直接解决问题。
