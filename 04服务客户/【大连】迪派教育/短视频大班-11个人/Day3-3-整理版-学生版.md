# 2026-07-18 迪派大班Day3-3 · 建立你的视频拆解体系：从看懂别人到自己能做

> 这份不是课堂录音的照搬。我把Day3-3讲的知识点，按你实际"找视频→拆视频→建自己的库"的顺序重排了，顺着手就能做完。

## 流程图总览

找对视频 → 提取文案 → 拆解画面 → 拆文案结构 → 建拆解库 → 找对标 → 每天一条不中断

---

## 步骤一：判断什么视频值得拆——别拆错了白费时间

### 做什么
打开抖音，不是见到爆款就拆。
先过这三道筛子，每条视频问自己"它值不值得我花半小时拆"。

### 用什么
**三道筛子：**

**第一道：拆行业顶部的作品，但不把它当对标。** 比如影视飓风是我们行业的头部——学它的拍摄手法、景别、构图、文案、选题，但别想着"我要超越它"。它太庞大了，你超不过。拆它是学手艺，不是设目标。

**第二道：拆有人设的账号。** 怎么看有人设？翻评论区——粉丝对他是不是真的喜欢和信任？不是调侃、不是看笑话。比如直男财经、小林这种，内容即使一般也有人设，因为粉丝对他极其忠诚。反过来，评论区全是调侃的（比如一些搞笑账号），没有认知、没人设，不拆。

**第三道：拆你"想学他某一点"的账号。** 抖音上有很多高质量视频并不火——没商业价值但值得学。它可能是某个小技巧做得特别好，你就拆那一点。

**图文不要拆。** 但可以换个用法：发现一个爆款图文（比如32种育儿知识），用自己的话讲一遍，做成口播——这是变换形式，不是拆解图文。

### 避什么坑 + 例子
- **坑：把什么热门视频都拆。** 有些视频只是信息密度高（一张图配五行字讲育儿技巧），但影响不了观众决策——不算好内容，拆了学不到东西。
- **坑：把拆解当对标。** 柯老师原话："拆解不等于对标。对标意味着在最高级别上，我们要超越它、将其视为同行并努力超过。我们很难超越行业顶部，因为它们已经积累了大量资源和优势。"
- **核心原则记住：短视频的核心在于处理信息。** 图文、视频、解说都是处理信息的不同形式。你做的所有事，本质都是"把信息用短视频方式处理好，让观众愿意看"。

## 步骤二：用轻抖提取视频文案——开口就能抄

### 做什么
看到一条想拆的视频，第一步把它的文案扒下来。用工具，别手打。

### 用什么
工具：**轻抖**（小程序/App都有）。操作步骤：
1. 在抖音找到目标视频 → 点分享 → 复制链接
2. 打开轻抖 → 粘贴链接
3. 点"提取文案"（注意：去水印是下载视频，别点错了）
4. 等处理完 → 复制文案 → 粘贴到飞书

**费用**：看广告免费一次。柯老师买了终身会员。如果想高效，建议买会员，闲鱼上能买到便宜的。

### 避什么坑 + 例子
- 别手动打字抄文案——浪费时间还容易出错。
- 提取文案和去水印是两个按钮，看清再点。

## 步骤三：用剪映拆解视频画面——把一条视频还原成"剧本"

### 做什么
把扒下来的视频拖进剪映，让AI按镜头自动切成片段，你就能"一帧一帧"看它是怎么拍的。

### 用什么
工具：**剪映**（电脑版）。操作步骤：
1. 下载目标视频到本地
2. 打开剪映 → 新建项目 → 把视频拖进去
3. 右键视频 → 点"智能镜头分割" → 等它分析完
4. 视频被按景别切成一块一块的片段
5. 右键每个片段 → 导出所选片段 → 存到桌面
6. 把片段上传到飞书 → 逐个加备注（配的什么文案、什么镜头、什么节奏）

### 避什么坑 + 例子
- 视频太大（5分钟以上）处理会慢，耐心等。
- 前期拆一条会慢，很正常。柯老师原话："前期可能会慢一些，但是这个东西后期做好之后真的会很快。"

## 步骤四：标点换行法拆文案——训练你的"网感"

### 做什么
把提取出来的文案，用"遇标点就换行"的方法重新排版，然后逐句分析开头和结尾是怎么写的。

### 用什么
**方法：遇标点换行。** 操作步骤：
1. 把文案粘贴到飞书文档
2. 每遇到句号、问号、感叹号就换一行
3. 标注每段是"开头/中间/结尾"
4. 分析：开头怎么钩人？中间怎么推进？结尾怎么收？

**柯老师演示的例子：**
- 原视频开头："就两根破棍子，科学家用它证明一件恐怖的事，这个宇宙从根本上就不想让你看透。"——猎奇法开头。
- 套用到海参行业："一个长得这么丑的海洋昆虫，是什么让它高达一千多块钱一斤？"——同样用猎奇，换了对象。

### 避什么坑 + 例子
- 拆完别就放在那——**一定要套用。** 看到别人好的开头，立刻想"换到我的行业怎么改"，练多了网感就有了。
- 关注开头和结尾——中间内容可以调整，但开头决定留不留人，结尾决定转不转。

## 步骤五：飞书建你的拆解库——从0到100条的积累

### 做什么
在飞书里建一个文件夹，每拆一条视频就录入一条。目标是**100条**。

### 用什么
工具：**飞书**（免费版就行）。操作步骤：
1. 飞书 → 云文档 → 新建文件夹（比如叫"我的视频拆解库"）
2. 用柯老师的模板（问他要），或者自己建表格，字段包括：
   - 视频标题
   - 发布时间+数据（点赞/收藏/转发/评论）
   - 账号信息
   - 目标受众
   - 开头写法分析
   - 结尾写法分析
   - 拆解备注
3. 每拆一条就录入一条。可以加图文、传拆好的片段、写备注。

### 避什么坑 + 例子
- 柯老师原话：**"我在接手任何一个行业的时候，会先去扒这个行业的20条到30个视频，然后去扒它们的爆款。扒完之后，我就对这个行业已经有所了解了。"**
- 这个习惯直接和你的报价挂钩。柯老师的单月操盘费是6000到8000（大连市场），普通行业5000-6000，难搞的行业8000——**原因就是做了100条这样的拆解。**
- 柯老师自己现在还在拆，只是换了工具。他手下的运营都过了"拆100条"这个基本期。他招新人时说过："你可以先去拍100条视频，之后你来找我。"

## 步骤六：用抖音热点服务中心找对标——永远盯低粉爆款

### 做什么
不要对标大博主（你干不过），只对标**5万粉丝以下、但出了爆款的账号**——他们才是你现阶段能追上的。

### 用什么
工具路径（抖音内）：
1. 搜"热点宝"小程序 → 进入抖音热点服务中心
2. 点"趋势榜单" → 选"垂类" → 找到你的行业
3. **关键操作：勾选"低粉爆款视频榜"** → 只看0-5万粉丝博主
4. 筛选"近七天" → 看这个行业最近新起来的博主在讨论什么
5. 不知道自己的行业属于什么类？问豆包："我想做XX领域的博主，在抖音热点服务中心榜单里属于什么类别？"

**看完视频还要看评论区！** 找对标不只是看视频主题——翻评论区，看还有什么问题这个博主没解决、还有很多人在问。你作为同类博主去发同类的视频，解答那些他没回答的问题——你就有可能成为下一个热点。

### 避什么坑 + 例子
- **坑：盯着大V对标。** 柯老师原话："我们找对标的时候就不要找大博主了，我们干不过他们。就找5万以下粉丝的博主，0到5万的，因为我们是新起号阶段。"
- **对标的核心：找相同的"我"和相同的"用户"。** 比如你是一个年轻的海参养殖户，去找大妈养殖户的视频——把"年轻活泼"和"大妈踏实"做互补替换。让一个很活泼、很年轻的人讲很老练的经验，这是优势叠加。

## 步骤七：建立每日拆解习惯 + 你的账号就是你的简历

### 做什么
每天拆一条视频，雷打不动。再给自己建一个个人账号，哪怕粉丝不多。

### 用什么
**每日拆解节奏：**
- 一天拆一条，刚开始慢正常。柯老师原话："一天拆解一个视频，这个增量并不大。关键在于找到新进入的、适合拆解的视频。"
- 100条视频的积累：一天拍十条，也就七天；拆分成一百天，看个人意愿。不管怎么算，先开始。
- 柯老师手下运营都过这个基本期："这样我们在后续工作中会更加顺畅，要不然说很多话他听不懂，我也很难给他解释。"

**个人账号心态：**
- 柯老师原话："如果想上班，一定要建立自己的账号。你上班的工资高低，很大程度上取决于你自己的账号能否做起来。假设你有一个自己的账号，数据还不错，哪怕粉丝不多，但有一定的播放量——你们上班的待遇会好很多。"
- 账号就是你的作品集。面试、接单时拿出来，比说什么都有说服力。

### 避什么坑 + 例子
- **坑：找借口不拆。** "刚开始可能会慢一些"——这是正常的，不是停下来的理由。
- **坑：只拆不做自己的视频。** 每节课带一条作品来上课，拆了解、解了做、做了再拆——闭环。
- **坑：互关互粉。** 不要搞互关互粉，刷推荐页看到同频的可以关注，但不要"你关我我关你"。
- **金句收尾：** 柯老师说："失败的方法千奇百怪，但成功的方法就那么几条。我告诉你们的只是其中一种，当然可能还有其他方法，但不多。按照这个方法，可以让你们迅速从一个初级或零基础的状态，晋升为一个有内功的人。这种方法是最快的，而且我替你们试验过，好用，真的很好用。"
