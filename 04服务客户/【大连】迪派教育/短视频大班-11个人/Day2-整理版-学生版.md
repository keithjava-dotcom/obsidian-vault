# 2026-07-11 短视频大班Day2 · 一条视频从零到发布的完整流程

> 这份笔记不是课堂录音的照搬。我把Day2讲的所有知识点，按照**你实际做一条视频的顺序**重新组织了。每一步该干嘛、用什么方法、注意什么坑，顺着手就能做完一条片子。

---

## 流程图总览

```
选题 → 构思 → 写文案 → 优化文案 → 设计场景 → 练表现力 → 拍摄+包装 → 发布
```

---

## 步骤一：选题——找到你的对抗点

**你要先想清楚：这条视频里谁在和谁打架？**

短视频必须有冲突。不是吵架那种冲突，是两种力量在对抗。
你看的所有电影、电视剧、短剧，全是这个逻辑——罗密欧与朱丽叶对抗家族，唐僧对抗女儿国国王的情感，短剧主角穿越到古代对抗规则。

在你的领域里找出对抗点。比如：

| 领域 | 对抗点 |
|------|--------|
| 宝妈 | 带娃 vs 工作 |
| 00后毕业生 | 听爸妈考公 vs 选自己喜欢的专业 |
| 北漂/深漂 | 在大城市卷 vs 回老家躺平 |
| 传统老板 | 旧模式做不下去 vs 不知道怎么转型 |
| 转行人 | 放弃稳定收入 vs 追求想要的生活 |

**两个小技巧：**

**找对抗点的方法：感知能力训练。** 
说白了就是对世界保持好奇，刨根问底。柯老师跟一个学员聊，从"你做什么工作"一路问到"为什么不想干这行""家里做什么的""你有啥爱好""大学在哪上的"，聊着聊着就挖出了选题。你不去深挖，永远觉得"我这人没啥可说的"。

**定制策略：两个领域加一起。** 你是搞音乐的 + 做自媒体 = 音乐可视化博主。你是懂汽车的 + 做自媒体 = 汽车带货IP。你是做海鲜的 + 情侣日常 = 95后海鲜情侣账号。两个东西一加，赛道就窄了，竞争就小了，你就独特了。

## 步骤二：构思——先自己想，再去看同行

**这一步最容易跳，一跳就废。**

人的大脑会本能地回避深度思考，因为思考太费能量了。但你得强迫自己先想——这个选题我能讲什么？我自己的经历里有什么跟这个选题挂钩的东西？先把自己的料全部倒出来。

**自己想过之后，再去看同行。** 搜你这个选题的关键词，看10到20个同行的视频，下载下来拆解。把20个视频融合成3个自己的版本，这不难。柯老师刚入行时写护肤文案，就是去扒李佳琦直播间的话术，扒头部护肤博主的选题。夏天的选题无非就是抗衰、防晒，把这些关键词拿过来，缝缝补补就变成自己的。

**注意顺序不能乱：先选题 → 再构思 → 最后收集素材。** 乱了你就容易走捷径，被AI操控，判断力会退化。先自己想了再抄，不是先抄了再假装想过。

## 步骤三：撰写文案——说，不要打字

**写文案的核心方法：用嘴说，不要用手敲。**

打开手机输入法的语音转文字，直接对着说话："我是一个95后宝妈，之前一个月能卖200台车，辞职回家带娃两年了，有五个特别崩溃的瞬间。第一个是……第二个是……"你这样说出来的东西，本身就是口语，本身就自然。

说完之后转成文字，这篇东西就是你的初稿。

### 3.1 选一个结构

两个结构，够你起号了：

**清单式**——最简单直接。比如"宝妈崩溃的五个瞬间""大连海岛必去的三个地方""90后离职前必须想清楚的三件事"。信息密度极高，观众一看就知道你要给几个要点，适合起号。

**故事型**——有背景、有冲突、有转折。比如"我为什么从月薪过万的4S店辞职回家带娃"。故事型的核心是让观众心里有疑问：然后呢？为什么会这样？接下来怎么办？

**别被"清单式"三个字骗了**，清单式也可以嵌套故事。你讲"最崩溃的五个瞬间"，每个瞬间就是一个迷你故事。水浒传108个英雄，就是一个巨大的清单套故事。

### 3.2 开场两秒——有情绪，不要大喊大叫

大多数人做不到镜头前吼叫。但你可以**有情绪**。

比如凌晨一点的宝妈，对着镜头用气声说："嘘……这就是我现在凌晨一点当宝妈的真实状态，我要给孩子转奶粉。"睡意朦胧的、偷偷摸摸的、怕吵醒家人的感觉。这种开头比大喊大叫真实一百倍。

### 3.3 五秒完播率——凭什么让观众留下来

观众凭什么花五秒看你？你得给一个理由。要么共情（"我也这样"），要么有用（"这个我得知道"），要么好奇（"到底怎么回事"）。

以宝妈为例：如果你想让同类宝妈看，你前五秒就说"真烦，老公又不带孩子，天天就知道打游戏。现在凌晨一点，他在旁边打游戏，我要给娃换尿不湿。"五秒说完，宝妈们立马觉得：这不就是我吗？评论区就会出现"同款老公""要这样的男人有何用"——互动率就上来了。

### 3.4 原子性：每5-7秒给一个新刺激

短视频的"短"不是时长短，是**信息密度要大**。15秒的视频和90分钟的视频都叫短视频，只要它每5到7秒给观众一个新的信息点。

你去看一条视频的8到17秒，如果这段时间没有新的东西进来，观众就走了。所以要把长段落拆开：比如"我今年33岁，以前做汽车销售，现在全职带娃"——这里面拆成三个信息点：33岁/做汽车销售/全职带娃，每5到7秒给一个。

### 3.5 冲突与对抗性——让观众脑子有疑问

文案里必须有不平衡的东西，让观众心里冒出"然后呢？""为什么？""怎么办？"

- "95后情侣裸辞回家躺平" → 观众：为什么要裸辞？躺平了然后呢？
- "父母觉得年轻人应该出去奋斗，但我偏不" → 冲突来了

你在第一秒埋对抗，观众就愿意看下去。短剧为什么让你一集接一集追？就因为它每一集结尾都扎你一下。

## 步骤四：优化文案——五招让文案活起来

初稿写完之后，用下面五招过一遍。

### 4.1 可视化

把抽象的"be句型"换成有画面的"do句型"。

- ❌ "我是一名宝妈"
- ✅ "辞职、裸辞回家带娃的宝妈"

- ❌ "这是一份可乐鸡翅"
- ✅ "把可乐倒在鸡翅上"

逼着自己在观众脑子里画画。方文山为什么厉害？"天青色等烟雨，而我在等你"——每一句都是画面。

### 4.2 专属细节

加具体的数字、时间、地点，让人以为是真的。

"上周六月十三号中午十一点二十五分，我坐了一趟从旗口到长兴岛的轮渡。" "2026年5月28号14:32分，我收拾了桌子上的文件，从4S店走了出来。"

加了数字就像真的。观众不需要知道真假，他们需要的是**感觉是真的**。

### 4.3 高光时刻

给自己加身份标签，制造落差感。

- "我是我们店的销冠，一个月卖200台车，然后我离职了"——销冠离职，和普通销售离职，感觉完全不一样。
- "我花了三年时间和父母给的50万学计算机编程，但最终不愿意从事这个行业"——投入越多放弃越可惜，落差越大。

记住一句话：**出门在外，身份是自己给的。** 只要不是骗人，包装一下没毛病，观众看的是故事好不好看，不是查你简历。

### 4.4 冲突（再说一遍，因为太重要）

前面几步都可以不做，但这个**必须做**。没有冲突的视频就是流水账，观众不会看的。

### 4.5 节奏感——长短句、押韵、排比

看一个叫"邱奇玉"的博主的视频，他的节奏感极强。

怎么练：
- **长短句交替**。短句一顿，长句一缓，节奏就出来了。
- **押韵**。不是说唱歌手那种，是读起来流畅。不会就去问豆包。
- **排比**。"我做错了什么？我放弃了什么？我得到了什么？"
- **遇到句号、问号、感叹号就换行。** 这不是排版技巧，是逼你把每一句都当一句话来说。

## 步骤五：设计场景——场景决定片子质感

**场景必须跟你的文案内容匹配，不可逆。**

### 5.1 场景和文案的对应关系

| 文案内容 | 场景 |
|----------|------|
| 深夜宝妈心酸 | 关了灯、拉上窗帘、孩子睡着了 |
| 创业艰辛 | 下班后的厂房、空无一人的车间、晚上开车回家路上 |
| 自律博主 | 凌晨4点天刚泛白 |
| 音乐故事 | 后台候场、酒吧角落、抱着乐器 |
| 亲子推荐 | 抱着孩子、跟孩子一起坐地上看书 |
| 美好回忆 | 日落时分、海边、蓝调时刻 |
| 北漂/深漂共鸣 | 深夜街头、路灯下、空旷的街道 |

### 5.2 四个最佳拍摄时段（按氛围排序）

1. **日出**（凌晨4-5点）：自律、奋斗、新生。夏天日出时天刚泛白但太阳没完全出来——这时候讲"我是如何自律的"比你白天讲有说服力一万倍。
2. **日落**（傍晚7:30-8:00）：美好、告别、回老家vs留城市。夕阳沉入海面，天空是柔和的蓝——这种画面在北京、上海、深圳的写字楼里永远看不到，因为他们还没下班。所以你拍这个，大城市的人会被画面本身吸引。
3. **蓝调时刻**（日落后10-20分钟）：唯美、诗意、沉思。太阳刚落山，天还没黑透，天空是最蓝的十几分钟。适合有文学感的文案。
4. **夜晚**：情感共鸣、孤独、不容易。昏黄路灯、空旷街道、车流穿过。讲创业经历、讲自己被社会碾压的故事——放在夜晚就对了。

白天直射光拍东西，除非你是拍婚纱照需要那种强烈日光，否则不好出效果。

### 5.3 物品元素——让画面替你说话

- 搞音乐的 → 抱着乐器
- 宝妈 → 满地玩具、奶瓶、孩子
- 海边护肤 → 防晒喷雾、好看的穿搭
- 想让人觉得你有文化 → 书

这叫道具。人靠衣装，合适的物件会让观众**下意识给你贴标签**。好莱坞让坏人洗白的方式是什么？让他救一只猫。一个超级坏的人抱着一只猫，你就觉得他没那么坏了。这些物件在替你说话。

### 5.4 色调——决定你的性格

冷暖两种基调，能驾驭一种就够了：

- **暖色**（红、黄、橙）：热情、温暖、积极
- **冷色**（蓝、白、黑）：理性、冷静、酷

王家卫的电影为什么一眼能认出来？色调。你不用做到那个水平，但要有意识地统一。你是热情的→暖色系穿搭+暖色场景。你是理性的→冷色系。保持统一，就是质感。

## 步骤六：表现力——一学就会，不学就不会

### 6.1 每天对着镜子说话

没有别的技巧。看着自己说话，自己跟自己聊天。表演训练里就这么干的——能看清自己就不会紧张了。

柯老师第一次上课也紧张得不知道自己讲的是啥。就是多说，说多了就松了。

### 6.2 把自己放进情境中

不是说"你现在要哭"，而是把人放进那个情景里。

柯老师的导演老师导戏时，不会说"眼睛要怎么样、鼻子要怎么样"，他会说："假设你赔了五十年的积蓄，赔了大几千万，老婆孩子都离开了你。"演员听完就能哭。你把观众当成你闺蜜、当成你身边那个人，自然就有感觉了。

### 6.3 脸就是钱，一定要露脸

好看有好看的卖法，不好看有不好看的卖法。年轻有年轻的卖法，年长有年长的卖法。

AI能生成任何帅哥美女，但观众不会为AI形象买单——因为它假。人设值钱的是你**这张真实的脸**。

让柯老师卖几十万的东西他卖不了，因为他长得不像能卖那么贵东西的人。卖几千块的他能卖。00后的小孩卖几十块的东西决策成本低，卖得飞快。

**你的脸就是你的定价。** 不出镜，这条命就废了一半。

## 步骤七：拍摄与包装——把片子包出质感

### 7.1 BGM——不要用剪映自带的

下一个网易云或随便一个音乐APP，平时就听。听偏古典的东西能提高审美。

方法：听到一首歌有感觉，转给自己微信文件传输助手，备注感受——"深情叙事""轻松愉悦""悲伤""怀旧"。积累多了，做片子的时候去自己库里找，而不是在剪映热门BGM里跟几百万人撞。

**千万别用剪映自带热门BGM。** 观众听了不下100遍了，听到就划走。

### 7.2 音效与白噪音——画龙点睛

不是必须加，但加上更好：海边加海浪声、下雨加滴答声、黑夜加蝉叫青蛙叫。

白噪音能把观众瞬间拉进一个情景里。这是锦上添花的东西。

### 7.3 字幕与字体——反映你的性格

- 喜欢简洁内敛 → 宋体、瘦金体、颜宋体（柯老师自己用的）
- 年轻活泼 → 花哨的彩色字体

但原则是**简洁**。太花哨的字体会干扰观众看你的脸和听你说的话。

### 7.4 大标题与小标题——给人看，更要给机器看

**大标题**放在画面顶部空白处（避开点赞收藏同城那些功能条）。让人瞬间知道这视频在讲什么。

**更重要的是给算法看。** 抖音有300多万个算法标签（2024年数据），算法会把你的每一帧画面切开来分析，然后给你打标签。你把大标题写清楚，就是直接告诉机器"我讲的是什么"，它给你推人就更精准。

**小标题**用来扩展推流人群。比如"即将崩溃的宝妈""90后的真实生活状态"——不只是宝妈能看到，90后能看到，甚至"即将崩溃"的人不管男女老少都能被推到。一个视频尽可能多地打标签。

### 7.5 两秒跳出率——基本功

基本功合格，播放量就能过1000到2000。

你的视频在抖音上没过1000播放？**就是视频质量问题，没有别的原因。** 把前面这些基本功做好，它自然会起来。

## 步骤八：发布——上线前的最后一步

### 8.1 钩子要多备几条，测出来的才算数

开头那句话不要只写一条。准备三五条不同的钩子，发出去看哪条好用。

柯老师去年做无人机时，那句"我花5万块钱从一家店到三家店，我是怎么做的？"卖了400多万。但在这句话之前，他试了好几十句。最终这句话好用，就一直用到它没用为止。

### 8.2 不看播放量，看粉丝说什么

做人设号的运营标准只有一个：**粉丝对你说什么。**

- 粉丝说"美女加微信" → 大概率号废了，冲着脸来的，换号。
- 粉丝说"老板你好，你家这东西怎么卖？" → 意向客户来了，这个号对了。

人设号不看播放量和刷礼物数，只看这个。通过内容让观众有购买的冲动和意向，你就可以不花广告费。而且人设视频投流极便宜——100块钱能买4000到5000播放。

## 附录A：起号保底公式

如果你实在没方向，用这个公式保下限：

1. **第一阶段（30-50条）：讲自己的经历和故事。** 你是谁？做过什么？经历过什么？
2. **第二阶段（50-100条）：讲自己正在做的事。** 今天学了什么？做了什么？有什么收获？身份放低，记录成长过程。
3. **第三阶段：讲你和粉丝/客户的故事。** 谁用过你的方法/产品？怎么改变的？沟通过程是什么样？

三个阶段走完，你会有一个能变现的账号。

## 附录B：老板IP不听话怎么办——苏格拉底式提问法

你学了一堆知识去上班，发现IP根本不看稿子，老板不按你写的念。

**解决方案：用开放式问题去问老板。** 你想让他说什么主题，就用提问的方式引导他说。拍的时候把你自己提问的部分剪掉，剩下的就是他的自述。

柯老师给一个迪派的客户用这个方法，一天拍了20条视频。一家公司一个月也就发20条，你一天把一个月活干了，剩下的时间就是你自己的。

---

## 附录C：认知碾压——面试和谈价的武器

去面试时，老板大概率会让你"看一下公司的号"。你把我课上教的这些——两秒跳出率、五秒完播率、原子性、信息密度、场景设计——摆出来分析他的号。

老板听不懂，但会觉得你很厉害。"这么专业，你来干吧。"

谈价也是一样。不要一上来就报多少钱，先看对方的号，一顿分析。对方觉得你专业得他都听不懂的时候，你再谈价格就占据了优势。

## 附录D：工具速查
