# 2026-07-10 短视频大班Day1 · 给自己做一个能变现的账号定位

> 这份不是课堂录音的照搬。我把Day1讲的所有知识点，按你**给自己做定位的实际流程**重排了——从"我有什么"到"怎么变现"，四步走完，每一步挂上课上讲的方法和案例。

## 流程图总览

```
收集信息 → 整理长短 → 找到用户 → 链接变现
```

---

## 步骤一：收集信息——搞清楚"我有什么"

**【做什么】**

把你所有东西摆出来：经历、技能、资源、时间、性格特点。有什么就写什么。自己列完清单只是第一步——如果你帮老板或别人做号，你还要会问。

**【用什么】**

**开放式提问**：让对方把东西全倒出来。

- ❌ "你只有一个男孩吗"——封闭式，对方答"对"，天聊死
- ✅ "你家什么情况？有几个孩子？平时谁带？"——开放式，答完一个引下一个

**苏格拉底式提问**：开放和封闭组合着用。先抛开放式让对方打开话匣子，再用封闭式锁定具体信息。看窦文涛的《圆桌派》——所有问题围绕观众视角去追问，不让对方厌烦，又能得到你要的答案。《奇葩说》也是，由浅入深——从职场问题聊到老板和打工人的心理。

**用AI帮你提问**：你对某行业不熟，要帮老板做号——让AI列问题你去问。

提示词：
> "我想帮一个做XX行业的老板做短视频号，但他表达逻辑不强。请你用苏格拉底式提问帮我列10到20个问题，由浅入深，帮我把他的经历、技能、观点全挖出来。"

但前提是——你自己先掌握了提问原理，再去用AI。别反过来。

**【避什么坑 + 例子】**

表达逻辑不强的人怎么办？别一上来就用大开放式问题，他接不住。先用封闭式当引子——"你是做海参的是吧？养了多少年了？"——再用开放式展开——"这些年有没有什么让你印象特别深的事？"

普通人不太具备侃侃而谈的能力，你要帮他。这叫信息挖掘。

## 步骤二：整理信息——长处打牌，短处也能当牌

**【做什么】**

摆完信息，分两堆：你擅长什么、缺什么。**两条路都能走。**

**【用什么】**

**长处怎么打**——宠物博主有爱心、善良、能量正，打情感牌。

**以弱胜强**——短处也能变成长处。你在某个行业不擅长、经验不足？直接说出来。坦诚=人设中非常高含量的特质。

柯老师给学生讲海参号的第一句文案：

> "今天是我去海鲜养殖场学习的第一天。我才发现，养海参的水是流动的。因为潮起潮落，天然的氧要进去。原来海参是不需要喂饲料的。"

一个不懂海参的新手，不是劣势。你学习的每一步都是内容——从"新手"到"逐渐懂"的过程，本身就是最有说服力的人设。

**主动暴露缺点赢信任**：年龄焦虑、长相焦虑、身材焦虑——不知道怎么拍？拍你的焦虑。当你主动暴露自己不会的时候，观众觉得你坦诚。而坦诚是能变现的。

**【避什么坑 + 例子】**

别拿抽象词描述自己。"我是个善良的人""我是专业的教练"——这些没用。**人设不是描述出来的，是做出来的。** 你救助一只猫的过程说明你善良。你记录学习海参的每一天说明你坦诚。每一个小事件叠加=你的人设。

简化理解：想减肥，从100公斤减到80公斤。中间是一条条视频——今天吃了什么、怎么练的、怎么睡的。这些视频加了你的观点，组成了你的人设。

## 步骤三：找到用户——谁为你买单

**【做什么】**

搞清楚谁会看你、谁可能掏钱。**做账号不能自嗨。变现跟粉丝量没有关系。**

**【用什么】**

**三种找用户的方法：**

1. **分析真实客户**。有生意的，把老客户剖开——多大年龄、男的女的、住哪儿、买的时候第一句话问什么、担心什么、买完什么行为。
2. **查同类账号粉丝画像**。不是对标（你想成为他），是同类（你跟他同行业）。用抖音指数搜同行的号，看他的粉丝男女比例、年龄段——这就是你的用户画像。
3. **把自己当用户**。行业太小众找不到参考——卖萨克斯吹嘴的，搜不到数据——问自己：如果我是我的客户，我关心什么？

**马斯洛选题法**——所有行业都能套：
- **生理层**："让你活下去"的问题。食品安全出问题→全人类关心。海参打不打药→一条跑了一千多万播放。315为什么每年都火？揭露各行各业对生理造成威胁的点。**任何行业绑定生理安全维度，流量不会差。**
- **安全层**："如何让你变得更好"。美食/穿搭/学习/健身/创业/教育博主——有技巧有经验就做这一层。
- **社交层**："让观众帮你转发"。女人看完分享给老公——"你看看人家怎么做家务的"。男人看完分享给哥们——"义父们，看这条"。想要男粉就说理解男人的话，想要女粉就说女人多不容易。**你能控制粉丝的男女比例。**
- **尊重层 & 自我实现层**：最难驾驭，最容易变鸡汤。但做成了极其值钱——财经、股票投资类博主，能讲明白的人极少。

**IP vs 网红**——决定你走哪条路：

|  | IP | 网红 |
|---|---|---|
| 做什么 | 影响别人做决策 | 被大众娱乐 |
| 变现 | 直接转化，快 | 靠广告，不稳定 |
| 生命周期 | 长 | 短，品牌方榨干就换人 |
| 需要的 | 真诚、专业 | 娱乐性、表演力 |

柯老师一个摄影师朋友——去年讲摄影器材，一个月接两三个广告，每条2000-4000。涨粉最好的时候让他做自己的课程他不做，沉迷流量。现在大品牌不找他了，接小品牌，还在焦虑。"想做长久生意就做IP。"

**【避什么坑 + 例子】**

**不要觉得必须有高播放量才能变现。**

柯老师自己的号不到200个粉丝，变现6万块。一个律师看了内容觉得对，开车过来聊了两小时，付了钱。第十条视频的时候他又推荐了四个朋友。

另一个案例：无人机新手学生，拍了一条训练视频——只拍到飞机飞过和一条横幅，播放量不到100，还被限流。但被当地一个玩无人机的人刷到，成交了两三千块。

**粉丝量和变现是两条线。** 别把心思全花在搞播放量上。

**⚡ 加分项：黑转粉——有人骂你，你不用怕**

董宇辉火三次，三次都靠黑粉起跳。别人刷嘉年华羞辱他，他拉黑——大家觉得他有骨气。别人骂他是背稿主播，他大方承认"对，我就是背稿的"——大家因为他坦诚更喜欢他。

核心操作：当你揭秘行业内幕遭到同行诋毁时——**把你怎么应对的过程拍下来，就是最好的内容。** 同行骂你越凶，你内容越有料。做海参被同行骂"你污蔑行业"——你把做这件事的初衷公布出来，把你见到的真实证据摆出来。全程记录打官司的过程，彩虹星球打了12年靠这个起号。

## 步骤四：链接变现——让用户为你买单

**【做什么】**

找到用户后，问自己：**他凭什么换你？** 你凭什么让他放弃原来买的那个人？

**【用什么】**

**产品设计**——你得想清楚靠什么赚钱：
- **轻交付**：卖货。付钱发货交易结束。时间成本低，但需要货品。
- **重交付**：卖服务、卖课。你得帮学生落地，服务一个周期。没库存成本，但占时间。
- **别靠广告**。广告不稳定，品牌方能榨干就榨，榨完换人。柯老师的摄影师朋友就是反面教材。

如果现在什么都还没有——你学会了新媒体运营，替别人做号就是产品。或者利用身边渠道带货拿分成，或者帮学校招生。

**人设内容 + 私域成交**——不投流的做法：

柯老师团队做海参号（小迪姐那个）：去客户那里拍内容，后台私信只加微信。不加就不卖。等开海节或者真捞海参的时候开直播，也不在直播间成交——全在微信里。**私域里想怎么卖怎么卖，前提是不能骗人，东西真的好。**

投流越来越贵，平台赚的就是创作者和消费者之间交易的钱。投过一次之后，除非你的作品极其好能自己跑出去，否则你得一直投。

**【避什么坑 + 例子】**

海参案例：你的客户是53岁山东人，他在雨生大哥那买海参。你凭什么让他换你？

因为你是大连的海鲜渠道、你懂海参、你还知道海参配小米粥比配鸡蛋吸收好——小米粥是碳水、海参是蛋白质，一起吃吸收率最高；鸡蛋也是蛋白质，一起吃不吸收。输出这样的观点，就建立了链接。

**变现的第一个分叉口**：不在于你有多少粉丝，在于你有没有产品。没有产品，再大的流量也会流走。

## 附录A：单点击破——找到你自己的强项

短视频是**单点击破效应**。你在某一点特别强就能出圈——文案强、拍摄强、表现力强、剪辑强，都能。

**怎么找**：做一条完整的视频，从策划到拍到剪。看哪一步你进入状态最快。柯老师写文案瞬间进入，但拍的时候永远get不到光比偏大还是偏蓝——他的强项是策划和文案。

**面试怎么用**：展示你的能力。永远别说自己是新手——就说干过。用学习的时间做出几个案例。你给老板做到这个程度，要多少钱都行：

柯老师最早谈修车店老板——先翻看大量修车视频，发现同行都在讲修车技巧，差一点的搞擦边。问了老板一个问题："你想赚有钱人的钱还是穷人的钱？"老板说有钱人。于是用"家庭关系+修车"，做了一条替男人发声的情感视频。第一条跑了3.8万播放。费用8000一个月——他付了。单月留资200到300条。账号叫"大连快球大王"，现在还能搜到。

## 附录B：自媒体判据——你在做自媒体还是传统媒体？

**自媒体 = 客观事实 + 你自己的观点。**

大连昨天下暴雨——这是事实。但你对暴雨怎么看？为什么甘井子老城区发洪水，东港没积水？你觉得是老城区经济不好、市政不愿投钱——这是你的观点。两样加一起=自媒体。

烘焙店涨价：面粉涨价了所以蛋糕要涨价——这是新闻通稿。但你说"老式面包就是好，因为没有乱七八糟的添加剂。虽然长得不好看，但我就觉得老式面包应该是这样的"——加了观点，赞同你的人会为你买单。

**每做一条内容问自己：这条东西里，有我的观点吗？没有 → 你在干传统媒体的活，不算自媒体。**

## 附录C：A-roll/B-roll——怎么把文案变成画面

**A-roll（主线）**：你说的话。第一部片子就是自我介绍——我是谁、在做什么、能为你做什么、优势在哪。两分钟以内。

**B-roll（画面）**：把A-roll文案里的**名词和动词**拍下来。"我在大连拍视频"→名词"大连"拍星海广场、有轨电车；动词"拍视频"拍第三视角你拍摄的过程。两个画面一组合。

**音乐要匹配起承转合**：00后充满希望→欢快。90后经历社会毒打→《平凡之路》那种。赔过钱一定不能配欢快音乐。

## 附录D：拍摄保底三条

1. **声音清晰**：买猛犸A1麦克风，一百多块钱。没有就找安静环境。
2. **画质清晰**：拍之前把镜头擦干净。
3. **光线充足**：顺光拍（站灯下面），人脸要亮。不要逆光。

别觉得没东西可拍。每个人都是有故事的。在北京待了六年，住过天通苑，知道早高峰被挤上挤下的感觉——拍出来成千上万跟你一样经历的人会有共鸣。你们00后大一赶上疫情，四年大学在学校只待了几个月——说出来一波人有共鸣。
