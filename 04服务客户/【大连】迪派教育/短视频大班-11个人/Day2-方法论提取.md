# Day2 方法论提取 · 可复用知识框架

> 提取原则：不是所有教学内容都是方法论——只提取跨学员、跨账号可复用的判断框架和操作流程。单次对谈的个案建议（如对某学员说"你做这个方向"）不入库。

---

## 一、短视频底层原理（3条）

### 1.1 原子性法则
> 短视频的"短"不是时长的短，是信息密度。

- 每5-7秒给观众一个新刺激点（新信息/情绪转折/观点/画面变化）
- 算法惯着观众→观众浮躁→需要高频信息刺激
- 信息密度 = 原子性 → 决定完播率
- 适用：所有短视频类型

### 1.2 冲突对抗性原则
> 短视频必须有冲突。没有冲突就是平铺直叙，观众不留。

- 冲突来源：工作vs家庭、大城市vs回家、专业vs转行、躺平vs奋斗
- 电影/文学/历史的底层逻辑就是对抗——短视频也一样
- 操作：每个选题先找对抗点，然后再写内容

### 1.3 具象化表达原则
> 文字能在脑子里构建画面。不要用抽象词。

- 方法：抽象+具象 → "我有超强时间管理能力" → "我一天买菜、带娃、换尿布、开会、剪视频，每项都完成"
- 方文山式文字画面感：用具体动作/场景/时间/数字
- 口诀：用"do"句型替代"be"句型

## 二、视频制作基本功（按制作流程）

### 2.1 开场前两秒——情绪优先
- 不用"欢迎收看XX的VLOG"
- 直接进入情绪状态："嘘，这就是我现在凌晨1点当宝妈的真实状态"
- 判断标准：观众能否在2秒内进入你的情绪

### 2.2 BGM选择——不用剪映自带
- 日常听古典音乐提高音乐审美
- 建立自己的BGM素材库：听到一首歌→备注感受（悲伤/开心/深情叙事）→存微信文件传输助手
- 不用剪映自带BGM：听的人太多，观众听觉疲劳
- 不同场景配不同BGM：叙事=安静深沉 / 快速动作=轻快明亮 / 回忆=民谣

### 2.3 音效白噪音——画龙点睛
- 风声、雨声、海浪声、蝉叫蛙鸣——不是必须加，但加上更好
- 作用：瞬间把观众拉进情景

### 2.4 字体——简洁原则
- 字体反映人的精神状态
- 不花哨：花哨字体干扰人脸和说话内容
- 个人审美就是你的辨识度

### 2.5 大标题+小标题——给人和机器看
- 手机屏幕=画板，顶部空白=标题位
- 大标题：让观众瞬间知道主题（也给算法打标签）
- 小标题：扩展受众范围（"90后崩溃宝妈"→90后+宝妈+崩溃人群都看得到）
- 算法标签系统：抖音300万+标签，机器逐帧抓取关键词

### 2.6 色调——决定性格
- 暖色=热情；冷色=理性/冷酷
- 能用冷暖对比更好，做不到就选一种主色调
- 色调=基本功，和场景、道具一起构成画面语言

## 三、内容结构与文案手法

### 3.1 两种基础文案结构
| 类型 | 适用场景 | 示例 |
|---|---|---|
| **清单式** | 起号最快 | "宝妈崩溃的五个瞬间""大连海鲜的三大类" |
| **故事型** | 深度内容/个人IP | 背景→冲突→转折→结论 |

- 初期建议单独使用一种，熟练后融合
- 清单式+故事型融合 = 文学级内容

### 3.2 五个核心文案手法
| 手法 | 口诀 | 操作 |
|---|---|---|
| **可视化** | be→do | "我是一名宝妈"→"辞职回家带娃的95后" |
| **专属细节** | 精确到分钟 | "2026年5月28号14:32分，我收拾了桌上的合同" |
| **故事感** | 必须有冲突 | 每个视频至少一个对抗点 |
| **高光时刻** | 给自己包装 | "销冠离职"比"销售离职"更高级 |
| **节奏感** | 长短句+押韵+排比 | 遇句号/问号/感叹号就换行 |

### 3.3 疑问驱动完播
- 不要让观众"知道"，让观众"想知道"
- 操作：每个段落结束时留一个未解答的问题
- 短剧逻辑：冲突→疑问→想看下一集

### 3.4 AI辅助写稿流程
1. 先自己说（语音转文字），不要打字
2. 说完了发给豆包，提示词："保持原意，优化长短句/押韵/排比/停顿"
3. 豆包优化后，自己读一遍——不符合自己说话语气的字词就改

## 四、创作流程（六步法，顺序不可乱）

```
① 找选题（行业对抗点）→ ② 自己构思（强制深度思考）→ ③ 搜同行收集素材
→ ④ 删减筛选（哪些能用、哪些不适合自己）→ ⑤ 选择结构（清单式/故事型）
→ ⑥ 写文案→读→改→设计场景→拍摄→剪辑→发
```

- 顺序不能乱。乱了就会走捷径→被AI操控→丧失判断力
- ②构思是核心：大脑本能回避深度思考，必须强制自己先想
- 抄袭走不远。借鉴同行但必须改编、融合自己的东西

## 五、账号运营策略

### 5.1 定位顺序：先自己→再观众
> 赚钱不等于有流量。流量是赚钱的必要条件不是充分条件。

- 不要先看什么赛道火：你能驾驭吗？适合自己的才是对的
- 流程：我有什么（技能/经历/资源）→这些能吸引什么样的人→怎么变现
- 行业好≠你能挣钱，一比九比例

### 5.2 定制策略：两个领域相加 = 新赛道
- 公式：核心能力A + 兴趣领域B = 独一无二的账号
- 案例：音乐+数码=音符可视化爆款 / 编程+AI=AI短视频 / 健身+音乐=健身vlog配原创曲
- 操作：先删（只留一个主方向），再测（把过往经历往里套）

### 5.3 三阶段起号公式（保下限）
| 阶段 | 内容 | 视频量 |
|---|---|---|
| 第一阶段 | 讲自己的经历和故事 | 30-50条 |
| 第二阶段 | 讲自己正在做什么（学习/成长过程） | 50-100条 |
| 第三阶段 | 讲你和粉丝/客户的故事（产品转化） | 持续 |

- 适用：履历平、没方向、老板没特点——都能用这个公式起号
- 核心：身份放低，记录真实成长

### 5.4 平台真相：抖音喜欢小博主
- 平台要让池子保持均衡——不能依赖大博主（参见快手辛巴教训）
- 证据：封小杨哥、封东北雨姐后推素人——抖音不希望被定义成"只有头部"
- "2026年做抖音不晚"的理由：平台需要新鲜血液

### 5.5 人设运营核心指标
> 不看播放量，看粉丝对IP说什么。

- "美女加微信"→号作废（冲颜值来的）
- "老板你好这个东西怎么卖"→有效留资
- 人设视频投流便宜：100元=4000-5000播放

## 六、表现力与拍摄

### 6.1 表现力提升
- 方法一：每天对着镜子说话（克服紧张，看熟自己）
- 方法二：把自己放进情境中去（不是"演"哭，是"想到自己赔了5000万"）
- 核心：多拍，熟能生巧

### 6.2 脸就是钱
- 人们不为AI形象买单——因为假
- 好看/不好看/年轻/年长各有卖点
- 露脸 = 人设真实性 = 信任基础

### 6.3 拍摄黄金时间段
| 时间段 | 氛围 | 适合内容 |
|---|---|---|
| 日出（凌晨4-5点） | 自律感 | 自律打卡/晨间日常 |
| 日落（19:30-20:00） | 回家的感觉 | 城市vs老家/情感共鸣 |
| 蓝调时刻（日落后10-20分钟） | 唯美诗意 | 文艺/文化内容 |
| 夜晚（路灯+车流） | 情感深沉 | 创业艰辛/人生感悟 |

### 6.4 场景搭建顺序
> 先有文案→再定场景→场景必须契合文案内容

- 宝妈深夜吐槽→关灯/拉窗帘/抱着孩子
- 搞音乐的故事→排练房/后台/抱着乐器
- 讲创业经历→厂房检查下班后/开车回家路上（不能太平）

### 6.5 物品元素 = 人设道具
- 抱乐器=搞艺术的 / 放书=有文化的 / 满地玩具=带娃的
- 影视行业叫"道具组"——短视频也一样，道具决定观众对你的第一判断

## 七、变现路径（五种）

| 编号 | 路径 | 门槛 | 收入预期 |
|---|---|---|---|
| ① | 接广告（星图/蒲公英） | 强专业性+3-4千粉 | 5000-8000/月 |
| ② | 平台收益（抖音/视频号） | 极强内容输出能力 | 不稳定 |
| ③ | 卖自己的产品/服务 | 有产品/可复用的知识 | 边际成本趋近零 |
| ④ | 直播卖货 | 货源/供应链 | 高投入高回报 |
| ⑤ | 短视频挂车卖货 | 选品眼光 | 中等 |

### 七点补充
- 上班≠放弃账号。你上班的工资不是老板决定的，是你的账号决定的
- 有几千粉丝的号，老板不敢开你、不敢骂你、不敢让你加班
- 内容价值决定投流效果——好内容100元能买到上万播放

## 八、职场技巧

### 8.1 苏格拉底式提问——应对不听话的IP/老板
- 问题：IP不看稿子、老板不配合
- 方案：用开放式问题提问→把答案录下来→剪掉提问部分→变成他的自述
- 效果：一天拍10-20条，一个月量一天搞定

### 8.2 认知碾压——面试/谈价技巧
- 老板问"投流多少钱"→不要说价格→说"我先看看你的号"→分析讲解→认知碾压
- 老板听不懂→觉得你专业→你把主动权握在手里→谈价格
